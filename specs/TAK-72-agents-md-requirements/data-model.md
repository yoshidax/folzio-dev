# Data Model: エージェント向けの規約の置き場所を AGENTS.md に限らない

この feature のデータは、リポジトリの文書の構成である。

## エージェント向けの規約

- **構成**: `AGENTS.md`（入口）と、`AGENTS.md` から参照する文書の全体
- **規則**:
  - エージェントが従う運用の規則は、この全体のどこかに1か所だけ置く（`docs_private/agents/README.md` の置き場所の基準）
  - 製品仕様は、置き場所を「エージェント向けの規約」として指定し、`AGENTS.md` の本文を指定しない（FR-307）
  - 同じ状況に対して、異なる指示を出す規則が 0 件である（SC-094（変更））

## AGENTS.md（入口）

- **属性**: 行数（上限は `scripts/dev/check-agents-md.sh` の `MAX_LINES`）、見出し（適用範囲の【】を持つ）、規則の行、参照の行
- **規則**:
  - 行数が上限を超えると、検査が失敗する（FR-309）
  - 参照するリポジトリのパスが存在しないと、検査が失敗する（FR-310）
  - 見出しと参照の行は、適用範囲を示す（FR-195（変更））

## 参照

- **属性**: 読むべき作業や状況、参照先のパス、適用範囲
- **規則**:
  - 読むべき作業や状況を示す（FR-308。例: 「バグを直す: `docs_private/agents/bugfix.md`」）
  - 参照先のパスが存在する（FR-310）

## 運用の文書（参照先の `docs_private/` の文書）

- **属性**: 冒頭の適用範囲の行（`**適用範囲**: 【…】`）、節
- **規則**:
  - 冒頭に、文書全体の適用範囲を示す（FR-195（変更）、research.md の R3）
  - 区分の違う節は、節の見出しにも【】を付ける

## 状態の遷移

なし。
