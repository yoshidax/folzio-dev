# Feature Specification: フォルダと zip の行頭アイコンの固定色

**Feature Branch**: `claude/adoring-mccarthy-vgojyp`（Cloud が指定した作業ブランチ。feature ディレクトリとは独立）

**Created**: 2026-11-02

**Status**: Draft（設計レビュー待ち）

**Input**: [TAK-46](https://linear.app/takyoshida/issue/TAK-46/リストビューのフォルダアイコンを青固定にzip-ファイルのアイコンを黄色固定にする)「リストビューのフォルダアイコンを青固定に、zip ファイルのアイコンを黄色固定にする」。
会話で「ISSUE TAK-46に対応して」と依頼され、次の点を保守者が決めた。

- 青は、外観モード・アクセントカラーによらない固定の `NSColor` 値で定義する（`.systemBlue` ではない）
- 黄色は `.systemYellow` を基準にし、青との明度が近くなるよう固定値を調整する
- `..` の行とメディアのフォールバックアイコンは現状（`secondaryLabelColor`）を維持する。検索結果は同じビューなので同じ表示とする
- ツリーの色は変えない（対象外）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。行頭アイコンの種類は FR-048・FR-076（file-list.md）、ツリーのフォルダアイコンは FR-047・A-28（directory-tree.md）に従う。US48 は永続シナリオ ID。

### User Story 1 - フォルダが一覧でも青で見える (Priority: P1)

利用者は、ファイルリストのリスト形式・サムネイル形式で、フォルダの行頭アイコンがツリーと同じ青で表示されるのを見て、同じフォルダがペインによって違う色に見える違和感なく使える。

**Why this priority**: Issue の中心の価値。

**Independent Test**: フォルダと zip を含むフォルダを開き、ライト／ダークの両方で、フォルダの行頭アイコンが青、zip が黄色であることを目視する。

**Acceptance Scenarios**:

- **US48-AS1**: **Given** リスト形式のファイルリストに通常のフォルダの行がある、**When** ライト・ダークのどちらでも表示する、**Then** 行頭アイコンは FR-255 の青で表示する。
- **US48-AS2**: **Given** サムネイル形式で zip の中のディレクトリの行がある、**When** 表示する、**Then** 行頭アイコンは FR-255 の青で表示する。
- **US48-AS3**: **Given** macOS のアクセントカラーを変更する、**When** ファイルリストを表示する、**Then** フォルダの行頭アイコンの色は変わらない。
- **US48-AS4**: **Given** 検索結果の一覧にフォルダが含まれる、**When** 表示する、**Then** 通常のファイルリストと同じ色で表示する。

---

### User Story 2 - zip がフォルダと区別できる (Priority: P1)

利用者は、zip ファイルの行頭アイコンが黄色で表示されるため、フォルダと一目で区別できる。

**Why this priority**: フォルダを青に固定すると、zip との色の区別が必要になるため。

**Independent Test**: zip ファイルとフォルダが並ぶ一覧で、zip が黄色、フォルダが青で表示される。

**Acceptance Scenarios**:

- **US48-AS5**: **Given** リスト形式またはサムネイル形式に zip ファイルの行がある、**When** 表示する、**Then** 行頭アイコンは FR-256 の黄色で表示する。
- **US48-AS6**: **Given** 行を選択して選択行の背景が変わる、**When** フォルダ・zip の行頭アイコンを見る、**Then** アイコンの色は固定のまま、判別できる。

---

### User Story 3 - 対象外の表示は変わらない (Priority: P2)

`..` の行とメディアのフォールバックアイコンは、従来どおりの表示を保つ。

**Why this priority**: 影響範囲を Issue の対象に限る。

**Independent Test**: `..` 行とメディアの汎用アイコンの色が変更前と同じ。

**Acceptance Scenarios**:

- **US48-AS7**: **Given** zip の中や階層の途中に `..` の行がある、**When** 表示する、**Then** 行頭アイコンは従来どおり `secondaryLabelColor` で表示する。
- **US48-AS8**: **Given** メディアの縮小画像の生成前または失敗時、**When** 汎用アイコンを表示する、**Then** 従来どおりの色で表示する。縮小画像の表示は変わらない。

### Edge Cases

- **EC-178**: ダークモードや選択行の背景（アクセントカラー）でも、固定色のアイコンは背景と区別でき、読めなければならない（アイコンは名前の補助であり、ファイル名は変わらず読める）。
- **EC-179**: アイコンの色を変えても、サムネイルの縮小画像、選択、キーボード操作、読み上げは変わらない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-255**: ファイルリストのリスト形式とサムネイル形式で、フォルダ（通常のフォルダ、zip の中のディレクトリ）の行頭アイコンは、macOS の外観モード（ライト／ダーク）とアクセントカラーによらず、固定の青で表示する。青はアプリが固定値として持ち、ツリーのフォルダアイコンの青に見た目を合わせる。
- **FR-256**: 同じ 2 つの形式で、zip ファイルの行頭アイコンは固定の黄色で表示する。黄色は FR-255 の青と明度が近く、同じ一覧で並べたとき統一感があるよう調整した固定値とする（外観モード・アクセントカラーによらない）。
- **FR-257**: `..` の行の行頭アイコンとメディアの汎用（フォールバック）アイコンの色は変えない。
- **FR-258**: 検索結果の一覧は同じビューを使うため、FR-255・FR-256 と同じ表示とする。ツリーの表示は変えない。

### Key Entities

- 新しいデータはない。行頭アイコンの種別（フォルダ・ディレクトリ・zip・`..`・メディア）ごとに表示色を決める。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-125**: ライト・ダークの両方で、リスト形式・サムネイル形式のフォルダの行頭アイコンの色が同一で、zip の色と区別できる。アクセントカラーを変えても色が変わらない。
- **SC-126**: `..` 行とメディアのフォールバックアイコンの色が変更前と一致し、ツリーの表示は変わらない。

## Assumptions

- **A-155**: ツリーのフォルダアイコンの青が AppKit の既定の描画に由来する場合でも、ツリーは変更しない。リスト側で同じ見え方にするための固定の青の値は、plan で確定し、保守者の GUI 確認（ライト／ダーク）で承認を得る。
- **A-156**: zip は現状 `ListItemKind.archive`（zip ファイル）だけを指す。
- **A-157**: 検索結果は同じリスト／サムネイルのビューのため、同じ表示になる（Issue の想定どおり）。

## 検証方針

アイコン種別ごとの色の割り当て（フォルダ・ディレクトリ・zip は固定色、`..` とメディアは従来）は、色の判断を AppKit に依存しない形に分けられる範囲で Swift Testing により検証する。実際の見え方（ライト／ダーク、アクセントカラー変更、選択行、ツリーとの色の一致）は保守者の GUI 確認に依頼する。macOS CI の build/test、Cloud の静的検査を分けて記録する。
