# UI Contract: スライドショー

**Date**: 2026-10-25 | **Branch**: `006-add-slideshow`

本 feature の差分契約。[spec.md](../spec.md) の要件本文を正とし、既存の [キーボードとメニュー](../../product/contracts/keyboard-and-menus.md) に対する追加・変更を記す。実装・検証後に product へ反映するまでは本 feature 内に置く。外部サービス・HTTP API・CLI は追加しない。

## 開始と終了

| 入力／表示 | 契約 | 要件 |
|---|---|---|
| ツールバー「スライドショーを開始」 | ペイン表示グループの右隣に1つの開始ボタン。実行中は無効にする | FR-114、A-47 |
| 表示 > スライドショーを開始 | 同じ開始 action を実行するメニュー項目 | FR-114 |
| ⇧⌘S | toolbar 非表示／全画面でも同じ条件で開始 | FR-114 |
| 実行中に下記の入力受理条件を満たす Esc | 全画面解除・検索解除・due より優先して1回だけ消費。送り・再開待ちを取消し、通常表示へ復帰。全画面なら同時に解除 | FR-123、変更後 FR-036/094 |
| 閉じる／アプリ終了 | 送りと保留処理を取消し、再起動時に再開しない | FR-126 |

開始ボタンのアクセシビリティラベルは「スライドショーを開始」、ツールチップは「スライドショーを開始（⇧⌘S）」とする。アイコンは既存の IconCatalog にある自前描画の方式へ合わせる。実行中に停止ボタンへ変形しない。

### 可否と無効時の副作用

| 条件 | 開始 | ペイン切替 | 戻る／進む |
|---|---|---|---|
| メディアあり・通常閲覧 | 有効 | 既存規則 | 既存規則 |
| 対象0件 | 無効 | 既存規則 | 既存規則 |
| 名前の変更中（全3種の名前編集） | 無効 | 無効 | 無効 |
| モーダル表示中 | 無効 | 既存規則 | 既存規則 |
| スライドショー active／復帰処理中 | 無効 | 無効 | 無効 |
| 全画面、非実行 | メディアがあれば有効 | 無効 | 無効 |
| 読み込み中／検索中、非実行 | 表示済みメディアがあれば有効 | 既存規則 | 既存規則 |

ボタン・メニュー検証・action 内 guard で同じ可否を共有する。無効な開始や重複開始は選択・ペイン表示・deadline に影響しない。実行中のペインボタン／メニューは preview-only の状態を示し、終了後は復帰先を示す。既存の編集やモーダルのキー処理を横取りしない。

## 対象と選択

- 対象は現在の表示順・フィルタ後の一覧全体の対応メディアだけ。フォルダ、zip 自体、zip 内ディレクトリ、親リンクは除外する。通常フォルダ、zip の現在階層、検索結果に同じ規則を適用し、別階層へ移らない（FR-115）。
- 開始位置は選択中のフォーカスメディア → 選択中メディアの表示順先頭 → 対象先頭。開始時に1件だけを選択・フォーカスし、プレビューへキーボードフォーカスを移す（FR-116/117）。
- 名前や行番号ではなく場所で識別する。zip 内は zip の場所と内部パスの組。同名別場所を同じ対象としない（FR-115）。
- 自動送りは3秒ごとに次、末尾から先頭へ循環。最新一覧を使い、対象1件なら同じ表示を維持する。非メディアを開いたり選択したりしない（FR-118、EC-66）。

## 実行中のキーと時間

### 入力受理条件と優先順位（U1）

スライドショーが Esc・矢印を受理するのは、実行中の対象ウィンドウがキー入力先で、対象のシートとアプリモーダルがなく、編集欄・メニュー等がそのキーを処理していない場合だけとする（FR-123）。条件外の Esc・矢印は既存の入力先へ渡し、スライドショーによる終了・全画面解除・検索解除・手動移動・期限再設定を行わない。monitor と responder fallback は同じ条件を使い、モーダル／編集を終えた同じキーを再適用しない。

モーダル表示中も自動送りは元の期限で続く。開閉・編集開始終了・そこで処理されたキーで期限を変えず、遅延時も最大1回だけ送る（FR-118/124）。これは新たな一時停止機能ではない。

| 入力 | 選択／再生 | 次の送りまでの待ち |
|---|---|---|
| ↑／↓（リスト） | 前／次のメディアへ、端で停止 | 押下ごとに3秒へ再設定 |
| ←／→（リスト） | 選択は不変 | 押下ごとに3秒へ再設定 |
| 上下左右（サムネイル） | 隠す直前のリスト幅から求めた列数で既存規則の移動。非メディアを飛ばし端で停止 | 押下ごとに3秒へ再設定 |
| 押し続けの矢印反復 | 通常の矢印と同じ | 反復ごとに再設定 |
| 修飾キー付き矢印 | スライドショーの移動に使わない | 不変 |
| Space、`<`／`>`、動画コントロール | 既存の動画操作。矢印を動画シークに使わない | 不変 |
| ⌃⌘F、画像ダブルクリック、既存全画面メニュー | 全画面切替。非 Esc の解除では preview-only で実行を継続 | 残り時間を保つ |
| 形式・サイズ・フィルタ・並べ替え変更 | 最新一覧・新設定に従う。隠れたリストの基準幅を維持 | 不変 |

受理した矢印の手動移動と自動送りが重なる場合は手動を優先し、二重に進めない（FR-121）。非 Esc の全画面切替では実行と残り時間を保つ（FR-122）。受理した Esc と送りが重なる場合は終了を優先し、同じ Esc を検索解除へ伝播させない（FR-123）。モーダル／編集のキーと due が重なる場合は既存のキー処理と元の期限での送りを行い、そのキーを終了・矢印の優先入力に数えない。

3秒は選択／プレビュー切替の操作を起点とし、デコード完了や動画終端を待たない。すでに同じ動画が見えている開始では再生位置と再生／一時停止状態を保ち、開始から3秒を数える。別メディアを経由して戻った動画は既存設定で先頭から表示する。自動再生・ループ設定は変更しない（FR-118/119）。

## 更新・異常・自動終了

| 出来事 | 契約 | 要件 |
|---|---|---|
| 追加・削除・並べ替え・フィルタ | 既存の選択整理の後、次の期限で最新のフォーカスの次、なければ先頭へ。期限は取り直さない | FR-125 |
| 現在対象の消去、残りあり | 空選択と空 preview を維持し、次の期限まで選び直さない。先に終了した場合も空のまま | FR-123/125、EC-68 |
| 対象0件 | 自動終了して復帰する。古い選択を復活させない | FR-125 |
| 同じ閲覧先の名前・場所の付け替え | 既存の URL／選択追従を継承し、実行と期限を保つ | FR-125、FR-104/105 |
| 別フォルダ・zip 階層・検索結果への置換 | 送りを終了し、復帰状態を確定してから置換する | FR-126 |
| 閲覧先消失・ボリューム取り外し | 既存規則の移動先または空表示を保って終了。古い閲覧先を戻さない | FR-126、EC-18/26/36 |
| 表示不能メディア | 既存エラー表示。通常の3秒で次へ。全件表示不能でも Esc が使える | FR-124、EC-67 |
| 遅延した結果・timer | 古い世代を採用しない。遅延回数分の連続送りをしない | FR-124、EC-70/71 |

## 復帰と履歴

通常ウィンドウの開始前 layout・focus・3ペイン幅へ戻す。全画面から開始していた場合も全画面化前の通常状態へ戻す。window frame を戻さず、幅が足りなければ preview → file list → tree の順に最小幅まで詰める。最小幅は160/240/320pt。現在の有効な選択だけを保ち、リストが見える場合は必要最小限スクロールする。消えた選択・開始前の選択を復活させない（FR-117/123）。

終了だけを理由に最後の動画を停止しない。復帰先が file-list-only の場合は既存どおり停止・消音する。実行・期限・復帰情報を保存せず、起動時は通常の3ペイン表示とする（FR-123/126）。

開始・終了・一時的ペイン変更・自動送り・矢印は履歴を増やさない。通常閲覧でユーザーが変えた形式・サイズ・フィルタ等は、復帰先の layout とともに通常どおり記録する。検索結果中は FR-113 の非記録を優先する。終了で検索を解除せず、後日の検索解除時に通常表示を現在の履歴へ反映する（変更後 FR-107/112）。

状態の責務・世代・遷移は [data-model.md](../data-model.md)、検証手順は [quickstart.md](../quickstart.md) を参照。
