# Feature Specification: スライドショー

**Feature Branch**: `006-add-slideshow`

**Created**: 2026-10-25

**Status**: Draft

**Input**: ファイルリストのメディアを、プレビューのみ表示で3秒ごとに表示順に切り替える。ツールバーまたはショートカットで開始し、最後から先頭へ循環して Esc で終了する。zip 内のメディア、動画、フルスクリーンに対応する。矢印キーの割り込み中は自動送りを止め、最後の押下から3秒後に選択中の次のメディアへ進む。

本書は追加・変更する項目だけを記す。正本は [product/README.md](../product/README.md)。既存の形式判定は FR-009・FR-039（overview.md）、表示順・選択・種類フィルタは FR-012・FR-016・FR-017・FR-056・FR-059（file-list.md）、zip 内の閲覧は FR-070〜073（zip.md）、検索結果は FR-084・FR-085・FR-087（search.md）、通常のプレビューは FR-028〜034・FR-038（preview.md）、ペイン表示と矢印移動は FR-088・FR-091〜094（window-layout.md）を参照する。参照する領域ファイルはいずれも `specs/product/` 配下とする。

## Clarifications

### Session 2026-10-25

- Q: 検索結果でスライドショー中に表示形式やフィルタを変えた場合、履歴へ記録するか？ → A: 記録しない。FR-113（navigation-history.md）を優先し、検索結果での表示変更は履歴を増やさない。終了だけでは検索を解除せず、後で検索を解除した時点の表示を現在の履歴へ反映する。一時的なペイン表示と実行状態は履歴へ含めない。
- Q: 削除や絞り込みで現在の選択が消えた後、自動送りと終了時の選択復帰をどう扱うか？ → A: 更新直後は既存規則どおり選択を外してプレビューを空にし、対象が残る場合だけ次の予定時刻に先頭を選ぶ。終了時はその時点の有効な選択だけを保ち、消えた選択や開始前の選択を復活させない。対象0件や閲覧先消失時は既存の空表示・移動先を保って終了する。
- Q: 同名メディアや並べ替え・一覧更新があるとき、現在のメディアを何で区別するか？ → A: 名前や行番号ではなく、通常ファイルは完全な場所、zip 内は zip ファイルの場所と内部パスの組で区別する。同名でも別の場所なら別の対象とし、名前変更への追従や選択解除は既存の一覧の規則を継承する。
- Q: 開始対象がすでにプレビュー中の動画の場合、先頭から再生し直すか？ → A: 表示中の同じ動画なら再生位置と再生／一時停止の状態を保ち、開始操作から3秒を数える。別のメディアへ移ってから戻った動画は新たな選択として先頭から既存の自動再生・ループ設定に従う。隠れていたプレビューを表示する場合は FR-088（window-layout.md）を適用する。
- Q: 実行中にウィンドウを狭め、開始前のペイン幅が収まらなくなった場合、終了時にどう復帰するか？ → A: ウィンドウの大きさは戻さず、既存のキーボード契約の復帰規則に従う。開始前の幅を基準に、プレビュー・ファイルリスト・ツリーの順に最小幅まで詰め、各ペインの最小幅を守る。復帰後のフォーカスと選択の可視化は通常の終了規則に従う。

### 解析指摘 U1 の明確化（2026-10-25）

既存の編集・モーダルのキー処理を横取りしない契約と、FR-118 の固定周期を優先する。Esc・矢印の入力受理条件は FR-123 に統一する。モーダル表示中も自動送りは継続し、開閉やそこで処理されたキーでは期限を変更しない。新たな一時停止状態は設けない。本書の「実行中の Esc による終了」「矢印の割り込み」は、この入力受理条件を満たす場合を指す。

## User Scenarios & Testing *(mandatory)*

### User Story 9 - 表示中のメディアを順番に鑑賞する (Priority: P1)

ユーザーは一覧の並べ替えと絞り込みで鑑賞対象を決め、スライドショーを開始する。プレビューだけを表示して画像と動画を3秒ずつ順送りし、一覧の末尾から先頭へ戻って鑑賞を続ける。

**Why this priority**: 手作業で選択を送り続けずに、現在の一覧を鑑賞できることが本機能の中心的な価値となる。

**Independent Test**: 画像・動画・フォルダ・zip が混在する一覧を降順に並べ、途中のメディアから開始する。3秒ごとの対象・順序・循環と Esc 後の表示を確認する。同じ確認を zip 内でも行う。

**Acceptance Scenarios**:

1. **US9-AS1**: **Given** メディアを含む一覧で1件を選択中, **When** ツールバーの「スライドショーを開始」を押す, **Then** 選択したメディアから始まり、ツリーとファイルリストが隠れ、プレビューへフォーカスが移る。3秒ごとに表示順の次のメディアへ進む。
2. **US9-AS2**: **Given** ツールバー非表示でメディアを含む一覧がある, **When** ⇧⌘S または「表示 > スライドショーを開始」を実行する, **Then** ツールバーと同じ条件・開始位置・間隔で開始する。3ペイン・ファイルリストのみ・プレビューのみのいずれの表示からも開始できる。
3. **US9-AS3**: **Given** メディア未選択、またはフォルダ・zip・`..` のみを選択中, **When** 開始する, **Then** 非メディアの選択位置によらず、表示順で最初のメディアから開始する。複数選択ではフォーカス中のメディアを優先し、それがなければ選択中のメディアのうち表示順で最初のものから開始する。
4. **US9-AS4**: **Given** zip・フォルダ・`..` を挟んだ一覧を降順または種類フィルタ付きで表示中, **When** 2周分の自動送りを行う, **Then** 画面外も含む表示対象のメディアだけを表示順で辿り、末尾の次は最初のメディアになる。フォルダや zip を開かず、フィルタで隠れたメディアは表示しない。
5. **US9-AS5**: **Given** メディアを含む zip 内の階層を表示中, **When** 開始する, **Then** その階層の表示対象メディアだけを通常のフォルダと同じように順送りする。zip 内のディレクトリや `..` では止まらず、別階層へ移らない。
6. **US9-AS6**: **Given** メディアが0件の一覧（種類フィルタで0件、zip・フォルダ・`..` しかない場合を含む）, **When** 開始手段を確認し ⇧⌘S を押す, **Then** ボタンとメニューは無効で、ショートカットでも開始せず、表示状態・選択は変わらない。
7. **US9-AS7**: **Given** 1秒の動画と10秒の動画を含む一覧、動画設定は既定, **When** 各動画へ自動送りする, **Then** どちらも自動再生し、短い動画はループし、どちらも選択から3秒後に次へ進む。切り替えた動画の音声は残らない。自動再生／ループをオフにした場合も、それぞれの設定を守って3秒後に次へ進む。
8. **US9-AS8**: **Given** メディアを表示中のスライドショー, **When** Esc を押して6秒以上待つ, **Then** 自動送りが再発しない。開始前のペイン表示とフォーカスへ戻り、最後のメディアの選択を保ち、リストが見える場合は必要最小限スクロールする。
9. **US9-AS9**: **Given** 検索結果を表示中（検索中も含む）でメディアが1件以上ある, **When** 開始して新しい結果が追加され、表示形式や種類フィルタを変更した後 Esc を押す, **Then** 現在の結果の表示順に従って続行し、終了時は検索結果を保つ。同じ Esc で検索解除は起きない。表示変更による履歴は増えず、後で検索を解除した時点の表示を FR-113（navigation-history.md）どおり現在の履歴へ反映し、一時的なペイン表示と実行状態は含めない。
10. **US9-AS10**: **Given** 名前の編集中、モーダル表示中、またはスライドショー実行中, **When** 開始操作を試す, **Then** 開始手段は無効で、重複実行や選択・送り予定時刻の変更は起こらない。
11. **US9-AS11**: **Given** 通常フォルダまたは zip 内で戻る側の履歴がある状態から開始した, **When** ペイン表示切り替えと戻る・進むを試し、続けて表示形式や種類フィルタを変えてから終了する, **Then** 実行中のペイン切り替えと履歴移動は無効となる。ユーザーの表示変更だけが履歴に残り、後で戻る・進むを行っても一時的なペイン表示やスライドショーは再現されない。
12. **US9-AS12**: **Given** メディアが複数あるスライドショー, **When** フィルタ変更・外部削除・追加・名前変更で対象列が変わる, **Then** 予定時刻を保って最新の表示順から次を選び、現在の対象が消えた場合は既存の規則でプレビューを更新・消去する。対象0件なら終了して表示復帰する。閲覧先の置き換えやウィンドウを閉じる操作でも終了し、次回起動で自動再開しない。
13. **US9-AS13**: **Given** 選択中のメディアが削除またはフィルタで非表示になり、ほかの対象は残っている, **When** 次の自動送り予定時刻より前に Esc を押す, **Then** 終了後も選択なし・プレビューは空のままで、開始前の選択や先頭メディアを自動選択しない。Esc を押さなければ次の予定時刻に最初の対象を選ぶ。zip 自体の外部変更では EC-26（zip.md）どおり親フォルダへ戻ってプレビューを空にし、ボリューム取り外しでは EC-18（directory-tree.md）どおり空表示にして終了する。
14. **US9-AS14**: **Given** 別フォルダに同名の画像がある検索結果で一方を選択してスライドショー中, **When** 結果の追加や並べ替えで行番号が変わる, **Then** 完全な場所で現在のメディアを特定し、新しい表示順でその次へ進む。同名のもう一方を同じメディアとみなして飛ばしたり、古い行番号の項目を現在のメディアとみなしたりしない。
15. **US9-AS15**: **Given** 動画を途中まで再生または一時停止したプレビューが見えている, **When** その動画を開始位置としてスライドショーを開始する, **Then** 再生位置と再生／一時停止の状態は変わらず、開始から3秒後に次へ進む。別のメディアを経て同じ動画へ戻ると先頭から自動再生設定に従い表示する。対象が1件なら EC-66 のとおり再生し直さない。ファイルリストのみ表示から開始した場合は FR-088（window-layout.md）どおり通常の選択と同じく表示する。

16. **US9-AS16**: **Given** 複数メディアのスライドショー実行中に対象ウィンドウのシートまたはアプリモーダルが表示された, **When** 3秒を超えて待ち、モーダルに Esc を入力する, **Then** 表示中も元の期限で自動送りを続け、Esc はモーダルの既存の取消だけに使う。同じ Esc でスライドショー終了・全画面解除・検索解除を行わず、閉じる操作でも期限を取り直さない。モーダルがなく編集欄も入力を受けていない対象ウィンドウへ、改めて Esc を入力すると終了する。編集欄への Esc も編集の既存処理だけに使い、送りの期限は変わらない。

### User Story 10 - 矢印キーで見たいメディアへ割り込む (Priority: P1)

ユーザーは鑑賞中に矢印キーで選び直せる。操作を続けている間は自動送りに妨げられず、操作をやめて3秒経つと、選び直したメディアの次から自動送りが続く。

**Why this priority**: 手動操作のたびにスライドショーが終了せず、鑑賞を継続できることが明示された主要要件となる。

**Independent Test**: 3秒未満の間隔で複数回の矢印キー操作を行い、自動送りが挟まらず、最後の操作から3秒後に1回だけ次へ進むことを確認する。

**Acceptance Scenarios**:

1. **US10-AS1**: **Given** リスト形式を基準とするスライドショー, **When** ↑／↓ を押す, **Then** 隠れたリストの前／次のメディアを選択して表示し、非メディアは飛ばす。←／→ では選択を動かさない。どの場合もスライドショーは終了しない。
2. **US10-AS2**: **Given** サムネイル形式を基準とするスライドショー, **When** 上下左右キーを押す, **Then** 隠す直前のリストの列数を基準として既存の移動規則で選択を動かす。非メディアを飛ばし、端では反対端へ循環せず止まる。
3. **US10-AS3**: **Given** 自動送りの直前に手動で B を選び、その2秒後に C を選んだ, **When** その後キーを押さずに待つ, **Then** B・C の操作中に自動送りは入らず、C を選ぶ最後のキー押下から3秒後に C の次へ1回進み、以後3秒周期で続く。
4. **US10-AS4**: **Given** 末尾のメディアを表示中, **When** 端を越える矢印キーを押す、または押し続けて反復入力する, **Then** 手動選択は端で止まるが押下・反復ごとに待ち時間を取り直し、最後の押下から3秒後に自動送りで先頭へ進む。リスト形式の ←／→ も待ち時間を取り直す。
5. **US10-AS5**: **Given** 自動送り予定時刻と矢印キー押下が重なる, **When** 操作が受け付けられる, **Then** 手動操作を優先し、自動送りによる二重移動は起きず、最後の押下から3秒後まで自動送りを行わない。

6. **US10-AS6**: **Given** 実行中にシート・アプリモーダルまたは編集欄が入力を受けている, **When** 矢印を入力する, **Then** 既存のモーダル／編集の操作だけに使い、スライドショーの手動移動や期限の再設定は起こらない。自動送りは元の期限で続く。入力先が対象ウィンドウに戻り FR-123 の受理条件を満たした後の矢印からは、通常どおり手動移動と3秒待機を行う。別ウィンドウへの Esc・矢印でも実行中の選択・期限を変更しない。

### User Story 11 - 全画面でも鑑賞と手動操作を続ける (Priority: P2)

ユーザーはスライドショー中にフルスクリーンへ入り、解除後も鑑賞を続けられる。Esc で終了すれば開始前の作業用表示へ戻れる。

**Why this priority**: 大きな表示での鑑賞と既存のフルスクリーン操作の両立に必要となる。

**Independent Test**: 動画を含むスライドショーで全画面化・解除・矢印移動・Esc 終了を行い、再生位置、選択、残り待ち時間、復帰先を確認する。

**Acceptance Scenarios**:

1. **US11-AS1**: **Given** スライドショー実行中, **When** ⌃⌘F、画像のダブルクリック、または既存の全画面メニューで全画面化／解除する, **Then** 実行を続け、解除後もプレビューのみ表示になる。選択・動画の再生位置と再生状態・次の送りまでの残り時間を保つ。
2. **US11-AS2**: **Given** 全画面のスライドショー, **When** 矢印キーを連続して押してから待つ, **Then** 通常ウィンドウと同じく割り込めて、最後の押下から3秒後に選択中の次へ進む。
3. **US11-AS3**: **Given** FR-123 の入力受理条件を満たす全画面のスライドショー, **When** Esc を1回押す, **Then** 終了と同時に全画面を解除し、開始前の通常ウィンドウのペイン表示とフォーカスへ戻る。開始時点ですでに全画面だった場合も、全画面化前のペイン表示へ戻る。
4. **US11-AS4**: **Given** 3ペイン表示から開始し、開始前のペイン幅の合計が収まらない幅まで通常ウィンドウを狭めた, **When** Esc で終了する, **Then** ウィンドウの大きさは開始前へ戻さず、プレビュー・ファイルリスト・ツリーの順に最小幅まで詰めて3ペインへ復帰する。各ペインの最小幅を守り、開始前のフォーカス先へ戻り、有効な選択がある場合は必要最小限のスクロールで可視にする。

### Edge Cases（EC-39 を変更）

- **EC-39**: プレビューのみ表示中に、一覧にメディアファイルはあるが何も選択していない状態になった場合（読み込み中にプレビューのみ表示にした、種類フィルタで選択中のファイルが非表示になった、選択中のファイルがアプリの外で削除された など）は、選択を自動で選び直さず、プレビューは空のままにする（表示するメディアファイルがない旨のメッセージは出さない）。読み込み中（検索中を含む）に切り替えた場合は、読み込みが終わっても自動選択しない。この状態で修飾キーなしの矢印キー（リスト形式は ↑↓、サムネイル形式は上下左右）を押すと、押したキーの方向に関わらず一覧の先頭から最初のメディアファイルを選択して表示する（FR-093（window-layout.md））。ただしスライドショー実行中は FR-125（preview.md）に従い、対象が残っていれば次の自動送り予定時刻に最初の対象を選ぶ。スライドショー終了やペイン表示の復帰そのものでは選び直さない（FR-123（preview.md））。

- **EC-66**: 対象が1件でも開始できる。同じ1件の選択・表示を維持して終了せず、3秒ごとに同じ動画を先頭から再生し直さない。
- **EC-67**: 破損・読み取り不可・非対応エンコード、または zip 内画像のサイズ制限で表示できない場合は FR-038（preview.md）のエラー表示を出し、通常の3秒周期で次へ進む。全件が表示不能でもエラー表示を順送りし、Esc で終了できる。
- **EC-68**: 外部削除やフィルタ変更で現在のメディアが消えた場合は既存の規則で選択とプレビューを更新・消去する。次の予定時刻には、その時点のフォーカス中メディアの次へ進み、フォーカスがなければ最初の対象へ進む。対象が0件になれば自動終了して開始前のペイン表示へ戻る。次の予定時刻より前に Esc で終了した場合も選択のない状態と空のプレビューを保ち、非表示・削除されたメディアや開始前の選択を復活させない。
- **EC-69**: 検索結果の追加、外部の追加・名前変更、表示形式・フィルタ・並べ替えの変更は最新のファイルリストに従って送り先に反映し、これらの変更自体では待ち時間を取り直さない。検索結果への追加可否は FR-085・FR-087（search.md）を変えない。
- **EC-70**: 読み込み中でも表示中の一覧にメディアが1件あれば開始できる。遅れて完了した以前の読み込みで現在の表示を上書きしない。処理遅延から戻った際に、遅れた回数分の自動送りを連続して行わない。
- **EC-71**: 開始操作を繰り返しても実行を重複させず、選択や次の予定時刻を変えない。Esc と予定時刻が重なる場合は終了を優先し、終了後の切り替えは起こらない。
- **EC-72**: 開始前からプレビューのみ表示の場合も開始でき、終了後はその状態に戻る。ウィンドウを閉じた場合やアプリ終了でも送りは終わり、次回起動時に自動再開しない。

## Requirements *(mandatory)*

### Functional Requirements

#### 追加: 開始・対象・順送り

- **FR-114**: ツールバーに「スライドショーを開始」ボタンをペイン表示ボタングループ（FR-089（window-layout.md））の右隣に追加し、「表示」メニューの同名項目と ⇧⌘S でも開始できなければならない。いずれも表示中の一覧に対応メディアが1件以上あるとき有効とし、名前の変更中、モーダル表示中、実行中は無効にする。ツールバー非表示中や全画面中もショートカットを使えなければならない。ボタンには同名のアクセシビリティラベルとショートカットを含むツールチップを付ける。
- **FR-115**: 対象は現在のファイルリストの表示内容全体のうち対応メディアだけとし、スクロールで画面外の項目も含めなければならない。現在の並べ替えと種類フィルタを反映し、リストでは上から下、サムネイルでは左上から右へ、行末から次行の左へ進む表示順を用いる。フォルダ・zip ファイルそのもの・zip 内ディレクトリ・`..` は除外し、中へ入らない。通常フォルダ、zip 内の現在階層、検索結果のいずれにも適用する。メディアの識別には通常ファイルの完全な場所、zip 内では zip ファイルの場所と内部パスの組を用い、名前や表示上の行番号だけでは識別しない。同名でも別の場所なら別の対象として扱う。
- **FR-116**: 開始位置は選択中のフォーカス行が対象メディアならそのファイル、それ以外では選択中の対象メディアの表示順先頭とし、対象メディア未選択なら一覧の最初の対象としなければならない。開始時はその1件だけを選択・フォーカスして表示する。この規則は通常のプレビューのみ表示への切り替えに伴う非メディア行からの補完規則（FR-093（window-layout.md））より優先する。
- **FR-117**: 開始するとツリーとファイルリストを隠してプレビューのみ表示にし、フォーカスをプレビューへ移さなければならない。開始前のペイン表示・フォーカス先・3ペインの幅を復帰用に保持し、すでに全画面なら全画面化前の通常ウィンドウの状態を復帰先とする。フォルダ、zip 内の階層、検索結果、並べ替え、フィルタ、ツリーの状態は開始で変更しない。
- **FR-118**: 自動送りは固定の3秒間隔とし、開始時の選択・プレビュー切り替えを起点として3秒後に次の対象へ進み、以後各切り替えを起点として繰り返さなければならない。デコード完了や動画の再生開始・終了を待って間隔を延長しない。末尾の次は最初の対象へ戻り、ユーザーが終了するまで続ける。ただし FR-125・FR-126 の継続不能・閲覧先変更時を除く。実行中にシート・アプリモーダルや編集欄が入力を受けても自動送りは継続し、その開閉・編集開始終了・そこで処理されたキーでは期限を変更しない。処理が遅れた場合は FR-124 に従い最大1回だけ送る。対象が1件なら EC-66 に従う。切り替えるたびに隠れたリストの選択・フォーカスも表示した1件に同期する。
- **FR-119**: 動画も静止画・アニメーション画像と同じ3秒の送り対象としなければならない。自動再生とループは既存の設定（FR-031・FR-032（preview.md））に従い、短い動画の終端で早送りせず、長い動画の終端まで待たない。開始位置がすでに表示中の同じ動画なら再生位置と再生／一時停止の状態を保ち、開始操作から3秒を数える。別のメディアを経て戻る動画は、新たな選択として先頭から既存の設定に従って表示する。ファイルリストのみ表示からの開始は FR-088（window-layout.md）に従い、隠していたプレビューを通常の選択と同じく表示する。対象1件の維持は EC-66 に従う。ユーザーによる動画の一時停止・シーク・音量変更（FR-033（preview.md））は送りの待ち時間に影響しない。別のメディアへの切り替えでは FR-034（preview.md）に従って以前の動画と音声を止める。

#### 追加: 割り込み・全画面・終了

- **FR-120**: 実行中に FR-123 の入力受理条件を満たす修飾キーなしの矢印キーで、隠れたファイルリストを基準にメディアを選び直せなければならない。方向、非メディアの読み飛ばし、手動移動時に端で止まる規則、動画でのシークとの区別は FR-093（window-layout.md）・FR-046（preview.md）に従う。サムネイルの縦移動は隠す直前の列数を保ち、プレビューや全画面の幅で列数を取り直さない。非表示中に形式・サイズを変えた場合は隠す直前のリスト幅と新しい設定による列数を基準にする。手動移動でスライドショーを終了してはならない。
- **FR-121**: 実行中に FR-123 の入力受理条件を満たす修飾キーなしの矢印キーを押すたび（押し続けによる反復を含む）、予定されていた自動送りを取り消し、最後の押下から3秒経つまで止めなければならない。3秒間押下がなければその時点の選択中メディアの次へ1回進み、以後3秒周期を再開する。端で移動できない押下やリスト形式の左右キーも待ち時間を取り直す。自動送りと押下が重なれば手動操作を優先し、二重に進めない。
- **FR-122**: 実行中も既存のフルスクリーン切り替え手段（FR-035・FR-036（preview.md））を使えなければならない。Esc 以外で全画面を切り替えても実行状態、選択、動画の再生位置と再生状態、次の送りまでの残り時間を保つ。全画面を解除してもスライドショーは続け、プレビューのみ表示を維持する。
- **FR-123**: Esc・矢印をスライドショー入力として受理するのは、実行中の対象ウィンドウがキー入力先であり、対象ウィンドウにシートがなく、アプリモーダルがなく、編集欄が入力を受けていない場合だけとする。メニュー等がキーを処理する間も横取りしない。この条件を満たさないキーは既存の入力先へ渡し、スライドショーの終了・手動移動・期限変更を行わない。モーダルや編集を終えるキーを同じ入力のままスライドショーへ再適用しない。受理した Esc は全画面解除・検索解除・自動送りよりスライドショー終了を優先し、自動送りと待機中の再開を取り消さなければならない。全画面中なら1回の Esc で同時に全画面も解除する。開始前のペイン表示・フォーカス先と幅へ戻す。ただし実行中にウィンドウを狭めた場合は、開始前のウィンドウの大きさへ戻さず、FR-002・FR-088（window-layout.md）と contracts/keyboard-and-menus.md の復帰規則に従い、プレビュー・ファイルリスト・ツリーの順に最小幅まで詰めて収め、各ペインの最小幅を守る。その時点で選択・表示対象に残っている最後のメディアだけは選択を保ち、リストが見える場合は FR-093（window-layout.md）と同じ必要最小限のスクロールで可視にする。選択が消去済みなら空のプレビューを保ち、表示復帰による FR-093 の選択補完を行わず、開始前の選択も復元しない。同じ Esc を検索解除などへ重ねて適用しない。終了したことだけを理由に最後の動画を停止せず、復帰先がファイルリストのみなら FR-088（window-layout.md）に従って停止・消音する。
- **FR-124**: 表示不能な対象は FR-038（preview.md）の表示で通知し、自動送りを止めず通常の次の予定時刻に次へ進まなければならない。読み込みが遅れても操作を受け付け、以前の読み込み結果による上書きや、遅延分をまとめた連続送りを起こさない。
- **FR-125**: 実行中の表示形式・種類フィルタ・並べ替え・一覧更新を反映し、各自動送りではその時点の表示対象と順序を用いなければならない。FR-115 の識別によりフォーカスが対象に残ればその次へ進み、なければ最初の対象へ進む。これらの変更自体では予定時刻を変えない。選択解除・プレビュー消去は既存の規則（FR-059（file-list.md）、EC-13（overview.md）、FR-087（search.md））を保ち、対象が0件になれば自動終了して FR-123 と同じ表示復帰を行う。名前や場所の変更で既存の一覧が選択を維持する場合はその対象へ追従し、FR-104（directory-tree.md）・FR-105（search.md）による場所の更新だけを FR-126 の別の閲覧先への置き換えとはみなさない。
- **FR-126**: フォルダ・zip 内の階層・検索結果が別の閲覧先に置き換わる場合は実行を終了し、開始前のペイン表示へ復帰してから新しい閲覧先を表示しなければならない。閲覧先の消失・ボリューム取り外しでも終了し、EC-26（zip.md）・EC-18（directory-tree.md）・EC-36（search.md）に従う移動先または空表示を保つ。表示復帰を理由に古い閲覧先・選択・プレビューを復元せず、履歴の置換・削除は FR-109（navigation-history.md）に従う。ウィンドウを閉じる／アプリ終了でも送りを取り消す。実行状態・待ち時間・復帰用状態は永続化せず、再起動後に自動再開しない。

#### FR-036 フルスクリーンのキーボード操作（変更）

- **FR-036**: フルスクリーンは、キーボードショートカットでも切り替えでき、Esc キーでも解除できなければならない。スライドショー実行中の Esc は FR-123（preview.md）に従い、スライドショー終了と全画面解除を同時に行う。

#### FR-090 ペイン表示の操作手段（変更）

- **FR-090**: 「表示」メニューに「ファイルリストのみ表示」と「プレビューのみ表示」の項目を置き、現在の表示状態の項目にはチェックマークを付けなければならない。キーボードショートカットは「ファイルリストのみ表示」が ⌃⌘2、「プレビューのみ表示」が ⌃⌘3 とする。メニュー・ショートカット・ツールバーのボタンは同じ状態を共有し、同じ規則（FR-089（window-layout.md））で切り替わり、どこから変更しても他方の表示に反映される。ツールバーが非表示のときも、メニューとショートカットで操作できなければならない（FR-040（overview.md））。ファイル名の変更中は無効にする。スライドショー中も両方のボタンとメニューを無効にし、ショートカットでは何もしない。実行中はプレビューのみ表示の状態を示し、終了後は復帰先の表示状態を示す。

#### FR-094 ペイン表示と全画面の復帰先（変更）

- **FR-094**: ファイルリストのみ表示とプレビューのみ表示のどちらからも、フルスクリーン（FR-035・FR-036（preview.md））に切り替えられなければならない。ファイルリストのみ表示中は、フルスクリーン切替のショートカットでフォーカス中のメディアファイルをフルスクリーン表示する。フォーカス中の行がメディアファイルでない場合（フォルダ・zip ファイル・zip の中のディレクトリ・`..`）は、何もしない（プレビューは FR-075（zip.md）・FR-076（file-list.md）のとおり空のまま）。フルスクリーンを解除したときは、フルスクリーン前の表示状態（フォーカスのあったペインを含む）に戻す。ただしスライドショー実行中は FR-122・FR-123（preview.md）を優先し、Esc 以外の解除ではプレビューのみ表示で継続し、Esc で終了すると開始前の通常ウィンドウの表示へ戻す。フルスクリーン中は、ペインの表示切り替えのメニュー項目を淡色にし、ショートカットは何もしない。

#### FR-107 履歴の記録対象（変更）

- **FR-107**: システムは、次の操作を行ったとき、操作の後の状態を1件の履歴として記録しなければならない。
  （1）フォルダの選択: ツリーでのフォルダの選択（クリック・ダブルクリック・矢印キー。お気に入りの項目の選択（FR-063（directory-tree.md））を含む）。
  （2）フォルダの移動: ファイルリストでフォルダ・zip ファイル・zip の中のディレクトリを開く操作（FR-069（zip.md）・FR-076（file-list.md））と、`..`・⌘↑ で1つ上の階層へ戻る操作（FR-070（zip.md）・FR-077（file-list.md））。このときのツリーの選択の同期（FR-078（file-list.md））は同じ1件の履歴に含める。
  （3）表示の変更: 表示形式の切り替え（FR-010（file-list.md））、サムネイルサイズの変更（FR-014（file-list.md））、種類フィルタの切り替え（FR-056（file-list.md））、zip ファイルの表示の切り替え（FR-095（zip.md））、ペインの表示切り替え（FR-088（window-layout.md））。
  これらは「表示」メニュー・ショートカット・ツールバーのどこから行っても同じく記録する。サムネイルサイズの変更は、ほかの記録する操作と戻る・進むを挟まずに続けて行ったもの（スライダーの1回のドラッグ、続けて押した ⌘+ / ⌘- を含む）を1件にまとめる。戻る・進むの直後のサイズの変更は、移った先の履歴にまとめず、新しい履歴として記録する（US8-AS7（navigation-history.md））。
  次は記録してはならない: ツールバーの表示切り替え（FR-050（window-layout.md））、フルスクリーン（FR-035・FR-036（preview.md））、ペインへのフォーカス移動、「お気に入り」の見出しの選択（⇧⌘F を含む。FR-065（directory-tree.md））、列見出しによる並べ替え（FR-012（file-list.md））、ファイルリストの中での選択の変更、ファイル操作（FR-018〜FR-027（file-operations.md））、検索の開始と検索結果の表示（FR-113（navigation-history.md））、戻る・進むそのもの、およびスライドショーの開始・終了・それに伴う一時的なペイン表示変更・自動送り・矢印キーの割り込み。
  スライドショー中の表示形式・サイズ・フィルタ等のユーザーによる表示変更は通常どおり記録するが、その履歴のペイン表示状態には開始前の復帰先を用い、一時的なプレビューのみ表示や実行状態は記録しない。ただし検索結果の表示中は FR-113（navigation-history.md）を優先し、表示変更を履歴に記録しない。スライドショー終了だけでは検索を解除せず、後で検索を解除した時点の通常の表示を現在の履歴へ反映する。一時的なペイン表示や実行状態は含めず、終了後にユーザーが変えたペイン表示は通常どおり扱う。
  操作の後の状態が現在の履歴と同じ場所・同じ表示の状態であれば（選択中のフォルダをもう一度選んだ場合など）、新しい履歴を記録しない。戻る側に移った後で新しい履歴を記録したときは、それより進む側の履歴をすべて取り除く（Finder と同じ）。

#### FR-112 戻る・進むの操作手段（変更）

- **FR-112**: ユーザーは、次のどの手段でも「戻る」「進む」を実行できなければならない。
  （1）ツールバー（FR-049（window-layout.md））の左端に置く、`<`（戻る）と `>`（進む）の2つのボタンからなるボタングループ。
  （2）キーボードショートカット ⌘[（戻る）と ⌘]（進む）（Finder と同じ）。
  （3）「表示」メニューの右に新しく置く「移動」メニューの「戻る」「進む」の項目。
  戻る側（進む側）に履歴がないときは、ツールバーのボタンとメニュー項目を淡色にして選べないようにし、ショートカットは何もしない（検索結果の表示中の「戻る」は FR-113（navigation-history.md）に従い、戻る側に履歴がなくても使える）。ツールバーが非表示のときも、メニューとショートカットで使えなければならない（FR-040（overview.md））。名前の変更中（FR-102（directory-tree.md））とフルスクリーン中、およびスライドショー実行中は、ボタン・メニュー項目を無効にし、ショートカットは何もしない。ボタンには「戻る」「進む」をアクセシビリティラベルとツールチップとして付ける。

### Key Entities *(include if feature involves data)*

- **対象列**: 現在の一覧に表示対象となるメディアを一覧の順に並べたもの。選択した項目だけに限定せず、閲覧先・フィルタ・並べ替え・一覧更新に従う。対象の識別は FR-115 の場所を基準とし、表示順の位置とは分ける。
- **実行状態**: 実行有無、現在のメディア、次の送り予定時刻、矢印キーによる待機状態、固定の3秒間隔。全画面状態とは独立して継続する。
- **復帰用表示状態**: 開始前の通常ウィンドウのペイン表示・フォーカス先・幅と、手動移動の基準となるリストの幅・列数。終了時に表示を戻すための一時的な状態。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-033**: 通常フォルダ・zip 内・検索結果の各一覧で2周分の確認を行い、表示対象・開始位置・順番・循環が受け入れシナリオと100%一致し、非メディアを表示・展開した回数が0回となる。
- **SC-034**: 事前に表示可能な静止画を用い、操作や一覧更新のない連続20回の自動送りで、各選択の切り替えが前の選択から3.0秒以上3.2秒以内に1回ずつ発生する。1秒・10秒の動画でも同じ時間枠で次へ進む。読み込みによる映像表示の遅れは既存の SC-001・SC-010（preview.md）に照らして別に確認する。
- **SC-035**: 1秒間隔の矢印キー操作を10回続ける確認で操作間の自動送りが0回、最後の押下から3.0秒以上3.2秒以内に選択中の次への自動送りが1回となる。端での操作・キー反復・全画面でも同じ結果となる。
- **SC-036**: 3種類のペイン表示の各状態から開始し全画面化・解除を3回繰り返しても、意図しない終了が0回となる。Esc 1回で終了と必要な全画面解除・表示復帰が完了し、6秒以上待っても自動送りが0回となる。US11-AS4 の狭めたウィンドウでの復帰でも、ツリー160pt・ファイルリスト240pt・プレビュー320ptの最小幅を下回るペインが0件となる。
- **SC-037**: ツールバー非表示で「開始 → 矢印キーの割り込み → 全画面化 → 終了」をキーボードだけで完了できる。表示不能メディアを含む1周の確認でも異常終了が0回で、エラー表示中も Esc で終了できる。

- **A-47**: 開始キーは既存の [キーボード契約](../product/contracts/keyboard-and-menus.md) と衝突しない ⇧⌘S とする。ボタンは実行中に停止ボタンへ切り替えず無効にし、終了は Esc とする。メニューからも同じ開始操作に到達できるようにする。
- **A-48**: 終了時は開始前の通常ウィンドウのペイン表示・フォーカスへ戻す。FR-123 の条件で受理した全画面中の Esc は終了と全画面解除を1回で行い、検索解除へ伝播させない。実行中のペイン切り替えと履歴移動は無効とし、開始・終了に伴う一時的な表示変更は履歴に残さない。
- **A-49**: 3秒は選択とプレビュー切り替えを起点とする。開始時にすでに同じ動画を表示している場合も、再生状態を保ったまま開始操作から3秒を数える。動画を最後まで見せるモードや間隔設定は追加せず、自動再生・ループ・音声は既存の設定を尊重する。Space 等の動画操作はスライドショーの一時停止手段にはしない。
- **A-50**: 複数選択の開始位置はフォーカス中のメディアを優先し、なければ選択中のメディアの表示順先頭、それもなければ一覧の対象メディアの先頭とする。開始後は1件だけの選択に揃える。
- **A-51**: 実行中も表示形式・サイズ・種類フィルタ・並べ替えは既存の手段で変更できる。対象列は固定せず最新の一覧に追従し、追加・削除・選択解除は既存仕様を継承する。読み込み中の一覧・検索結果にもメディアが1件あれば開始を許可する。
- **A-52**: 対象が1件なら表示を維持して継続し、表示不能な項目はエラーのまま通常の3秒後に進む。対象0件、閲覧先の置き換え、ウィンドウを閉じる／アプリ終了は、Esc 以外に継続できなくなる終了条件とする。
- **A-53**: 割り込みの対象は修飾キーなしの矢印キーとし、端やリスト形式の左右キーでも3秒を数え直す。サムネイルの移動基準は隠す直前の配置とする。ランダム再生、逆順専用モード、トランジション、専用の一時停止、再生設定の追加・永続化は今回の範囲外とする。
