## Clarifications

### Session 2026-10-27

- Q: ツールバーの3つのボタンの並びは？ 要件では「左端」が拡大とフィットの両方に書かれている。 → A: 左から「拡大（+）」「表示領域に合わせる（両矢印）」「縮小（−）」の順とし、中ボタンをフィットとする。3つは1つのボタングループとして隙間なく並べる。
- Q: 倍率の100%は何を基準にするか？ → A: FR-028（preview.md）のフィット表示を100%とする。原寸（画像の1画素を1ポイントで表示する状態）は基準にしない。小さい画像はフィットで原寸を超えて拡大されているため、その状態が100%になる。
- Q: 25%の刻み方は？ → A: 現在の倍率に25ポイントを加減する（100% → 125% → 150%、100% → 75% → 50%）。乗算（100% → 125% → 156.25%）にはしない。取り得る倍率は25%以上800%以下の25%の倍数とし、上限・下限では変化させない。
- Q: ⌘+ / ⌘- は既存のサムネイルサイズ変更と同じキーである。どちらを優先するか？ → A: 要望どおり ⌘+ / ⌘- をプレビューの拡大・縮小に使う。既存のサムネイルサイズ変更は ⌃⌘. / ⌃⌘, に移し、キーボードだけで操作できる状態を保つ（FR-040・憲章 原則 III）。⌘0 は既存の割り当てと衝突しないため、そのままフィットに使う。プレビューに画像を表示していないときの ⌘+ / ⌘- は何もしない（サムネイルサイズは変えない）。
- Q: 表示する画像が変わったとき、倍率をどうするか？ → A: 100%（フィット）に戻す。フルスクリーンの切り替え、ウィンドウやペインのサイズ変更、同じ画像を表示したままのペイン表示の復帰では、現在の倍率を保つ。
- Q: 倍率を上げて画像がビューポートより大きくなったとき、見えない部分をどう扱うか？ → A: 画像の中央を基準に配置し、ビューポートの外にはみ出した部分は表示しない。今回の範囲ではスクロール・パン・ドラッグによる移動を提供しない。トラックパッドのピンチ操作も範囲外とする。
- Q: スライドショー実行中の画像にも倍率変更を使えるか？ → A: 使える。次の画像へ切り替わった時点で100%に戻す。倍率変更は切り替え間隔・切り替え効果・次の送り予定時刻を変えない。
- Q: 倍率は保存するか？ 履歴に含めるか？ → A: 保存しない。履歴の「表示の状態」（FR-108（navigation-history.md））にも含めない。起動時および履歴の移動後は100%で表示する。
- Q: 表示メニューでの項目名は？ → A: 要件の「表示領域に合わせる」をメニュー名とし、ショートカットの説明にある「ウィンドウに合わせる」は同じ操作を指すものとして扱う。
- Q: 既存の契約で ⌘+ / ⌘- をサムネイルサイズ変更として示している箇所（プレビューのみ表示のキー一覧、zip の中と検索結果のキー一覧、ツールバーのサイズのスライダー、メニューバーの「サムネイルを拡大・縮小」、履歴の US8-AS7）をどう扱うか？ → A: すべて ⌃⌘. / ⌃⌘, に統一する。プレビューのみ表示では、画像を表示していれば ⌘+ / ⌘- がプレビューの倍率を変え、⌃⌘. / ⌃⌘, が隠れたファイルリストのサムネイルサイズを変える。履歴の US8-AS7 も ⌃⌘. に読み替える。
- Q: 拡大・縮小・表示領域に合わせるの操作を、履歴（戻る・進む）の1件として記録するか？ → A: 記録しない。FR-107（navigation-history.md）の記録対象にも、履歴の表示の状態にも加えない。25%刻みの各操作で履歴は増えない。
- Q: 可視の数値表示を追加しないまま、倍率を VoiceOver などの支援技術にどう伝えるか？ → A: プレビューのアクセシビリティの値として現在の倍率（%）を公開し、倍率が変わったときに新しい倍率を読み上げる。可視の数値表示は追加しない。
- Q: ⌘+ は Shift を含む `+` の入力が必要だが、Shift なしの ⌘= でも拡大するか？ → A: ⌘= と ⇧⌘= のどちらでも拡大として受け付ける。メニューとツールチップの表示は ⌘+ のままとする。縮小の ⌘- は Shift を要さない。
- Q: シート・モーダル・名前の変更中・設定ウインドウがキーのとき、拡大・縮小・表示領域に合わせるに追加の制限を設けるか？ → A: 設けない。FR-136 の条件（プレビューが表示され、画像を表示している）だけを条件とし、これらの状態でも同じ条件を満たせば使える。倍率変更は取り消しを要さない一時的な表示操作であるため。
- Q: サムネイルサイズの移動先を ⌥⌘+ / ⌥⌘- とすると、macOS のアクセシビリティズームのショートカット（⌥⌘= / ⌥⌘-）と重なる。どのキーにするか？ → A: ⌃⌘. / ⌃⌘, にする（拡大が `.`、縮小が `,`）。⌃⌘+ / ⌃⌘- も検討したが、`+` は Shift を要するため拡大だけ4キーの同時押しになり、縮小との違いが分かりにくい。`.` と `,` は US・JIS のどちらの配列でも Shift なしで押せる隣り合うキーで、キーに刻まれた `>`（大きく）と `<`（小さく）で覚えられる。既存の ⌃⌘ 系（⌃⌘F・⌃⌘T・⌃⌘Z・⌃⌘2・⌃⌘3）とも macOS 標準のショートカットとも重ならない（A-74）。
- Q: プレビューの拡大 ⌘+ は、JIS 配列では ⌘= も Shift を要する。JIS 配列向けに ⌘;（`+` の刻まれたキー）も拡大として受け付けるか？ → A: 受け付けない。ショートカットは US 配列を基準とする。JIS など異なる配列での使いにくさは、将来のショートカットキーのカスタマイズで回避できるようにする（A-75）。

## User Scenarios & Testing *(mandatory)*

### User Story 14 - プレビュー画像を拡大・縮小する (Priority: P1)

ユーザーは、プレビューに表示した画像の細部を確かめたいときや、逆に全体を小さく見たいときに、
ツールバー・表示メニュー・ショートカットで表示倍率を変える。拡大しすぎたときは、表示領域に合わせる操作で
元のフィット表示にすぐ戻せる。

**Why this priority**: 画像ビューアの主要な閲覧操作であり、今回の要望の中心となる。これ単体で価値が完結する。

**Independent Test**: 画像を選択してプレビューに表示し、ツールバーの3ボタン、表示メニューの3項目、⌘+・⌘-・⌘0 で
倍率が25%刻みに変わること、動画では無効になること、別の画像へ移ると100%に戻ることを確かめる。
フルスクリーンとプレビューのみ表示でも同じ操作ができることを確かめる。

**Acceptance Scenarios**:

1. **US14-AS1**: **Given** 3ペイン表示で画像をプレビューに表示中, **When** ツールバーの「拡大」を押す, **Then** 表示倍率が125%になり、画像は縦横比を保ったまま中央に表示される。もう一度押すと150%になる
2. **US14-AS2**: **Given** 表示倍率が150%, **When** ツールバーの「縮小」を押す, **Then** 125%になる。続けて押すと100%・75%・50%・25%と下がり、25%で止まる。25%では「縮小」が無効になり、それ以上押しても表示は変わらない
3. **US14-AS3**: **Given** 表示倍率が175%, **When** ツールバーの「表示領域に合わせる」を押す, **Then** 100%のフィット表示に戻り、画像全体がビューポート内に収まって中央に表示される
4. **US14-AS4**: **Given** 画像をプレビューに表示中, **When** ⌘+・⌘-・⌘0 を押す, **Then** それぞれツールバーの「拡大」「縮小」「表示領域に合わせる」と同じ結果になる。この操作は3ペイン表示・プレビューのみ表示・フルスクリーンのいずれでもできる
5. **US14-AS5**: **Given** 画像Aを150%で表示中, **When** ファイルリストで画像Bを選択する, **Then** 画像Bは100%のフィット表示で現れる。画像Aへ戻っても100%で表示される
6. **US14-AS6**: **Given** 動画を表示中、画像のない空のプレビュー、表示できない画像、またはファイルリストのみ表示, **When** ツールバー・表示メニュー・ショートカットの拡大・縮小・表示領域に合わせるを実行する, **Then** 何も起きず、プレビューの表示は変わらない
7. **US14-AS7**: **Given** 100%の画像, **When** 「拡大」を28回続けて実行する, **Then** 800%で止まり、それ以上は変わらない。800%では「拡大」が無効になる
8. **US14-AS8**: **Given** フルスクリーンで画像を200%表示中, **When** フルスクリーンを解除する, **Then** 200%の倍率を保ち、通常ウィンドウの新しいビューポートに対するフィットを基準に表示する。再びフルスクリーンにしても200%を保つ
9. **US14-AS9**: **Given** 画像を表示中でファイルリストがサムネイル形式, **When** ⌃⌘. / ⌃⌘, を押す, **Then** 従来どおりサムネイルの大きさが変わり、プレビューの倍率は変わらない。⌘+ / ⌘- はプレビューの倍率だけを変える
10. **US14-AS10**: **Given** スライドショーで画像を200%表示中, **When** 自動送りで次の画像へ切り替わる, **Then** 次の画像は100%のフィット表示になり、スライドショーは同じ間隔と切り替え効果で続く
11. **US14-AS11**: **Given** ツールバーを表示中, **When** 3つのボタンを見る, **Then** 左から虫眼鏡のレンズに `+`・両矢印・`-` を重ねたアイコンが並び、それぞれ「拡大」「表示領域に合わせる」「縮小」のアクセシビリティラベルと、ショートカットを含むツールチップを持つ
12. **US14-AS12**: **Given** 画像を表示中, **When** ⌘= または ⇧⌘= を押す, **Then** どちらもツールバーの「拡大」と同じく倍率が25ポイント上がる。メニューとツールチップの表示は ⌘+ のまま変わらない
13. **US14-AS13**: **Given** 画像を150%で表示中, **When** VoiceOver を使いながら「拡大」を実行する, **Then** プレビューのアクセシビリティの値が150%から175%に変わり、175%と読み上げられる。画面上に倍率の数値表示は出ない
14. **US14-AS14**: **Given** ツールバーを表示し、プレビューのみ表示で画像を表示中, **When** ⌘+ を押してから ⌃⌘. を押す, **Then** ⌘+ でプレビューの倍率が125%になり、⌃⌘. で隠れたファイルリストのサムネイルサイズが大きくなる。3ペイン表示に戻すと両方の結果が反映されている
15. **US14-AS15**: **Given** 画像を125%で表示中, **When** 「拡大」を実行してから ⌘[ を押す, **Then** 倍率の変更は履歴に記録されず、⌘[ は倍率変更より前の履歴へ移る。移った先の画像は100%で表示される（FR-137）
16. **US14-AS16**: **Given** ファイル名を編集中、検索のシートを表示中、または設定ウインドウがキーで、背後に画像を表示している, **When** ⌘+ を押す, **Then** 倍率が125%になり、シート・編集・設定ウインドウはそのまま続く

### User Story 8 - 操作の履歴（変更。navigation-history.md）

### Edge Cases

- **EC-81**: 倍率を上げている間にウィンドウやペインの大きさが変わった場合も、新しいビューポートに対するフィットを100%として現在の倍率を適用し、縦横比と中央配置を保つ。ビューポートからはみ出した部分は表示しない
- **EC-82**: 16×16 や 1×1 ピクセルの極端に小さい画像でも、フィットで拡大された状態を100%として25%刻みの拡大・縮小ができ、クラッシュしない
- **EC-83**: 1億画素級の大きな画像でも、倍率の変更中にアプリが応答し続ける。倍率変更のためのデコードに失敗した場合は FR-038（preview.md）のエラー表示に切り替え、次に表示する画像は100%から始める
- **EC-84**: アニメーション GIF、および OS 標準の仕組みで再生できるアニメーション WebP は、倍率を変えても再生を最初からやり直さない。再生できない WebP の先頭フレームも、静止画と同じく拡大・縮小できる
- **EC-85**: 上限（800%）で「拡大」、下限（25%）で「縮小」を、ツールバー・メニュー・ショートカットのどれで実行しても表示は変わらず、反対端へ循環しない。該当する操作は無効になる
- **EC-86**: スライドショーの切り替え効果の表示中に倍率を変えても、効果の進行・切り替え間隔・次の送り予定時刻は変わらない。次に画像が切り替わると100%に戻る
- **EC-87**: プレビューを隠す表示（ファイルリストのみ表示）にしてから戻したとき、同じ画像が表示されていれば倍率を保つ。隠れている間に選択が変わっていれば、新しい画像は100%で表示する
- **EC-88**: 履歴の戻る・進むで表示を復元したときは、同じ画像に戻る場合も100%で表示する
- **EC-89**: プレビューのみ表示で ⌘+ / ⌘- を押したとき、画像を表示していれば倍率が変わり、画像がない・動画・表示できない画像なら何も起きない。同じ状態で ⌃⌘. / ⌃⌘, を押すと、隠れたファイルリストのサムネイルサイズだけが変わる（FR-135・136）
- **EC-90**: 倍率を変えても履歴の件数は増えない。戻る・進むの直後に倍率を変えても新しい履歴は記録されず、履歴の表示の状態も変わらない（FR-107（navigation-history.md）・FR-137）

## Requirements *(mandatory)*

### Functional Requirements

#### 追加: プレビュー画像の倍率

- **FR-133**: ユーザーは、プレビューに表示中の画像の表示倍率を、「拡大」「縮小」「表示領域に合わせる」の3操作で変えられなければならない。倍率は FR-028（preview.md）のフィット表示を100%とし、拡大は現在の倍率に25ポイント（25%刻みの1段）を加え、縮小は25ポイントを引く。取り得る倍率は25%以上800%以下の25%の倍数とし、上限・下限ではそれ以上変化させない。「表示領域に合わせる」は、その時点のビューポートに対するフィット表示（100%）に戻す。倍率を変えた画像も縦横比を保ってビューポートの中央に配置し、ビューポートより大きい場合は中央を基準に、はみ出した部分を表示しない。スクロール・パン・ドラッグによる表示位置の移動は行わない。動画、表示する画像がない状態、表示できない画像（FR-038（preview.md））には適用しない
- **FR-134**: ツールバーに、虫眼鏡のレンズの内側に記号を重ねた3つのボタンを1つのボタングループとして、左から「拡大」（記号 `+`）、「表示領域に合わせる」（記号は両矢印）、「縮小」（記号 `-`）の順に置かなければならない。グループは「スライドショーを開始」ボタンの右隣、種類フィルタの左に置く。各ボタンは押した状態を保たない一時的な操作とし、アクセシビリティのラベル「拡大」「表示領域に合わせる」「縮小」と、ショートカットを含むツールチップを付けなければならない。FR-136 の条件を満たさないときと、上限・下限に達した拡大・縮小は無効にし、押しても何も起きないようにする
- **FR-135**: 「表示」メニューの「フルスクリーン」の下に区切り線を置き、「拡大」「縮小」「表示領域に合わせる」をこの順で追加しなければならない。ショートカットは「拡大」が ⌘+、「縮小」が ⌘-、「表示領域に合わせる」が ⌘0 とする。拡大は ⇧ を含む ⌘+ と Shift なしの ⌘= のどちらでも受け付け、メニューとツールチップの表示は ⌘+ のままとする。⌘+ / ⌘- は FR-014（file-list.md）のサムネイルサイズ変更と衝突するため、既存の「サムネイルを拡大・縮小」のショートカットを ⌃⌘. / ⌃⌘, に移す。この移行は contracts/keyboard-and-menus.md のファイルリストの行だけでなく、プレビューのみ表示・zip の中・検索結果のキー一覧、ツールバーのサイズのスライダー、メニューバーの「サムネイルを拡大・縮小」の表示、および navigation-history.md の FR-107（3）と US8-AS7 の参照にも適用する。プレビューのみ表示では、画像を表示していれば ⌘+ / ⌘- がプレビューの倍率を変え、⌃⌘. / ⌃⌘, が隠れたファイルリストのサムネイルサイズを変える。⌘+ / ⌘- / ⌘0 がプレビューの倍率を変えるのは FR-136 の条件を満たすときだけとし、満たさないときは何もしない。3項目の有効・無効は FR-136 に従う。ツールバーが非表示のときとフルスクリーン中も、メニューとショートカットで操作できなければならない
- **FR-136**: 拡大・縮小・表示領域に合わせるを使えるのは、プレビューが表示され（3ペイン表示・プレビューのみ表示・フルスクリーン）、かつ画像を表示しているときだけとする。ファイルリストのみ表示、動画、画像のない空のプレビュー、表示できない画像では使えず、ツールバーの3ボタンと表示メニューの3項目を無効にし、ショートカットは何もしない。スライドショー実行中も画像を表示していれば使える。拡大は800%で、縮小は25%で無効にする。シート・モーダル・名前の変更中・設定ウインドウがキーのときも、この条件だけを適用し、追加の制限を設けない
- **FR-137**: 表示倍率は保存せず、履歴の表示の状態（FR-108（navigation-history.md））にも含めない。倍率を変えた操作は履歴の1件としても記録せず、FR-107（navigation-history.md）の記録対象に加えない。表示する画像が別の画像に切り替わったとき（ファイルリストの選択変更、プレビューのみ表示中とフルスクリーン中の矢印キーによる移動、スライドショーの自動送りと手動移動を含む）と、履歴の移動（同じ画像に戻る場合を含む）は100%に戻さなければならない。フルスクリーンの切り替え、ウィンドウ・ペインのサイズ変更、ツールバーの表示切り替え、同じ画像を表示したままのペイン表示の復帰では、現在の倍率を保つ。サイズ変更時は新しいビューポートに対するフィットを再計算し、その100%に現在の倍率を適用する。起動時と、画像を表示していない状態から次に画像を表示するときは100%から始める
- **FR-138**: プレビューは、表示中の画像の現在の倍率をアクセシビリティの値として公開し、倍率が変わったときに新しい倍率（パーセント）を読み上げ可能な形で通知しなければならない。可視の数値表示とスライダーは追加しない（A-64）。倍率を変更できない状態（FR-136 の条件を満たさないとき）は倍率を公開せず、拡大・縮小・表示領域に合わせるを無効として読み上げる

#### FR-028 既定のフィット表示（変更）

- **FR-028**: システムは、画像を表示するとき、既定で縦横比を保ったままプレビューペイン内に収まる最大サイズで表示しなければならない。ここでプレビューペインの画像描画領域を「ビューポート」と呼び、余白は設けず描画領域全体を基準にする。ペインより小さい画像も、ビューポートからはみ出さない範囲で最も大きくなるよう拡大しなければならない。フィット表示の拡大率の上限は設けず、原寸を超える拡大を許容する。画像は切り取らず、ビューポートの中央に配置する。このフィット表示を倍率100%とし、ユーザーは FR-133 の操作で25%刻みに拡大・縮小できる（倍率を変えたときは、ビューポートからはみ出した部分を表示しない）。動画にはこの拡大規則を適用しない（動画の表示サイズ規則は本要件の対象外とする）

#### FR-029 レイアウトの追従（変更）

- **FR-029**: プレビューのレイアウトは、ペインやウィンドウのサイズ変更、フルスクリーンへの切り替えに追従して再計算されなければならない。フィット表示（100%）では画像を新しいビューポートに収まる最大サイズで再計算し、拡大・縮小した表示では新しいビューポートに対するフィットを100%として、現在の倍率（FR-133）を適用して再計算する

#### FR-045 アイコンの対象（変更）

- **FR-045**: アプリアイコン以外のアイコンのうち、ツリーのフォルダアイコン（FR-047）、ファイルリストの行頭アイコン（FR-048）、ツールバーのボタンのアイコン（FR-051・FR-057・FR-089・FR-096・FR-112・FR-134）、お気に入りのスターアイコン（FR-061）は本機能の対象に含める。メニューバー常駐アイコンとウィンドウタイトルバーのアイコンは本機能の対象外とする

#### FR-107 履歴に記録する操作（変更）

- **FR-107**: システムは、次の操作を行ったとき、操作の後の状態を1件の履歴として記録しなければならない。
  （1）フォルダの選択: ツリーでのフォルダの選択（クリック・ダブルクリック・矢印キー。お気に入りの項目の選択（FR-063（directory-tree.md））を含む）。
  （2）フォルダの移動: ファイルリストでフォルダ・zip ファイル・zip の中のディレクトリを開く操作（FR-069（zip.md）・FR-076（file-list.md））と、
  `..`・⌘↑ で1つ上の階層へ戻る操作（FR-070（zip.md）・FR-077（file-list.md））。このときのツリーの選択の同期（FR-078（file-list.md））は
  同じ1件の履歴に含める。
  （3）表示の変更: 表示形式の切り替え（FR-010（file-list.md））、サムネイルサイズの変更（FR-014（file-list.md））、種類フィルタの切り替え
  （FR-056（file-list.md））、zip ファイルの表示の切り替え（FR-095（zip.md））、ペインの表示切り替え（FR-088（window-layout.md））。
  これらは「表示」メニュー・ショートカット・ツールバーのどこから行っても同じく記録する。サムネイルサイズの変更は、ほかの記録する
  操作と戻る・進むを挟まずに続けて行ったもの（スライダーの1回のドラッグ、続けて押した ⌃⌘. / ⌃⌘, を含む）を1件にまとめる。
  戻る・進むの直後のサイズの変更は、移った先の履歴にまとめず、新しい履歴として記録する（US8-AS7）。
  次は記録してはならない: ツールバーの表示切り替え（FR-050（window-layout.md））、フルスクリーン（FR-035・FR-036（preview.md））、
  ペインへのフォーカス移動、「お気に入り」の見出しの選択（⇧⌘F を含む。FR-065（directory-tree.md））、列見出しによる並べ替え（FR-012（file-list.md））、
  ファイルリストの中での選択の変更、ファイル操作（FR-018〜FR-027（file-operations.md））、検索の開始と検索結果の表示（FR-113）、戻る・進むそのもの、
  プレビュー画像の拡大・縮小・表示領域に合わせる（FR-133（preview.md）・FR-137（preview.md））、
  およびスライドショーの開始・終了・それに伴う一時的なペイン表示変更・自動送り・矢印キーの割り込み。
  スライドショー中の表示形式・サイズ・フィルタ等のユーザーによる表示変更は通常どおり記録するが、その履歴のペイン表示状態には開始前の
  復帰先を用い、一時的なプレビューのみ表示や実行状態は記録しない。ただし検索結果の表示中は FR-113 を優先し、表示変更を履歴に記録しない。
  スライドショー終了だけでは検索を解除せず、後で検索を解除した時点の通常の表示を現在の履歴へ反映する。一時的なペイン表示や実行状態は
  含めず、終了後にユーザーが変えたペイン表示は通常どおり扱う。
  操作の後の状態が現在の履歴と同じ場所・同じ表示の状態であれば（選択中のフォルダをもう一度選んだ場合など）、新しい履歴を記録しない。
  戻る側に移った後で新しい履歴を記録したときは、それより進む側の履歴をすべて取り除く（Finder と同じ）

### Key Entities *(include if feature involves data)*

- **表示倍率**（追加。preview.md の主なエンティティ）: プレビューに表示中の画像の倍率。フィット表示を100%とし、25%以上800%以下の25%の倍数を取る。画像ごとではなく、表示中のプレビューに対する一時的な状態で、別の画像に切り替わったときと履歴の移動後は100%に戻る。保存せず、履歴の表示の状態にも含めず、倍率の変更は履歴の1件としても記録しない（FR-137）

## Assumptions

### A-11 拡大した画像の見え方（変更）

- **A-11**: 画像はフィットで原寸を超えて拡大するため、小さい画像やドット絵は粗く（ぼやけて）見えることがある。画素をくっきり見せる表示（原寸表示や補間方法の選択）は引き続き範囲外とし、本機能の倍率変更（FR-133）は画像全体の拡大・縮小として提供する

### A-12 キーボード到達性（変更）

- **A-12**: 憲章 原則 III の「拡大/縮小/フィット」は、ユーザー操作として提供する場合のキーボード到達性を求めるものと解釈する。フィットは画像の初期表示として自動でも行い、手動の拡大・縮小・フィットには FR-135 のキー割り当てを設ける

### 追加: 非対話で採用した推奨回答と範囲

- **A-61**: ツールバーの3ボタンは左から拡大・表示領域に合わせる・縮小とし、要件の「左端」の重複は中ボタン（両矢印）をフィットとする意味に解釈する。3つは押した状態を保たない一時的なボタンで、現在の倍率が100%でもフィットボタンは押された見た目にしない
- **A-62**: 100%は原寸ではなくフィット表示とする。小さい画像は原寸を超えて拡大されたフィットの状態が100%になる。倍率の刻みは加算（25ポイント）とし、範囲は25%以上800%以下とする。800%を上限とするのは、拡大の要求に実用的な上限を置き、表示と操作の破綻を避けるためである
- **A-63**: ⌘+ / ⌘- は要望どおりプレビューの倍率変更に使う。既存のサムネイルサイズ変更は ⌃⌘. / ⌃⌘, に移し、キーボードだけで操作できる状態を保つ（FR-040・憲章 原則 III）。⌘+ はキーボード配列で `+` を入力するための Shift を含む操作のほか、Shift なしの ⌘= でも受け付ける（A-72）。プレビューに画像がないときの ⌘+ / ⌘- は何もしない
- **A-64**: 拡大した画像の表示位置を変えるスクロール・パン・ドラッグ、トラックパッドのピンチ操作、倍率の数値表示、倍率のスライダー、画像ごとの倍率の記憶は範囲外とする。スライドショーの切り替え効果「ズーム」（FR-130（preview.md））は本機能の倍率変更とは別の機能であり、変更しない

- **A-66**: 表示倍率は画像を切り替えたときに100%へ戻す。フルスクリーンの切替・サイズ変更・ツールバーの表示切替・同じ画像を表示したままのペイン表示の復帰では保つ。保存も履歴への記録もしない。履歴の移動後は100%で表示する

- **A-68**: アニメーション画像は倍率変更で再生をやり直さない。アニメーション WebP を再生できない場合は、先頭フレームの静止画として拡大・縮小できる（FR-030（preview.md））
- **A-69**: ⌘+ / ⌘- のサムネイルサイズからの移行は、contracts/keyboard-and-menus.md の全該当箇所（プレビューのみ表示・zip の中・検索結果・サイズのスライダー・メニューバー）と navigation-history.md の FR-107（3）・US8-AS7 に及ぶ。プレビューのみ表示では、プレビューに画像があれば ⌘+ / ⌘- は倍率、⌃⌘. / ⌃⌘, はサムネイルサイズを変える
- **A-70**: 倍率の変更は履歴の1件として記録しない。履歴の表示の状態にも含めない。25%刻みの連続操作で履歴が埋まらず、戻る・進むを閲覧の移動として使えるようにするためである
- **A-71**: 可視の倍率表示を追加しない代わりに、倍率をアクセシビリティの値として公開し、変更時に読み上げる。憲章 原則 III のアクセシビリティを、可視 UI を増やさずに満たすためである
- **A-72**: 拡大は ⌘= と ⇧⌘= の両方で受け付ける。`+` の入力に Shift を要する配列でも、Shift なしで拡大できるようにするためである。メニューとツールチップの表示は要件どおり ⌘+ とする

- **A-75**: ショートカットは US 配列を基準とする。プレビューの拡大は ⌘+ と ⌘= で受け付け、JIS 配列向けの別のキー（⌘; など）は追加しない。JIS など異なる配列での使いにくさは、将来のショートカットキーのカスタマイズ（本機能の範囲外）で回避できるようにする
