# Quickstart: プレビュー画像の拡大・縮小の検証

**Date**: 2026-10-27 | **Branch**: `008-preview-image-zoom`

本書は実装後の検証ガイド。操作の契約は [contracts/preview-zoom.md](contracts/preview-zoom.md)、状態とリセットは [data-model.md](data-model.md)、受け入れ条件は [spec.md](spec.md) を参照する。数値・文言の正本は spec と product の領域。

## 前提

- macOS 15 以降、Swift 6 の開発環境、Instruments（OS Signposts／Points of Interest）。
- ネットワーク接続・外部パッケージは不要。
- GUI の起動と操作はユーザーが行う。エージェントは build・test・bundle の作成までを行い、起動コマンドと確認点を渡す。
- 倍率は保存しないため、UserDefaults の削除・移行は不要。再起動後は常に100%から始まる。

## 手動シナリオ

### 1. ツールバー・メニュー・キー（US14-AS1〜AS4・AS7・AS11・AS12、SC-045・SC-049）

1. `zoom/03-landscape-24mp.jpg` を選択し、3ペインのプレビューに表示する。ツールバーに「スライドショーを開始」の右隣、種類フィルタの左に3つのボタンが並ぶ。左から虫眼鏡に `+`・両矢印・`-` が入ったアイコンで、ライト・ダークの両方で区別できる。
2. 各ボタンのツールチップに「拡大（⌘+）」「表示領域に合わせる（⌘0）」「縮小（⌘-）」が出る。
3. 左ボタンを1回押す。125%になり、縦横比を保ったまま中央に表示される。もう一度で150%。
4. 右ボタンで125% → 100% → 75% → 50% → 25%。25%で右ボタンが無効になり、それ以上下がらない。
5. 中ボタンで100%のフィットに戻る。画像全体がビューポートに収まり、中央に表示される。
6. ⌘+・⌘-・⌘0 がツールバーと同じ結果になる。⌘+ は ⇧⌘= でも ⌘= でも同じく1段上がる。メニューの表示は ⌘+ のまま。
7. 「表示」メニューで「フルスクリーン」の下に区切り線があり、「拡大」「縮小」「表示領域に合わせる」の順に並ぶ。各項目が上と同じ結果になる。
8. 100%から「拡大」を28回実行する。800%で止まり、拡大のツールバーセグメントとメニュー項目が無効になる。29回目を実行しても800%のまま。
9. 150%から「拡大」を実行してから ⌘[ を押す。倍率変更は履歴に記録されず、⌘[ は倍率変更より前の履歴へ移る。移った先の画像は100%（US14-AS15）。

### 2. 表示領域に合わせる・サイズ変更・フルスクリーン（US14-AS3・AS8、EC-81、SC-044）

1. ビューポートより大きい画像と小さい画像の両方で、拡大・縮小のあとに中ボタン・⌘0・メニューを実行する。毎回 FR-028 のフィットと同じ大きさ・位置になる。
2. 200%にしてからウィンドウを大きく／小さくする。新しいビューポートのフィットを100%として200%が適用され、縦横比と中央配置が保たれる。
3. 200%でフルスクリーンにする。200%を保ち、解除しても200%を保つ。再びフルスクリーンにしても200%のまま。
4. ツールバーを非表示にする。倍率は変わらず、メニューとショートカットで操作できる。
5. ペインの境界をドラッグしてプレビューの幅を変える。倍率を保ったまま再計算される。

### 3. 画像の切り替え・履歴・ペイン・スライドショー（US14-AS5・AS10・AS15、EC-86〜EC-88・EC-90、SC-047）

1. 画像Aを150%にして、ファイルリストで画像Bを選ぶ。Bは100%で現れる。Aへ戻っても100%。
2. 150%でプレビューのみ表示にし、同じ画像のまま3ペインへ戻す。倍率は保たれる。ファイルリストのみ表示にして戻しても同じ。
3. ファイルリストのみ表示の間に別の画像を選び、プレビューへ戻す。新しい画像は100%。
4. 150%で履歴の戻る・進むを使う。同じ画像に戻る場合も100%。
5. `slideshow/mixed/` を開始し、画像を200%にして自動送りを待つ。次の画像は100%で現れ、間隔・切り替え効果は変わらない。切り替え効果の途中で倍率を変えても、効果の進行・次の予定時刻は変わらない。
6. 履歴の戻る・進むの直後に倍率を変える。履歴の件数は増えず、表示の状態も変わらない。
7. アプリを終了して起動し直す。最初の画像は100%で表示される。

### 4. 無効な状態（US14-AS6・AS14、EC-85・EC-89、SC-046）

1. 動画を表示し、ツールバーの3ボタン・メニューの3項目が無効で、⌘+・⌘-・⌘0 を押しても何も起きないことを確かめる。
2. 画像のない空のプレビュー、破損画像（`broken/`）、ファイルリストのみ表示でも同じ。
3. 25%で縮小、800%で拡大を、ツールバー・メニュー・ショートカットのそれぞれで実行する。表示は変わらず、反対端へ循環しない。
4. 動画の状態で ⌘+ / ⌘- を押す。サムネイルサイズが変わらないことも確かめる。
5. プレビューのみ表示で画像を表示していない・動画のとき、⌘+ / ⌘- は何もせず、⌃⌘. / ⌃⌘, だけが隠れたファイルリストのサムネイルサイズを変える。

### 5. サムネイルサイズの移行（US14-AS9・AS14、SC-045・SC-051）

1. 3ペイン表示・サムネイル形式で ⌃⌘. / ⌃⌘, を押す。サムネイルの大きさが従来どおり16ポイントずつ変わり、プレビューの倍率は変わらない。
2. ⌘+ / ⌘- を押す。プレビューの倍率だけが変わり、サムネイルサイズは変わらない。
3. プレビューのみ表示にして ⌘+ を押し、続けて ⌃⌘. を押す。⌘+ で倍率が125%になり、⌃⌘. で隠れたファイルリストのサムネイルサイズが大きくなる。3ペインへ戻すと両方が反映されている。
4. 表示メニューの「サムネイルを拡大」「サムネイルを縮小」の表示が ⌃⌘. / ⌃⌘, になり、キーボードだけで操作できる。ツールバーのサイズのスライダーと下部バーの説明も同じキーを示す。
5. 履歴の US8-AS7 相当（サムネイルサイズの変更）が ⌃⌘. / ⌃⌘, で記録される。⌘+ / ⌘- では履歴の件数が変わらない。

### 6. 極端な画像・アニメーション・性能（EC-82〜EC-84、SC-043・SC-048）

1. `zoom/01-small-16.png` と `zoom/02-tiny-1.png` を表示する。フィットで拡大された状態が100%で、25%刻みの拡大・縮小ができ、クラッシュしない。
2. 100%から800%まで拡大し、800%から25%まで縮小する。各段で縦横比と中央配置が崩れず、上下限を超えない。これを20回繰り返す。
3. `bigimage/big.png`（1億画素）で拡大・縮小を繰り返す。操作中にアプリが応答し続ける。
4. アニメーション GIF とアニメーション WebP を表示し、倍率を変える。再生が最初からやり直さない。再生できない WebP は先頭フレームの静止画として拡大・縮小できる。
5. 24MP の JPEG で拡大・縮小・フィットを各10回行う。操作から表示完了までが0.5秒以内で、UI が応答しない回数が0回であることを、OS Signposts の `PreviewZoomApply` と目視で記録する。結果を作業ログに残す。

### 7. VoiceOver（US14-AS13、SC-050）

1. VoiceOver を有効にして画像を表示する。プレビューの値が現在の倍率（例「100%」）になっている。
2. 「拡大」を実行する。値が125%に変わり、「125%」と読み上げられる。画面上に倍率の数値表示は出ない。
3. 100%から800%まで拡大し、800%から25%まで縮小する。各操作の後に値が実際の倍率と一致し、新しい倍率が読み上げられる。読み上げの回数が操作回数と一致する。
4. 画像を切り替える。値は100%に戻るが、操作による変更ではないため読み上げの通知はない。
5. 動画・空・表示できない画像・ファイルリストのみ表示で、3操作が無効として読み上げられる。
6. ツールバーの3セグメントが「拡大」「表示領域に合わせる」「縮小」と読み上げられ、ツールチップにそれぞれのキーが含まれる。

### 8. シート・設定ウインドウ・名前の変更中（US14-AS16、SC-052）

1. ファイル名を編集中に ⌘+・⌘-・⌘0 を押す。倍率が変わり、編集は続く。
2. 検索のシートを表示中に同じ3キーを押す。倍率が変わり、シートは閉じない。
3. 設定ウインドウをキーにした状態で同じ3キーを押す。倍率が変わり、設定ウインドウは閉じない・値も変わらない。
4. それぞれ10回繰り返し、期待どおりの倍率になることを確かめる。
