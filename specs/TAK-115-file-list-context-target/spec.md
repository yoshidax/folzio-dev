## User Scenarios & Testing *(mandatory)*

変更点だけを定める。背景の右クリック（FR-213（file-list.md）・A-121（file-operations.md））、右クリックメニューの項目の並び、
キーボードショートカットとメニューバーのメニューの対象（選択中の項目）、ツリーの右クリック（A-21（directory-tree.md））は変えない。

ID は、並行して進めている TAK-105（未マージ）が使う FR-395〜FR-396・SC-216〜SC-218・EC-261〜EC-263・
A-232〜A-236・US85 の次から振る。

### User Story 1 - 右クリックした項目を操作する (Priority: P1)

利用者はファイルリストで、選択していない項目を右クリックしてメニューの操作を選び、選択を変えずにその項目に対して実行する。
選択中の別の項目が操作の対象になることはない。

**Why this priority**: TAK-115 の中心の要件である。今は選択外の項目を右クリックしても選択中の項目が対象になり、
右クリックした項目と違うものをゴミ箱に入れたり名前を変えたりするおそれがある。ツリーとファイルリストで右クリックの対象の
規則を揃える。

**Independent Test**: リスト形式で項目 A を選択した状態で項目 B を右クリックして「ゴミ箱に入れる」を選び、
選択とプレビューが A のままで、対象が B だけ（確認モーダルを出す設定なら対象は B だけ）であり、A が残ることを確かめる。
サムネイル形式でも同じ手順で確かめる。

**Acceptance Scenarios**:

- **US86-AS1**: **Given** リスト形式の通常のフォルダの一覧で項目 A を選択し、A をプレビューしている,
  - **When** 選択していない項目 B を右クリックする,
  - **Then** 選択とプレビューは A のままで、B が選択とは別の枠で示され、項目向けの右クリックメニューが出る
- **US86-AS2**: **Given** US86-AS1 のメニューを表示している,
  - **When** 「ゴミ箱に入れる」を選ぶ,
  - **Then** B だけを対象にし（確認モーダルを出す場合は対象を B だけとして示し）、A はゴミ箱に入らず、選択は A のまま残る
- **US86-AS3**: **Given** サムネイル形式で項目 A を選択している,
  - **When** 選択していない項目 B を右クリックして「名前を変更」を選ぶ,
  - **Then** 選択は A のままで、B の名前の編集が始まる（A の名前は編集されない）
- **US86-AS4**: **Given** 項目 A を選択している,
  - **When** 選択していない項目 B を右クリックし、「コピー」「複製」「パス名をコピー」「開く」「Finder に表示」を
    それぞれ選ぶ,
  - **Then** どれも B だけを対象にし、メニューの「コピー」の文言は B の名前を示す
- **US86-AS5**: **Given** 項目 A・B・C を複数選択している,
  - **When** B を右クリックして「ゴミ箱に入れる」を選ぶ,
  - **Then** 選択は A・B・C のまま変わらず、A・B・C の全体を対象にする（従来どおり）
- **US86-AS6**: **Given** 項目 A を選択している,
  - **When** 選択していない項目 B を右クリックし、メニューの項目を選ばずに閉じる,
  - **Then** 選択・プレビューは A のままで、B の枠は消える
- **US86-AS7**: **Given** 検索結果の表示中、または zip の中の一覧で項目 A を選択している,
  - **When** 選択していない項目 B を右クリックする,
  - **Then** 通常のフォルダの一覧と同じく選択は A のままで、メニューの操作は B を対象にする
    （zip の中で使えない操作が淡色になるのは従来どおり（FR-073（zip.md）））
- **US86-AS8**: **Given** 項目 A を選択している,
  - **When** 選択していない項目 B を右クリックしたあと、⌘⌫ を押す（またはメニューバーの「ファイル」の「ゴミ箱に入れる」を選ぶ）,
  - **Then** キーボードとメニューバーの操作は従来どおり選択中の A を対象にする
- **US86-AS9**: **Given** 項目 A を選択している,
  - **When** 項目のない背景を右クリックする,
  - **Then** 選択は A のまま変わらず、表示中のフォルダ向けのメニューが出る（FR-213（file-list.md）。従来どおり）

### Edge Cases

- **EC-264**: 選択外の項目として `..` を右クリックした場合は、選択中の項目に関わらず、`..` に対して使えない操作
  （ゴミ箱に入れる・名前を変更・複製・コピーなど）を淡色にする。
- **EC-265**: 別の項目の名前を編集している間に選択外の項目を右クリックした場合は、
  ほかの項目をクリックしたときと同じく名前の編集を終えてから、メニューを出す。
- **EC-266**: 動画を再生している間に選択外の項目を右クリックした場合は、選択とプレビューを変えないため、
  再生を止めない。
- **EC-267**: 選択外の項目に対するメニューの操作の結果、その項目が一覧から消えた（ゴミ箱に入れた、名前を変えて
  並び順が変わったなど）場合も、選択中の項目の選択は保つ。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-397**: ファイルリストで選択していない項目を右クリックしたとき、システムは、選択を変えずに、
  その項目だけを項目向けの右クリックメニューの操作の対象にしなければならない。
  - リスト形式とサムネイル形式の両方に適用し、通常のフォルダの一覧・検索結果・zip の中の一覧のどれでも同じとする。
  - 選択・フォーカスのある項目・プレビュー・キーボードフォーカスは変えない（A-238）。
  - メニューの項目の有効・無効と文言（「“B”をコピー」など）は、右クリックした項目に基づいて決める。
  - 対象にするメニューの項目は、「中を表示」「開く」「このアプリケーションで開く」「ゴミ箱に入れる」「名前を変更」
    「複製」「コピー」「パス名をコピー」「Finder に表示」とする。
  - 「上の階層へ」「ペースト」「移動ペースト」は、従来どおり表示中のフォルダ（または表示中の階層）に対して働く。
  - メニューを表示している間は、右クリックした項目を選択とは別の枠で示し、メニューを閉じたら消す。
  - 選択中の項目を右クリックしたときは、従来どおり選択を変えず、選択中の項目の全体を対象にする。
  - 背景の右クリックは FR-213（file-list.md）のまま、選択を変えない。
- **FR-398**: 選択外の項目の右クリックメニューで「名前を変更」を選んだとき、システムは、選択を変えずに、
  その項目の名前の編集を始めなければならない。
  - 編集の始め方と終え方、名前の検証、確認は、選択中の項目の名前の変更と同じとする。

### Key Entities

- **右クリックメニューの対象**: 右クリックした項目が選択中なら選択中の全体、選択外ならその項目だけ、背景なら表示中のフォルダ。
  メニューを開くたびに決め、そのメニューの操作だけに使う。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-219**: リスト形式とサムネイル形式のそれぞれで、ある項目を選択した状態で選択していない別の項目を右クリックし、
  FR-397 の対象のメニューの項目を選んだとき、右クリックした項目以外が対象になる件数と、選択が変わる件数がどちらも 0 件。
- **SC-220**: 複数選択している項目のうちの1つを右クリックしてメニューの操作を選んだとき、
  対象が選択中の全体と異なる件数が 0 件。

## Assumptions

- **A-237**: 右クリックには、Control キーを押しながらのクリックと、トラックパッドの2本指のクリックを含む
  （OS が項目のメニューを出す操作のすべて）。
- **A-238**: 右クリックではキーボードフォーカスを移さない（「名前を変更」で名前の編集を始めるときだけ、
  編集のためにファイルリストへ移す）。
- **A-239**: 右クリックした項目を対象にするのは右クリックメニューの操作だけとし、キーボードショートカットと
  メニューバーのメニューは従来どおり選択中の項目を対象にする。
