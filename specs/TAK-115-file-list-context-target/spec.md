# Feature Specification: ファイルリストの右クリックの対象を Finder に合わせる

**Feature Branch**: `feature/tak-115-file-list-context-target`

**Created**: 2026-11-16

**Status**: Draft

**Input**: [TAK-115](https://linear.app/takyoshida/issue/TAK-115/)「ファイルリストで選択外の項目を右クリックしたとき、Finder と同じくその項目を選択して操作の対象にする」。

## Clarifications

### Session 2026-11-16

- Q: 選択外の項目を右クリックしたとき、選択を変えずにその項目だけを対象にするか、その項目を選択するか
  → A: Finder のリスト表示・アイコン表示と同じく、その項目を選択する（保守者の決定。FR-397）
- Q: 選択中の項目を右クリックしたときは → A: 今の複数選択を保ち、選択中の全体を対象にする（FR-397）
- Q: メニューを何も選ばずに閉じたとき、選択を右クリックの前に戻すか → A: 戻さない（Finder と同じ。EC-264）
- Q: 右クリックでキーボードフォーカスをファイルリストへ移すか → A: 移さない（現行の右クリックの動作と、
  FR-079（file-operations.md）の「右クリックメニューから削除したときはフォーカスを移さない」に合わせる。A-238）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。背景の右クリック（FR-213（file-list.md）・A-121（file-operations.md））、
右クリックメニューの項目と有効条件、ツリーの右クリック（A-21（directory-tree.md））は変えない。

ID は、並行して進めている TAK-105（未マージ）が使う FR-395〜FR-396・SC-216〜SC-218・EC-261〜EC-263・
A-232〜A-236・US85 の次から振る。

### User Story 1 - 右クリックした項目を操作する (Priority: P1)

利用者はファイルリストで、選択していない項目を右クリックしてメニューの操作を選び、その項目に対して実行する。
選択中の別の項目が操作の対象になることはない。

**Why this priority**: TAK-115 の中心の要件である。今は選択外の項目を右クリックしても選択中の項目が対象になり、
右クリックした項目と違うものをゴミ箱に入れたり名前を変えたりするおそれがある。

**Independent Test**: リスト形式で項目 A を選択した状態で項目 B を右クリックして「ゴミ箱に入れる」を選び、
確認モーダルの対象が B だけで、確定すると B だけがゴミ箱に入ることを確かめる。
サムネイル形式でも同じ手順で確かめる。

**Acceptance Scenarios**:

- **US86-AS1**: **Given** リスト形式の通常のフォルダの一覧で項目 A を選択している,
  - **When** 選択していない項目 B を右クリックする,
  - **Then** 選択が B だけに変わり、プレビューが B に切り替わってから、項目向けの右クリックメニューが出る
- **US86-AS2**: **Given** US86-AS1 のメニューを表示している,
  - **When** 「ゴミ箱に入れる」を選ぶ,
  - **Then** B だけを対象にし（確認モーダルを出す場合は対象を B だけとして示し）、A はゴミ箱に入らない
- **US86-AS3**: **Given** サムネイル形式で項目 A を選択している,
  - **When** 選択していない項目 B を右クリックして「名前を変更」を選ぶ,
  - **Then** B が選択され、B の名前の編集が始まる（A の名前は編集されない）
- **US86-AS4**: **Given** 項目 A・B・C を複数選択している,
  - **When** B を右クリックして「ゴミ箱に入れる」を選ぶ,
  - **Then** 選択は A・B・C のまま変わらず、A・B・C の全体を対象にする
- **US86-AS5**: **Given** 項目 A を選択している,
  - **When** 選択していない項目 B を右クリックし、メニューの項目を選ばずに閉じる,
  - **Then** 選択は B のまま残り、A へは戻らない
- **US86-AS6**: **Given** 検索結果の表示中、または zip の中の一覧で項目 A を選択している,
  - **When** 選択していない項目 B を右クリックする,
  - **Then** 通常のフォルダの一覧と同じく B だけが選択され、メニューの操作は B を対象にする
    （zip の中で使えない操作が淡色になるのは従来どおり（FR-073（zip.md）））
- **US86-AS7**: **Given** 項目 A を選択している,
  - **When** 項目のない背景を右クリックする,
  - **Then** 選択は A のまま変わらず、表示中のフォルダ向けのメニューが出る（FR-213（file-list.md）。従来どおり）

### Edge Cases

- **EC-264**: 選択外の項目の右クリックで選択が変わった後に、メニューの項目を選ばずに閉じた場合は、
  選択を右クリックの前に戻さない。
- **EC-265**: 別の項目の名前を編集している間に選択外の項目を右クリックした場合は、
  ほかの項目をクリックして選んだときと同じく名前の編集を終えてから、右クリックした項目を選択する。
- **EC-266**: 再生中の動画をプレビューしている間に選択外の項目を右クリックした場合は、
  ほかの選択の変更と同じく再生を止め、右クリックした項目をプレビューする（FR-034（preview.md））。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-397**: ファイルリストで選択していない項目を右クリックしたとき、システムは、その項目だけを選択してから、
  項目向けの右クリックメニューを表示しなければならない。
  - リスト形式とサムネイル形式の両方に適用し、通常のフォルダの一覧・検索結果・zip の中の一覧のどれでも同じとする。
  - 選択の変更は、その項目をクリックして選んだときと同じに扱い、プレビューもその項目に切り替える。
  - 選択中の項目を右クリックしたときは選択を変えず、メニューの操作は選択中の項目の全体を対象にする。
  - 背景の右クリックは FR-213（file-list.md）のまま、選択を変えない。
  - キーボードフォーカスは移さない（A-238）。

### Key Entities

- 新しいエンティティはない。既存のファイルリストの選択（選択中の項目とフォーカスのある項目）を、右クリックで変える。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-219**: リスト形式とサムネイル形式のそれぞれで、ある項目を選択した状態で選択していない別の項目を右クリックし、
  「ゴミ箱に入れる」「名前を変更」「複製」「コピー」「パス名をコピー」を選んだとき、
  右クリックした項目以外が対象になる件数が 0 件。
- **SC-220**: 複数選択している項目のうちの1つを右クリックしてメニューの操作を選んだとき、
  対象が選択中の全体と異なる件数が 0 件。

## Assumptions

- **A-237**: 右クリックには、Control キーを押しながらのクリックと、トラックパッドの2本指のクリックを含む
  （OS が項目のメニューを出す操作のすべて）。
- **A-238**: 右クリックではキーボードフォーカスを移さない（ツリーやプレビューにフォーカスがあるときは、
  選択とプレビューだけが変わり、⌘⌫ などのキーボード操作は従来どおりフォーカスのあるペインに働く）。
- **A-239**: 選択が変わるのは、OS が項目向けのメニューを出すときだけとする（列見出しの右クリック（FR-273（file-list.md））
  と背景の右クリックでは選択を変えない）。
