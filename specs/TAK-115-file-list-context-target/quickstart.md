# Quickstart: ファイルリストの右クリックの対象をツリーに合わせる

## 自動の検証

```bash
swift build
swift test
scripts/dev/check-all.sh
scripts/make-app.sh
```

## GUI の確認

古い Folzio を終了してから `open .build/Folzio.app` で起動し、3ペインが表示されることを確かめてから行う。
画像が数枚あるフォルダを使う（ゴミ箱に入れても困らないコピーを用意する）。

1. リスト形式で項目 A を選択し、選択していない項目 B を右クリックする。
   - 選択とプレビューは A のままで、B に枠が出てからメニューが出る（US86-AS1）
   - 「ゴミ箱に入れる」を選ぶと、B だけが対象になる（確認モーダルが出る設定なら、対象は B だけ）。A は残り、選択も A のまま（US86-AS2）
2. サムネイル形式で項目 A を選択し、選択していない項目 B を右クリックする。
   - 選択は A のままで、B に枠が出る。メニューを閉じると枠が消える（US86-AS1・US86-AS6）
   - もう一度 B を右クリックして「名前を変更」を選ぶと、選択は A のままで B の名前の編集が始まる（US86-AS3）
3. どちらかの形式で A を選択し、選択していない B を右クリックして、「コピー」の文言が B の名前を示すことを確かめる。
   - 「コピー」を選んでから表示中のフォルダへペーストすると、B のコピーができる（US86-AS4）
   - 同じく B を右クリックして「複製」を選ぶと、B の複製ができる
4. どちらかの形式で A・B・C を複数選択し、B を右クリックする。
   - 選択は A・B・C のまま。「ゴミ箱に入れる」の対象（確認モーダル）は3件（US86-AS5）
5. A を選択し、選択していない B を右クリックしてメニューを閉じてから、⌘⌫ を押す。
   - 対象は選択中の A（US86-AS8）
6. A を選択し、項目のない背景を右クリックする。
   - 選択は A のままで、「新規フォルダ」を含む表示中のフォルダ向けのメニューが出る（US86-AS9）
7. Control キーを押しながら選択していない項目をクリックする（トラックパッドなら2本指のクリックも）。
   - 右クリックと同じく、その項目に枠が出て、メニューの操作はその項目を対象にする（A-237）
8. 動画を再生中に、選択していない別の項目を右クリックする。
   - 再生は止まらず、プレビューも変わらない（EC-266）
9. 項目 A の名前を編集中（Return で編集を始め、名前を変えた状態）に、選択していない項目 B を右クリックする。
   - A の名前の編集が終わってから、B を対象にしたメニューが出る（EC-265）
10. 1件のファイルを選択した状態で、`..` の行（zip の中など、`..` が出る一覧）を右クリックする。
    - 「ゴミ箱に入れる」「名前を変更」「複製」「コピー」は淡色になる（EC-264）
