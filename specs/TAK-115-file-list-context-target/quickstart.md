# Quickstart: ファイルリストの右クリックの対象を Finder に合わせる

## 自動の検証

```bash
swift build
swift test
scripts/dev/check-all.sh
scripts/make-app.sh
```

## GUI の確認

古い Folzio を終了してから `open .build/Folzio.app` で起動し、3ペインが表示されることを確かめてから行う。
画像が数枚あるフォルダを使う（ゴミ箱に入れても困らないコピーを用意する）。

1. リスト形式で項目 A を選択し、選択していない項目 B を右クリックする。
   - 選択が B だけに変わり、プレビューが B に切り替わってからメニューが出る（US86-AS1）
   - 「ゴミ箱に入れる」を選ぶと、B だけが対象になる（確認モーダルが出る設定なら、対象は B だけ）。A は残る（US86-AS2）
2. サムネイル形式で項目 A を選択し、選択していない項目 B を右クリックして「名前を変更」を選ぶ。
   - B の名前の編集が始まる（US86-AS3）
3. どちらかの形式で A・B・C を複数選択し、B を右クリックする。
   - 選択は A・B・C のまま。「ゴミ箱に入れる」の対象（確認モーダル）は3件（US86-AS4）
4. A を選択し、選択していない B を右クリックしてから、Esc またはメニューの外のクリックでメニューを閉じる。
   - 選択は B のまま残る（US86-AS5）
5. A を選択し、項目のない背景を右クリックする。
   - 選択は A のままで、「新規フォルダ」を含む表示中のフォルダ向けのメニューが出る（US86-AS7）
6. Control キーを押しながら選択していない項目をクリックする（トラックパッドなら2本指のクリックも）。
   - 右クリックと同じく、その項目が選択されてからメニューが出る（A-237）
7. ツリーをクリックしてフォーカスをツリーに置いたまま、ファイルリストの選択していない項目を右クリックし、メニューを閉じる。
   - ファイルリストの選択とプレビューはその項目に変わり、キーボードフォーカスはツリーに残る（A-238）
8. 動画を再生中に、選択していない別の項目を右クリックする。
   - 再生が止まり、右クリックした項目がプレビューされる（EC-266）
9. 項目 A の名前を編集中（Return で編集を始め、名前を変えた状態）に、選択していない項目 B を右クリックする。
   - ほかの項目をクリックしたときと同じく A の名前の編集が終わり、B が選択されてからメニューが出る（EC-265）
