# Feature Specification: リスト形式の列の表示・非表示

**Feature Branch**: `claude/jolly-ptolemy-1b91ys`（Cloud が指定した作業ブランチ。feature ディレクトリとは独立）

**Created**: 2026-11-02

**Status**: Draft

**Input**: [TAK-47](https://linear.app/takyoshida/issue/TAK-47/) 「リスト形式の列を Finder と同じく列見出しの右クリックで表示・非表示できるようにする」。
会話で「ISSUE TAK-47に対応して」と依頼され、次の点を保守者が決めた。

- 列の表示状態は保存し、アプリの再起動後も復元する（Finder と同じ）
- 「場所」列（FR-084・search.md）はポップアップの対象に含めず、従来どおり検索結果の表示中だけ自動で表示する
- 「ファイル名」列は Finder の「名前」と同じく、ポップアップの項目に含めず常に表示する（すべての列を非表示にしても残る）
- サイズ・変更日は既定で非表示とし、既定の表示列は現行どおりファイル名・作成日・種類とする
- サイズは自動単位（KB・MB など）で表示し、フォルダ（zip の中のフォルダを含む）は `--` とする
- 列幅・列の並び順の保存は今回の範囲外とする

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。リスト形式は FR-010〜FR-012（file-list.md）、日付の書式は FR-151（overview.md）、場所列は FR-084（search.md）に従う。US51〜US52 は永続シナリオ ID。

### User Story 1 - 列見出しの右クリックで列を選ぶ (Priority: P1)

利用者はリスト形式の列見出しを右クリックし、Finder と同じ項目のポップアップで、表示する列をチェックで選ぶ。

**Why this priority**: Issue の中心の価値。サイズ・変更日を確認したい利用者が、列を足せるようになる。

**Independent Test**: リスト形式で列見出しを右クリックし、「サイズ」にチェックを入れると、サイズの列がすぐに現れる。

**Acceptance Scenarios**:

- **US51-AS1**: **Given** リスト形式でフォルダを表示中、**When** 列見出しの行を右クリックする、**Then** 「作成日」「種類」「サイズ」「変更日」の順の項目を持つポップアップが開き、表示中の列にチェックが付く。「ファイル名」の項目はない（Finder の「名前」と同じ）。
- **US51-AS2**: **Given** ポップアップを開いている、**When** チェックのない項目を選ぶ、**Then** その列がすぐに一覧へ加わる。続けて同じ項目を選ぶと、列がすぐに消える。ポップアップは項目を選ぶと閉じる。
- **US51-AS3**: **Given** 「作成日」「種類」「サイズ」「変更日」をすべて非表示にした、**When** 一覧を見る、**Then** 「ファイル名」の列だけが残り、表示されている。ファイル名の列を隠す手段はない。
- **US51-AS4**: **Given** 既定の状態（初回起動）、**When** リスト形式を表示する、**Then** ファイル名・作成日・種類の列だけを表示する。サイズ・変更日は表示しない。
- **US51-AS5**: **Given** 列見出しではなくファイルの行や一覧の空白を右クリックする、**When** メニューを見る、**Then** 列の選択は現れない（既存の挙動を変えない）。
- **US51-AS6**: **Given** サムネイル形式、**When** 表示する、**Then** 列の設定は影響しない。

### User Story 2 - サイズと変更日を見て並べ替える (Priority: P2)

利用者は、追加したサイズ・変更日の列で内容を確認し、列見出しのクリックで並べ替える。

**Why this priority**: 列を足しても使えなければ価値が半減するが、列の選択が先にできれば成り立つ。

**Independent Test**: サイズの列を表示し、列見出しをクリックすると、サイズの昇順・降順に並ぶ。

**Acceptance Scenarios**:

- **US52-AS1**: **Given** サイズの列を表示中、**When** ファイルを見る、**Then** 自動単位（KB・MB など）で表示する。フォルダ（zip の中のフォルダを含む）と、取得できない項目は `--` を表示する。
- **US52-AS2**: **Given** 変更日の列を表示中、**When** ファイルを見る、**Then** 作成日と同じ書式（FR-151）で変更日を表示する。zip の中の項目は、entry の更新日時を表示する。取得できない項目は `--` を表示する。
- **US52-AS3**: **Given** サイズまたは変更日の列を表示中、**When** 列見出しをクリックする、**Then** その列の昇順に並び、もう一度クリックすると降順になる（FR-012）。サイズの並べ替えでは、フォルダ（zip の中のフォルダを含む）を 0 バイトとして扱う（Finder と同じ）。昇順ではフォルダが先頭（フォルダどうしは名前の自然順）、降順では末尾になる。変更日の並べ替えでは、フォルダもファイルと同じく変更日で並べ、フォルダをまとめて先頭や末尾に置かない。変更日を取得できない項目は、昇順・降順のどちらでも末尾に置く。値が同じ項目は名前の自然順にする。
- **US52-AS4**: **Given** 「表示 > 並べ替え」メニュー、**When** メニューを開く、**Then** サイズと変更日が項目に加わり、列見出しのクリックと同じ並べ替えが行える。列が非表示でも選べる。
- **US52-AS5**: **Given** サイズで並べ替え中、**When** 「サイズ」の列を非表示にする、**Then** 並べ替えはファイル名に切り替わる。方向は、ファイル名で最後に並べ替えたときの方向（一度も並べ替えていなければ昇順）とする（Finder と同じ）。この方向はアプリの再起動後も復元する。作成日・種類・変更日でも同じ。

### User Story 3 - 列の表示状態を保存する (Priority: P2)

利用者が選んだ列は、アプリを再起動しても同じになる。

**Why this priority**: 起動のたびに選び直すのは Finder の操作感を損なう。

**Independent Test**: サイズの列を表示してアプリを終了し、再起動すると、サイズの列が表示されている。

**Acceptance Scenarios**:

- **US52-AS6**: **Given** 列の表示を変更した、**When** アプリを終了して再起動する、**Then** 同じ列が表示される。
- **US52-AS7**: **Given** 保存された値が壊れている、または未知の列を含む、**When** 起動する、**Then** 既定の列で表示し、クラッシュしない。未知の列は無視する。

### Edge Cases

- 検索結果の表示中: 場所の列は、ポップアップの設定とは別に自動で現れる（FR-084）。ポップアップには加えない。
- 並べ替えに使っている列を非表示にした場合: ファイル名の並べ替えに切り替わる（US52-AS5）。「表示 > 並べ替え」メニューで選んだ列は、非表示でも並べ替えに使える。
- zip の中のフォルダ、アクセスできないファイルのサイズ・変更日: `--` を表示する。
- ファイルの行の選択、リネーム、Quick Look の位置（ファイル名の列が基準）: 他の列の表示・非表示に影響されない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-269**: リスト形式の列見出しの行を右クリックすると、「作成日」「種類」「サイズ」「変更日」の順の項目を持つポップアップが開かなければならない。表示中の列にはチェックを付ける。場所の列（FR-084）は項目に含めない
- **FR-270**: ポップアップの項目を選ぶと、その列の表示・非表示をすぐに一覧へ反映しなければならない。「ファイル名」の列はポップアップの項目に含めず、すべての列を非表示にしても常に表示する（Finder の「名前」と同じ）。既定の表示列は、ファイル名・作成日・種類とする
- **FR-271**: 列の表示状態は保存し、次回起動時に復元しなければならない。保存された値が壊れている場合は既定に戻し、未知の列は無視する（FR-003 の保存対象に加える）
- **FR-272**: リスト形式は「サイズ」「変更日」の列を持てなければならない。サイズは自動単位で表示し、フォルダ（zip の中のフォルダを含む）と取得できない項目は `--` とする。変更日は FR-151 の書式で表示し、zip の中の項目は entry の更新日時を使う。取得できない場合は `--` とする
- **FR-273**（FR-012 の追記）: 「サイズ」「変更日」の列見出しのクリックと「表示 > 並べ替え」メニューで、その列の昇順・降順に並べ替えられなければならない。サイズの並べ替えではフォルダ（zip の中を含む）を 0 バイトとして扱い、変更日を取得できない項目は昇順・降順のどちらでも末尾に置く。値が同じ項目は名前の自然順にする。並べ替えに使っている列を非表示にしたときは、ファイル名の並べ替えに切り替え、方向はファイル名で最後に使った方向（なければ昇順）とする。この方向は保存し、再起動後も復元する
- **FR-011（変更）**: リスト形式は「ファイル名」「作成日」「種類」「サイズ」「変更日」の列を持たなければならない。既定で表示するのは前の3つで、表示する列は FR-269〜FR-271 で選べる。作成日・変更日の書式は表示言語と地域設定に従う（FR-151）。取得できない場合は `--` を表示する（EC-116）

### Key Entities

- **列の表示状態**: ファイル名・作成日・種類・サイズ・変更日それぞれの表示・非表示。ファイル名は項目にはなく常に表示。保存対象
- **変更日**: 通常のファイルでは内容の最終更新日時、zip の中の項目では entry の更新日時。表示と並べ替えに使う

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-133**: 利用者は、列見出しを右クリックして1回選ぶだけで、サイズまたは変更日の列を表示・非表示にでき、変更は即座に（体感の遅れなく）一覧へ反映される
- **SC-134**: アプリを再起動しても、選んだ列の表示状態が 100% 復元される
- **SC-135**: サイズ・変更日の列見出しをクリックすると、全項目が指定の昇順・降順に並ぶ（フォルダは 0 バイト扱い、変更日のない項目は末尾）
- **SC-136**: 列の表示・非表示を切り替えても、行の選択、リネーム、Quick Look の表示位置が変わらない

## Assumptions

- **A-164**: Finder の「最後に開いた日」「追加日」などは対象外とし、今回の5つの列だけを扱う
- **A-165**: 列幅の変更・列の並べ替え・その保存は今回の範囲外。列の順序は固定（ファイル名・作成日・種類・サイズ・変更日）で、場所は検索結果の表示中だけ末尾に加わる
- **A-166**: サイズの単位表記は OS の自動単位に従い、桁区切りの細かい指定は設けない
- **A-167**: ポップアップは、ファイルリストのリスト形式の列見出しにだけ現れる
