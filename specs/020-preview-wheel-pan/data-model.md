# データモデル

- `PreviewInteractionMode`: `wheelZoomPan` または `scroll`。保存値が未設定・未知・型不正なら `wheelZoomPan`。
- 表示倍率: 25%〜800%の有限な連続値。ボタン操作は25ポイント加減、通常ホイールは1.1倍またはその逆数、ピンチは連続的に変化する。
- ジェスチャ: ピンチ開始時のカーソル座標を一時的に保持し、終了・中断・モード／画像変更時に破棄。倍率は各入力で更新し、上下限の超過分を蓄積しない。
- キーボードの押下状態: Option と矢印による移動の方向を一時的に保持し、キー・Option の解放やフォーカス喪失で更新または破棄。
- ドラッグ: 開始点、開始時の表示位置、閾値を越えたかを一時的に保持。mouseUp または表示／モード変更・非アクティブ化で破棄。
- 倍率と表示中心は既存の一時状態を利用し、保存・履歴に含めない。
