## Clarifications

### Session 2026-11-12

- Q: ホイールとピンチの倍率は？ → A: ホイールは1目盛りで1.1倍またはその逆数、ピンチは連続的に変える。上下限は25%〜800%を維持する。
- Q: トラックパッドの表示位置の移動は？ → A: 2本指スクロールで移動し、ピンチで倍率を変える。
- Q: 拡大中心と既存の操作は？ → A: ホイールとピンチはカーソル位置を中心とし、ボタン・メニュー・ショートカットはビューポート中心とする。修飾付き矢印キーも維持する。
- Q: 既存ユーザーへの初期設定は？ → A: 設定が未保存なら既存ユーザーも新モードにし、選択後は再起動をまたいで保持する。
- Q: ダブルクリックとドラッグの競合は？ → A: 移動を伴うドラッグだけをパンとし、通常のクリックとダブルクリックは既存動作を保つ。

## User Scenarios & Testing

### User Story 1 - 画像を直接操作する (Priority: P1)

画像を見ながらホイールで拡大し、ドラッグして見たい部分に移動する。

**Independent Test**: 新モードで画像を拡大して各方向にドラッグし、バーが出ず端まで移動できることを確認する。

1. **Given** 新モードで画像を表示中、**When** 縦方向にホイールを回す、**Then** 倍率が変わる。
2. **Given** 画像がはみ出している、**When** ドラッグする、**Then** 画像がドラッグ方向に動き、ドラッグ中は握った手のカーソルを表示する。
3. **Given** 画像または余白をダブルクリックする、**When** 全画面を切り替える、**Then** 倍率と位置をクリックで変えない。
4. **Given** 新モードで画像を表示中、**When** トラックパッドでピンチまたは2本指スクロールする、**Then** ピンチではカーソル位置を中心に連続的に倍率が変わり、スクロールでは表示位置が移動する。

### User Story 2 - 操作モードを選ぶ (Priority: P2)

従来のスクロール操作を好むユーザーは設定で従来モードに戻せる。

**Independent Test**: 設定を切り替えて再起動し、選択した操作が維持されることを確認する。

1. **Given** この設定が未保存、**When** 画像を表示する、**Then** 新モードで操作できる。
2. **Given** 従来モードを選択、**When** はみ出した画像を操作する、**Then** バーとホイール・トラックパッドで位置を移動できる。

### Edge Cases

- 画像が収まる方向は中央に保ち、パンできない。端を超えて背景を露出させない。
- 画像なし・読み込み中・表示不能・動画では画像の操作をしない。動画の既存操作を妨げない。
- モード切替、画像変更、操作の中断時には進行中のジェスチャとドラッグ状態を破棄する。
- カーソルの下が余白でも、その座標を基準に画像を拡大・縮小し、画像が収まる方向や端では中央配置と端の制約を優先する。
- 画面外へのドラッグ終了、ウインドウ非アクティブ化、表示対象の変更、モード切替時はカーソルを復元する。
- 全画面、スライドショー、アニメーション画像、zip 内の画像にも既存の表示・切替規則を保って適用する。

## Requirements

### Functional Requirements

- **FR-376**: 設定ウインドウの一般タブに画像の操作モードとして「ホイールズームとドラッグ」「スクロール」の2択を設けなければならない。
  - 未設定または不正値は前者とし、既存ユーザーを含め即時反映・保存・復元する。
  - モード切替自体では現在の倍率と位置を維持する。
- **FR-377**: 新モードでは画像上またはプレビューの余白へのマウスホイール操作とトラックパッドのピンチで倍率を変更できなければならない。
  - 通常のホイール1目盛りで、OS が渡す縦方向の正の量なら現在の倍率の1.1倍、負なら1.1で割った倍率とし、複数目盛りはその回数に応じる。
  - ピンチアウトで拡大、ピンチインで縮小し、操作量に応じて連続的に変える。
  - ピンチが上下限に達した後は超過分を蓄積せず、反転すると直ちに逆方向へ倍率を変える。
  - ホイール操作による表示の変化は約0.12秒で補間し、「動きを減らす」が有効なときは補間しない。
  - 25%〜800%に収め、カーソル位置を基準として FR-159 に従う。
- **FR-379**: 新モードではトラックパッドの2本指スクロールで表示位置を上下左右に移動できなければならない。
  - OS のスクロール方向と慣性に従い、FR-158 と同じ範囲で移動する。
  - OS のページ間スワイプの指の本数には連動せず、3本指ジェスチャを独自に取得しない。
  - 操作フェーズがあるスクロール入力は移動、フェーズのないホイール入力は倍率変更に使う。
  - 装置の種類そのものは判別しないため、フェーズ付きスクロールを出すマウスは移動になり得る。
- **FR-378**: 新モードでは画像または余白からの主ボタンドラッグで画像をポインタと同方向に移動できなければならない。
  - はみ出す各方向の両端に到達でき、収まる方向は中央とし、画像の端を超えない。
  - 移動を伴うドラッグ中は OS 標準の握った手のカーソルを表示し、終了・中断で元に戻す。
  - クリックとダブルクリックの既存動作（FR-220・221）を維持する。
- **FR-158（変更）**: 従来モードでは表示中の画像がビューポートを超える各方向に対応するスクロールバーを表示し、マウスのバー操作とマウスホイールまたはトラックパッドのスクロールでその方向の両端まで表示位置を移動できなければならない。
  - 新モードでは画像用スクロールバーを表示しない。
  - 収まる方向にはバーを表示せず、移動させない。
  - スクロールバーが描画領域の寸法やフィット倍率を変えない。
  - 両モードでプレビューにフォーカス中は ⌥↑・⌥↓・⌥←・⌥→ でも対応する方向へ移動できる。
  - Option と縦・横の矢印を同時に押したとき、両方向にはみ出し画像端に達していなければ45度に移動する。
  - 1回の移動距離は1方向の場合と同じ40ポイントとし、斜めでは各軸を 40 / √2 ポイント移動する。
  - 向かい合う方向はその軸で相殺し、画像の端と収まる方向は既存の位置制限に従う。
  - 押し続けた方向をシステムのキーリピート設定に従い繰り返し、キーまたは Option の解放とフォーカス喪失に追従する。
  - 従来モードのバーはアクセシビリティから識別・操作可能とする。
  - 動画・画像なし・読み込み中・表示不能時は画像用バーを表示せず、画像用操作は何もしない。
- **FR-133（変更）**: ユーザーは、プレビューに表示中の画像の表示倍率を、「拡大」「縮小」「表示領域に合わせる」の3操作で変えられなければならない。
  - 倍率は FR-028 のフィット表示を100%とし、拡大は現在の倍率に25ポイントを加え、縮小は25ポイントを引く。
  - 倍率は25%以上800%以下の連続値とし、上限・下限を超える変更は端に収める。
  - 「表示領域に合わせる」は、その時点のビューポートに対するフィット表示（100%）に戻す。
  - 画像は縦横比を保ち、収まる方向は中央に配置する。
  - はみ出す方向の位置は FR-158・FR-159 に従う。
  - 動画、表示する画像がない状態、表示できない画像（FR-038）には適用しない。
- **FR-159（変更）**: 表示位置は画像の中心から始める。
  - ホイールとピンチによる倍率変更では、変更前のカーソル位置にある画像上の位置を可能な限り同じ画面位置に保つ。
  - その他の倍率変更、ウィンドウ・ペインのサイズ変更、フルスクリーン切替、同じ画像を表示したままのペイン表示切替では、変更前のビューポート中心にある画像上の相対位置を可能な限り中心に保ち、画像端を超える場合は端に収める。
  - 収まる方向は中央とする。
  - 別画像への変更または履歴移動では FR-137 に従い倍率と位置をリセットし、フィット操作でも位置を中央に戻す。
  - 位置は保存せず履歴にも記録しない。
  - スクロール・倍率変更はアニメーション再生を再開しない。
- **A-62（変更）**: 100%は原寸ではなくフィット表示とする。
  - 小さい画像は原寸を超えて拡大されたフィットの状態が100%になる。
  - ボタン・メニュー・ショートカットの倍率変更は25ポイントの加算とし、範囲は25%以上800%以下とする。
  - 800%を上限とするのは、拡大の要求に実用的な上限を置き、表示と操作の破綻を避けるためである。
- **A-64（変更）**: 倍率の数値表示、倍率のスライダー、画像ごとの倍率や位置の記憶は範囲外とする。
  - スライドショーの切り替え効果「ズーム」（FR-130）は表示倍率とは別の機能であり、変更しない。
- **SC-070（変更）**: 従来モードで縦のみ、横のみ、両方向の3条件で各10回スクロールし、各対象方向の両端に到達できない回数、不要なバーが表示される回数は0回となる。

- **FR-127（変更）**: 設定ウインドウ（⌘,）に「スライドショー」の区分を追加し、次の3項目を置かなければならない。
  - （1）切り替え間隔のテキストフィールドと単位「秒」の表示、（2）「最後まで表示したら先頭から繰り返す」
    チェックボックス、（3）切り替え効果を「なし」「クロスフェード」「スライド」「ズーム」
    の4つから1つ選ぶポップアップメニュー。
  - 区分は既存の「動画」「ファイル操作」の下に置く。
  - 既定値はそれぞれ 3秒・オン・「なし」とする。
  - 設定ウインドウでは Tab／⇧Tab で、既存の項目を含むすべての項目に上から順に、
    システムのキーボードナビゲーションの設定に関わらずフォーカスを移せなければならない。
  - 一般タブの順序は contracts/settings.md に従う。
  - チェックボックスは Space で切り替え、ポップアップメニューは Space で開いて矢印キーと Return で選ぶ。
  - 各項目はアクセシビリティのラベル（「切り替え間隔（秒）」「最後まで表示したら先頭から繰り返す」「切り替え効果」）
    を持たなければならない
- **US21-AS1（変更）**: 従来モードでは、縦方向だけがはみ出す画像に縦スクロールバーだけを表示し、
  上端から下端までスクロールできる。
  - 横方向だけの場合は横について同様とする。
  - 新モードではバーを表示せず、ドラッグまたは2本指スクロールで両端に移動できる。
- **US21-AS2（変更）**: 両方向にはみ出す画像は四隅まで移動できる。
  - 従来モードでは両方のスクロールバーを表示する。
  - 新モードではバーを表示せず、ドラッグまたは2本指スクロールで移動する。
- **US21-AS4（変更）**: 表示位置の変更後に倍率やビューポートを変えても、FR-159 に従って画像上の位置を保つ。
  - 範囲外になる位置は端に収める。
  - 画像が収まる方向は中央に配置されバーが消える。
- **A-94（変更）**: 従来モードのスクロールバーは画像に重ねて表示し、OS の外観・操作を尊重する。
  - 表示位置の維持は FR-159 に従い、ホイール・ピンチではカーソル位置、その他はビューポート中心を基準とする。
  - ⌥方向キーはプレビューのフォーカス時に限るため、ツリー等の既存操作と衝突しない。

### Key Entities

- **画像操作モード**: 永続化する2択。倍率と位置は既存どおり一時的な状態。
- **表示倍率（変更）**: フィット表示を100%とし、25%以上800%以下の連続値を取る。
  - 画像ごとではなく表示中のプレビューに対する一時的な状態で、別の画像への切り替えと履歴の移動後は100%に戻る。
  - 保存せず、履歴の表示の状態にも含めず、倍率の変更は履歴の1件としても記録しない（FR-137）。

自動テストでモードの保存・不正値、スクロール量の境界と反転、位置制限、および既存操作との共存を検証する。

## Success Criteria

### Measurable Outcomes

- **SC-205**: 3ペイン・プレビューのみ・全画面の各表示で、縦のみ・横のみ・両方向にはみ出す画像を新モードで操作し、到達可能な各端にドラッグで到達できない場合とバーが表示される場合は0件。
- **SC-206**: 両モードの切替、再起動、未設定・不正値の各条件で、意図したモードと操作が一致しない場合は0件。
- **SC-207**: 新モードでホイールとピンチを各方向に操作し、指定と異なる方向または範囲外に倍率が変化した場合と、端の制限がない場合にカーソル下の画像位置が移動する場合は0件。

## Assumptions

- 既存のズーム操作と ⌥矢印は両モードで使える。倍率・位置の寿命とアニメーション継続は FR-137・159 に従う。
- 入力の精度だけではマウスとトラックパッドを区別できず、操作フェーズによって扱いが変わる。機器ごとの入力と操作感を手動で確認する。
