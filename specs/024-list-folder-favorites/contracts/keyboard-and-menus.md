# Keyboard and menus — フォルダ操作の変更案

実装・検証後に `specs/product/contracts/keyboard-and-menus.md` の該当箇所へ反映する。

## 通常フォルダの共通操作と順序

1. ここにペースト／ここに移動ペースト
2. 区切り
3. ゴミ箱に入れる
4. 区切り
5. 名前を変更
6. 複製
7. 区切り
8. コピー（単一は名前、複数は件数を示す）
9. パス名をコピー
10. 区切り
11. お気に入りに追加
12. 区切り
13. Finder に表示

ツリー・リスト形式・サムネイル形式で同じ順とする。
一覧の「中を表示」「上の階層へ」とその区切りは先頭に残し、従来の条件で表示する。
一覧で実フォルダを含む対象には「開く」「このアプリケーションで開く」を表示しない。
通常フォルダの項目メニューから「新規フォルダ」を外し、背景・メニューバー・⇧⌘N に残す。
お気に入りの仮想項目は既存の別メニューとする。

## 単一・複数対象

| 操作 | 実フォルダ1件 | 実フォルダ複数件 |
|---|---|---|
| ペースト群 | クリップボード条件に従い有効 | 無効 |
| ゴミ箱 | ルート以外で有効 | 全対象がルート以外なら有効 |
| 名前を変更 | ルート以外で有効 | 無効 |
| コピー・複製 | 有効 | 全対象に有効 |
| パス名をコピー | 有効 | 無効 |
| お気に入りに追加 | 未登録なら有効 | 無効 |
| Finder に表示 | 有効 | 全対象に有効 |

ツリーの見出し・お気に入り等が混ざる場合は通常フォルダの一部だけを操作しない。
一覧のフォルダとファイルが混ざる場合、コピー・複製等は対象全体、フォルダへのペーストは無効とする。
ゴミ箱・名前変更の既存ルート保護、名前編集中の無効条件と確認・失敗表示は維持する。

## 入力経路とペースト先

| 入力経路 | 一覧 | ツリー |
|---|---|---|
| 実フォルダ1件の項目メニュー | そのフォルダの中 | そのフォルダの中 |
| 複数／混在フォルダの項目メニュー | 無効 | 無効 |
| 背景メニュー | 表示中のフォルダ | 既存の扱い |
| メニューバー・⌘V・⌥⌘V | 表示中のフォルダ | 選択中の単一フォルダ |

検索結果でも単一実フォルダの項目メニューからは貼り付けられる。
検索結果の背景・メニューバー・キーからのペーストと、zip 内へのペーストは無効。
一覧で実フォルダを含まない項目メニューのペーストは従来どおり。
対象消失時に表示中のフォルダや別の選択へ先を変えない。
ここでキーの経路は項目メニューを閉じた状態を指し、開いているメニュー内のキー操作はそのメニューの対象に従う。

## キーと表示

- コピー ⌘C、複製 ⌘D を、ツリーの選択にも接続する。
- 登録は既存の addToFavorites と ⌃⌘T を共用する。
- 一覧のフォーカス時の登録は一覧、ツリー・プレビューのフォーカス時はツリーを対象にする。
- 登録は対象ペインが表示中で、文字入力中でない場合だけ使える。
- 一覧のみ表示でも登録できる。候補がなくてもツリーへ戻さない。
- 右クリック対象をキーやメニューバーへ流用しない。
- 既存の翻訳キー・MenuShortcutApplier・標準 NSMenuItem のアクセシビリティラベルを共用する。

## 製品契約の更新箇所

- コマンド一覧・メニューバー: ツリーのコピー・複製、登録のフォーカス条件。
- ペースト: 項目・背景・キーと検索結果の例外。
- ツリーと一覧の右クリック: 共通順序・新規フォルダの削除・複数条件・外部で開く項目の非表示。
- ペイン切り替え: ツリー非表示でも一覧対象の登録を許可する説明。
- 旧来の「ツリーは複数対象でゴミ箱だけ有効」「複製は一覧だけ」「一覧のペーストは常に表示中のフォルダ」
  「検索結果の右クリックはペーストが一律無効」という説明。
