## User Scenarios & Testing *(mandatory)*

### User Story 87 - 一覧で見つけたフォルダをその場で登録する (Priority: P1)

利用者は、一覧にあるフォルダを開いたりツリーで探し直したりせず、右クリックまたはキーボードで登録する。

**Why this priority**: Issue の目的そのものであり、フォルダを探し直す操作が不要になる。

**Independent Test**: リスト形式とサムネイル形式で、未登録のフォルダ1件を右クリック・⌃⌘T・
「ファイル > お気に入りに追加」で登録し、対象と保存結果を確認する。

**Acceptance Scenarios**:

- **US87-AS1**: **Given** リスト形式またはサムネイル形式で未登録の実フォルダを表示中,
  - **When** その項目の右クリックメニューの「お気に入りに追加」を選ぶ,
  - **Then** そのフォルダがお気に入りの末尾に1件追加される。
- **US87-AS2**: **Given** 一覧で別の項目を選択中でツリーにフォーカスがある,
  - **When** 選択外のフォルダを右クリックして登録する,
  - **Then** 右クリックしたフォルダだけが追加され、一覧の選択とキーボードフォーカスは変わらない。
- **US87-AS3**: **Given** ファイルリストにフォーカスがあり未登録の実フォルダだけを選択中,
  - **When** ⌃⌘T または「ファイル > お気に入りに追加」を実行する,
  - **Then** ツリーの選択とは独立して一覧で選択中のフォルダが追加される。
- **US87-AS4**: **Given** フォルダ2件、またはフォルダとファイルを複数選択中,
  - **When** 選択中の項目の右クリックメニューまたは一覧を対象とする登録コマンドを使う,
  - **Then** 登録項目は淡色で選べず、ショートカットを押しても1件も追加されない。
- **US87-AS5**: **Given** 検索結果または名前で絞り込んだ一覧に未登録の実フォルダがある,
  - **When** そのフォルダ1件を登録する,
  - **Then** その実フォルダが追加され、検索結果・絞り込み・表示位置は保たれる。
- **US87-AS6**: **Given** ファイルリストのみ表示で未登録の実フォルダ1件を選択中,
  - **When** 一覧を対象とする登録を実行してから3ペイン表示に戻す,
  - **Then** 追加したお気に入りがツリーに表示される。
- **US87-AS7**: **Given** すでに登録済みのフォルダに独自の表示名がある,
  - **When** 一覧から同じフォルダを再登録しようとし、続けてアプリを再起動する,
  - **Then** 登録は重複せず、既存の登録順と表示名が復元される。
- **US87-AS8**: **Given** 3ペイン表示でツリーまたはプレビューにフォーカスがある,
  - **When** ⌃⌘T を実行する,
  - **Then** 従来どおりツリーの選択を対象にし、お気に入りの登録では見出し・お気に入りの項目・複数選択を無効にする。

### User Story 88 - どちらのビューでも同じフォルダ操作を使う (Priority: P1)

利用者は同じ実フォルダに対して、ツリーでも一覧でも同じファイル操作を同じ順のメニューから使う。

**Why this priority**: 目的変更の中心であり、表示場所による操作の違いをなくす。
**Independent Test**: 同じフォルダについてツリー・リスト形式・サムネイル形式の項目と有効条件を比べる。

**Acceptance Scenarios**:

- **US88-AS1**: **Given** 同じ通常フォルダ1件をツリーと一覧で表示中,
  - **When** それぞれの項目メニューを開く,
  - **Then** ファイル操作が同じ順で並び、一覧の「開く」「このアプリケーションで開く」は表示されない。
- **US88-AS2**: **Given** ツリーで通常フォルダ1件または複数件を対象にしている,
  - **When** コピーを実行する,
  - **Then** 対象すべての実フォルダがコピー元となり、別のフォルダへペーストできる。
- **US88-AS3**: **Given** ツリーで通常フォルダ1件または複数件を対象にしている,
  - **When** 複製を実行する,
  - **Then** 元の内容を変えず、それぞれの親フォルダ内に既存の採番規則による複製が作られる。
- **US88-AS4**: **Given** 複数フォルダを対象にしている,
  - **When** 共通メニューを開く,
  - **Then** コピー・複製・Finder に表示は全対象に使え、単一対象の操作は無効になる。

### User Story 89 - 右クリックしたフォルダを貼り付け先にする (Priority: P1)

利用者は一覧でも対象フォルダの中へ直接ペーストでき、背景やキーからのペーストと区別できる。

**Why this priority**: 同じ「ペースト」が別のフォルダへ書き込む差を解消する。
**Independent Test**: 親 P とその子 A・B、別のコピー元 S を用意し、作成先・移動先を比較する。

**Acceptance Scenarios**:

- **US89-AS1**: **Given** 一覧に P の内容を表示し、B を選択中,
  - **When** 選択外の A の項目メニューからペーストまたは移動ペーストする,
  - **Then** 書き込み先は A の中となり、P や B の中には書き込まない。
- **US89-AS2**: **Given** 一覧で A を選択中,
  - **When** 背景メニュー・メニューバー・⌘V または ⌥⌘V でペーストする,
  - **Then** 従来どおり現在表示中の P の中に書き込む。
- **US89-AS3**: **Given** 検索結果に実フォルダ A がある,
  - **When** A の項目メニューからペーストする,
  - **Then** A の中に書き込み、検索結果を解除しない。
- **US89-AS4**: **Given** フォルダ2件またはフォルダとファイルを対象にしている,
  - **When** 項目メニューを開く,
  - **Then** ペーストと移動ペーストは無効で、表示中のフォルダへ代わりに書き込まない。

### Edge Cases

- **EC-268**: 一覧の対象がメディアファイル・zip ファイル・zip 内の項目・`..`・選択なしの場合、登録は実行できない。
  - メニュー項目は淡色にし、キーボードから実行してもツリーの選択へ対象を切り替えない。
- **EC-269**: 複数選択に `..` と実フォルダ1件が含まれる場合も、お気に入りへの登録は複数選択として無効にする。
  - 一部を除外してから単一選択として扱ってはならない。
- **EC-270**: 右クリック後に対象が一覧からなくなった場合、別の項目へ対象を切り替えず何もしない。
  - 一覧に残っているフォルダの実体だけが消えた場合は、登録後の所在確認に FR-067（directory-tree.md）を適用する。
- **EC-271**: 名前の編集中とツールバーの名前の絞り込み欄への文字入力中は、メニューバーとショートカットによる登録を無効にする。
  - 一覧の名前の編集中に右クリックメニューを開く場合は、先に編集を確定する既存の扱いに従う（EC-265（file-list.md））。
- **EC-272**: フォルダを含む混在選択の項目メニューでは、「開く」「このアプリケーションで開く」を出さず、対象フォルダへのペーストも無効にする。
  - コピー・複製・ゴミ箱などの複数操作は、各ビューの対象全体に対する既存の条件に従う。
- **EC-273**: ペースト先が操作前に消失・移動した場合、別のフォルダへ切り替えず既存の失敗表示を行う。
  - 書き込み権限不足・同名衝突・自己の中へのコピーや移動は既存の確認・検証規則に従う。
- **EC-274**: zip 内の仮想ディレクトリと `..` は、共通メニューの実フォルダ操作の対象にしない。
  - メディア・zip ファイルだけのメニューと、背景・キーのペーストの既存動作は維持する。

## Requirements *(mandatory)*

### Functional Requirements

#### FR-062（変更、directory-tree.md）

- **FR-062**: ユーザーは、任意のフォルダ（ホーム・ボリュームのルートを含む）をお気に入りに登録できなければならない。
  - 登録は、ツリーのフォルダとファイルリストの項目の右クリックメニューの「お気に入りに追加」、
    「ファイル > お気に入りに追加」、キーボードショートカット ⌃⌘T で行う。
  - メニューバーとショートカットは、ファイルリストにフォーカスがあるときは一覧の選択を対象にし、
    ツリーまたはプレビューにフォーカスがあるときはツリーの選択を対象にする。
  - 一覧の対象と有効条件は FR-399（file-list.md）に従う。
  - ツリーの複数選択時は FR-218（directory-tree.md）に従う。
  - 名前の編集中と名前の絞り込み欄への文字入力中は、メニューバーとショートカットを無効にする。
  - ツリーを対象とする登録は、ツリーを隠している間（FR-092（window-layout.md））は無効にする。
  - 登録済みのフォルダを再び登録しても重複させず、メニュー項目は淡色にする。
  - ツリーの「お気に入り」の見出しやお気に入りの項目を対象とする登録は無効にする。

#### FR-092（変更、window-layout.md）

- **FR-092**: ペインを隠している間、システムは隠しているペインへキーボードフォーカスを移す手段を無効にしなければならない。
  - 「表示」メニューの各ペインへのフォーカスの項目（⌥⌘1・⌥⌘2・⌥⌘3）のうち隠しているペインの項目は淡色にし、
    そのショートカットは何もしない。
  - Tab キーによるフォーカスの巡回は表示中のペインの間だけで行う。
  - ツリーを隠している間は、「お気に入りへ移動」（⇧⌘F、FR-065（directory-tree.md））と
    ツリーを対象にする「お気に入りに追加」（FR-062（directory-tree.md））を無効にする。
  - ファイルリストのみ表示での一覧を対象とする「お気に入りに追加」は FR-399（file-list.md）に従って使える。
  - 検索（⌥⌘F、FR-080（search.md））と名前で絞り込む（⌘F、FR-391（file-list.md））はファイルリストのみ表示では使え、
    プレビューのみ表示では淡色にしてショートカットも何もしない。

#### FR-217（変更、directory-tree.md）

- **FR-217**: ツリーの操作の対象は次のとおりとしなければならない。
  - （1）⌘⌫ と、ツリーを対象にする「ファイル」「編集」メニューの項目は、ツリーで選択中の行全体を対象にする。
    - メニューはツリーにフォーカスがあるときにツリーを対象にする。
    - ⌃⌘T は FR-062（directory-tree.md）に従い、ツリーまたはプレビューにフォーカスがあるときにツリーを対象にする。
  - （2）右クリックメニューは、選択中の行を右クリックしたときは選択中の行全体を、
    選択外の行を右クリックしたときはその行だけを対象にし、ツリーの選択を変えない（A-21（directory-tree.md））。
  - （3）ドラッグは、選択中の行から始めたときは選択中の行全体を、
    選択外の行から始めたときはその行だけを対象にする（US23-AS2（directory-tree.md）と同じ）。
  - ドラッグを終えた時点（ドロップ・中止）では、ツリーの選択と主の行をドラッグ前に戻す。
    - 操作の結果による選択の更新は FR-219（directory-tree.md）に従う。

#### FR-018（変更、file-operations.md）

- **FR-018**: ユーザーは、選択したファイルとフォルダ（FR-076）に対して「コピー」「名前の変更」「削除」「移動」「複製」
  を実行できなければならない。
  - フォルダの操作はその中身を含めて行い、FR-019〜FR-027
    をファイルと同じく適用する（削除はフォルダごとゴミ箱へ入れる）。
  - 「複製」は対象と同じフォルダに「名前 2」という名前で作成し（既にその名前がある場合は空いている連番まで進める）、
    既存のファイルを変更しないため確認モーダル（FR-022）の対象外とする
  - 拡張子を除いた名前の末尾にスペースと半角十進数字の連番がある場合は、その数の次から採番する。
  - 連番の桁数による整数上限を設けない。
  - 生成する連番の先頭ゼロは除く。
  - ゼロだけの連番は 0 として扱う。
  - 空き名の判定では大文字小文字を区別しない。
  - ツリーの通常フォルダもコピーと複製の対象にし、単一・複数対象の条件は FR-402 に従う。

#### FR-019（変更、file-operations.md）

- **FR-019**: システムは、各操作を右クリックメニューとキーボードショートカットの両方から実行できるようにし、
  その割り当ては Finder に準じなければならない（コピー ⌘C、ペースト ⌘V、移動ペースト ⌥⌘V、名前の変更 Return、ゴミ箱へ
  ⌘Delete、複製 ⌘D）
  - ツリーにフォーカスがあるときの ⌘C・⌘D と「編集」メニューは、ツリーの選択を対象にする。
  - 項目メニューのペースト先と、背景・メニューバー・キーのペースト先の区別は FR-403 に従う。

#### FR-076（変更、file-list.md）

- **FR-076**: システムは、ファイルリストに選択フォルダ直下のサブフォルダ（隠しフォルダとパッケージを除く）
  を表示しなければならない。
  - ユーザーは、フォルダの行をダブルクリックするか、選択して ⌘↓ を押すことで、
    ファイルリストをそのフォルダの一覧に切り替えられなければならない。
  - フォルダの行は、プレビュー（FR-075 と同じく空にし、再生中の動画は停止する）・
    縮小画像と行頭アイコン（フォルダを示す汎用アイコン）・種類フィルタ（FR-056・FR-060。常に表示し、
    ファイルとして数えない）・フルスクリーン中の矢印キー移動（FR-046。止まらずに飛ばす）について、zip
    の中のディレクトリと同じく扱う。
  - フォルダの行は FR-018〜FR-027 のファイル操作の対象とする。
  - ツリーの通常フォルダに対しては、ゴミ箱に入れる操作を FR-079、名前の変更を FR-103、ドラッグによる移動・コピーを
    FR-020 に従って行え、コピーと複製は FR-402（file-operations.md）に従って行える。

#### FR-208（変更、file-operations.md）

- **FR-208**: ユーザーは、次のどの手段でも新しいフォルダを作成できなければならない。
  - （1）ツリーの利用可能なお気に入りの項目の右クリックメニューの「新規フォルダ」。
  - 登録したフォルダの中に作り、ツリーの選択は変えない（A-21（directory-tree.md））。
  - （2）ファイルリストの背景（リスト形式・サムネイル形式で、どの項目にも当たらない位置）
    の右クリックメニューの「新規フォルダ」。
  - 表示中のフォルダの中に作る。
  - （3）「ファイル > 新規フォルダ」と ⇧⌘N（Finder と同じ割り当て。FR-019）。
  - ファイルリストにフォーカスがあるときは表示中のフォルダの中に、
    ツリーにフォーカスがあるときは選択中のフォルダ（お気に入りの項目では登録したフォルダ）の中に作る
  - 通常の実フォルダの項目メニューには、ツリー・ファイルリストとも「新規フォルダ」を出さない。

#### FR-213（変更、file-list.md）

- **FR-213**: ファイルリストの背景を右クリックしたとき、システムは選択中の項目向けのメニューの代わりに、
  表示中のフォルダ向けのメニューを次の順で表示しなければならない。
  - 1. 新規フォルダ（⇧⌘N）、2. ─、3. ペースト（⌘V）／ 移動ペースト（⌥⌘V）、4. ─、5. Finder に表示。
