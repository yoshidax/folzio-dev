# Feature Specification: 操作ごとの実行前の確認の設定

**Feature Branch**: `feature/tak-105-confirm-move-rename`

**Created**: 2026-11-16

**Status**: Draft

**Input**: [TAK-105](https://linear.app/takyoshida/issue/TAK-105/)「ファイル・フォルダの移動と名前変更の確認を設定可能にする」。

## Clarifications

### Session 2026-11-16

- Q: 設定の粒度は、1つの設定に移動・名前の変更を加えるか、操作ごとに分けるか → A: 操作ごとに分ける（FR-023）
- Q: ツリーのフォルダをゴミ箱に入れる操作の常時確認は残すか → A: 常に確認のまま残す（FR-024・A-233）
- Q: 以前の版で確認をオフにしていた利用者の、移動・名前の変更の確認の初期状態は → A: オン（確認する）で始める（FR-396）
- Q: 「今後この確認を表示しない」を移動・名前の変更のモーダルにも出すか → A: 出し、その操作の確認だけを止める（FR-395）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。確認モーダルの内容（FR-022（file-operations.md））、同名の衝突（FR-025（file-operations.md））、
失敗の表示（FR-026（file-operations.md））は変えない。

### User Story 1 - 操作ごとに確認の要否を選ぶ (Priority: P1)

利用者は設定ウインドウで、コピー・移動・名前の変更・お気に入りから削除・ゴミ箱に入れるの5つの操作について、
実行前に確認するかを別々に選ぶ。

**Why this priority**: TAK-105 の中心の要件である。移動や名前の変更を確認なしで実行したい利用者が、
削除の確認まで外さずに済む。

**Independent Test**: 設定ウインドウで「移動する前に確認する」だけをオフにし、移動が確認なしで実行され、
コピー・名前の変更・ゴミ箱に入れる操作では従来どおり確認モーダルが出ることを確かめる。

**Acceptance Scenarios**:

- **US85-AS1**: **Given** 日本語表示,
  - **When** 設定ウインドウの「ファイル操作」を見る,
  - **Then** 「コピーする前に確認する」「移動する前に確認する」「名前を変更する前に確認する」
    「お気に入りから削除する前に確認する」「ゴミ箱に入れる前に確認する」の5つのチェックボックスがこの順に並び、
    最後のチェックボックスの下に補足説明がある
- **US85-AS2**: **Given** 「移動する前に確認する」だけがオフ,
  - **When** ファイルリストの項目をツリーの別のフォルダへドラッグ&ドロップする（またはペーストで移動する）,
  - **Then** 確認モーダルなしで移動し、同名の項目があれば衝突のダイアログ（FR-025（file-operations.md））は従来どおり出る
- **US85-AS3**: **Given** 「移動する前に確認する」だけがオフ,
  - **When** コピー・名前の変更・ファイルリストからのゴミ箱に入れる操作をそれぞれ実行する,
  - **Then** どの操作でも従来どおり確認モーダルが出る
- **US85-AS4**: **Given** 「名前を変更する前に確認する」がオフ,
  - **When** ファイルリストのファイルまたはツリーの通常のフォルダの名前を変更して確定する,
  - **Then** 確認モーダルなしで名前が変わる。拡張子を変える場合の確認（EC-15（file-operations.md））は従来どおり出る
- **US85-AS5**: **Given** 「ゴミ箱に入れる前に確認する」がオフ,
  - **When** ツリーで通常のフォルダをゴミ箱に入れる,
  - **Then** 確認モーダルが必ず出て、「今後この確認を表示しない」は出ない（FR-079（file-operations.md））

---

### User Story 2 - 確認モーダルから、その操作の確認だけを止める (Priority: P2)

利用者は確認モーダルの「今後この確認を表示しない」で、その種類の操作の確認だけを止める。

**Why this priority**: 設定ウインドウを開かずに確認を外せる、現行の手段を移動と名前の変更にも広げる。

**Independent Test**: 移動の確認モーダルで「今後この確認を表示しない」をオンにして確定し、次の移動は確認なしになり、
コピーの確認は残ることを確かめる。

**Acceptance Scenarios**:

- **US85-AS6**: **Given** すべての確認がオン,
  - **When** 移動の確認モーダルで「今後この確認を表示しない」をオンにして「実行」を選ぶ,
  - **Then** 移動が実行され、設定の「移動する前に確認する」だけがオフになり、ほかの4つはオンのまま残る
- **US85-AS7**: **Given** 設定ウインドウを開いたまま、名前の変更の確認モーダルを表示している,
  - **When** 「今後この確認を表示しない」をオンにして確定する,
  - **Then** 設定ウインドウの「名前を変更する前に確認する」がその場でオフの表示に変わる

---

### User Story 3 - 更新しても確認が黙って消えない (Priority: P2)

以前の版で確認の設定をオフにしていた利用者が更新しても、移動と名前の変更の確認は消えない。

**Why this priority**: 以前の版では移動と名前の変更は常に確認していた。更新だけで確認が消えると、
利用者が気付かないまま確認なしで実行されてしまう。

**Independent Test**: 以前の版の確認の設定をオフにした状態で更新後の版を起動し、設定ウインドウの表示と、
移動・名前の変更・コピーの確認の有無を確かめる。

**Acceptance Scenarios**:

- **US85-AS8**: **Given** 以前の版で「コピー・ゴミ箱に入れる・お気に入りから削除する前に確認する」をオフにしていた,
  - **When** 更新後に初めて設定ウインドウを開く,
  - **Then** 「コピーする前に確認する」「お気に入りから削除する前に確認する」「ゴミ箱に入れる前に確認する」はオフ、
    「移動する前に確認する」「名前を変更する前に確認する」はオンで表示される
- **US85-AS9**: **Given** 以前の版で確認の設定をオンのまま使っていた（または一度も変えていない）,
  - **When** 更新後に設定ウインドウを開く,
  - **Then** 5つのチェックボックスはすべてオンで表示される

### 変更する既存のシナリオ

- **US4-AS7**（変更）: **Given** 「コピーする前に確認する」と「ゴミ箱に入れる前に確認する」がオフ,
  - **When** コピーまたはファイルリストからの削除を実行する,
  - **Then** モーダルなしで即座に実行される（削除はゴミ箱へ移動するため元に戻せる）。
    ツリーのフォルダをゴミ箱に入れる操作（FR-079）では、設定に関わらず確認モーダルが表示される
- **US40-AS1**（変更）: **Given** 日本語表示,
  - **When** 設定ウインドウの「ファイル操作」を見る,
  - **Then** 5つの確認のチェックボックス（FR-223）の最後の「ゴミ箱に入れる前に確認する」の下に、
    「ツリーのフォルダをゴミ箱に入れる操作は、この設定に関わらず常に確認します」がチェックボックスの文言より
    小さく淡い文字で、チェックボックスの文言の先頭に揃えて表示される
- **US40-AS2**（変更）: **Given** 英語表示,
  - **When** 同じ箇所を見る,
  - **Then** US40-AS1 と同じ構造で、5つのチェックボックスの文言が「Confirm before copying」「Confirm before moving」
    「Confirm before renaming」「Confirm before removing from Favorites」「Confirm before moving to the Trash」、
    その下の補足説明が
    「Moving folders in the directory tree to the Trash is always confirmed, regardless of this setting」
    と表示される
- **US40-AS3**（変更）: **Given** 「ゴミ箱に入れる前に確認する」がオン,
  - **When** 補足説明の文字をクリックする,
  - **Then** どのチェックボックスの状態も保存値も変わらず、補足説明は選択・編集・
    キーボードフォーカスの対象にならない。チェックボックスの文言をクリックしたときは従来どおり切り替わる
- **US40-AS4**（変更）: **Given** VoiceOver を使用中,
  - **When** Tab で「ゴミ箱に入れる前に確認する」へ移る,
  - **Then** チェックボックスの名前と状態に加えて、補足説明の文が読み上げられる。
    Tab の移動順は、言語 → 画像の操作 → 自動再生 → ループ → コピー → 移動 → 名前の変更 → お気に入りから削除 →
    ゴミ箱に入れる → 切り替え間隔 → 繰り返し → 切り替え効果とする
- **US1-AS13**（変更）: **Given** 「お気に入り」の下の項目を右クリックした（またはツリーでその項目を選択した）,
  - **When** 「お気に入りから削除」を選ぶ（または ⌘⌫ を押す）,
  - **Then** 確認モーダルが表示され、確定するとその項目が「お気に入り」から消え、
    実際のフォルダには何も変更が加わらない（ゴミ箱にも入らない）。
    キャンセルすると登録はそのまま残る。「お気に入りから削除する前に確認する」がオフなら、確認なしで即座に消える

### Edge Cases

- **EC-261**: 設定ウインドウを表示中に、確認モーダルの「今後この確認を表示しない」で確認の設定が変わった場合は、
  表示中のチェックボックスにもその場で反映する。
- **EC-262**: 確認モーダルで「今後この確認を表示しない」をオンにしてキャンセルした場合も、その操作の確認はオフになり、
  操作は実行しない（現行の動作を保つ）。
- **EC-263**: 確認モーダルを出す親のウインドウがない場合も、確認がオンの移動・名前の変更と、
  ツリーのフォルダをゴミ箱に入れる操作は、確認を経ずに実行しない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-023**（変更）: ユーザーは、設定で、コピー・移動・名前の変更・お気に入りから削除・ゴミ箱に入れるの
  5つの操作のそれぞれについて、実行前に確認モーダルを表示するかを選べなければならない。
  - 既定はどれも「表示する」とする。
  - 各操作の設定は、ほかの操作の設定に影響しない。
- **FR-024**（変更）: 確認モーダルの省略は、操作ごとに次の設定に従わなければならない。
  - コピー（ツリーのフォルダへのペースト・ドロップによるコピー、アプリ外から受け取るコピーと画像・動画の保存を含む）
    は「コピーする前に確認する」に従う。
  - 移動（移動ペースト、ドラッグ&ドロップによる移動、アプリ外から受け取る移動を含む）は「移動する前に確認する」に従う。
  - 名前の変更（ツリーのフォルダの名前の変更（FR-103）を含む）は「名前を変更する前に確認する」に従う。
  - お気に入りの削除（FR-064）は「お気に入りから削除する前に確認する」に従う。
  - ファイルリストからの削除（ゴミ箱へ入れる）は「ゴミ箱に入れる前に確認する」に従う。
  - ツリーのフォルダをゴミ箱に入れる操作（FR-079）は、設定に関わらず常に確認モーダルを表示しなければならない。
  - 設定ウインドウの確認の項目には、ツリーのフォルダをゴミ箱に入れる操作を、設定に関わらず常に確認する操作として示す
    （FR-223（window-layout.md））。
  - 複製（FR-018）とフォルダの新規作成（FR-209）、および作成直後のフォルダの名前の編集（FR-211）
    は確認モーダルの対象外とし、設定にも影響されない。
  - 名前の変更で拡張子を変える場合の確認（EC-15）は、名前の変更の確認の設定に関わらず表示する。
  - Folzio からアプリ外へドラッグし、ドロップ先のアプリが実行する移動（FR-344）は、確認モーダルの対象外とする。
  - 省略時の安全性は、削除が必ずゴミ箱経由で元に戻せること（FR-021）、コピーが元のファイルを変更しないこと、
    同名ファイルの上書きが常に確認されること（FR-025）、移動と名前の変更が元の項目を失わないことで担保する。
  - この方針は憲章 v1.1.0 原則 I の「確認または取り消し可能性」に従う
- **FR-064**（変更）: ユーザーは、「お気に入り」の下の項目を、その項目の右クリックメニューの「お気に入りから削除」と、
  その項目をツリーで選択中の ⌘⌫（ファイルリストの「ゴミ箱に入れる」と同じキー）で、
  お気に入りから削除できなければならない。
  - どちらの手段でも、実行前に対象のお気に入りの表示名（FR-101）と登録したフォルダの絶対パス、
    「お気に入りから削除する」
    旨を示す確認モーダルを表示し（同じ表示名の項目が複数あっても対象を見分けられるようにする）、
    キャンセルした場合は登録を変えてはならない。
  - 「お気に入りから削除する前に確認する」（FR-023）がオフのときは、確認を省略して即座に削除する。
  - 削除はお気に入りの登録だけを取り除き、実際のフォルダとその中身を変更してはならない（ゴミ箱にも入れない）。
  - お気に入りの項目の右クリックメニューには「ゴミ箱に入れる」を出さない。
  - ホーム・ボリュームの最上位・「お気に入り」の見出しの右クリックメニューには削除の項目を出さず、それらを選択中に ⌘⌫
    を押しても何もしない。
  - ツリーの通常のフォルダは FR-079 に従ってゴミ箱に入れられる。
  - ファイルリストにフォーカスがあるときの ⌘⌫ は、従来どおり選択中のファイルをゴミ箱に入れる（FR-019）
- **FR-103**（変更）: ユーザーは、ツリーの通常のフォルダ（ホーム・
  マウント中のボリュームの最上位の下にある実際のフォルダ。FR-079 と同じ範囲）の名前を、
  次のどの手段でも変更できなければならない。
  - （1）そのフォルダをツリーで選択し、ツリーにキーボードフォーカスがあるときに Return を押す。
  - （2）そのフォルダの行の右クリックメニューの「名前を変更」を選ぶ（右クリックした行を対象にし、
    選択中の行でなくてもよい。A-21）。
  - （3）ツリーにキーボードフォーカスがあり、そのフォルダを選択しているときに「編集」メニューの「名前を変更」を選ぶ。
  - 名前の編集はその行の中で行い、編集の始め方と終え方、名前の検証、
    確認はファイルリストのフォルダの名前の変更と同じとする。
  - すなわち、編集を始めたときは現在の名前を入れ、ファイルリストと同じ範囲（最後の「.」より前。「.」がなければ全体）
    を選択した状態にする。
  - Return またはほかの場所のクリックなどで確定し、Esc で取り消す（名前を変えず、確認モーダルも出さない）。
  - 確定した名前は前後の空白（改行を含む）を取り除き、空、または編集前と同じ名前なら何もしない。
  - 「/」または「:」を含む名前、先頭が「.」の名前、
    同じ場所にある別の項目（ツリーやファイルリストに表示していない隠し項目やファイルを含む）
    と大文字小文字の違いだけを含めて同じ名前、システムがパッケージとして扱う名前（EC-53）は、
    検証エラーを表示して拒否する（EC-14・FR-025）。
  - 元フォルダ自身の大文字小文字だけの変更は FR-025 に従い許可する。
  - 検証を通った名前は、「名前を変更する前に確認する」（FR-023・FR-024）がオンなら確認モーダル（FR-022）を表示してから
    変更し、キャンセルした場合は変更しない。
    - オフなら確認モーダルを出さずに変更する。
  - この確認モーダルには、ファイルリストの名前の変更の確認モーダルの内容に加えて、
    対象のフォルダの絶対パスを示す（同じ名前の別のフォルダと見分けられるようにする）。
  - 名前の編集欄には「フォルダの名前」
    というアクセシビリティラベルを付ける（お気に入りの表示名の編集欄の「お気に入りの名前」（FR-101）と区別する）。
  - 失敗した場合は FR-026 に従って表示する。
  - 編集を始めても、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003）は変えない。
  - ホーム・ボリュームの最上位・「お気に入り」の見出しを選択中の Return は何もせず、
    それらの右クリックメニューに「名前を変更」は出さず、それらを選択中は「編集」メニューの「名前を変更」を無効にする。
  - お気に入りの項目の Return・「名前を変更」は、従来どおり表示名の変更（FR-099）とする。
  - ファイルリストに zip の中または検索結果を表示中でも、ツリーにフォーカスがあれば（1）〜（3）は使える（zip
    の中の読み取り専用と検索結果の制限はファイルリストの操作にだけ適用する）。
  - ファイルリストにフォーカスがあるときの Return と「名前を変更」は、従来どおりファイル名の変更（FR-019）とする
- **FR-223**（変更）: 「ファイル操作」の確認の項目は、5つのチェックボックスの行と、補足説明の行で表示しなければならない。
  - （1）チェックボックスの文言と並びは、「コピーする前に確認する」（英語: Confirm before copying）、
    「移動する前に確認する」（英語: Confirm before moving）、「名前を変更する前に確認する」（英語: Confirm before renaming）、
    「お気に入りから削除する前に確認する」（英語: Confirm before removing from Favorites）、
    「ゴミ箱に入れる前に確認する」（英語: Confirm before moving to the Trash）の順とする。
  - （2）補足説明は「ツリーのフォルダをゴミ箱に入れる操作は、この設定に関わらず常に確認します」
    （英語: Moving folders in the directory tree to the Trash is always confirmed, regardless of this setting）
    とし、「ゴミ箱に入れる前に確認する」の直下に、そのチェックボックスの文言の先頭に揃えて置く。
  - チェックボックスとの間隔は、同じ区分の中の項目どうしの間隔より狭くし、主文に従属する説明として見せる。
  - 5つのチェックボックスどうしの間隔は、同じ区分の中の項目どうしの間隔（FR-222）とする。
  - （3）補足説明は、チェックボックスの文言より小さい文字と、OS の標準の淡い（二次的な）文字色で表示する。
  - クリック・選択・編集・キーボードフォーカスの対象にしない。
  - （4）補足説明の文は、「ゴミ箱に入れる前に確認する」のアクセシビリティの説明（ヘルプ）としても提供し、
    読み上げでそのチェックボックスと結び付ける。
  - 補足説明の行を、読み上げで独立した項目として二重に読ませない。
  - （5）各チェックボックスの意味・既定値と、常に確認する操作の範囲は FR-022〜024（file-operations.md）に従う。
  - FR-024（file-operations.md）の
    「設定ウインドウの確認の項目には、ツリーのフォルダをゴミ箱に入れる操作を、設定に関わらず常に確認する操作として示す」
    は、この補足説明で満たす
- **FR-347**（変更）: アプリ外から受け取る移動・コピー・画像・動画の保存（ドラッグとペースト）は、
  既存のファイル操作の確認（FR-022〜FR-024）、衝突（FR-025）、 失敗の表示（FR-026）、結果の反映（FR-027・FR-165）
  に従わなければならない。
  - 移動は「移動する前に確認する」に従い、コピーと画像・動画の保存は「コピーする前に確認する」に従う（FR-024）
  - 受け取った項目の元の場所が Folzio に表示中のフォルダにある場合、移動の結果は EC-13（overview.md）
    と同じく反映する
  - 画像・動画の保存の確認モーダルと衝突のダイアログには、宛先に作るファイルの名前を示す（一時的なフォルダの場所は示
    さない）
- **FR-395**: 省略できる確認モーダル（FR-024 でツリーのフォルダをゴミ箱に入れる操作を除くもの）には、
  「今後この確認を表示しない」を表示しなければならない。
  - オンにして閉じると、そのモーダルの操作の確認の設定だけをオフにし、ほかの操作の確認の設定は変えない。
  - 移動と名前の変更の確認モーダルにも表示する（以前の版では表示しなかった）。
  - ツリーのフォルダをゴミ箱に入れる操作の確認モーダルには表示しない（FR-079）。
- **FR-396**: 以前の版の確認の設定（コピー・ゴミ箱に入れる・お気に入りから削除をまとめた1つの設定）を保存している場合、
  システムは更新後の最初の読み込みで、その値を操作ごとの設定へ引き継がなければならない。
  - コピー・お気に入りから削除・ゴミ箱に入れるの3つの確認は、以前の設定の値を引き継ぐ。
  - 移動と名前の変更の確認は、以前の設定の値に関わらずオン（確認する）で始める。
  - 操作ごとの設定が保存済みの操作は、以前の設定を読まずにその値を使う。
  - 以前の設定がない、または値が不正な場合は、5つすべてをオンとする。

### Key Entities

- **操作ごとの確認の設定**: コピー・移動・名前の変更・お気に入りから削除・ゴミ箱に入れるの5つの操作それぞれの、
  実行前に確認するかの真偽値。既定はすべて真。
- **以前の版の確認の設定**: コピー・ゴミ箱に入れる・お気に入りから削除をまとめた1つの真偽値。移行の読み込み元としてだけ使う。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-216**: 5つの操作の確認の設定のうち1つだけをオフにした5通りのそれぞれで、
  オフにした操作は確認モーダルなしで実行され、ほかの4つの操作は確認モーダルを経て実行される
  （25 の組み合わせで期待と異なるものが 0 件）。
- **SC-217**: 以前の版の確認の設定をオフにしていた利用者が更新した後、移動・名前の変更の確認を自分でオフにするまでに、
  確認モーダルを経ずに実行された移動・名前の変更が 0 件。
- **SC-218**: 確認モーダルの「今後この確認を表示しない」で確認を止めたとき、止めた操作以外の確認の設定が変わる件数が 0 件。

## Assumptions

- **A-232**: 確認の要否は操作の種類ごとに決め、操作を始めたペイン（ファイルリスト・ツリー）やドラッグとペーストの
  違いでは分けない（ツリーのフォルダをゴミ箱に入れる操作の例外だけを残す）。
- **A-233**: ツリーのフォルダをゴミ箱に入れる操作は、選択していない行を右クリックして実行でき、
  フォルダを中身ごと失うおそれがあるため、引き続き常に確認する（A-33（directory-tree.md））。
- **A-234**: 以前の版の確認の設定は、移行の読み込み元として残し、削除も上書きもしない（以前の版へ戻したときに、
  その版の挙動を保つ）。
- **A-235**: 移動と名前の変更の確認を省略しても、元の項目は残る（移動先または新しい名前で存在する）ため、
  憲章 v1.1.0 原則 I の「確認または取り消し可能性」は、利用者が明示的に確認を外す選択として満たす。
- **A-236**: 既存の項目の「確認モーダルの省略設定（FR-023）」は、その操作の確認の設定（FR-023）を指し、
  「省略設定がオン」はその操作の確認がオフの状態を指すと読む（既存の項目の文言は、この feature では書き換えない）。
