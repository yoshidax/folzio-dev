## Clarifications

### Session 2026-10-31

- Q: 動画の再生コントロールの上のダブルクリックも全画面の切り替えに含めるか → A: 含めない。映像と余白だけで切り替え、コントロールとスクロールバーは従来の操作だけを行う（保守者が選択。FR-220・EC-150）
- Q: 通常表示の「メディア表示区画」はどこまでか → A: メディアの周りの余白を含むプレビュー領域全体（保守者が選択。FR-220）
- Q: 通常表示で読み込み中・表示できない旨の表示のときもダブルクリックで全画面にするか → A: する。⌃⌘F と同じく、メディアファイルを選んでいれば対象とする（推奨を採用。EC-149）
- Q: トラックパッドの「タップでクリック」による2回のタップや、VoiceOver の操作もダブルクリックとして扱うか → A: macOS がダブルクリックとして届けるものはすべて同じに扱う。
  キーボードだけの利用者は既存の ⌃⌘F・Esc（FR-036）を使い、新しいアクセシビリティの操作は追加しない（推奨を採用。A-134）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。全画面の既存の規則は FR-036・FR-037・FR-046（preview.md）、解除時の表示とフォーカスの復帰は FR-094（window-layout.md）、
スライドショー中の全画面は FR-122・FR-123（preview.md）に従う。US1・US2 はタスク内の略称で、永続のシナリオ ID は既存の US5 に追加する。

### User Story 1 - 画像でも動画でもダブルクリックで全画面にする (Priority: P1)

利用者は、プレビューに画像または動画を表示しているとき、プレビュー領域をダブルクリックして全画面にする。

**Why this priority**: 現在は画像だけが対象で、動画ではキーやメニューを使う必要がある。メディアの種類によらず同じ操作で全画面にできることが本変更の中心。

**Independent Test**: 3ペイン表示とプレビューのみ表示のそれぞれで、画像と動画を表示し、メディアの上と周りの余白をダブルクリックする。

**Acceptance Scenarios**:

- **US5-AS7**: **Given** 3ペイン表示またはプレビューのみ表示でプレビューに動画を表示中, **When** 映像の上、または映像の周りの余白をダブルクリックする,
  **Then** 全画面表示に切り替わり、動画の再生位置と再生状態（再生中・一時停止）はダブルクリックの前と同じ
- **US5-AS8**: **Given** プレビューに画像を表示中, **When** 画像の周りの余白（画像が描かれていないプレビュー領域）をダブルクリックする,
  **Then** 画像の上をダブルクリックしたとき（US5-AS1）と同じく全画面表示に切り替わる
- **US5-AS9**: **Given** プレビューに動画を表示中, **When** 再生コントロール（再生ボタン・シークバー・音量）の上をダブルクリックする,
  **Then** 全画面は切り替わらず、従来どおりそのコントロールの操作だけが行われる

### User Story 2 - 全画面のどこをダブルクリックしても元に戻す (Priority: P1)

利用者は、全画面中に画面のどこをダブルクリックしても全画面を解除し、全画面前の表示に戻る。

**Why this priority**: 全画面ではメディアが画面の一部にしか描かれないことが多く、余白をダブルクリックしても戻れないと、狙う位置を探す手間が生じる。

**Independent Test**: 画像と動画のそれぞれで全画面にし、メディアの上・上下左右の余白・画面の隅をダブルクリックして、全画面前の表示状態に戻ることを確かめる。

**Acceptance Scenarios**:

- **US5-AS10**: **Given** 画像または動画を全画面表示中, **When** メディアの上、メディアの周りの余白、画面の隅のいずれかをダブルクリックする,
  **Then** 全画面が解除され、全画面前のペイン表示・ペイン幅・フォーカスのあったペインに戻る（FR-094（window-layout.md））。
  動画の再生位置と再生状態は維持される（FR-037）
- **US5-AS11**: **Given** 全画面表示中に矢印キーで別のメディアへ移動した, **When** 画面のどこかをダブルクリックする,
  **Then** 全画面が解除され、移動後のファイルが選択・プレビューされた状態になる（FR-046）
- **US5-AS12**: **Given** スライドショーを全画面で実行中, **When** 画面のどこかをダブルクリックする,
  **Then** FR-122 のとおりスライドショーを続けたまま全画面を解除し、プレビューのみ表示で継続する。画像と動画のどちらを表示中でも同じ

### Edge Cases

- **EC-149**: 通常表示でプレビューが空のとき（何も選択していない、フォルダ・zip ファイル・zip の中のディレクトリ・`..` の行を選択している。FR-075・FR-076（file-list.md））は、
  プレビュー領域をダブルクリックしても何もしない。読み込み中の表示と表示できない旨の表示（FR-038）は、メディアファイルを選んでいるため、
  ダブルクリックで全画面に切り替える。全画面中はこれらの表示でも、ダブルクリックで解除する
- **EC-150**: 動画の再生コントロールと、拡大した画像のスクロールバー（FR-158）の上でのダブルクリックは、全画面の切り替えに使わない。
  通常表示でも全画面中でも同じとする。全画面中にメニューバーやツールバーが表示されている場合、それらの上のダブルクリックも切り替えに使わない
- **EC-151**: スライドショーの切り替え効果の表示中も、ダブルクリックは下のプレビューに届き（FR-131）、表示中のメディアの種類によらず全画面を切り替える。
  切り替えた後の効果の扱いは FR-131 に従う
- **EC-152**: ダブルクリックの1回目のクリックで、動画の再生・一時停止、再生位置、音量、画像の倍率と表示位置（FR-133・FR-159）を変えない。
  全画面の切り替えに伴う画像の位置の保ち方は FR-159 に従う

## Requirements *(mandatory)*

### Functional Requirements

- **FR-035（変更）**: ユーザーは、プレビューに画像または動画を表示しているとき、メディア表示区画のダブルクリックでフルスクリーン表示に切り替え、
  フルスクリーン中は画面のどこをダブルクリックしても解除できなければならない。反応する領域と除外する部品は FR-220 に従う。
  対象は静止画・アニメーション画像・動画とし、解除後の表示は FR-094（window-layout.md）、スライドショー実行中は FR-122 に従う
- **FR-220**: ダブルクリックに反応する領域は次のとおりとする。（1）3ペイン表示とプレビューのみ表示では、メディアの周りの余白を含むプレビュー領域全体を
  メディア表示区画とする。プレビューが空のとき（EC-149）は反応しない。（2）フルスクリーン中は、メディアの周りの余白を含む画面全体とする。
  （1）（2）とも、動画の再生コントロールと画像のスクロールバー（FR-158）の上は除く（EC-150）
- **FR-221**: ダブルクリックによる全画面の切り替えは、その1回目のクリックで動画の再生状態・再生位置・音量、画像の倍率と表示位置を変えてはならない（EC-152）。
  切り替えの前後で、動画の再生位置と再生状態を維持する（FR-037）
- **FR-131（変更）**: 矢印キーによる手動の選び直し（FR-120）、スライドショー開始時の最初の表示、終了時の表示復帰、スライドショー以外での
  選択の変更には切り替え効果を付けてはならない。効果の表示中も矢印キー・Esc・全画面の切り替えなどの操作を受け付け、効果を打ち切って
  その操作の結果を即座に表示しなければならない。効果の表示中も、マウスのクリック（メディア表示区画のダブルクリックによる全画面の切り替え（FR-035）を
  含む）は下のプレビューへ届かなければならず、効果の表示は VoiceOver の要素にしてはならない。macOS の「視差効果を減らす」が
  オンの間は、「スライド」と「ズーム」を「クロスフェード」に置き換えて表示しなければならない（保存した設定値は変えない）

### Key Entities

新しいエンティティはない。全画面状態と全画面前の表示状態は既存のもの（FR-094（window-layout.md））を使う。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-108**: 3ペイン表示とプレビューのみ表示のそれぞれで、静止画・アニメーション画像・動画（再生中と一時停止中）を表示し、メディアの上と
  メディアの周りの余白を各5回ダブルクリックして全画面にする。全画面中はメディアの上・上下左右の余白・画面の四隅を各5回ダブルクリックして解除する。
  切り替わらなかった回数が0回、解除後のペイン表示・ペイン幅・フォーカスが全画面前と異なった回数が0回、動画の再生位置と再生状態が変わった回数が0回となる
- **SC-109**: 動画の再生コントロールと画像のスクロールバーの上を、通常表示と全画面中で各5回ダブルクリックし、全画面が切り替わった回数が0回となる。
  空のプレビュー（EC-149）を5回ダブルクリックし、全画面になった回数が0回となる

## Assumptions

- **A-133**: 動画の再生コントロールは、マウスを動画の上に置いたときに表示される標準の再生コントロールを指す。コントロールが隠れている間は、
  その位置も映像の一部として反応領域に含める
- **A-134**: ダブルクリックの間隔は macOS のシステム設定に従う。シングルクリックで動画の再生・一時停止を切り替える操作は追加しない
- **A-135**: 全画面の切り替えのキーボード操作（⌃⌘F）・Esc・メニュー（FR-036）と、ファイルリストのみ表示からの全画面（FR-094（window-layout.md））は変更しない。
  ファイルリスト上のメディアの行のダブルクリック（TAK-18 の対象）は本変更に含めない

## 検証方針

ダブルクリックの対象・反応する領域・除外する部品の判断のうち、表示状態とプレビュー内容だけで決まる部分（プレビューが空かどうか、全画面中かどうか）は
Swift Testing で自動検証する。マウスの位置による反応領域、動画の再生状態の維持、スライドショー中の動作は quickstart.md で実機確認する。
Cloud の静的検査、macOS CI の build/test、保守者の起動スモークと実機確認を分けて記録する。
