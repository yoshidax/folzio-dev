# Quickstart: TAK-88 の検証

Cloud では `scripts/dev/check-all.sh` だけ、CI では `swift build` と `swift test`、保守者の macOS では次の確認を行う
（`docs_private/cloud-agent-workflow.md` の 5 章）。結果は `checklists/validation.md` に記録する。

## 準備

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

- Safari と Chrome で、JPEG・PNG・GIF・WebP の画像のあるページを開く
- 写真アプリに、写真（HEIC・JPEG）と動画（MOV・MP4）を1つずつ用意する
- 宛先のフォルダを、起動ディスク（APFS）と、あれば exFAT の USB ドライブに用意する

## 先に行う確認（R1）

```bash
swift scripts/dev/pasteboard-probe.swift
```

- スクリプトのウインドウへ、Safari・Chrome の画像、写真アプリの写真・動画をドラッグし、表示された型・約束の種類・マスク・書き出された名前と時間を記録する
- 各アプリで「コピー」した後に、スクリプトのクリップボードの表示を記録する
- 200 MB 程度の TIFF をクリップボードに置いたときの、読み出しの時間を記録する

## ドラッグ（US77）

| 確かめる操作 | 期待する結果 |
|---|---|
| Safari・Chrome の画像を、ツリーのフォルダ・お気に入り・リストのフォルダの行・サムネイルのフォルダ・一覧の背景へ | 下記 |
| Option・⌘ を押しながらドロップ | コピーとして示され、保存される（US77-AS6） |
| 宛先に同じ名前がある | 「置き換える / 両方残す / 中止」（US77-AS4） |
| 確認・衝突でキャンセル | 宛先に何もない。一時的なフォルダが残らない（US77-AS5） |
| リンク・文字列、Mail の PDF の添付をドラッグ | 宛先が強調されない（US77-AS3・SC-183） |
| 写真アプリの MOV・MP4 をドラッグ | 2 秒を超えるとパネル。終わると保存（US77-AS8） |
| パネルの「取り消す」・⌘. | 宛先に何もない（US77-AS9） |
| 名前の変更中に ⌘. | 名前の変更が取り消され、受け取りは続く（SC-189） |

- **Safari・Chrome の画像を、ツリーのフォルダ・お気に入り・リストのフォルダの行・サムネイルのフォルダ・一覧の背景へ**（期待する結果）:
  宛先が強調され、コピーとして保存される（US77-AS1・AS2・AS7・SC-186）。
  - `xattr -l` で quarantine の印がある（SC-191）

## ペースト（US78）

| 確かめる操作 | 期待する結果 |
|---|---|
| 「画像をコピー」の後、ファイルリストで ⌘V | PNG で保存（US78-AS1） |
| 同じクリップボードで、ツリーの ⌘V・「ここにペースト」 | 選んだフォルダに保存（US78-AS2） |
| 画像データだけのとき、メニューを開く | 「移動ペースト」が淡色（US78-AS3） |
| 写真アプリでコピーして ⌘V | 元のファイルが保存（US78-AS8。R1 の結果で変わる） |
| zip の中・検索結果で ⌘V、名前の編集中に ⌘V | 今と同じ（US78-AS6・AS7） |

## 安全性（SC-190・SC-196）

- 自動テスト（`Tests/FolzioCoreTests/ImportedFileNameTests.swift`・`ImportInspectorTests.swift`・`ImportCleanupRecordTests.swift`）で、
  細工した名前・種類・大きさ・構造・起動時の記録の各場合を確かめる。CI で実行する
- 保守者は、動作の確認として次を行う
  - 中身が JPEG で名前が `.png` のファイルを書き出すアプリ（R1 のスクリプトの書き出しの機能）からドラッグし、`.jpg` で保存されること
  - 書き出しの途中で Folzio を強制終了し、次の起動の後に一時的なフォルダが残らないこと（SC-188）

## 変わらないこと（SC-192）

- Finder からのドラッグ（同じボリューム・別のボリューム、修飾キー）、アプリ内のドラッグ、⌘C・⌘V・⌥⌘V が今と同じに動く
