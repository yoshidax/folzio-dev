# Contract: ブラウザの画像の受け取り（TAK-88）

ユーザーから見える操作と、ペーストボードとの取り決め。product へ反映する本文は spec.md の「反映する本文」にある。

## 受け付けるペーストボードの型

| 場面 | 登録・読み出す型 | 受け付けないもの |
|---|---|---|
| ドラッグ | 下記 | URL・文字列・HTML だけ |
| ペースト | 下記 | URL・文字列・HTML だけ |

- **ドラッグ**（登録・読み出す型）: `.fileURL`、`NSFilePromiseReceiver.readableDraggedTypes`、`.png`、`.tiff`（R1 の結果でほかの画素の画像の型を加える）
- **ペースト**（登録・読み出す型）: 一般のペーストボードの同じ型。約束は R1 の 3 の結果で決める（R11）
- 複数があるときの順: file URL → 約束 → 画像データ（EC-241）
- 約束は、示す種類が画像・対応形式の動画・不明のときだけ受け付ける（FR-348）

## 宛先と操作

- 宛先は FR-345（file-operations.md）と同じ。宛先の強調も同じ
- 操作は常にコピーとして示す（`.copy`）。ドラッグ元のマスクに `.copy` がなければ受け付けない（FR-356）
- 移動ペーストは file URL があるときだけ有効（FR-354）

## メニューとキー

| 項目 | キー | 有効な条件 |
|---|---|---|
| 編集 > ペースト・右クリックの「ペースト」「ここにペースト」 | ⌘V | 下記 |
| 編集 > 移動ペースト・右クリックの「移動ペースト」「ここに移動ペースト」 | ⌥⌘V | クリップボードに file URL がある（今と同じ） |
| 編集 > 受け取りを取り消す（新規） | ⌘. | 下記 |

- **編集 > ペースト・右クリックの「ペースト」「ここにペースト」**（有効な条件）: クリップボードに file URL・約束・画像データのどれかがある。
  - 場所の条件（zip の中・検索結果など）は今と同じ
- **編集 > 受け取りを取り消す（新規）**（有効な条件）: 受け取りを待っている操作がある。
  - キーのウインドウにシートがなく、モーダルがなく、テキストの編集中でない
  - 割り当ての変更の対象外（予約キーの表に ⌘. を加える）。ショートカット一覧の「選択とファイル操作」に載せる（A-124）
- メニューの有効・無効は型の一覧だけで決め、データを読まない（FR-354）

## 進み具合のパネル

| 要素 | 内容 |
|---|---|
| 表示 | 受け取りが 2 秒を超えたとき。操作を妨げず、フォーカスを奪わない |
| 行 | 宛先のフォルダの名前、件数、書き出し済みの件数、大きさ、段階（書き出し中・確認中） |
| 取り消す | 行ごとのボタン。⌘. は最後に始めた操作 |
| 閉じる | 確認モーダルを出す直前にその行を消し、行がなくなったら閉じる |

## 保存されるファイル

- 名前・拡張子: R6（FR-352・FR-357・FR-360・EC-243）
- 印: quarantine。ブラウザの印を保ち、なければ Folzio とその日時だけ（FR-358）
- 上限: 画像 256 MB、動画 4 GB、変換は 1 枚目が 1 億画素まで（FR-359）
- 確認・衝突・失敗: 既存のコピーと同じ（FR-347）。確認モーダルには宛先に作る名前を示す
