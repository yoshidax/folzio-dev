# Feature Specification: ツールバーの検索欄による名前の絞り込み

> **移行済み（2026-11-13）**: 現在の仕様は [specs/product/](../product/README.md) を正とする。
> このファイルは TAK-86 時点の記録として凍結しており、更新しない。

**Feature Branch**: `claude/peaceful-bell-dj1h3u`

**Created**: 2026-11-12

**Status**: Draft

**Input**: TAK-86 https://linear.app/takyoshida/issue/TAK-86 — ツールバーの右端に、ファイル名・フォルダ名を入力するテキストフィールド（検索欄）を追加する。
Issue の当初の内容は「Return で、ツリーで選択中のフォルダを起点に検索する」だったが、2026-11-12 に保守者が要件を改めた。
検索欄は、ファイルリストに表示されているファイルとフォルダの絞り込み（フィルタ）とし、起点を指定する検索は今までどおり検索のモーダルで行う。
検索欄の虫眼鏡アイコンを押すと、⌘F の検索のモーダルを開き、検索欄の文字をキーワードとして引き継ぐ。

## Clarifications

### Session 2026-11-12（要件の変更）

- 保守者の決定: ツールバーからの検索は、起点からの検索ではなく、ファイルリストに表示されているファイルとフォルダのフィルタとする。
  起点からの検索は今までどおり検索のモーダルで行い、両者を棲み分ける（A-223）
- Q: 絞り込みをいつ一覧に反映するか？ → A: 入力のたびに反映する。×ボタンと Esc で文字を消すと絞り込みも解除する（FR-381・FR-383）
- Q: 絞り込み中に別のフォルダへ移動したとき（ツリーの選択、フォルダを開く、戻る・進む、検索の開始と解除など）は？ → A: 絞り込みを解除し、検索欄も空にする（FR-384）
- Q: 虫眼鏡から検索のモーダルを開き、検索欄の文字をキーワードとして引き継ぐ機能は残すか？ → A: 残す（FR-390）
- Q: 照合の規則と、対象にする一覧は？ → A: 検索のモーダルと同じ規則（FR-082（search.md））とし、通常のフォルダ・zip の中・検索結果のすべての一覧で、
  ファイル・フォルダ・zip の行を絞り込む。先頭の `..` の行は常に残す（FR-381・FR-382）

## User Scenarios & Testing *(mandatory)*

### User Story 81 - 表示中の一覧を名前で絞り込む (Priority: P1)

ユーザーは、ツールバーの検索欄に文字を入力するだけで、いま表示している一覧を、名前が一致するファイルとフォルダだけに絞り込める。
項目の多いフォルダや検索結果の中から、目的の項目をすばやく見つけられる。

**Why this priority**: TAK-86 の主目的。

**Independent Test**: ツールバーを表示し、ファイルとフォルダが混ざったフォルダを開いて検索欄に文字を入力する。
入力のたびに一覧が絞り込まれ、文字を消すと元に戻ることを確かめる。

**Acceptance Scenarios**:

- **US81-AS1**: **Given** フォルダ A の一覧に `cat01.jpg`・`dog.png`・フォルダ `cats`・`..` の行がある, **When** 検索欄に `cat` と入力する,
  **Then** 1文字入力するたびに一覧が絞り込まれ、`cat` まで入力すると `..`・`cats`・`cat01.jpg` だけが表示される。Return は要らない
- **US81-AS2**: **Given** 検索欄が空, **When** 文字を入力する, **Then** 検索欄の右端にクリア（×）ボタンが現れる
- **US81-AS3**: **Given** `cat` で絞り込み中, **When** ×ボタンを押す（または検索欄で Esc を押す）,
  **Then** 検索欄が空になり、×ボタンが消え、絞り込みが解除されて A の一覧がすべて表示される
- **US81-AS4**: **Given** A の一覧を表示中, **When** 検索欄に `*.png` と入力する, **Then** 名前全体が `.png` で終わる項目だけが表示される（FR-082（search.md）のワイルドカード）
- **US81-AS5**: **Given** A の一覧に名前が一致する項目がない, **When** 検索欄に `zzz` と入力する,
  **Then** `..` の行だけが残り、`zzz` に一致する項目がない旨のメッセージが表示される
- **US81-AS6**: **Given** `cat` で絞り込み中, **When** ツリーで別のフォルダを選ぶ（または一覧のフォルダの行を開く、「戻る」を実行する）,
  **Then** 絞り込みが解除され、検索欄は空になり、移動先の一覧がすべて表示される
- **US81-AS7**: **Given** 検索のモーダルから検索した検索結果を表示中, **When** 検索欄に `2024` と入力する,
  **Then** 検索結果のうち名前に `2024` を含む行だけが表示される。検索バーのキーワード・起点・件数は変わらない
- **US81-AS8**: **Given** zip の中の一覧を表示中, **When** 検索欄に文字を入力する, **Then** zip の中のディレクトリとファイルの行が同じ規則で絞り込まれ、`..` は残る
- **US81-AS9**: **Given** `dog.png` を選択してプレビュー中, **When** 検索欄に `cat` と入力して `dog.png` が非表示になる,
  **Then** `dog.png` は選択から外れ、プレビューは空になる（種類フィルタの FR-059（file-list.md）と同じ規則）
- **US81-AS10**: **Given** 絞り込み中で検索欄にフォーカスがある, **When** Return を押す,
  **Then** 絞り込みを保ったまま、キーボードフォーカスがファイルリストへ移る
- **US81-AS11**: **Given** 検索欄で日本語を変換中, **When** 変換を確定する,
  **Then** 確定した文字で絞り込まれる。確定の Return では、フォーカスはファイルリストへ移らない

### User Story 82 - 入力したキーワードを持って検索のモーダルへ移る (Priority: P2)

ユーザーは、表示中の一覧を絞り込んでも目的の項目が見つからないとき、虫眼鏡アイコンを押して検索のモーダルを開ける。
入力済みの文字はキーワードとして引き継がれ、下の階層まで探す検索へそのまま移れる。

**Why this priority**: 絞り込みと検索の棲み分けをつなぐ。US81 だけでも絞り込みは使えるため P2 とする。

**Independent Test**: 検索欄に文字を入れて虫眼鏡を押し、モーダルのキーワード欄に同じ文字が入ることを確かめる。
検索欄が空のときは ⌥⌘F と同じ内容で開くことを確かめる。

**Acceptance Scenarios**:

- **US82-AS1**: **Given** 検索欄に `kyoto` と入力済み, **When** 検索欄の虫眼鏡アイコンを押す,
  **Then** 検索のモーダルが開き、検索キーワード欄に `kyoto` が全選択の状態で入っている。
  検索起点ディレクトリは ⌥⌘F で開いた場合と同じ既定値（FR-081（search.md））である
- **US82-AS2**: **Given** 検索欄が空で、同じ起動中に `cat` で検索したことがある, **When** 虫眼鏡アイコンを押す,
  **Then** ⌥⌘F で開いた場合と同じく、検索キーワード欄に `cat` が全選択の状態で入っている
- **US82-AS3**: **Given** 虫眼鏡から開いたモーダル, **When** 「キャンセル」を押す, **Then** 検索欄の文字と絞り込みは変わらない
- **US82-AS4**: **Given** 虫眼鏡から開いたモーダル, **When** 「検索」を押して検索が始まる,
  **Then** 表示する一覧が検索結果に替わるので、絞り込みは解除され、検索欄は空になる（FR-384）
- **US82-AS5**: **Given** 検索欄に `kyoto` と入力済みで、検索欄にフォーカスがある, **When** ⌥⌘F を押す,
  **Then** 虫眼鏡を押した場合と同じく、検索キーワード欄に `kyoto` が入った検索のモーダルが開く
- **US82-AS6**: **Given** 一覧を表示中, **When** ⌥⌘F（または虫眼鏡）で検索のモーダルを開く,
  **Then** モーダルの冒頭に見出し「サブフォルダを含めて検索」と、その下に小さく淡い文字で
  「検索起点ディレクトリとその下のすべてのサブフォルダから、名前が一致するファイルとフォルダを探します。」が表示される。
  キーボードフォーカスは従来どおり検索キーワード欄にあり、VoiceOver はキーワード欄の説明としてこの文を読み上げる

### User Story 83 - キーボードだけで絞り込む (Priority: P2)

ユーザーは、マウスを使わずに、ショートカットで検索欄へ移り、絞り込み、一覧へ戻れる。

**Why this priority**: 憲章 原則 III（新しい操作にはキーボードで到達できる手段を同時に提供する）を満たすため。

**Independent Test**: ファイルリストにフォーカスを置き、⌘F → 文字の入力 → Return → 矢印キーで、マウスなしで絞り込みと選択ができることを確かめる。

**Acceptance Scenarios**:

- **US83-AS1**: **Given** ファイルリストにフォーカスがある, **When** ⌘F を押す（または「ファイル」メニューの「名前で絞り込む」を選ぶ）,
  **Then** ツールバーの検索欄にフォーカスが移り、入力済みの文字があれば全選択される
- **US83-AS2**: **Given** ツールバーを隠している, **When** ⌘F を押す, **Then** ツールバーが表示され、検索欄にフォーカスが移る
- **US83-AS3**: **Given** 絞り込み中で、Return でファイルリストへ戻った後, **When** ⌘F を押してから Esc を押す,
  **Then** 検索欄の文字が消え、絞り込みが解除される
- **US83-AS4**: **Given** プレビューのみ表示中、またはカスタマイズで検索欄を外している, **When** 「ファイル」メニューを開く,
  **Then** 「名前で絞り込む」は淡色で選べず、⌘F も何もしない

### User Story 84 - 検索欄を含むツールバーを自分の並びにする (Priority: P3)

ユーザーは、検索欄をほかのセットと同じく、ツールバーのカスタマイズで並び替え・削除・再追加できる。
一度もカスタマイズしていないユーザーには、検索欄が既定で右端に現れる。

**Why this priority**: 既存のカスタマイズ（FR-233〜FR-235（window-layout.md））との整合。絞り込みの機能そのものではないため P3 とする。

**Independent Test**: 保存した並びがない状態で起動し、検索欄が右端にあることを確かめる。
カスタマイズ画面で検索欄を動かし、再起動後に位置が復元されることを確かめる。

**Acceptance Scenarios**:

- **US84-AS1**: **Given** ツールバーを一度もカスタマイズしていない, **When** この変更を含む版を起動してツールバーを表示する,
  **Then** 検索欄がツールバーの右端に表示される
- **US84-AS2**: **Given** この変更より前にツールバーを並び替えて保存した, **When** この変更を含む版を起動する,
  **Then** 保存した並びのまま表示され、検索欄は自動では加わらない。カスタマイズ画面には検索欄が候補として表示され、ドラッグで追加できる
- **US84-AS3**: **Given** カスタマイズ画面で検索欄を左端へ移した, **When** アプリを再起動する, **Then** 検索欄は左端に復元され、文字は空で始まる
- **US84-AS4**: **Given** 絞り込み中, **When** ツールバーを隠す（⇧⌘T）、検索欄をカスタマイズで外す、またはツールバーを文字だけで表示する形式にする,
  **Then** 絞り込みは解除される（検索欄が見えない状態で、絞り込みだけが残らない）
- **US84-AS5**: **Given** ツールバーを文字だけで表示する形式にした、またはウインドウが狭く検索欄があふれた, **When** 「絞り込み」の項目を選ぶ,
  **Then** 検索のモーダルが開く

### Edge Cases

- **EC-250**: 絞り込み中に、一覧の項目が増えた・名前が変わった場合（アプリの外での変更、名前の変更、複製、ペースト、検索中に見つかった項目）は、
  その時点の名前で照合し、一致する項目だけを表示する。
  - 一覧で名前を変えた項目が一致しなくなった場合は、その行は非表示になり、選択から外れる（FR-385）
- **EC-251**: 検索中（検索結果を集めている間）に絞り込んでも、検索は止めない。
  - 絞り込みを解除すると、その時点までに見つかった結果がすべて表示される
- **EC-252**: 前後の空白を除いた文字が空（空白だけ）のときは、絞り込まない
- **EC-253**: ウインドウが狭く検索欄があふれて見えなくなっただけでは、絞り込みを解除しない。
  - ウインドウを広げると、検索欄は入力済みの文字のまま現れる
- **EC-254**: 検索欄の文字と絞り込みは保存しない。再起動後は、絞り込みのない状態で始まる。
  - 履歴（navigation-history.md）にも記録せず、戻る・進むで移った先は絞り込みのない状態で表示する
- **EC-255**: 表示言語を切り替えた場合、検索欄のプレースホルダ・ラベル・ツールチップと、一致する項目がない旨のメッセージは新しい言語に変わり、
  入力済みの文字と絞り込みは保つ
- **EC-256**: カスタマイズ画面のパレットの見本の検索欄には入力できず、絞り込みも虫眼鏡も働かない（標準の動作）
- **EC-257**: 検索欄にフォーカスがある間、ファイル操作のショートカット（⌘⌫・⌘C・⌘V・⌘D など）は、検索欄の文字の編集として働くか、何もしない。
  - ファイルリストとツリーで選択中の項目を対象にしない（検索欄で文字を消そうとして、ファイルをゴミ箱に入れることがない）
- **EC-258**: 絞り込み中にプレビューのみ表示・フルスクリーン・スライドショーへ移った場合は、検索欄は無効になるが、絞り込みは保つ。
  - フルスクリーン中の矢印キーでの移動とスライドショーは、絞り込んだ後の一覧を対象にする（種類フィルタと同じ。FR-387）
- **EC-259**: 並べ替え・表示形式・種類フィルタ・「zipファイルを表示」・列の表示の変更では、絞り込みを解除しない
- **EC-260**: 検索結果を表示中に絞り込んでいるとき、ファイルリストで Esc を押すと、従来どおり検索結果の表示を解除する（FR-086（search.md））。
  - 表示する一覧が替わるので、絞り込みも解除される（FR-384）
- 絞り込みはファイルリスト（リスト形式とサムネイル形式）だけに適用し、ツリーの表示には影響しない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-380**: ツールバーに、ファイルリストを名前（ファイル名とフォルダ名）で絞り込むための検索欄（標準の検索フィールド）を1つのセットとして追加しなければならない。
  - 既定の並びでは、ツールバーの右端に置く（FR-233（変更））
  - 検索欄の中の左端に虫眼鏡アイコンを表示する
  - 検索欄が空のときは、名前で絞り込む欄であることを示すプレースホルダを表示する
  - 検索欄に1文字以上が入っている間、検索欄の中の右端にクリア（×）ボタンを表示する
- **FR-381**: 検索欄に文字が入っている間、システムは、ファイルリストに表示する行を、名前がその文字に一致するものだけに絞り込まなければならない（名前の絞り込み）。
  - 絞り込みは、文字を入力・削除するたびに、Return を待たずに反映する
  - 照合の規則は検索のモーダルと同じとする（FR-082（search.md）。ワイルドカードを含まない文字は名前への部分一致、`*`・`?` を含む文字は名前全体との一致、
    英字の大文字小文字と Unicode の正規化の違いは区別しない）
  - 対象は、メディアファイル・フォルダ・zip ファイル・zip の中のディレクトリの行とする
  - 先頭の `..` の行は、絞り込みに関わらず表示する
  - 前後の空白を除いた文字が空のときは、絞り込まない
  - 種類フィルタ（FR-056（file-list.md））と「zipファイルを表示」（FR-095（zip.md））で表示の対象になった行を、さらに名前で絞り込む
  - リスト形式とサムネイル形式の両方に適用し、ツリーの表示には影響しない
- **FR-382**: 名前の絞り込みは、通常のフォルダの一覧・zip の中の一覧・検索結果の一覧のどれにも適用しなければならない。
  - 検索結果を絞り込んでも、検索バーのキーワード・起点・件数（FR-084（search.md））は変えず、実行中の検索も止めない
  - 絞り込みはフォルダを辿らず、表示中の一覧の項目だけを照合する
- **FR-383**: 検索欄の×ボタンを押すか、検索欄で Esc を押すと、システムは検索欄の文字を消し、名前の絞り込みを解除しなければならない
- **FR-384**: ファイルリストに表示する一覧が別の場所へ替わったとき、システムは名前の絞り込みを解除し、検索欄を空にしなければならない。
  - 替わる操作は、ツリーでのフォルダの選択、一覧のフォルダ・zip の行と `..` を開く操作、上の階層へ（⌘↑）、戻る・進む、検索の開始、検索結果の解除、

  - 「キャンセル」（Esc を含む）ではモーダルを閉じるだけで、ファイルリスト・ツリー・
    プレビューを取消操作によって変えてはならない。
  - モーダルを開いたときは検索キーワード欄にフォーカスを置き、
    同じ起動中に前回検索したキーワードがあれば全選択した状態で入れておく（検索起点ディレクトリは毎回上の既定値とする）。
  - 標準パネルを開いていないときは、Return で「検索」（キーワードが空のときは何もしない）、Esc で「キャンセル」
    とする。
  - Tab は検索キーワード → 検索起点ディレクトリ → 「選択…」 → キャンセル → 検索の順、⇧Tab は逆順に移動し、
    システムのキーボードナビゲーションの設定に関わらずボタンにも止まる。
  - 検索起点ディレクトリは直接入力・編集を引き続き可能とし、入力手段によらず「検索」を押したときに確かめる。
  - 直接入力では前後の空白を除き、先頭の `~` はホームフォルダ、末尾の `/` は無視して解釈する。
  - GUI 選択で反映してから起点欄を編集していない間だけは、名前の末尾の空白も含む選択した絶対パスを文字どおり使い、
    空白除去は行わない。
  - 起点欄を編集した時点で従来の直接入力の解釈へ戻す。
  - キーワードの編集や標準パネルの取消では、この区別を変えない。
  - `/` と `~` のどちらでも始まらないパス、存在しないパス、フォルダでないパス（zip ファイルを含む）、
    読み取り権限のないフォルダの場合は、モーダルを閉じずに理由を入力欄の近くに表示し、
    検索を始めてはならない（検証失敗を理由にファイルリストの表示は変えない）。
  - フォルダ選択パネルの動作は FR-141〜FR-144 に従う
