# Quickstart: TAK-86 ツールバーの検索欄による名前の絞り込み

## 自動の検査

```bash
scripts/dev/check-all.sh          # Cloud と保守者のローカル
swift build && swift test         # 保守者のローカルと macOS CI
```

## GUI 確認（保守者）

準備: 古い Folzio を終了し、次を実行する。ツールバーが隠れていれば ⇧⌘T で表示する。

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

確認用に、フォルダ A（`cat01.jpg`・`Cat02.png`・`dog.png`・フォルダ `cats`・フォルダ `sub`、`sub` の中に `my_cat.png`）を用意する。

### 0 起動スモーク

- 3 ペインが表示され、ツールバーの右端に検索欄がある（保存した並びがない場合。US84-AS1）

### 1 絞り込み（US81-AS1〜AS5・AS9・AS10）

- 検索欄の左端に虫眼鏡があり、空のときは「名前で絞り込み」と表示される
- A を開いて `c`・`ca`・`cat` と入力する。1文字ごとに一覧が絞り込まれ、`cat` で `..`・`cats`・`cat01.jpg`・`Cat02.png` だけになる。Return は要らない
- 1文字目で右端に×ボタンが現れる。×ボタンを押すと文字が消え、一覧がすべて戻る
- もう一度 `cat` と入れて Esc。文字が消え、一覧がすべて戻る
- `*.png` と入れると、名前が `.png` で終わる項目だけになる。`c?t*` でも規則どおりに絞り込まれる
- `zzz` と入れると `..` だけが残り、「“zzz”に一致する項目はありません」と出る
- 空白だけを入れても絞り込まれない
- `dog.png` を選んでプレビューしてから `cat` と入れる。`dog.png` は選択から外れ、プレビューが空になる。×ボタンで戻しても選択は戻らない
- サムネイル形式でも同じに絞り込まれる。ツリーの表示は変わらない
- 絞り込み中に Return を押すと、絞り込みを保ったままファイルリストへフォーカスが移り、矢印キーで絞り込んだ行だけを移動できる。⌘A は絞り込んだ行だけを選ぶ

### 2 日本語の入力（US81-AS11）

- 日本語入力で「ねこ」と打つ。変換中は一覧が変わらず、確定すると確定した文字で絞り込まれる
- 確定の Return では、フォーカスはファイルリストへ移らない。もう一度 Return で移る

### 3 解除される操作・されない操作（US81-AS6〜AS8・SC-210）

- `cat` で絞り込み中に、ツリーで別のフォルダを選ぶ。絞り込みが解除され、検索欄が空になる
- 同じことを、フォルダの行を開く（`cats` をダブルクリック）・`..` を開く・⌘↑・「戻る」（⌘[）・⌥⌘F からの検索の開始・検索結果での Esc で確かめる
- 絞り込み中に、並べ替えの列を変える・表示形式を変える（⌘1 / ⌘2 はファイルリストにフォーカスを戻してから）・「画像のみ表示」を切り替える。絞り込みは解除されない
- 絞り込み中に、Finder で A に `cat99.jpg` と `bird.jpg` を加える。`cat99.jpg` だけが一覧に現れ、絞り込みは解除されない
- ⌥⌘F で A を起点に `*` を検索し、検索結果を表示する。検索欄に `my` と入れると `my_cat.png` だけになり、検索バーの件数は変わらない
- zip の中を表示して検索欄に文字を入れる。zip の中の行が絞り込まれ、`..` は残る

### 4 キーボード（US83-AS1〜AS4・SC-214）

- ファイルリストにフォーカスを置いて ⌘F。検索欄にフォーカスが移る。「ファイル」メニューに「名前で絞り込む（⌘F）」がある
- 文字を入れて Return → 矢印キーで選択 → ⌘F（文字が全選択される）→ Esc で解除、までをマウスなしで行える
- ⇧⌘T でツールバーを隠してから ⌘F。ツールバーが表示され、検索欄にフォーカスが移る
- 「プレビューのみ表示」（⌃⌘3）では、検索欄が無効の表示になり、「名前で絞り込む」が淡色になる。絞り込み中に切り替えた場合、3ペインに戻すと絞り込みと文字が残っている
- 設定のショートカットの一覧に「名前で絞り込む」があり、キーを変えるとメニューと検索欄のツールチップに反映される

### 5 虫眼鏡とフォーカス中のコマンド（US82-AS1〜AS5・EC-257・SC-211・SC-213）

- 検索欄に `kyoto` と入れて虫眼鏡を押す。検索のモーダルが開き、キーワード欄に `kyoto` が全選択で入っている。起点は ⌥⌘F と同じ
- 「キャンセル」で閉じる。検索欄の `kyoto` と絞り込みはそのまま
- もう一度虫眼鏡を押して「検索」。検索結果が表示され、検索欄は空になる
- 検索欄を空にして虫眼鏡を押す。⌥⌘F と同じ内容（前回のキーワードがあればそれ）で開く
- アプリを起動し直し、一度も検索していない状態で、検索欄が空のまま虫眼鏡を押す。キーワード欄は空で開く
- 検索欄に `kyoto` と入れたまま ⌥⌘F を押す。虫眼鏡と同じく、`kyoto` が入ったモーダルが開く
- 虫眼鏡にポインタを置くと「検索…（⌥⌘F）」、検索欄のほかの場所では「名前で絞り込む（⌘F）」と出る
- ファイルリストでファイルを1つ選んでから検索欄を押し、文字を入れる。⌘⌫・⌘C・⌘V・⌘D を順に押す。
  選択中のファイルはゴミ箱に入らず、複製もされず、ペーストも起きない（検索欄の文字の編集になるか、何も起きない）
- ファイルリストで名前の変更中に検索欄を押す。名前の変更は、ほかの場所を押したときと同じ扱いで終わる

### 5a 検索のモーダルの見出しと補足説明（US82-AS6・FR-394・SC-215）

- ⌥⌘F・「ファイル」メニューの「検索…」・虫眼鏡のどれで開いても、冒頭に太字の見出し「サブフォルダを含めて検索」があり、
  その下に小さく淡い文字で「検索起点ディレクトリとその下のすべてのサブフォルダから、名前が一致するファイルとフォルダを探します。」と出る
- 補足説明が切れずに折り返して全文が見える。表示言語を英語にして開き直しても、`Search Including Subfolders` と英語の説明が切れずに見える
- 補足説明はクリックしても選択されず、Tab はこれまでどおり キーワード → 起点 → 選択… → キャンセル → 検索 の順に移る
- VoiceOver でキーワード欄に移ると、説明として補足説明の文が読まれる。補足説明だけを独立した項目として読まない

### 6 カスタマイズ（US84-AS1〜AS5）

- ツールバーを右クリック →「ツールバーをカスタマイズ…」。パレットに「絞り込み」があり、ドラッグで並び替え・削除・再追加ができる。パレットの見本には入力できない
- 絞り込み中に、検索欄をツールバーから外す。絞り込みが解除される。再び追加すると空で始まる
- 絞り込み中に ⇧⌘T でツールバーを隠す。絞り込みが解除される
- 絞り込み中に表示を「テキストのみ」にする。絞り込みが解除される。「絞り込み」を押すと検索のモーダルが開く
- 絞り込み中にウインドウを狭くして検索欄をあふれさせる。絞り込みは解除されない。あふれたメニューの「絞り込み」を選ぶと検索のモーダルが開く
- 検索欄を左端へ移して再起動。左端に復元され、文字は空で始まる。「デフォルトセット」を入れると右端に戻る
- この変更より前に保存した並びで起動しても、並びが変わらず、検索欄は自動では加わらない（US84-AS2）。保存値がない場合は、次で作って確かめる（確認の後に削除する）

  ```bash
  defaults write local.folzio.Folzio view.toolbarItems -array history viewMode NSToolbarFlexibleSpaceItem
  ```

  ```bash
  defaults delete local.folzio.Folzio view.toolbarItems
  ```

  ドメインは `scripts/make-app.sh` の `CFBundleIdentifier`（`open .build/Folzio.app` で起動した場合）。起動のしかたで変わるので、`docs_private/agents/launch-debugging.md` で確かめる

### 7 フルスクリーンとスライドショー（EC-258・FR-387）

- `cat` で絞り込んでからフルスクリーン（⌃⌘F）にし、矢印キーで移動する。絞り込んだ画像だけを移動する。戻ると絞り込みと文字が残っている
- `cat` で絞り込んでからスライドショー（⇧⌘S）を始める。絞り込んだ画像だけが対象になる

### 8 言語とアクセシビリティ（EC-255）

- 設定で表示言語を英語にすると、プレースホルダが `Filter by Name`、パレットの名前が `Filter`、メニューが `Filter by Name`、
  一致なしのメッセージが `No items match “zzz”` になる。入力済みの文字と絞り込みは残る
- VoiceOver で検索欄に移ると「名前で絞り込み」と読む
