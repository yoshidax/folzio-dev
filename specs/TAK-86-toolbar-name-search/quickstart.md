## GUI 確認（保守者）

準備: 古い Folzio を終了し、次を実行する。ツールバーが隠れていれば ⇧⌘T で表示する。

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

確認用に、サブフォルダを持つフォルダ A（中に `cat01.jpg`、`sub/my_cat.png`、名前に `cat` を含まない画像）を用意する。

### 0 起動スモーク

- 3 ペインが表示され、ツールバーの右端に検索欄がある（保存した並びがない場合。US83-AS1）

### 1 見た目と×ボタン（US81-AS2・US81-AS3）

- 検索欄の左端に虫眼鏡があり、空のときは「名前で検索」と表示される
- 1文字入力すると右端に×ボタンが現れ、ファイルリストは変わらない
- ×ボタンを押すと文字が消え、×ボタンも消える。検索結果を表示中でも、結果は変わらない
- 文字を入れて Esc を押すと文字が消える。検索結果は解除されない（EC-257）

### 2 Return での検索（US81-AS1・AS4〜AS8）

- ツリーで A を選び、`cat` と入れて Return。`cat01.jpg` と `sub/my_cat.png` が一覧に出て、検索バーにキーワード `cat` と起点 A が出る。
  フォーカスはファイルリストへ移り、検索欄には `cat` が残る
- 同じキーワードで ⌘F のモーダル（起点は既定のまま）から検索し、一覧・件数・検索バーが同じになる（SC-208）
- 検索結果を表示したまま、検索欄を `my` に変えて Return。同じ A を起点にした結果へ置き換わる
- ツリーで ⌘クリックして複数のフォルダを選び、Return。一覧に表示していたフォルダ（最後にクリックした行）が起点になる
- お気に入りの項目を選んで Return。そのフォルダが起点になる
- zip の中を表示して Return。zip ファイルを含むフォルダが起点になる
- 検索結果から、隠しフォルダの配下のフォルダを開く（一覧はそのフォルダ、ツリーは表示できる祖先を選択。EC-102（search.md））。
  その状態で Return を押すと、一覧のフォルダが起点になり、ツリーで選択中の祖先へは広がらない（EC-251）
- 検索欄が空・空白だけのときの Return では何も起きない
- 日本語入力で「ねこ」と打ち、変換の確定の Return では検索が始まらない。もう一度 Return で始まる
- 検索の後に ⌘F を押すと、キーワード欄に直前のキーワードが全選択で入っている

### 3 虫眼鏡（US82-AS1〜AS3）

- 検索欄に `kyoto` と入れて虫眼鏡を押す。検索のモーダルが開き、キーワード欄に `kyoto` が全選択で入っている。起点は ⌘F と同じ
- モーダルでキーワードを書き換えて「検索」または「キャンセル」。ツールバーの検索欄は `kyoto` のまま
- 検索欄を空にして虫眼鏡を押す。⌘F と同じ内容（前回のキーワードがあればそれ）で開く
- アプリを起動し直し、一度も検索していない状態で、検索欄が空のまま虫眼鏡を押す。キーワード欄は空で開く（SC-209）
- 虫眼鏡にポインタを置くと「検索…（⌘F）」と出る。検索欄のほかの場所では出ない
- 虫眼鏡を押したときに、Return の検索が同時に始まらない

### 4 有効・無効（US82-AS4）

- 「プレビューのみ表示」（⌃⌘3）にすると検索欄が無効の表示になり、入力も虫眼鏡もできない。3ペインに戻すと使え、入力済みの文字は残っている
- ファイルリストで名前の変更中に検索欄を押す。名前の変更は、ほかの場所を押したときと同じ扱いで終わる

### 5 フォーカス中のコマンド（US82-AS5・EC-258・SC-212）

- ファイルリストでファイルを1つ選んでから検索欄を押し、文字を入れる。⌘⌫・⌘C・⌘V・⌘D を順に押す。
  選択中のファイルはゴミ箱に入らず、複製もされず、ペーストも起きない（検索欄の文字の編集になるか、何も起きない）
- 検索欄に `kyoto` と入れたまま ⌘F を押す。虫眼鏡と同じく、`kyoto` が入ったモーダルが開く

### 6 カスタマイズ（US83-AS1〜AS4）

- ツールバーを右クリック →「ツールバーをカスタマイズ…」。パレットに「検索」があり、ドラッグで並び替え・削除・再追加ができる
- パレットの見本の検索欄には入力できない（EC-256）。文字を入れた検索欄をツールバーから外して再び追加すると、空で始まる（EC-254）
- 検索欄を左端へ移して再起動。左端に復元され、文字は空で始まる
- 「デフォルトセット」を入れると、検索欄が右端に戻る
- 表示を「テキストのみ」にして「検索」を押す。検索のモーダルが開く
- ウインドウを狭くして検索欄をあふれさせ、あふれたメニューの「検索」を選ぶ。検索のモーダルが開く
- この変更より前の版で並びを変えて保存した設定がある場合: 起動しても並びが変わらず、検索欄は自動では加わらない（US83-AS2）。
  ない場合は、次で保存値を作って確かめる（確認の後に削除する）

  ```bash
  defaults write local.folzio.Folzio view.toolbarItems -array history viewMode NSToolbarFlexibleSpaceItem
  ```

  ```bash
  defaults delete local.folzio.Folzio view.toolbarItems
  ```

  ドメインは `scripts/make-app.sh` の `CFBundleIdentifier`（`open .build/Folzio.app` で起動した場合）。起動のしかたで変わるので、`docs_private/agents/launch-debugging.md` で確かめる

### 7 言語とアクセシビリティ（EC-255）

- 設定で表示言語を英語にすると、プレースホルダが `Search by Name`、パレットの名前が `Search`、虫眼鏡のツールチップが `Find… (⌘F)` になる。入力済みの文字は残る
- VoiceOver で検索欄に移ると「名前で検索」と読む

### 8 検証に失敗する起点（EC-252）

- ターミナルで読み取り権限のないフォルダを作り（`mkdir -p /tmp/folzio-noread && chmod 000 /tmp/folzio-noread`）、ツリーでそのフォルダを選ぶ
- 検索欄に `a` と入れて Return。検索は始まらず、キーワード `a` と起点のパスと理由が入った検索のモーダルが開く。一覧は変わらない
- 確認の後に `chmod 755 /tmp/folzio-noread && rmdir /tmp/folzio-noread` で消す
