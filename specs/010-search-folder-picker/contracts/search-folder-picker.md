# UI Contract: 検索起点フォルダの選択

本 feature の差分契約。既存は `specs/product/contracts/keyboard-and-menus.md`・`settings.md`、検索内容は product の search.md と `009-folder-search` を参照する。

## 親の検索シート（FR-081・142・144、US1-AS25）

- 起点欄の近くに「フォルダを選択…」を置く。キーワード・起点の有効性に関わらず利用可能。重複提示や検索検証との競合中だけ無効にする。
- 起点の既定値は開いた時点で一覧に表示中のフォルダ。検索結果中は検索前、zip 内は zip を含むフォルダとする。EC-102 の一覧 F・ツリー V では F を使う。⌘F と「ファイル」メニューの「検索…」の双方で同じ規則を適用する（変更後の US1-AS25）。既存キー契約の一覧基準を維持し、product/search.md の FR-081・US1-AS25 のツリー基準の記述を実装・検証後に揃える。
- Tab は キーワード → 起点 → フォルダを選択… → キャンセル → 検索 → キーワード。⇧Tab は逆順。システムのキーボードナビゲーション設定によらずボタンへ止まる。
- 選択ボタンは Space で開く。親だけが表示中の Return は従来どおり検索、Esc は検索シートを閉じる。
- 開いたときのキーワードへのフォーカスと前回値の全選択は初回だけ。子から戻ると選択ボタンへフォーカスする。
- 子の表示中は親を操作できない。親の検索・取消を子のキーで起動しない。
- 初期位置解決中も親の検索ボタンと Return は利用できる。空キーワードは無操作とし、それ以外の検索操作を受理した時点で保留中の提示依頼を失効させてから検索条件を検証する。検索検証中は選択と重複検索を拒否する。
- 失効した初期位置の成功・失敗は、検索検証より先に返っても後に返っても子を提示せず、親のエラーも変えない。検索失敗時は親を保ち理由を示す。旧依頼は復活せず、選択ボタンの再操作で新しい依頼を開始する。先に子が提示済みなら親の検索は受理しない。

## 子の構成（FR-141）

タイトル・アクセシビリティ名は「検索起点フォルダを選択」。現在位置の読み取り専用絶対パス、場所の選択（ホーム・ルート・表示可能なボリューム）、親への移動、直下フォルダの単一選択テーブル、理由欄、「キャンセル」「選択」で構成する。

- フォルダの行だけを出す。通常ファイル・zip・パッケージ・隠し項目は表示しない。
- 表示切替、新規作成、複数選択、パス直接入力、ドラッグによるパス指定、最近使った場所を提供しない。
- 名前順に並べる。行のアクセシビリティ名は元の名前を保持する。現在位置・ボタン・一覧・読み込み中も識別可能にする。
- 行の単一クリック・矢印キーは選択だけ。行が選択されていればそのフォルダ、未選択なら現在位置を「選択」の対象とする。空フォルダ・ルートも確定できる。
- 子の現在位置は親の欄と独立する。移動中に欄を書き換えない。

## 子のキーと移動（FR-144・EC-105）

| 入力 | 動作 |
|---|---|
| ↑ / ↓（一覧） | 直下のフォルダ1つを選択。内部へは入らない |
| ダブルクリック / ⌘↓（一覧） | 選択フォルダへ移動し、行選択を解除 |
| ⌘↑ / 親ボタン | GUI で到達可能な親へ移動。独立ボリューム等の入口で親へ移れなければ無効 |
| Return | 現在の確定対象を検証して選択。親へ伝播しない |
| Esc / キャンセル | 子だけを閉じる。処理中でも有効。親へ伝播しない |
| Tab / ⇧Tab | 場所 → 親 → 一覧 → キャンセル → 選択の順 / 逆順。無効な要素は飛ばす |
| Space | フォーカス中のボタンを操作 |

初期フォーカスはフォルダ一覧とする。表が空でも Tab で全操作へ到達できる。⌘⇧. や⌘⇧G から OS 標準の隠し表示・パス入力を呼び出さず、親にも渡さない。

## 初期位置（FR-143）

1. 現在の起点入力を FR-081 の入力元別規則で解釈した候補。
2. 検索シートを開いた時点に捕捉した、FR-081 の一覧基準の既定フォルダ。
3. ホーム。

全候補へ存在・フォルダ・読取り・GUI 到達可否を適用し、隠し・パッケージとその内部を飛ばす。ルートと各ボリュームは移動先として提供するが、初期位置の追加フォールバックにはしない。全滅なら子を開かず親に理由を表示・読み上げ、欄は保持する。
EC-102 の F が禁止対象の内部なら現在入力と既定の F を飛ばし、ホームへ進む。ツリーの V を追加候補にせず、取消でも親の F を保持する。

## 確定・取消の境界（FR-142・EC-103〜106）

| 結果 | 子 | 親の起点・入力元 | キーワード・親の既存エラー |
|---|---|---|---|
| 確定検証成功 | 閉じる | 選択 URL の絶対パスで全体置換、picked にする | キーワード保持、古い起点エラーだけ消す |
| 確定検証失敗 | 開いたまま理由を表示・読み上げ | 不変 | すべて保持 |
| 取消 | 閉じる | 不変 | すべて保持 |

確定時に対象が消失・非フォルダ・読取不能・GUI 対象外なら拒否する。処理中は重複確定を防ぎ、行選択の変更・移動・取消は有効にする。行選択を変えれば旧検証を失効させて新しい対象を確定でき、移動すれば新しい場所を読み込む。表示や検証の古い完了は、新しい選択や閉じた画面へ適用しない。

確定パスへ引用符やエスケープを加えない。`Photos ` の末尾空白は起点欄を編集しない間保持する。キーワード編集・子の再表示・取消では typed に戻さない。起点を直接編集すると従来の trim・ホーム展開等へ戻る。

検索開始時には入力元によらず再検証する。失敗は親へ表示し、新規検索を始めず、親を閉じない。

SC-058 の5ケースは、有効な検索開始が成立し、検索バーの起点と配下の既知の一致結果で選択場所を照合できれば合格とする。全走査の完了は要求せず、ルートを含め照合後の解除を許す。照合前に終了したケースは未確認とする。

## 既存検索・保存との関係

開く・移動・確定・取消で検索・ツリー・一覧・プレビューを操作しない。既存検索の進行・途中件数・外部変更の反映は続ける。新しい検索の有効な開始時だけ FR-085 で置換する。

選択による設定保存・履歴記録・最後のフォルダ更新はない。入力元は検索シート内だけの状態。画面を閉じて開き直すと既存の起点既定値へ戻る。

## アクセシビリティと表示

親のボタンは「フォルダを選択…」、子は検索起点を選ぶ画面であることを読み上げる。エラーは表示だけでなく announcementRequested で通知する。標準色・標準コントロールでダークモードと OS の設定を尊重し、処理中も取消へ到達可能にする。実際の読み上げ・子からのフォーカス復帰は手動検証する。
