# ファイル操作

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md` から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

- **FR-018**: ユーザーは、選択したファイルとフォルダ（FR-076）に対して「コピー」「名前の変更」「削除」「移動」「複製」を実行できなければ
  ならない。フォルダの操作はその中身を含めて行い、FR-019〜FR-027 をファイルと同じく適用する（削除はフォルダごとゴミ箱へ入れる）。
  「複製」は対象と同じフォルダに「名前 2」という名前で作成し（既にその名前がある場合は空いている連番まで進める）、
  既存のファイルを変更しないため確認モーダル（FR-022）の対象外とする
- **FR-019**: システムは、各操作を右クリックメニューとキーボードショートカットの両方から実行できるようにし、
  その割り当ては Finder に準じなければならない（コピー ⌘C、ペースト ⌘V、移動ペースト ⌥⌘V、
  名前の変更 Return、ゴミ箱へ ⌘Delete、複製 ⌘D）
- **FR-020**: ユーザーは、リストのファイルをツリー上のフォルダへドラッグ&ドロップして移動できなければならない。
  ドロップ時に Option キーを押している場合はコピーとする
- **FR-021**: 削除は、ファイルを OS のゴミ箱へ移動することで行わなければならない（完全削除は行わない）
- **FR-022**: システムは、コピー・名前の変更・削除・移動の実行前に、対象ファイルと操作内容を示す確認モーダルを
  表示しなければならない。キャンセルした場合はファイルシステムを変更してはならない
- **FR-023**: ユーザーは、設定で確認モーダルを表示しないように変更できなければならない。既定は「表示する」
- **FR-024**: 確認モーダルの省略は、コピー・削除（ゴミ箱へ入れる）と、お気に入りの削除（FR-064）にだけ
  適用されなければならない。名前の変更と移動は、設定に関わらず常に確認モーダルを表示しなければならない。
  複製（FR-018）は確認モーダルの対象外とし、設定にも影響されない。省略時の安全性は、削除が必ずゴミ箱経由で
  元に戻せること（FR-021）、コピーが元のファイルを変更しないこと、同名ファイルの上書きが常に確認されること
  （FR-025）で担保する。この方針は憲章 v1.1.0 原則 I の「確認または取り消し可能性」に従う
- **FR-025**: コピーまたは移動の操作先に同名ファイルが存在する場合、システムは確認モーダル設定に関わらず
  「置き換える / 両方残す / 中止」を選ばせなければならない。名前の変更で既存の名前（大文字小文字の違いのみを
  含む）を指定した場合は、衝突ダイアログを出さず、名前の検証エラーとして拒否しなければならない。
  複製は FR-018 の連番の規則に従い、この対象外とする
- **FR-026**: 操作が失敗した場合、システムは対象ファイル名と失敗理由を表示し、成功した分と失敗した分を
  区別して伝えなければならない
- **FR-027**: 操作の結果は、ツリー・リスト・プレビューに即座に反映されなければならない
- **FR-079**: ユーザーは、ツリーの通常のフォルダ（ホーム・マウント中のボリュームの下にある実際のフォルダ）を、その行の
  右クリックメニューの「ゴミ箱に入れる」と、そのフォルダをツリーで選択中の ⌘⌫（FR-019 と同じキー）で、中身ごと OS の
  ゴミ箱に入れられなければならない。確認モーダル（FR-022）・確認の省略（FR-023・FR-024）・ゴミ箱経由（FR-021）・失敗の
  表示（FR-026）・結果の反映（FR-027）はファイルリストのゴミ箱に入れる操作と同じとする。ホーム・ボリュームの最上位・
  「お気に入り」の見出し・お気に入りの項目は対象にしない（FR-064）。ファイルリストに表示中のフォルダ、またはその祖先を
  ゴミ箱に入れた場合は、削除したフォルダの親をツリーで選択し、ファイルリストを親の一覧に切り替え、プレビューを空にする
  （再生中の動画は FR-034 と同じく停止する）。キーボードフォーカスは移さない（⌘⌫ で削除したときはツリーに残り、右クリックメニューから削除したときは
  削除前にフォーカスがあったペインに残る）。選択した親は最後に選択していたフォルダ
  （FR-003）として保存する。表示中のフォルダと祖先・子孫の関係にないフォルダを削除した場合は、ツリーの選択とファイルリストの
  表示を変えない

## 主なエンティティ

- **ファイル操作**: 種類（コピー/移動/名前の変更/削除）、対象ファイル群、操作先、結果（成功/失敗と理由）

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS23**: **Given** ファイルリストでフォルダを選択した, **When** ⌘⌫ を押して確認モーダルで確定する, **Then** フォルダが中身ごと
  OS のゴミ箱へ移動し、ファイルリストとツリーから消える。プレビューは空のままで、キャンセルした場合は何も変わらない
- **US1-AS24**: **Given** ツリーで通常のフォルダを選択し、その内容をファイルリストに表示中, **When** ⌘⌫ を押す（またはそのフォルダの行を
  右クリックして「ゴミ箱に入れる」を選ぶ）、確認モーダルで確定する, **Then** フォルダが中身ごと OS のゴミ箱へ移動してツリーから消え、
  ツリーでは親フォルダが選択されてファイルリストは親の一覧に切り替わる（プレビューは空。⌘⌫ で削除したときはフォーカスはツリーのまま、右クリックメニューからではフォーカスを移さない）。
  キャンセルした場合は何も変わらない。ホーム・ボリュームの最上位・「お気に入り」の見出しでは右クリックメニューに
  「ゴミ箱に入れる」が出ず、⌘⌫ も何もしない

### US4 Finder と同じ感覚でファイルを整理する（P3）

- **US4-AS1**: **Given** ファイルを選択, **When** 右クリックする, **Then** コピー・ペースト・名前の変更・ゴミ箱に
  入れる等の操作メニューが表示される
- **US4-AS2**: **Given** ファイルを選択, **When** リネームを開始（Return キーまたはメニュー）して新しい名前を確定する,
  **Then** 確認後にファイル名が変更され、リストに反映される
- **US4-AS3**: **Given** ファイルを選択, **When** 削除（⌘+Delete またはメニュー）を実行する, **Then** 確認後に
  ファイルが OS のゴミ箱へ移動し、リストから消える
- **US4-AS4**: **Given** ファイルを選択, **When** コピー（⌘C）して別フォルダを選び、ペースト（⌘V）する,
  **Then** 確認後に複製が作成される
- **US4-AS5**: **Given** ファイル（複数可）を選択, **When** ツリー上の別フォルダへドラッグ&ドロップする,
  **Then** 確認後にそのフォルダへ移動する。ドロップ時に Option キーを押していれば移動ではなくコピーになる
- **US4-AS6**: **Given** 確認モーダルが表示されている, **When** キャンセルする, **Then** ファイルシステムには一切の
  変更が加わらない
- **US4-AS7**: **Given** 確認を省略する設定が有効, **When** コピーまたは削除を実行する, **Then** モーダルなしで即座に
  実行される（削除はゴミ箱へ移動するため元に戻せる）。名前の変更と移動では、設定に関わらず確認モーダルが
  表示される
- **US4-AS8**: **Given** 移動・コピー先に同名ファイルがある, **When** 操作を実行する, **Then** 設定に関わらず
  「置き換える / 両方残す / 中止」を選ぶダイアログが表示される

## エッジケース

- **EC-08**: 書き込み権限のない場所へのコピー・移動・リネーム・削除は失敗理由を表示し、部分的な変更を残さない
- **EC-14**: リネームで空の名前、使用できない文字、同名の既存ファイルを指定した場合はエラーを表示し確定しない
- **EC-15**: リネームで拡張子を変更しようとした場合は Finder と同様に確認する
- **EC-16**: フォルダを自分自身またはその配下へ移動・コピーしようとした場合（ファイルリストのフォルダをツリーの自分自身や配下の
  フォルダへドロップした場合を含む）は操作を拒否する（zip の中のディレクトリは FR-073 によりドラッグできない）
- **EC-17**: ファイルリストのフォルダをゴミ箱に入れた・移動した・名前を変更した場合、またはツリーでフォルダをゴミ箱に入れた場合（FR-079）、
  ツリーとファイルリストの該当項目にも即座に反映する（FR-027）。
  そのフォルダがお気に入りに登録されていれば、FR-067 に従って見つからない表示になる

## 成功基準

- **SC-006**: 確認モーダルでキャンセルした操作のうち、ファイルシステムに変更が残るものが 0 件
- **SC-008**: Finder の操作に慣れたユーザーが、説明なしでコピー・リネーム・削除・移動の4操作を初回で完了できる

## 前提

- **A-05**: 削除は Finder と同じくゴミ箱への移動とし、ゴミ箱から元に戻せる
- **A-07**: コピーと移動の操作方法（⌘C/⌘V、ドラッグ&ドロップ、Option キーでコピー）は Finder に準じる
