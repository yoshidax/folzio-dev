# ファイル操作

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md`
から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

- **FR-018**: ユーザーは、選択したファイルとフォルダ（FR-076）に対して「コピー」「名前の変更」「削除」「移動」「複製」
  を実行できなければならない。
  - フォルダの操作はその中身を含めて行い、FR-019〜FR-027
    をファイルと同じく適用する（削除はフォルダごとゴミ箱へ入れる）。
  - 「複製」は対象と同じフォルダに「名前 2」という名前で作成し（既にその名前がある場合は空いている連番まで進める）、
    既存のファイルを変更しないため確認モーダル（FR-022）の対象外とする
  - 拡張子を除いた名前の末尾にスペースと半角十進数字の連番がある場合は、その数の次から採番する。
  - 連番の桁数による整数上限を設けない。
  - 生成する連番の先頭ゼロは除く。
  - ゼロだけの連番は 0 として扱う。
  - 空き名の判定では大文字小文字を区別しない。
- **FR-019**: システムは、各操作を右クリックメニューとキーボードショートカットの両方から実行できるようにし、
  その割り当ては Finder に準じなければならない（コピー ⌘C、ペースト ⌘V、移動ペースト ⌥⌘V、名前の変更 Return、ゴミ箱へ
  ⌘Delete、複製 ⌘D）
- **FR-020**: ユーザーはアプリ内で、ツリーで選択した通常のフォルダ（複数可。FR-217・FR-218）、
  またはファイルリストで選択したファイル・フォルダを、
  ツリー上またはファイルリスト上の別のフォルダへドラッグ&ドロップできなければならない。
  - 通常は移動、ドロップ時に Option を押していればコピーとする。
  - ファイルリストはリスト形式・サムネイル形式の両方に対応し、
    ツリーとファイルリストのどちらでも複数選択はまとめて扱う。
  - 確認・衝突・エラーは FR-022〜FR-026 に従う。

- **FR-021**: 削除は、ファイルを OS のゴミ箱へ移動することで行わなければならない（完全削除は行わない）
- **FR-022**: システムは、コピー・名前の変更・削除・移動の実行前に、
  対象ファイルと操作内容を示す確認モーダルを表示しなければならない。
  - キャンセルした場合はファイルシステムを変更してはならない
- **FR-023**: ユーザーは、設定で確認モーダルを表示しないように変更できなければならない。既定は「表示する」
- **FR-024**: 確認モーダルの省略は、コピー（ツリーのフォルダへのペースト・ドロップによるコピーを含む）と、
  ファイルリストからの削除（ゴミ箱へ入れる）と、お気に入りの削除（FR-064）にだけ適用されなければならない。
  - 名前の変更（ツリーのフォルダの名前の変更（FR-103）を含む）と移動、
    およびツリーのフォルダをゴミ箱に入れる操作（FR-079）は、設定に関わらず常に確認モーダルを表示しなければならない。
  - 設定ウインドウの確認の項目には、名前の変更・移動・ツリーのフォルダをゴミ箱に入れる操作を、
    設定に関わらず常に確認する操作として示す（FR-223（window-layout.md））。
  - 複製（FR-018）とフォルダの新規作成（FR-209）、および作成直後のフォルダの名前の編集（FR-211）
    は確認モーダルの対象外とし、設定にも影響されない。
  - Folzio からアプリ外へドラッグし、ドロップ先のアプリが実行する移動（FR-344）は、確認モーダルの対象外とする。
  - 省略時の安全性は、削除が必ずゴミ箱経由で元に戻せること（FR-021）、コピーが元のファイルを変更しないこと、
    同名ファイルの上書きが常に確認されること（FR-025）で担保する。
  - この方針は憲章 v1.1.0 原則 I の「確認または取り消し可能性」に従う
- **FR-025**: コピーまたは移動の操作先に同名ファイルが存在する場合、システムは確認モーダル設定に関わらず
  「置き換える / 両方残す / 中止」を選ばせなければならない。
  - ただしコピー元と衝突先が同一の項目である場合は「置き換える」を選べないようにし、「両方残す / 中止」を選ばせる。
  - この例外はドラッグ以外のコピーにも適用する。
  - 「両方残す」の採番は FR-018 の連番規則に従い、既存項目を変更しない。
  - 名前の変更で同じ親フォルダにある別の項目の名前（大文字小文字の違いのみを含む）を指定した場合は、
    衝突ダイアログを出さず、名前の検証エラーとして拒否しなければならない。
  - 複製は FR-018 の連番の規則に従い、この対象外とする。
  - 元項目自身の名前の大文字小文字だけを変える変更は、ボリュームが大文字小文字を区別するかに関わらず許可し、
    入力した表記を保存する。
  - 別のディレクトリエントリは、同じ実体を指すリンクであっても別項目として扱う。

- **FR-026**: 操作が失敗した場合、システムは対象ファイル名と失敗理由を表示し、
  成功した分と失敗した分を区別して伝えなければならない
- **FR-027**: 操作の結果は、ツリー・リスト・プレビューに即座に反映されなければならない
- **FR-079**: ユーザーは、ツリーの通常のフォルダ（ホーム・マウント中のボリュームの下にある実際のフォルダ）を、
  その行の右クリックメニューの「ゴミ箱に入れる」と、ツリーで選択中の ⌘⌫（FR-019 と同じキー。「ファイル」「編集」
  メニューの「ゴミ箱に入れる」を含む）で、中身ごと OS のゴミ箱に入れられなければならない。
  - 対象は FR-217 に従い、複数のフォルダをまとめて1回の操作として扱う（FR-218）。
  - 右クリックメニューは、右クリックした行が選択外ならその行を対象にし、
    ツリーでそのフォルダを選択していなくても（ほかのフォルダを選択中でも）使える（A-21）。
  - どの手段でも、実行前に対象の件数と、
    各フォルダの名前とその絶対パス（同じ名前の別のフォルダと見分けられるようにする。6件以上のときは先頭の5件を示し、
    残りを件数で示す）、フォルダを中身ごとゴミ箱に入れる旨を示す確認モーダル（FR-022）を、
    確認モーダルの省略設定（FR-023）に関わらず必ず表示し、キャンセルした場合はファイルシステムを変更してはならない。
  - この確認モーダルには「今後この確認を表示しない」を出さない。
  - ゴミ箱経由（FR-021）・失敗の表示（FR-026）・結果の反映（FR-027）はファイルリストのゴミ箱に入れる操作と同じとする。
  - ホーム・ボリュームの最上位・「お気に入り」の見出し・お気に入りの項目は対象にしない（FR-064）。
  - ファイルリストに表示中のフォルダ、またはその祖先をゴミ箱に入れた場合は、
    削除したフォルダ（表示中のフォルダを含むもの）の親をツリーで選択し、ファイルリストを親の一覧に切り替え、
    プレビューを空にする（再生中の動画は FR-034 と同じく停止する）。
  - キーボードフォーカスは移さない（⌘⌫ で削除したときはツリーに残り、
    右クリックメニューから削除したときは削除前にフォーカスがあったペインに残る）。
  - 選択した親は最後に選択していたフォルダ（FR-003）として保存する。
  - 表示中のフォルダと祖先・子孫の関係にないフォルダだけを削除した場合は、ファイルリストの表示を変えない。
  - 削除後のツリーの選択は FR-219 に従う

- **FR-162**: ドラッグ元はツリーの通常フォルダ（FR-079 と同じ範囲。複数選択は FR-217・FR-218 に従う）または通常一覧・
  検索結果の実項目とする。
  - ホーム・ボリュームのルート、お気に入りの項目・見出し、`..`、zip 内の項目はドラッグ元にしない。
  - zip ファイル自体は通常のファイルとして扱う。
  - 検索結果のフォルダも対象とする（FR-083・FR-087（search.md））。
- **FR-163**: 宛先はツリーの実在するフォルダ行（ホーム・ボリュームのルート、利用可能なお気に入りを含む）、
  通常一覧・検索結果の実フォルダ項目、または通常一覧の背景（表示中のフォルダ、FR-349）とする。
  - 通常一覧のファイル・zip ファイルの行・アイコンの上は、背景と同じく表示中のフォルダとする（FR-349）。
  - お気に入り見出し、見つからないお気に入り、`..`、zip 内、検索結果の背景と検索結果のファイル、
    ツリーの行間にはドロップできない。
  - アプリ外からのドラッグも同じ宛先で受け付ける（FR-345）。
  - アプリ外へのドラッグは FR-344 に従う。
- **FR-164**: システムは現在の操作と対象全体について宛先を検証し、有効なフォルダ行・項目を視覚的に強調する。
  - Option の変更に追従して操作種別と有効性を更新し、ドロップ時にも再検証する。
  - EC-16・EC-121 の不正な操作は受け付けない。
- **FR-165**: 操作後は FR-027 に従いツリー・リストを更新し、移動された選択項目を元一覧から外す。
  - プレビュー対象が消えたらプレビューを空にして動画を停止する。
  - コピー・キャンセル・失敗した項目の選択とプレビューは保つ。
  - 部分成功では成功分だけ反映する。
  - ツリーから表示中のフォルダまたは祖先を移動した場合は EC-123 に従う。
  - 検索結果は FR-087 および EC-123 に従う。
- **FR-183**: システムは、次の場合に「パス名をコピー」を淡色にして選べなくしなければならない。
  - ファイルリストで複数の行を選択している、ツリーで複数の行を対象にしている（FR-217）、`..` の行を対象にしている、
    zip の中の項目（メディア・ディレクトリ・`..`）を対象にしている（FR-073）、
    見つからないお気に入りの項目を対象にしている、ツリーの「お気に入り」の見出しを選択中、
    またはキーボード操作でツリーに選択がない、名前の変更中（FR-102）
- **FR-184**: ユーザーは、キーボードから「編集 > パス名をコピー」（⌥⌘C、Finder と同じ割り当て）で、
  フォーカスのあるペインの選択中の項目に FR-181〜183 と同じ規則でパスをコピーできなければならない。
  - ファイルリストにフォーカスがあるときはファイルリストの選択、ツリーにフォーカスがあるときはツリーの選択を対象にし、
    プレビューにフォーカスがあるとき、ペインの表示切り替えで対象のペインを隠している間（FR-092）、フルスクリーン中、
    スライドショー実行中は無効にする
- **FR-185**: 「パス名をコピー」はファイルシステムを変更せず、確認モーダルを出さず、ファイルリスト・ツリー・
  プレビューの選択・フォーカス・スクロール・再生状態を変えない。
  - 成功しても結果の表示を出さない

- **FR-208**: ユーザーは、次のどの手段でも新しいフォルダを作成できなければならない。
  - （1）ツリーのフォルダの行（通常のフォルダ・ホーム・マウント中のボリュームの最上位・利用可能なお気に入りの項目）
    の右クリックメニューの「新規フォルダ」。
  - 右クリックした行のフォルダ（お気に入りの項目では登録したフォルダ）の中に作り、ツリーの選択は変えない（A-21）。
  - （2）ファイルリストの背景（リスト形式・サムネイル形式で、どの項目にも当たらない位置）
    の右クリックメニューの「新規フォルダ」。
  - 表示中のフォルダの中に作る。
  - （3）「ファイル > 新規フォルダ」と ⇧⌘N（Finder と同じ割り当て。FR-019）。
  - ファイルリストにフォーカスがあるときは表示中のフォルダの中に、
    ツリーにフォーカスがあるときは選択中のフォルダ（お気に入りの項目では登録したフォルダ）の中に作る
- **FR-209**: 新しいフォルダの名前は既定名「名称未設定フォルダ」（英語: untitled folder）としなければならない。
  - 作成先に同じ名前の項目（大文字小文字の違いのみ・隠し項目・ファイルを含む）がある場合は、FR-018
    の複製と同じく「名称未設定フォルダ 2」から空いている番号まで進める。
  - 作成は既存の項目を変更しないため、確認モーダル（FR-022）を出さず、確認モーダルの省略設定（FR-023）にも影響されない
- **FR-210**: 作成後、システムは新しいフォルダの行で名前の編集を次のとおり始めなければならない。
  - （1）ファイルリストから作成した場合（背景の右クリックメニュー、
    またはファイルリストにフォーカスがあるときのメニューと ⇧⌘N）:ファイルリストで新しい行だけを選択し、
    並べ替えの位置で行全体が見えるまで必要最小限のスクロールを行い、その行で名前の編集を始める。
  - フォルダの行を選んだときと同じくプレビューは空にし、再生中の動画は止める（FR-076）。
  - キーボードフォーカスはファイルリストのまま。
  - （2）ツリーで通常のフォルダ・ホーム・ボリュームの最上位を作成先にした場合: 作成先をツリーで展開し、
    新しい行が見えるまで必要最小限のスクロールを行い、その行で名前の編集を始める。
  - ツリーの選択・ファイルリストの表示と選択・プレビュー・最後に選択していたフォルダ（FR-003）は変えない（FR-103
    と同じ）。
  - キーボードフォーカスはツリーにする。
  - （3）お気に入りの項目を作成先にした場合: お気に入りの項目は子の行を持たない（FR-063）ため、
    ファイルリストが登録したフォルダを通常の一覧として表示中なら（1）
    と同じくファイルリストの新しい行で名前の編集を始め、キーボードフォーカスをファイルリストに移す。
  - 表示していなければ、名前の編集は始めず既定名で作成するだけとする。
  - ツリー下側の実際の階層の展開・選択は変えない（FR-063）
- **FR-211**: 作成直後の名前の編集は、編集の始め方と終え方、名前の検証をフォルダの名前の変更（FR-103・EC-14・EC-53）
  と同じとする。
  - ただし確認モーダルは、FR-024 に関わらず出さない（作ったばかりの空のフォルダに名前を付けるため）。
  - Esc で取り消した場合、確定した名前が空（前後の空白だけを含む）または既定名と同じ場合は、
    何もせずフォルダを既定名のまま残す。
  - 検証エラーのときはエラーを表示し、フォルダを既定名のまま残す。
  - 名前の変更に失敗した場合は FR-026 に従って表示する。
  - 名前の編集を取り消しても作成は取り消さない
- **FR-212**: 次の場合、「新規フォルダ」（右クリックメニュー・「ファイル」メニュー）を淡色にして選べなくし、⇧⌘N
  は何もしない。
  - ファイルリストを作成先にするとき: zip の中を表示中（FR-073）、検索結果を表示中、表示中のフォルダが見つからない・
    読み込めない。
  - ツリーを作成先にするとき: 「お気に入り」の見出しを選択中、選択がない、見つからないお気に入りの項目（FR-067）。
  - 共通: 名前の変更中（FR-102）、フルスクリーン中、スライドショー実行中、プレビューにフォーカスがあるとき、
    ペインの表示切り替えで作成先のペインを隠している間（FR-092）。
  - 書き込みできない場所は事前に無効にせず、実行して EC-141 に従う
- **FR-214**: 作成の結果は、ツリー・ファイルリストに即座に反映しなければならない（FR-027）。
  - 作成先がファイルリストに表示中なら新しい行を並べ替えの位置に加え、
    ツリーで作成先が展開済みなら新しい行を兄弟の並び順の位置に加え、開閉の三角の有無を更新する（FR-054）。
  - 検索結果は新しく現れた項目を加えない従来の規則（FR-087）に従う。
  - 操作の履歴（FR-107）と最後に選択していたフォルダ（FR-003）は変えない
- **FR-219**: ツリーからの移動とゴミ箱に入れる操作で1件以上が成功した後、ツリーは、
  主の行（FR-216。単一選択ならその行）1つだけを選択した状態にしなければならない。
  - ただし、ファイルリストに表示中のフォルダ、またはその祖先を移動・削除した場合は、FR-079・EC-123
    に従って表示を切り替えた後のフォルダの行1つを選択する（主の行がお気に入りの項目でも、
    この場合は切り替え後の行を選択する）。
  - 主の行が折りたたみで隠れている場合（EC-148）は、ファイルリストからの同期（FR-078）
    と同じく祖先を展開してから選択する。
  - コピー・キャンセル・すべて失敗した場合は、ツリーの選択とファイルリストの表示を変えない。
  - キーボードフォーカスは FR-079 と同じく移さない

- **FR-344**: Folzio のビューから始めたドラッグをアプリ外へドロップするとき、
  システムはドロップ先にコピーと移動を許可しなければならない。
  - ドラッグ元の範囲は FR-162 と同じ（ツリー・リスト形式・サムネイル形式・検索結果）。
  - どちらの操作にするか（修飾キー、同じボリュームかどうか）はドロップ先のアプリが決め、
    Folzio は確認モーダルを表示しない。
  - Dock のゴミ箱へのドラッグには対応しない。
  - Dock はドラッグ元に削除を任せるため、削除の操作を許可しない。
  - Folzio はドラッグ元として項目を削除しない。
  - FR-024 の移動の確認は、アプリ外のドロップ先が実行する移動には適用しない。
- **FR-345**: システムは、アプリ外からのドラッグを、FR-163 のアプリ内のドラッグと同じ宛先で受け付けなければならない。
  - 宛先は、ツリーの実在するフォルダ行（ホーム・ボリュームの最上位を含む）、利用可能なお気に入りの項目
    （登録したフォルダ）、リスト形式のフォルダの行、サムネイル形式のフォルダのアイコン、検索結果のフォルダ、
    通常の一覧の背景（表示中のフォルダ、FR-349）とする。
  - お気に入りの見出し、見つからないお気に入り、`..`、zip の中、検索結果の背景とファイル、
    ツリーの行間にはドロップできない。
  - 有効な宛先は FR-164 と同じく視覚的に強調し、修飾キーの変更に追従して操作の種類と有効性を更新し、
    ドロップ時にも再検証する。
- **FR-346**: アプリ外から file URL を受け取ったとき、システムは Finder と同じ規則で、
  移動かコピーかを決めなければならない。
  - 修飾キーがなければ、受け取るすべての項目が宛先と同じボリュームにあるときは移動、それ以外はコピー（EC-237）。
  - ドロップ時に Option を押していればコピー、⌘ を押していれば移動とする。
  - Option と ⌘ を同時に押したとき（Finder ではエイリアスの操作）は、OS が絞ったドラッグ元の許可に従う。
  - コピーも移動も許可されていなければ、宛先を有効にしない（A-206）。
  - Finder はこのときもコピーを許可するため、Finder からの Option と ⌘ の同時はコピーになる。
  - ドラッグ元のアプリが許可しない操作は EC-238 に従う。
  - 自分自身・配下への転送、親と同じ場所への移動、フォルダと配下の同時の転送は、
    EC-16・EC-121 と同じく全体を拒否する。
- **FR-347**: アプリ外から受け取る移動・コピー・画像・動画の保存（ドラッグとペースト）は、
  既存のファイル操作の確認（FR-022〜FR-024）、衝突（FR-025）、 失敗の表示（FR-026）、結果の反映（FR-027・FR-165）
  に従わなければならない。
  - 移動は確認モーダルの省略設定に関わらず確認し、コピーと画像・動画の保存は省略設定に従う（FR-024）
  - 受け取った項目の元の場所が Folzio に表示中のフォルダにある場合、移動の結果は EC-13（overview.md）
    と同じく反映する
  - 画像・動画の保存の確認モーダルと衝突のダイアログには、宛先に作るファイルの名前を示す（一時的なフォルダの場所は示
    さない）
- **FR-348**: システムは、アプリ外からのドラッグのうち、file URL、ファイルの書き出しの約束、
  画像データのどれかを持つものだけを受け付けなければならない。
  - どれも持たないドラッグ（URL・文字列・HTML だけのもの）は宛先を有効にしない
  - ファイルの書き出しの約束は、ドラッグ元が示す種類が、画像、対応形式の動画（FR-362）、または不明（種類を示さない、
    データなど一般的な種類だけを示す）のときだけ受け付ける
  - 画像・動画でない種類（PDF・文書など）だけを示した約束は、宛先を有効にしない（書き出させてから拒否しないため。
    最後は中身で判定する。FR-357）
  - 直接の画像データはPNG・JPEG・TIFFを対象とする。書き出しの約束から受け取る画像の形式はFR-357に従う
  - 複数を持つときは EC-241 の順に1つを選ぶ
  - アプリ外からのドラッグを受け取るために、ネットワークへ通信しない（FR-367）
- **FR-349**: ユーザーは、ファイルリスト（リスト形式・サムネイル形式）に通常のフォルダの一覧を表示しているとき、
  アプリ内とアプリ外からのドラッグを一覧の背景へドロップして、表示中のフォルダへ移動・コピーできなければならない。
  - 背景は、どの項目にも当たらない位置、リスト形式の行間、
    フォルダでない項目（メディアファイル・zip ファイル）の行・アイコンの上とする（A-207）。
  - フォルダの行・アイコンの上は、そのフォルダを宛先にする（FR-163）。
  - `..` の行は宛先にしない。
  - 検索結果を表示中（FR-087（search.md））、zip の中を表示中（FR-073（zip.md））、
    表示中のフォルダが見つからない・読み込めないときは、背景を宛先にしない。
  - 移動かコピーかは、アプリ内のドラッグは FR-020、アプリ外からのドラッグは FR-346 に従う。
  - 確認・衝突・失敗・反映は FR-347（FR-022〜FR-027）に従う。
  - 表示中のフォルダの項目を同じ一覧の背景へ移動するのは、親と同じ場所への移動として拒否する。
  - Option のコピーは EC-121 に従い、衝突を示す（「両方残す / 中止」）。
  - 背景が宛先のときは、個々の項目ではなく一覧全体を強調する（FR-164）。

### 画像・動画の取り込み

- **FR-364**: EC-241でファイルの書き出しの約束を選んだとき、システムは事前作成した一時的なフォルダへ書き出しを要求し、
  検査済みファイルを宛先へ保存しなければならない。
  - 起動ディスクのOSの一時領域に、操作ごとの受け取り用と検査用のフォルダを背景で事前作成する。
    ドラッグ元へ知らせるのは受け取り用フォルダだけとする
  - 同じドラッグの全ての約束へ共通の受け取り用フォルダを渡し、ドロップ処理を返す前に書き出しを要求する。
    完了は非同期に待つ
  - 準備済みのフォルダを操作ごとに1組確保して補充する。準備できていない間は約束のドラッグを受け付けず、ホバー・
    ドロップのUIスレッドで作成しない
  - 操作の種類はコピーとして扱う（確認の省略設定・確認モーダルの表示・元の項目を消さないこと）
  - 受け取り通知でファイルが読める間に、通知ごとの別名で検査用フォルダへ複製する。
    検査と保存はその複製だけを対象とする（FR-357）
  - 複製はAPFSでは内容を共有する複製とし、拡張属性を保つ。共有できない場合は通常の複製とする
  - 検査済みファイルと宛先が同じボリュームなら移動、異なるならコピーする。
    外部ディスクへは一時領域と宛先の両方に容量が必要となる
  - 複製した後の元のファイルは使わず、一時的なフォルダとともに消す
  - ファイル名と形式はドラッグ元のアプリが書き出したものを使う（FR-360で名前を直す場合を除く）。
    同じ実体パスの再利用はEC-243に従う
  - 確認・衝突でキャンセル・中止した場合、書き出しが失敗した場合、保存が終わった場合のどれでも、
    一時的なフォルダとその中身を消す
  - 宛先へ直接書き出させない（確認のキャンセルと衝突の「両方残す」を守るため）
  - 受け取り取消時は保存と進捗の行を直ちに止め、書き出し中の受け取り先と受信オブジェクトは完了通知まで保持してから掃
    除する
  - 取消後の保持中もFR-355・FR-359の期限・容量を監視し、制限に達した場合は完了前でも掃除する
  - 打ち切り後の通知で一時領域が再生成された場合も保存せず、再度掃除する

- **FR-365**: アプリ外からfile URLがなく、EC-241で画像データを選んだとき、
  システムは画像をPNG形式のファイルとして宛先へ保存しなければならない。
  - 項目ごとにPNG、JPEG、TIFFの順に、項目に実際にある型を1つ選ぶ。全体の型一覧に合成された型だけでは選ばない
  - データが PNG のときは、変換せずにそのまま書く（複数の画像を含む PNG も、すべての画像を残す）
  - ほかの形式（TIFF など）のときは、PNG に変換して書く
  - 複数の画像を含むデータ（複数ページの TIFF など）を変換するときは、1 枚目の画像だけを使う
  - 保存はFR-350と同じく一時的なフォルダに書き、宛先と同じボリュームなら移動、異なるならコピーする。
    操作はコピーとして扱う

- **FR-366**: FR-365 で保存するファイルの名前は、同じドラッグ・クリップボードにある画像の URL（file URL でないもの）
  の末尾の名前とし、拡張子を `.png` にしなければならない。
  - 末尾の名前は、パーセントエンコードを解き、元の拡張子を除いて `.png`
    を付ける（`https://example.com/a/cat.jpg?w=1` → `cat.png`）
  - URL がない、または末尾の名前が FR-357 の名前の条件を満たさない場合は、「画像 2026-11-08 13.45.12.png」（英語:
    `Image 2026-11-08 13.45.12.png`）の形で、 ドロップ・ペーストした日時から名前を付ける
  - 日時はローカルのタイムゾーンで、数字は ASCII にする
  - 名前の接頭辞（「画像」・`Image`）は表示言語に従う
  - 名前を取る URL は、スキームが `http`・`https` のものだけとする（`data:`・`blob:` などの URL
    の末尾は名前にならないため、日時の名前にする）
  - URL から名前を取るために、その URL へ通信しない（FR-367）
  - 操作の中で名前が重なる場合は EC-243、宛先に同じ名前がある場合は FR-025に従う

- **FR-367**: システムは、画像の受け取り（ドラッグ・ペースト）のために、ネットワークへ通信してはならない。
  - ドラッグ・クリップボードにある URL は、名前を取るための文字列としてだけ扱い、開かない・取得しない・解決しない
  - HTML・リッチテキストなどの書式付きのデータは読まない
  - ファイルの書き出しの約束で、ドラッグ元のアプリ（ブラウザ）が画像を取得するために通信する場合は、
    そのアプリの動作であり、Folzio は通信しない

- **FR-354**: ユーザーは、一般クリップボードにfile URLがなく画像データがあるとき、
  既存のペーストで画像をPNGファイルとして保存できなければならない（FR-365〜FR-367・FR-356〜FR-361）。
  - 使うデータの順はfile URL、画像データとする（EC-241）。一般クリップボードの約束は使わず、
    約束だけではペーストを有効にしない
  - file URLの写真・動画は既存のコピー経路で保存し、元の形式の保持は保証しない。
    画像表現だけを受け取った場合は動画を取得したものと扱わない
  - 対象のペーストは、ファイルリストの ⌘V・右クリックの「ペースト」（表示中のフォルダへ）、ツリーの
    ⌘V（選択した通常のフォルダへ）・右クリックの「ここにペースト」とする
  - ペーストできる場所と条件（zip の中・検索結果・お気に入りの項目・複数の行の選択中・名前の編集中は無効）は、
    file URL のペーストと同じにする
  - 移動ペースト（⌥⌘V・「移動ペースト」・「ここに移動ペースト」）は、file URL がないときは無効にする（Folzio
    が消す元の項目がないため）
  - 「ペースト」「ここにペースト」のメニュー項目は、クリップボードにfile
    URLまたはFR-351の画像データがあるときに有効にする
  - 画像データは、コピー元のアプリと、ほかに文字列などがあるかを問わない（表計算のセルのコピーに含まれる絵も保存する。
    A-214）
  - メニューの有効・無効を決めるときは、クリップボードにあるデータの種類だけを調べ、データの中身を読まない
  - クリップボードの中身は、ユーザーがペーストを実行したときだけ読む

- **FR-355**: システムは、ファイルの書き出しの約束の書き出しを、ドロップから 60 秒で打ち切らなければならない。
  - ドラッグ元が動画（FR-362）の書き出しを約束したときは、打ち切りを 10
    分とする（約束の種類はドラッグ元が示すものを使う）
  - 種類が不明な約束（FR-348）は、画像と同じく 60 秒とする
  - 打ち切りまでに書き出されなかった約束は失敗として扱い、EC-248 に従う
  - 打ち切った後に書き出されたファイルは、宛先へ入れず、一時的なフォルダごと消す
  - 書き出し・変換・一時的なフォルダへの書き込みは UI スレッドで行わない
  - 画像データの取得だけはドロップ・ペーストの実行中に、選んだ型をUIスレッドで同期的に読む。変換・
    書き込みをUIスレッドへ持ち込まない
  - A-212の実測では生成した200 / 256 MB TIFFを含め0.2秒未満だったため採用する。
    遅延提供される大きなデータは未測定であり、0.2秒超を観測した場合は取得方法を見直す

- **FR-356**: アプリ外からドラッグで受け取る画像・動画の保存は、ドラッグ元が現在の修飾キーの状態で
  コピーを許可するときだけ受け付け、コピーとして示し、コピーとして行わなければならない。
  - 対象はファイルの書き出しの約束と画像データとし、動画はFR-362に従う
  - 修飾キーによってコピーの許可が失われた場合も、宛先を有効にせず、保存しない
  - 宛先はFR-345と同じ範囲とし、強調と再検証もFR-345に従う
  - 画像データのペーストは、FR-354に従ってコピーとして行う

- **FR-357**: システムは、アプリ外から受け取る画像・動画のファイル（書き出されたファイルと、
  画像データから作るファイル）を、次の条件を満たすものだけ宛先へ保存しなければならない。
  - 書き出されたファイルは、共通の受け取り用フォルダ（FR-364）の直下にある通常のファイルであること（フォルダ・
    パッケージ・シンボリックリンク・エイリアスでないこと）
  - 共通の受け取り用フォルダの外を指すファイルは受け取らない。親の確認と複製は受け取り通知でファイルが読める間に行う
  - 検査と保存は、検査用のフォルダ（FR-364）に作った複製に対して行う（ドラッグ元が開いたままのファイルに後から書き込
    んでも、検査した中身が変わらないため）
  - 中身を画像または動画として判別できること（拡張子の偽装への対策。拡張子ではなく中身で判定する。
    中身の先頭の形式の情報と、含む画像の数だけを調べ、 画像を展開せず、動画を再生しない）
  - 中身から判別した形式が、画素を持つ画像（JPEG・PNG・GIF・WebP・HEIC・AVIF・TIFF・BMP など。Folzio
    の非対応形式の画像を含む）、 または FR-362 の動画であること
  - SVG・EPS・PostScript・PDF など、スクリプトや命令を含められる形式は、
    中身がそう判別されたら保存しない（拡張子だけが `.svg` で中身が PNG のものは、FR-360 で `.png` に直して保存する）
  - 名前の条件: 名前の変更の検証の文字の規則（空でない、`/` と `:` を含まない、`.` で始まらない）を満たし、
    制御文字と文字の向きを変える書式の文字を含まず、 拡張子を含めて UTF-8 で 200 バイト以下であること
  - 200 バイトは、EC-243 と FR-025 の「両方残す」で連番を付けても、ファイル名の上限の 255
    バイトに収めるための値である
  - 名前の条件は、宛先に同じ名前の項目があるかを含まない（同じ名前は FR-025 の衝突として扱う）
  - 拡張子は条件にしない。拡張子は FR-360 で中身の形式のものに直す（`photo.jpg.command` も、中身が JPEG なら JPEG
    の拡張子で保存され、中身が画像でなければ保存しない）
  - 名前の条件だけを満たさないファイルは、FR-360 の名前を付けて保存する
  - ほかの条件を満たさないファイル・データは保存せず、FR-026 と同じく名前と理由を表示する
    （「画像として読めません」「この形式の画像は保存できません」「この形式の動画は保存できません」など）

- **FR-358**: システムは、アプリ外から受け取って保存した画像・動画のファイルに、
  インターネットから入手したことを示す印（quarantine 属性）を付けなければならない。
  - 書き出されたファイルに印があれば、それを引き継ぐ
  - 印がない書き出されたファイルと、画像データから作るファイルには、Folzio が印を付ける
  - Folzio が付ける印には、アプリ名（Folzio）と保存した日時だけを記録し、URL（ページ・画像の場所）は記録しない
  - 印は、宛先へ移す前に、一時的なフォルダの中で付ける（印のないファイルが宛先に現れないため）
  - file URL の移動・コピー（FR-346）は、今と同じく元の項目の属性を変えない
  - 宛先のボリュームが拡張属性を保存できない場合は、印なしで保存し、失敗にしない（安全性は FR-357 で保つ。A-218）

- **FR-359**: システムは、アプリ外から受け取る画像データと書き出されたファイルの大きさを制限しなければならない。
  - 1件の画像データ、または中身が画像と判別された1件の書き出されたファイルが 256 MB を超える場合は保存しない
  - 中身が動画（FR-362）と判別された書き出されたファイルの上限は 4 GB とする
  - 保存するかどうかの上限は、中身から判別した種類で決め、ドラッグ元が示す種類では決めない（動画と名乗った 3 GB
    の画像は保存しない）
  - 書き出しを待つ間も、受け取り用フォルダの大きさ（検査用の複製を含めない）を 1 秒ごとに調べ、
    約束ごとの上限（ドラッグ元が示す種類で、画像 256 MB・動画 4 GB）の合計を超えたら、
    その操作の約束をすべて失敗として打ち切り、一時的なフォルダを消す
  - ドラッグ元が示す種類は、待つ時間（FR-355）と書き出し中の見張りにだけ使う。種類が不明な約束は、
    見張りでも画像の値（256 MB）を使う
  - PNG 以外のデータを PNG に変換するのは、1 枚目の画像の画素数が 1 億以下のときだけとし、超える場合は保存しない
  - 画素数は、画像を展開する前に、画像の情報から調べる
  - 書き出されたファイルと PNG のデータは展開しないので、画素数の上限を適用しない
  - 保存しなかったデータ・ファイルは、FR-026 と同じく理由を表示する

- **FR-360**: システムは、書き出されたファイルの拡張子が、FR-357 で中身から判別した形式のものでない場合、
  拡張子を中身の形式のものに直して保存しなければならない。
  - 最後の拡張子を中身の形式の拡張子に置き換え、拡張子がなければ付ける
  - 例: 中身が JPEG のとき、`cat.png` → `cat.jpg`、`photo.jpg_large` → `photo.jpg`、`download` → `download.jpg`、
    `photo.jpg.command` → `photo.jpg.jpg`
  - 拡張子の大文字と小文字の違いだけのとき（`cat.JPG` と JPEG）は直さない
  - 同じ形式の別の拡張子は、Folzio の対応形式の拡張子（FR-039（overview.md）。`.jpeg` と `.jpg` など）のときだけ残す
  - それ以外の同じ形式の拡張子（`.jfif`・`.jpe` など）は、形式の標準の拡張子に直す（Folzio
    で表示できるようにするため）
  - 書き出されたファイルの名前が FR-357 の名前の条件を満たさない場合は、中身の形式の拡張子で FR-366
    の日時の名前を付けて保存する
  - FR-365 の画像データも同じく中身で判別し、PNG と判別できたものだけを変換せずに書き、ほかの画素を持つ画像は PNG
    に変換し、判別できないものは保存しない（EC-244）
  - 直した名前・付けた名前は、確認モーダルと衝突のダイアログに、宛先に作る名前として示す

- **FR-361**: システムは、作った一時的なフォルダの場所を記録し、操作が終わって消したら記録から外し、
  起動したときに記録に残る一時的なフォルダを消さなければならない。
  - 消すのは記録した場所だけとし、ほかの場所は探さない
  - 消す前に、その場所が記録したときと同じボリューム（ボリュームの識別子で確かめる）にあり、OS
    が一時ファイルのために用意する場所 （FR-364 の起動ディスクの場所を含む）の中の、Folzio
    が付けた名前の形のフォルダであることを確かめる。確かめられなければ消さずに記録から外す
  - 一時的なフォルダは、中身（共通の受け取り用フォルダ・検査用のフォルダを含む）とともにフォルダそのものを消し、
    ゴミ箱を経ない（ユーザーの項目を含まないことを、上の確認で保つ）
  - 記録した場所のボリュームがつながっていないときは、記録を次の起動へ持ち越す
  - 記録してから 30 日を過ぎたものは、消さずに記録から外す
  - 待機用のフォルダも作成直後から記録する。起動時の残存フォルダの掃除が終わってから新しいフォルダを事前作成する
  - 記録は設定ではない（設定の書き出し・初期化の対象にしない）。保存先は plan で決める

- **FR-362**: システムは、アプリ外から受け取るファイルの書き出しの約束のうち、Folzioの対応形式の動画を、
  画像と同じ規則（FR-364・FR-357〜FR-361）で宛先へ保存しなければならない。
  - 対応する動画の形式はMP4・QuickTimeとする（FR-039（overview.md））
  - 動画は、中身を動画として判別できるものだけとし、形式の情報だけを読んで再生しない
  - 対応形式でない動画（AVI・MKVなど）は保存せず、FR-026と同じく理由を表示する
  - 画像データ（FR-365）とクリップボードの画像データには動画を含まない
  - 大きさの上限はFR-359、書き出しの打ち切りはFR-355の動画の値を使う

- **FR-363**: システムは、ファイルの書き出しの約束の書き出しが 2 秒で終わらないとき、
  進み具合を示す小さなパネルを表示し、ユーザーが受け取りを取り消せるようにしなければならない。
  - パネルには、約束の件数、書き出し済みの件数、書き出された大きさの合計を示す
  - パネルはモーダルにせず、キーボードのフォーカスを奪わない（ほかの操作を続けられる。EC-248）
  - 取り消しは、パネルの「取り消す」ボタンと、⌘.（macOS の標準の取り消しのキー）で行う
  - ⌘. は、受け取りを待っている操作があるときだけ効き、複数あるときは最後に始めた操作を取り消す
  - 名前の編集欄・検索のシート・確認モーダル・ダイアログなど、⌘. で取り消せるものが開いているときは、⌘.
    をそちらに使い、受け取りは取り消さない
  - 取り消した操作は、宛先に何も作らず、一時的なフォルダを消し、失敗の表示を出さない
  - 書き出しが終わったらパネルを閉じ、続けて確認モーダル（FR-347）を表示する
  - ⌘. は、ショートカットの割り当て（FR-256（window-layout.md））で変えられない標準のキーとして扱う
  - ⌘. は、ショートカット一覧（FR-202）の「選択とファイル操作」に「受け取りを取り消す」として載せる（A-124）
  - 取消後の一時領域の掃除はFR-350に従い、未完了の書き出し先を取消直後に消さない

## 主なエンティティ

- **ファイル操作**: 種類（コピー/移動/名前の変更/削除/フォルダの作成）、対象ファイル群、操作先、結果（成功/失敗と理由）
- **作成先**: 新しいフォルダを作る実フォルダ。
  - 右クリックした行・表示中のフォルダ・ツリーで選択中のフォルダのいずれか。
  - お気に入りの項目では登録したフォルダ
- **作成の起点**: ツリー（通常のフォルダ・お気に入りの項目）またはファイルリスト。
  - 作成後に名前の編集を始める場所（FR-210）を決める
- **アプリ外からのドラッグ**: Folzio 以外のアプリ（または Folzio に登録していないビュー）から始まったドラッグ。
  - 受け付けるデータは file URL、ファイルの書き出しの約束、画像データの3種類で、この順に1つを選ぶ（FR-348・EC-241）
- **受け取りの操作**: 移動・コピー・画像の保存のどれか。
  - file URL は、宛先、対象の項目のボリューム、修飾キー、ドラッグ元が許可する操作で決まる（FR-346）
  - 画像の保存は、常にコピーとして扱う（FR-356）
- **ドロップ先のアプリ**: Folzio からアプリ外へのドラッグを受け取るアプリ（Finder、ブラウザなど）。
  - 移動とコピーのどちらにするかを決める

- **ファイルの書き出しの約束**: ドラッグ元のアプリが、ドロップ中の要求に応じて、
  受け取り側が指定した場所へ非同期にファイルを書き出す仕組み。
  - ファイルの名前と中身はドラッグ元が決めるため、FR-357〜FR-360 で検査する

- **画像データ**: ドラッグ・クリップボードにある、ファイルになっていない画像（PNG・TIFF など）。
  - 同じドラッグ・クリップボードに画像の URL があることがある（FR-366）

- **一時的なフォルダ**: 起動ディスクのOSの一時領域で事前作成し、受け取り用と検査用を持つ操作ごとのフォルダ。
  - 保存するファイルは宛先と同じボリュームなら移動、異なるならコピーし、操作の終わりに必ず消す（FR-364）

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS23**: **Given** ファイルリストでフォルダを選択した,
  - **When** ⌘⌫ を押して確認モーダルで確定する,
  - **Then** フォルダが中身ごと OS のゴミ箱へ移動し、ファイルリストとツリーから消える。プレビューは空のままで、
    キャンセルした場合は何も変わらない
- **US1-AS24**: **Given** ツリーで通常のフォルダを選択し、その内容をファイルリストに表示中,
  - **When** ⌘⌫ を押す（またはそのフォルダの行を右クリックして「ゴミ箱に入れる」を選ぶ）、確認モーダルで確定する,
  - **Then** フォルダが中身ごと OS のゴミ箱へ移動してツリーから消え、
    ツリーでは親フォルダが選択されてファイルリストは親の一覧に切り替わる（プレビューは空。⌘⌫
    で削除したときはフォーカスはツリーのまま、右クリックメニューからではフォーカスを移さない）。
    キャンセルした場合は何も変わらない。ホーム・ボリュームの最上位・「お気に入り」
    の見出しでは右クリックメニューに「ゴミ箱に入れる」が出ず、⌘⌫ も何もしない
- **US1-AS44**: **Given** ツリーでフォルダ A を選択し、確認モーダルの省略設定（FR-023）がオン,
  - **When** 別のフォルダ B の行を右クリックして「ゴミ箱に入れる」を選ぶ,
  - **Then** B のフォルダ名と絶対パスを示す確認モーダルが必ず表示され、確定すると B が中身ごとゴミ箱に入り、
    ツリーの選択はフォルダ A のまま変わらない。キャンセルすると何も変わらない。A を選択中に ⌘⌫ を押した場合と、
    「ファイル」「編集」メニューの「ゴミ箱に入れる」を選んだ場合も、省略設定に関わらず A
    のフォルダ名と絶対パスを示す確認モーダルが表示される

### US4 Finder と同じ感覚でファイルを整理する（P3）

- **US4-AS1**: **Given** ファイルを選択,
  - **When** 右クリックする,
  - **Then** コピー・ペースト・名前の変更・ゴミ箱に入れる等の操作メニューが表示される
- **US4-AS2**: **Given** ファイルを選択,
  - **When** リネームを開始（Return キーまたはメニュー）して新しい名前を確定する,
  - **Then** 確認後にファイル名が変更され、リストに反映される
- **US4-AS3**: **Given** ファイルを選択,
  - **When** 削除（⌘+Delete またはメニュー）を実行する,
  - **Then** 確認後にファイルが OS のゴミ箱へ移動し、リストから消える
- **US4-AS4**: **Given** ファイルを選択,
  - **When** コピー（⌘C）して別フォルダを選び、ペースト（⌘V）する,
  - **Then** 確認後に複製が作成される
- **US4-AS5**: **Given** ファイル（複数可）を選択,
  - **When** ツリー上の別フォルダへドラッグ&ドロップする,
  - **Then** 確認後にそのフォルダへ移動する。ドロップ時に Option キーを押していれば移動ではなくコピーになる
- **US4-AS6**: **Given** 確認モーダルが表示されている,
  - **When** キャンセルする,
  - **Then** ファイルシステムには一切の変更が加わらない
- **US4-AS7**: **Given** 確認を省略する設定が有効,
  - **When** コピーまたは削除を実行する,
  - **Then** モーダルなしで即座に実行される（削除はゴミ箱へ移動するため元に戻せる）。名前の変更と移動、
    およびツリーのフォルダをゴミ箱に入れる操作（FR-079）では、設定に関わらず確認モーダルが表示される
- **US4-AS8**: **Given** 移動・コピー先に同名の別の項目がある,
  - **When** 操作を実行する,
  - **Then** 設定に関わらず「置き換える / 両方残す / 中止」
    を選ぶダイアログが表示される。コピー先の同名項目がコピー元そのものの場合は「置き換える」を選べず、
    「両方残す / 中止」から選ぶ。

### US23 アプリ内ドラッグで整理する（P1）

- **US23-AS1**: 通常のツリーフォルダ（複数選択を含む）を別のツリーフォルダまたはリスト内のフォルダにドラッグすると、
  確認後に中身ごと移動する。
  - Option を押してドロップするとコピーする。
  - 複数選択から始めたときは選択全体を一操作として扱い、選択外の行から始めたときはその行だけを対象とする。
- **US23-AS2**: リスト形式またはサムネイル形式の選択済みファイル・
  フォルダをツリーまたはリストのフォルダにドラッグすると、選択全体を一操作として扱う。
  - 選択外の項目から開始した場合はその項目だけを対象とする。
- **US23-AS3**: 有効な宛先を指す間は視覚的に示し、無効な宛先では受け付けない。
  - ドラッグの中止または確認のキャンセルでは変更しない。
- **US23-AS4**: 衝突や失敗があれば既存の選択肢と結果表示に従い、成功と失敗を区別する。
  - 完了後の表示・選択・プレビューは結果と整合する。
- **US23-AS5**: 検索結果の選択ファイル・フォルダはツリーまたは検索結果のフォルダへドラッグできる。
  - zip 内の項目、親に戻る行、お気に入り見出しや見つからないお気に入りにはドロップできない。

### US26 項目のパスをコピーする（P1）

- **US26-AS1**: 通常のフォルダの一覧でメディアファイルを1件選択して右クリックメニューの「パス名をコピー」を選ぶと、
  そのファイルの絶対パスがクリップボードの文字列になり、ファイルリスト・ツリー・プレビューの状態は変わらない。
- **US26-AS2**: フォルダまたは zip ファイルの行（zip ファイルの表示がオン）を1件選択して同じ操作をすると、
  そのフォルダまたは zip ファイルの絶対パスをコピーする。
- **US26-AS3**: 複数の行を選択している間は「パス名をコピー」は淡色で選べない。
- **US26-AS4**: 検索結果のファイルまたはフォルダの行で同じ操作をすると、その項目の絶対パスをコピーする。
- **US26-AS5**: ツリーで別のフォルダを選択したまま、通常のフォルダの行で「パス名をコピー」を選ぶと、
  右クリックした行のフォルダの絶対パスをコピーし、ツリーの選択・ファイルリスト・プレビューは変わらない（A-21）。
- **US26-AS6**: お気に入りの項目（利用可能）で同じ操作をすると、
  登録したフォルダの絶対パスをコピーする（表示名ではない）。
- **US26-AS7**: 「お気に入り」の見出しを右クリックしても、従来どおりメニューを出さない。
- **US26-AS8**: ファイルリストにフォーカスがあり1件だけ選択しているとき、⌥⌘C または「編集 > パス名をコピー」
  でその項目の絶対パスをコピーする。
- **US26-AS9**: ツリーにフォーカスがあり通常のフォルダ・ホーム・ボリュームの最上位・
  利用可能なお気に入りの項目を選択しているとき、同じ操作でそのフォルダの絶対パスをコピーする。

### US35 整理先のフォルダをその場で作る（P1）

- **US35-AS1**: **Given** ツリーでフォルダ A を選択中,
  - **When** 別のフォルダ B の行を右クリックして「新規フォルダ」を選ぶ,
  - **Then** B の中に「名称未設定フォルダ」が作られ、B
    がツリーで展開されて新しい行で名前の編集が始まる。ツリーの選択（A）・ファイルリスト・
    プレビューは変わらない。名前を入力して Return で確定すると、確認モーダルなしにその名前になる
- **US35-AS2**: **Given** ファイルリストに通常のフォルダ F の一覧を表示中（リスト形式またはサムネイル形式）,
  - **When** 項目のない背景を右クリックして「新規フォルダ」を選ぶ,
  - **Then** F の中に「名称未設定フォルダ」が作られ、
    ファイルリストではその行だけが選択されて名前の編集が始まる。ツリーで F が展開済みなら新しいフォルダの行も現れる
- **US35-AS3**: **Given** ファイルリストにフォーカスがあり F を表示中,
  - **When** ⇧⌘N を押す（または「ファイル > 新規フォルダ」を選ぶ）,
  - **Then** US35-AS2 と同じ結果になる。ツリーにフォーカスがありフォルダ B を選択中なら、US35-AS1 と同じく B
    の中に作られる
- **US35-AS4**: **Given** お気に入りの項目 X（登録先は実フォルダ R）,
  - **When** X を右クリックして「新規フォルダ」を選ぶ（または X を選択しツリーにフォーカスがあるときに ⇧⌘N）,
  - **Then** R の中に作られる。ファイルリストが R を表示中なら、
    ファイルリストで新しい行を選択して名前の編集を始める。表示していなければ既定名のまま作成だけを行う
- **US35-AS5**: **Given** F に「名称未設定フォルダ」が既にある,
  - **When** F に新規フォルダを作る,
  - **Then** 「名称未設定フォルダ 2」（それもあれば空いている次の番号）で作られ、既存の項目は変わらない
- **US35-AS6**: **Given** 作成直後の名前の編集中,
  - **When** Esc を押す、空の名前で確定する、または既定名のまま確定する,
  - **Then**フォルダは既定名のまま残る。「/」「:」・先頭の「.」・同じ場所の別項目と同じ名前・
    パッケージとして扱われる名前で確定すると、フォルダの名前の変更と同じ検証エラーを表示し、名前は既定名のまま残る
- **US35-AS7**: **Given** ファイルリストに zip の中または検索結果を表示中,
  - **When** 背景を右クリックする、またはファイルリストにフォーカスがあるときに ⇧⌘N を押す,
  - **Then** 「新規フォルダ」は淡色で、
    何も作られない。見つからないお気に入りの項目の右クリックでも同じく淡色。書き込みできない場所では、
    作成を試みて失敗の理由を表示し、何も作られない
- **US35-AS8**: **Given** ファイルリストで項目を選択中,
  - **When** 項目（メディア・zip ファイル・フォルダ・`..`）を右クリックする,
  - **Then** 従来どおり選択中の項目向けのメニューが出て、「新規フォルダ」は含まれない

### US36 複数のフォルダをまとめて移動・コピーする（P1）

- **US36-AS1**: **Given** ツリーで通常のフォルダ A・B・C を複数選択している,
  - **When** 選択中のいずれかの行からツリーのフォルダ D へドラッグしてドロップし、確認モーダルで確定する,
  - **Then** A・B・C が中身ごと D へ1回の操作として移動し、確認モーダルには3件を示す。Option
    を押してドロップするとコピーし、元の A・B・C は残る
- **US36-AS2**: **Given** A・B を複数選択している,
  - **When** 選択外の通常のフォルダ F の行からドラッグを始める,
  - **Then** F だけを対象にする（A・B は対象にしない）。ドラッグを中止したときは、ツリーの選択は A・B のまま、
    ファイルリストの表示も変わらない
- **US36-AS3**: **Given** フォルダ P とその配下のフォルダ P/Q を同時に選択している、または選択したフォルダ自身・
  配下を宛先にしている,
  - **When** ドラッグする,
  - **Then**宛先は有効にならず、ドロップしても何も変わらない（EC-121・EC-16）。一部の項目だけを黙って除いて実行しない
- **US36-AS4**: **Given** 通常のフォルダとホーム（またはボリュームの最上位・お気に入りの項目）を同時に選択している,
  - **When** 選択中の行からドラッグを始める,
  - **Then**ドラッグは始まらない（FR-218）
- **US36-AS5**: **Given** 複数選択の移動で一部が衝突・失敗した,
  - **When** 結果が表示される,
  - **Then** 既存の衝突の選択肢（FR-025）と結果表示（FR-026）に従い、
    成功した分と失敗した分を区別して伝える。ツリーとファイルリストには成功した分だけを反映する（FR-165）

### US37 複数のフォルダをまとめてゴミ箱に入れる（P1）

- **US37-AS1**: **Given** ツリーで通常のフォルダ A・B・C を複数選択し、確認モーダルの省略設定（FR-023）がオン,
  - **When** ⌘⌫ を押す,
  - **Then** 確認モーダルが必ず表示され、対象の件数と各フォルダの名前・絶対パスを示す。確定すると A・B・C
    が中身ごとゴミ箱に入り、ツリーとファイルリストから消える。キャンセルすると何も変わらない
- **US37-AS2**: **Given** A・B・C を複数選択している,
  - **When** B の行を右クリックして「ゴミ箱に入れる」を選ぶ,
  - **Then** A・B・C の全体を対象にする。選択外のフォルダ D の行を右クリックした場合は D だけを対象にし、
    ツリーの選択は変えない（A-21）
- **US37-AS3**: **Given** A の内容をファイルリストに表示し、A・B を複数選択している,
  - **When** まとめてゴミ箱に入れて確定する,
  - **Then** A の親をツリーで単一選択し、ファイルリストを親の一覧に切り替え、プレビューを空にする（FR-079・FR-219）
- **US37-AS4**: **Given** フォルダ P と配下の P/Q を同時に選択している,
  - **When** ⌘⌫ を押す,
  - **Then** 理由を示すエラーを表示して全体を拒否し、どのフォルダもゴミ箱に入れない（EC-146）

### US75 Folzio の項目を他のアプリへ渡す（P1）

- **US75-AS1**: **Given** リスト形式またはサムネイル形式でファイル A・B を選択している,
  - **When** 同じボリュームの Finder のフォルダへドラッグしてドロップする,
  - **Then** A・B がそのフォルダへ移動し、Folzio の一覧から消える（EC-236）。Option
    を押してドロップするとコピーになり、一覧に残る
- **US75-AS2**: **Given** ツリーで通常のフォルダ F を選択している,
  - **When** F の行を別のボリュームの Finder のフォルダへドラッグしてドロップする,
  - **Then** Finder の規則どおり F が中身ごとコピーされ、ツリーの F は残る
- **US75-AS3**: **Given** 画像ファイルを選択している,
  - **When** Web ブラウザのファイルのアップロード欄へドラッグしてドロップする,
  - **Then** ブラウザがそのファイルを受け取り、Folzio の元のファイルは変わらない
- **US75-AS4**: **Given** zip の中の項目、`..`、ホーム・ボリュームの最上位、お気に入りの項目を指している,
  - **When** そこからドラッグを始める,
  - **Then** ドラッグは始まらない（FR-162 と同じ）
- **US75-AS5**: **Given** ファイルまたはツリーのフォルダを選択している,
  - **When** Dock のゴミ箱へドラッグしてドロップする,
  - **Then** 項目は元の場所に残り、Folzio の表示も変わらない（Dock のゴミ箱には対応しない。FR-344）。
    ゴミ箱へは ⌘⌫ と「ゴミ箱に入れる」で入れる

### US76 Finder の項目を Folzio のフォルダへ受け取る（P1）

- **US76-AS1**: **Given** Finder で、宛先と同じボリュームのファイル A を選択している,
  - **When** リスト形式のフォルダの行へドラッグしてドロップし、確認モーダルで確定する,
  - **Then** A がそのフォルダへ移動する。Option を押してドロップするとコピーになる
- **US76-AS2**: **Given** Finder で、別のボリュームのファイル B を選択している,
  - **When** サムネイル形式のフォルダのアイコンへドラッグしてドロップする,
  - **Then** B がそのフォルダへコピーされる（確認モーダルは FR-024 の省略設定に従う）。
    ⌘ を押してドロップすると移動になる
- **US76-AS3**: **Given** 宛先に同じ名前の項目がある,
  - **When** Finder の項目をドロップする,
  - **Then** 設定に関わらず「置き換える / 両方残す / 中止」を選ぶダイアログが表示される（FR-025）
- **US76-AS4**: **Given** Finder の項目をドラッグしている,
  - **When** `..`・zip の中・お気に入りの見出し・見つからないお気に入り・検索結果の背景とファイル・
    ツリーの行間の上へ来る,
  - **Then** 宛先は強調されず、ドロップしても何も変わらない
- **US76-AS5**: **Given** Finder で、Folzio のツリーのフォルダ P を選択している,
  - **When** P を P 自身または配下のフォルダへ、または P の親へ移動しようとする,
  - **Then** 宛先は有効にならない（EC-16・EC-121）
- **US76-AS6**: **Given** ブラウザのリンク・文字列のうち、file URL・ファイルの書き出しの約束・
  画像データのどれも持たないものをドラッグしている,
  - **When** Folzio のフォルダの上へ来る,
  - **Then** 宛先は強調されず、ドロップしても何も変わらない（FR-348）。file URL
    を持つ場合（ローカルのファイルを表示中など）は、そのファイルの移動・コピーとして扱い、画像は US79
    に従って保存する
- **US76-AS7**: **Given** ファイルリストに通常のフォルダ F の一覧を表示している,
  - **When** Finder のファイルを、一覧の何もない所、または F の中の画像ファイルの行・アイコンの上へドロップする,
  - **Then** 一覧全体が宛先として強調され、ファイルは F へ FR-346 の規則で移動・コピーされる（FR-349）
- **US76-AS8**: **Given** ファイルリストに F の一覧を表示し、ツリーで F と別のフォルダ G を選べる,
  - **When** ツリーの G をファイルリストの背景へドラッグしてドロップする,
  - **Then** G が F へ移動する（Option でコピー。FR-020）。F
    の一覧の項目を同じ一覧の背景へ移動しようとしたときは、宛先は有効にならない（EC-121）

### US79 ブラウザの画像をドラッグしてフォルダへ保存する（P1）

ユーザーは、Web ブラウザに表示中の画像を、Folzio のツリーのフォルダ・お気に入り・リスト形式のフォルダの行・
  サムネイル形式のフォルダのアイコン・ファイルリストの背景へドラッグして、ファイルとして保存できる。
  ブラウザの「名前を付けて保存」と保存先の選択を省き、閲覧中の画像を整理先のフォルダへ直接入れる。

- **US79-AS1**: **Given** ブラウザに画像を表示している
  - **When** その画像をツリーのフォルダへドラッグしてドロップする
  - **Then** ブラウザが付けた名前と形式で、画像がそのフォルダに保存される。保存はコピーとして扱い、確認モーダルは
    FR-024の省略設定に従う

- **US79-AS2**: **Given** ブラウザがファイルの書き出しの約束を渡さず、画像データだけを渡す
  - **When** その画像をフォルダへドロップする
  - **Then** 画像は PNG 形式で、FR-366 の名前で保存される

- **US79-AS3**: **Given** ブラウザのリンクや文字列（file URL・ファイルの書き出しの約束・画像データのどれもない）
  をドラッグしている
  - **When** フォルダの上へ来る
  - **Then** 宛先は強調されず、ドロップしても何も変わらない。Folzio はその URL へ通信しない（FR-348・
    FR-367）

- **US79-AS4**: **Given** 宛先に同じ名前のファイルがある
  - **When** 画像をドロップする
  - **Then** 設定に関わらず「置き換える / 両方残す / 中止」を選ぶダイアログが表示される（FR-025）

- **US79-AS5**: **Given** 確認モーダルまたは衝突のダイアログが表示されている
  - **When** キャンセル・中止する
  - **Then** 宛先のフォルダには何も作られず、取り込みのために作った一時的なファイルも残らない（FR-364）

- **US79-AS6**: **Given** 画像をドラッグしている
  - **When** Option または ⌘ を押しながらフォルダの上へ来てドロップする
  - **Then** ドラッグ元がその修飾キーの状態でコピーを許可するときは、コピーとして示され、コピーとして保存される。
    コピーを許可しないときは宛先が有効にならず、保存されない（FR-356）

- **US79-AS7**: **Given** ファイルリストに通常のフォルダ F の一覧を表示している
  - **When** ブラウザの画像を一覧の背景へドロップする
  - **Then** 一覧全体が宛先として強調され、画像は F に保存される（FR-349）

- **US79-AS8**: **Given** 写真アプリで MOV の動画を選択している
  - **When** ツリーのフォルダへドラッグしてドロップする（コピーの扱いはUS78-AS8のfile URLの規則に従う）
  - **Then** 書き出しが 2 秒を超えると進み具合のパネルが表示され（FR-363）、
    終わると動画がコピーとしてそのフォルダに保存される（FR-356・FR-362）。 AVI・MKV
    など対応形式でない動画は保存されず、理由が表示される

- **US79-AS9**: **Given** 進み具合のパネルが表示されている
  - **When** 「取り消す」ボタンを押すか ⌘. を押す
  - **Then** 受け取りは取り消され、宛先には何も作られず、一時的なファイルも残らない（FR-363）

### US78 コピーした画像をペーストしてフォルダへ保存する（P1）

ユーザーは、ブラウザの「画像をコピー」でクリップボードに入れた画像を、Folzio のファイルリストの ⌘V・「ペースト」、
  ツリーの ⌘V・「ここにペースト」で、表示中のフォルダ・選択したフォルダへファイルとして保存できる。
  ドラッグと同じ操作をキーボードで行えるようにする（憲章 原則 III）。

- **US78-AS1**: **Given** ブラウザで画像を「画像をコピー」し、ファイルリストに通常のフォルダ F の一覧を表示している
  - **When** ⌘V を押す
  - **Then** 画像が PNG 形式で、FR-366 の名前で F に保存される。確認・衝突・失敗は FR-347に従う

- **US78-AS2**: **Given** 同じクリップボードで、ツリーの通常のフォルダ G を選択している
  - **When** ⌘V を押す、または G の右クリックの「ここにペースト」を選ぶ
  - **Then** 画像が G に保存される

- **US78-AS3**: **Given** クリップボードに画像データだけがある（file URL がない）
  - **When** 編集メニューと右クリックメニューを開く
  - **Then** 「ペースト」「ここにペースト」は有効、「移動ペースト」「ここに移動ペースト」は淡色で選べない（⌥⌘V
    も何もしない）

- **US78-AS4**: **Given** クリップボードにリンクや文字列だけがある
  - **When** ファイルリストとツリーのメニューを開く
  - **Then** ペーストと移動ペーストはどちらも淡色で選べない（今と同じ）

- **US78-AS5**: **Given** クリップボードに file URL と画像データの両方がある（Finder
  でファイルをコピーした場合など）
  - **When** ⌘V を押す
  - **Then** 今と同じく、file URL の項目がコピーされ、画像データは使わない（EC-241）

- **US78-AS6**: **Given** 画像をコピーし、zip の中または検索結果を表示している
  - **When** ⌘V を押す
  - **Then** 何も起きない（今と同じく、ペーストは無効。FR-073（zip.md）・search.md の検索結果へのペースト）

- **US78-AS7**: **Given** 画像をコピーし、名前の変更の編集欄で入力している
  - **When** ⌘V を押す
  - **Then** 今と同じく、編集欄への文字列の貼り付けとして扱い、画像は保存しない

- **US78-AS8**: **Given** 写真アプリで写真をコピーし、クリップボードにfile URLと縮小した画像データがある
  - **When** ファイルリストで ⌘V を押す
  - **Then** file URLの項目を既存のコピー経路で保存し、縮小した画像データは使わない。
    元のHEIC等の形式の保持は保証しない（EC-241）

## エッジケース

- **EC-08**: 書き込み権限のない場所へのコピー・移動・リネーム・削除は失敗理由を表示し、部分的な変更を残さない
- **EC-14**: リネームで使用できない文字、同じ親フォルダにある別項目と同名（大文字小文字の違いのみを含む）
  を指定した場合、またはフォルダの名前をシステムがパッケージとして扱う名前（EC-53）
  に変えようとした場合はエラーを表示し確定しない。
  - 空の名前（前後の空白だけを含む）と編集前と同じ名前は、エラーを出さずに何もしない（EC-48）
- **EC-15**: リネームで拡張子を変更しようとした場合は Finder と同様に確認する
- **EC-16**: フォルダを自分自身またはその配下へ移動・
  コピーしようとした場合（ファイルリストのフォルダをツリーの自分自身や配下のフォルダへドロップした場合を含む）
  は操作を拒否する（zip の中のディレクトリは FR-073 によりドラッグできない）
- **EC-17**: ファイルリストのフォルダをゴミ箱に入れた・移動した・名前を変更した場合、
  またはツリーでフォルダをゴミ箱に入れた・名前を変更した場合（FR-079・FR-103）、
  ツリーとファイルリストの該当項目にも即座に反映する（FR-027）。
  - そのフォルダ（またはその配下のフォルダ）がお気に入りに登録されていれば、FR-067 に従って見つからない表示になり、
    名前を元に戻せば通常の表示に戻る（FR-106）
- **EC-47**: 名前の編集中や確認モーダルの表示中に、対象のフォルダがアプリの外で削除・移動・名前変更された場合は、
  確定しても名前を変えず、対象のフォルダ名と失敗の理由を表示する（FR-026）。
  - 書き込み権限のないフォルダや読み取り専用のボリューム上のフォルダも、失敗の理由を表示し、
    部分的な変更を残さない（EC-08）
- **EC-48**: 空の名前（前後の空白だけを含む）、または編集前と同じ名前で確定した場合は、
  エラーも確認モーダルも出さずに編集を終え、何も変えない（ファイルリストの名前の変更と同じ）
- **EC-49**: フォルダの名前に「.」が含まれていても、拡張子の変更の確認（EC-15）
  は行わない（ファイルリストのフォルダの名前の変更と同じ）
- **EC-53**: フォルダの名前を、システムがパッケージ（`.app` など。FR-006）として扱う名前（例: `Photos.app`）
  に変えようとした場合は、検証エラーを表示して拒否し、
  名前を変えない（名前を変えただけでフォルダがツリーとファイルリストから見えなくなる事故を防ぐ）。
  - ツリーのフォルダの名前の変更（FR-103）とファイルリストのフォルダの名前の変更の両方に適用する（EC-14）。
  - ファイルの名前の変更には適用しない（ファイルはパッケージにならない）。
  - これにより、フォルダの名前の変更で配下のファイルが検索の対象外（FR-083）になる場合はなくなる（先頭の「.」も
    FR-103 で拒否する）

- **EC-121**: 移動先がいずれかの対象の親と同じ場合、その移動全体を拒否する。
  - 同じ場所へのコピーでは同名衝突を示し、「両方残す」または「中止」を選べるが、コピー元を失わないよう「置き換える」
    は選べない。
  - 対象フォルダ自身または配下への移動・コピーは全体を拒否する。
  - 選択集合にフォルダとその配下の項目が同時に含まれる場合も、移動・コピーとも全体を拒否する。
  - 複数項目の一部だけを黙って除外しない。
- **EC-122**: ドラッグ中または確認中に対象・宛先が消失、変更、アクセス不能になった場合は確定時にも検証し、
  既存のエラー表示と結果の反映に従う。
  - 権限エラーは EC-08（file-operations.md）に従う。
- **EC-123**: 検索結果以外の表示中に、ツリーから表示中のフォルダまたはその祖先を移動した場合、
  元の親を表示しプレビューを空にする。
  - 検索結果を表示中は、検索結果を維持して移動した配下の結果を除き、検索中の重複再出現を防ぐ。
  - コピーでは元の表示を保つ。
  - お気に入りは FR-067 に従う。

- **EC-141**: 作成の直前に作成先が削除・移動・名前変更された、またはアクセスできなくなった場合は、何も作らず、
  作成先の名前と失敗の理由を表示する（FR-026）。
  - 書き込み権限のない場所・読み取り専用のボリュームも同じ（EC-08）
- **EC-142**: 既定名を決めてから作成するまでの間に同じ名前の項目がアプリの外で現れた場合は、既存の項目を上書き・
  変更せず、次の空いている番号の名前で作る
- **EC-143**: 作成直後の名前の編集中に、そのフォルダがアプリの外で削除・移動・名前変更された場合は、
  確定しても名前を変えず、失敗の理由を表示する（EC-47 と同じ）
- **EC-144**: ツリーで作成先が折りたたまれている、または開閉の三角がない（サブフォルダがない）場合は、
  作成後に三角を表示して展開し、新しい行を表示する（FR-054）。
  - 作成先の祖先が折りたたまれている場合（右クリックした行は常に見えているため、⇧⌘N
    でスクロール外のフォルダを選択中の場合を含む）は、新しい行が見えるまで必要最小限のスクロールを行う
- **EC-145**: 種類フィルタ（FR-056）がオンでも、
  新しいフォルダの行はファイルリストに表示する（フォルダの行は種類フィルタで隠れない）
- **EC-146**: ツリーでゴミ箱に入れる対象（FR-217）に、フォルダとその配下のフォルダが同時に含まれる場合、
  システムは理由を示すエラーを表示して操作全体を拒否し、どのフォルダもゴミ箱に入れてはならない。
  - 確認モーダルは表示しない。
  - 一部の項目だけを黙って除いて実行しない（EC-121 と同じ考え方）
- **EC-147**: 複数選択の操作の実行時に、対象の一部がアプリの外で削除・移動されていた場合は、その分を失敗として FR-026
  に従って表示し、残りの結果を反映する。
  - 見つからない項目を黙って成功として扱わない
- **EC-236**: アプリ外へドラッグした項目が、ドロップ先のアプリによって移動・削除された場合、
  システムは EC-13（overview.md）と同じくツリー・ファイルリスト・プレビューに反映しなければならない。
  - ファイルリストに表示中のフォルダ（または祖先）がツリーから外へ移動された場合は、
    アプリ外で削除された場合の既存の扱いに従う
  - 検索結果の表示中は、移動・削除された項目を、アプリ内の移動と同じく検索結果から外す（FR-087（search.md））
  - 検索中に遅れて届く、移動・削除された項目の古い場所の結果も表示しない（アプリ内の移動と同じ）
  - この記録は、Folzio からのドラッグに限らず、アプリ外で移動・削除された項目を検索結果から外すとき（EC-13）に行う
  - フォルダごと移動・削除された場合は、そのフォルダの配下で、まだ届いていない別の項目の古い場所の結果も表示しない
- **EC-237**: アプリ外から受け取る項目に、宛先と同じボリュームのものと別のボリュームのものが混在する場合、
  修飾キーがなければコピーとする。
  - 元の項目を消す移動は、すべてが同じボリュームのときだけにする
- **EC-238**: ドラッグ元のアプリが、決めた操作（移動またはコピー）を許可していない場合、
  システムはもう一方の操作が許可されていればそれに切り替え、どちらも許可されていなければ宛先を有効にしない。
  - 修飾キーを押しているときは OS がドラッグ元の許可を絞る（Option はコピー（`.copy`）、⌘ は移動（`.generic`））
  - そのため、切り替えは主に修飾キーなしのときに起こる

- **EC-248**: ブラウザがファイルの書き出しに失敗した場合（画像の取得に失敗した、60
  秒で書き出しが終わらない（FR-355）など）、 システムは FR-026と同じく対象の名前と失敗の理由を表示し、

## 前提

- **A-05**: 削除は Finder と同じくゴミ箱への移動とし、ゴミ箱から元に戻せる
- **A-07**: コピーと移動の操作方法（⌘C/⌘V、ドラッグ&ドロップ、Option キーでコピー）は Finder に準じる
- **A-100**: zip の中の項目は絶対パスを持たないため「パス名をコピー」の対象外とする。
  - zip 内のパスの表現（例: `/a/b.zip!/dir/file`）は定めない。
- **A-101**: 複数選択へのパス名のコピーは対象外。複数の行を選んでいる間はメニュー項目を淡色にする。
- **A-102**: ⌥⌘C は既存のショートカットと衝突しない。
  - ⌘C（ファイルのコピー）とは別の操作で、クリップボードを文字列に置き換える（このとき「ペースト」「移動ペースト」
    は無効になる）。
- **A-103**: 存在しなくなった項目のパスも、表示している絶対パスをそのままコピーする。
- **A-104**: 見つからないお気に入りの項目は、利用できないものとして「パス名をコピー」を淡色にする。

- **A-119**: 既定名は Finder に合わせる（日本語「名称未設定フォルダ」、英語「untitled folder」）。
  - 連番の付け方は複製（FR-018）と同じ
- **A-120**: 作成直後の名前付けは、既存の項目の名前を変える操作ではないため確認モーダルを出さない（FR-024
  の常時確認は既存の項目の改名が対象）
- **A-121**: ファイルリストの背景の右クリックは、ファイルリストの選択を変えない。
  - 背景かどうかは右クリックした位置に項目があるかで決める（リスト形式の最終行より下、サムネイル形式の項目の間と外側）
- **A-122**: 取り消し（⌘Z）、選択項目から新規フォルダ（Finder の ⌃⌘N）、フォルダ以外の新規作成、
  検索起点の選択パネルでの新規作成（FR-141（search.md）・A-84（search.md））は範囲外とする
- **A-123**: zip の中は読み取り専用（FR-073）、検索結果は作成先となる単一のフォルダがないため、
  ファイルリストを作成先にする作成の対象外とする。
  - 検索結果を表示中でも、ツリーにフォーカスがあればツリーの選択中のフォルダに作れる（FR-103 と同じ考え方）
- **A-124**: ショートカット一覧（FR-202）の「選択とファイル操作」に、受け取りの取り消しを加える。
  - キーは⌘.とする（FR-363）
  - 既存の新規フォルダを含む46項目から合計47項目とする

- **A-125**: 新しい文言（「新規フォルダ」「名称未設定フォルダ」とその英語）は既存の翻訳の仕組み（contracts/
  localization.md）で両言語に追加する
- **A-202**: アプリ外へのドラッグの移動は、ドロップ先のアプリ（Finder）が実行し、取り消しもそのアプリで行う。
  - ユーザーがドロップ先と修飾キーを明示的に選ぶ操作であり、Finder 同士のドラッグと同じ扱いにする
  - 憲章 原則 I の「確認または取り消し可能性」は、Finder の「取り消す」で満たすと解釈した
- **A-203**: アプリ外から受け取る操作の決め方は、Finder の中でドラッグしたときと同じ結果にするため、
  Folzio の中でのドラッグ（FR-020、常に移動、Option でコピー）と違う Finder の規則に合わせた。
  - それまでのツリーでのアプリ外からのドロップ（常に移動、Option でコピー）は、この規則に変わった
- **A-204**: Web ブラウザに表示中の画像の取り込みは、ドラッグ（FR-364・FR-365）とペースト（FR-354）の両方で行う。
  - 憲章 原則 III の「新しい操作にはキーボードの手段を同時に提供する」は、
    ブラウザの「画像をコピー」の後のペースト（FR-354）で満たす
  - FR-344〜FR-347 のキーボードの手段は既存の ⌘C・⌘V・⌥⌘V（FR-019）で、Folzio と Finder の間で file URL のコピー・

  - ツリーのフォルダには ⌘C がないため、ファイルリストで親フォルダの一覧を表示し、そのフォルダを選んで ⌘C する
  - お気に入りはペースト先にならない（A-20（directory-tree.md））ため、

- **A-205**: Folzio から始めたドラッグをほかのアプリへ渡すデータは、file URL だけとする
  （画像データやファイルの書き出しの約束は渡さない）。
- **A-206**: エイリアスの作成（Finder の ⌥⌘ ドラッグ）は対象外とする。
- **A-207**: ファイルリストでフォルダでない項目の上へのドロップは、Finder の一覧と同じにするため、
  背景へのドロップとして扱う。
  - 一覧がファイルで埋まっていても、表示中のフォルダへ落とせる
  - 右クリックメニューの「新規フォルダ」の背景（FR-208。どの項目にも当たらない位置）より広い

- **A-215**: ブラウザ以外のアプリ（写真、Mail など）が渡すファイルの書き出しの約束と画像データも、
  同じ規則（FR-354〜FR-362・FR-364〜FR-367）で受け取る。
  - FR-357 により、画像と対応形式の動画（FR-362）でないもの（Mail の PDF の添付など）は保存しない

- **A-216**: 画像の保存は常にコピーとする（FR-356）。
  - 元の画像はブラウザの中にあり、Folzio が消す元の項目がないため。

- **A-217**: 書き出しを待つ間の表示は、2 秒を超えたときだけ出す（FR-363）。
  - ブラウザの画像の書き出しは通常すぐに終わるため、短い受け取りでパネルを点滅させない
  - 動画や iCloud から取り寄せる写真では長く待つことがあるため、取り消しの手段を設ける

- **A-218**: 安全性の規則（FR-357〜FR-360）の脅威は、ユーザーが閲覧した攻撃目的のページが、画像の URL・
  ファイルの書き出しの約束の名前と中身・画像データ・クリップボードを細工することとする。
  - ページは、ユーザーのドラッグ、ブラウザの「画像をコピー」、ページ上のクリック1回で使える非同期のクリップボード
    API（画像の書き込み）でデータを Folzio に渡せる
  - クリップボードは、ユーザーが選んでいない画像に置き換えられていることがある。それでも保存されるのは FR-357
    を満たす画素を持つ画像だけで、 名前は日時の名前か、ページが決めた URL の末尾から FR-357
    の名前の条件で作る名前になる
  - Folzio は、受け取ったファイルを開かず、実行しない。保存した画像の表示は既存のプレビュー（表示サイズに縮小して読
    み込む）で行う
  - 守りの中心は FR-357（画素を持つ画像だけを、中身の形式の拡張子で保存する）である。
    保存されたファイルを既定のアプリ（⌘O）で開くと、画像のアプリで開かれる
  - FR-358 の印は補助の守りである。画像の書類を開くときに OS の確認は出ないが、
    ファイルを後でほかの場所へ移したときにも、インターネットから入手したことが残る
  - 印を保存できない宛先では印を失う（Finder のコピーと同じ）。そのため、FR-357 を緩めて画像以外を受け取る変更は、
    この前提を見直してから行う

- **A-212**: 2026-11-09に保守者がSafari・Chrome・写真アプリのドラッグとコピーを確認し、
  T006の結果に基づくT007の変更を承認した。
  - 測定環境・形式・マスク・読み出し時間・失敗と再試行は`../TAK-88-browser-image-import/checklists/validation.md`に
    記録する。今回の条件以外の動作を保証するものではない
  - 製品への保存と操作の回帰はT031・T037で確認する。遅延提供される大きなTIFFと、
    単一の受け取り側から複数ファイルが届く場合は未実測として残す

- **A-213**: 新しい文言（日時の名前の接頭辞、失敗の理由）は、既存の翻訳の仕組み（contracts/localization.md）
  で両言語に追加する。
  - 訳はcontracts/localization.mdの「画像・動画の取り込み」に示す

- **A-214**: クリップボードの画像データは、コピー元のアプリを問わず保存の対象にする（FR-354）。
  - 表計算のセル・プレゼンテーションの図形などのコピーにも、OS が絵を添えるため、⌘V でその絵が PNG として保存される
  - コピー元を見分ける確かな方法がなく、プレビューや画面収録の絵も保存できるようにするため、規則を単純にした
  - 意図しない保存は、確認モーダル（FR-024 の設定に従う）で名前を見て取りやめるか、⌘Delete でゴミ箱へ入れて戻せる
