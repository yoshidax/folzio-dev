# ファイル操作

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md` から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

- **FR-018**: ユーザーは、選択したファイルとフォルダ（FR-076）に対して「コピー」「名前の変更」「削除」「移動」「複製」を実行できなければ
  ならない。フォルダの操作はその中身を含めて行い、FR-019〜FR-027 をファイルと同じく適用する（削除はフォルダごとゴミ箱へ入れる）。
  「複製」は対象と同じフォルダに「名前 2」という名前で作成し（既にその名前がある場合は空いている連番まで進める）、
  既存のファイルを変更しないため確認モーダル（FR-022）の対象外とする
- **FR-019**: システムは、各操作を右クリックメニューとキーボードショートカットの両方から実行できるようにし、
  その割り当ては Finder に準じなければならない（コピー ⌘C、ペースト ⌘V、移動ペースト ⌥⌘V、
  名前の変更 Return、ゴミ箱へ ⌘Delete、複製 ⌘D）
- **FR-020**: ユーザーはアプリ内で、ツリーの通常のフォルダ、またはファイルリストで選択したファイル・フォルダを、ツリー上またはファイルリスト上の別のフォルダへドラッグ&ドロップできなければならない。通常は移動、ドロップ時に Option を押していればコピーとする。ファイルリストはリスト形式・サムネイル形式の両方に対応し、複数選択はまとめて扱う。確認・衝突・エラーは FR-022〜FR-026 に従う。

- **FR-021**: 削除は、ファイルを OS のゴミ箱へ移動することで行わなければならない（完全削除は行わない）
- **FR-022**: システムは、コピー・名前の変更・削除・移動の実行前に、対象ファイルと操作内容を示す確認モーダルを
  表示しなければならない。キャンセルした場合はファイルシステムを変更してはならない
- **FR-023**: ユーザーは、設定で確認モーダルを表示しないように変更できなければならない。既定は「表示する」
- **FR-024**: 確認モーダルの省略は、コピー（ツリーのフォルダへのペースト・ドロップによるコピーを含む）と、ファイルリストからの
  削除（ゴミ箱へ入れる）と、お気に入りの削除（FR-064）にだけ適用されなければならない。名前の変更（ツリーのフォルダの名前の変更（FR-103）を含む）と移動、およびツリーのフォルダをゴミ箱に
  入れる操作（FR-079）は、設定に関わらず常に確認モーダルを表示しなければならない。設定ウインドウの確認の項目には、
  常に確認する操作として名前の変更・移動・ツリーのフォルダのゴミ箱を示す。
  複製（FR-018）は確認モーダルの対象外とし、設定にも影響されない。省略時の安全性は、削除が必ずゴミ箱経由で
  元に戻せること（FR-021）、コピーが元のファイルを変更しないこと、同名ファイルの上書きが常に確認されること
  （FR-025）で担保する。この方針は憲章 v1.1.0 原則 I の「確認または取り消し可能性」に従う
- **FR-025**: コピーまたは移動の操作先に同名ファイルが存在する場合、システムは確認モーダル設定に関わらず「置き換える / 両方残す / 中止」を選ばせなければならない。ただしコピー元と衝突先が同一の項目である場合は「置き換える」を選べないようにし、「両方残す / 中止」を選ばせる。この例外はドラッグ以外のコピーにも適用する。名前の変更で既存の名前（大文字小文字の違いのみを含む）を指定した場合は、衝突ダイアログを出さず、名前の検証エラーとして拒否しなければならない。複製は FR-018 の連番の規則に従い、この対象外とする。

- **FR-026**: 操作が失敗した場合、システムは対象ファイル名と失敗理由を表示し、成功した分と失敗した分を
  区別して伝えなければならない
- **FR-027**: 操作の結果は、ツリー・リスト・プレビューに即座に反映されなければならない
- **FR-079**: ユーザーは、ツリーの通常のフォルダ（ホーム・マウント中のボリュームの下にある実際のフォルダ）を、その行の
  右クリックメニューの「ゴミ箱に入れる」と、そのフォルダをツリーで選択中の ⌘⌫（FR-019 と同じキー。「ファイル」「編集」メニューの
  「ゴミ箱に入れる」を含む）で、中身ごと OS の
  ゴミ箱に入れられなければならない。右クリックメニューは右クリックした行を対象にし、ツリーでそのフォルダを選択していなくても
  （ほかのフォルダを選択中でも）使える（A-21）。どの手段でも、実行前に対象のフォルダ名とその絶対パス
  （同じ名前の別のフォルダと見分けられるようにする）、フォルダを
  中身ごとゴミ箱に入れる旨を示す確認モーダル（FR-022）を、確認モーダルの省略設定（FR-023）に関わらず必ず表示し、
  キャンセルした場合はファイルシステムを変更してはならない。この確認モーダルには「今後この確認を表示しない」を出さない。
  ゴミ箱経由（FR-021）・失敗の表示（FR-026）・結果の反映（FR-027）はファイルリストのゴミ箱に入れる操作と同じとする。
  ホーム・ボリュームの最上位・「お気に入り」の見出し・お気に入りの項目は対象にしない（FR-064）。ファイルリストに表示中の
  フォルダ、またはその祖先をゴミ箱に入れた場合は、削除したフォルダの親をツリーで選択し、ファイルリストを親の一覧に切り替え、
  プレビューを空にする（再生中の動画は FR-034 と同じく停止する）。キーボードフォーカスは移さない（⌘⌫ で削除したときはツリーに
  残り、右クリックメニューから削除したときは削除前にフォーカスがあったペインに残る）。選択した親は最後に選択していたフォルダ
  （FR-003）として保存する。表示中のフォルダと祖先・子孫の関係にないフォルダを削除した場合は、ツリーの選択とファイルリストの
  表示を変えない

- **FR-162**: ドラッグ元はツリーの通常フォルダ（FR-079 と同じ範囲）または通常一覧・検索結果の実項目とする。ホーム・ボリュームのルート、お気に入りの項目・見出し、`..`、zip 内の項目はドラッグ元にしない。zip ファイル自体は通常のファイルとして扱う。検索結果のフォルダも対象とする（FR-083・FR-087（search.md））。
- **FR-163**: 宛先はツリーの実在するフォルダ行（ホーム・ボリュームのルート、利用可能なお気に入りを含む）または通常一覧・検索結果の実フォルダ項目とする。お気に入り見出し、見つからないお気に入り、`..`、ファイル、zip ファイル、zip 内、検索結果の背景、リストの背景、行間にはドロップできない。アプリ外とのドラッグの動作変更は対象外とする。
- **FR-164**: システムは現在の操作と対象全体について宛先を検証し、有効なフォルダ行・項目を視覚的に強調する。Option の変更に追従して操作種別と有効性を更新し、ドロップ時にも再検証する。EC-16・EC-121 の不正な操作は受け付けない。
- **FR-165**: 操作後は FR-027 に従いツリー・リストを更新し、移動された選択項目を元一覧から外す。プレビュー対象が消えたらプレビューを空にして動画を停止する。コピー・キャンセル・失敗した項目の選択とプレビューは保つ。部分成功では成功分だけ反映する。ツリーから表示中のフォルダまたは祖先を移動した場合は EC-123 に従う。検索結果は FR-087 および EC-123 に従う。

## 主なエンティティ

- **ファイル操作**: 種類（コピー/移動/名前の変更/削除）、対象ファイル群、操作先、結果（成功/失敗と理由）

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS23**: **Given** ファイルリストでフォルダを選択した, **When** ⌘⌫ を押して確認モーダルで確定する, **Then** フォルダが中身ごと
  OS のゴミ箱へ移動し、ファイルリストとツリーから消える。プレビューは空のままで、キャンセルした場合は何も変わらない
- **US1-AS24**: **Given** ツリーで通常のフォルダを選択し、その内容をファイルリストに表示中, **When** ⌘⌫ を押す（またはそのフォルダの行を
  右クリックして「ゴミ箱に入れる」を選ぶ）、確認モーダルで確定する, **Then** フォルダが中身ごと OS のゴミ箱へ移動してツリーから消え、
  ツリーでは親フォルダが選択されてファイルリストは親の一覧に切り替わる（プレビューは空。⌘⌫ で削除したときはフォーカスはツリーのまま、右クリックメニューからではフォーカスを移さない）。
  キャンセルした場合は何も変わらない。ホーム・ボリュームの最上位・「お気に入り」の見出しでは右クリックメニューに
  「ゴミ箱に入れる」が出ず、⌘⌫ も何もしない
- **US1-AS44**: **Given** ツリーでフォルダ A を選択し、確認モーダルの省略設定（FR-023）がオン,
  **When** 別のフォルダ B の行を右クリックして「ゴミ箱に入れる」を選ぶ, **Then** B のフォルダ名と絶対パスを示す確認モーダルが
  必ず表示され、確定すると B が中身ごとゴミ箱に入り、ツリーの選択はフォルダ A のまま変わらない。キャンセルすると
  何も変わらない。A を選択中に ⌘⌫ を押した場合と、「ファイル」「編集」メニューの「ゴミ箱に入れる」を選んだ場合も、省略設定に関わらず
  A のフォルダ名と絶対パスを示す確認モーダルが表示される

### US4 Finder と同じ感覚でファイルを整理する（P3）

- **US4-AS1**: **Given** ファイルを選択, **When** 右クリックする, **Then** コピー・ペースト・名前の変更・ゴミ箱に
  入れる等の操作メニューが表示される
- **US4-AS2**: **Given** ファイルを選択, **When** リネームを開始（Return キーまたはメニュー）して新しい名前を確定する,
  **Then** 確認後にファイル名が変更され、リストに反映される
- **US4-AS3**: **Given** ファイルを選択, **When** 削除（⌘+Delete またはメニュー）を実行する, **Then** 確認後に
  ファイルが OS のゴミ箱へ移動し、リストから消える
- **US4-AS4**: **Given** ファイルを選択, **When** コピー（⌘C）して別フォルダを選び、ペースト（⌘V）する,
  **Then** 確認後に複製が作成される
- **US4-AS5**: **Given** ファイル（複数可）を選択, **When** ツリー上の別フォルダへドラッグ&ドロップする,
  **Then** 確認後にそのフォルダへ移動する。ドロップ時に Option キーを押していれば移動ではなくコピーになる
- **US4-AS6**: **Given** 確認モーダルが表示されている, **When** キャンセルする, **Then** ファイルシステムには一切の
  変更が加わらない
- **US4-AS7**: **Given** 確認を省略する設定が有効, **When** コピーまたは削除を実行する, **Then** モーダルなしで
  即座に実行される（削除はゴミ箱へ移動するため元に戻せる）。名前の変更と移動、およびツリーのフォルダをゴミ箱に入れる操作
  （FR-079）では、設定に関わらず確認モーダルが表示される
- **US4-AS8**: **Given** 移動・コピー先に同名の別の項目がある, **When** 操作を実行する, **Then** 設定に関わらず「置き換える / 両方残す / 中止」を選ぶダイアログが表示される。コピー先の同名項目がコピー元そのものの場合は「置き換える」を選べず、「両方残す / 中止」から選ぶ。

### US23 アプリ内ドラッグで整理する（P1）

- **US23-AS1**: 通常のツリーフォルダを別のツリーフォルダまたはリスト内のフォルダにドラッグすると、確認後に中身ごと移動する。Option を押してドロップするとコピーする。
- **US23-AS2**: リスト形式またはサムネイル形式の選択済みファイル・フォルダをツリーまたはリストのフォルダにドラッグすると、選択全体を一操作として扱う。選択外の項目から開始した場合はその項目だけを対象とする。
- **US23-AS3**: 有効な宛先を指す間は視覚的に示し、無効な宛先では受け付けない。ドラッグの中止または確認のキャンセルでは変更しない。
- **US23-AS4**: 衝突や失敗があれば既存の選択肢と結果表示に従い、成功と失敗を区別する。完了後の表示・選択・プレビューは結果と整合する。
- **US23-AS5**: 検索結果の選択ファイル・フォルダはツリーまたは検索結果のフォルダへドラッグできる。zip 内の項目、親に戻る行、お気に入り見出しや見つからないお気に入りにはドロップできない。

## エッジケース

- **EC-08**: 書き込み権限のない場所へのコピー・移動・リネーム・削除は失敗理由を表示し、部分的な変更を残さない
- **EC-14**: リネームで使用できない文字、同名の既存ファイルを指定した場合、または
  フォルダの名前をシステムがパッケージとして扱う名前（EC-53）に変えようとした場合はエラーを表示し確定しない。空の名前
  （前後の空白だけを含む）と編集前と同じ名前は、エラーを出さずに何もしない（EC-48）
- **EC-15**: リネームで拡張子を変更しようとした場合は Finder と同様に確認する
- **EC-16**: フォルダを自分自身またはその配下へ移動・コピーしようとした場合（ファイルリストのフォルダをツリーの自分自身や配下の
  フォルダへドロップした場合を含む）は操作を拒否する（zip の中のディレクトリは FR-073 によりドラッグできない）
- **EC-17**: ファイルリストのフォルダをゴミ箱に入れた・移動した・名前を変更した場合、またはツリーでフォルダを
  ゴミ箱に入れた・名前を変更した場合（FR-079・FR-103）、ツリーとファイルリストの該当項目にも即座に反映する（FR-027）。
  そのフォルダ（またはその配下のフォルダ）がお気に入りに登録されていれば、FR-067 に従って見つからない表示になり、
  名前を元に戻せば通常の表示に戻る（FR-106）
- **EC-47**: 名前の編集中や確認モーダルの表示中に、対象のフォルダがアプリの外で削除・移動・名前変更された場合は、確定しても
  名前を変えず、対象のフォルダ名と失敗の理由を表示する（FR-026）。書き込み権限のないフォルダや
  読み取り専用のボリューム上のフォルダも、失敗の理由を表示し、部分的な変更を残さない（EC-08）
- **EC-48**: 空の名前（前後の空白だけを含む）、または編集前と同じ名前で確定した場合は、エラーも確認モーダルも出さずに
  編集を終え、何も変えない（ファイルリストの名前の変更と同じ）
- **EC-49**: フォルダの名前に「.」が含まれていても、拡張子の変更の確認（EC-15）は行わない
  （ファイルリストのフォルダの名前の変更と同じ）
- **EC-53**: フォルダの名前を、システムがパッケージ（`.app` など。FR-006）として扱う名前（例: `Photos.app`）に
  変えようとした場合は、検証エラーを表示して拒否し、名前を変えない（名前を変えただけでフォルダがツリーとファイルリストから
  見えなくなる事故を防ぐ）。ツリーのフォルダの名前の変更（FR-103）とファイルリストのフォルダの名前の変更の両方に適用する（EC-14）。
  ファイルの名前の変更には適用しない（ファイルはパッケージにならない）。これにより、フォルダの名前の変更で配下のファイルが
  検索の対象外（FR-083）になる場合はなくなる（先頭の「.」も FR-103 で拒否する）

- **EC-121**: 移動先がいずれかの対象の親と同じ場合、その移動全体を拒否する。同じ場所へのコピーでは同名衝突を示し、「両方残す」または「中止」を選べるが、コピー元を失わないよう「置き換える」は選べない。対象フォルダ自身または配下への移動・コピーは全体を拒否する。選択集合にフォルダとその配下の項目が同時に含まれる場合も、移動・コピーとも全体を拒否する。複数項目の一部だけを黙って除外しない。
- **EC-122**: ドラッグ中または確認中に対象・宛先が消失、変更、アクセス不能になった場合は確定時にも検証し、既存のエラー表示と結果の反映に従う。権限エラーは EC-08（file-operations.md）に従う。
- **EC-123**: 検索結果以外の表示中に、ツリーから表示中のフォルダまたはその祖先を移動した場合、元の親を表示しプレビューを空にする。検索結果を表示中は、検索結果を維持して移動した配下の結果を除き、検索中の重複再出現を防ぐ。コピーでは元の表示を保つ。お気に入りは FR-067 に従う。

## 成功基準

- **SC-006**: 確認モーダルでキャンセルした操作のうち、ファイルシステムに変更が残るものが 0 件
- **SC-008**: Finder の操作に慣れたユーザーが、説明なしでコピー・リネーム・削除・移動の4操作を初回で完了できる
- **SC-027**: ツリーのフォルダをゴミ箱に入れる操作のうち、確認モーダルを経ずに実行されるものが 0 件（確認モーダルの省略設定が
  オンでも）

- **SC-074**: ツリー・リスト形式・サムネイル形式の各ドラッグ元とツリー・リストの両宛先について、移動・Option コピーをそれぞれ確認し、対象・結果が誤る組み合わせは0件。
- **SC-075**: 複数選択、無効な宛先、キャンセル、衝突、権限エラーと検索・zip・お気に入りの各確認で、意図しない変更や不整合が0件。

## 前提

- **A-05**: 削除は Finder と同じくゴミ箱への移動とし、ゴミ箱から元に戻せる
- **A-07**: コピーと移動の操作方法（⌘C/⌘V、ドラッグ&ドロップ、Option キーでコピー）は Finder に準じる
