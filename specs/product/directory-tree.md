# ディレクトリツリー

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md`
から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

### ディレクトリツリー

- **FR-004**: システムは、
  ホームフォルダとマウント中のボリュームをルートとするフォルダ階層をツリー形式で表示しなければならない
- **FR-005**: ユーザーは、ツリーのノードをクリックまたはキーボード（左右キーで折りたたみ/展開、上下キーで移動）
  で展開・折りたたみ・選択できなければならない
- **FR-006**: システムは、ツリーにフォルダのみを表示し、ファイル、隠しフォルダ、パッケージ（`.app` など）
  は表示してはならない。
  - パッケージはフォルダとして扱わず、展開も開く操作もしない
- **FR-007**: システムは、ツリーで選択されたフォルダの内容をファイルリストに表示しなければならない
- **FR-047**: システムは、ツリーの各フォルダ名の先頭にフォルダアイコンを表示しなければならない。
  - ここでフォルダアイコンはフォルダ種別を表すアイコンを指し、ホームとボリュームはフォルダ形状以外のシンボルでもよい。
  - アイコンは「ホーム」「マウント中のボリューム」「通常のフォルダ」の3種類を相互に判別できるものとし、展開・
    折りたたみの状態によって変化しない。
  - アイコンは展開・折りたたみの操作や選択状態を妨げず、フォルダ名の可読性を損なわない大きさとする
- **FR-053**: ユーザーは、ツリーのフォルダの行をダブルクリックして、そのフォルダの展開・
  折りたたみを切り替えられなければならない。
  - 折りたたまれていれば展開し、展開されていれば折りたたむ（トグル）。
  - 反応する範囲はフォルダアイコンとフォルダ名を含む行全体とする。
  - ダブルクリックしたフォルダは、シングルクリックと同じく選択され、
    ファイルリストはそのフォルダの内容に切り替わる（FR-007）。
  - 開閉の三角は従来どおりシングルクリックで開閉し、FR-005 のクリック・キーボード操作も変わらない。
  - FR-054 で開閉できないフォルダは、ダブルクリックしても選択だけを行い、開閉しない
- **FR-054**: システムは、ツリーに表示するサブフォルダ（FR-006 により隠しフォルダとパッケージは数えない）
  を1つも持たないフォルダに開閉の三角を表示してはならず、そのフォルダは開閉できないものとして扱う。
  - 読み取り権限のないフォルダも開閉の三角を表示せず、開閉できない。
  - 外部の変更（FR-042）でサブフォルダが追加・削除された場合は、三角の有無もそれに合わせて更新する
- **FR-055**: サブフォルダの有無の確認は、ツリーに表示されているフォルダについて、
  その直下1階層だけを調べて行わなければならない。
  - 初期表示時はルート（ホームとマウント中の各ボリューム）と、その直下に表示された各フォルダを確認する。
  - フォルダを展開したときは、その直下に新たに表示された各フォルダを確認する。
  - 表示されていないフォルダや、それより深い階層を先読みしてはならない。
  - 確認が終わるまでそのフォルダには三角を表示せず（行内の三角の位置は空けておき、
    確認後に行の位置がずれないようにする）、サブフォルダがあると分かった時点で表示する。
  - 確認中のフォルダはダブルクリックしても選択だけを行い、開閉しない。
  - 確認はツリーの表示・選択・スクロールを止めてはならず、
    確認の完了を待たずにツリーを操作できなければならない（表示の停止は SC-004 と同じく 100ms 未満とする）。
  - 読み取り権限以外の理由（ボリュームの応答がない、読み取り中に取り外された等）で確認に失敗したフォルダは、
    サブフォルダがあるものとして三角を表示し、開閉できるようにする。
  - 展開時に読めなければ、既存のアクセスできない旨の表示を出す
- **FR-103**: ユーザーは、ツリーの通常のフォルダ（ホーム・
  マウント中のボリュームの最上位の下にある実際のフォルダ。FR-079 と同じ範囲）の名前を、
  次のどの手段でも変更できなければならない。
  - （1）そのフォルダをツリーで選択し、ツリーにキーボードフォーカスがあるときに Return を押す。
  - （2）そのフォルダの行の右クリックメニューの「名前を変更」を選ぶ（右クリックした行を対象にし、
    選択中の行でなくてもよい。A-21）。
  - （3）ツリーにキーボードフォーカスがあり、そのフォルダを選択しているときに「編集」メニューの「名前を変更」を選ぶ。
  - 名前の編集はその行の中で行い、編集の始め方と終え方、名前の検証、
    確認はファイルリストのフォルダの名前の変更と同じとする。
  - すなわち、編集を始めたときは現在の名前を入れ、ファイルリストと同じ範囲（最後の「.」より前。「.」がなければ全体）
    を選択した状態にする。
  - Return またはほかの場所のクリックなどで確定し、Esc で取り消す（名前を変えず、確認モーダルも出さない）。
  - 確定した名前は前後の空白（改行を含む）を取り除き、空、または編集前と同じ名前なら何もしない。
  - 「/」または「:」を含む名前、先頭が「.」の名前、
    同じ場所にある別の項目（ツリーやファイルリストに表示していない隠し項目やファイルを含む）
    と大文字小文字の違いだけを含めて同じ名前、システムがパッケージとして扱う名前（EC-53）は、
    検証エラーを表示して拒否する（EC-14・FR-025）。
  - 元フォルダ自身の大文字小文字だけの変更は FR-025 に従い許可する。
  - 検証を通った名前は、確認モーダル（FR-022）を設定に関わらず表示してから変更し（FR-024）、
    キャンセルした場合は変更しない。
  - この確認モーダルには、ファイルリストの名前の変更の確認モーダルの内容に加えて、
    対象のフォルダの絶対パスを示す（同じ名前の別のフォルダと見分けられるようにする）。
  - 名前の編集欄には「フォルダの名前」
    というアクセシビリティラベルを付ける（お気に入りの表示名の編集欄の「お気に入りの名前」（FR-101）と区別する）。
  - 失敗した場合は FR-026 に従って表示する。
  - 編集を始めても、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003）は変えない。
  - ホーム・ボリュームの最上位・「お気に入り」の見出しを選択中の Return は何もせず、
    それらの右クリックメニューに「名前を変更」は出さず、それらを選択中は「編集」メニューの「名前を変更」を無効にする。
  - お気に入りの項目の Return・「名前を変更」は、従来どおり表示名の変更（FR-099）とする。
  - ファイルリストに zip の中または検索結果を表示中でも、ツリーにフォーカスがあれば（1）〜（3）は使える（zip
    の中の読み取り専用と検索結果の制限はファイルリストの操作にだけ適用する）。
  - ファイルリストにフォーカスがあるときの Return と「名前を変更」は、従来どおりファイル名の変更（FR-019）とする
- **FR-104**: ツリーでフォルダの名前を変えたとき、システムは結果を次のとおり即座に反映しなければならない（FR-027）。
  - ツリーでは、そのフォルダを新しい名前で、兄弟フォルダの中の並び順の位置に表示する。
  - そのフォルダと配下の展開状態とサブフォルダの有無の確認結果（FR-054・FR-055）は保つ。
  - 名前を変えたフォルダ（またはその配下）を選択していた場合は選択を保ち、
    選択中の行全体が見える位置まで必要最小限のスクロールを行う。
  - そうでない場合は、ツリーの選択を変えない。
  - ファイルリストが、名前を変えたフォルダ自身またはその配下（その中の zip ファイルの中を含む）を表示している場合は、
    一覧の項目・並び順・選択・スクロール位置・表示形式・プレビュー（再生中の動画も止めない）を変えない。
  - 以後の操作（`..`・⌘↑・ファイル操作・検索のモーダルの検索起点の既定値など）は新しい場所を対象にする。
  - ファイルリストが、名前を変えたフォルダの親を表示している場合は、そのフォルダの行を新しい名前にし、
    並べ替えの位置へ移す（選択していれば選択を保つ）。
  - 最後に選択していたフォルダ（FR-003）が、名前を変えたフォルダ自身またはその配下であれば、新しい場所として保存する。
  - これらのどれにも当たらない場合は、ファイルリストとプレビューを変えない
- **FR-215**: ユーザーは、ツリーでクリック・⌘クリック・Shift クリック、および Shift+↑↓
  で複数の行を選択できなければならない。
  - ⌘クリックは選択中の行を選択から外すこともできる。
  - ↑↓（Shift なし）と通常のクリックは、従来どおり1行だけを選択する（FR-005）。
  - 複数選択の行の種類（通常のフォルダ・ホーム・ボリュームの最上位・お気に入りの項目・見出し）は制限しない。
  - 操作の可否は FR-218 で決める
- **FR-216**: ツリーで複数の行を選択しているとき、ファイルリストには、最後にクリックした行、
  またはキーボードで最後に移動した行（以下「主の行」）のフォルダを、単一選択のときと同じ規則（FR-007・FR-063・FR-065、
  履歴（navigation-history.md）、最後に選択していたフォルダ（FR-003））で表示しなければならない。
  - ⌘クリックで行を選択から外したときは、ファイルリストの表示を変えない。
  - ファイルリスト側の操作（フォルダを開く・親に戻る（FR-078）、戻る・進む（navigation-history.md）、
    検索結果のフォルダを開く（FR-140）など）でツリーの選択が表示中のフォルダに同期されたときは、複数選択を解き、
    同期した1行の選択にし、その行を主の行とする。
  - 検索結果の表示中に、複数選択の中の行を通常のクリックで選んだときは、選択をその1行にし、FR-086
    と同じく検索結果の表示を終えてその行のフォルダの一覧を表示する
- **FR-217**: ツリーの操作の対象は次のとおりとしなければならない。
  - （1）⌘⌫ と、ツリーを対象にする「ファイル」「編集」
    メニューの項目（ツリーにフォーカスがあるとき。どのペインからでも効く ⌃⌘T を含む）は、
    ツリーで選択中の行全体を対象にする。
  - （2）右クリックメニューは、選択中の行を右クリックしたときは選択中の行全体を、
    選択外の行を右クリックしたときはその行だけを対象にし、ツリーの選択を変えない（A-21）。
  - （3）ドラッグは、選択中の行から始めたときは選択中の行全体を、
    選択外の行から始めたときはその行だけを対象にする（US23-AS2 と同じ）。
  - ドラッグを終えた時点（ドロップ・中止）では、ツリーの選択と主の行をドラッグ前に戻す（操作の結果による選択の更新は
    FR-219 に従う）
- **FR-218**: 対象が2行以上のとき、システムは次のとおり扱わなければならない。
  - （1）ゴミ箱に入れる操作とドラッグは、対象のすべてが通常のフォルダ（FR-079 と同じ範囲）のときだけ実行できる。
  - そうでなければ、「ゴミ箱に入れる」は淡色で選べず、⌘⌫ は何もせず、ドラッグは始まらない。
  - 対象の一部だけを除いて実行しない。
  - （2）単一の対象を前提とする操作（新規フォルダ（FR-208。⇧⌘N・「ファイル > 新規フォルダ」・右クリック）・
    名前を変更（FR-103・FR-099）・パス名をコピー（FR-182）・お気に入りに追加（FR-062）・お気に入りから削除（FR-064）・
    Finder に表示・ここにペースト・ここに移動ペースト・⌘V・⌥⌘V）は、メニュー項目を淡色で選べなくし、
    キーボードショートカット（Return を含む）は何もしない。
  - （3）複数を対象にする右クリックメニューには、対象の行の種類に関わらず、
    通常のフォルダの右クリックメニューと同じ項目を同じ順で出し、（1）（2）に従って有効・
    無効を決める（「ゴミ箱に入れる」だけが有効になり得る）

### お気に入り

- **FR-061**: システムは、ツリーの最上部（ホームとマウント中のボリュームより上）に、仮想的な項目「お気に入り」
  を常に固定で表示しなければならない。
  - 「お気に入り」はファイルシステム上のフォルダではなく、スターアイコンと「お気に入り」のラベルで表示し、
    通常のフォルダと同じく開閉の三角で展開・折りたたみできる。
  - 登録が0件でも表示する。
  - ほかのツリー項目の並べ替えや外部変更（FR-042）によって位置が変わってはならない
- **FR-062**: ユーザーは、任意のフォルダ（ホーム・ボリュームのルートを含む）をお気に入りに登録できなければならない。
  - 登録はツリーのフォルダの右クリックメニューの「お気に入りに追加」と、キーボードショートカット⌃⌘T（Finder
    の「サイドバーに追加」と同じ）で行う。
  - ショートカットの対象はツリーで選択中のフォルダとする。
  - ファイル名の変更中と、ペインの表示切り替えでツリーを隠している間（FR-092）は ⌃⌘T を無効にする。
  - 登録済みのフォルダを再び登録しても重複させない。
  - 「お気に入り」の見出しやお気に入りの項目を選択中の ⌃⌘T は何もしない
- **FR-063**: 「お気に入り」の下には、登録したフォルダを1件ずつ項目として表示しなければならない。
  - 各項目は開閉の三角を持たず、展開してサブフォルダを辿ることはできない（FR-054・FR-055 のサブフォルダ確認の対象外）。
  - 項目を選択すると、そのフォルダが選択されたものとしてファイルリストをその内容に切り替える（FR-007）。
  - このとき、ツリー下側の実際の階層の展開状態と選択位置は動かさない
- **FR-064**: ユーザーは、「お気に入り」の下の項目を、その項目の右クリックメニューの「お気に入りから削除」と、
  その項目をツリーで選択中の ⌘⌫（ファイルリストの「ゴミ箱に入れる」と同じキー）で、
  お気に入りから削除できなければならない。
  - どちらの手段でも、実行前に対象のお気に入りの表示名（FR-101）と登録したフォルダの絶対パス、
    「お気に入りから削除する」
    旨を示す確認モーダルを表示し（同じ表示名の項目が複数あっても対象を見分けられるようにする）、
    キャンセルした場合は登録を変えてはならない。
  - 確認モーダルの省略設定（FR-023）がオンのときは、ファイル操作と同じく確認を省略して即座に削除する。
  - 削除はお気に入りの登録だけを取り除き、実際のフォルダとその中身を変更してはならない（ゴミ箱にも入れない）。
  - お気に入りの項目の右クリックメニューには「ゴミ箱に入れる」を出さない。
  - ホーム・ボリュームの最上位・「お気に入り」の見出しの右クリックメニューには削除の項目を出さず、それらを選択中に ⌘⌫
    を押しても何もしない。
  - ツリーの通常のフォルダは FR-079 に従ってゴミ箱に入れられる。
  - ファイルリストにフォーカスがあるときの ⌘⌫ は、従来どおり選択中のファイルをゴミ箱に入れる（FR-019）
- **FR-065**: ユーザーは、キーボードショートカット ⇧⌘F で、ツリーの選択を「お気に入り」
  の見出しの行へ移せなければならない。
  - ⇧⌘F はキーボードフォーカスをツリーへ移し、「お気に入り」が折りたたまれていれば展開する。
  - どのペインにフォーカスがあっても、
    フルスクリーン表示中とファイル名の変更中でなければ使える（ペインの表示切り替えでツリーを隠している間は FR-092
    により無効）。
  - 見出しの行は、⇧⌘F・クリック・矢印キーのどれで選択した場合も選択できるが、フォルダの選択として扱わない。
  - ファイルリスト・プレビュー・再生中の動画は直前のフォルダの状態のまま変えず、最後に選択していたフォルダ（FR-003）
    も更新しない。
  - 続けて矢印キーでお気に入りの項目を選ぶと、FR-063 のとおりそのフォルダの表示に切り替わる
- **FR-066**: お気に入りの登録内容は FR-003 に従い保存し、次回起動時に復元しなければならない
- **FR-067**: 登録したフォルダが登録時の場所に見つからない場合（アプリの外での削除・移動・名前変更、
  ボリュームの取り外し、起動時に存在しない等）、システムはその項目をお気に入りから自動で消してはならず、
  見つからないことが分かる表示（淡色など）で残さなければならない。
  - 移動先・新しい名前には追従しない。
  - 見つからない項目を選択したときは、
    ファイルリストに既存の読み込めない旨の表示（存在しないフォルダを開いたときと同じ「フォルダが見つかりません」）
    を出す。
  - 同じ場所にフォルダが戻った場合（ボリュームの再接続など）は、外部変更の反映（FR-042）
    と同様に自動で通常の表示に戻す。
  - 見つからない項目も FR-064 の手段で削除できる
- **FR-099**: ユーザーは、「お気に入り」の下の項目の表示名を、次のどの手段でも変更できなければならない。
  - （1）その項目をツリーで選択し、ツリーにキーボードフォーカスがあるときに Return を押す。
  - （2）その項目の右クリックメニューの「名前を変更」を選ぶ（右クリックした行を対象にする。A-21）。
  - （3）ツリーにキーボードフォーカスがあり、その項目を選択しているときに、「編集」メニューの「名前を変更」を選ぶ。
  - 名前の編集はその項目の行の中で行い、編集を始めたときは現在の表示名を全選択した状態にする。
  - Return またはほかの場所のクリックなどで編集を終えたときは確定し、Esc
    を押したときは取り消して編集前の表示名に戻す。
  - 名前の変更はお気に入りの表示名だけを変え、実際のフォルダの名前・場所・中身を変更してはならない。
  - ファイルシステムを変えないため、確認モーダル（FR-022・FR-024）は表示しない。
  - 「お気に入り」の見出しとホーム・ボリュームの最上位を選択中の Return は何もせず、
    それらの右クリックメニューに「名前を変更」は出さない。
  - ツリーの通常のフォルダの Return・「名前を変更」は、実際のフォルダの名前の変更（FR-103）とする。
  - ツリーにフォーカスがあり、お気に入りの項目と通常のフォルダ以外を選択しているときは、「編集」
    メニューの「名前を変更」は無効にする。
  - ファイルリストに zip の中（FR-073）または検索結果を表示中でも、
    ツリーにフォーカスがありお気に入りの項目を選択していれば（1）〜（3）は使える（zip
    の中の読み取り専用と検索結果の制限はファイルリストの操作にだけ適用する）。
  - ファイルリストにフォーカスがあるときの Return と「名前を変更」は、従来どおりファイル名の変更（FR-019）とする
- **FR-100**: システムは、確定した名前を次のとおり扱わなければならない。
  - 前後の空白（改行を含む）を取り除く。
  - 取り除いた結果が空なら、表示名の変更を解除して、登録したフォルダの名前で表示する。
  - 名前は1行とし、改行は入力できない。
  - 長さは 255 文字までとし、それを超える入力はできない。
  - ファイル名として使えない文字（`/`・`:` など）も含めてよい。
  - ほかのお気に入りの項目と同じ名前も受け付ける。
  - 編集前と同じ名前で確定した場合は何も変えない
- **FR-101**: お気に入りの項目には、表示名を変更していればその名前を、
  変更していなければ登録したフォルダの名前を表示しなければならない。
  - この表示名は、ツリーの項目の表示、アクセシビリティ API に公開する項目の名前、
    お気に入りの削除の確認モーダル（FR-064）の対象の名前に使う。
  - 名前の編集欄には「お気に入りの名前」というアクセシビリティラベルを付ける。
  - 表示名はお気に入りの登録内容の一部として FR-066 に従い保存し、次回起動時に復元する。
  - 表示名を変更する機能を入れる前に登録したお気に入りは、
    登録順のまま表示名を変更していない項目として復元しなければならない（保存形式を変える場合は旧形式から読み替える）。
  - 表示名は登録したフォルダが見つからない間（FR-067）も保ち、変更できる。
  - お気に入りから削除したときは表示名も破棄する
- **FR-102**: お気に入りの表示名の編集中とツリーのフォルダの名前の編集中（FR-103）は、
  ファイル名の変更中と同じ扱いとしなければならない。
  - 既存の項目がいう「ファイル名の変更中」は、ファイル名の変更・お気に入りの表示名の編集・
    ツリーのフォルダの名前の編集のすべて（以下「名前の変更中」）を指すものとし、既存の項目の本文は変えない。
  - 契約（contracts/keyboard-and-menus.md）で名前の変更中に無効とされている操作のすべて（⌃⌘T（FR-062）・⇧⌘F（FR-065）
    ・⌘F（FR-080）・ペインの表示切り替え（FR-090）・zip ファイルの表示切り替え（FR-096）・種類フィルタの「表示」
    メニュー項目・「中を表示」「上の階層へ」・検索結果の表示を終える Esc・戻る・進む（FR-112（navigation-history.md）））
    は、編集を終えるまで無効にする。
  - 編集を始めても、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003）は変えない
- **FR-106**: ツリーで名前を変えたフォルダ、またはその配下のフォルダがお気に入りに登録されている場合、
  システムはファイルリストでフォルダの名前を変えた場合（EC-17）と同じく、その項目を
  FR-067に従って見つからない表示（淡色）にし、新しい名前に追従してはならない。
  - その後、ツリー・ファイルリスト・アプリの外のいずれかでフォルダを元の名前（元の場所）に戻したときは、
    項目を通常の表示に戻す。
  - このとき、項目の並び位置と表示名（FR-101）は名前を変える前と同じでなければならない
- **FR-182**: ユーザーは、ツリーの通常のフォルダ、ホーム、マウント中のボリュームの最上位、
  利用可能なお気に入りの項目の行の右クリックメニューの「パス名をコピー」で、その絶対パスをコピーできなければならない。
  - 右クリックした行を対象にし、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003）
    は変えない（A-21）。
  - お気に入りの項目では登録したフォルダの絶対パスをコピーする。
  - 「お気に入り」の見出しはメニューを出さない（従来どおり）

## 主なエンティティ

- **フォルダ（ディレクトリ）**: ツリーのノード。
  - 名前、場所、子フォルダ、アクセス可否、行頭に表示するフォルダアイコン、サブフォルダの有無（未確認／あり／なし／
    確認失敗。「あり」と「確認失敗」のときだけ開閉できる）を持つ。
  - 親フォルダの一覧ではファイルリストの項目にもなり（名前、場所、作成日、種類「フォルダ」）、
    ファイル操作の対象になる。
  - ツリーのノードとしても、ゴミ箱に入れる操作と名前の変更の対象になる（ホーム・ボリュームの最上位を除く）。
  - 名前を変えると、そのフォルダと配下の場所が変わり、それを表示・参照しているツリー・ファイルリスト・検索結果・
    最後に選択していたフォルダは新しい場所に追従する。
  - お気に入りの登録は追従しない（FR-106）
- **ボリューム**: ツリーのルートの1つ。マウント・取り外しされる
- **お気に入り**: ユーザーが登録したフォルダの一覧。
  - 各登録はフォルダの場所、ユーザーが付けた表示名（任意。付けていなければ登録したフォルダの名前で表示する）、
    その場所にフォルダが見つかるかどうか（見つかる／見つからない）を持ち、ツリー最上部の仮想項目「お気に入り」
    の下に表示される。
  - 実際のフォルダとは独立し、登録・削除・名前の変更はファイルシステムを変更しない

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS1**: **Given** アプリ起動直後,
  - **When** ツリーでフォルダを展開する,
  - **Then** その直下のサブフォルダが階層表示され、さらに展開・折りたたみできる
- **US1-AS7**: **Given** ツリーにフォルダが表示されている,
  - **When** ツリーを見る,
  - **Then** 各フォルダ名の先頭にフォルダアイコンが表示され、ホーム・マウント中のボリューム・
    通常フォルダがアイコンで区別できる。展開・折りたたみの操作と選択状態はアイコンによって妨げられない
- **US1-AS8**: **Given** ツリーにフォルダが表示されている,
  - **When** フォルダの行（アイコンまたはフォルダ名）をダブルクリックする,
  - **Then** そのフォルダが選択されてファイルリストがその内容に切り替わり、さらに折りたたまれていれば展開し、
    展開されていれば折りたたむ
- **US1-AS9**: **Given** サブフォルダ（隠しフォルダとパッケージを除く）を持たないフォルダがツリーに表示されている,
  - **When** ツリーを見る／その行をダブルクリックする,
  - **Then** そのフォルダには開閉の三角が表示されず、ダブルクリックしても選択だけが行われ展開されない
- **US1-AS10**: **Given** ツリーを表示中,
  - **When** ツリーの最上部を見る,
  - **Then** スターアイコンと「お気に入り」のラベルを持つ項目が、ホームとボリュームより上に固定で表示され、
    開閉の三角で展開・折りたたみできる
- **US1-AS11**: **Given** ツリーで任意のフォルダを右クリックした,
  - **When** 「お気に入りに追加」を選ぶ,
  - **Then** そのフォルダが「お気に入り」の下に追加される。ツリーでフォルダを選択して ⌃⌘T
    を押した場合も同じく追加される
- **US1-AS12**: **Given** 「お気に入り」の下にフォルダが登録されている,
  - **When** その項目をクリックする,
  - **Then** そのフォルダが選択されてファイルリストがその内容に切り替わり、
    ツリー下側の実際の階層の展開状態は変わらない。項目には開閉の三角が表示されない
- **US1-AS13**: **Given** 「お気に入り」の下の項目を右クリックした（またはツリーでその項目を選択した）,
  - **When** 「お気に入りから削除」を選ぶ（または ⌘⌫ を押す）,
  - **Then** 確認モーダルが表示され、確定するとその項目が「お気に入り」から消え、
    実際のフォルダには何も変更が加わらない（ゴミ箱にも入らない）。
    キャンセルすると登録はそのまま残る。確認モーダルの省略設定がオンなら、確認なしで即座に消える
- **US1-AS14**: **Given** ファイルリストにフォルダの内容を表示中で、「お気に入り」が折りたたまれている,
  - **When** ⇧⌘F を押す,
  - **Then** キーボードフォーカスがツリーに移って「お気に入り」が選択・展開され、
    ファイルリストとプレビューは直前の表示のまま変わらない。続けて ↓ キーでお気に入りの項目を選ぶと、
    そのフォルダの内容に切り替わる
- **US1-AS30**: **Given** 「お気に入り」の下に登録したフォルダの項目があり、ツリーでその項目を選択している,
  - **When** Return を押して新しい名前を入力し、Return で確定する,
  - **Then** その項目は新しい名前で表示され、
    実際のフォルダの名前とファイルリストの表示内容は変わらない。確認モーダルは表示されない
- **US1-AS31**: **Given** 「お気に入り」の下に登録したフォルダの項目がある,
  - **When** その項目を右クリックして「名前を変更」を選び、新しい名前を入力して確定する,
  - **Then** US1-AS30 と同じく、その項目だけが新しい名前で表示され、実際のフォルダの名前は変わらない
- **US1-AS32**: **Given** お気に入りの項目の名前を編集している,
  - **When** Esc を押す,
  - **Then** 編集を取り消し、項目は編集前の名前のまま表示される
- **US1-AS33**: **Given** 名前を変えたお気に入りの項目がある,
  - **When** 名前を空にして確定する,
  - **Then** 項目の名前は登録したフォルダの名前に戻る
- **US1-AS34**: **Given** 名前を変えたお気に入りの項目がある,
  - **When** アプリを終了して再び起動する,
  - **Then** その項目は変更後の名前で表示される
- **US1-AS35**: **Given** ツリーで「お気に入り」の見出し、またはホーム・ボリュームの最上位を選択している,
  - **When** Return を押す,
  - **Then** 何も起きない（名前の編集は始まらず、実際のフォルダの名前も変わらない）。ツリーの通常のフォルダの Return
    は、実際のフォルダの名前の変更（US1-AS36）とする
- **US1-AS36**: **Given** ツリーで通常のフォルダを選択し、ツリーにキーボードフォーカスがある,
  - **When** Return を押して新しい名前を入力し、Return で確定して確認モーダルで「実行」を選ぶ,
  - **Then** 実際のフォルダの名前が変わり、ツリーでは新しい名前で並び順の位置に表示され、
    選択と展開状態はそのまま保たれる
- **US1-AS37**: **Given** ツリーでフォルダ A を選択している,
  - **When** 別のフォルダ B の行を右クリックして「名前を変更」を選び、名前を確定して確認モーダルで「実行」を選ぶ,
  - **Then** フォルダ B の名前が変わり、ツリーの選択はフォルダ A のまま、ファイルリストの表示も変わらない
- **US1-AS38**: **Given** ツリーのフォルダの名前を編集している,
  - **When** Esc を押す,
  - **Then** 編集を取り消し、確認モーダルは出ず、フォルダの名前は変わらない。確認モーダルで「キャンセル」
    を選んだ場合も名前は変わらない
- **US1-AS39**: **Given** ツリーのフォルダの名前を編集している,
  - **When** 「/」「:」を含む名前、先頭が「.」の名前、
    同じ場所にある別の項目と同じ名前（大文字小文字の違いだけのものを含む）、またはパッケージとして扱われる名前（例:
    `Photos.app`）で確定する,
  - **Then** ファイルリストの名前の変更と同じ検証エラーが表示され、フォルダの名前は変わらない
- **US1-AS40**: **Given** ファイルリストにツリーで選択したフォルダの内容を表示し、ファイルを選択してプレビュー中,
  - **When** ツリーでそのフォルダ（またはその祖先）の名前を変える,
  - **Then** ファイルリストの項目・選択・スクロール位置とプレビューは変わらず、再生中の動画も止まらない。続けて ⌘↑ や
    `..` で戻ると、新しい名前のフォルダの親に戻る
- **US1-AS41**: **Given** ファイルリストにフォルダ P の一覧を表示中で、P のサブフォルダ C がツリーにも表示されている,
  - **When** ツリーで C の名前を変える,
  - **Then** ファイルリストの C の行も新しい名前になり、並び順の位置へ移る
- **US1-AS42**: **Given** 検索結果を表示中で、一覧の「場所」列にフォルダ F を含むファイルがある,
  - **When** ツリーで F の名前を変える,
  - **Then** それらのファイルは一覧に残り、「場所」列（サムネイル形式ではツールチップ）
    が新しい名前に変わる。選択とプレビューはそのまま保たれる
- **US1-AS43**: **Given** フォルダ F がお気に入りに登録され、表示名を変えている,
  - **When** ツリーで F の名前を変える,
  - **Then** お気に入りの項目は見つからない表示（淡色）になる。もう一度 F の名前を元に戻すと、項目は同じ位置・
    同じ表示名のまま通常の表示に戻る
- **US1-AS45**: **Given** ツリーでホーム・ボリュームの最上位・「お気に入り」
  の見出しを選択している（または右クリックした）,
  - **When** Return を押す（または右クリックメニューを見る）,
  - **Then** 名前の編集は始まらず、右クリックメニューに「名前を変更」は出ない

### US38 複数選択中の表示とメニュー（P2）

- **US38-AS1**: **Given** A を選択して A の内容を表示している,
  - **When** ⌘クリックで B を追加する,
  - **Then** ファイルリストは B の内容に切り替わる。Shift+↓ で選択を広げたときは、
    最後に移動した行のフォルダの内容を表示する
- **US38-AS2**: **Given** A・B を選択し B の内容を表示している,
  - **When** ⌘クリックで A を選択から外す,
  - **Then** ファイルリストの表示は B のまま変わらない
- **US38-AS3**: **Given** ツリーで2行以上を選択している,
  - **When** Return を押す、または「編集」メニューの「名前を変更」「パス名をコピー」や「ファイル」
    メニューの「お気に入りに追加」「Finder に表示」を見る,
  - **Then** Return は何もせず、それらのメニュー項目は淡色で選べない。右クリックメニューでも、
    複数を対象にするときは「ゴミ箱に入れる」以外の項目を淡色で選べなくする
- **US38-AS4**: **Given** A・B を選択し B の内容を表示している,
  - **When** ファイルリストで B のサブフォルダ B1 を開く,
  - **Then** ツリーの選択は B1 の1行になり、以後の Shift+↑↓ は B1 を起点にする（FR-216）

## エッジケース

- **EC-05**: 読み取り権限のないフォルダをツリーで選択した場合、アクセスできない旨を表示し、他の操作は継続できる。
  - このフォルダには開閉の三角を表示せず、ダブルクリックしても展開しない
- **EC-06**: サブフォルダを持たないフォルダ、
  または隠しフォルダやパッケージしか持たないフォルダには開閉の三角を表示せず、ダブルクリックしても展開しない
- **EC-07**: 読み取り権限以外の理由でサブフォルダの有無を確認できなかったフォルダは、
  三角を表示して開閉できるようにし、展開時に読めなければアクセスできない旨を表示する
- **EC-18**: 外付けドライブやネットワークボリュームが取り外された場合、該当ツリーノードを消し、関連する表示を空にする
- **EC-20**: お気に入りに登録したフォルダが削除・移動・名前変更された場合や、そのボリュームが取り外された場合は、
  項目を残したまま見つからない表示にし、選択するとファイルリストに「フォルダが見つかりません」を表示する。
  - 同じ場所に戻れば通常の表示に戻る
- **EC-40**: 前後の空白だけの名前、または空の名前で確定した場合は、名前の変更を解除し、
  登録したフォルダの名前で表示する（エラーにしない）
- **EC-41**: ほかのお気に入りの項目と同じ名前、または登録したフォルダの名前と同じ名前で確定した場合も、
  そのまま受け付ける（お気に入りの名前は実際のファイル名ではないため、重複を拒否しない）
- **EC-42**: 見つからない項目（FR-067）も名前を変えられる。
  - 名前を変えても見つからない表示（淡色）はそのまま続き、同じ場所にフォルダが戻れば変更後の名前のまま通常の表示に戻る
- **EC-43**: 名前の編集中に、登録したフォルダがアプリの外で削除・移動・名前変更された場合も、編集は続けられる。
  - 確定した名前はその項目に付き、項目は FR-067 に従って見つからない表示になる
- **EC-44**: お気に入りから削除した項目は、付けていた名前も破棄する。
  - 同じフォルダを再び登録すると、登録したフォルダの名前で表示される
- **EC-45**: 表示名を変更する機能を入れる前のバージョンで登録したお気に入りは、アップデート後も登録順のまま、
  登録したフォルダの名前で表示される（登録が失われたり、並びが変わったりしない）
- **EC-46**: ファイルリストに zip の中や検索結果を表示中に、ツリーのお気に入りの項目の名前を変えても、
  ファイルリストの表示内容・選択・プレビューは変わらない
- **EC-50**: ファイルリストに、名前を変えたフォルダ（またはその配下）にある zip ファイルの中を表示している場合も、zip
  の中の一覧・選択・プレビューは変わらない。
  - 以後の `..`・⌘↑ は新しい場所を辿る
- **EC-51**: お気に入りの項目を選択してそのフォルダをファイルリストに表示中に、
  ツリーの実際の階層でそのフォルダ（またはその祖先）の名前を変えた場合、お気に入りの項目は見つからない表示になるが、
  ファイルリストの表示は変えない（FR-104）。
  - その項目を選択し直すと「フォルダが見つかりません」を表示する（FR-067）
- **EC-148**: 2行以上を選択しているときに、選択中の行を含む親フォルダを折りたたんで行が見えなくなった場合、
  見えなくなった行は選択から外れ、親フォルダの行は選択に加わらない。
  - ファイルリストの表示は変えない（主の行が隠れた場合も変えない）。
  - 隠れた主の行からの ↑↓・Shift+↑↓ は、主の行を隠したフォルダの行を起点にする

## 成功基準

- **SC-013**: ツリーの表示サイズで、ホーム・マウント中のボリューム・通常フォルダの3種類のアイコンが
  相互に判別できる
- **SC-018**: 場所の違う同じ名前のフォルダを2つお気に入りに登録し、片方の名前を変えたあと、
  ユーザーがツリーの表示だけで目的のフォルダの項目を選べる割合が 100%（取り違え 0 件）
- **SC-019**: お気に入りの名前の変更を行ったあと、実際のフォルダの名前・場所・中身に変更が残るものが 0 件
- **SC-020**: Finder の操作に慣れたユーザーが、説明なしでお気に入りの項目の名前の変更を初回で完了できる
- **SC-021**: 変更した表示名が、アプリの再起動後に 100% 復元される
- **SC-022**: Finder の操作に慣れたユーザーが、説明なしでツリーのフォルダの名前の変更を初回で完了できる
- **SC-023**: ツリーのフォルダの名前の変更を Esc・確認モーダルのキャンセル・検証エラーで終えたとき、
  ファイルシステムに変更が残るものが 0 件（SC-006と同じ基準）
- **SC-024**: ファイルリストに表示中のフォルダ（またはその祖先）の名前をツリーで変えたとき、ファイルリストの項目・
  選択・スクロール位置・プレビューが変わる場合が 0 件
- **SC-026**: お気に入りに登録したフォルダの名前を変えて元に戻したとき、項目が通常の表示・同じ並び位置・
  同じ表示名に戻る割合が 100%

## 前提

- **A-04**: ツリーのルートは Finder のサイドバーに近い「ホームフォルダ + マウント中のボリューム」とした
- **A-19**: お気に入りの項目名は、既定では登録したフォルダの名前とし、ユーザーが表示名を変更できる（FR-099）。
  - 並びは登録した順（新しいものを末尾）とする。
  - 並べ替え・ドラッグによる登録は範囲外
- **A-20**: お気に入りの見出しはドロップ先・ペースト先にしない。
  - 利用可能なお気に入りの項目はアプリ内ドラッグのドロップ先として登録先の実フォルダを使える。
  - 見つからない項目はドロップ先にしない。
  - お気に入りの項目をペースト先にはしない。
  - アプリ外とのドラッグの既存動作は今回変更しない。

- **A-21**: ツリーの右クリックメニューの各項目は、Finder と同じく右クリックした行を対象にする（選択中の行ではない）。
  - お気に入りの追加・削除・名前の変更、ツリーのフォルダの「ゴミ箱に入れる」「名前を変更」（FR-079・FR-103）、
    「新規フォルダ」（FR-208）と、既存の「ここにペースト」「ここに移動ペースト」「Finder に表示」に同じ規則を使う
- **A-27**: 「お気に入り」の見出しの開閉状態は保存せず、起動時は折りたたんだ状態で始める
- **A-28**: ツリーのフォルダアイコンは「ホーム」「マウント中のボリューム」「通常のフォルダ」の3種類を区別し、
  展開状態によるアイコンの変化は設けない。
  - ファイルリストの行頭アイコンは実際の縮小画像を使い、形式別の独自アイコンセットはフォールバック用の最小限にとどめる
- **A-29**: お気に入りの名前の変更は、ファイルの名前の変更（FR-024）と違って確認モーダルを出さない。
  - ファイルシステムを変えず、Esc で取り消せ、空にして確定すれば元の名前に戻せるため、
    憲章の「確認または取り消し可能性」を満たす
- **A-30**: 次は今回の範囲外とする。
  - 選択中の項目のクリックや一定時間の長押しによる編集の開始（お気に入りの項目とツリーのフォルダの両方）、
    お気に入りの項目への絶対パスのツールチップの表示、表示名の一括リセット
- **A-31**: 編集をほかの場所のクリックなどで終えたときに確定する扱いは、Finder の名前の変更に合わせた
- **A-32**: ツリーのフォルダの名前の変更の操作・検証・確認は、
  ファイルリストのフォルダの名前の変更に合わせた（入力内容の指定）。
  - 確認モーダルは名前の変更の既存の規則（FR-024）どおり常に表示する
- **A-33**: 「削除前に確認モーダルを必ず出す」は、
  ツリーのフォルダをゴミ箱に入れる操作では確認モーダルの省略設定（FR-023）を適用しない意味と解釈した。
  - ツリーでは選択中でない行を右クリックして削除できるため、取り違えを防ぐ確認を省略しない。
  - ファイルリストからのゴミ箱に入れる操作とお気に入りの削除は、従来どおり省略できる
- **A-34**: 「リネーム対象のフォルダが検索結果に表示されている」は、検索結果の「場所」
  列（サムネイル形式ではツールチップ）や検索バーの起点にそのフォルダが含まれている状態、
  またはそのフォルダが検索結果のフォルダの行になっている状態（FR-083・FR-139）と解釈した。
  - 「検索条件に該当しなくなったら外れる」は、名前の変更で新しい場所が検索の対象外（FR-083）
    になったファイルとフォルダを外すことと解釈した。
  - フォルダの行は、名前を変えてキーワードに一致しなくなっても外さない（FR-087・FR-105）。
  - ただし、検索の対象外になる名前（先頭の「.」、パッケージになる名前）は FR-103・EC-53 で拒否するため、
    アプリの中での名前の変更で外れる項目は実際には出ない

- **A-35**: 「ファイルリストのフォルダーの表示は変わらない」は、
  ファイルリストが名前を変えたフォルダ自身（またはその配下）を表示しているときに、一覧の内容・選択・スクロール・
  プレビューを保つ意味と解釈した。
  - ファイルリストが親フォルダを表示していて名前を変えたフォルダが行として見えている場合は、
    その行の名前を新しくする（FR-027）
- **A-36**: 右クリックメニューから選択中でない行の名前を変えた・ゴミ箱に入れたときは、
  ツリーの選択を対象の行へ移さない（A-21の「右クリックした行を対象にする」規則と、既存の FR-079 の振る舞いに合わせた）
- **A-37**: ツリーの右クリックメニューの「名前を変更」は、ファイルリストの右クリックメニューと同じく「ゴミ箱に入れる」
  の次の区切り線の後に置く。
  - 項目名は Finder とファイルリストに合わせて「名前を変更」とする
- **A-38**: 名前を変えたフォルダの中のファイルをコピー（⌘C）した後に名前を変えた場合、
  クリップボードは古い場所を指したままになる。
  - そのペーストは失敗として FR-026 に従って表示し、クリップボードの内容を新しい場所へ読み替えることはしない
- **A-39**: ホームフォルダとマウント中のボリュームの最上位の名前の変更は範囲外とする。
  - 通常フォルダ自身の大文字小文字だけの変更（`Album` → `album`）は FR-025・FR-103 に従って許可する。
- **A-126**: ツリーの全選択（⌘A）は追加しない。
  - ツリーにフォーカスがあるときの ⌘A は従来どおりツリーの選択を変えない。
  - ルートやお気に入りを含む全行の選択は、一括操作の対象にならず（FR-218）有用でないため
- **A-127**: 複数の対象の確認モーダルは、ファイルリストの確認モーダルと同じく先頭の5件と残りの件数を示し、
  ツリーの規則（FR-079）に合わせて各件に絶対パスを添える
- **A-128**: 移動・削除の後のツリーの選択は、残った選択や失敗した項目を保たず、主の行の単一選択に戻す（FR-219）。
  - 複数選択の行が消えた後に、見えている選択とファイルリストの表示の関係を単純に保つため。
  - コピー・キャンセル・すべて失敗のときは、ファイルリストの FR-165 と同じく選択を保つ
- **A-129**: ツリーの一括削除はドラッグでは行わない（Dock のゴミ箱などアプリの外へのドラッグの変更は FR-163
  のとおり対象外）。
  - ⌘⌫ とメニュー・右クリックの「ゴミ箱に入れる」で行い、ファイルリストの一括削除と同じ操作経路にする
- **A-130**: お気に入りの項目の一括削除（お気に入りからの登録の削除）は対象外とする。
  - お気に入りを含む複数の対象では、⌘⌫ と「お気に入りから削除」を無効にする（FR-218）
- **A-131**: 1行だけを選択しているときに、
  その行を含む親フォルダを折りたたんだ場合の振る舞いは変えない（現行の仕様に規定がなく、複数選択の目的の外のため）。
  - EC-148 は2行以上の選択に限る
- **A-132**: ⌘・Shift を押しながら行からドラッグを始める操作は、選択の変更として扱い、ドラッグは始めない。
  - ドラッグは修飾キーなしで始め、コピーはドロップ時の Option で行う（FR-020）
