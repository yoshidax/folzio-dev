# UI Contract: キーボード操作とメニュー

ユーザーに公開する操作体系の契約。割り当ては Finder に準じる（FR-019）。すべての操作をキーボードだけで
実行できること（FR-040、憲章 原則 III）を、この表で網羅的に担保する。新しい操作を追加するときは、
必ずこの表に行を追加する。

「名前の変更中」は、ファイルリストでのファイル名の変更（FR-019）、ツリーでのお気に入りの表示名の編集（FR-099）、
ツリーでのフォルダの名前の編集（FR-103）のすべてを指す（FR-102）。

以下の表示名は日本語の表示名。英語は [localization.md](localization.md) を参照（FR-152）。

## ショートカット一覧（FR-200〜207）

### 起動・終了

「ファイル」の検索項目より後、ゴミ箱グループより前に「ショートカット一覧…」（Keyboard Shortcuts…、⌘/）を置く。
ファイルメニュー末尾に区切りと「閉じる」（Close、⌘W）を置く。

| 操作 | 結果 |
|---|---|
| ⌘/ / ファイル > ショートカット一覧… | 既存の親の一覧を作成または前面化。再実行で閉じない |
| ⌘W / ファイル > 閉じる | キー入力先の閉じられるウィンドウだけを閉じる |
| 親を閉じる | 対応する一覧も閉じる |
| 一覧の ↑↓ / Page Up・Down / Home・End | 一覧だけを縦スクロール |
| 一覧の Esc | 何もしない。親へ流さない |

起動は親終了後・名前の編集・親sheet・app modal・親全画面・slideshow中は無効。
設定や一覧がキーの場合も同じ親を対象とする。親へクリックすれば通常どおり操作できる。
既存の明示ターゲットを持つプレビュー拡大縮小のメニューは既存契約どおり親を操作する。

### 掲載範囲と固定順

以下はカタログと全行を照合する一覧。1行を1項目とし、合計45項目。
説明は日本語・英語の完全な文として翻訳する。条件は短い注記にし、現在無効でも項目を隠さない。
条件を省略した既存操作の解釈は 本契約の各操作の節 に従う。
OS標準の一般編集キー・設定内の各コントロールのキー・マウス操作の網羅は対象外。

### 表示とアクセシビリティ

見出し→キー→説明→条件の順。キー列の幅は揃え、説明・条件は残り幅で折り返す。
初期640×680pt、最小480×360ptの内容領域。スクロール内容の先頭が開いた直後の入力対象。
装飾は system colors と標準フォントを使用する。条件は色だけで区別しない。
VoiceOver は各見出しと項目のキー・説明・条件を対応づけて読めること。
言語切り替えで文を更新しても行IDと先頭可視項目を保持する。

### 同期の検証

契約表の44項目をカタログの ID とキー表記に照合し、翻訳の空欄・欠落・内部キー表示を自動検出する。
実際の入力処理との一致は quickstart の全項目照合を実施し、未確認を成功扱いにしない。
メニュー以外のキーはフォーカスと状態に依存するため、一覧自体は有効性のライブ表示を行わない。

## ペイン間のフォーカス移動

| キー | 動作 |
|------|------|
| Tab / ⇧Tab | ツリー → リスト → プレビュー の順（逆順）にフォーカスを移す。ペインの表示切り替えで隠しているペインは飛ばし、表示中のペインの間だけを巡回する（FR-092） |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | ツリー / リスト / プレビューへ直接フォーカスする。ペインの表示切り替えで隠しているペインの項目は淡色で、ショートカットは何もしない（FR-092） |
| ⇧⌘F | ツリーへフォーカスし、「お気に入り」の見出しを選択する。折りたたまれていれば展開する。ファイルリスト・プレビューは変えない。フルスクリーン中・名前の変更中・ペインの表示切り替えでツリーを隠している間は無効（FR-065・092） |

## 履歴の移動（FR-107〜113）

| キー / 操作 | 動作 | 要件 |
|-------------|------|------|
| ⌘[ / 移動 > 戻る / ツールバーの `<` | 1つ前の履歴へ移り、その履歴の場所と表示の状態を復元する。戻る側に履歴がないときは何もしない | FR-108・112 |
| ⌘] / 移動 > 進む / ツールバーの `>` | 1つ後の履歴へ移り、その履歴の場所と表示の状態を復元する。進む側に履歴がないときは何もしない | FR-108・112 |
| 検索結果の表示中の ⌘[ | 検索結果の表示を終えて（検索中なら止めて）Esc（FR-086）と同じ場所に戻る。戻る側の履歴へは移らず、戻る側に履歴がなくても使える。zip の中で始めた検索では zip ファイルを含むフォルダに戻り、その場所を新しい履歴として記録する | FR-113 |

- 戻る・進むは、ツールバー・メニュー・ショートカットのどこから行っても同じ履歴を使う。ツールバーが非表示でもメニューと
  ショートカットで使える（FR-040・112）
- 戻る側（進む側）に履歴がないときは、ツールバーのボタンとメニュー項目を淡色にし、ショートカットは何もしない。
  検索結果の表示中は「進む」を無効にする（FR-112・113）
- 検索結果のフォルダの行を開くと、検索結果を履歴に残さず、検索終了時の表示状態を現在の履歴に反映してから開いた場所を記録する。検索前と同じ場所・状態なら記録しない。zip 内から始めた検索では、開いたフォルダを zip 内の場所の次に記録する（FR-113・140、EC-99・100）
- 名前の変更中・フルスクリーン中・スライドショー実行中は、`<`・`>`・メニュー項目・⌘[・⌘] を無効にする（FR-102・112）
- ツールバーのボタンには「戻る」「進む」をアクセシビリティラベルとツールチップとして付ける（FR-112）

## スライドショー（FR-114・118・120〜123・127〜132）

| 操作 | 動作 | 要件 |
|------|------|------|
| ⇧⌘S / 表示 > スライドショーを開始 / ツールバーの「スライドショーを開始」ボタン | スライドショーを開始する。表示中の一覧に対応メディアが1件以上あるときだけ有効で、名前の変更中・モーダル表示中・実行中は無効。ツールバー非表示中・全画面中もショートカットを使える | FR-114 |
| Esc（実行中で入力受理条件を満たす） | スライドショーを終了する。全画面中なら同時に解除し、開始前のペイン表示・フォーカス・幅へ戻す。終了だけを理由に最後の動画を止めない（復帰先がファイルリストのみなら停止・消音） | FR-123 |
| ↑ / ↓（実行中で受理条件を満たす。リスト形式） | 隠れたファイルリストの前 / 次のメディアへ選択を移す。端では止まり、押下のたびに待ち時間を取り直す。自動送りは取り消さない | FR-120・121 |
| ↑ / ↓ / ← / →（実行中で受理条件を満たす。サムネイル形式） | 隠す直前の列数を基準に選択を移す。← / → は端で止まり、押下のたびに待ち時間を取り直す | FR-120・121 |
| ⌃⌘F / メディア表示区画のダブルクリック / 全画面メニュー（実行中） | 全画面を切り替えても実行・選択・動画の再生位置と状態・次の送りまでの残り時間を保つ。解除後もプレビューのみ表示を続ける | FR-122 |
| 矢印キー・Esc・全画面の切り替え（準備待ち・効果の表示中） | 効果の完了を待たず、効果を打ち切って操作の結果を即座に表示する。矢印は選択中のメディア（次の対象）を起点に選び直し、Esc はその選択を保って終了する | FR-131、EC-80 |
| ⌘, | 設定ウインドウを開く。実行中も開け、変更は次の自動送りから反映する。編集中の Esc は間隔の編集だけを取り消し、ウインドウもスライドショーも閉じない | FR-127・128・132 |

- Esc・矢印をスライドショー入力として受理するのは、実行中の対象ウィンドウがキー入力先で、シート・アプリモーダルがなく、編集欄が
  入力を受けていない場合だけ。メニュー等がキーを処理する間も横取りしない。条件を満たさないキーは既存の入力先へ渡し、終了・移動・
  期限変更を行わない（FR-123）
- 切り替え効果は自動送りだけに使う。矢印による選び直し・開始時の最初の表示・終了時の復帰・スライドショー以外の選択変更には付けない。
  効果の表示中もマウスのクリックは下のプレビューへ届き、VoiceOver の要素にはしない（FR-130・131）
- macOS の「視差効果を減らす」がオンの間は「スライド」「ズーム」を「クロスフェード」で表示し、保存値と設定ウインドウの表示は変えない（FR-131、A-59）

設定ウインドウのキーボード操作:

| 入力 | 動作 | 要件 |
|------|------|------|
| Tab / ⇧Tab | 動画を自動再生する → 動画をループ再生する → 確認する → 切り替え間隔 → 繰り返す → 切り替え効果 → 先頭へ戻る（⇧Tab は逆順）。システムのキーボードナビゲーションの設定に関わらず、すべての項目に止まる | FR-127 |
| Space（チェックボックス） | オン / オフを切り替えて保存する | FR-127 |
| Space（ポップアップメニュー） | メニューを開く。矢印キーで選び、Return で確定して保存する | FR-127 |
| Return / フォーカスの移動 / ウインドウを閉じる（切り替え間隔の編集中） | 値を検証して確定する。不正な値は保存せず、直前の有効値の表示へ戻す | FR-128、EC-73 |
| Esc（切り替え間隔の編集中） | 編集を取り消して直前の有効値の表示へ戻す。保存せず、設定ウインドウもスライドショーも閉じない | FR-128 |

- アクセシビリティのラベル: 切り替え間隔は「切り替え間隔（秒）」、繰り返しは「最後まで表示したら先頭から繰り返す」、
  効果は「切り替え効果」（FR-127、SC-042）

## ペインの表示切り替え（FR-088〜094）

| キー / 操作 | 動作 | 要件 |
|-------------|------|------|
| ⌃⌘2 / 表示 > ファイルリストのみ表示 / ツールバーの「ファイルリストのみ表示」ボタン | ツリーとプレビューを隠し、ファイルリストをウインドウの幅いっぱいに表示する。ファイルリストのみ表示中にもう一度押すと3ペイン表示に戻す。プレビューのみ表示中に押すと、ファイルリストのみ表示に切り替わる | FR-088〜090 |
| ⌃⌘3 / 表示 > プレビューのみ表示 / ツールバーの「プレビューのみ表示」ボタン | ツリーとファイルリストを隠し、プレビューをウインドウの幅いっぱいに表示する。プレビューのみ表示中にもう一度押すと3ペイン表示に戻す。ファイルリストのみ表示中に押すと、プレビューのみ表示に切り替わる | FR-088〜090 |

- 既定は3ペイン表示（ツールバーのどちらのボタンも押されていない、メニューのチェックなし）。起動のたびに3ペイン表示で始まり、保存しない
- ツールバーの2つのボタンは同時に押された状態にならない。押されている側をもう一度押すと押下が外れて3ペイン表示に戻る（FR-089）
- 「表示」メニューの2つの項目は、現在の表示状態の側にチェックマークを付ける。メニュー・ショートカット・ツールバーは同じ状態を共有し、
  ツールバーが非表示でもメニューとショートカットで切り替えられる（FR-090）
- フルスクリーン中・名前の変更中・スライドショー実行中は、2つのメニュー項目を淡色にし、⌃⌘2・⌃⌘3 とツールバーのボタンは何もしない
  （FR-090・094）
- 切り替えたときのフォーカス: ファイルリストのみ表示ではファイルリストへ、プレビューのみ表示ではプレビューへ移す（すでにそこにあれば動かさない）。
  3ペイン表示に戻したときは、切り替え前に表示していたペインに残す（FR-091）
- 3ペイン表示に戻したときは、各ペインの幅を切り替え前と同じに戻す。隠している間にウインドウを狭めていたら、プレビュー → ファイルリスト → ツリーの順に
  最小幅まで詰める。仕切りのドラッグ・ダブルクリックではペインは隠れない（FR-002・088）
- 隠している間も、ファイルリストの表示内容（フォルダ・zip の中の階層・検索結果）・選択・表示形式・並べ替え・種類フィルタ・ツリーの選択と
  展開状態は保つ（FR-088）
- 隠しているペインに関わる操作（FR-092）:
  - ツリーを隠している間（どちらの表示状態でも）: ⌥⌘1・⇧⌘F（お気に入りへ移動）・⌃⌘T（お気に入りに追加）は淡色で、何もしない
  - ファイルリストのみ表示: ⌥⌘3 は淡色。⌘F（検索）は使える
  - プレビューのみ表示: ⌥⌘2・⌘F（検索）は淡色。⌘↓・⌘↑・ファイル操作（⌘C・⌘D・⌘Delete など）はファイルリストにフォーカスがないため淡色。

    画像を表示していれば ⌘+ / ⌘- / ⌘0 はプレビューの倍率を変え、画像がない・動画・表示できない画像では何もしない
    （FR-135・EC-89・A-69（preview.md））

  FR-125（preview.md）に従い、対象が残っていれば次の自動送り予定時刻に最初の対象を選び、終了やペイン表示の復帰そのものでは
  選び直さない（EC-39）
- ファイルリストのみ表示の間は、プレビューで動画を再生しない（隠れたペインから音声を流さない）。3ペイン表示に戻すかフルスクリーンにすると、
  フォーカス中の動画を通常の選択と同じく表示する（FR-088、001 の research.md R45）
- フルスクリーン（⌃⌘F・プレビューのメディア表示区画のダブルクリック）はどちらの表示状態からも使える。ファイルリストのみ表示中の ⌃⌘F は、フォーカス中の
  メディアファイルをフルスクリーン表示する。フォーカス中の行がメディアファイルでない場合（フォルダ・zip ファイル・zip の中の
  ディレクトリ・`..`）は何もしない（プレビューは空のまま。FR-075・076・094）。解除すると、フルスクリーン前の表示状態とフォーカスのあった
  ペインに戻る（FR-094）

プレビューのみ表示中のキー（FR-093）:

| キー | 動作 |
|------|------|
| ↑ / ↓ | 隠れたファイルリストの選択を前 / 次のメディアファイルへ移し、プレビューを切り替える（リスト形式・サムネイル形式の両方。サムネイル形式は1行分） |

| 矢印キー（移動先がフォルダ・zip ファイル・zip の中のディレクトリ・`..` の行） | その行を飛ばし、同じ方向の次のメディアファイルへ移る。その方向にメディアがなければ移動しない（反対端へ循環しない） |

- 修飾キー（⌘・⌥・⌃・⇧）付きの矢印キーは、ファイルの切り替えに使わない
- プレビューのみ表示に切り替えたとき、一覧が読み込み済みでフォーカス中の行がメディアでなければ（フォルダ・zip ファイル・zip の中の
  ディレクトリ・`..`）、並び順でその行より後ろの最初のメディアファイルを、後ろになければ前にある最も近いメディアファイルを選択して表示する。
  一覧が読み込み済みで何も選択していなければ先頭から最初のメディアファイルを選択する。読み込み中に切り替えた場合は自動選択しない
- 表示中の一覧にメディアファイルが1件もない（ファイルがない、フォルダ・zip ファイル・`..` しかない、種類フィルタや検索で0件）ときは、
  プレビューに「表示するメディアファイルがありません」を出し、矢印キーでは何もしない
- メディアファイルはあるが何も選択していない（読み込み中に切り替えた、種類フィルタで選択中のファイルが非表示になった、外部で削除された）ときは、
  選び直さずプレビューを空のままにする（メッセージは出さない）。読み込み中に切り替えた場合は、読み込みが終わっても自動選択しない。
  矢印キー（リスト形式は ↑↓、サムネイル形式は上下左右）を押すと、方向に関わらず
  先頭から最初のメディアファイルを選択して表示する（spec Edge Cases）
- 3ペイン表示・ファイルリストのみ表示に戻すと、ファイルリストでは最後に表示したファイルが選択され、見える位置まで必要最小限スクロールする

## zip ファイルの表示切り替え（FR-095〜098）

| キー / 操作 | 動作 | 要件 |
|-------------|------|------|
| ⌃⌘Z / 表示 > zipファイルを表示 / ツールバーの「zipファイルを表示」ボタン | ファイルリストに zip ファイルの行を出すかどうかを切り替える。オンのときメニューにチェックマークが付き、ボタンは押された見た目になる | FR-095・096 |
| 切り替え後 | 通常のフォルダの一覧（リスト形式・サムネイル形式の両方）に zip ファイルの行が現れる／消える。一覧のスクロール位置は保つ | FR-095・097 |

- 既定はオフ（非表示）。保存し、次回起動時に復元する。保存された値がない初回起動だけ非表示で始まる（FR-003・095）
- 3つの経路は同じ状態を共有し、どこから変えてもツールバーの押下とメニューのチェックが一致する。ツールバーが非表示でもメニューとショートカットで
  切り替えられる（FR-096）
- 名前の変更中は、メニュー項目・⌃⌘Z・ツールバーのボタンを無効にする（FR-096）
- 種類フィルタ（⇧⌘I / ⇧⌘M）とは独立し、両方の条件を満たす行だけを表示する。zip ファイルの表示を戻しても、非表示中に外れた選択は戻らない（FR-095・097）
- フォーカス中の行が zip ファイルのときにオフにすると、その行を選択から外す。表示中のファイルが選択に残っていれば、並び順で最後のものを
  フォーカスしてプレビューし、残らなければプレビューを空にして再生中の動画を止める（FR-097。種類フィルタと同じ規則）
- オフにした結果、`..` 以外の行がなくなったときは、既存の空のメッセージを出す（専用のメッセージは出さない。FR-097）
- zip の中の一覧と検索結果には効果がない。zip の中を表示中にオフにしても、その一覧・選択・プレビュー・表示形式・フルスクリーンは変わらない。
  `..` / ⌘↑ で戻った先では zip ファイルの行がないため、行の選択もスクロールも行わず、選択のない一覧（プレビューは空）を表示する（FR-098）

プレビューは変わらない。見出しの下の各項目には三角がなく、選ぶとそのフォルダの内容がファイルリストに出る。

項目名も表示名にする。編集欄には「お気に入りの名前」のアクセシビリティラベルを付ける（FR-101）。通常のフォルダの名前の編集欄には「フォルダの名前」の

zip の中を表示している間（FR-071・073・075）:

- 一覧の先頭行は常に `..`。続いてディレクトリと対応メディアが、選択した列の順に区別なく並ぶ。`..` は並べ替えの対象にしない
- 矢印キー・⇧ + 矢印・⌘A・⌘1 / ⌘2・⌃⌘. / ⌃⌘,・⇧⌘I / ⇧⌘M・Space・⌃⌘F は通常のフォルダと同じに使える。種類フィルタは
  メディアの行だけを絞り、zip ファイル・ディレクトリ・`..` は残す
- 読み取り専用。Return（名前の変更）・⌘C・⌘V・⌥⌘V・⌘D・⌘Delete・⌘O・⇧⌘N は何もしない。ドラッグも始まらない
- ディレクトリ・`..`（と通常のフォルダの zip ファイル）の行を選ぶと、プレビューは空になり、再生中の動画は止まる
- ツリーで別のフォルダを選ぶと、zip の中の表示を終えてそのフォルダの一覧になる

通常のフォルダを表示している間（FR-076〜078）:

- 一覧の先頭行は `..`（ツリーのルートを表示中は出さない）。続いてサブフォルダ・zip ファイル・対応メディアが、選択した列の順に区別なく並ぶ
- フォルダの行は、ファイルと同じく Return・⌘C・⌘V・⌥⌘V・⌘D・⌘Delete・⌘O・ドラッグの対象になる。⌘O は既定のアプリ（Finder）で開く
- `..` の行は操作の対象にならない。⌘A で選択に入っても、コピー・ゴミ箱などの対象から除く。`..` だけを選択中は、ファイル操作の
  メニュー項目が淡色になる
- フォルダ・`..` の行を選ぶと、プレビューは空になり、再生中の動画は止まる
- フォルダを開く・戻るとツリーの選択が同期する。祖先が折りたたまれていれば展開し、行が見える位置までスクロールする。
  キーボードフォーカスは移らない

検索結果を表示している間（FR-084〜087）:

- 一覧の上部に検索バー（「「<キーワード>」の検索結果 — <起点のフォルダ名> — <件数> 件」、検索中は「検索中…」とスピナー）を出す。
  件数は一致したファイルとフォルダの合計。検索バーのラベルには起点の絶対パスのツールチップを付け、同じ名前の起点を見分けられるようにする
- 先頭行の `..` は出ない。⌘↑ と「上の階層へ」は何もしない（淡色）。フォルダの行では ⌘↓・ダブルクリック・「中を表示」で検索結果を終えてフォルダを開く。ツリーに表示されない場合は表示可能な最も近い祖先を選択・保存し、一覧と履歴は開いた場所のままにする（EC-102）。メディアの行では ⌘↓ は何もしない（FR-140）
- リスト形式では「名前」「作成日」「種類」に加えて「場所」列を出す。列見出しのクリックと「表示 > 並べ替え > 場所」で並べ替えられる。
  ファイルとフォルダを区別せず列の順に混ぜて並べる。サムネイル形式は名前だけを出し、ポインタを重ねると場所をツールチップで示す
- 矢印キー・⇧ + 矢印・⌘A・⌘1 / ⌘2・⌃⌘. / ⌃⌘,・⇧⌘I / ⇧⌘M・Space・⌃⌘F は通常のフォルダと同じに使える
- Return（名前の変更）・⌘C・⌘D・⌘Delete・⌘O・ドラッグはファイルとフォルダの行で通常のフォルダと同じに使える。⌘V・⌥⌘V はフォルダの行を選んでいても何もしない（淡色）。⇧⌘N も何もしない（淡色）。検索結果のフォルダ行へのアプリ内ドロップは FR-163 に従う
- ゴミ箱に入れた・移動したファイルやフォルダ（アプリの外での削除・移動を含む）は、フォルダ内の結果も含めて一覧から消える。名前を変更した行は新しい名前で残り、フォルダ内の結果の場所も更新する。複製や新しく現れた項目は加えない。検索前の場所の祖先を一覧から移動・ゴミ箱に入れても検索結果は続き、Esc・⌘[ では元の場所がない旨を示す（EC-101）
- フォルダの行の選択ではプレビューを空にして動画を止め、フルスクリーンの移動とスライドショーの対象から除く。種類フィルタはフォルダの行を隠さない（FR-139）。フォルダの行の右クリックメニューには「中を表示」を置く（FR-140）。
- ツリーでフォルダ（お気に入りの項目を含む）を選ぶか、選択中のフォルダの行をクリックすると、検索結果の表示を終えてそのフォルダの一覧になる。
  検索中なら検索は止まる。「お気に入り」の見出しを選んでも終わらない
- ファイルリストにフォーカスがあるとき（フルスクリーン中と名前の変更中を除く）は、Esc でも検索結果の表示を終えて検索前のフォルダの一覧に戻る。検索中なら検索は止まる。
  ⌘[ はフォーカスのあるペインに関わらず同じに検索結果の表示を終える（戻る側に履歴がなくても使える。FR-113）

  スライドショー実行中も使える。動画・空のプレビュー・表示できない画像・ファイルリストのみ表示では、メニューとツールバーの項目を無効にし、
  キーは何もしない（サムネイルサイズも変えない）。名前の変更中・シート表示中・設定ウインドウがキーのときも、この条件だけで使える
  （FR-136・A-73（preview.md））
- 倍率は FR-028 のフィット表示を100%とし、25%〜800%の25%刻み。はみ出す方向はスクロールバー、ホイール、トラックパッド、プレビューにフォーカス中の ⌥方向キーで移動できる。表示位置は FR-159 に従う。ドラッグによるパン・ピンチ・倍率の数値表示はない（FR-133・FR-158・FR-159・A-64（preview.md））

  （A-72・A-75（preview.md））

## 右クリックメニュー（ファイルリスト）

選択中のファイルに対して、次の順で表示する。項目の名前は Finder に合わせる。

1. 開く（既定のアプリで開く）
2. ─
3. ゴミ箱に入れる（⌘Delete）
4. ─
5. 名前を変更（Return）
6. 複製（⌘D）
7. ─
8. "<名前>" をコピー（⌘C）（複数選択時は「n 項目をコピー」）
9. パス名をコピー（⌥⌘C）（1件だけ選択しているときのみ有効。FR-181・183）
10. ペースト（⌘V）／ 移動ペースト（⌥⌘V）（クリップボードにファイルがある場合のみ有効）
11. ─
12. Finder に表示

- 通常のフォルダの zip ファイル・フォルダの行でも、同じ項目を同じ条件で有効にする（zip ファイルそのものとフォルダはファイル操作の対象: FR-073・076）。
  ファイル操作の前に、1番目として「中を表示（⌘↓）」と「上の階層へ（⌘↑）」と区切り線を加える（「上の階層へ」は戻る先があるときだけ表示する）
- 通常のフォルダの `..` の行では、「中を表示（⌘↓）」と「上の階層へ（⌘↑）」とペーストのほかは淡色で選べない
- zip の中を表示中は、メディア・ディレクトリ・`..` のどの行でも、「中を表示（⌘↓）」（ディレクトリと `..` のみ有効）と
  「上の階層へ（⌘↑）」のほかは、すべて淡色で選べない（FR-073）
- 検索結果を表示中は、通常のフォルダのメディアの行と同じ項目を出す。「ペースト」「移動ペースト」は淡色で選べず、「上の階層へ」は出さない（FR-087）

項目のない背景（リスト形式の最終行より下、サムネイル形式の項目の間と外側）を右クリックしたときは、選択中の項目向けのメニューの代わりに、
表示中のフォルダ向けの次のメニューを出す（FR-213）。

1. 新規フォルダ（⇧⌘N）
2. ─
3. ペースト（⌘V）／ 移動ペースト（⌥⌘V）（表示中のフォルダへ。クリップボードにファイルがある場合のみ有効）
4. ─
5. Finder に表示（表示中のフォルダ）

- 背景の右クリックはファイルリストの選択・プレビューを変えない（A-121）
- zip の中を表示中は、すべて淡色。検索結果を表示中は、「新規フォルダ」「ペースト」「移動ペースト」「Finder に表示」を淡色にする
- 項目（メディア・zip ファイル・フォルダ・`..`）の右クリックメニューは、上の項目の右クリックメニューのままで、「新規フォルダ」を出さない

## 右クリックメニュー（ツリー）

右クリックした行の種類で項目を変える（[data-model.md](../../001-three-pane-media-viewer/data-model.md) の「TreeItemRole と FavoriteCommands」）。

通常のフォルダ（ホーム・ボリュームのルートを含む）:

1. 新規フォルダ（⇧⌘N）
2. ─
3. ゴミ箱に入れる（⌘Delete）
4. ─
5. 名前を変更（Return）
6. ─
7. ここにペースト / ここに移動ペースト
8. ─
9. お気に入りに追加（⌃⌘T）（登録済みのフォルダでは無効）
10. ─
11. パス名をコピー（⌥⌘C）
12. Finder に表示

（ホーム・ボリュームのルートでは、3〜6（「ゴミ箱に入れる」「名前を変更」とその後の区切り線）を出さない。FR-079・FR-103）

「新規フォルダ」は右クリックした行のフォルダの中に作り、ツリーの選択は変えない（FR-208・A-21）。作成後は作成先を展開し、新しい行で
名前の編集を始める（確認モーダルなし。FR-210・211）。

選択中の行を右クリックしたときは選択中の行全体を対象にし、2行以上なら右クリックした行の種類に関わらず上の通常のフォルダの項目を同じ順で出す。
このとき有効になり得るのは「ゴミ箱に入れる」だけで、対象のすべてが通常のフォルダのときに有効にする。ほかの項目（新規フォルダを含む）は淡色にする。
選択外の行を右クリックしたときは、その行だけを対象にする（FR-217・FR-218・A-21）。

「ゴミ箱に入れる」と「名前を変更」は右クリックした行のフォルダを対象にし、ツリーの選択は変えない（選択中の行ではない。A-21・A-36）。
「ゴミ箱に入れる」の確認モーダルはフォルダ名と絶対パスを示し、確認モーダルの省略設定に関わらず必ず表示する（FR-079）。
ゴミ箱経由・失敗の表示はファイルリストのゴミ箱と同じ（FR-021・026）。「名前を変更」の編集・検証・確認はディレクトリツリーの表の Return と同じ（FR-103）。
名前の編集中に右クリックメニューを開いたときは、先に編集を確定する（お気に入りの項目と同じ）。

お気に入りの項目:

1. 新規フォルダ（⇧⌘N）（見つからない項目では無効。登録したフォルダの中に作る）
2. ─
3. 名前を変更（Return）
4. お気に入りから削除（⌘Delete）
5. ─
6. パス名をコピー（⌥⌘C）（見つからない項目では無効）

「名前を変更」は右クリックした行を対象にし、ツリーの選択は変えない（A-21）。名前の編集中に右クリックメニューを開いたときは、
先に編集を確定する。確定した後、キーボードフォーカスはツリーに戻し、メニューを閉じた後も Return・⌘Delete・矢印キーが
そのままツリーで効くようにする（ボリュームの接続・取り外しで編集を確定したときも同じ）。

「お気に入り」の見出し: メニューを出さない。

## 確認モーダルと衝突ダイアログ

- 確認モーダル（設定で ON のとき）: 操作名、対象の件数、先頭最大5件のファイル名、操作先を表示する。
  対象にフォルダが含まれるときは「フォルダは中身ごと」操作する旨を添える（R32）。
  既定ボタンは「実行」、Esc で「キャンセル」（FR-022）
- 確認モーダルには「今後この確認を表示しない」チェックボックスを置き、設定の `confirmBeforeFileOperations` と連動させる（FR-023）。
  ただしファイルリストからのコピー・削除でだけ省略でき、名前の変更と移動、およびツリーのフォルダをゴミ箱に入れる操作の確認モーダルは
  設定に関わらず常に表示し、チェックボックスも出さない（FR-024・079）。複製（⌘D）とフォルダの新規作成（⇧⌘N）、作成直後の名前の確定は確認モーダルを出さず、設定にも影響されない（FR-018・024・209・211）
- ツリーから行うゴミ箱に入れる操作と名前の変更の確認モーダルは、上の内容に加えて対象のフォルダの絶対パスを示す（FR-079・103）。表示する本文:

  ```text
  ゴミ箱に入れますか？

  対象: 1 件
  ・<フォルダ名>
  フォルダは中身ごとゴミ箱に入ります
  場所: <フォルダの絶対パス>
  ```

  ```text
  名前を変更しますか？

  対象: 1 件
  ・<変更前のフォルダ名>
  フォルダは中身ごと操作します
  場所: <変更前のフォルダの絶対パス>
  ```
- お気に入りの削除の確認モーダル（設定で ON のとき）: 「お気に入りから削除しますか？」、対象のお気に入りの表示名、
  登録したフォルダの絶対パス、実際のフォルダは変更されないこと。既定ボタンは「削除」、Esc で「キャンセル」。
  「今後この確認を表示しない」はファイル操作と同じ `confirmBeforeFileOperations` を変える（FR-024・064）。
  お気に入りの表示名の変更は確認モーダルを出さない（FR-099、A-29）。表示する本文:

  ```text
  お気に入りから削除しますか？

  対象: <表示名>
  場所: <登録したフォルダの絶対パス>
  実際のフォルダは変更されません
  ```
- 衝突ダイアログ（コピー・移動で常に表示する）: 「置き換える」「両方残す」「中止」と、「残りすべてに適用」のチェックボックス（FR-025）。コピー元と衝突先が同一のとき「置き換える」は選べない。
  名前の変更で既存の名前を指定した場合は、衝突ダイアログではなく名前の検証エラーを表示する
