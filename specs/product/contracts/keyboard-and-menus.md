# UI Contract: キーボード操作とメニュー

ユーザーに公開する操作体系の契約。割り当ては Finder に準じる（FR-019）。すべての操作をキーボードだけで
実行できること（FR-040、憲章 原則 III）を、この表で網羅的に担保する。新しい操作を追加するときは、
必ずこの表に行を追加する。

「名前の変更中」は、ファイルリストでのファイル名の変更（FR-019）と、ツリーでのお気に入りの表示名の編集（FR-099）の両方を指す（FR-102）。

## ペイン間のフォーカス移動

| キー | 動作 |
|------|------|
| Tab / ⇧Tab | ツリー → リスト → プレビュー の順（逆順）にフォーカスを移す。ペインの表示切り替えで隠しているペインは飛ばし、表示中のペインの間だけを巡回する（FR-092） |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | ツリー / リスト / プレビューへ直接フォーカスする。ペインの表示切り替えで隠しているペインの項目は淡色で、ショートカットは何もしない（FR-092） |
| ⇧⌘F | ツリーへフォーカスし、「お気に入り」の見出しを選択する。折りたたまれていれば展開する。ファイルリスト・プレビューは変えない。フルスクリーン中・名前の変更中・ペインの表示切り替えでツリーを隠している間は無効（FR-065・092） |

## ペインの表示切り替え（FR-088〜094）

| キー / 操作 | 動作 | 要件 |
|-------------|------|------|
| ⌃⌘2 / 表示 > ファイルリストのみ表示 / ツールバーの「ファイルリストのみ表示」ボタン | ツリーとプレビューを隠し、ファイルリストをウインドウの幅いっぱいに表示する。ファイルリストのみ表示中にもう一度押すと3ペイン表示に戻す。プレビューのみ表示中に押すと、ファイルリストのみ表示に切り替わる | FR-088〜090 |
| ⌃⌘3 / 表示 > プレビューのみ表示 / ツールバーの「プレビューのみ表示」ボタン | ツリーとファイルリストを隠し、プレビューをウインドウの幅いっぱいに表示する。プレビューのみ表示中にもう一度押すと3ペイン表示に戻す。ファイルリストのみ表示中に押すと、プレビューのみ表示に切り替わる | FR-088〜090 |

- 既定は3ペイン表示（ツールバーのどちらのボタンも押されていない、メニューのチェックなし）。起動のたびに3ペイン表示で始まり、保存しない
- ツールバーの2つのボタンは同時に押された状態にならない。押されている側をもう一度押すと押下が外れて3ペイン表示に戻る（FR-089）
- 「表示」メニューの2つの項目は、現在の表示状態の側にチェックマークを付ける。メニュー・ショートカット・ツールバーは同じ状態を共有し、
  ツールバーが非表示でもメニューとショートカットで切り替えられる（FR-090）
- フルスクリーン中と名前の変更中は、2つのメニュー項目を淡色にし、⌃⌘2・⌃⌘3 とツールバーのボタンは何もしない（FR-090・094）
- 切り替えたときのフォーカス: ファイルリストのみ表示ではファイルリストへ、プレビューのみ表示ではプレビューへ移す（すでにそこにあれば動かさない）。
  3ペイン表示に戻したときは、切り替え前に表示していたペインに残す（FR-091）
- 3ペイン表示に戻したときは、各ペインの幅を切り替え前と同じに戻す。隠している間にウインドウを狭めていたら、プレビュー → ファイルリスト → ツリーの順に
  最小幅まで詰める。仕切りのドラッグ・ダブルクリックではペインは隠れない（FR-002・088）
- 隠している間も、ファイルリストの表示内容（フォルダ・zip の中の階層・検索結果）・選択・表示形式・並べ替え・種類フィルタ・ツリーの選択と
  展開状態は保つ（FR-088）
- 隠しているペインに関わる操作（FR-092）:
  - ツリーを隠している間（どちらの表示状態でも）: ⌥⌘1・⇧⌘F（お気に入りへ移動）・⌃⌘T（お気に入りに追加）は淡色で、何もしない
  - ファイルリストのみ表示: ⌥⌘3 は淡色。⌘F（検索）は使える
  - プレビューのみ表示: ⌥⌘2・⌘F（検索）は淡色。⌘↓・⌘↑・ファイル操作（⌘C・⌘D・⌘Delete など）はファイルリストにフォーカスがないため淡色。
    ⌘1 / ⌘2・⌘+ / ⌘-・⇧⌘I / ⇧⌘M は使え、隠れたファイルリストの表示形式・サイズ・絞り込みを変える（矢印キーの移動規則に反映する）
- ファイルリストのみ表示の間は、プレビューで動画を再生しない（隠れたペインから音声を流さない）。3ペイン表示に戻すかフルスクリーンにすると、
  フォーカス中の動画を通常の選択と同じく表示する（FR-088、001 の research.md R45）
- フルスクリーン（⌃⌘F・プレビューのダブルクリック）はどちらの表示状態からも使える。ファイルリストのみ表示中の ⌃⌘F は、フォーカス中の
  メディアファイルをフルスクリーン表示する。フォーカス中の行がメディアファイルでない場合（フォルダ・zip ファイル・zip の中の
  ディレクトリ・`..`）は何もしない（プレビューは空のまま。FR-075・076・094）。解除すると、フルスクリーン前の表示状態とフォーカスのあった
  ペインに戻る（FR-094）

プレビューのみ表示中のキー（FR-093）:

| キー | 動作 |
|------|------|
| ↑ / ↓ | 隠れたファイルリストの選択を前 / 次のメディアファイルへ移し、プレビューを切り替える（リスト形式・サムネイル形式の両方。サムネイル形式は1行分） |
| ← / →（サムネイル形式） | 隠れたファイルリストの選択を前 / 次のメディアファイルへ移す |
| ← / →（リスト形式） | 何もしない |
| 矢印キー（移動先がフォルダ・zip ファイル・zip の中のディレクトリ・`..` の行） | その行を飛ばし、同じ方向の次のメディアファイルへ移る。その方向にメディアがなければ移動しない（反対端へ循環しない） |
| 矢印キー（動画を表示中） | 常にファイルの切り替えに使う。再生中の動画は止まる（FR-034） |
| < / >（動画を表示中） | 5 秒戻す / 送る（シークは画面上のコントロールでも行える） |
| Space | 動画の再生 / 一時停止（プレビューの動画にフォーカスがあるとき。標準の動画コントロールの動作） |

- 修飾キー（⌘・⌥・⌃・⇧）付きの矢印キーは、ファイルの切り替えに使わない
- プレビューのみ表示に切り替えたとき、一覧が読み込み済みでフォーカス中の行がメディアでなければ（フォルダ・zip ファイル・zip の中の
  ディレクトリ・`..`）、並び順でその行より後ろの最初のメディアファイルを、後ろになければ前にある最も近いメディアファイルを選択して表示する。
  一覧が読み込み済みで何も選択していなければ先頭から最初のメディアファイルを選択する。読み込み中に切り替えた場合は自動選択しない
- 表示中の一覧にメディアファイルが1件もない（ファイルがない、フォルダ・zip ファイル・`..` しかない、種類フィルタや検索で0件）ときは、
  プレビューに「表示するメディアファイルがありません」を出し、矢印キーでは何もしない
- メディアファイルはあるが何も選択していない（読み込み中に切り替えた、種類フィルタで選択中のファイルが非表示になった、外部で削除された）ときは、
  選び直さずプレビューを空のままにする（メッセージは出さない）。読み込み中に切り替えた場合は、読み込みが終わっても自動選択しない。
  矢印キー（リスト形式は ↑↓、サムネイル形式は上下左右）を押すと、方向に関わらず
  先頭から最初のメディアファイルを選択して表示する（spec Edge Cases）
- 3ペイン表示・ファイルリストのみ表示に戻すと、ファイルリストでは最後に表示したファイルが選択され、見える位置まで必要最小限スクロールする

## zip ファイルの表示切り替え（FR-095〜098）

| キー / 操作 | 動作 | 要件 |
|-------------|------|------|
| ⌃⌘Z / 表示 > zipファイルを表示 / ツールバーの「zipファイルを表示」ボタン | ファイルリストに zip ファイルの行を出すかどうかを切り替える。オンのときメニューにチェックマークが付き、ボタンは押された見た目になる | FR-095・096 |
| 切り替え後 | 通常のフォルダの一覧（リスト形式・サムネイル形式の両方）に zip ファイルの行が現れる／消える。一覧のスクロール位置は保つ | FR-095・097 |

- 既定はオフ（非表示）。保存し、次回起動時に復元する。保存された値がない初回起動だけ非表示で始まる（FR-003・095）
- 3つの経路は同じ状態を共有し、どこから変えてもツールバーの押下とメニューのチェックが一致する。ツールバーが非表示でもメニューとショートカットで
  切り替えられる（FR-096）
- 名前の変更中は、メニュー項目・⌃⌘Z・ツールバーのボタンを無効にする（FR-096）
- 種類フィルタ（⇧⌘I / ⇧⌘M）とは独立し、両方の条件を満たす行だけを表示する。zip ファイルの表示を戻しても、非表示中に外れた選択は戻らない（FR-095・097）
- フォーカス中の行が zip ファイルのときにオフにすると、その行を選択から外す。表示中のファイルが選択に残っていれば、並び順で最後のものを
  フォーカスしてプレビューし、残らなければプレビューを空にして再生中の動画を止める（FR-097。種類フィルタと同じ規則）
- オフにした結果、`..` 以外の行がなくなったときは、既存の空のメッセージを出す（専用のメッセージは出さない。FR-097）
- zip の中の一覧と検索結果には効果がない。zip の中を表示中にオフにしても、その一覧・選択・プレビュー・表示形式・フルスクリーンは変わらない。
  `..` / ⌘↑ で戻った先では zip ファイルの行がないため、行の選択もスクロールも行わず、選択のない一覧（プレビューは空）を表示する（FR-098）

## ディレクトリツリー

| キー | 動作 |
|------|------|
| ↑ / ↓ | 前 / 次のフォルダを選択する（選択したフォルダの内容がリストに表示される） |
| → | 折りたたまれていれば展開し、展開済みなら最初の子を選択する |
| ← | 展開されていれば折りたたみ、折りたたまれていれば親を選択する |
| ⌥→ / ⌥← | 配下をすべて展開 / 折りたたむ。展開するのはサブフォルダの有無を確認済みの階層までで、まだ確認していない孫以下は先読みしない（FR-055） |
| ⌘V / ⌥⌘V | 選択したフォルダへペースト（コピー / 移動）。お気に入りの見出し・項目では無効 |
| ⌃⌘T | ツリーで選択中のフォルダ（ホーム・ボリュームのルートを含む）をお気に入りの末尾に登録する。どのペインにフォーカスがあっても効く。登録済みのフォルダ・見出し・お気に入りの項目と名前の変更中、ペインの表示切り替えでツリーを隠している間は無効（FR-062・092） |
| ⌘Delete | 通常のフォルダ（ホーム・ボリュームの最上位を除く）を選択中のとき、確認モーダルの後にフォルダを中身ごとゴミ箱に入れる。表示中のフォルダ（またはその祖先）を入れたときは、親フォルダを選択してその一覧を表示し、フォーカスはツリーに残る（FR-079）。お気に入りの項目を選択中のときは、確認モーダルの後にお気に入りから削除する（実際のフォルダは変えない）。ホーム・ボリュームの最上位・「お気に入り」の見出しでは何もしない（FR-064） |
| Return | お気に入りの項目を選択中のとき、その項目の表示名の編集を行の中で始める（現在の表示名を全選択）。Return で確定、Esc で取り消す。ほかの場所のクリックでも確定する。確定した名前は前後の空白を除き、空なら登録したフォルダの名前に戻す。実際のフォルダの名前は変えず、確認モーダルも出さない。「お気に入り」の見出し・ホーム・ボリュームの最上位・通常のフォルダを選択中は何もしない。ファイルリストに zip の中や検索結果を表示中でも使える（FR-099〜101） |

「お気に入り」の見出しは、ホームとボリュームより上に常に表示する。見出しは開閉の三角を持つ通常の行で、→ / ← と
ダブルクリックで開閉できる。起動時は折りたたまれている。見出しを ↑↓ やクリックで選んでも、ファイルリスト・
プレビューは変わらない。見出しの下の各項目には三角がなく、選ぶとそのフォルダの内容がファイルリストに出る。
ツリー下側の実際の階層は展開・選択しない（FR-061・063・065）。見つからない項目は淡色の文字で表示する（FR-067）。
お気に入りの項目は、表示名を付けていればその名前で、付けていなければ登録したフォルダの名前で表示する。アクセシビリティの
項目名も表示名にする。編集欄には「お気に入りの名前」のアクセシビリティラベルを付ける（FR-101）。名前の編集中は、
ツリーのメニュー項目（名前を変更（Return・右クリック）・⌘Delete・ゴミ箱に入れる（右クリック）・ここにペースト（右クリック）・
ここに移動ペースト（右クリック）・移動ペースト（⌥⌘V）・Finder に表示・お気に入りに追加・お気に入りから削除（右クリック））を
無効にする（FR-102）。「編集 > ペースト」（⌘V）は無効にしない。名前の変更中は編集欄（フィールドエディタ）が受け、
編集欄へのテキストのペーストになる。

| マウス操作 | 動作 | 要件 |
|------------|------|------|
| 行（アイコンまたはフォルダ名）のダブルクリック | そのフォルダを選択し、折りたたまれていれば展開、展開されていれば折りたたむ。開閉の三角がない（サブフォルダなし・確認中・権限なし）フォルダでは選択だけを行う | FR-053・054 |
| 開閉の三角のクリック | 従来どおり1回のクリックで展開・折りたたみする | FR-005 |
| 選択中のフォルダの行のクリック（検索結果を表示中） | 検索結果の表示を終え、そのフォルダの一覧を表示する（「お気に入り」の見出しでは何もしない） | FR-086 |

開閉の三角は、サブフォルダ（隠しフォルダ・パッケージを除く）があると確認できたフォルダと、確認に失敗した
フォルダにだけ表示する。三角のないフォルダでは → キーでも展開しない（FR-054・055）。ダブルクリックは
→ / ← キーによる開閉のマウス操作版で、キーボードの割り当ては変えない。

ドロップ先: リストからドラッグしたファイルをツリーのフォルダ上にドロップすると移動、⌥ を押しながらだとコピー（FR-020）。
お気に入りの見出しと項目はドロップ先にならない。

## ファイルリスト

| キー | 動作 | 要件 |
|------|------|------|
| ↑ / ↓（リスト形式）、↑↓←→（サムネイル形式） | 選択を移動し、プレビューを追従させる。サムネイル形式ではフォーカス項目全体が見える最小限のスクロールも行う（既に見えている場合は動かさない） | FR-017 |
| ⇧ + 矢印 / ⌘A | 選択範囲を広げる / すべて選択する。サムネイル形式では移動先のフォーカス項目にスクロールが追従する | FR-016・017 |
| ⌘1 / ⌘2 | サムネイル形式 / リスト形式に切り替える（Finder と同じ番号） | FR-010 |
| ⌘+ / ⌘- | サムネイルを大きく / 小さくする | FR-014 |
| ⇧⌘I | 「画像のみ表示」のオン・オフを切り替える | FR-056・058 |
| ⇧⌘M | 「動画のみ表示」のオン・オフを切り替える | FR-056・058 |
| Return | 名前の変更を開始する（Return で確定、Esc で取り消す） | FR-019 |
| Esc | 検索結果を表示中（フルスクリーン中と名前の変更中を除く）は、検索結果の表示を終えて検索前のフォルダの一覧に戻る。検索中なら検索を止める。それ以外では何もしない | FR-086 |
| ⌘C / ⌘V / ⌥⌘V | コピー / ペースト / 移動ペースト | FR-019 |
| ⌘D | 複製（同じフォルダに「名前 2」として作成） | FR-019 |
| ⌘Delete | ゴミ箱に入れる（フォルダは中身ごと） | FR-019・021・076 |
| Space | 選択中の動画を再生 / 一時停止する | FR-033 |
| ⌃⌘F | プレビューのフルスクリーンを切り替える。ファイルリストのみ表示中も、フォーカス中のメディアファイルをフルスクリーン表示する。フォルダ・zip ファイル・zip の中のディレクトリ・`..` の行では何もしない | FR-036・094 |
| ⌘↓ | フォーカス行が zip ファイル・フォルダ・zip の中のディレクトリなら中を表示し、`..` なら1つ上の階層へ戻る。メディアの行では何もしない。フォルダを開いたときはツリーでもそのフォルダを選択する（フォーカスはファイルリストのまま） | FR-069・070・076・078 |
| ⌘↑ | どの行を選択中でも1つ上の階層へ戻る。zip の中では1つ上の階層（最上位では zip を含むフォルダの一覧）へ、通常のフォルダでは親フォルダへ戻り、ツリーでも親フォルダを選択する。戻った先では出てきた zip ファイル・ディレクトリ・フォルダの行を選択する。ツリーのルート（ホーム・ボリュームの最上位）を表示中は何もしない | FR-069・070・077・078 |

| マウス操作 | 動作 | 要件 |
|------------|------|------|
| zip ファイル・フォルダ・zip の中のディレクトリの行のダブルクリック | 中を表示する（⌘↓ と同じ） | FR-069・076 |
| `..` の行のダブルクリック | 1つ上の階層へ戻る（⌘↑ と同じ） | FR-070 |
| メディアの行のダブルクリック | 何もしない（従来どおり） | — |

zip の中を表示している間（FR-071・073・075）:

- 一覧の先頭行は常に `..`。続いてディレクトリと対応メディアが、選択した列の順に区別なく並ぶ。`..` は並べ替えの対象にしない
- 矢印キー・⇧ + 矢印・⌘A・⌘1 / ⌘2・⌘+ / ⌘-・⇧⌘I / ⇧⌘M・Space・⌃⌘F は通常のフォルダと同じに使える。種類フィルタは
  メディアの行だけを絞り、zip ファイル・ディレクトリ・`..` は残す
- 読み取り専用。Return（名前の変更）・⌘C・⌘V・⌥⌘V・⌘D・⌘Delete・⌘O は何もしない。ドラッグも始まらない
- ディレクトリ・`..`（と通常のフォルダの zip ファイル）の行を選ぶと、プレビューは空になり、再生中の動画は止まる
- ツリーで別のフォルダを選ぶと、zip の中の表示を終えてそのフォルダの一覧になる

通常のフォルダを表示している間（FR-076〜078）:

- 一覧の先頭行は `..`（ツリーのルートを表示中は出さない）。続いてサブフォルダ・zip ファイル・対応メディアが、選択した列の順に区別なく並ぶ
- フォルダの行は、ファイルと同じく Return・⌘C・⌘V・⌥⌘V・⌘D・⌘Delete・⌘O・ドラッグの対象になる。⌘O は既定のアプリ（Finder）で開く
- `..` の行は操作の対象にならない。⌘A で選択に入っても、コピー・ゴミ箱などの対象から除く。`..` だけを選択中は、ファイル操作の
  メニュー項目が淡色になる
- フォルダ・`..` の行を選ぶと、プレビューは空になり、再生中の動画は止まる
- フォルダを開く・戻るとツリーの選択が同期する。祖先が折りたたまれていれば展開し、行が見える位置までスクロールする。
  キーボードフォーカスは移らない

検索結果を表示している間（FR-084〜087）:

- 一覧の上部に検索バー（「「<キーワード>」の検索結果 — <起点のフォルダ名> — <件数> 件」、検索中は「検索中…」とスピナー）を出す。
  検索バーのラベルには起点の絶対パスのツールチップを付け、同じ名前の起点を見分けられるようにする
- 先頭行の `..` は出ない。⌘↑ と「上の階層へ」は何もしない（淡色）。⌘↓ はメディアの行だけなので何もしない
- リスト形式では「名前」「作成日」「種類」に加えて「場所」列を出す。列見出しのクリックと「表示 > 並べ替え > 場所」で並べ替えられる。
  サムネイル形式は名前だけを出し、ポインタを重ねると場所をツールチップで示す
- 矢印キー・⇧ + 矢印・⌘A・⌘1 / ⌘2・⌘+ / ⌘-・⇧⌘I / ⇧⌘M・Space・⌃⌘F は通常のフォルダと同じに使える
- Return（名前の変更）・⌘C・⌘D・⌘Delete・⌘O・ドラッグは通常のフォルダと同じに使える。⌘V・⌥⌘V は貼り付け先のフォルダがないため何もしない（淡色）
- ゴミ箱に入れた・移動したファイル（アプリの外での削除・移動を含む）は一覧から消える。名前を変更したファイルは新しい名前で残る。
  複製で作ったファイルや新しく現れたファイルは一覧に加わらない
- ツリーでフォルダ（お気に入りの項目を含む）を選ぶか、選択中のフォルダの行をクリックすると、検索結果の表示を終えてそのフォルダの一覧になる。
  検索中なら検索は止まる。「お気に入り」の見出しを選んでも終わらない
- ファイルリストにフォーカスがあるとき（フルスクリーン中と名前の変更中を除く）は、Esc でも検索結果の表示を終えて検索前のフォルダの一覧に戻る。検索中なら検索は止まる

## 右クリックメニュー（ファイルリスト）

選択中のファイルに対して、次の順で表示する。項目の名前は Finder に合わせる。

1. 開く（既定のアプリで開く）
2. ─
3. ゴミ箱に入れる（⌘Delete）
4. ─
5. 名前を変更（Return）
6. 複製（⌘D）
7. ─
8. "<名前>" をコピー（⌘C）（複数選択時は「n 項目をコピー」）
9. ペースト（⌘V）／ 移動ペースト（⌥⌘V）（クリップボードにファイルがある場合のみ有効）
10. ─
11. Finder に表示

- 通常のフォルダの zip ファイル・フォルダの行でも、同じ項目を同じ条件で有効にする（zip ファイルそのものとフォルダはファイル操作の対象: FR-073・076）。
  ファイル操作の前に、1番目として「中を表示（⌘↓）」と「上の階層へ（⌘↑）」と区切り線を加える（「上の階層へ」は戻る先があるときだけ表示する）
- 通常のフォルダの `..` の行では、「中を表示（⌘↓）」と「上の階層へ（⌘↑）」とペーストのほかは淡色で選べない
- zip の中を表示中は、メディア・ディレクトリ・`..` のどの行でも、「中を表示（⌘↓）」（ディレクトリと `..` のみ有効）と
  「上の階層へ（⌘↑）」のほかは、すべて淡色で選べない（FR-073）
- 検索結果を表示中は、通常のフォルダのメディアの行と同じ項目を出す。「ペースト」「移動ペースト」は淡色で選べず、「上の階層へ」は出さない（FR-087）

## 右クリックメニュー（ツリー）

右クリックした行の種類で項目を変える（[data-model.md](../../001-three-pane-media-viewer/data-model.md) の「TreeItemRole と FavoriteCommands」）。

通常のフォルダ（ホーム・ボリュームのルートを含む）:

1. ゴミ箱に入れる（⌘Delete）（ホーム・ボリュームのルートでは、この項目と次の区切り線を出さない。FR-079）
2. ─
3. ここにペースト / ここに移動ペースト
4. ─
5. お気に入りに追加（⌃⌘T）（登録済みのフォルダでは無効）
6. ─
7. Finder に表示

「ゴミ箱に入れる」は右クリックした行のフォルダを対象にする（選択中の行ではない）。確認モーダル・確認の省略・失敗の表示は
ファイルリストのゴミ箱と同じ（FR-021〜024・026）。

お気に入りの項目:

1. 名前を変更（Return）
2. お気に入りから削除（⌘Delete）

「名前を変更」は右クリックした行を対象にし、ツリーの選択は変えない（A-21）。名前の編集中に右クリックメニューを開いたときは、
先に編集を確定する。確定した後、キーボードフォーカスはツリーに戻し、メニューを閉じた後も Return・⌘Delete・矢印キーが
そのままツリーで効くようにする（ボリュームの接続・取り外しで編集を確定したときも同じ）。

「お気に入り」の見出し: メニューを出さない。

## メニューバー

| メニュー | 項目 |
|----------|------|
| アプリ名 | 設定…（⌘,） / 終了（⌘Q） |
| ファイル | 開く / 中を表示（⌘↓）/ 上の階層へ（⌘↑）/ Finder に表示 / お気に入りに追加（⌃⌘T）/ 検索…（⌘F）/ ゴミ箱に入れる |
| 編集 | コピー / ペースト / 移動ペースト / 複製 / 名前を変更 / すべてを選択 |
| 表示 | ツールバーを表示（隠す）（⇧⌘T）/ フルスクリーン（⌃⌘F）/ サムネイル（⌘1）/ リスト（⌘2）/ サムネイルを拡大・縮小（⌘+ / ⌘-）/ 画像のみ表示（⇧⌘I）・動画のみ表示（⇧⌘M）/ zipファイルを表示（⌃⌘Z）/ ファイルリストのみ表示（⌃⌘2）・プレビューのみ表示（⌃⌘3）/ ディレクトリツリー・ファイルリスト・プレビューへフォーカス（⌥⌘1〜3）/ お気に入りへ移動（⇧⌘F）/ 並べ替え（名前・作成日・種類・場所） |

- 項目は実装の並び順で記す。並べ替えはメニューには置かず、リスト形式の列見出しのクリックで行う（FR-012）
- 「画像のみ表示」「動画のみ表示」は、オンの項目にチェックマークを付ける。両方オンのときは両方にチェックが付き、
  一覧は画像と動画をすべて表示する（FR-056・058）。名前の変更中は無効にする
- 「zipファイルを表示」は、オンの項目にチェックマークを付ける。既定はオフで、値は保存する（FR-095・096）。名前の変更中は無効にする
- 「ゴミ箱に入れる」（ファイル・編集の両メニュー、⌘Delete）は、ツリーでお気に入りの項目を選択中のとき項目名を
  「お気に入りから削除」に変え、お気に入りの削除を行う。ツリーでルート以外の通常のフォルダを選択中のときは、項目名「ゴミ箱に入れる」の
  まま有効で、そのフォルダをゴミ箱に入れる（FR-079）。ツリーでホーム・ボリュームの最上位・「お気に入り」の見出しを選択中のときは無効（FR-064）
- 「編集 > 名前を変更」（Return）は、ツリーにフォーカスがありお気に入りの項目を選択中のとき、その項目の表示名の編集を始める。
  ツリーにフォーカスがあり、お気に入りの項目以外を選択中のとき（または何も選択していないとき）は無効。名前の変更中は無効。
  ツリーにフォーカスがあるときは、ファイルリストに zip の中や検索結果を表示中でも上の規則で有効になる（zip の中の読み取り専用と
  検索結果の制限はファイルリストにフォーカスがあるときだけ効く）。ファイルリストにフォーカスがあるときは従来どおりファイル名の変更（FR-019・073）
- 種類フィルタは、ファイルリストの選択・⌘A・コピーなどの操作・フルスクリーン中の矢印移動の対象を、表示中の一覧に限る
- 「zipファイルを表示」がオフの間は、zip ファイルの行が一覧にないため、選択・⌘A・コピーなどの操作・⌘↓（開く）・フルスクリーン中の矢印移動の
  対象にもならない（FR-095）
- 「中を表示」「上の階層へ」は、ファイルリストにフォーカスがあるときだけ有効で、名前の変更中は無効。「中を表示」はフォーカス行が
  zip ファイル・フォルダ・ディレクトリ・`..` のとき、「上の階層へ」は戻る先があるとき（zip の中、またはツリーのルート以外の通常のフォルダ）だけ有効（FR-069・077）
- zip の中を表示中は、「開く」「Finder に表示」「ゴミ箱に入れる」と「編集」メニューのコピー・ペースト・移動ペースト・複製・名前を変更を
  無効にする（FR-073）
- 「検索…」（⌘F）は、フルスクリーン中と名前の変更中は無効。検索結果を表示中は「ペースト」「移動ペースト」「上の階層へ」を無効にする（FR-080・087）
- 「表示 > 並べ替え」の「場所」は検索結果を表示中だけ有効。検索結果の表示を終えると、「場所」を選んでいた場合は保存済みの並べ替えに戻る
- 「ファイルリストのみ表示」「プレビューのみ表示」は、現在の表示状態の側にチェックマークを付ける。フルスクリーン中と名前の変更中は無効。
  ペインを隠している間は、隠しているペインへのフォーカスの項目（⌥⌘1〜3）と、ツリーを隠している間の「お気に入りへ移動」「お気に入りに追加」、
  プレビューのみ表示中の「検索…」を無効にする（FR-090・092）

## 確認モーダルと衝突ダイアログ

- 確認モーダル（設定で ON のとき）: 操作名、対象の件数、先頭最大5件のファイル名、操作先を表示する。
  対象にフォルダが含まれるときは「フォルダは中身ごと」操作する旨を添える（R32）。
  既定ボタンは「実行」、Esc で「キャンセル」（FR-022）
- 確認モーダルには「今後この確認を表示しない」チェックボックスを置き、設定の `confirmBeforeFileOperations` と連動させる（FR-023）。
  ただしコピー・削除でだけ省略でき、名前の変更と移動の確認モーダルは設定に関わらず常に表示し、チェックボックスも出さない（FR-024）。
  複製（⌘D）は確認モーダルを出さず、設定にも影響されない（FR-018・024）
- お気に入りの削除の確認モーダル（設定で ON のとき）: 「お気に入りから削除しますか？」、対象のお気に入りの表示名、
  登録したフォルダの絶対パス、実際のフォルダは変更されないこと。既定ボタンは「削除」、Esc で「キャンセル」。
  「今後この確認を表示しない」はファイル操作と同じ `confirmBeforeFileOperations` を変える（FR-024・064）。
  お気に入りの表示名の変更は確認モーダルを出さない（FR-099、A-29）。表示する本文:

  ```text
  お気に入りから削除しますか？

  対象: <表示名>
  場所: <登録したフォルダの絶対パス>
  実際のフォルダは変更されません
  ```
- 衝突ダイアログ（コピー・移動で常に表示する）: 「置き換える」「両方残す」「中止」と、「残りすべてに適用」のチェックボックス（FR-025）。
  名前の変更で既存の名前を指定した場合は、衝突ダイアログではなく名前の検証エラーを表示する
