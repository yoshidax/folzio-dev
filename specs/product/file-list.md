# ファイルリスト

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md`
から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

### ファイルリスト

- **FR-008**: システムは、選択フォルダ直下の項目のうち、サブフォルダ（FR-076）、対応メディア形式のファイル、zip
  ファイル（FR-068。zip ファイルの表示設定（FR-095）がオンのときだけ）を表示しなければならない。
  - 非対応ファイル・隠しファイル・隠しフォルダ・パッケージ（`.app` など）は表示しない（zip の中の一覧は FR-070
    に従う）
- **FR-010**: ユーザーは、表示形式を「リスト形式」と「サムネイル形式」で切り替えられなければならない
- **FR-011**: リスト形式は「ファイル名」「作成日」「種類」「サイズ」「変更日」の列を持たなければならない。
  - 既定で表示するのは前の3つで、表示する列は FR-273〜FR-275 で選べる。
  - 作成日・変更日の書式は表示言語と地域設定に従う（FR-151）。
  - 取得できない場合は `--` を表示する（EC-116）
- **FR-012**: ユーザーは、リスト形式の列見出しをクリックしてその列で昇順・降順に並べ替えられなければならない。
  - 既定はファイル名の昇順（数字を数値として比較する Finder と同じ自然順）とする。
  - 名前と場所は macOS 標準の比較に従い、表示言語・地域により一部の文字の順が変わりうるが、
    数字の自然順は保つ（EC-112）
- **FR-273**: リスト形式の列見出しの行を右クリックすると、「作成日」「種類」「サイズ」「変更日」
  の順の項目を持つポップアップが開かなければならない。
  - 表示中の列にはチェックを付ける。
  - 場所の列（FR-084）は項目に含めない
- **FR-274**: ポップアップの項目を選ぶと、その列の表示・非表示をすぐに一覧へ反映しなければならない。
  - 「ファイル名」の列はポップアップの項目に含めず、すべての列を非表示にしても常に表示する（Finder の「名前」と同じ）。
  - 既定の表示列は、ファイル名・作成日・種類とする
- **FR-275**: 列の表示状態は保存し、次回起動時に復元しなければならない。
  - 保存された値が壊れている場合は既定に戻し、未知の列は無視する（FR-003 の保存対象に加える）
- **FR-276**: リスト形式は「サイズ」「変更日」の列を持てなければならない。
  - サイズは自動単位で表示し、フォルダ（zip の中のフォルダを含む）と取得できない項目は `--` とする。
  - 変更日は FR-151 の書式で表示し、zip の中の項目は entry の更新日時を使う。
  - 取得できない場合は `--` とする
- **FR-277**（FR-012 の追記）: 「サイズ」「変更日」の列見出しのクリックと「表示 > 並べ替え」メニューで、その列の昇順・
  降順に並べ替えられなければならない。
  - サイズの並べ替えではフォルダ（zip の中を含む）を 0 バイトとして扱い、変更日を取得できない項目は昇順・
    降順のどちらでも末尾に置く。
  - 値が同じ項目は名前の自然順にする。
  - 並べ替えに使っている列を非表示にしたときは、ファイル名の並べ替えに切り替え、
    方向はファイル名で最後に使った方向（なければ昇順）とする。
  - この方向は保存し、再起動後も復元する
- **FR-288**（FR-012 の追記）: 「ファイル名」の列で並べ替えるとき、システムは、フォルダの行（通常のフォルダの `folder` と
  zip の中の `directory`）を、昇順・降順のどちらでも、ファイルの行（メディアファイルと zip ファイル）
  より前にまとめなければならない。
  - フォルダ同士、ファイル同士は名前の自然順（降順では逆順）で並べる。
  - zip ファイルはファイルとして扱う。
  - `..` は従来どおり常に先頭で、並べ替えの対象にしない。
  - この規則は、通常のフォルダの一覧・検索結果（FR-084）・zip の中の一覧（FR-071）に同じく適用し、
    検索中の追加（FR-085）も同じ順序になるようにする。
  - 名前以外の列の並べ替えは変えない。
- **FR-013**: サムネイル形式では、各ファイルの縮小画像（動画は代表フレーム）とファイル名を表示しなければならない。
  - 縮小画像の生成が終わるまでは代替表示を出し、生成後に差し替える
- **FR-014**: ユーザーは、サムネイルの大きさを最小 48pt〜最大 512pt の範囲で連続的に変更できなければならない。
  - 保存された値が範囲外の場合は、この範囲に丸める
- **FR-015**: サムネイル形式では、サムネイルをペイン幅に合わせて自動で折り返して配置し、
  横スクロールを発生させてはならない
- **FR-016**: ユーザーは、クリック・⌘クリック・Shift クリック、および Shift+矢印キー・⌘A
  で複数のファイルを選択できなければならない
- **FR-017**: ユーザーは、キーボードの矢印キーで選択を移動できなければならない。
  - プレビューは常に、最後に選択（フォーカス）されたファイルを表示する。
  - サムネイル形式では、矢印キー（Shift+矢印を含む）でフォーカスを移動したとき、
    フォーカス項目全体が見える位置まで必要最小限のスクロールを行わなければならない（既に全体が見えている場合はスクロー
    ルしない）。
  - ビューポートより高い項目では、項目の上端を可視領域の上端に合わせる。
  - フォーカス項目は最後に移動した項目とし、Shift+矢印で範囲を広げた場合も移動先の項目を基準にする。
  - スクロール追従の規定はサムネイル形式のみに適用する。
  - リスト形式は既存のスクロール挙動を維持し、本規定の対象外とする。
  - サムネイルサイズ・ペイン幅・ウィンドウサイズの変更による再レイアウトではスクロール追従を行わない
- **FR-048**: リスト形式では、
  各行のファイル名の先頭にそのファイルの内容を示す縮小画像アイコンを表示しなければならない。
  - 画像は内容を、動画は代表フレームを縮小したものを使う。
  - 生成中および生成に失敗した場合は、形式（画像/動画と拡張子）を区別できる汎用アイコンを表示する。
  - アイコン生成は表示や操作を妨げてはならず、生成完了後に差し替える。
  - アイコンは選択・複数選択・キーボード操作の対象を変えず、ファイル名は引き続き読み上げ可能でなければならない。
  - サムネイル形式の表示は FR-013 のままとし、本要件の対象外とする

### 種類フィルタ

- **FR-056**: ユーザーは、ファイルリストに表示するファイルを種類で絞り込む「種類フィルタ」を使えなければならない。
  - 種類フィルタは「画像のみ表示」と「動画のみ表示」の2つの独立したオン・オフからなる。
  - 「画像のみ表示」だけがオンのときは FR-008 で表示対象となるファイルのうち画像（FR-039 の画像形式）だけを、
    「動画のみ表示」だけがオンのときは動画だけを表示する。
  - 両方オン、または両方オフのときは、FR-008 の対象の画像と動画をすべて表示する。
  - 既定は両方オフとする。
  - 種類フィルタの状態は保存せず（FR-003 の保存対象に含めない）、
    アプリを起動するたびに両方オフで始めなければならない。
  - 起動中は、ツリーで別のフォルダを選んでも種類フィルタの状態を保ち、移動先のフォルダにも同じ絞り込みを適用する。
  - ただし、戻る・進む（FR-108（navigation-history.md））で移ったときは、
    移った先の履歴が持つ種類フィルタの状態に戻す。
  - 種類フィルタはファイルリスト（リスト形式・サムネイル形式の両方）にだけ適用し、ツリーの表示には影響しない。
  - 種類フィルタはメディアファイルにだけ適用し、zip ファイル（FR-068）、zip の中のディレクトリ、先頭行の
    `..`（FR-070）は種類フィルタの状態に関わらず表示する（ただし zip ファイルは、zip ファイルの表示設定（FR-095）
    がオフのときは表示しない）。
  - zip の中を表示中も同じ絞り込みを zip の中のメディアファイルに適用する
- **FR-057**: ツールバーには、種類フィルタの2つのトグルボタンを表示形式の切り替えボタン（FR-051）の左側に、
  左から「画像のみ表示」「動画のみ表示」の順で置かなければならない。
  - 各ボタンはクリックするたびにオン・オフが切り替わり、オンのときは押された状態の見た目で示す
- **FR-058**: 「表示」メニューに「画像のみ表示」と「動画のみ表示」の項目を置き、
  オンの項目にはチェックマークを付けなければならない。
  - キーボードショートカットは「画像のみ表示」が ⇧⌘I、「動画のみ表示」が ⇧⌘M とする。
  - メニュー・ショートカット・ツールバーのボタンは同じ状態を共有し、どこから変更しても他方の表示に反映される。
  - ツールバーが非表示のときも、メニューとショートカットで操作できなければならない（FR-040）
- **FR-059**: 種類フィルタの変更で選択中のファイルが非表示になった場合、
  システムはそのファイルを選択から外さなければならない。
  - プレビュー中（フォーカス）のファイルが表示されたまま残る場合は、
    フォーカスとプレビューをそのまま保つ（非表示になったほかのファイルは選択から外す）。
  - プレビュー中のファイルが非表示になり、選択に表示中のファイルが残る場合は、
    残ったうち一覧の並び順で最後のものをフォーカスにしてプレビューする。
  - 選択が1つも残らない場合はプレビューを空にし、別のファイルを自動で選択しない。
  - 再生中の動画が非表示になった場合は FR-034 と同じく再生を停止する。
  - 選択から外したファイルは、種類フィルタを戻して再び表示されても選択に戻さない
- **FR-060**: 選択フォルダに FR-008 の対象ファイルがあるのに種類フィルタによって1件も表示されない場合、
  システムはファイルリストに、どちらの種類で絞り込み中かと該当するファイルがないことを示すメッセージ（例:
  「画像のみ表示中:該当するファイルはありません」）を表示しなければならない。
  - 対象ファイルが元々1件もないフォルダでは、種類フィルタの状態に関わらず従来の空のメッセージを表示する。
  - フォルダ（FR-076）・zip ファイル・zip の中のディレクトリ・`..` の行は、この判定でファイルとして数えない。
  - zip ファイルの表示設定（FR-095）がオフのときは zip ファイルの行自体を表示しない。
  - 表示している階層（フォルダまたは zip の中の階層）
    に対応メディアファイルがあるのに種類フィルタで1件も表示されない場合は、それらの行が残っていても、
    残った行に加えて絞り込み中のメッセージを表示する。
  - 対応メディアファイルが元々1件もない階層では、フォルダ・zip ファイル・
    ディレクトリが1つでもあれば空のメッセージを出さず、`..` 以外の行が1つもなければ従来の空のメッセージを表示する

### ファイルリストのフォルダ

- **FR-076**: システムは、ファイルリストに選択フォルダ直下のサブフォルダ（隠しフォルダとパッケージを除く）
  を表示しなければならない。
  - ユーザーは、フォルダの行をダブルクリックするか、選択して ⌘↓ を押すことで、
    ファイルリストをそのフォルダの一覧に切り替えられなければならない。
  - フォルダの行は、プレビュー（FR-075 と同じく空にし、再生中の動画は停止する）・
    縮小画像と行頭アイコン（フォルダを示す汎用アイコン）・種類フィルタ（FR-056・FR-060。常に表示し、
    ファイルとして数えない）・フルスクリーン中の矢印キー移動（FR-046。止まらずに飛ばす）について、zip
    の中のディレクトリと同じく扱う。
  - フォルダの行は FR-018〜FR-027 のファイル操作の対象とする。
  - ツリーの通常フォルダに対しては、ゴミ箱に入れる操作を FR-079、名前の変更を FR-103、ドラッグによる移動・コピーを
    FR-020 に従って行える（複製はファイルリストからだけ行う）。

- **FR-077**: 通常のフォルダの一覧でも、先頭行に1つ上の階層へ戻る行 `..` を表示しなければならない。
  - `..` は zip の中の `..`（FR-070）と同じ行とし、並べ替えの対象にせず常に先頭に置く。
  - `..` のダブルクリック・⌘↓、および選択中の行に関わらない⌘↑ で、親フォルダの一覧に戻る。
  - 戻った先では、直前まで表示していたフォルダの行だけを選択し、FR-070
    と同じく見える位置まで必要最小限のスクロールを行う。
  - ただし、ツリーのルート（ホームフォルダ、マウント中のボリュームの最上位）を表示しているときは `..` を表示せず、⌘↑
    も何もしない（ツリーの外へは戻らない）。
  - お気に入りの項目（FR-063）のフォルダを表示しているときは、そのフォルダがツリーのルートでなければ `..` を表示し、
    戻ると親フォルダをツリーの実際の階層で選択する（FR-078）
- **FR-078**: ファイルリストでフォルダを開いた、または `..`・⌘↑ で親フォルダに戻ったとき、システムはツリーの選択を、
  ファイルリストに表示しているフォルダへ同期しなければならない。
  - ツリーの実際の階層（お気に入りの項目ではなく、ホーム・ボリューム以下）でそのフォルダの行を選択し、
    祖先が折りたたまれていれば展開し、その行全体が見える位置まで必要最小限のスクロールを行う。
  - キーボードフォーカスはファイルリストに残す。
  - 親へ戻ったとき、直前まで表示していた子フォルダの展開状態は変えない（折りたたまない）。
  - この同期で選択したフォルダは、ツリーで選択したときと同じく最後に選択していたフォルダ（FR-003）として保存する。
  - 同期はファイルリストの表示を待たせてはならず、FR-055 のサブフォルダ確認も通常の展開と同じく行う
- **FR-181**: ユーザーは、ファイルリスト（通常のフォルダと検索結果の一覧）で1件だけ選択したファイル・フォルダ・zip
  ファイル（メディアファイルを含む）の絶対パスを、行の右クリックメニューの「パス名をコピー」
  で文字列としてクリップボードにコピーできなければならない。
  - コピーする文字列は引用符・エスケープ・末尾スラッシュを加えない絶対パスとし、
    クリップボードの既存の内容は置き換える。
  - 無効にする条件は FR-183（file-operations.md）、キーボード手段は FR-184（file-operations.md）に従う
- **FR-213**: ファイルリストの背景を右クリックしたとき、システムは選択中の項目向けのメニューの代わりに、
  表示中のフォルダ向けのメニューを次の順で表示しなければならない。
  - 1. 新規フォルダ（⇧⌘N）、2. ─、3. ペースト（⌘V）／ 移動ペースト（⌥⌘V）、4. ─、5. Finder に表示。
  - ペースト・移動ペーストの対象と有効条件は従来のペースト（表示中のフォルダへ。FR-019・FR-073・FR-087）と同じとし、
    「Finder に表示」は表示中のフォルダを Finder で表示する（zip の中・検索結果の表示中は淡色）。
  - 背景の右クリックではファイルリストの選択・プレビューを変えない。
  - 項目の右クリックメニューは変えず、「新規フォルダ」を出さない

### 内容の置き換えの反映

- **FR-228**: システムは、表示中のフォルダの一覧にあるメディアファイルについて、
  同じパスのまま内容が置き換わったこと（アプリの外での上書き、およびアプリでのコピー・移動の「置き換える」
  （FR-025（file-operations.md））を含む）を、外部の変更の反映（FR-042（overview.md））と同じ契機で検出し、
  そのファイルの縮小画像（FR-013）を置き換え後の内容で作り直さなければならない。
  - 内容が変わっていないファイルの縮小画像は、作り直してはならない
- **FR-229**: 置き換えを検出したファイルが、静止画またはアニメーション画像としてプレビュー中であれば、システムは、
  ユーザーが選択し直さなくても、プレビューを置き換え後の内容で読み込み直さなければならない。
  - 選択・フォーカス・一覧のスクロール位置は変えない（倍率と読み込み中の表示は EC-162（preview.md）、動画は
    EC-163（preview.md）に従う）

### クイックルックと既定のアプリで開く

- **FR-247**: ユーザーは、ファイルリストにフォーカスがありメディアファイルを選択しているとき、Space で macOS の Quick
  Look の標準パネルによる一時プレビューを開閉できなければならない。
  - 開くときは対象の行（サムネイル形式ではサムネイル）の画面上の位置を起点に拡大し、閉じるときはその位置へ縮む。
  - 表示は Quick Look の標準のものとし、「プレビュー」アプリの起動や独自の簡易プレビューで代替してはならない。
  - 対象は画像（静止画・アニメーション画像）と動画の両方とする。
  - 動画の再生／一時停止の Space との関係は FR-248（preview.md）に従う
- **FR-249**: 複数のメディアを選択しているときの Space は、選択中のメディアを一覧の並び順で Quick Look
  の複数ファイル形式の UI に渡す。
  - `<` `>` ボタンによる項目の移動は Quick Look の標準の動作とし、ファイルリストの選択は変えない。
  - メディアでない選択（フォルダ・zip ファイル・`..`）は対象から除く。
  - 対象が0件なら何もしない（EC-171）
- **FR-250**: FR-247・FR-249・FR-251 は、リスト形式とサムネイル形式のどちらでも、
  通常のフォルダと検索結果のどちらでも同じに使える。
  - ファイルリストのみ表示（⌃⌘2）でも使える。
  - zip の中は対象外とする（A-150）
- **FR-251**: ユーザーは、ファイルリストのメディアの行（サムネイル）のダブルクリックで、そのファイルを OS
  が関連付けた既定のアプリで開けなければならない。
  - ダブルクリックした行は1件だけの選択にする。
  - フォルダ・zip ファイル・zip の中のディレクトリ・`..` の行のダブルクリックは変えない（FR-069・FR-070（zip.md）、
    FR-076）。
  - zip の中のメディアは対象外とする（A-150）
- **FR-253**: 一時プレビューを開いて閉じるだけの操作では、ファイルリストの選択・フォーカス・並べ替え・表示形式・
  スクロール位置と、プレビューペインの表示内容は変わらない（EC-172・175 の場合と、FR-254 の矢印キーによる移動を除く）。
  - 一時プレビューの表示中の Esc とパネルの閉じるボタンは、パネルを閉じるだけとし、検索結果の表示は終えない
- **FR-254**: 一時プレビューの表示中は、矢印キー（⇧ との組み合わせを含む）を、1件選択でも複数選択でも、
  ファイルリストのキー入力として扱わなければならない。
  - 選択の移動と表示の規則は、ファイルリストにフォーカスがあるときの矢印キーと同じとする（FR-016・FR-017。フォルダ・
    zip・`..` の行にも止まる）。
  - 選択が変わったら、一時プレビューの項目（FR-249 の対象）と起点の位置を新しい選択に更新する。
  - 更新後に対象が0件になったときは閉じる（US3-AS36）

### 名前の絞り込み（TAK-86）

- **FR-380**: ツールバーに、ファイルリストを名前（ファイル名とフォルダ名）
  で絞り込むための検索欄（標準の検索フィールド）を1つのセットとして追加しなければならない。
  - 既定の並びでは、ツールバーの右端に置く（FR-233（window-layout.md））
  - 検索欄の中の左端に虫眼鏡アイコンを表示する
  - 検索欄が空のときは、名前で絞り込む欄であることを示すプレースホルダを表示する
  - 検索欄に1文字以上が入っている間、検索欄の中の右端にクリア（×）ボタンを表示する
- **FR-381**: 検索欄に文字が入っている間、システムは、ファイルリストに表示する行を、
  名前がその文字に一致するものだけに絞り込まなければならない（名前の絞り込み）。
  - 絞り込みは、文字を入力・削除するたびに、Return を待たずに反映する
  - 照合の規則は検索のモーダルと同じとする（FR-082（search.md））
    - ワイルドカードを含まない文字は名前への部分一致、`*`・`?` を含む文字は名前全体との一致とする
    - 英字の大文字小文字と Unicode の正規化の違いは区別しない
  - 対象は、メディアファイル・フォルダ・zip ファイル・zip の中のディレクトリの行とする
  - 先頭の `..` の行は、絞り込みに関わらず表示する
  - 前後の空白を除いた文字が空のときは、絞り込まない
  - 種類フィルタ（FR-056）と「zipファイルを表示」（FR-095（zip.md））で表示の対象になった行を、さらに名前で絞り込む
  - リスト形式とサムネイル形式の両方に適用し、ツリーの表示には影響しない
- **FR-382**: 名前の絞り込みは、通常のフォルダの一覧・zip の中の一覧・検索結果の一覧のどれにも適用しなければならない。
  - 検索結果を絞り込んでも、検索バーのキーワード・起点・件数（FR-084（search.md））は変えず、実行中の検索も止めない
  - 絞り込みはフォルダを辿らず、表示中の一覧の項目だけを照合する
- **FR-383**: 検索欄の×ボタンを押すか、検索欄で Esc を押すと、システムは検索欄の文字を消し、
  名前の絞り込みを解除しなければならない
- **FR-384**: ファイルリストに表示する一覧が別の場所へ替わったとき、システムは名前の絞り込みを解除し、
  検索欄を空にしなければならない。
  - 替わる操作は、ツリーでのフォルダの選択、一覧のフォルダ・zip の行と `..` を開く操作、上の階層へ（⌘↑）、戻る・進む、
    検索の開始、検索結果の解除、表示中のフォルダが消えたことによる移動を含む
  - 同じ場所の一覧の更新（アプリの外での変更の反映、ファイル操作の結果の反映）と EC-259 の変更では解除しない
  - 名前の絞り込みは保存せず、履歴にも記録しない（EC-254）
- **FR-385**: 名前の絞り込みで選択中の項目が非表示になった場合、システムは、
  種類フィルタの変更で非表示になった場合（FR-059）と同じ規則で、その項目を選択から外し、
  フォーカスとプレビューを扱わなければならない。
  - 選択から外した項目は、絞り込みを解除して再び表示されても選択に戻さない
- **FR-386**: 名前の絞り込みの対象になる行（`..` を除く）があるのに、絞り込みによって1行も表示されない場合、
  システムはファイルリストに、入力した文字に一致する項目がない旨のメッセージを表示しなければならない。
  - メッセージには入力した文字を含め、フォルダが空のメッセージ・種類フィルタの絞り込み中のメッセージ（FR-060）・
    検索で一致がない旨のメッセージ（FR-084（search.md））と区別する
  - 1行でも表示される場合は、このメッセージを出さず、FR-060 の判定を従来どおり行う
- **FR-387**: 表示中の一覧を対象にする操作（すべてを選択、矢印キーでの移動、フルスクリーン中の移動、スライドショー）
  は、種類フィルタと同じく、名前で絞り込んだ後の一覧を対象にしなければならない
- **FR-388**: 検索欄（入力・虫眼鏡・×ボタン）は、検索のモーダルを開ける条件（FR-080（search.md））
  を満たすときだけ有効にしなければならない。
  - フルスクリーン表示中とプレビューのみ表示中（FR-092（window-layout.md））は、無効の表示にする
  - 無効の間も、入力済みの文字と絞り込みは保つ（EC-258）
  - 検索欄での入力は、名前の変更中（FR-102（directory-tree.md））として扱わない
  - 名前の変更中に検索欄を押した場合の名前の変更の扱いは、ほかの場所を押した場合と同じとする
- **FR-389**: 検索欄にフォーカスがある状態で Return を押すと、システムは、
  絞り込みを保ったままキーボードフォーカスをファイルリストへ移さなければならない。
  - 絞り込みで検索結果が1行も表示されず、ファイルリストがメッセージに替わっているときは、フォーカスを検索欄に残す
  - 日本語入力の変換を確定する Return では、フォーカスを移さない
  - 変換中の未確定の文字では絞り込みを変えず、確定した文字で絞り込む
- **FR-390**: 検索欄の虫眼鏡アイコンを押すと、システムは検索のモーダル（FR-080（search.md））を開かなければならない。
  - 検索欄に前後の空白を除いて1文字以上が入っているときは、検索キーワード欄に検索欄の文字（前後の空白を除く）
    を全選択の状態で入れる
  - 検索欄が空（空白だけを含む）のときは、⌥⌘F で開いた場合と同じく、前回検索したキーワードがあればそれを入れる
  - 上の2点を除き、モーダルの構成・既定の起点・検証・キーボード操作・「検索」「キャンセル」の動作は、⌥⌘F
    で開いた場合（FR-081・FR-141〜FR-144（search.md））と同じとする
  - 検索欄にフォーカスがある状態で ⌥⌘F（「ファイル」メニューの「検索…」を含む）を実行した場合も、
    虫眼鏡を押した場合と同じに扱う
  - モーダルを開いただけ、またはキャンセルしただけでは、検索欄の文字と絞り込みを変えない
- **FR-391**: ユーザーは、「ファイル」メニューの「名前で絞り込む」（英語: `Filter by Name`）
  とキーボードショートカット ⌘F で、ツールバーの検索欄へキーボードフォーカスを移せなければならない。
  - 入力済みの文字があれば全選択する
  - ツールバーを隠しているときは、ツールバーを表示してからフォーカスを移す
  - 次のときは、項目を淡色にして選べなくし、ショートカットも何もしない
    - 検索欄が無効のとき（FR-388）
    - 検索欄がツールバーにないとき
    - ツールバーを文字だけで表示する形式のとき
    - ウインドウが狭く、検索欄がツールバーからあふれて表示されていないとき
  - このコマンドは、割り当てを変更できるコマンドの1つとする（FR-268（window-layout.md））
- **FR-392**: 検索欄のセットのラベル（カスタマイズ画面とテキスト表示で使う名前）は「絞り込み」（英語: `Filter`）
  としなければならない（FR-236（window-layout.md））。
  - プレースホルダとアクセシビリティのラベルは「名前で絞り込み」（英語: `Filter by Name`）とする
  - 検索欄のツールチップは「名前で絞り込む（⌘F）」（英語: `Filter by Name (⌘F)`）とし、
    キーは現在の割り当てに従う（FR-237（window-layout.md））
  - 虫眼鏡アイコンのツールチップとアクセシビリティのラベルは「検索…（⌥⌘F）」（英語: `Find… (⌥⌘F)`）とし、
    キーは現在の割り当てに従う
  - 一致する項目がない旨のメッセージは「“{入力した文字}”に一致する項目はありません」（英語:
    `No items match “{入力した文字}”`）とする
  - ツールバーを文字だけで表示する形式と、あふれたときのメニューでは、項目「絞り込み」
    を選ぶと検索のモーダルを開く（有効の条件は FR-388）
  - 虫眼鏡の動作（検索のモーダルを開く）は、検索欄のアクセシビリティのアクション「検索…（⌥⌘F）」としても提供し、
    VoiceOver から実行できるようにする
- **FR-393**: 検索欄のセットは、ほかのセットと同じくツールバーのカスタマイズ（並び替え・削除・再追加）の対象とし、
  保存した並びに識別子 `nameFilter` で記録しなければならない。
  - 検索欄を加える前に保存した並び（検索欄を含まない）は、そのまま復元し、
    検索欄を自動では追加しない（FR-235（window-layout.md））
  - ツールバーを隠したとき、検索欄をツールバーから外したとき、ツールバーを文字だけで表示する形式にしたときは、
    名前の絞り込みを解除する

## 主なエンティティ

- **上の階層へ戻る行（`..`）**: ファイルリストの先頭行に置く仮想的な項目。
  - 通常のフォルダ（ツリーのルートを除く）と zip の中の一覧で共通。
  - 並べ替え・ファイル操作・種類フィルタの対象にならない
- **メディアファイル**: リストの項目。
  - ファイル名、場所、作成日、種類（画像/動画と形式）、サイズ、縮小画像、
    行頭アイコン（縮小画像または形式別の汎用アイコン）を持つ
- **種類フィルタ**: 「画像のみ表示」と「動画のみ表示」のオン・オフ。
  - 既定は両方オフ。
  - 起動中はフォルダを移っても保たれる（戻る・進むで移ったときは、移った先の履歴の状態に戻る）。
  - 保存はせず、起動のたびに既定に戻る。
  - メディアファイルにだけ適用し、zip ファイル・zip の中のディレクトリ・`..` は隠さない
- **一時プレビューの対象**: 選択中のメディアファイルの URL の並び（一覧の並び順）と、各項目の画面上の起点の矩形。
  - ファイルシステムのファイルだけを持ち、zip の中の項目は含まない。
  - 永続化しない（FR-247・FR-249）
- **ファイルの内容の識別情報**: 同じパスのファイルの内容が置き換わったかを判断するための値。
  - ファイルの大きさ・更新日時・ファイルシステム上の実体の番号などからなる（A-141（overview.md））。
  - 一覧を作るとき、またはプレビューを読み込むときに得る。
  - zip の中のファイルでは、zip ファイル自体の識別情報を使う
- **縮小画像・プレビュー画像の保持**: 表示を速くするために保持している、作成済みの縮小画像とデコード済みの画像。
  - パスと、作ったときの内容の識別情報の組で区別する（FR-230（preview.md））
- **名前の絞り込み**: 検索欄に入力された文字と、その文字から決まる照合の条件。
  - 表示中の一覧だけに働き、保存せず、履歴にも記録しない
  - 表示する一覧が別の場所へ替わると解除される

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS2**: **Given** ツリーでフォルダを選択した,
  - **When** 中央のリストを見る,
  - **Then** そのフォルダ直下のサブフォルダ・対応メディアファイル（画像・動画）・zip ファイル（zip
    ファイルの表示設定がオンのとき）のみが表示され、非対応ファイルと隠しファイル・隠しフォルダ・
    パッケージは表示されない
- **US1-AS4**: **Given** リストでファイルが選択されている,
  - **When** 上下（サムネイル形式では上下左右）キーで選択を移動する,
  - **Then** プレビューが新しく選択されたファイルに切り替わり、
    サムネイル形式では選択項目全体が見える位置まで必要最小限スクロールする（既に全体が見えている場合はスクロールしない）
- **US1-AS21**: **Given** サブフォルダを持つフォルダを表示中,
  - **When** ファイルリストでサブフォルダの行をダブルクリックする（または選択して ⌘↓ を押す）,
  - **Then** ファイルリストがそのサブフォルダの一覧に切り替わり、
    ツリーでもそのサブフォルダが選択される（折りたたまれていた親は展開され、行が見える位置までスクロールされる）。
    キーボードフォーカスはファイルリストに残る
- **US1-AS22**: **Given** ツリーのルート以外のフォルダを表示中,
  - **When** 先頭行の `..` をダブルクリックする（または ⌘↑ を押す）,
  - **Then** 親フォルダの一覧に戻り、直前まで表示していたフォルダの行が選択されて見える位置までスクロールされ、
    ツリーでは親フォルダが選択される。ホームフォルダやボリュームの最上位を表示中は `..` が表示されず、⌘↑
    を押しても何も起きない

### US3 リスト形式とサムネイル形式を切り替えて一覧する（P2）

- **US3-AS1**: **Given** リスト形式で表示中,
  - **When** 表示形式をサムネイル形式に切り替える,
  - **Then** 同じファイル群がサムネイルのグリッドで表示され、選択状態は維持される
- **US3-AS2**: **Given** リスト形式,
  - **When** 列見出し（ファイル名・作成日・種類）をクリックする,
  - **Then** その列で昇順に並び替わり、再度クリックすると降順になる
- **US3-AS3**: **Given** サムネイル形式,
  - **When** サムネイルサイズを変更する,
  - **Then** 操作に追従して連続的にサイズが変わり、1行あたりの列数が自動で調整される
- **US3-AS4**: **Given** サムネイル形式,
  - **When** ペインの幅を狭める,
  - **Then** サムネイルは折り返して再配置され、横スクロールバーは表示されない
- **US3-AS5**: **Given** アプリを終了して再起動した,
  - **When** ファイルリストを見る,
  - **Then** 前回の表示形式とサムネイルサイズが復元されている
- **US3-AS6**: **Given** リスト形式,
  - **When** ファイルリストを見る,
  - **Then** 各行のファイル名の先頭に、
    そのファイルの内容を示す縮小画像アイコンが表示される。動画は代表フレームを使い、
    生成中または生成に失敗した行は形式別の汎用アイコンを表示する
- **US3-AS11**: **Given** 画像と動画が混在するフォルダを表示中で、種類フィルタが既定（両方オフ）,
  - **When** ファイルリストを見る,
  - **Then** 対応する画像と動画がすべて表示される
- **US3-AS12**: **Given** ツールバーを表示中,
  - **When** 表示形式ボタンの左にある「画像のみ表示」ボタンを押す,
  - **Then** ボタンが押された状態になり、ファイルリストには画像だけが表示され、「表示」メニューの「画像のみ表示」
    にチェックが付く。「動画のみ表示」ボタンだけを押した場合は動画だけが表示される
- **US3-AS13**: **Given** 「画像のみ表示」と「動画のみ表示」の両方を押した,
  - **When** ファイルリストを見る,
  - **Then** 画像と動画がすべて表示される。どちらか一方を戻すと、押されている側の種類だけの表示になる

### US53 サイズと変更日で並べ替え、列の状態を保存する（P2）

- **US53-AS1**: **Given** サイズの列を表示中、
  - **When** ファイルを見る、
  - **Then** 自動単位（KB・MB など）で表示する。フォルダ（zip の中のフォルダを含む）と、取得できない項目は `--`
    を表示する。
- **US53-AS2**: **Given** 変更日の列を表示中、
  - **When** ファイルを見る、
  - **Then** 作成日と同じ書式（FR-151）で変更日を表示する。zip の中の項目は、entry
    の更新日時を表示する。取得できない項目は `--` を表示する。
- **US53-AS3**: **Given** サイズまたは変更日の列を表示中、
  - **When** 列見出しをクリックする、
  - **Then** その列の昇順に並び、もう一度クリックすると降順になる（FR-012）。サイズの並べ替えでは、フォルダ（zip
    の中のフォルダを含む）を 0 バイトとして扱う（Finder と同じ）。
    昇順ではフォルダが先頭（フォルダどうしは名前の自然順）、降順では末尾になる。変更日の並べ替えでは、
    フォルダもファイルと同じく変更日で並べ、フォルダをまとめて先頭や末尾に置かない。変更日を取得できない項目は、昇順・
    降順のどちらでも末尾に置く。値が同じ項目は名前の自然順にする。
- **US53-AS4**: **Given** 「表示 > 並べ替え」メニュー、
  - **When** メニューを開く、
  - **Then** サイズと変更日が項目に加わり、列見出しのクリックと同じ並べ替えが行える。列が非表示でも選べる。
- **US53-AS5**: **Given** サイズで並べ替え中、
  - **When** 「サイズ」の列を非表示にする、
  - **Then** 並べ替えはファイル名に切り替わる。方向は、
    ファイル名で最後に並べ替えたときの方向（一度も並べ替えていなければ昇順）とする（Finder と同じ）。
    この方向はアプリの再起動後も復元する。作成日・種類・変更日でも同じ。
- **US53-AS6**: **Given** 列の表示を変更した、**When** アプリを終了して再起動する、**Then** 同じ列が表示される。
- **US53-AS7**: **Given** 保存された値が壊れている、または未知の列を含む、
  - **When** 起動する、
  - **Then** 既定の列で表示し、クラッシュしない。未知の列は無視する。

  - **Then** 検索のモーダルが開き、検索キーワード欄に `kyoto` が全選択の状態で入っている
    - 検索起点ディレクトリは ⌥⌘F で開いた場合と同じ既定値（FR-081（search.md））である
- **US82-AS2**: **Given** 検索欄が空で、同じ起動中に `cat` で検索したことがある,
  - **When** 虫眼鏡アイコンを押す,
  - **Then** ⌥⌘F で開いた場合と同じく、検索キーワード欄に `cat` が全選択の状態で入っている
- **US82-AS3**: **Given** 虫眼鏡から開いたモーダル,
  - **When** 「キャンセル」を押す,
  - **Then** 検索欄の文字と絞り込みは変わらない
- **US82-AS4**: **Given** 虫眼鏡から開いたモーダル,
  - **When** 「検索」を押して検索が始まる,
  - **Then** 表示する一覧が検索結果に替わるので、絞り込みは解除され、検索欄は空になる（FR-384）
- **US82-AS5**: **Given** 検索欄に `kyoto` と入力済みで、検索欄にフォーカスがある,
  - **When** ⌥⌘F を押す,
  - **Then** 虫眼鏡を押した場合と同じく、検索キーワード欄に `kyoto` が入った検索のモーダルが開く
- **US82-AS6**: **Given** 一覧を表示中,
  - **When** ⌥⌘F（または虫眼鏡）で検索のモーダルを開く,
  - **Then** モーダルの冒頭に見出し「サブフォルダを含めて検索」と、
    その下に小さく淡い文字で補足説明（FR-394（search.md））が表示される
    - キーボードフォーカスは従来どおり検索キーワード欄にあり、VoiceOver はキーワード欄の説明として補足説明を読み上げる

### US83 キーボードだけで絞り込む（P2）

- **US83-AS1**: **Given** ファイルリストにフォーカスがある,
  - **When** ⌘F を押す（または「ファイル」メニューの「名前で絞り込む」を選ぶ）,
  - **Then** ツールバーの検索欄にフォーカスが移り、入力済みの文字があれば全選択される
- **US83-AS2**: **Given** ツールバーを隠している,
  - **When** ⌘F を押す,
  - **Then** ツールバーが表示され、検索欄にフォーカスが移る
- **US83-AS3**: **Given** 絞り込み中で、Return でファイルリストへ戻った後,
  - **When** ⌘F を押してから Esc を押す,
  - **Then** 検索欄の文字が消え、絞り込みが解除される
- **US83-AS4**: **Given** プレビューのみ表示中、またはカスタマイズで検索欄を外している,
  - **When** 「ファイル」メニューを開く,
  - **Then** 「名前で絞り込む」は淡色で選べず、⌘F も何もしない

### US84 検索欄を含むツールバーを自分の並びにする（P3）

- **US84-AS1**: **Given** ツールバーを一度もカスタマイズしていない,
  - **When** 検索欄を加えた版を起動してツールバーを表示する,
  - **Then** 検索欄がツールバーの右端に表示される
- **US84-AS2**: **Given** 検索欄を加える前にツールバーを並び替えて保存した,
  - **When** 検索欄を加えた版を起動する,
  - **Then** 保存した並びのまま表示され、検索欄は自動では加わらない
    - カスタマイズ画面には検索欄が候補として表示され、ドラッグで追加できる
- **US84-AS3**: **Given** カスタマイズ画面で検索欄を左端へ移した,
  - **When** アプリを再起動する,
  - **Then** 検索欄は左端に復元され、文字は空で始まる
- **US84-AS4**: **Given** 絞り込み中,
  - **When** ツールバーを隠す（⇧⌘T）、検索欄をカスタマイズで外す、またはツールバーを文字だけで表示する形式にする,
  - **Then** 絞り込みは解除される（検索欄が見えない状態で、絞り込みだけが残らない）
- **US84-AS5**: **Given** ツールバーを文字だけで表示する形式にした、またはウインドウが狭く検索欄があふれた,
  - **When** 「絞り込み」の項目を選ぶ,
  - **Then** 検索のモーダルが開く

## エッジケース

- **EC-01**: 対応メディア・zip ファイル・サブフォルダ（隠しフォルダとパッケージを除く）
  が1つもないフォルダを選んだ場合、リストは空であることを示すメッセージを表示する（`..`
  の行だけが残る場合も空とみなす）
- **EC-02**: 対応メディアはあるが種類フィルタで1件も表示されない場合、
  リストは絞り込み中で該当ファイルがないことを示すメッセージを表示し、従来の空のメッセージとは区別する
- **EC-04**: 動画の代表フレームを取得できない場合も、リストの行頭アイコンは形式別の汎用アイコンにフォールバックし、
  ファイルの表示・選択は継続できる
- **EC-09**: 10,000 ファイル以上を含むフォルダを選んだ場合、リストは段階的に表示され UI は操作可能なまま
- **EC-21**: 種類フィルタで選択中のファイルが非表示になった場合は、そのファイルを選択から外し、
  選択が残らなければプレビューを空にする（再生中の動画は停止する）。
  - フィルタを戻しても選択は復元しない
- **EC-170**: 一時プレビューは、ファイルリストにフォーカスがあるときだけ開く。
  - ツリー・プレビュー・検索シート・設定ウインドウにフォーカスがあるとき、フルスクリーン中、名前の変更中、
    スライドショー実行中は Space を一時プレビューに使わない（名前の変更中の Space は文字入力、ほかは従来の動作）
- **EC-171**: 選択がない、またはメディアでない行（フォルダ・zip ファイル・`..`）だけの選択で Space を押したときは、
  何もしない。
  - ビープ音も出さない
- **EC-172**: 一時プレビューの表示中に、選択中のファイルが削除・移動・名前の変更で消えた、
  またはフォルダの表示が切り替わった（戻る・進む、検索の開始・終了）ときは、一時プレビューを閉じる。
  - 存在しない項目を表示し続けない
- **EC-173**: 一時プレビューの起点の行がスクロールで見えない位置にあるときは、
  見える位置にスクロールしてから開く（FR-017 と同じ必要最小限のスクロール）。
  - それでも位置が決まらない場合は、ファイルリスト全体の位置を起点にして、アニメーションなしで開いてもよい
- **EC-174**: macOS の「視差効果を減らす」がオンのとき、拡大・縮小のアニメーションは OS
  の標準の挙動に従う（アプリ側で独自に付け足さない）
- **EC-175**: 一時プレビューを表示している間、プレビューペインで再生中の動画は一時停止する（二重の音声を避ける）。
  - 矢印キーで選択が動画に移ったときも、表示している間はプレビューペインの動画を自動再生せず、
    一時停止の状態で表示する（FR-031・FR-032（preview.md）の自動再生は抑える）。
  - 閉じた後に再生を自動で始めない・再開しない
- **EC-176**: 既定のアプリを開けないとき（関連付けがない、ファイルがない、権限がない）は、⌘O と同じく何も表示せず、
  選択・プレビューも変えない
- **EC-177**: ダブルクリックでアプリを開いても、Folzio の選択・プレビュー・動画の再生状態は、
  ダブルクリックした行の選択に伴う通常の切り替え（FR-017、FR-034（preview.md））以外は変えない
- **EC-188**: ダークモードや選択行の背景（アクセントカラー）でも、固定色のアイコンは背景と区別でき、
  読めなければならない（アイコンは名前の補助であり、ファイル名は変わらず読める）。
- **EC-189**: アイコンの色を変えても、サムネイルの縮小画像、選択、キーボード操作、読み上げは変わらない。
- **EC-250**: 絞り込み中に、一覧の項目が増えた・名前が変わった場合（アプリの外での変更、名前の変更、複製、ペースト、
  検索中に見つかった項目）は、その時点の名前で照合し、一致する項目だけを表示する。
  - 一覧で名前を変えた項目が一致しなくなった場合は、その行は非表示になり、選択から外れる（FR-385）
- **EC-251**: 検索中（検索結果を集めている間）に絞り込んでも、検索は止めない。
  - 絞り込みを解除すると、その時点までに見つかった結果がすべて表示される
- **EC-252**: 前後の空白を除いた文字が空（空白だけ）のときは、絞り込まない
- **EC-253**: ウインドウが狭く検索欄があふれて見えなくなっただけでは、絞り込みを解除しない。
  - ウインドウを広げると、検索欄は入力済みの文字のまま現れる
- **EC-254**: 検索欄の文字と絞り込みは保存せず、再起動後は絞り込みのない状態で始まる。
  - 履歴（navigation-history.md）にも記録せず、戻る・進むで移った先は絞り込みのない状態で表示する
- **EC-255**: 表示言語を切り替えた場合、検索欄のプレースホルダ・ラベル・ツールチップと、

- **EC-256**: カスタマイズ画面のパレットの見本の検索欄には入力できず、絞り込みも虫眼鏡も働かない（標準の動作）
- **EC-257**: 検索欄にフォーカスがある間、ファイル操作のショートカット（⌘⌫・⌘C・⌘V・⌘D など）は、
  検索欄の文字の編集として働くか、何もしない。
  - ファイルリストとツリーで選択中の項目を対象にしない（検索欄で文字を消そうとして、
    ファイルをゴミ箱に入れることがない）
- **EC-258**: 絞り込み中にプレビューのみ表示・フルスクリーン・スライドショーへ移った場合は、検索欄は無効になるが、
  絞り込みは保つ。
  - フルスクリーン中の矢印キーでの移動とスライドショーは、絞り込んだ後の一覧を対象にする（種類フィルタと同じ。FR-387）
- **EC-259**: 並べ替え・表示形式・種類フィルタ・「zipファイルを表示」・列の表示の変更では、絞り込みを解除しない
- **EC-260**: 検索結果を表示中に絞り込んでいるとき、ファイルリストで Esc を押すと、
  従来どおり検索結果の表示を解除する（FR-086（search.md））。

## 前提

- **A-03**: 「扱えるイメージファイルのみフィルタ」は、対応する画像と動画の両方を表示する意味と解釈した。
  - フィルタはファイルにだけ適用し、サブフォルダ（隠しフォルダとパッケージを除く）と zip
    の中のディレクトリはファイルリストに表示する
- **A-08**: 「作成日」はファイルシステムが記録しているファイルの作成日時とする（EXIF の撮影日時ではない）
- **A-15**: 縮小画像はアプリ内で生成し、ユーザーのフォルダには書き込まない（憲章 原則 I）
- **A-25**: 一覧の並べ替えでは、「ファイル名」の列に限り、フォルダ（通常のフォルダ・zip の中のディレクトリ）
  を先頭にまとめ、zip ファイル（zip ファイルの表示設定がオンのとき）
  とメディアファイルをその後ろに並べる（FR-288。Finder の名前順と同じ。`..` は常に先頭）。
  - それ以外の列では、フォルダ・zip ファイル・メディアファイルを区別せず、選択した列の順に混ぜて並べる。
  - フォルダの「作成日」はファイルシステムの作成日時、「種類」は「フォルダ」とする
- **A-149**: 一時プレビューの表示と、起点・終点の拡大縮小のアニメーションは、macOS の Quick Look
  の標準パネルの機能で実現した。
  - 起点からの拡大・縮小は実機で確認した（TAK-18、2026-11-02）
