# プレビュー

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md` から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

### プレビュー

- **FR-028**: システムは、画像を表示するとき、既定で縦横比を保ったままプレビューペイン内に収まる最大サイズで表示しなければならない。ここでプレビューペインの画像描画領域を「ビューポート」と呼び、余白は設けず描画領域全体を基準にする。ペインより小さい画像も、ビューポートからはみ出さない範囲で最も大きくなるよう拡大しなければならない。フィット表示の拡大率の上限は設けず、原寸を超える拡大を許容する。画像は切り取らず、ビューポートの中央に配置する。このフィット表示を倍率100%とし、ユーザーは FR-133 の操作で25%刻みに拡大・縮小できる。はみ出した部分は FR-158 の操作で表示できる。動画にはこの拡大規則を適用しない（動画の表示サイズ規則は本要件の対象外とする）。
- **FR-029**: プレビューのレイアウトは、ペインやウィンドウのサイズ変更、フルスクリーンへの切り替えに追従して再計算されなければならない。
  フィット表示（100%）では画像を新しいビューポートに収まる最大サイズで再計算し、拡大・縮小した表示では新しいビューポートに対するフィットを100%として、
  現在の倍率（FR-133）を適用して再計算する
- **FR-030**: システムは、アニメーション GIF をアニメーションとして再生しなければならない。アニメーション
  WebP は、OS 標準の仕組みで再生できる場合のみアニメーションとして再生し、できない場合は先頭フレームを
  静止画として表示する（独自のアニメーション再生処理は作らない）
- **FR-031**: システムは、動画を選択したとき既定で自動再生・ループ再生しなければならない
- **FR-032**: ユーザーは、設定で「自動再生」と「ループ再生」をそれぞれ独立にオフにできなければならない
- **FR-033**: 動画プレビューは、再生/一時停止・シーク・音量調整をマウスとキーボード（Space で再生/一時停止 等。Space の条件は FR-248）で
  操作できなければならない。フルスクリーン表示中は矢印キーをファイル移動（FR-046）に割り当てるため、
  シークは `<` キーで戻る・`>` キーで進む操作と、画面上のコントロールで行えるようにする
- **FR-248**: 動画の再生／一時停止のキーボード操作（Space）は、プレビューの動画にフォーカスがあるときに限る。
  ファイルリストにフォーカスがあるときの Space は FR-247（file-list.md）に従い、動画の行でも再生／一時停止を切り替えない
- **FR-034**: 別のファイルを選択したとき、システムは再生中の動画を停止しなければならない
- **FR-038**: 表示できないファイル（破損・非対応のエンコード等）を選択した場合、システムはクラッシュせず、
  プレビューにファイル名と表示できない旨を示さなければならない。通常の画像ファイルにはファイルサイズの上限を設けず、
  表示サイズにダウンサンプリングしてデコードする。zip の中の画像は、展開後のサイズが 512MB を超える場合に
  表示できないものとし、どちらも同じ表示で通知する
- **FR-230**: 同じパスのまま内容が置き換わったファイル（FR-228（file-list.md））を置き換えの後に選択したとき、システムは、置き換え前の
  内容から作った縮小画像・プレビューの画像を表示してはならない。置き換えの前に始めた読み込みの結果も、置き換え後に表示・再利用しては
  ならない（EC-161）

### フルスクリーン

- **FR-035**: ユーザーは、プレビューに画像または動画を表示しているとき、メディア表示区画のダブルクリックでフルスクリーン表示に切り替え、
  フルスクリーン中は画面のどこをダブルクリックしても解除できなければならない。反応する領域と除外する部品は FR-220 に従う。
  対象は静止画・アニメーション画像・動画とし、解除後の表示は FR-094（window-layout.md）、スライドショー実行中は FR-122 に従う
- **FR-220**: ダブルクリックに反応する領域は次のとおりとする。（1）3ペイン表示とプレビューのみ表示では、メディアの周りの余白を含むプレビュー領域全体を
  メディア表示区画とする。プレビューが空のとき（EC-149）は反応しない。（2）フルスクリーン中は、メディアの周りの余白を含む画面全体とする。
  （1）（2）とも、動画の再生コントロールと画像のスクロールバー（FR-158）の上は除く（EC-150）
- **FR-221**: ダブルクリックによる全画面の切り替えは、その1回目のクリックで動画の再生状態・再生位置・音量、画像の倍率と表示位置を変えてはならない（EC-152）。
  切り替えの前後で、動画の再生位置と再生状態を維持する（FR-037）
- **FR-036**: フルスクリーンは、キーボードショートカットでも切り替えでき、Esc キーでも解除できなければならない。
  スライドショー実行中の Esc は FR-123 に従い、スライドショー終了と全画面解除を同時に行う
- **FR-037**: フルスクリーンの切替時、動画の再生位置と再生状態を維持しなければならない
- **FR-046**: フルスクリーン表示中、ユーザーは矢印キーでファイルリスト内の選択を移動できなければならない。
  移動規則はファイルリストと完全に同じとし、リスト形式では上下キーのみ、サムネイル形式では上下左右キーを
  用いる。移動に伴い、プレビューは新しく選択されたファイルに更新されなければならない。移動後の選択は
  ファイルリストにも反映され、フルスクリーンを解除したときは移動後のファイルが選択・プレビューされた状態に
  なる。解除時にその項目がビューポート外または一部しか見えない場合は、FR-017 と同じ必要最小限のスクロールで
  見える位置に合わせる。先頭または末尾に達した状態でさらに同じ方向へ移動しようとした場合は、選択を
  移動せず端で停止する（反対端へ循環しない）。この移動は画像・動画の両方のフルスクリーンに適用し、
  再生中の動画から別のファイルへ移動した場合は FR-034 に従って動画の再生を停止する。ただし、移動先がフォルダ（FR-076）・
  zip ファイル・zip の中のディレクトリ・`..` の行の場合は、そこで止まらず、同じ方向への移動を同じ規則で繰り返して最初に
  見つかったメディアファイルへ移る。その方向にメディアファイルが見つからなければ、選択を移動せず端で停止する

### スライドショー

- **FR-115**: 対象は現在のファイルリストの表示内容全体のうち対応メディアだけとし、スクロールで画面外の項目も含めなければならない。
  現在の並べ替えと種類フィルタを反映し、リストでは上から下、サムネイルでは左上から右へ、行末から次行の左へ進む表示順を用いる。
  フォルダ・zip ファイルそのもの・zip 内ディレクトリ・`..` は除外し、中へ入らない。通常フォルダ、zip 内の現在階層、検索結果のいずれにも
  適用する。メディアの識別には通常ファイルの完全な場所、zip 内では zip ファイルの場所と内部パスの組を用い、名前や表示上の行番号だけでは
  識別しない。同名でも別の場所なら別の対象として扱う
- **FR-116**: 開始位置は選択中のフォーカス行が対象メディアならそのファイル、それ以外では選択中の対象メディアの表示順先頭とし、
  対象メディア未選択なら一覧の最初の対象としなければならない。開始時はその1件だけを選択・フォーカスして表示する。この規則は通常の
  プレビューのみ表示への切り替えに伴う非メディア行からの補完規則（FR-093（window-layout.md））より優先する
- **FR-117**: 開始するとツリーとファイルリストを隠してプレビューのみ表示にし、フォーカスをプレビューへ移さなければならない。
  開始前のペイン表示・フォーカス先・3ペインの幅を復帰用に保持し、すでに全画面なら全画面化前の通常ウィンドウの状態を復帰先とする。
  フォルダ、zip 内の階層、検索結果、並べ替え、フィルタ、ツリーの状態は開始で変更しない
- **FR-118**: 自動送りは設定した切り替え間隔（FR-127・FR-128、既定3秒）とし、開始時の選択・プレビュー切り替えを起点として
  切り替え間隔の後に次の対象へ進み、以後各切り替えの開始を起点として繰り返さなければならない。デコード完了、動画の再生開始・終了、
  切り替え効果（FR-130）の完了を待って間隔を延長しない。繰り返しがオンなら末尾の次は最初の対象へ戻り、ユーザーが終了するまで続ける。
  繰り返しがオフなら FR-129 に従って末尾で終了する。ただし FR-125・FR-126 の継続不能・閲覧先変更時を除く。実行中にシート・
  アプリモーダルや編集欄が入力を受けても自動送りは継続し、その開閉・編集開始終了・そこで処理されたキーでは期限を変更しない。
  処理が遅れた場合は FR-124 に従い最大1回だけ送る。対象が1件なら EC-66 に従う。切り替えるたびに隠れたリストの選択・フォーカスも
  表示した1件に同期する
- **FR-119**: 動画も静止画・アニメーション画像と同じ切り替え間隔の送り対象としなければならない。自動再生とループは既存の設定
  （FR-031・FR-032）に従い、切り替え間隔より短い動画の終端で早送りせず、長い動画の終端まで待たない。開始位置がすでに表示中の
  同じ動画なら再生位置と再生／一時停止の状態を保ち、開始操作から切り替え間隔を数える。別のメディアを経て戻る動画は、新たな選択として
  先頭から既存の設定に従って表示する。ファイルリストのみ表示からの開始は FR-088（window-layout.md）に従い、隠していたプレビューを
  通常の選択と同じく表示する。対象1件の維持は EC-66 に従う。ユーザーによる動画の一時停止・シーク・音量変更（FR-033）は送りの
  待ち時間に影響しない。別のメディアへの切り替えでは FR-034 に従って以前の動画と音声を止める。スライドショーの繰り返し（FR-129）は
  動画のループ再生の設定（FR-032）とは独立とする
- **FR-120**: 実行中に FR-123 の入力受理条件を満たす修飾キーなしの矢印キーで、隠れたファイルリストを基準にメディアを選び直せなければ
  ならない。方向、非メディアの読み飛ばし、手動移動時に端で止まる規則、動画でのシークとの区別は FR-093（window-layout.md）・
  FR-046 に従う。サムネイルの縦移動は隠す直前の列数を保ち、プレビューや全画面の幅で列数を取り直さない。非表示中に形式・サイズを
  変えた場合は隠す直前のリスト幅と新しい設定による列数を基準にする。手動移動でスライドショーを終了してはならない
- **FR-121**: 実行中に FR-123 の入力受理条件を満たす修飾キーなしの矢印キーを押すたび（押し続けによる反復を含む）、予定されていた
  自動送りを取り消し、最後の押下から切り替え間隔が経つまで止めなければならない。切り替え間隔の間押下がなければ、その時点の選択中
  メディアの次へ1回進み（繰り返しがオフで選択中のメディアが末尾なら FR-129 に従って終了し）、以後切り替え間隔の周期を再開する。
  端で移動できない押下やリスト形式の左右キーも待ち時間を取り直す。自動送りと押下が重なれば手動操作を優先し、二重に進めない
- **FR-122**: 実行中も既存のフルスクリーン切り替え手段（FR-035・FR-036）を使えなければならない。Esc 以外で全画面を切り替えても
  実行状態、選択、動画の再生位置と再生状態、次の送りまでの残り時間を保つ。全画面を解除してもスライドショーは続け、
  プレビューのみ表示を維持する
- **FR-123**: Esc・矢印をスライドショー入力として受理するのは、実行中の対象ウィンドウがキー入力先であり、対象ウィンドウにシートがなく、
  アプリモーダルがなく、編集欄が入力を受けていない場合だけとする。メニュー等がキーを処理する間も横取りしない。この条件を満たさない
  キーは既存の入力先へ渡し、スライドショーの終了・手動移動・期限変更を行わない。モーダルや編集を終えるキーを同じ入力のまま
  スライドショーへ再適用しない。受理した Esc は全画面解除・検索解除・自動送りよりスライドショー終了を優先し、自動送りと待機中の
  再開を取り消さなければならない。全画面中なら1回の Esc で同時に全画面も解除する。開始前のペイン表示・フォーカス先と幅へ戻す。
  ただし実行中にウィンドウを狭めた場合は、開始前のウィンドウの大きさへ戻さず、FR-002・FR-088（window-layout.md）と
  contracts/keyboard-and-menus.md の復帰規則に従い、プレビュー・ファイルリスト・ツリーの順に最小幅まで詰めて収め、各ペインの
  最小幅を守る。その時点で選択・表示対象に残っている最後のメディアだけは選択を保ち、リストが見える場合は FR-093
  （window-layout.md）と同じ必要最小限のスクロールで可視にする。選択が消去済みなら空のプレビューを保ち、表示復帰による
  FR-093 の選択補完を行わず、開始前の選択も復元しない。同じ Esc を検索解除などへ重ねて適用しない。終了したことだけを理由に
  最後の動画を停止せず、復帰先がファイルリストのみなら FR-088 に従って停止・消音する
- **FR-124**: 表示不能な対象は FR-038 の表示で通知し、自動送りを止めず通常の次の予定時刻に次へ進まなければならない。
  読み込みが遅れても操作を受け付け、以前の読み込み結果による上書きや、遅延分をまとめた連続送りを起こさない
- **FR-125**: 実行中の表示形式・種類フィルタ・並べ替え・一覧更新を反映し、各自動送りではその時点の表示対象と順序を用いなければ
  ならない。FR-115 の識別によりフォーカスが対象に残ればその次へ進み、なければ最初の対象へ進む。これらの変更自体では予定時刻を
  変えない。選択解除・プレビュー消去は既存の規則（FR-059（file-list.md）・EC-13（overview.md）・FR-087（search.md））を保ち、
  対象が0件になれば自動終了して FR-123 と同じ表示復帰を行う。名前や場所の変更で既存の一覧が選択を維持する場合はその対象へ追従し、
  FR-104（directory-tree.md）・FR-105（search.md）による場所の更新だけを FR-126 の別の閲覧先への置き換えとはみなさない
- **FR-126**: フォルダ・zip 内の階層・検索結果が別の閲覧先に置き換わる場合は実行を終了し、開始前のペイン表示へ復帰してから
  新しい閲覧先を表示しなければならない。閲覧先の消失・ボリューム取り外しでも終了し、EC-26（zip.md）・EC-18（directory-tree.md）・
  EC-36（search.md）に従う移動先または空表示を保つ。表示復帰を理由に古い閲覧先・選択・プレビューを復元せず、履歴の置換・削除は
  FR-109（navigation-history.md）に従う。ウィンドウを閉じる／アプリ終了でも送りを取り消す。実行状態・待ち時間・復帰用状態は
  永続化せず、再起動後に自動再開しない
- **FR-127**: 設定ウインドウ（⌘,）に「スライドショー」の区分を追加し、次の3項目を置かなければならない。（1）切り替え間隔の
  テキストフィールドと単位「秒」の表示、（2）「最後まで表示したら先頭から繰り返す」チェックボックス、（3）切り替え効果を「なし」
  「クロスフェード」「スライド」「ズーム」の4つから1つ選ぶポップアップメニュー。区分は既存の「動画」「ファイル操作」の下に置く。
  既定値はそれぞれ 3秒・オン・「なし」とする。設定ウインドウでは Tab／⇧Tab で、既存の項目を含むすべての項目に上から順
  （動画 → ファイル操作 → 切り替え間隔 → 繰り返し → 切り替え効果）に、システムのキーボードナビゲーションの設定に関わらず
  フォーカスを移せなければならない。チェックボックスは Space で切り替え、ポップアップメニューは Space で開いて矢印キーと Return で
  選ぶ。各項目はアクセシビリティのラベル（「切り替え間隔（秒）」「最後まで表示したら先頭から繰り返す」「切り替え効果」）を
  持たなければならない
- **FR-128**: 切り替え間隔は 1 以上 3600 以下の整数（秒）だけを受け付けなければならない。値は Return、フォーカスの移動、
  設定ウインドウを閉じる操作のいずれかで確定し、確定時に前後の空白を無視し、全角数字を半角として解釈する。空欄・0 以下・小数・
  数字以外の文字を含む値・3600 を超える値は確定せず、保存値を変えずにフィールドを直前の有効値の表示へ戻さなければならない。
  このとき警告のダイアログや警告音は出さない。編集中の Esc は確定ではなく取り消しとし、保存値を変えずにフィールドを直前の有効値の
  表示へ戻す。この Esc では設定ウインドウを閉じず、スライドショーも終了しない（FR-123）
- **FR-129**: 繰り返しがオンのときは、FR-118 のとおり表示順の末尾の次に最初の対象へ戻って続けなければならない。オフのときは、
  表示順の末尾のメディアへの切り替え（末尾のメディアから開始した場合、矢印キーで末尾へ移った場合を含む）から切り替え間隔が
  経った時点で、次へ進まずにスライドショーを終了しなければならない。末尾で矢印キーを押した場合は、FR-121 のとおり最後の押下から
  切り替え間隔が経った時点で終了する。終了時の表示は、受理した Esc による終了（FR-123）と同じとする（全画面の解除、開始前の
  ペイン表示・フォーカスへの復帰、最後のメディアの選択の保持を含む）。末尾の判定は、その時点の最新の表示対象と順序（FR-125）で行う
- **FR-130**: 切り替え効果は、スライドショーの自動送りによる切り替えにだけ使わなければならない。「なし」は効果なしで即座に
  切り替える。「クロスフェード」は前の表示を薄れさせながら次のメディアを重ねて表示する。「スライド」は次のメディアを右から入れ、
  前の表示を左へ押し出す（末尾から先頭へ戻る場合も同じ向き）。「ズーム」は前の表示を薄れさせながら、次のメディアを中央から
  拡大して等倍まで表示する。「なし」以外の効果はいずれも、効果を始めてから約0.5秒で完了し、切り替え間隔の長さによらず同じ長さとする。
  効果は次のメディアの表示の準備ができた時点で始め、前の動画は静止した表示として扱う（EC-78・EC-80）
- **FR-131**: 矢印キーによる手動の選び直し（FR-120）、スライドショー開始時の最初の表示、終了時の表示復帰、スライドショー以外での
  選択の変更には切り替え効果を付けてはならない。効果の表示中も矢印キー・Esc・全画面の切り替えなどの操作を受け付け、効果を打ち切って
  その操作の結果を即座に表示しなければならない。効果の表示中も、マウスのクリック（メディア表示区画のダブルクリックによる全画面の切り替え（FR-035）を
  含む）は下のプレビューへ届かなければならず、効果の表示は VoiceOver の要素にしてはならない。macOS の「視差効果を減らす」が
  オンの間は、「スライド」と「ズーム」を「クロスフェード」に置き換えて表示しなければならない（保存した設定値は変えない）
- **FR-132**: 3項目の設定は確定した時点で保存し、次回起動時に復元しなければならない。スライドショーの実行中に変更した場合も
  実行を続け、すでに予定されている次の切り替えの時刻は変えず、切り替え間隔はその次の予定から、繰り返しは次の自動送りの判断から、
  切り替え効果は次の自動送りから新しい値を使わなければならない。矢印キーによる待機中に間隔を変えた場合は、待機の期限を変えず、
  待機後の周期から新しい値を使う

- **FR-160**: スライドショー実行中は、プレビュー領域のメディア周囲および透明部分の背景を、OS のライト・ダーク外観にかかわらず黒にしなければならない。静止画・アニメーション画像・動画、読み込み中・表示不能時および切り替え効果中も適用する。文字や操作部品は判読・操作できる状態を維持する。
- **FR-161**: スライドショーの終了または中止時は通常のプレビュー背景へ戻さなければならない。スライドショー以外のプレビューのみ表示およびフルスクリーン表示の背景は変更しない。

### 表示倍率

- **FR-133**: ユーザーは、プレビューに表示中の画像の表示倍率を、「拡大」「縮小」「表示領域に合わせる」の3操作で変えられなければならない。倍率は FR-028 のフィット表示を100%とし、拡大は現在の倍率に25ポイント（25%刻みの1段）を加え、縮小は25ポイントを引く。取り得る倍率は25%以上800%以下の25%の倍数とし、上限・下限ではそれ以上変化させない。「表示領域に合わせる」は、その時点のビューポートに対するフィット表示（100%）に戻す。画像は縦横比を保ち、収まる方向は中央に配置する。はみ出す方向の位置は FR-158・FR-159 に従う。動画、表示する画像がない状態、表示できない画像（FR-038）には適用しない。
- **FR-135**: 「表示」メニューの「フルスクリーン」の下に区切り線を置き、「拡大」「縮小」「表示領域に合わせる」
  をこの順で追加しなければならない。ショートカットは「拡大」が ⌘+、「縮小」が ⌘-、「表示領域に合わせる」が ⌘0 とする。
  拡大は ⇧ を含む ⌘+ と Shift なしの ⌘= のどちらでも受け付け、メニューとツールチップの表示は ⌘+ のままとする。
  ⌘+ / ⌘- は FR-014（file-list.md）のサムネイルサイズ変更と衝突するため、
  既存の「サムネイルを拡大・縮小」のショートカットを ⌃⌘. / ⌃⌘, に移す。この移行は contracts/keyboard-and-menus.md
  のファイルリストの行だけでなく、プレビューのみ表示・zip の中・検索結果のキー一覧、ツールバーのサイズのスライダー、
  メニューバーの「サムネイルを拡大・縮小」の表示、および navigation-history.md の FR-107（3）
  と US8-AS7 の参照にも適用する。プレビューのみ表示では、画像を表示していれば ⌘+ / ⌘- がプレビューの倍率を変え、
  ⌃⌘. / ⌃⌘, が隠れたファイルリストのサムネイルサイズを変える。⌘+ / ⌘- / ⌘0 がプレビューの倍率を変えるのは FR-136
  の条件を満たすときだけとし、満たさないときは何もしない。3項目の有効・無効は FR-136 に従う。
  ツールバーが非表示のときとフルスクリーン中も、メニューとショートカットで操作できなければならない
- **FR-136**: 拡大・縮小・表示領域に合わせるを使えるのは、プレビューが表示され（3ペイン表示・プレビューのみ表示・フルスクリーン）、
  かつ画像を表示しているときだけとする。ファイルリストのみ表示、動画、画像のない空のプレビュー、
  表示できない画像では使えず、ツールバーの3ボタンと表示メニューの3項目を無効にし、ショートカットは何もしない。
  スライドショー実行中も画像を表示していれば使える。拡大は800%で、縮小は25%で無効にする。
  シート・モーダル・名前の変更中・設定ウインドウがキーのときも、この条件だけを適用し、追加の制限を設けない
- **FR-137**: 表示倍率は保存せず、履歴の表示の状態（FR-108（navigation-history.md））
  にも含めない。倍率を変えた操作は履歴の1件としても記録せず、FR-107（navigation-history.md）の記録対象に加えない。
  表示する画像が別の画像に切り替わったとき（ファイルリストの選択変更、プレビューのみ表示中とフルスクリーン中の矢印キーによる移動、
  スライドショーの自動送りと手動移動を含む）と、履歴の移動（同じ画像に戻る場合を含む）は100%に戻さなければならない。
  フルスクリーンの切り替え、ウィンドウ・ペインのサイズ変更、ツールバーの表示切り替え、同じ画像を表示したままのペイン表示の復帰では、
  現在の倍率を保つ。サイズ変更時は新しいビューポートに対するフィットを再計算し、その100%に現在の倍率を適用する。
  起動時と、画像を表示していない状態から次に画像を表示するときは100%から始める
- **FR-138**: プレビューは、表示中の画像の現在の倍率をアクセシビリティの値として公開し、
  倍率が変わったときに新しい倍率（パーセント）を読み上げ可能な形で通知しなければならない。値と読み上げは地域の割合の書式に従う（FR-151）。可視の数値表示とスライダーは追加しない（A-64）。
  倍率を変更できない状態（FR-136 の条件を満たさないとき）は倍率を公開せず、拡大・縮小・表示領域に合わせるを無効として読み上げる

- **FR-158**: 表示中の画像がビューポートを超える各方向に対応するスクロールバーを表示し、マウスのバー操作とマウスホイールまたはトラックパッドのスクロールで、その方向の両端まで表示位置を移動できなければならない。収まる方向にはバーを表示せず、移動させない。スクロールバーが描画領域の寸法やフィット倍率を変えない。プレビューにフォーカス中は ⌥↑・⌥↓・⌥←・⌥→ でも対応する方向へ移動できる。バーはアクセシビリティから識別・操作可能とする。動画・画像なし・読み込み中・表示不能時は画像用バーを表示せず、操作は何もしない。
- **FR-159**: 表示位置は画像の中心から始める。倍率変更、ウィンドウ・ペインのサイズ変更、フルスクリーン切替、同じ画像を表示したままのペイン表示切替では、変更前のビューポート中心にある画像上の相対位置を可能な限り中心に保ち、画像端を超える場合は端に収める。収まる方向は中央とする。別画像への変更または履歴移動では FR-137 に従い倍率と位置をリセットし、フィット操作でも位置を中央に戻す。位置は保存せず履歴にも記録しない。スクロール・倍率変更はアニメーション再生を再開しない。

## 主なエンティティ

- **対象列**: 現在の一覧に表示対象となるメディアを一覧の順に並べたもの。選択した項目だけに限定せず、閲覧先・フィルタ・並べ替え・
  一覧更新に従う。対象の識別は FR-115 の場所を基準とし、表示順の位置とは分ける
- **実行状態**: 実行有無、現在のメディア、次の送り予定時刻、矢印キーによる待機状態。間隔は固定の3秒ではなく、スライドショーの設定から
  取る。全画面状態とは独立して継続し、保存しない（FR-126）
- **復帰用表示状態**: 開始前の通常ウィンドウのペイン表示・フォーカス先・幅と、手動移動の基準となるリストの幅・列数。終了時に表示を
  戻すための一時的な状態
- **表示倍率**: プレビューに表示中の画像の倍率。フィット表示を100%とし、25%以上800%以下の25%の倍数を取る。
  画像ごとではなく、表示中のプレビューに対する一時的な状態で、別の画像に切り替わったときと履歴の移動後は100%に戻る。
  保存せず、履歴の表示の状態にも含めず、倍率の変更は履歴の1件としても記録しない（FR-137）

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS3**: **Given** リストでファイルを選択した, **When** プレビューを見る, **Then** 画像全体が縦横比を
  保ったままプレビューペイン内の最大サイズで表示され、ペインより小さい画像はペインから
  はみ出さない範囲で拡大される
- **US1-AS5**: **Given** アニメーション GIF を選択した, **When** プレビューを見る, **Then** アニメーションが
  再生される
- **US1-AS6**: **Given** アニメーション WebP を選択した, **When** プレビューを見る, **Then** OS 標準の仕組みで
  再生できる場合はアニメーションが再生され、できない場合は先頭フレームが静止画として表示される

### US2 動画をプレビューで再生する（P2）

- **US2-AS1**: **Given** デフォルト設定, **When** 動画ファイルを選択する, **Then** 操作なしで再生が始まり、
  終端に達すると先頭から繰り返し再生される
- **US2-AS2**: **Given** 「自動再生」をオフにした, **When** 動画ファイルを選択する, **Then** 先頭フレームで停止した
  状態で表示され、ユーザーが再生操作するまで再生されない
- **US2-AS3**: **Given** 「ループ再生」をオフにした, **When** 動画が終端に達する, **Then** 再生は終端で停止する
- **US2-AS4**: **Given** 動画を再生中, **When** 別のファイルを選択する, **Then** 前の動画の再生（音声を含む）は
  停止する
- **US2-AS5**: **Given** 動画を表示中, **When** 再生/一時停止・シーク・音量の操作をする, **Then** それぞれ
  マウスとキーボードの両方で操作できる

### US5 プレビューをフルスクリーンで見る（P3）

- **US5-AS1**: **Given** プレビューに画像を表示中, **When** プレビューをダブルクリックする, **Then** 画像が
  画面全体に収まる最大サイズまで縦横比を保って全画面表示され、画面より小さい画像は拡大される
- **US5-AS2**: **Given** 画像をフルスクリーン表示中, **When** 画像をダブルクリックする, **Then** 元の3ペイン表示に戻り、
  ペイン幅はフルスクリーン前と同じで、矢印キーで移動していなければ選択状態もフルスクリーン前と同じ
- **US5-AS3**: **Given** フルスクリーン表示中, **When** Esc キーを押す, **Then** フルスクリーンが解除される
- **US5-AS4**: **Given** プレビューにメディアを表示中, **When** フルスクリーン切替のキーボードショートカットを押す,
  **Then** ダブルクリックと同じく切り替わる
- **US5-AS5**: **Given** 動画を再生中, **When** フルスクリーンに切り替える／解除する, **Then** 再生位置と再生状態が
  維持される
- **US5-AS6**: **Given** フルスクリーン表示中, **When** 矢印キーで選択を移動する, **Then** プレビューが新しく選択された
  ファイルに切り替わり、解除後もそのファイルが選択・プレビューされた状態になる
- **US5-AS7**: **Given** 3ペイン表示またはプレビューのみ表示でプレビューに動画を表示中, **When** 映像の上、または映像の周りの余白をダブルクリックする,
  **Then** 全画面表示に切り替わり、動画の再生位置と再生状態（再生中・一時停止）はダブルクリックの前と同じ
- **US5-AS8**: **Given** プレビューに画像を表示中, **When** 画像の周りの余白（画像が描かれていないプレビュー領域）をダブルクリックする,
  **Then** 画像の上をダブルクリックしたとき（US5-AS1）と同じく全画面表示に切り替わる
- **US5-AS9**: **Given** プレビューに動画を表示中, **When** 再生コントロール（再生ボタン・シークバー・音量）の上をダブルクリックする,
  **Then** 全画面は切り替わらず、従来どおりそのコントロールの操作だけが行われる
- **US5-AS10**: **Given** 画像または動画を全画面表示中, **When** メディアの上、メディアの周りの余白、画面の隅のいずれかをダブルクリックする,
  **Then** 全画面が解除され、全画面前のペイン表示・ペイン幅・フォーカスのあったペインに戻る（FR-094（window-layout.md））。
  動画の再生位置と再生状態は維持される（FR-037）
- **US5-AS11**: **Given** 全画面表示中に矢印キーで別のメディアへ移動した, **When** 画面のどこかをダブルクリックする,
  **Then** 全画面が解除され、移動後のファイルが選択・プレビューされた状態になる（FR-046）
- **US5-AS12**: **Given** スライドショーを全画面で実行中, **When** 画面のどこかをダブルクリックする,
  **Then** FR-122 のとおりスライドショーを続けたまま全画面を解除し、プレビューのみ表示で継続する。画像と動画のどちらを表示中でも同じ

### US9 表示中のメディアを順番に鑑賞する（P1）

- **US9-AS1**: **Given** メディアを含む一覧で1件を選択中, **When** ツールバーの「スライドショーを開始」を押す, **Then** 選択した
  メディアから始まり、ツリーとファイルリストが隠れ、プレビューへフォーカスが移る。3秒ごとに表示順の次のメディアへ進む
- **US9-AS2**: **Given** ツールバー非表示でメディアを含む一覧がある, **When** ⇧⌘S または「表示 > スライドショーを開始」を実行する,
  **Then** ツールバーと同じ条件・開始位置・間隔で開始する。3ペイン・ファイルリストのみ・プレビューのみのいずれの表示からも開始できる
- **US9-AS3**: **Given** メディア未選択、またはフォルダ・zip・`..` のみを選択中, **When** 開始する, **Then** 非メディアの選択位置に
  よらず、表示順で最初のメディアから開始する。複数選択ではフォーカス中のメディアを優先し、それがなければ選択中のメディアのうち
  表示順で最初のものから開始する
- **US9-AS4**: **Given** zip・フォルダ・`..` を挟んだ一覧を降順または種類フィルタ付きで表示中, **When** 2周分の自動送りを行う,
  **Then** 画面外も含む表示対象のメディアだけを表示順で辿り、末尾の次は最初のメディアになる。フォルダや zip を開かず、
  フィルタで隠れたメディアは表示しない
- **US9-AS5**: **Given** メディアを含む zip 内の階層を表示中, **When** 開始する, **Then** その階層の表示対象メディアだけを通常の
  フォルダと同じように順送りする。zip 内のディレクトリや `..` では止まらず、別階層へ移らない
- **US9-AS6**: **Given** メディアが0件の一覧（種類フィルタで0件、zip・フォルダ・`..` しかない場合を含む）, **When** 開始手段を確認し
  ⇧⌘S を押す, **Then** ボタンとメニューは無効で、ショートカットでも開始せず、表示状態・選択は変わらない
- **US9-AS7**: **Given** 1秒の動画と10秒の動画を含む一覧、動画設定は既定, **When** 各動画へ自動送りする, **Then** どちらも自動再生し、
  短い動画はループし、どちらも選択から3秒後に次へ進む。切り替えた動画の音声は残らない。自動再生／ループをオフにした場合も、
  それぞれの設定を守って3秒後に次へ進む
- **US9-AS8**: **Given** メディアを表示中のスライドショー, **When** Esc を押して6秒以上待つ, **Then** 自動送りが再発しない。
  開始前のペイン表示とフォーカスへ戻り、最後のメディアの選択を保ち、リストが見える場合は必要最小限スクロールする
- **US9-AS9**: **Given** 検索結果を表示中（検索中も含む）でメディアが1件以上ある, **When** 開始して新しい結果が追加され、
  表示形式や種類フィルタを変更した後 Esc を押す, **Then** 現在の結果の表示順に従って続行し、終了時は検索結果を保つ。
  同じ Esc で検索解除は起きない。表示変更による履歴は増えず、後で検索を解除した時点の表示を FR-113（navigation-history.md）
  どおり現在の履歴へ反映し、一時的なペイン表示と実行状態は含めない
- **US9-AS10**: **Given** 名前の編集中、モーダル表示中、またはスライドショー実行中, **When** 開始操作を試す, **Then** 開始手段は無効で、
  重複実行や選択・送り予定時刻の変更は起こらない
- **US9-AS11**: **Given** 通常フォルダまたは zip 内で戻る側の履歴がある状態から開始した, **When** ペイン表示切り替えと戻る・進むを
  試し、続けて表示形式や種類フィルタを変えてから終了する, **Then** 実行中のペイン切り替えと履歴移動は無効となる。ユーザーの表示変更
  だけが履歴に残り、後で戻る・進むを行っても一時的なペイン表示やスライドショーは再現されない
- **US9-AS12**: **Given** メディアが複数あるスライドショー, **When** フィルタ変更・外部削除・追加・名前変更で対象列が変わる,
  **Then** 予定時刻を保って最新の表示順から次を選び、現在の対象が消えた場合は既存の規則でプレビューを更新・消去する。
  対象0件なら終了して表示復帰する。閲覧先の置き換えやウィンドウを閉じる操作でも終了し、次回起動で自動再開しない
- **US9-AS13**: **Given** 選択中のメディアが削除またはフィルタで非表示になり、ほかの対象は残っている, **When** 次の自動送り
  予定時刻より前に Esc を押す, **Then** 終了後も選択なし・プレビューは空のままで、開始前の選択や先頭メディアを自動選択しない。
  Esc を押さなければ次の予定時刻に最初の対象を選ぶ。zip 自体の外部変更では EC-26（zip.md）どおり親フォルダへ戻ってプレビューを
  空にし、ボリューム取り外しでは EC-18（directory-tree.md）どおり空表示にして終了する
- **US9-AS14**: **Given** 別フォルダに同名の画像がある検索結果で一方を選択してスライドショー中, **When** 結果の追加や並べ替えで
  行番号が変わる, **Then** 完全な場所で現在のメディアを特定し、新しい表示順でその次へ進む。同名のもう一方を同じメディアとみなして
  飛ばしたり、古い行番号の項目を現在のメディアとみなしたりしない
- **US9-AS15**: **Given** 動画を途中まで再生または一時停止したプレビューが見えている, **When** その動画を開始位置として
  スライドショーを開始する, **Then** 再生位置と再生／一時停止の状態は変わらず、開始から3秒後に次へ進む。別のメディアを経て
  同じ動画へ戻ると先頭から自動再生設定に従い表示する。対象が1件なら EC-66 のとおり再生し直さない。ファイルリストのみ表示から
  開始した場合は FR-088（window-layout.md）どおり通常の選択と同じく表示する
- **US9-AS16**: **Given** 複数メディアのスライドショー実行中に対象ウィンドウのシートまたはアプリモーダルが表示された,
  **When** 3秒を超えて待ち、モーダルに Esc を入力する, **Then** 表示中も元の期限で自動送りを続け、Esc はモーダルの既存の取消だけに
  使う。同じ Esc でスライドショー終了・全画面解除・検索解除を行わず、閉じる操作でも期限を取り直さない。モーダルがなく編集欄も
  入力を受けていない対象ウィンドウへ、改めて Esc を入力すると終了する。編集欄への Esc も編集の既存処理だけに使い、送りの期限は変わらない

### US10 矢印キーで見たいメディアへ割り込む（P1）

- **US10-AS1**: **Given** リスト形式を基準とするスライドショー, **When** ↑／↓ を押す, **Then** 隠れたリストの前／次のメディアを
  選択して表示し、非メディアは飛ばす。←／→ では選択を動かさない。どの場合もスライドショーは終了しない
- **US10-AS2**: **Given** サムネイル形式を基準とするスライドショー, **When** 上下左右キーを押す, **Then** 隠す直前のリストの
  列数を基準として既存の移動規則で選択を動かす。非メディアを飛ばし、端では反対端へ循環せず止まる
- **US10-AS3**: **Given** 自動送りの直前に手動で B を選び、その2秒後に C を選んだ, **When** その後キーを押さずに待つ,
  **Then** B・C の操作中に自動送りは入らず、C を選ぶ最後のキー押下から3秒後に C の次へ1回進み、以後3秒周期で続く
- **US10-AS4**: **Given** 末尾のメディアを表示中, **When** 端を越える矢印キーを押す、または押し続けて反復入力する,
  **Then** 手動選択は端で止まるが押下・反復ごとに待ち時間を取り直し、最後の押下から3秒後に自動送りで先頭へ進む。
  リスト形式の ←／→ も待ち時間を取り直す
- **US10-AS5**: **Given** 自動送り予定時刻と矢印キー押下が重なる, **When** 操作が受け付けられる, **Then** 手動操作を優先し、
  自動送りによる二重移動は起きず、最後の押下から3秒後まで自動送りを行わない
- **US10-AS6**: **Given** 実行中にシート・アプリモーダルまたは編集欄が入力を受けている, **When** 矢印を入力する, **Then** 既存の
  モーダル／編集の操作だけに使い、スライドショーの手動移動や期限の再設定は起こらない。自動送りは元の期限で続く。入力先が
  対象ウィンドウに戻り FR-123 の受理条件を満たした後の矢印からは、通常どおり手動移動と3秒待機を行う。別ウィンドウへの Esc・矢印でも
  実行中の選択・期限を変更しない

### US11 全画面でも鑑賞と手動操作を続ける（P2）

- **US11-AS1**: **Given** スライドショー実行中, **When** ⌃⌘F、画像のダブルクリック、または既存の全画面メニューで全画面化／解除する,
  **Then** 実行を続け、解除後もプレビューのみ表示になる。選択・動画の再生位置と再生状態・次の送りまでの残り時間を保つ
- **US11-AS2**: **Given** 全画面のスライドショー, **When** 矢印キーを連続して押してから待つ, **Then** 通常ウィンドウと同じく割り込めて、
  最後の押下から3秒後に選択中の次へ進む
- **US11-AS3**: **Given** FR-123 の入力受理条件を満たす全画面のスライドショー, **When** Esc を1回押す, **Then** 終了と同時に
  全画面を解除し、開始前の通常ウィンドウのペイン表示とフォーカスへ戻る。開始時点ですでに全画面だった場合も、全画面化前の
  ペイン表示へ戻る
- **US11-AS4**: **Given** 3ペイン表示から開始し、開始前のペイン幅の合計が収まらない幅まで通常ウィンドウを狭めた, **When** Esc で終了する,
  **Then** ウィンドウの大きさは開始前へ戻さず、プレビュー・ファイルリスト・ツリーの順に最小幅まで詰めて3ペインへ復帰する。
  各ペインの最小幅を守り、開始前のフォーカス先へ戻り、有効な選択がある場合は必要最小限のスクロールで可視にする

### US12 切り替え間隔と繰り返しを好みに合わせる（P1）

- **US12-AS1**: **Given** 初めて起動したアプリ, **When** 設定ウインドウ（⌘,）を開く, **Then** 「スライドショー」の区分に、
  切り替え間隔のテキストフィールド（値 `3`、単位「秒」）、「最後まで表示したら先頭から繰り返す」チェックボックス（オン）、

- **US12-AS2**: **Given** 切り替え間隔を `10` にして確定した, **When** メディアが複数ある一覧でスライドショーを開始する,
  **Then** 開始から10秒ごとに次のメディアへ進む。矢印キーで割り込んだ場合も、最後の押下から10秒後に次へ進む
- **US12-AS3**: **Given** 切り替え間隔が `5`, **When** フィールドへ `0`・`-1`・`2.5`・`abc`・`3601`、または空欄を入力して確定する,
  **Then** どの場合も値は確定されず、フィールドは直前の有効値 `5` に戻る。スライドショーの間隔も5秒のまま変わらない
- **US12-AS4**: **Given** 切り替え間隔のフィールドに `１５`（全角）や ` 15 `（前後に空白）を入力した, **When** 確定する,

- **US12-AS5**: **Given** 繰り返しがオフで、5件のメディアのうち3件目を選択している, **When** スライドショーを開始して待つ,
  **Then** 3件目・4件目・5件目を表示し、5件目の表示から設定した間隔が経つと先頭へ戻らずにスライドショーを終了する。
  終了後の表示は Esc で終了した場合（FR-123）と同じで、5件目の選択を保つ
- **US12-AS6**: **Given** 繰り返しがオンの状態でスライドショーを実行中, **When** 末尾のメディアから設定した間隔が経つ,
  **Then** 先頭のメディアへ戻って続ける
- **US12-AS7**: **Given** 繰り返しがオフで、末尾のメディアを表示中のスライドショー, **When** ↑ で1件前へ戻り、設定した間隔だけ待つ,
  **Then** 末尾のメディアへ進み、そこからさらに設定した間隔が経つと終了する
- **US12-AS8**: **Given** 切り替え間隔・繰り返し・切り替え効果をそれぞれ既定値から変えた, **When** アプリを終了して起動し直す,
  **Then** 設定ウインドウとスライドショーの振る舞いに、変えた値がそのまま使われる
- **US12-AS9**: **Given** 間隔5秒でスライドショーを実行中に設定ウインドウを開いた, **When** 間隔を `2` に変えて確定する,
  **Then** すでに予定されていた次の切り替えは元の時刻のまま行い、その次からは2秒ごとに進む。スライドショーは終了しない

### US13 切り替え効果を選ぶ（P2）

- **US13-AS1**: **Given** 切り替え効果が「なし」（既定）, **When** スライドショーが自動送りする, **Then** 前のメディアから
  次のメディアへ効果なしで即座に切り替わる
- **US13-AS2**: **Given** 切り替え効果が「クロスフェード」, **When** 自動送りする, **Then** 前のメディアが薄れると同時に
  次のメディアが現れ、約0.5秒で次のメディアだけの表示になる
- **US13-AS3**: **Given** 切り替え効果が「スライド」, **When** 自動送りする（末尾から先頭へ戻る場合を含む）, **Then** 次のメディアが
  右から入り、前のメディアが左へ押し出され、約0.5秒で完了する
- **US13-AS4**: **Given** 切り替え効果が「ズーム」, **When** 自動送りする, **Then** 前のメディアが薄れる間に、次のメディアが
  中央から拡大しながら現れ、約0.5秒で等倍の表示になる
- **US13-AS5**: **Given** 「なし」以外の効果でスライドショーを実行中, **When** 矢印キーでメディアを選び直す, **Then** 効果を付けずに
  即座に切り替わる。待ち時間の後の自動送りには再び選んだ効果を使う
- **US13-AS6**: **Given** 「なし」以外の効果で切り替えの途中, **When** 矢印キー・Esc・全画面の切り替えを行う, **Then** 効果の完了を
  待たずに操作を受け付ける。矢印キーでは効果を打ち切って選び直したメディアを即座に表示し、Esc では効果を打ち切って終了する（FR-123）
- **US13-AS7**: **Given** macOS の「視差効果を減らす」がオンで、効果が「スライド」または「ズーム」, **When** 自動送りする,
  **Then** 移動や拡大を伴わない「クロスフェード」で切り替える。「クロスフェード」と「なし」はそのまま使う
- **US13-AS8**: **Given** 「なし」以外の効果を選んでいる, **When** スライドショー以外の通常の操作で、ファイルリストの選択を変えて
  プレビューを切り替える, **Then** 効果は付かず、従来どおり即座に切り替わる

### US14 プレビュー画像を拡大・縮小する（P1）

  もう一度押すと150%になる
- **US14-AS2**: **Given** 表示倍率が150%, **When** ツールバーの「縮小」を押す, **Then**
  125%になる。続けて押すと100%・75%・50%・25%と下がり、25%で止まる。25%では「縮小」が無効になり、

- **US14-AS3**: **Given** 表示倍率が175%, **When** ツールバーの「表示領域に合わせる」

- **US14-AS4**: **Given** 画像をプレビューに表示中, **When** ⌘+・⌘-・⌘0 を押す, **Then**

- **US14-AS5**: **Given** 画像Aを150%で表示中, **When** ファイルリストで画像Bを選択する, **Then**

- **US14-AS7**: **Given** 100%の画像, **When** 「拡大」を28回続けて実行する, **Then**
  800%で止まり、それ以上は変わらない。800%では「拡大」が無効になる
- **US14-AS8**: **Given** フルスクリーンで画像を200%表示中, **When** フルスクリーンを解除する,
  **Then** 200%の倍率を保ち、通常ウィンドウの新しいビューポートに対するフィットを基準に表示する。
  再びフルスクリーンにしても200%を保つ
- **US14-AS9**: **Given** 画像を表示中でファイルリストがサムネイル形式, **When** ⌃⌘. / ⌃⌘,

  ⌘+ / ⌘- はプレビューの倍率だけを変える
- **US14-AS10**: **Given** スライドショーで画像を200%表示中, **When** 自動送りで次の画像へ切り替わる,

- **US14-AS11**: **Given** ツールバーを表示中, **When** 3つのボタンを見る, **Then** 左から虫眼鏡のレンズに

- **US14-AS12**: **Given** 画像を表示中, **When** ⌘= または ⇧⌘= を押す, **Then**

- **US14-AS13**: **Given** 画像を150%で表示中, **When** VoiceOver を使いながら「拡大」

### US21 拡大画像の全体を見る（P1）

- **US21-AS1**: 縦方向だけがはみ出す画像では縦スクロールバーだけを表示し、上端から下端までスクロールできる。横方向だけの場合は横について同様とする。
- **US21-AS2**: 両方向にはみ出す画像では両方のバーを表示し、スクロール操作で四隅まで到達できる。
- **US21-AS3**: プレビューにフォーカスして ⌥ と方向キーを押すと、対応方向にスクロールできる。修飾なし方向キーによる既存のファイル移動は変わらない。
- **US21-AS4**: スクロール後に倍率やビューポートを変えても、可能な限り同じ画像上の位置を中心に保つ。範囲外になる位置は端に収める。画像が収まる方向は中央に配置されバーが消える。
- **US21-AS5**: 別の画像への切り替え、履歴移動、またはフィット操作後はフィット表示で中央に戻り、スクロールバーは表示されない。
- **US21-AS6**: アニメーション画像の再生はスクロールや倍率変更で再開せず、3ペイン、プレビューのみ、フルスクリーン、スライドショー中でもスクロールできる。

### US22 スライドショーの背景を黒くする（P1）

- **US22-AS1**: **Given** ライトまたはダークの外観で画像を表示している、**When** スライドショーを開始する、**Then** メディアの周囲と透明部分の背景は黒になる。
- **US22-AS2**: **Given** スライドショー実行中、**When** 動画・アニメーション画像・別の画像に移る、または自動送りの切り替え効果が表示される、**Then** プレビュー領域の背景は黒のままである。
- **US22-AS3**: **Given** スライドショー実行中、**When** Esc や末尾到達などで終了する、**Then** 背景はスライドショー以外の通常の表示に戻る。
- **US22-AS4**: **Given** 通常のプレビューのみ表示または通常のフルスクリーン表示、**When** スライドショーを実行していない、**Then** 既存の背景表示が維持される。

## エッジケース

- **EC-03**: 破損した画像・動画ファイル、拡張子と中身が一致しないファイルを選んだ場合、アプリは落ちずに
  プレビューに「表示できません」とその理由を表示する。リストの行頭アイコンは形式別の汎用アイコンに
  フォールバックする
- **EC-11**: 非常に大きな画像（例: 1億画素級）でもアプリは応答し続け、表示できない場合はその旨を表示する。通常の画像ファイルには
  ファイルサイズの上限を設けず、表示サイズにダウンサンプリングしてデコードする。zip の中の画像は展開後のサイズが 512MB を
  超える場合に表示できないものとし、通常画像のデコード失敗と同じ表示で通知する
- **EC-12**: 極端に小さい画像（例: 16×16 や 1×1 ピクセル）を選んだ場合もクラッシュせず、縦横比を保ったまま
  プレビューペインに収まる最大サイズまで拡大して中央に表示する

- **EC-66**: 対象が1件でも開始できる。繰り返しがオンなら、同じ1件の選択・表示を維持して終了せず、切り替え間隔ごとに同じ動画を
  先頭から再生し直さない。切り替え効果も付けない。繰り返しがオフなら、開始から設定した間隔が経つと終了する（FR-129）
- **EC-67**: 破損・読み取り不可・非対応エンコード、または zip 内画像のサイズ制限で表示できない場合は FR-038 のエラー表示を出し、
  設定した切り替え間隔の後に次へ進む。全件が表示不能でもエラー表示を順送りし（繰り返しがオフなら末尾で終了する）、Esc で終了できる。
  エラー表示への切り替えとエラー表示からの切り替えにも、選んだ切り替え効果を使う
- **EC-68**: 外部削除やフィルタ変更で現在のメディアが消えた場合は既存の規則で選択とプレビューを更新・消去する。次の予定時刻には、
  その時点のフォーカス中メディアの次へ進み、フォーカスがなければ最初の対象へ進む。対象が0件になれば自動終了して開始前のペイン表示へ戻る。

- **EC-69**: 検索結果の追加、外部の追加・名前変更、表示形式・フィルタ・並べ替えの変更は最新のファイルリストに従って送り先に反映し、

- **EC-70**: 読み込み中でも表示中の一覧にメディアが1件あれば開始できる。遅れて完了した以前の読み込みで現在の表示を上書きしない。
  処理遅延から戻った際に、遅れた回数分の自動送りを連続して行わない
- **EC-71**: 開始操作を繰り返しても実行を重複させず、選択や次の予定時刻を変えない。Esc と予定時刻が重なる場合は終了を優先し、
  終了後の切り替えは起こらない
- **EC-72**: 開始前からプレビューのみ表示の場合も開始でき、終了後はその状態に戻る。ウィンドウを閉じた場合やアプリ終了でも送りは終わり、

- **EC-73**: 切り替え間隔のフィールドで、値を確定しないまま設定ウインドウを閉じた場合も、閉じる時点で確定と同じ検証を行う。
  有効な値なら保存し、不正な値なら直前の有効値を保つ
- **EC-74**: 切り替え間隔の前に `0` を付けた値（例: `007`）は数値として解釈し、`7` として受け付ける。桁区切り（`1,000`）や
  符号付き（`+5`）は不正な値として扱う
- **EC-75**: 保存されている設定が読み取れない、または範囲外の場合（切り替え間隔が 1〜3600 の整数でない、切り替え効果が4種類の
  いずれでもない、繰り返しの値が真偽値でない）は、その項目だけを既定値（3秒・「なし」・オン）として扱う
- **EC-76**: 繰り返しがオフのとき、実行中の一覧更新・並べ替え・フィルタ変更で現在のメディアが表示順の末尾になった場合は、
  次の予定時刻に終了する。末尾でなくなった場合は次のメディアへ進んで続ける。現在のメディアが消えて選択がない場合は、FR-125 のとおり
  次の予定時刻に最初の対象を選んで続ける
- **EC-77**: 繰り返しを実行中にオフへ変えた場合は、次の自動送りの判断から新しい設定を使う。末尾のメディアを表示中にオフにした場合は、
  次の予定時刻に先頭へ戻らず終了する
- **EC-78**: 動画への切り替えに効果を使う場合も、次の動画の自動再生・ループは切り替えの開始時点から既存の設定（FR-031・FR-032）に
  従う。前の動画は切り替えの開始時点で再生と音声を止め（FR-034）、そのときのフレームで静止した表示を効果に使う。効果の表示中に
  前の動画の再生や音声が続かない
- **EC-79**: 前のプレビューが空（選択が消えた後など）から次のメディアへ自動送りする場合も、選んだ効果を使う。空の状態は背景だけの

- **EC-80**: 効果の表示中にウインドウの大きさが変わった場合や、表示の準備が切り替え時刻に間に合わない場合も、切り替え間隔の起点は
  切り替えの開始時点のまま変えず、効果の完了を待って次の予定時刻を遅らせない。表示の準備が間に合わない場合は、前の表示を保ったまま
  準備の完了を待ち、準備ができた時点で効果を始める（準備を待つ時間も切り替え間隔に含める）。次の予定時刻までに準備が終わらなければ、
  その効果は行わず、FR-124 のとおり次の予定時刻に次へ進む。表示不能なファイルのエラー表示（FR-038）は、判定が済んだ時点で準備が
  できたものとして扱う。動画は、最初のフレームを表示できる時点で準備ができたものとして扱い、効果の途中に黒い（空の）表示を見せない。
  効果の表示中にウインドウの大きさが変わった場合（全画面の切り替えを含む）は、効果を打ち切って次のメディアをそのまま表示する

  効果を打ち切り、選択中のメディアを起点に選び直したメディアを即座に表示する（FR-121）。Esc では準備待ち・効果を打ち切って終了し、
  選択中のメディアの選択を保つ（FR-123・FR-129）。「なし」では従来と同じ表示の更新とする
- **EC-81**: 倍率を上げている間にウィンドウやペインの大きさが変わった場合も、新しいビューポートに対するフィットを100%として現在の倍率を適用し、縦横比と FR-159 の位置を保つ。はみ出す方向には FR-158 のスクロールを提供する。
- **EC-82**: 16×16 や 1×1 ピクセルの極端に小さい画像でも、フィットで拡大された状態を100%として25%刻みの拡大・縮小ができ、

- **EC-86**: スライドショーの切り替え効果の表示中に倍率を変えても、効果の進行・切り替え間隔・次の送り予定時刻は変わらない。

- **EC-87**: プレビューを隠す表示（ファイルリストのみ表示）にしてから戻したとき、同じ画像が表示されていれば倍率を保つ。

- **EC-88**: 履歴の戻る・進むで表示を復元したときは、同じ画像に戻る場合も100%で表示する
- **EC-89**: プレビューのみ表示で ⌘+ / ⌘- を押したとき、画像を表示していれば倍率が変わり、
  画像がない・動画・表示できない画像なら何も起きない。同じ状態で ⌃⌘. / ⌃⌘, を押すと、

- **EC-90**: 倍率を変えても履歴の件数は増えない。戻る・進むの直後に倍率を変えても新しい履歴は記録されず、

- **EC-117**: 一方向だけがはみ出す場合、収まる方向には移動できず中央に表示する。ちょうど収まる方向にはバーを出さない。位置が端にあるまま縮小やサイズ変更が起きた場合は表示可能な端に収める。

- **EC-119**: 読み込み中・表示不能時もスライドショー中のプレビュー背景は黒とし、既存の通知を判読可能にする。
- **EC-120**: 全画面中に開始・終了した場合や、閲覧先変更などで終了した場合も黒の適用と通常背景への復帰を行う（FR-123・125・126（preview.md））。
- **EC-149**: 通常表示でプレビューが空のとき（何も選択していない、フォルダ・zip ファイル・zip の中のディレクトリ・`..` の行を選択している。FR-075・FR-076（file-list.md））は、

  ダブルクリックで全画面に切り替える。全画面中はこれらの表示でも、ダブルクリックで解除する
- **EC-150**: 動画の再生コントロールと、拡大した画像のスクロールバー（FR-158）の上でのダブルクリックは、全画面の切り替えに使わない。
  通常表示でも全画面中でも同じとする。全画面中にメニューバーやツールバーが表示されている場合、それらの上のダブルクリックも切り替えに使わない
- **EC-151**: スライドショーの切り替え効果の表示中も、ダブルクリックは下のプレビューに届き（FR-131）、表示中のメディアの種類によらず全画面を切り替える。

- **EC-159**: 置き換え（FR-228（file-list.md））でファイルの種類の扱いが変わった場合（静止画をアニメーション画像で置き換えた場合など）、

- **EC-160**: 書き込みの途中で変更が通知された場合、書き込み途中の内容を一時的に表示してもよいが、書き込みが終わった後の通知で

- **EC-162**: プレビュー中の画像を拡大していた場合、FR-229（file-list.md）による読み込み直しでは、同じファイルの表示の続きとして

## 成功基準

- **SC-033**: 通常フォルダ・zip 内・検索結果の各一覧で2周分の確認を行い、表示対象・開始位置・順番・循環が受け入れシナリオと100%一致し、

  3.0秒以上3.2秒以内に1回ずつ発生する。1秒・10秒の動画でも同じ時間枠で次へ進む。読み込みによる映像表示の遅れは既存の
  SC-001・SC-010 に照らして別に確認する
- **SC-035**: 1秒間隔の矢印キー操作を10回続ける確認で操作間の自動送りが0回、最後の押下から3.0秒以上3.2秒以内に選択中の次への
  自動送りが1回となる。端での操作・キー反復・全画面でも同じ結果となる
- **SC-036**: 3種類のペイン表示の各状態から開始し全画面化・解除を3回繰り返しても、意図しない終了が0回となる。Esc 1回で終了と
  必要な全画面解除・表示復帰が完了し、6秒以上待っても自動送りが0回となる。US11-AS4 の狭めたウィンドウでの復帰でも、

- **SC-037**: ツールバー非表示で「開始 → 矢印キーの割り込み → 全画面化 → 終了」をキーボードだけで完了できる。表示不能メディアを

- **SC-038**: 切り替え間隔を 1秒・3秒・10秒に設定した各場合で、事前に表示可能な静止画を用いた連続10回の自動送りが、前の切り替えから
  設定値以上・設定値＋0.2秒以内に1回ずつ発生する。4種類の切り替え効果のどれを選んでも同じ時間枠に収まる。矢印キーの最後の押下から

- **SC-039**: US12-AS3・EC-74 に挙げた不正な値をすべて入力して確定しても、保存値とスライドショーの間隔が変わった回数が0回で、

- **SC-040**: 繰り返しがオフのとき、通常フォルダ・zip 内・検索結果の各一覧で途中のメディアから開始すると、末尾までの各メディアを
  1回ずつ表示し、末尾の表示から設定した間隔の後に終了する。先頭へ戻った回数は0回となる。繰り返しがオンのときは2周分の確認で

- **SC-071**: 3ペイン・プレビューのみ・フルスクリーンで各4方向にキーボード操作を行い、スクロール可能な方向に移動できない回数と、修飾なし方向キーの既存動作を妨げた回数は0回となる。

- **SC-072**: ライト・ダーク外観それぞれで、画像・透明画像・アニメーション画像・動画・表示不能時と各切り替え効果を確認したとき、スライドショーの背景が黒以外になる場面は0件である。
- **SC-073**: 通常ウィンドウ・通常フルスクリーンからそれぞれ開始して終了した後、通常の背景へ戻らないケースは0件である。
- **SC-108**: 3ペイン表示とプレビューのみ表示のそれぞれで、静止画・アニメーション画像・動画（再生中と一時停止中）を表示し、メディアの上と
  メディアの周りの余白を各5回ダブルクリックして全画面にする。全画面中はメディアの上・上下左右の余白・画面の四隅を各5回ダブルクリックして解除する。
  切り替わらなかった回数が0回、解除後のペイン表示・ペイン幅・フォーカスが全画面前と異なった回数が0回、動画の再生位置と再生状態が変わった回数が0回となる
- **SC-109**: 動画の再生コントロールと画像のスクロールバーの上を、通常表示と全画面中で各5回ダブルクリックし、全画面が切り替わった回数が0回となる。
  空のプレビュー（EC-149）を5回ダブルクリックし、全画面になった回数が0回となる

## 前提

- **A-47**: 開始キーは既存の contracts/keyboard-and-menus.md と衝突しない ⇧⌘S とする。ボタンは実行中に停止ボタンへ切り替えず無効にし、
  終了は Esc とする。メニューからも同じ開始操作に到達できるようにする
- **A-48**: 終了時は開始前の通常ウィンドウのペイン表示・フォーカスへ戻す。FR-123 の条件で受理した全画面中の Esc は終了と全画面解除を
  1回で行い、検索解除へ伝播させない。実行中のペイン切り替えと履歴移動は無効とし、開始・終了に伴う一時的な表示変更は履歴に残さない
- **A-49**: 切り替え間隔は選択とプレビュー切り替えの開始を起点とし、切り替え効果の完了を待たない。開始時にすでに同じ動画を表示している
  場合も、再生状態を保ったまま開始操作から切り替え間隔を数える。動画を最後まで見せるモードは追加せず、自動再生・ループ・音声は
  既存の設定を尊重する。Space 等の動画操作はスライドショーの一時停止手段にはしない
- **A-50**: 複数選択の開始位置はフォーカス中のメディアを優先し、なければ選択中のメディアの表示順先頭、それもなければ一覧の対象メディアの
  先頭とする。開始後は1件だけの選択に揃える
- **A-51**: 実行中も表示形式・サイズ・種類フィルタ・並べ替えは既存の手段で変更できる。並べ替えは既存の「表示 > 並べ替え」メニューを使い、
  スライドショー専用の新しい操作は追加しない。対象列は固定せず最新の一覧に追従し、これらの変更自体では予定時刻を変えない。
  追加・削除・選択解除は既存仕様を継承する。読み込み中の一覧・検索結果にもメディアが1件あれば開始を許可する
- **A-52**: 対象が1件なら EC-66 に従う。表示不能な項目はエラーのまま、通常の切り替え間隔の後に進む。対象0件、閲覧先の置き換え、
  ウィンドウを閉じる／アプリ終了、繰り返しがオフで末尾のメディアから切り替え間隔が経ったとき（FR-129）は、Esc 以外で実行を終える
  終了条件とする。繰り返しオフの末尾での終了は、全画面中でも受理した Esc と同じ表示復帰を行う
- **A-53**: 割り込みの対象は修飾キーなしの矢印キーとし、端やリスト形式の左右キーでも切り替え間隔を数え直す。サムネイルの移動基準は
  隠す直前の配置とする。ランダム再生、逆順専用モード、専用の一時停止、効果の長さや向きの設定、効果ごとの詳細設定は範囲外とする
- **A-54**: 006 の受け入れシナリオ（US9〜US11）と成功基準（SC-034〜SC-036）にある「3秒」は、切り替え間隔が既定値（3秒）で、
  繰り返しがオン・切り替え効果が「なし」の場合の確認として読む。US9-AS8・SC-036 の「6秒以上待っても」は、切り替え間隔の2倍以上
  待つ確認として読む。設定を変えた場合の確認は US12・US13 と SC-038〜042 で行う
- **A-55**: 「デフォルトは現在のパターン」は、効果なしで即座に切り替える「なし」を既定値とする意味に解釈する（006 の A-53 は
  トランジションを範囲外としていた）。典型的な3つの効果は、写真のスライドショーで広く使われる「クロスフェード」「スライド」「ズーム」とする
- **A-56**: 切り替え間隔の上限は 3600 秒（1時間）とする。要望は下限（1以上の整数）だけを定めているが、入力欄で極端な値を受けないための
  実用上の上限として置く。小数の秒は受け付けない
- **A-57**: 繰り返しがオフのときの終点は、開始位置によらず表示順の末尾とし、自動送りで末尾から先頭へ戻らない（途中から開始した場合、
  自動送りでは開始位置より前のメディアへ戻らない）。ただし、選択が消えて最初の対象を選ぶ場合（EC-76・FR-125）と、矢印キーによる
  選び直し（FR-121・US12-AS7）は除く。末尾の表示から切り替え間隔が経った時点で、Esc と同じ表示復帰を伴って終了する。
  最後のメディアを表示したまま止まる状態は設けない
- **A-58**: 切り替え効果は自動送りにだけ使い、矢印キーによる手動の選び直しは即座に切り替える。連続した手動操作の応答性（憲章 II）を
  優先するためである。効果の長さは約0.5秒の固定とし、最短の切り替え間隔（1秒）でも効果が次の切り替えに重ならない
- **A-59**: 「視差効果を減らす」がオンの間は、移動や拡大を伴う効果をクロスフェードに置き換える（憲章 III の OS 設定の尊重）。
  設定ウインドウの表示や保存値は置き換えない
- **A-60**: 設定項目は既存の設定ウインドウ（⌘,）に「スライドショー」の区分として追加し、ツールバーやメニューへのスライドショー専用の
  設定項目、実行中に表示する操作パネルは追加しない。設定ウインドウの他の項目と同じく、確定した変更は再起動なしで反映する。
  「最後まで表示したら先頭から繰り返す」は既存の「動画をループ再生する」と別の設定であることが分かる名前とする
- **A-61**: ツールバーの3ボタンは左から拡大・表示領域に合わせる・縮小とし、要件の「左端」の重複は中ボタン（両矢印）
  をフィットとする意味に解釈する。3つは押した状態を保たない一時的なボタンで、現在の倍率が100%でもフィットボタンは押された見た目にしない
- **A-62**: 100%は原寸ではなくフィット表示とする。小さい画像は原寸を超えて拡大されたフィットの状態が100%になる。
  倍率の刻みは加算（25ポイント）とし、範囲は25%以上800%以下とする。800%を上限とするのは、
  拡大の要求に実用的な上限を置き、表示と操作の破綻を避けるためである
- **A-63**: ⌘+ / ⌘- は要望どおりプレビューの倍率変更に使う。既存のサムネイルサイズ変更は ⌃⌘. / ⌃⌘, に移し、
  キーボードだけで操作できる状態を保つ（FR-040・憲章 原則 III）。⌘+ はキーボード配列で `+` を入力するための Shift
  を含む操作のほか、Shift なしの ⌘= でも受け付ける（A-72）。プレビューに画像がないときの ⌘+ / ⌘- は何もしない
- **A-64**: 画像をドラッグしてパンする操作、トラックパッドのピンチ操作、倍率の数値表示、倍率のスライダー、画像ごとの倍率や位置の記憶は範囲外とする。スライドショーの切り替え効果「ズーム」（FR-130）は表示倍率とは別の機能であり、変更しない。
- **A-65**: ツールバーのグループは「スライドショーを開始」の右隣、種類フィルタの左に置く。
  ツールバーの項目の並びは既存の順序を保ち、本グループをその間に挿入する。表示メニューの3項目は「フルスクリーン」の下に区切り線を置いて追加する
- **A-66**: 表示倍率は画像を切り替えたときに100%へ戻す。フルスクリーンの切替・サイズ変更・ツールバーの表示切替・同じ画像を表示したままのペイン表示の復帰では保つ。
  保存も履歴への記録もしない。履歴の移動後は100%で表示する
- **A-67**: スライドショー中も画像なら倍率変更を使える。画像が切り替わると100%に戻り、
  切り替え効果・切り替え間隔・次の送り予定時刻は変えない。動画のスライドショーでは倍率変更を使えない
- **A-68**: アニメーション画像は倍率変更で再生をやり直さない。アニメーション WebP を再生できない場合は、
  先頭フレームの静止画として拡大・縮小できる（FR-030）
- **A-69**: ⌘+ / ⌘- のサムネイルサイズからの移行は、contracts/keyboard-and-menus.md
  の全該当箇所（プレビューのみ表示・zip の中・検索結果・サイズのスライダー・メニューバー）と navigation-history.md
  の FR-107（3）・US8-AS7 に及ぶ。プレビューのみ表示では、プレビューに画像があれば ⌘+ / ⌘- は倍率、
  ⌃⌘. / ⌃⌘, はサムネイルサイズを変える
- **A-70**: 倍率の変更は履歴の1件として記録しない。履歴の表示の状態にも含めない。25%刻みの連続操作で履歴が埋まらず、
  戻る・進むを閲覧の移動として使えるようにするためである
- **A-71**: 可視の倍率表示を追加しない代わりに、倍率をアクセシビリティの値として公開し、
  変更時に読み上げる。憲章 原則 III のアクセシビリティを、可視 UI を増やさずに満たすためである
- **A-72**: 拡大は ⌘= と ⇧⌘= の両方で受け付ける。`+` の入力に Shift を要する配列でも、
  Shift なしで拡大できるようにするためである。メニューとツールチップの表示は要件どおり ⌘+ とする
- **A-73**: 拡大・縮小・表示領域に合わせるの有効条件は FR-136 だけとし、シート・モーダル・名前の変更中・設定ウインドウがキーのときに追加の制限を設けない。
  倍率変更は取り消しを要さない一時的な表示操作であり、既存の ⌘+ / ⌘- によるサムネイルサイズ変更もこれらの状態で使えていたためである
- **A-74**: サムネイルサイズの変更の移動先は、拡大を ⌃⌘.、縮小を ⌃⌘, とする。
  ⌥⌘= / ⌥⌘- は macOS のアクセシビリティズーム（キーボードショートカットを有効にした場合）が先に受け取るため、
  画面拡大を使うユーザーがサムネイルサイズを変えられなくなる（憲章 原則 III）。⌃⌘+ / ⌃⌘- は、
  `+` が Shift を要して拡大だけ4キーの同時押しになり、縮小との違いが分かりにくいため採らない。
  `.` と `,` は Shift なしで押せる隣り合うキーで、キーに刻まれた `>`・`<` で拡大・縮小を覚えられる。
  ⌃⌘. / ⌃⌘, はアプリの既存のショートカット（設定の ⌘, を含む）とも macOS 標準のショートカットとも、
  修飾キーの違いで重ならない
- **A-75**: ショートカットは US 配列を基準とする。プレビューの拡大は ⌘+ と ⌘= で受け付け、
  JIS 配列向けの別のキー（⌘; など）は追加しない。JIS など異なる配列での使いにくさは、
  将来のショートカットキーのカスタマイズ（本機能の範囲外）で回避できるようにする

- **A-10**: 動画の音声は既定で再生する（ミュートしない）
- **A-11**: 画像はフィットで原寸を超えて拡大するため、小さい画像やドット絵は粗く（ぼやけて）見えることがある。
  画素をくっきり見せる表示（原寸表示や補間方法の選択）は引き続き範囲外とし、本機能の倍率変更（FR-133）は画像全体の拡大・縮小として提供する
- **A-12**: 憲章 原則 III の「拡大/縮小/フィット」は、ユーザー操作として提供する場合のキーボード到達性を求めるものと解釈する。
  フィットは画像の初期表示として自動でも行い、手動の拡大・縮小・フィットには FR-135 のキー割り当てを設ける
- **A-13**: プレビュー内の画像の拡大規則は画像のみを対象とし、動画の表示サイズは従来の挙動を維持する

- **A-94**: スクロールバーは画像に重ねて表示し、OS の外観・操作を尊重する。表示位置の維持はビューポート中心の画像内相対座標を基準とする。⌥方向キーはプレビューのフォーカス時に限るため、ツリー等の既存操作と衝突しない。
- **A-133**: 動画の再生コントロールは、マウスを動画の上に置いたときに表示される標準の再生コントロールを指す。コントロールが隠れている間は、
  その位置も映像の一部として反応領域に含める
- **A-134**: ダブルクリックの間隔は macOS のシステム設定に従う。シングルクリックで動画の再生・一時停止を切り替える操作は追加しない
- **A-135**: 全画面の切り替えのキーボード操作（⌃⌘F）・Esc・メニュー（FR-036）と、ファイルリストのみ表示からの全画面（FR-094（window-layout.md））は変更しない。
  ファイルリスト上のメディアの行のダブルクリック（TAK-18 の対象）は本変更に含めない
