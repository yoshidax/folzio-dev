# zip ファイル

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md`
から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

### zip ファイル

- **FR-068**: システムは、zip ファイルの表示設定（FR-095）がオンのとき、ファイルリストに zip ファイル（拡張子 .zip、
  大文字小文字を区別しない）を表示しなければならない。
  - zip ファイルはツリーには表示せず、ツリーでディレクトリとして扱ってはならない
- **FR-069**: ユーザーは、ファイルリストで zip ファイルをダブルクリックして、その zip の中の一覧（最上位）
  をファイルリストに表示できなければならない。
  - zip の中の一覧でディレクトリをダブルクリックすると、そのディレクトリの中の一覧に切り替える。
  - zip の中の探索はファイルリストの中で完結させ、ツリーの選択・展開状態は zip ファイルを含むフォルダのまま変えない。
  - zip の中を表示中にツリーで別のフォルダ（お気に入りの項目を含む）を選ぶと、zip の中の表示を終えて、
    そのフォルダの一覧に切り替える（FR-007）。
  - キーボードでは Finder と同じく、⌘↓ で選択中の zip ファイル・ディレクトリ・`..` を開き、⌘↑
    で選択中の行に関わらず1つ上の階層へ戻る（zip の最上位では zip ファイルを含むフォルダの一覧へ戻る）。
  - メディアファイルを選択中の ⌘↓ は何もしない。
  - zip の中を表示していないときの ⌘↑ は FR-077 に従う。
  - Return は従来どおり名前の変更（FR-019）に使い、開く操作には割り当てない。
  - zip ファイルの表示設定（FR-095）がオフの間は zip ファイルの行が表示されないため、zip
    ファイルを開く操作の対象にもならない
- **FR-070**: zip の中の一覧には、その階層の直下にあるディレクトリと対応メディアファイル（FR-039。判定は FR-009
  と同じく拡張子による）だけを表示し、それ以外のファイルは表示してはならない。
  - 一覧の先頭行には、1つ上の階層へ戻る項目 `..` を常に表示する。
  - `..` は並べ替えの対象にせず、常に先頭に置く。
  - zip の最上位で `..` を開くと、zip ファイルを含むフォルダの一覧（FR-008）に戻る。
  - `..` または ⌘↑（FR-069）で1つ上の階層へ戻ったときは、戻った先の一覧で、直前まで中を表示していた zip
    ファイルまたはディレクトリの行だけを選択し、その行全体が見える位置まで FR-017
    と同じ必要最小限のスクロールを行う（リスト形式・サムネイル形式の両方）。
  - 選択した行はメディアファイルではないため、プレビューは FR-075 により空になる。
  - 戻った先で zip ファイルの表示設定（FR-095）がオフのときは、その zip ファイルの行が表示されないため、
    行の選択もスクロールも行わず、選択のない一覧を表示する（プレビューは空）
- **FR-071**: zip の中の一覧でも、表示形式の切り替え（FR-010）・並べ替え（FR-012）・縮小画像（FR-013・FR-048）・
  複数選択と矢印キーでの移動（FR-016・FR-017）・プレビュー（FR-028〜FR-038）・フルスクリーン（FR-035〜FR-037・FR-046）
  を、通常のフォルダと同等に行えなければならない
- **FR-072**: システムは、zip の中のファイル（画像・動画とも）を、一時ファイルなどへ展開せずに zip
  から直接読み込まなければならない。
  - zip の中身をユーザーのフォルダに書き出してはならない（憲章 原則 I）。
  - zip の中の動画は、動画全体をメモリに展開せず、再生・シーク・代表フレームの取得に必要な部分だけを zip
    から順に読み出して再生しなければならない（ストリーミング方式）。
  - 動画の再生に使うメモリは動画のサイズに比例して増えてはならず、動画のサイズによる再生可否の上限は設けない
- **FR-073**: zip の中は読み取り専用とする。
  - zip の中のファイルとディレクトリに対するコピー・名前の変更・ゴミ箱に入れる・移動・複製・ドラッグ&ドロップ、および
    zip の中の一覧へのペーストは行えてはならない。
  - 右クリックメニューの該当項目は淡色で選べないようにし、対応するキーボードショートカット（FR-019）は何もしない。
  - zip ファイルそのものは通常のファイルと同じく FR-018〜FR-027 のファイル操作の対象とする
- **FR-074**: システムは、zip の中のファイル名・ディレクトリ名の文字コードを自動で判定しなければならない。
  - 名前に UTF-8 の印（zip の汎用フラグのビット 11）があれば UTF-8 として読む。
  - 印がない場合は、UTF-8 として正しく読めれば UTF-8、読めなければ Shift_JIS（CP932）、それでも読めなければ CP437
    として読む。
  - 判定は名前ごとに行い、文字コードを手動で切り替える設定は設けない。
  - 判定後の名前を、表示・並べ替え（FR-012 の自然順）・拡張子による形式の判定（FR-009）に使う
- **FR-075**: プレビュー（フォーカス）の対象が zip ファイル・zip の中のディレクトリ・`..` の行になった場合（クリック・
  矢印キー・複数選択のいずれでも）、システムはプレビューを空にしなければならない。
  - 再生中の動画は FR-034 と同じく停止する。
  - これらの行の縮小画像・行頭アイコンは、種類（zip／ディレクトリ／上の階層へ戻る）を区別できる汎用アイコンとする

### zip ファイルの表示制御

- **FR-095**: ユーザーは、ファイルリストに zip ファイル（FR-068）を表示するかどうかを切り替えられなければならない。
  - 設定は独立したオン・オフで、既定はオフ（非表示）とする。
  - 設定は FR-003 に従い保存し、再起動後に復元しなければならない。
  - 保存された値がない初回起動時のみ、既定の非表示を使う。
  - 設定は通常のフォルダの一覧にだけ適用し、リスト形式・サムネイル形式の両方に同じように適用する。
  - zip の中の一覧（FR-070）は zip ファイルの行を含まないため、表示は変わらない。
  - 検索結果（FR-084）に zip ファイルの行を含めるかどうかは、検索を始めた時点の設定の値で決まり（FR-278）、
    検索結果の表示中に切り替えても既存の結果は変わらない。
  - オフの間は通常の一覧に zip ファイルの行を表示せず、その行の選択・プレビュー・フルスクリーンの移動・
    開く操作（FR-069）の対象にもならない。
  - 種類フィルタ（FR-056）とは独立し、両方の条件を満たす行だけを表示する
- **FR-096**: ツールバー（FR-049）には、「zipファイルを表示」のトグルボタンを、種類フィルタの2つのボタン（FR-057）
  の右、表示形式の切り替えボタン（FR-051）の左に置かなければならない。
  - ボタンはオンのとき押された見た目で示し、クリックするたびにオン・オフが切り替わる。
  - 「表示」メニューに「zipファイルを表示」の項目を置き、オンのときチェックマークを付ける。
  - キーボードショートカットは ⌃⌘Z とする（⇧⌘Z は「やり直す」で使用中）。
  - メニュー・ショートカット・ツールバーのボタンは同じ状態を共有し、どこから変更しても他方の表示に反映される。
  - ツールバーが非表示のときも、メニューとショートカットで操作できなければならない（FR-040）。
  - ファイル名の変更中は無効にする。
  - ボタンとメニュー項目は、状態をスクリーンリーダーなどのアクセシビリティ API から識別できるラベルを持つ
- **FR-097**: zip ファイルの表示設定をオフにしたとき、フォーカス中の行が zip ファイルだった場合は、システムはその zip
  ファイルを選択から外さなければならない。
  - 表示中のファイルが選択に残る場合は、FR-059 と同じく一覧の並び順で最後のファイルをフォーカスにしてプレビューし、
    選択が1つも残らない場合はプレビューを空にして、再生中の動画を FR-034 に従って停止する。
  - 非表示にした結果、一覧に `..` 以外の行がなくなった場合は、既存の空のメッセージを表示する（zip
    ファイルを非表示中であることを示す専用のメッセージは設けない）
- **FR-098**: zip の中の一覧を表示中に zip ファイルの表示設定をオフにしても、表示中の zip の中の一覧と、その選択・
  プレビュー・表示形式・フルスクリーンを変えてはならない。
  - `..` または ⌘↑ で zip ファイルを含むフォルダへ戻ったときは、FR-070 の選択とスクロールを行わず（戻り先に zip
    ファイルの行が表示されないため）、選択のない一覧を表示してプレビューを空にする
- **FR-231**: zip ファイルが同じパスのまま別の内容に置き換わった後にその zip を開いた場合、システムは、
  中のファイルの縮小画像とプレビューに、置き換え後の zip の内容を表示しなければならない。
  - 置き換え前の zip から作った縮小画像・プレビューの画像を表示してはならない。
  - 表示中の zip が置き換わった場合の一覧の扱いは、EC-26 のとおりとする

## 主なエンティティ

- **zip ファイル**: ファイルリストの項目の1つ。
  - ファイル名、場所、作成日を持ち、開くと中の一覧を表示する。
  - ツリーのノードにはならない。
  - 中身は読み取り専用。
  - zip ファイルの表示設定（FR-095）がオフの間はファイルリストに表示されない
- **zip の中の項目**: zip の中のディレクトリまたはメディアファイル。
  - zip の中のパス、名前、種類を持つ。
  - メディアファイルはメディアファイルと同じく縮小画像・行頭アイコン・プレビューの対象になる
- **zip の中の現在位置**: zip の中を表示中の、開いている zip ファイルとその中の階層。先頭行の `..` で1つ上へ戻る

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS15**: **Given** 画像を含む zip ファイルがあるフォルダを表示中で zip ファイルの表示設定がオン,
  - **When** ファイルリストでその zip ファイルをダブルクリックする,
  - **Then** ファイルリストが zip の中の一覧に切り替わり、先頭行に `..`、続いて zip
    の中のディレクトリと対応メディアファイルが表示され、
    それ以外のファイルは表示されない。ツリーの選択と表示は変わらない
- **US1-AS16**: **Given** zip の中の一覧を表示中,
  - **When** ディレクトリをダブルクリックする／先頭行の `..` をダブルクリックする,
  - **Then** そのディレクトリの中の一覧に切り替わる／1つ上の階層の一覧に戻る。zip の最上位で `..` を選ぶと、zip
    ファイルを含むフォルダの一覧に戻る。戻った先では、直前まで中を表示していた zip ファイル（またはディレクトリ）
    の行が選択され、見える位置までスクロールされる。ダブルクリックの代わりに、選択中の行を ⌘↓ で開き、⌘↑
    で（どの行を選択中でも）1つ上の階層に戻ることもできる
- **US1-AS17**: **Given** zip の中の一覧を表示中,
  - **When** 画像や動画を選択する・表示形式を切り替える・フルスクリーンにする,
  - **Then** 通常のフォルダと同じくプレビュー（動画の自動再生・ループ・シークを含む）・リスト形式／サムネイル形式・
    フルスクリーンが使え、zip の中身は一時ファイルに展開されない
- **US1-AS18**: **Given** zip の中のファイルを選択中,
  - **When** 右クリックする／⌘⌫・Return・⌘C などを押す／ツリーへドラッグする,
  - **Then** ファイル操作のメニュー項目は淡色で選べず、キー操作とドラッグでは何も起きず、zip は変更されない
- **US1-AS19**: **Given** 動画を再生中,
  - **When** 矢印キーやクリックで zip ファイル・ディレクトリ・`..` の行を選ぶ,
  - **Then** 動画の再生（音声を含む）が止まり、プレビューは空になる
- **US1-AS20**: **Given** zip の中で画像をフルスクリーン表示中で、次の行がディレクトリ,
  - **When** 矢印キーでその方向へ移動する,
  - **Then** ディレクトリの行を飛ばして次の画像（または動画）
    が表示される。その方向にメディアファイルがなければ表示は変わらない
- **US1-AS29**: **Given** zip の中の一覧を表示中で zip ファイルの表示設定がオン,
  - **When** 「表示」メニューまたは ⌃⌘Z で zip ファイルを非表示にし、続けて ⌘↑ で zip ファイルを含むフォルダへ戻る,
  - **Then** 戻るまでの zip の中の一覧は変わらず、戻った先の一覧には zip ファイルの行が表示されず、
    何も選択されていない状態でプレビューは空になる

### US3 リスト形式とサムネイル形式を切り替えて一覧する（P2）

- **US3-AS19**: **Given** zip ファイルとメディアファイルが混在するフォルダを表示中で、zip
  ファイルの表示設定が既定（非表示）,
  - **When** ツールバーの「zipファイルを表示」ボタンを押す（または「表示」メニューの項目・⌃⌘Z を実行する）,
  - **Then** zip ファイルの行がリスト形式・サムネイル形式の両方に表示され、ボタンが押された状態になり、
    メニュー項目にチェックが付く。もう一度実行すると zip ファイルの行が再び消える
- **US3-AS20**: **Given** zip ファイルの表示設定がオンで、zip ファイルの行を選択中,
  - **When** zip ファイルを非表示にする,
  - **Then** その zip ファイルは選択から外れ、
    ほかに表示中のファイルがあれば一覧の並び順で最後のものが選択されてプレビューされ、
    なければプレビューが空になる。表示中の階層に zip ファイルしかなければ、`..` の行を除いて一覧が空になり、
    空のメッセージが表示される
- **US3-AS21**: **Given** zip ファイルの表示設定をオフにしてアプリを終了した,
  - **When** 再起動する,
  - **Then** zip ファイルは非表示のまま復元される。保存された設定がない初回起動時も非表示で始まる
- **US3-AS22**: **Given** zip の中の一覧を表示中,
  - **When** zip ファイルの表示設定をオフにする,
  - **Then** zip の中の一覧はそのまま表示され、中のファイルのプレビュー・表示形式の切り替え・
    フルスクリーンを続けて使える

### US42 zip を置き換えた後に開き直す（P2）

- **US42-AS1**: **Given** zip Z の中の画像 P を表示したことがある,
  - **When** Z を、同じ名前の P を含む内容の違う zip で置き換えてから、Z を開いて P を選択する,
  - **Then** P のサムネイルとプレビューが置き換え後の zip の内容になる
- **US42-AS2**: **Given** zip Z の中の画像 P をプレビュー中,
  - **When** アプリの外で Z を置き換える,
  - **Then** EC-26 のとおり zip を含むフォルダの一覧に戻り、プレビューを空にする

### US58 zip の中の画像でも同じ上限が働く（P2）

- **US58-AS1**: **Given** 画像が 40 件以上ある zip を開いている,
  - **When** 読み込みの完了を待たずに 40 回続けて次の画像へ移動する,
  - **Then** zip の項目の読み出しとデコードを合わせて、同時に実行される数は常に 2 件以下である
- **US58-AS2**: **Given** zip の中の画像の先読みが待機中または実行中,
  - **When** zip から出てフォルダの一覧に戻る,
  - **Then** zip の中の待機中の先読みはすべて取り消され（EC-199（preview.md））、
    フォルダの画像の読み込みの枠を占めない

## エッジケース

- **EC-10**: 10,000 項目以上を含む zip を開いた場合も、読み込み中の表示を出し、UI は操作可能なまま（SC-015）
- **EC-22**: zip の中を表示中は読み取り専用とし、ファイル操作のメニュー項目・ショートカット・ドラッグ&ドロップ・
  ペーストはどれも zip を変更しない
- **EC-23**: zip の中の名前が UTF-8 で記録されていない場合（Windows で作られた日本語の zip など）も、FR-074
  の自動判定で文字化けせずに表示する
- **EC-24**: 壊れた zip、または拡張子が .zip でも zip として読めないファイルを開いた場合、アプリは落ちずに、
  ファイルリストに zip を開けない旨とその理由を表示する。
  - zip ファイルを含むフォルダの一覧には ⌘↑ で戻れる
- **EC-25**: zip の中の、暗号化されたファイルや、対応していない圧縮方式（無圧縮と deflate 以外）
  で格納されたファイルは一覧に表示する。
  - 選択するとプレビューに FR-038 と同じく表示できない旨と理由を示し、縮小画像・
    行頭アイコンは形式別の汎用アイコンにフォールバックする。
  - パスワードの入力は求めない
- **EC-26**: zip の中を表示中に、その zip ファイルがアプリの外で削除・移動・変更された場合は、zip
  を含むフォルダの一覧に戻り、FR-042 に従ってその変更を反映する。
  - プレビュー中だった zip の中のファイルの表示は空にする
- **EC-27**: 種類フィルタがオンでも zip ファイル（zip ファイルの表示設定がオンのとき）・zip の中のディレクトリ・`..`
  は表示したままにする。
  - 表示中の階層のメディアファイルが絞り込みで0件になった場合は、それらの行に加えて絞り込み中のメッセージを表示する
- **EC-28**: zip ファイルの表示設定がオフのとき、zip ファイルの行は種類フィルタの状態に関わらず表示しない。
  - 表示中の階層にメディアファイルとフォルダがなく zip ファイルだけがある場合は、`..` の行を除いて一覧が空になるため、
    既存の空のメッセージを表示する（zip ファイルを非表示中であることを示す専用のメッセージは出さない）
- **EC-29**: zip ファイルの表示設定をオフにしたとき、フォーカス中の行が zip ファイルだった場合は、
  種類フィルタで非表示になったとき（FR-059）と同じく選択から外し、
  表示中のファイルが残れば最後のものをフォーカスしてプレビューし、
  残らなければプレビューを空にして再生中の動画を停止する
- **EC-30**: zip の中の一覧を表示中に zip ファイルの表示設定をオフにしても、その一覧は変えない。
  - `..` や ⌘↑ で戻った先では zip ファイルの行を選択せず、
    選択のない状態で一覧を表示してプレビューを空にする（スクロールもしない）

## 成功基準

- **SC-014**: zip の中の 1GB 以上の動画を再生・シークしても、その動画のためにアプリが追加で使うメモリが 128MB
  を超えない。
  - zip を開いて再生している間、一時ファイルが作られない。
  - 圧縮せずに格納された 1080p 動画は、選択から再生開始までが SC-010 と同じ 1 秒以内
- **SC-015**: 10,000 項目を含む zip を開いても、SC-003 と同じく中の一覧の最初の項目が 1 秒以内に表示され、
  読み込み中もスクロール・選択・ツリーの操作が途切れない。
  - 読み込みの間は、通常のフォルダと同じ読み込み中の表示が出る
- **SC-017**: zip ファイルの表示を切り替えてから一覧に反映されるまでが 0.2 秒以内（10,000 ファイルを含むフォルダ）。
  - 切り替え中も一覧のスクロール位置を保ち、操作が 100ms 以上止まらない。
  - 切り替え後にアプリを終了して再起動すると、同じ表示状態が復元される（保存された値がない初回起動時は非表示）

## 前提

- **A-22**: zip の中の zip（入れ子の zip）は FR-070 の「それ以外のファイル」として表示しない。
  - .zip 以外のアーカイブ形式（.rar・.7z・.cbz など）、パスワード付き zip の展開、zip の作成・書き換えは今回の範囲外
- **A-23**: zip ファイルの表示設定は「ファイルリストに zip ファイルの行を出すかどうか」だけを切り替え、zip
  ファイル自体の存在・中身・ファイル操作には影響しない。
  - 非表示の間はファイルリストから zip を開く手段がないが、これは意図した挙動とし、
    ツリーやメニューに別の入口は設けない。
  - 表示設定は初回起動時のみ非表示で、以後は保存した値を復元する
- **A-24**: zip の中の項目の「作成日」の列には、zip に記録された更新日時を表示する（zip は作成日時を持たないため）
- **A-26**: zip の中に圧縮して格納された動画は、データを先頭から順に展開しないと目的の位置を読めないため、
  再生開始やシークが通常のファイルや圧縮せずに格納された動画より遅くなることがある（SC-014 のメモリ基準は守る）
