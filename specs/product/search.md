# 検索

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md` から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

- **FR-080**: ユーザーは、キーボードショートカット ⌘F と「ファイル」メニューの「検索…」で、ファイル名による検索の条件を入力する
  モーダル（検索のモーダル）を開けなければならない。どのペインにフォーカスがあっても使えるが、フルスクリーン表示中とファイル名の
  変更中、およびプレビューのみ表示中（FR-092）は無効にする
- **FR-081**: 検索のモーダルは、「検索キーワード」（標準の検索フィールド）、「検索起点ディレクトリ」（1行のテキスト入力）と
  その近くの「選択…」ボタン、「検索」ボタン、「キャンセル」ボタンで構成しなければならない。検索起点ディレクトリの既定値は、
  ファイルリストに表示中のフォルダの絶対パスとする。検索結果の表示中は検索前のフォルダ、zip の中を表示中は FR-069 により
  zip ファイルを含むフォルダとする。お気に入りの見出しを選択しても一覧のフォルダを使う。EC-102（009-folder-search）で
  一覧に F、ツリーに祖先 V を表示している場合は F を使い、V へ置き換えない。「検索」で検索を始めてモーダルを閉じる。
  「キャンセル」（Esc を含む）ではモーダルを閉じるだけで、ファイルリスト・ツリー・プレビューを取消操作によって変えてはならない。
  モーダルを開いたときは検索キーワード欄にフォーカスを置き、同じ起動中に前回検索したキーワードがあれば全選択した状態で入れておく
  （検索起点ディレクトリは毎回上の既定値とする）。標準パネルを開いていないときは、Return で「検索」（キーワードが空のときは何もしない）、
  Esc で「キャンセル」とする。Tab は検索キーワード → 検索起点ディレクトリ → 「選択…」 → キャンセル → 検索の順、⇧Tab は逆順に移動し、
  システムのキーボードナビゲーションの設定に関わらずボタンにも止まる。検索起点ディレクトリは直接入力・編集を引き続き可能とし、
  入力手段によらず「検索」を押したときに確かめる。直接入力では前後の空白を除き、先頭の `~` はホームフォルダ、末尾の `/` は無視して解釈する。
  GUI 選択で反映してから起点欄を編集していない間だけは、名前の末尾の空白も含む選択した絶対パスを文字どおり使い、空白除去は行わない。
  起点欄を編集した時点で従来の直接入力の解釈へ戻す。キーワードの編集や標準パネルの取消では、この区別を変えない。`/` と `~` の
  どちらでも始まらないパス、存在しないパス、フォルダでないパス（zip ファイルを含む）、読み取り権限のないフォルダの場合は、モーダルを
  閉じずに理由を入力欄の近くに表示し、検索を始めてはならない（検証失敗を理由にファイルリストの表示は変えない）。フォルダ選択パネルの
  動作は FR-141〜FR-144 に従う
- **FR-082**: 検索キーワードは、ファイル名（拡張子を含む）とだけ照合し、フォルダのパスは照合に含めない。ワイルドカードは `*`（0文字以上の
  任意の文字）と `?`（任意の1文字）とする。ワイルドカードを含まないキーワードはファイル名への部分一致、含むキーワードはファイル名全体との
  一致とする。英字の大文字小文字と Unicode の正規化の違い（濁点の合成・分解など）は区別しない。前後の空白を除いたキーワードが空のときは
  「検索」ボタンを無効にする
- **FR-083**: 検索は、検索起点ディレクトリ以下のすべての階層のサブフォルダを辿って行わなければならない。一致の対象は対応メディアファイル
  （FR-039。判定は FR-009 と同じく拡張子による）だけとし、フォルダ名は照合しない。隠しファイルと隠しフォルダ（とその中）は対象外とし、
  シンボリックリンクのフォルダとパッケージ（.app など）の中は辿らない。ファイルへのシンボリックリンクは、通常のフォルダの一覧と同じく
  名前（拡張子）で対応メディアファイルかを判定し、一致の対象にする。読み取り権限のないフォルダは飛ばして検索を続ける。
  zip ファイル（FR-068）は対応メディアファイルではないため一致の対象にせず、zip の中も検索しない
- **FR-084**: システムは、検索結果（一致したファイル）を、フォルダの区別なく1つの一覧としてファイルリストに表示しなければならない。
  リスト形式には「場所」列（ファイルを含むフォルダの、検索起点のフォルダ名から始まるパス）を加え、FR-012 の並べ替えの対象にする。
  サムネイル形式はファイル名だけを表示し、場所はポインタを重ねたときの説明で示す。先頭行の `..` は表示せず、⌘↑ は何もしない。
  ファイルリストの上部に、検索結果を表示中であることと、キーワード・検索起点・件数を示す（同じ名前のフォルダを見分けられるよう、
  検索起点の絶対パスをツールチップで示す）。表示形式（FR-010）・並べ替え（FR-012）・
  複数選択と矢印キーでの移動（FR-016・FR-017）・種類フィルタ（FR-056）・プレビュー（FR-028〜FR-038）・フルスクリーン（FR-035〜FR-037・
  FR-046）は通常のフォルダと同じに使える。一致が0件の場合は、該当するファイルがない旨のメッセージを、FR-060 の空のメッセージ・
  絞り込み中のメッセージと区別して表示する
- **FR-085**: 検索は UI を止めずに行い、見つかったファイルから順に一覧へ追加しなければならない（並び順は現在の並べ替えに従う）。検索中は
  検索中であることと途中の件数を表示し、完了したら件数を確定する。検索中もスクロール・選択・プレビュー・ツリーの操作を続けられなければ
  ならない。検索結果の表示を解除したとき（FR-086）、または新しい検索を始めたときは、実行中の検索を止める。新しい検索の結果は前の結果を
  置き換える。結果の件数に上限は設けない
- **FR-086**: 検索結果を表示中に、ユーザーがツリーでフォルダ（お気に入りの項目を含む）を選択したとき、システムは検索結果の表示を
  解除し、ファイルリストをそのフォルダの一覧に切り替えなければならない（FR-007）。検索前から選択されていたフォルダの行を
  クリックした場合も同じく解除する。「お気に入り」の見出しの選択は、FR-065 のとおりフォルダの選択として扱わないため解除しない。
  フルスクリーン中とファイル名の変更中を除き、ファイルリストで Esc を押した場合も同じく検索結果の表示を解除し、検索前のフォルダの一覧に戻す
  （検索中なら検索を止める）。検索結果を表示中もツリーの選択は検索前のまま変えず、検索結果と検索条件は保存しない（FR-003 の最後に
  選択していたフォルダも更新しない）
- **FR-087**: 検索結果の一覧で選択したファイルには、コピー・名前の変更・ゴミ箱に入れる・移動・複製・ドラッグ&ドロップ（FR-018〜
  FR-027）を通常のフォルダと同じに行えなければならない。貼り付け先のフォルダがないため、検索結果へのペースト（⌘V・⌥⌘V）は右クリック
  メニューで淡色にして選べないようにし、ショートカットも何もしない。ゴミ箱に入れた・移動したファイル、およびアプリの外で削除・移動された
  （元の場所から消えた）ファイルは一覧から外す（プレビュー中だった場合はプレビューを空にする）。名前を変更したファイルは、キーワードに
  一致しなくなっても新しい名前で一覧に残す。ただし、対応メディアファイルの拡張子でない名前に変えた場合は、FR-083 の対象外になるため
  一覧から外す（プレビュー中だった場合はプレビューを空にする）。複製で作ったファイルや、検索の後に新しく現れたファイルは一覧に加えない
- **FR-105**: 検索結果を表示中（検索中を含む）に、ツリーで検索結果のファイルを含むフォルダ（検索起点そのもの、その祖先、
  または配下のフォルダ）の名前を変えた場合、システムは次のとおり一覧を同期しなければならない。
  該当するファイルは一覧に残し、リスト形式の「場所」列とサムネイル形式のツールチップ（FR-084）を新しい名前で表示する。
  検索起点そのものの名前を変えた場合は、検索バーの起点のフォルダ名とツールチップの絶対パスも新しい名前にする（アプリの外での
  削除・移動を扱う EC-36とは区別し、結果を外さない）。検索起点の祖先の名前を変えた場合は、検索バーのツールチップの
  絶対パスを新しい名前にする。「場所」列で並べ替えている場合は並べ直す。選択・プレビューは保つ。
  新しい場所が検索の対象（FR-083）でなくなったファイルは一覧から外し（FR-103 の検証により、ツリーやファイルリストでの
  名前の変更ではこの場合は起きない。名前の変更を検索結果へ反映する処理の規則として定める）、それがプレビュー中だった場合はプレビューを
  空にして再生中の動画を止める（FR-087と同じ）。検索中であれば検索を止めずに続け、以後に見つかったファイルも
  新しい場所で加える。フォルダの名前は検索キーワードと照合しない（FR-082・FR-083）ため、フォルダの名前の変更で
  一覧にファイルが加わることはない

### 検索起点フォルダの選択

- **FR-141**: 「選択…」を押すと、macOS 標準のフォルダ選択パネル（`NSOpenPanel`）を検索シートの子シートとして開かなければならない。
  パネルは既存の1つのフォルダを選ぶ用途に構成し、通常ファイル・zip ファイルを選択対象にせず、複数選択と新規フォルダ作成を提供しない。
  パッケージはフォルダとして辿れず、選択できない。隠し項目は標準パネルの動作に従い、既定では非表示、⌘⇧. で表示でき、
  隠しフォルダも選択できる。パネルで「選択」を押すとパネルを閉じ、選択 URL の存在・フォルダであること・読み取り可否を
  UI スレッドの外で再検証する。成功した場合だけ検索起点欄の全体を選択した絶対パスで置き換え、以前の起点に対する検証エラーを消す。
  キーワードを保ち、検索は開始しない。失敗した場合は選択 URL を反映せず、検索シートを開いたまま理由を表示・読み上げ、
  起点欄とキーワードを保持して選び直し・取消を可能にする。確定後も検索時の再検証は省略しない。GUI 選択の表示制限を
  直接入力の検索起点の検証へ追加してはならない
- **FR-142**: 標準パネルで「選択」を押したときは、検索起点欄の全体を選択したフォルダの絶対パスで置き換え、
  以前の起点に対する検証エラーを消さなければならない。キーワードを保ち、パネルだけを閉じる。取消（Esc を含む）と検証失敗では、
  検索シートを開く直前の起点欄・キーワードを保つ。開く・確定・取消のいずれでも検索を開始せず、選択操作を理由にツリーの選択・
  ファイルリスト・プレビューを変更しない。既存の検索が進行中でも、この操作だけでは停止・再開始・置換しない。「変えない」は
  選択操作による変更を指し、既存検索の進行と結果の更新（FR-085）、外部変更の反映（FR-042、overview.md）は継続する。
  新しい検索を有効な条件で開始した時点で FR-085 に従い置き換える。選択後も起点欄を直接編集でき、検索には最新の欄の値を
  FR-081 の規則で解釈して使う。GUI 選択後に起点欄を編集したかどうかは検索シート内だけで扱い、シートを閉じたら破棄する
  （検索条件の非保存は FR-086・contracts/settings.md に従う）
- **FR-143**: 標準パネルの初期表示フォルダは、次の優先順で決めなければならない。（1）現在の起点欄を FR-081 と同じ規則
  （未編集の GUI 選択パスは文字どおり、それ以外は空白・`~`・末尾 `/` の解釈）で解釈した、存在し読み取り可能なフォルダ、
  （2）検索シートを開いた時点の既定フォルダ（存在し読み取り可能な場合）、（3）ユーザーのホームフォルダ。各候補は存在・フォルダ・
  読取りを確かめ、パッケージと読み取り不能なフォルダは飛ばして次へ進む。隠しフォルダは許可する。初期表示のために起点欄を書き換えず、
  パネルを再度開くときも現在の起点欄を優先する。（2）は FR-081 の既定値を開いた時点で捕捉し、後からツリーの選択や一覧の変化で
  置き換えない。EC-102 の F が無効なら、（1）と（2）の F を飛ばしてホームへ進み、ツリーの V を追加候補にはしない。
  取消では起点欄の F を保持する。いずれの候補も利用できない場合は検索シートを保ち、起点欄の近くに理由を表示して直接入力・
  再試行を可能にする。初期位置の解決中も親の「検索」は利用できる。空キーワードの無操作を除き検索操作を受理した時点で
  保留中のパネル提示を失効させ、その後で検索条件を検証する。失効した解決の成功・失敗は、検索検証との完了順によらず
  パネルの提示や親のエラー変更に使わない。検索検証に失敗しても旧依頼を復活させず、親で理由を示して選択操作の再試行を可能にする。
  標準パネルを表示済みなら FR-144 に従い親の検索を受理しない
- **FR-144**: 新しいフォルダ選択操作はキーボードだけで利用でき、「選択…」にフォーカスがあるとき Space で標準パネルを開けなければならない。
  標準パネルでは OS 標準のキーボード操作で階層移動・単一フォルダの選択・確定・取消ができる。パネル表示中は検索シートを操作できず、
  Return・Esc はパネルだけで処理する。確定・取消・検証失敗の後は「選択…」へフォーカスを戻す。ボタンは検索起点フォルダを選ぶ操作で
  あると分かるラベルでスクリーンリーダーから識別でき、パネル自体の標準のアクセシビリティを使う

## 主なエンティティ

- **検索条件**: 検索キーワード（ワイルドカード `*`・`?` を含められる）と検索起点ディレクトリ。保存しない
- **検索結果**: 検索条件に一致したメディアファイルの一覧と、各ファイルの場所（検索起点のフォルダ名から始まるパス）、
  状態（検索中／完了）、件数。ツリーでフォルダを選択すると解除される。元の場所から消えたファイルは外れ、新しく現れたファイルは
  加わらない（FR-087）

## 受け入れシナリオ

### US1 フォルダを辿って画像をプレビューする（P1）

- **US1-AS25**: **Given** 一覧にフォルダを表示中（EC-102 で一覧の F とツリーの V が異なる場合を含む）, **When** ⌘F を押す
  （または「ファイル」メニューの「検索…」を選ぶ）, **Then** 検索キーワードと検索起点ディレクトリの入力欄、「選択…」「検索」「キャンセル」
  ボタンを持つ検索のモーダルが表示され、検索起点ディレクトリには一覧に表示中のフォルダの絶対パスが入っている。検索結果の表示中は
  検索前のフォルダ、zip の中を表示中は zip ファイルを含むフォルダとし、EC-102 では V でなく F を使う。「キャンセル」を押すと、
  ファイルリスト・ツリー・プレビューは何も変わらない
- **US1-AS26**: **Given** 検索のモーダルで検索キーワードに `*.png` を入力した, **When** 「検索」を押す, **Then** 検索起点ディレクトリ以下の
  すべての階層にある PNG ファイルが、ファイルリストにフォルダの区別なく1つの一覧としてバッチで追加され、表示は現在の
  並べ替え順に従い、リスト形式では各ファイルの「場所」列で同じ名前のファイルを見分けられる。検索中もスクロール・選択・
  プレビュー・ツリーの操作ができる
- **US1-AS27**: **Given** 検索キーワードに `cat`（ワイルドカードなし）を入力した, **When** 検索する, **Then** 名前に `cat` を含むファイル
  （例: `Cat01.jpg`、`my_cat.mov`）が大文字小文字を区別せずに見つかる
- **US1-AS28**: **Given** 検索結果を表示中, **When** ツリーでフォルダ（検索前から選択されていたフォルダを含む）を選択する, **Then** 検索結果の
  表示が終わり、ファイルリストはそのフォルダの一覧に切り替わる。検索中であれば検索は止まる

### US16 フォルダを画面で選んで検索起点を設定する（P1）

- **US16-AS1**: **Given** 検索シートでキーワードと起点パスを入力済み, **When** 「選択…」を押して標準パネルで別の読み取り可能な
  フォルダを1つ選び「選択」を押す, **Then** 検索起点欄の全体が選択したフォルダの絶対パスになり、キーワードは保たれる。
  検索シートは開いたままで、選択操作による検索開始・ツリーの選択・ファイルリスト・プレビューの変更は起きない。その後「検索」を押すと、
  その起点で既存の検索を開始する
- **US16-AS2**: **Given** 検索シートでキーワードと起点パスを編集中, **When** 標準パネルを開き「キャンセル」または Esc で取り消す,
  **Then** パネルだけが閉じ、検索シートと両入力欄の値が保持される。新たな検索は始まらず、取消操作によってツリー・ファイルリスト・
  プレビューは変わらない
- **US16-AS3**: **Given** フォルダ選択で起点を設定済み, **When** 起点欄を別の有効なパスに直接書き換えて「検索」を押す,
  **Then** 選択時のパスではなく欄にある最新のパスを使う。直接入力だけで検索する従来の操作も利用できる
- **US16-AS4**: **Given** 起点欄が GUI で選択できる読み取り可能なフォルダを表す（直接入力の前後の空白・先頭の `~`・末尾の `/` は
  FR-081 に従う）, **When** 標準パネルを開く, **Then** 解釈後のフォルダを最初に表示する。選択を確定するまでは入力欄の文字列を変更しない
- **US16-AS5**: **Given** 起点欄が空または無効なパス, **When** 標準パネルを開く, **Then** 検索シートを開いた時点の既定フォルダを、
  そこも利用できなければホームフォルダを最初に表示する。取消では無効な入力もそのまま保ち、有効なフォルダを選び確定すれば
  その絶対パスへ置き換えられる
- **US16-AS6**: **Given** 検索シートが開いている, **When** キーボードだけで「選択…」へ移り、Space で標準パネルを開き、
  フォルダを選んで確定または取消する, **Then** 検索シートへ戻り「選択…」にフォーカスが戻る。標準パネルでの Return・Esc は
  そのパネルだけに作用し、検索を開始したり検索シートを閉じたりしない。操作名はスクリーンリーダーでも識別できる
- **US16-AS7**: **Given** フォルダを選択して確定した後、そのフォルダが削除されたか読み取り権限を失った, **When** 「検索」を押す,
  **Then** FR-081 の検証で拒否し、シートを閉じずに理由を表示する。新たな検索は始めず、検証失敗を理由に一覧は変えない
- **US16-AS8**: **Given** 標準パネルが開いている, **When** 通常のファイルや zip ファイルを選ぼうとする, **Then** 検索起点として
  確定できない。複数のフォルダを同時に検索起点へ設定することもできない。パッケージの内部へ移動することもできない
- **US16-AS9**: **Given** 起点の検証エラーを表示中, **When** 標準パネルで読み取り可能なフォルダを確定する,
  **Then** 新しい絶対パスが入り、古いパスに対するエラー表示が消える。検索シートは開いたままで、実際の検索時には最新のパスを再検証する
- **US16-AS10**: **Given** 同じ親の下に `Photos` と末尾に空白がある `Photos ` の両フォルダが存在する,
  **When** 標準パネルで `Photos ` を選び、起点欄を編集せずに検索する, **Then** `Photos ` が起点となり、`Photos` へ置き換わらない。
  パネルを開き直すと同じフォルダから始まり、取消やキーワードの編集後もこの扱いを保つ。起点欄を直接編集した場合は従来の空白除去を適用する
- **US16-AS11**: **Given** 起点欄が隠しフォルダまたはパッケージを指している, **When** 標準パネルを開く,
  **Then** 隠しフォルダならその場所を初期表示でき、パネルで隠し項目を表示して選択できる。パッケージや読み取り不能なフォルダなら
  次の候補（既定フォルダ、ホーム）へ進む。パッケージは一覧に出てもフォルダとして選択・内部移動できない。
  直接入力からの検索の可否は従来の検証に従う
- **US16-AS12**: **Given** 標準パネルで確定しようとしたフォルダが削除済み、または読み取り不能である, **When** 「選択」を押す,
  **Then** パネルは閉じ、検索シートに理由が表示・読み上げられる。検索起点欄・キーワードは変わらず、その無効な URL は反映されない。
  別のフォルダを選び直せ、取消した場合は元の検索シートへ戻れる
- **US16-AS13**: **Given** 検索 A が進行中で、検索シートから標準パネルを開く, **When** フォルダを確定または取り消す,
  **Then** 検索 A は継続し、発見された結果と途中の件数は更新される。選択操作による停止・再開始・結果の置換は起きない。
  新しい検索 B を有効な条件で開始したときだけ、検索 A を停止し、その結果を B の結果で置き換える

## エッジケース

- **EC-32**: 検索で一致するファイルが1件もない場合は、該当するファイルがない旨を表示し、フォルダが空のときのメッセージ・絞り込み中の
  メッセージとは区別する（FR-084）
- **EC-33**: 検索中に読み取り権限のないフォルダに当たった場合は、そのフォルダを飛ばして検索を続ける（FR-083）
- **EC-34**: 検索起点ディレクトリに存在しないパス・フォルダでないパス（zip ファイルを含む）・読み取り権限のないフォルダ・`/` と `~` のどちらでも
  始まらないパスを入力して「検索」を押した場合は、モーダルを閉じずに理由を表示し、検索を始めない（FR-081）
- **EC-35**: 検索結果を表示中に、一覧のファイルがゴミ箱に入れられた・移動された（アプリの外での削除・移動を含む）場合は一覧から外す。
  検索結果へのペーストはできない（FR-087）
- **EC-36**: 検索結果を表示中に、検索起点ディレクトリそのものが削除・移動された、または起点を含むボリュームが外された場合は、起点以下の結果を
  すべて一覧から外す。検索結果の表示は続け、検索前のフォルダ・ツリーの選択・最後に表示していたフォルダは変えない。フォーカス中の結果を
  外した場合はプレビューを空にし、再生中の動画を止める。検索が終わっていて結果が0件になった場合は、該当するファイルがない旨を表示する
  （FR-087）
- **EC-103**: 起点欄が空・相対パス・存在しないパス・ファイルのパス・読み取り不能なフォルダでも、フォルダ選択は開ける。
  初期表示は FR-143 に従い、取消では元の入力を変更しない。パネルの初期位置への切り替えだけでパス欄を補正しない
- **EC-104**: 選択後から検索開始までにフォルダが削除・移動された、ボリュームが外された、読み取り権限を失った場合は、
  直接入力と同じく FR-081・EC-34 で扱う。GUI で選択したことを理由に検証を省略しない
- **EC-105**: 標準パネルでの Esc はパネルの取消だけを行い、Return はパネルの操作だけを行う。検索シートへ入力を伝播させない。
  復帰後に検索シートで Esc を押した場合は従来どおり検索シートを閉じる。既存の検索は停止しない
- **EC-106**: 日本語・空白を含むフォルダ、ルート `/`、読み取り可能な外部ボリュームのフォルダを選んだ場合も、選択した場所を表す
  絶対パスを欄へ反映する。名前の末尾の空白も保持し、引用符やエスケープ記号を付け加えず、起点欄を編集しなければ再入力せずに検索できる

- **EC-52**: 検索中に検索起点の配下のフォルダの名前を変えた場合も、検索を止めずに続け、名前を変える前に見つかった
  ファイルは新しい場所で一覧に残り、以後に見つかったファイルも新しい場所で加わる（FR-105）

## 成功基準

- **SC-016**: ローカルディスク上の 10,000 ファイルを含む階層を起点に検索しても、3 秒以内に検索が終わる。検索中も
  スクロール・選択・プレビュー・ツリーの操作が 100ms 以上止まらない（SC-004 と同じ基準）
- **SC-025**: 検索結果を表示中にフォルダの名前を変えたとき、一覧に古い名前の場所が残る結果が 0 件

- **SC-058**: 読み取り可能な通常のフォルダ・日本語名・空白を含む名前・ルート・外部ボリュームの5ケースで、
  起点パスを手入力せずに選択し、有効な検索開始が成立する。選択したフォルダと検索起点が一致するケースは5件中5件、選択の確定だけで検索が始まるケースは0件。
  合格には検索バーの起点パスと、その配下の既知の一致結果で起点を照合する。全階層の走査完了は要求せず、`/` を含め照合後は既存の解除操作で
  終了してよい。起点一致を確認する前に終了したケースは未確認とし、合格に含めない。US16-AS10 の末尾空白があるフォルダと、
  空白がない同名フォルダを併存させたケースでも、未編集の選択パスで検索でき、別フォルダを起点にした件数は0件
- **SC-059**: 標準パネルの取消（キャンセルボタンと Esc）を各5回、合計10回行い、検索シートが閉じる回数、入力値が変わる回数、
  ツリーの選択・一覧・プレビューが選択操作により変わる回数はいずれも0回となる
- **SC-060**: キーボードだけで検索シートを開き、「選択…」から標準パネルを開いて確定し、検索する一連の操作を5回行い、5回すべて完了できる。
  無効な起点からの選び直し、選択後の直接編集、選択後に消えたフォルダの拒否、古いエラーの解消、隠しフォルダ・パッケージの標準動作、
  確定時の削除済み・読み取り不能なフォルダの拒否、既存検索の継続の7ケースもすべて受け入れシナリオどおりとなる（US16-AS3・AS5・AS7・AS9・
  AS11〜AS13）

## 前提

- **A-83**: 要望の GUI は macOS 標準のフォルダ選択パネル（`NSOpenPanel`）を検索シートの子シートとして使うものと解釈する。
  独自のフォルダ一覧・場所一覧・親移動・表示切替は作らない。選択した時点では入力だけを更新し、検索開始は従来の「検索」操作にまとめる
- **A-84**: 検索起点は従来どおり1つとし、複数起点・新規フォルダ作成・最近使った起点の履歴は範囲外とする。検索条件の保存・
  モーダルを開き直したときの起点の既定値も既存の FR-081・FR-086 と contracts/settings.md に従う
- **A-85**: 標準パネルの初期表示には、現在の有効な入力、モーダルを開いた時点の既定フォルダ、ホームの順に使う。隠しフォルダは許可し、
  パッケージ・読み取り不能なフォルダは飛ばす。入力を修正せずに選び直せ、繰り返し選ぶときも現在の条件から辿れるようにする
- **A-86**: 専用のグローバルショートカットは増やさず、Tab・⇧Tab と「選択…」の Space 操作を入口とする。標準パネル内のキー操作は
  OS 標準に従う。パネルから戻ったときは「選択…」へフォーカスを戻す

- **A-06**: 検索結果のリスト形式に表示する「場所」列の並び順は、検索結果の表示中だけの一時的なものであり、保存しない。
  検索を解除したときは検索前の並び順に戻す（FR-003・084）
