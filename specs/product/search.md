# 検索

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md`
から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

- **FR-080**: ユーザーは、キーボードショートカット ⌥⌘F と「ファイル」メニューの「検索…」で、
  名前（ファイル名とフォルダ名）による検索の条件を入力するモーダル（検索のモーダル）を開けなければならない。
  - どのペインにフォーカスがあっても使えるが、フルスクリーン表示中とファイル名の変更中、
    およびプレビューのみ表示中（FR-092）は無効にする

- **FR-081**: 検索のモーダルは、冒頭の見出しとその補足説明（FR-394）、「検索キーワード」（標準の検索フィールド）、
  「検索起点ディレクトリ」（1行のテキスト入力）とその近くの「選択…」ボタン、「検索」ボタン、「キャンセル」ボタンで
  構成しなければならない。
  - 検索起点ディレクトリの既定値は、ファイルリストに表示中のフォルダの絶対パスとする。
  - 検索結果の表示中は検索前のフォルダ、zip の中を表示中は FR-069 により zip ファイルを含むフォルダとする。
  - お気に入りの見出しを選択しても一覧のフォルダを使う。
  - EC-102で一覧に F、ツリーに祖先 V を表示している場合は F を使い、V へ置き換えない。
  - 「検索」で検索を始めてモーダルを閉じる。
  - 「キャンセル」（Esc を含む）ではモーダルを閉じるだけで、ファイルリスト・ツリー・
    プレビューを取消操作によって変えてはならない。
  - モーダルを開いたときは検索キーワード欄にフォーカスを置き、
    同じ起動中に前回検索したキーワードがあれば全選択した状態で入れておく（検索起点ディレクトリは毎回上の既定値とする）。
  - 標準パネルを開いていないときは、Return で「検索」（キーワードが空のときは何もしない）、Esc で「キャンセル」
    とする。
  - Tab は検索キーワード → 検索起点ディレクトリ → 「選択…」 → キャンセル → 検索の順、⇧Tab は逆順に移動し、
    システムのキーボードナビゲーションの設定に関わらずボタンにも止まる。
  - 検索起点ディレクトリは直接入力・編集を引き続き可能とし、入力手段によらず「検索」を押したときに確かめる。
  - 直接入力では前後の空白を除き、先頭の `~` はホームフォルダ、末尾の `/` は無視して解釈する。
  - GUI 選択で反映してから起点欄を編集していない間だけは、名前の末尾の空白も含む選択した絶対パスを文字どおり使い、
    空白除去は行わない。
  - 起点欄を編集した時点で従来の直接入力の解釈へ戻す。
  - キーワードの編集や標準パネルの取消では、この区別を変えない。
  - `/` と `~` のどちらでも始まらないパス、存在しないパス、フォルダでないパス（zip ファイルを含む）、
    読み取り権限のないフォルダの場合は、モーダルを閉じずに理由を入力欄の近くに表示し、
    検索を始めてはならない（検証失敗を理由にファイルリストの表示は変えない）。
  - フォルダ選択パネルの動作は FR-141〜FR-144 に従う
- **FR-394**: 検索のモーダルの冒頭に、機能名の見出しと、その補足説明を表示しなければならない。
  - 見出しは「サブフォルダを含めて検索」（英語: `Search Including Subfolders`）とし、
    設定ウインドウの区分の見出しと同じく、標準の大きさの太字で表示する
  - 補足説明は次の文とする
    - 「検索起点ディレクトリとその下のすべてのサブフォルダから、名前が一致するファイルとフォルダを探します。」
    - 英語: `Finds files and folders whose names match, in the folder you search in and all of its subfolders.`
  - 補足説明は、設定ウインドウの補足説明（FR-223（window-layout.md））と同じく、見出しより小さい文字と、OS
    の標準の淡い（二次的な）文字色で表示する
  - 見出しと補足説明は選択・編集できず、Tab の移動先にならない（FR-081 の Tab の順は変えない）
  - 補足説明は、検索キーワード欄のアクセシビリティの説明（ヘルプ）としても提供し、
    読み上げで独立した項目として二重に読ませない
  - 表示言語を切り替えたときは、見出しと補足説明も新しい言語にする（モーダルの大きさは contracts/localization.md
    の検索シートの規則に従う）
  - 開き方（⌥⌘F・メニュー・ツールバーの検索欄の虫眼鏡（FR-390（file-list.md）））によらず同じに表示する
- **FR-082**: 検索キーワードは、ファイル名（拡張子を含む）とフォルダ名とだけ照合し、フォルダのパスは照合に含めない。
  - フォルダ名は、「.」を含む場合も名前全体を照合に使い、拡張子として扱わない。
  - ワイルドカードは `*`（0文字以上の任意の文字）と `?`（任意の1文字）とする。
  - ワイルドカードを含まないキーワードは名前への部分一致、含むキーワードは名前全体との一致とする。
  - 英字の大文字小文字と Unicode の正規化の違い（濁点の合成・分解など）は区別しない。
  - 前後の空白を除いたキーワードが空のときは「検索」ボタンを無効にする

- **FR-083**: 検索は、検索起点ディレクトリ以下のすべての階層のサブフォルダを辿って行わなければならない。
  - 一致の対象は、対応メディアファイル（FR-039。判定は FR-009 と同じく拡張子による）と、
    フォルダ（通常のフォルダの一覧にフォルダの行として表示するもの。FR-076）と、「zipファイルを表示」（FR-095）
    がオンのときの zip ファイル（FR-068。拡張子 `.zip`、大文字小文字を区別しない）とする。
  - 検索起点ディレクトリそのものは一致の対象にしない。
  - 隠しファイルと隠しフォルダ（とその中）は対象外とし、シンボリックリンクのフォルダとパッケージ（.app など）
    の中は辿らない。
  - フォルダへのシンボリックリンクとパッケージそのものは、フォルダとしても一致の対象にしない。
  - ファイルへのシンボリックリンクは、通常のフォルダの一覧と同じく名前（拡張子）で対応メディアファイルか zip
    ファイルかを判定し、一致の対象にする。
  - 名前が一致したフォルダの中も辿り続け、中のファイルとフォルダと zip
    ファイルはそれぞれの名前で照合する（親のフォルダが一致したことを理由に、中の項目を一致とはしない）。
  - 読み取り権限のないフォルダは、名前が一致すれば一致の対象にするが、中は飛ばして検索を続ける。
  - zip ファイルの中のディレクトリとファイルは照合せず、zip の中も検索しない。
  - 明示的に指定した検索起点が隠しフォルダの配下にある場合は、起点より上の隠しフォルダを理由に対象外にはしない。
  - その起点以下で現れる隠しフォルダは従来どおり中ごと飛ばし、結果から開いたフォルダのツリー同期は EC-102 に従う

- **FR-084**: システムは、検索結果（一致したファイルとフォルダ）を、
  階層の区別なく1つの一覧としてファイルリストに表示しなければならない。
  - リスト形式には「場所」列（その項目を含むフォルダの、検索起点のフォルダ名から始まるパス）を加え、FR-012
    の並べ替えの対象にする。
  - ファイル名の列で並べるときはフォルダを先頭にまとめ、
    それ以外の列ではファイルとフォルダを区別せず選択した列の順に混ぜて並べる（FR-288・A-25（file-list.md））。
  - サムネイル形式は名前だけを表示し、場所はポインタを重ねたときの説明で示す。
  - 先頭行の `..` は表示せず、⌘↑ は何もしない。
  - ファイルリストの上部に、検索結果を表示中であることと、キーワード・検索起点・
    件数（一致したファイルとフォルダの合計）を示す（同じ名前のフォルダを見分けられるよう、
    検索起点の絶対パスをツールチップで示す）。
  - 表示形式（FR-010）・並べ替え（FR-012）・複数選択と矢印キーでの移動（FR-016・FR-017）・種類フィルタ（FR-056）・
    プレビュー（FR-028〜FR-038）・フルスクリーン（FR-035〜FR-037・FR-046）は通常のフォルダと同じに使える。
  - 一致が0件（ファイルもフォルダも一致しない）の場合は、該当する項目がない旨のメッセージを、FR-060 の空のメッセージ・
    絞り込み中のメッセージと区別して表示する

- **FR-085**: 検索は UI を止めずに行い、
  見つかったファイルとフォルダから順に一覧へ追加しなければならない（並び順は現在の並べ替えに従う）。
  - 検索中は検索中であることと途中の件数（見つかったファイルとフォルダの合計）を表示し、完了したら件数を確定する。
  - 検索中もスクロール・選択・プレビュー・ツリーの操作を続けられなければならない。
  - 検索結果の表示を解除したとき（FR-086）、フォルダの行を開いたとき（FR-140）、または新しい検索を始めたときは、
    実行中の検索を止める。
  - 新しい検索の結果は前の結果を置き換える。
  - 結果の件数に上限は設けない

- **FR-086**: 検索結果を表示中に、ユーザーがツリーでフォルダ（お気に入りの項目を含む）を選択したとき、
  システムは検索結果の表示を解除し、ファイルリストをそのフォルダの一覧に切り替えなければならない（FR-007）。
  - 検索前から選択されていたフォルダの行をクリックした場合も同じく解除する。
  - 「お気に入り」の見出しの選択は、FR-065 のとおりフォルダの選択として扱わないため解除しない。
  - フルスクリーン中とファイル名の変更中を除き、ファイルリストで Esc を押した場合も同じく検索結果の表示を解除し、
    検索前のフォルダの一覧に戻す（検索中なら検索を止める）。
  - 検索結果を表示中もツリーの選択は検索前のまま変えず、検索結果と検索条件は保存しない（FR-003
    の最後に選択していたフォルダも更新しない）
- **FR-087**: 検索結果の一覧で選択したファイルとフォルダには、コピー・名前の変更・ゴミ箱に入れる・移動・複製・
  ドラッグ&ドロップ（FR-018〜FR-027）を通常のフォルダの一覧と同じに行えなければならない（フォルダの行は FR-076
  と同じく操作の対象にする）。
  - 貼り付け先のフォルダがないため、検索結果へのペースト（⌘V・⌥⌘V）は、
    フォルダの行を選択中も含めて右クリックメニューで淡色にして選べないようにし、ショートカットも何もしない。
  - ゴミ箱に入れた・移動したファイルとフォルダ、およびアプリの外で削除・移動された（元の場所から消えた）
    ファイルとフォルダは一覧から外す。
  - フォルダが消えた場合は、その中にあった検索結果（ファイルとフォルダ）もすべて外す。
  - 外したファイルがプレビュー中だった場合はプレビューを空にする。
  - 検索前のフォルダやその祖先のフォルダの行をゴミ箱に入れた・移動した場合も、検索結果の表示を続ける（EC-101）。
  - 名前を変更したファイルとフォルダは、キーワードに一致しなくなっても新しい名前で一覧に残し、
    名前を変えたフォルダの中にある検索結果は FR-105 のとおり新しい場所で表示する。
  - ただし、ファイルを対応メディアファイルの拡張子でない名前に変えた場合は、FR-083
    の対象外になるため一覧から外す（プレビュー中だった場合はプレビューを空にする）。
  - 複製で作ったファイルとフォルダや、検索の後に新しく現れたファイルとフォルダは一覧に加えない

- **FR-105**: 検索結果を表示中（検索中を含む）に、ツリーまたは検索結果の一覧で、
  検索結果の項目を含むフォルダ（検索起点そのもの、その祖先、または配下のフォルダ）か、
  検索結果のフォルダの行のフォルダの名前を変えた場合、システムは次のとおり一覧を同期しなければならない。
  - 該当するファイルとフォルダは一覧に残し、リスト形式の「場所」列とサムネイル形式のツールチップ（FR-084）
    を新しい名前で表示する。
  - 名前を変えたフォルダが検索結果の行であれば、
    その行もキーワードに一致しなくなったかどうかに関わらず新しい名前で表示する（FR-087）。
  - 検索起点そのものの名前を変えた場合は、
    検索バーの起点のフォルダ名とツールチップの絶対パスも新しい名前にする（アプリの外での削除・移動を扱う
    EC-36とは区別し、結果を外さない）。
  - 検索起点の祖先の名前を変えた場合は、検索バーのツールチップの絶対パスを新しい名前にする。
  - 並べ替えている列の値が変わった場合（「場所」列、またはフォルダの行の名前）は並べ直す。
  - 選択・プレビューは保つ。
  - 新しい場所が検索の対象（FR-083）でなくなったファイルとフォルダは一覧から外し（FR-103 の検証により、
    ツリーやファイルリストでの名前の変更ではこの場合は起きない。名前の変更を検索結果へ反映する処理の規則として定める）、
    それがプレビュー中だった場合はプレビューを空にして再生中の動画を止める（FR-087と同じ）。
  - 検索中であれば検索を止めずに続け、以後に見つかったファイルとフォルダも新しい場所で加える。
  - 名前の変更を、照合済みの項目の一致を判定し直す契機にはしない。
  - 新しい名前がキーワードに一致するようになったフォルダも、検索結果の行でなければ一覧に加えない。
  - 検索中は、名前を変えた時点でまだ照合していないフォルダを、照合する時点の名前で照合する

- **FR-139**: システムは、検索結果のフォルダの行を、通常のフォルダの一覧のフォルダの行（FR-076（file-list.md））
  と同じく表示し、扱わなければならない。
  - 行頭アイコンと縮小画像はフォルダを示す汎用アイコン、「種類」は「フォルダ」、「作成日」
    はファイルシステムの作成日時とする（A-25（file-list.md））。
  - フォルダの行を選択（フォーカス）したときはプレビューを空にし、再生中の動画を止める（FR-075（zip.md））。
  - 種類フィルタ（FR-056（file-list.md））はフォルダの行に適用せず常に表示し、FR-060（file-list.md）
    の判定ではファイルとして数えない。
  - 一致したメディアファイルが種類フィルタで1件も表示されない場合は、
    残ったフォルダの行に加えて絞り込み中のメッセージを表示する。
  - 一致したメディアファイルが元々1件もない場合は、
    フォルダの行が1つでもあれば該当する項目がない旨のメッセージも絞り込み中のメッセージも出さない。
  - フルスクリーン中の矢印キーによる移動（FR-046（preview.md））では、FR-076 と同じくフォルダの行に止まらずに飛ばす。
  - スライドショー（FR-115（preview.md））の対象にしない
- **FR-140**: ユーザーは、検索結果のフォルダの行をダブルクリックするか、フォーカス行にして ⌘↓（「ファイル」
  メニューと右クリックメニューの「中を表示」を含む）を押すことで、そのフォルダを開けなければならない。
  - 開くと、システムは検索結果の表示を終え（検索中なら止め）、ファイルリストをそのフォルダの一覧に切り替え、
    ツリーの選択をそのフォルダへ同期する（FR-078（file-list.md）。最後に選択していたフォルダ（FR-003（overview.md））
    としても保存する）。
  - キーボードフォーカスはファイルリストに残す。
  - ただし、開いたフォルダがツリーに表示されない場合は、EC-102 のとおり表示可能な最も近い祖先を選択・保存し、
    一覧と履歴の場所は開いたフォルダのままにする。
  - 開いたフォルダの一覧は、通常のフォルダの一覧と同じく先頭行の `..` と ⌘↑ を使える（FR-077（file-list.md））。
  - 履歴は FR-113 （navigation-history.md）に従い、検索結果は記録せず、
    開いたフォルダを新しい履歴として記録する（開いたフォルダが検索前の場所と同じ場合は EC-99、zip
    の中で始めた検索の場合は EC-100）。
  - フォーカス行がファイルの行のときの ⌘↓ は、従来どおり何もしない。
  - 検索結果の右クリックメニューでは、フォルダの行に「中を表示（⌘↓）」と区切り線をファイル操作の前に加え、
    「上の階層へ」は出さない
- **FR-278**: システムは、zip ファイルを一致の対象にするかどうかを、検索を始めた時点の「zipファイルを表示」（FR-095）
  の値で決めなければならない。
  - オフ（既定）の検索では zip ファイルを照合せず、結果にも件数にも含めない。
  - オンの検索では、zip ファイルの名前（拡張子を含む）を FR-082 の規則（部分一致・ワイルドカード・
    大文字小文字と正規化の違いを区別しない）でキーワードと照合し、一致した zip ファイルを検索結果の行にする。
  - その検索の間、決めた対象は変えない。
  - 検索結果の表示中や検索中に設定を切り替えても、既存の結果・実行中の検索・件数は変えず、
    切り替えた値は次に始める検索から使う。
  - 検索を終えて検索前の一覧に戻ったときは、切り替え後の値に従う（FR-095）
- **FR-279**: システムは、検索結果の zip ファイルの行を、通常の一覧の zip ファイルの行（FR-068・FR-075（zip.md））
  と同じく表示し、扱わなければならない。
  - 行頭アイコンと縮小画像は zip ファイルを示す汎用アイコン、「種類」は通常の一覧と同じ zip の種類名、「作成日」
    「サイズ」「変更日」（FR-273 の列の設定に従って表示する）はファイルシステムの値とする。
  - 「場所」列とサムネイル形式のツールチップ（FR-084）、名前の変更への追随（FR-105）、変更通知への追随（FR-232）は、
    ファイルの行と同じに扱う。

## 主なエンティティ

- **検索条件**: 検索キーワード（ワイルドカード `*`・`?` を含められる）と検索起点ディレクトリ。保存しない
- **検索結果**: 検索条件に一致したメディアファイルとフォルダの一覧と、各項目の場所（検索起点のフォルダ名から始まるパス）、
  状態（検索中／完了）、件数（ファイルとフォルダの合計）。
  - ツリーでフォルダを選択するか、フォルダの行を開くと解除される。
  - 元の場所から消えた項目（消えたフォルダの中の項目を含む）は外れ、新しく現れた項目は加わらない（FR-087）

### US56 検索結果の zip ファイルを開く・操作する（P2）

- **US56-AS2**: **Given** 検索結果の zip ファイルの行にフォーカスがある,
  - **When** 画面と右クリックメニューを見る,

    の種類名になる。右クリックメニューには「中を表示（⌘↓）」と区切り線がファイル操作の前に加わり、「上の階層へ」

- **US56-AS3**: **Given** 検索結果で動画を再生中,
  - **When** 矢印キーで zip ファイルの行へ選択を移す,

- **US56-AS4**: **Given** 「画像のみ表示」をオンにしている,

### US43 検索結果でも置き換え後の内容を見る（P3）

## エッジケース

- **EC-32**: 検索で一致するファイルもフォルダも1件もない場合は、該当する項目がない旨を表示し、
  フォルダが空のときのメッセージ・絞り込み中のメッセージとは区別する（FR-084）

- **EC-33**: 検索中に読み取り権限のないフォルダに当たった場合は、そのフォルダの中を飛ばして検索を続ける。
  - そのフォルダの名前が一致すれば、行として表示する（FR-083・EC-91）

- **EC-34**: 検索起点ディレクトリに存在しないパス・フォルダでないパス（zip ファイルを含む）・
  読み取り権限のないフォルダ・`/` と `~` のどちらでも始まらないパスを入力して「検索」を押した場合は、
  モーダルを閉じずに理由を表示し、検索を始めない（FR-081）
- **EC-35**: 検索結果を表示中に、一覧のファイルまたはフォルダがゴミ箱に入れられた・移動された（アプリの外での削除・
  移動を含む）場合は一覧から外す。
  - フォルダの場合は、その中にあった検索結果もすべて外す。
  - 検索結果へのペーストはできない（FR-087）

- **EC-36**: 検索結果を表示中に、検索起点ディレクトリそのものが削除・移動された、
  または起点を含むボリュームが外された場合は、起点以下の結果（ファイルとフォルダ）をすべて一覧から外す。
  - 検索結果の表示は続け、検索前のフォルダ・ツリーの選択・最後に表示していたフォルダは変えない。
  - フォーカス中の結果を外した場合はプレビューを空にし、再生中の動画を止める。
  - 検索が終わっていて結果が0件になった場合は、該当する項目がない旨を表示する（FR-087）

- **EC-103**: 起点欄が空・相対パス・存在しないパス・ファイルのパス・読み取り不能なフォルダでも、フォルダ選択は開ける。
  - 初期表示は FR-143 に従い、取消では元の入力を変更しない。
  - パネルの初期位置への切り替えだけでパス欄を補正しない
- **EC-104**: 選択後から検索開始までにフォルダが削除・移動された、ボリュームが外された、読み取り権限を失った場合は、
  直接入力と同じく FR-081・EC-34 で扱う。
  - GUI で選択したことを理由に検証を省略しない
- **EC-105**: 標準パネルでの Esc はパネルの取消だけを行い、Return はパネルの操作だけを行う。
  - 検索シートへ入力を伝播させない。
  - 復帰後に検索シートで Esc を押した場合は従来どおり検索シートを閉じる。
  - 既存の検索は停止しない
- **EC-106**: 日本語・空白を含むフォルダ、ルート `/`、読み取り可能な外部ボリュームのフォルダを選んだ場合も、
  選択した場所を表す絶対パスを欄へ反映する。
  - 名前の末尾の空白も保持し、引用符やエスケープ記号を付け加えず、起点欄を編集しなければ再入力せずに検索できる

- **EC-52**: 検索中に検索起点の配下のフォルダの名前を変えた場合も、検索を止めずに続け、
  名前を変える前に見つかったファイルとフォルダは新しい場所で一覧に残り、
  以後に見つかったファイルとフォルダも新しい場所で加わる（FR-105）

- **EC-91**: 読み取り権限のないフォルダも、名前が一致すれば行として表示する（中は辿らない。FR-083）。
  - その行を開いたときの扱いは、通常のフォルダの一覧で読み取り権限のないフォルダを開いたときと同じとする
- **EC-92**: 名前が一致したフォルダの中も辿り続け、中のファイルとフォルダはそれぞれの名前で照合する。
  - 親のフォルダが一致したことを理由に、中の項目を一致とはしない（FR-083）
- **EC-93**: 検索中にフォルダの行を開いた場合は、検索を止めてからそのフォルダの一覧に切り替える（FR-140）
- **EC-94**: 検索結果を表示中に、ツリーまたは一覧でフォルダの名前を変え、
  新しい名前がキーワードに一致するようになっても、そのフォルダが検索結果の行でなければ一覧に加えない。
  - 検索中は、名前を変えた時点でまだ照合していないフォルダを、照合する時点の名前で照合する（FR-105）
- **EC-95**: 検索結果を表示中に、フォルダの行のフォルダがアプリの外で削除・移動された場合は、
  その行と中にあった検索結果をすべて外す。
  - プレビュー中のファイルが外れた場合はプレビューを空にし、再生中の動画を止める。
  - 新しく作られたフォルダは一覧に加えない（FR-087）
- **EC-96**: 一致したのがフォルダだけでメディアファイルが0件の場合は、該当する項目がない旨のメッセージを出さない。
  - このとき種類フィルタがオンでも、一致したメディアファイルが元々ないため絞り込み中のメッセージは出さない（FR-139）
- **EC-97**: フォルダの名前に「.」が含まれていても、名前全体をキーワードと照合し、拡張子として扱わない。
  - たとえば `2024.10_trip` は `2024.10` で部分一致し、`photos.jpg` という名前のフォルダは `*.jpg`
    に一致する（FR-082）
- **EC-98**: 別の場所にある同じ名前のフォルダは、それぞれ別の行として表示し、「場所」
  列（サムネイル形式ではツールチップ）で見分けられる（FR-084）
- **EC-99**: 検索起点を検索前の場所 A の祖先にして、検索結果の A のフォルダの行を開いた場合は、A の一覧になるが、
  新しい履歴は記録しない。
  - 検索結果の表示を終えたときの表示の状態を現在の履歴（A）に反映してから比べるため、
    操作の後の状態が現在の履歴と同じ場所・同じ表示の状態になる（FR-107（navigation-history.md））。
  - 続けて「戻る」を実行すると A より前の履歴へ移り、戻る側に履歴がなければ「戻る」は無効になる（FR-113・FR-140）
- **EC-100**: zip の中の階層 D を表示中に始めた検索でフォルダの行 F を開いた場合は、F を D の履歴の次に記録する。
  - 続けて「戻る」を実行すると D へ戻る。
  - Esc・「戻る」で検索結果の表示を終えたとき（FR-113）とは異なり、zip
    ファイルを含むフォルダの一覧を履歴に記録しない（FR-113・FR-140）
- **EC-101**: 検索結果を表示中に、検索結果の一覧から、検索前のフォルダ（zip の中で始めた検索では zip
  ファイルを含むフォルダ）そのもの、またはその祖先のフォルダの行をゴミ箱に入れた、
  または移動した（ツリーのフォルダへのドラッグ&ドロップを含む）場合は、検索結果の表示を続け、
  その行と中にあった検索結果を一覧から外すだけにする。
  - 検索前のフォルダ・ツリーの選択・最後に表示していたフォルダ（FR-003（overview.md））は変えない（EC-36 と同じ）。
  - 続けて Esc・「戻る」で検索結果の表示を終えた場合は、検索前のフォルダが元の場所に存在しないため、
    存在しないフォルダを開こうとした場合と同じに扱い、その場所を履歴に記録しない（EC-62 （navigation-history.md））。
  - ゴミ箱に入れた・移動した時点で、そのフォルダと配下の場所は FR-109（navigation-history.md）
    のとおり履歴から取り除かれている。
  - ツリーから同じフォルダをゴミ箱に入れた場合は、従来どおり FR-079（file-operations.md）
    に従い親フォルダへ移る（FR-087）
- **EC-102**: 検索結果から開いたフォルダ F が、隠しフォルダの配下などの理由でツリーの実際の階層に表示されない場合は、
  ファイルリストには F の一覧を表示し、ツリーでは表示可能な最も近い祖先 V を選択する。
  - 最後に選択していたフォルダ（FR-003 （overview.md））としても V を保存する。
  - 同期は一覧の読み込みを待たせず、キーボードフォーカスはファイルリストに残す。
  - 履歴には F を記録し、V への移動や履歴の追加は行わない。
  - 検索結果から開く場合に限る FR-078（file-list.md）の例外とし、
    お気に入りから開く場合など既存の経路は変更しない（FR-140）
- **EC-191**: 名前が `x.zip` の**フォルダ**は、これまでどおりフォルダの行として一致する（zip ファイルの行にはしない）。
  - 「zipファイルを表示」（FR-095（zip.md））にも従わない（FR-083）
- **EC-192**: 中身が zip として読めないファイル（壊れた・拡張子だけが `.zip` のファイル）も、
  名前が一致すれば行として表示する。
  - 判定は通常の一覧と同じく拡張子による。
  - 開いたときは通常の一覧の zip ファイルと同じ扱いになる（FR-069（zip.md）・FR-083）
- **EC-193**: 読み取り権限のない zip ファイルも、名前が一致すれば行として表示する（FR-083）
- **EC-194**: 検索の途中で「zipファイルを表示」を切り替えても、実行中の検索の対象は変わらない（FR-278・US55-AS2）
- **EC-195**: zip の中を表示中に始めた検索の起点・履歴の扱い（EC-100）は変えない。
  - 起点は zip ファイルを含むフォルダで、その zip ファイル自身も名前が一致すれば（設定がオンのとき）行になる（FR-083・
    FR-278）

## 成功基準

## 前提

- **A-83**: 要望の GUI は macOS 標準のフォルダ選択パネル（`NSOpenPanel`）
  を検索シートの子シートとして使うものと解釈する。
  - 独自のフォルダ一覧・場所一覧・親移動・表示切替は作らない。
  - 選択した時点では入力だけを更新し、検索開始は従来の「検索」操作にまとめる
- **A-84**: 検索起点は従来どおり1つとし、複数起点・新規フォルダ作成・最近使った起点の履歴は範囲外とする。
  - 検索条件の保存・モーダルを開き直したときの起点の既定値も既存の FR-081・FR-086 と contracts/settings.md に従う
- **A-85**: 標準パネルの初期表示には、現在の有効な入力、モーダルを開いた時点の既定フォルダ、ホームの順に使う。
  - 隠しフォルダは許可し、パッケージ・読み取り不能なフォルダは飛ばす。
  - 入力を修正せずに選び直せ、繰り返し選ぶときも現在の条件から辿れるようにする
- **A-86**: 専用のグローバルショートカットは増やさず、Tab・⇧Tab と「選択…」の Space 操作を入口とする。
  - 標準パネル内のキー操作は OS 標準に従う。
  - パネルから戻ったときは「選択…」へフォーカスを戻す

- **A-06**: 検索結果のリスト形式に表示する「場所」列の並び順は、検索結果の表示中だけの一時的なものであり、保存しない。
  - 検索を解除したときは検索前の並び順に戻す（FR-003・084）

- **A-76**: 「フォルダも検索対象にする」は、フォルダ名をキーワードと照合し、
  一致したフォルダを検索結果の行として表示する意味と解釈した。
  - フォルダのパス（祖先のフォルダ名）との照合は引き続き行わず、親のフォルダが一致しても中のファイルを一致とはしない。
  - パスで照合すると、一致したフォルダの配下がすべて結果に入り、目的のフォルダを見つけにくくなるためである
- **A-77**: フォルダの照合は常に行い、ファイルだけ・フォルダだけに絞る切り替え（検索のモーダルのチェックボックスなど）
  は設けない。
  - 要望が「フォルダも対象にする」であり、検索のモーダルの入力を増やさないためである。
  - 種類フィルタはフォルダの行を隠さない（FR-076 と同じ）ため、フォルダだけ・
    ファイルだけを表示する手段は本機能の範囲外とする
- **A-78**: 一致の対象にするフォルダは、通常のフォルダの一覧にフォルダの行として出るもの（FR-076）に合わせる。
  - 隠しフォルダ・パッケージ・フォルダへのシンボリックリンクは対象外とする。
  - 検索起点そのものは検索バーで示すため、行にしない
- **A-80**: フォルダの行を開くと検索結果の表示を終え、検索結果は従来どおり履歴に記録しない（FR-113）。
  - 開いたフォルダから検索結果へ戻る操作（検索結果を保ったまま中を見る操作）は範囲外とし、必要なら同じ条件で検索し直す
- **A-81**: 検索バーの件数は、一致したファイルとフォルダと zip ファイルの合計とし、内訳は表示しない。
  - 種類フィルタと件数の関係は従来の検索結果と同じとする
- **A-82**: フォルダの行のファイル操作・右クリックメニュー・キー操作は、通常のフォルダの一覧のフォルダの行（FR-076・
  contracts/keyboard-and-menus.md）と同じとし、検索結果に固有の制限（ペーストできない、「上の階層へ」がない。FR-087）
  だけを加える
- **A-171**: 対象にするのは、通常のフォルダの一覧で zip ファイルの行になるもの（FR-068。拡張子 `.zip`、
  大文字小文字を区別しない）に合わせる。
  - 拡張子で判定し、中身が zip として読めるかは確かめない。
  - `.zipx` や `.zip.bak` など拡張子が `.zip` でないファイルは対象にしない
- **A-172**: zip の中のディレクトリ名・ファイル名の検索（zip の中を辿る検索）は範囲外とする。
  - 検索の速度と、zip の文字コード判定（FR-074）・読み取りを検索に持ち込まないためである
- **A-173**: 検索結果の zip ファイルを対象にするかは、検索を始めた時点の「zipファイルを表示」の値で決め、
  検索の間は変えない。
  - 検索条件を保存しない（FR-086）規則と、オンに切り替えても検索し直さずには zip
    ファイルを増やせない（途中の値で一部だけ含まれる状態を避ける）ことによる
- **A-174**: 種類フィルタ（FR-056）は zip ファイルの行を隠さない。
  - 通常の一覧の zip ファイル（FR-056 の末尾）とフォルダの行（FR-139）と同じ扱いに揃える
- **A-175**: 検索結果の zip ファイルの行を開く操作は、フォルダの行を開く操作（FR-140）
  と同じ流れ（検索結果の表示を終え、履歴は検索結果を記録せずに開いた場所を新しい履歴にする）とする。
  - 検索結果を保ったまま zip の中を見る操作は範囲外とする（A-80 と同じ）
- **A-176**: zip ファイルを検索結果から開いたあと、zip の最上位から ⌘↑ で戻る一覧では、「zipファイルを表示」
  がオフであれば zip ファイルの行が表示されない（FR-070）。
  - その場合の扱いは FR-070 に従い、この feature では変えない
