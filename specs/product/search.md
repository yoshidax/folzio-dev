# 検索

この領域の現在の仕様（Living spec）。ID は `specs/001-three-pane-media-viewer/spec.md` から引き継いだもの。ほかの領域は [README.md](README.md) を参照。

## 機能要件

- **FR-080**: ユーザーは、キーボードショートカット ⌘F と「ファイル」メニューの「検索…」で、名前（ファイル名とフォルダ名）による
  検索の条件を入力するモーダル（検索のモーダル）を開けなければならない。どのペインにフォーカスがあっても使えるが、フルスクリーン
  表示中とファイル名の変更中、およびプレビューのみ表示中（FR-092）は無効にする

- **FR-081**: 検索のモーダルは、「検索キーワード」（標準の検索フィールド）、「検索起点ディレクトリ」（1行のテキスト入力）と
  その近くの「選択…」ボタン、「検索」ボタン、「キャンセル」ボタンで構成しなければならない。検索起点ディレクトリの既定値は、
  ファイルリストに表示中のフォルダの絶対パスとする。検索結果の表示中は検索前のフォルダ、zip の中を表示中は FR-069 により
  zip ファイルを含むフォルダとする。お気に入りの見出しを選択しても一覧のフォルダを使う。EC-102で
  一覧に F、ツリーに祖先 V を表示している場合は F を使い、V へ置き換えない。「検索」で検索を始めてモーダルを閉じる。
  「キャンセル」（Esc を含む）ではモーダルを閉じるだけで、ファイルリスト・ツリー・プレビューを取消操作によって変えてはならない。
  モーダルを開いたときは検索キーワード欄にフォーカスを置き、同じ起動中に前回検索したキーワードがあれば全選択した状態で入れておく
  （検索起点ディレクトリは毎回上の既定値とする）。標準パネルを開いていないときは、Return で「検索」（キーワードが空のときは何もしない）、
  Esc で「キャンセル」とする。Tab は検索キーワード → 検索起点ディレクトリ → 「選択…」 → キャンセル → 検索の順、⇧Tab は逆順に移動し、
  システムのキーボードナビゲーションの設定に関わらずボタンにも止まる。検索起点ディレクトリは直接入力・編集を引き続き可能とし、
  入力手段によらず「検索」を押したときに確かめる。直接入力では前後の空白を除き、先頭の `~` はホームフォルダ、末尾の `/` は無視して解釈する。
  GUI 選択で反映してから起点欄を編集していない間だけは、名前の末尾の空白も含む選択した絶対パスを文字どおり使い、空白除去は行わない。
  起点欄を編集した時点で従来の直接入力の解釈へ戻す。キーワードの編集や標準パネルの取消では、この区別を変えない。`/` と `~` の
  どちらでも始まらないパス、存在しないパス、フォルダでないパス（zip ファイルを含む）、読み取り権限のないフォルダの場合は、モーダルを
  閉じずに理由を入力欄の近くに表示し、検索を始めてはならない（検証失敗を理由にファイルリストの表示は変えない）。フォルダ選択パネルの
  動作は FR-141〜FR-144 に従う
- **FR-082**: 検索キーワードは、ファイル名（拡張子を含む）とフォルダ名とだけ照合し、フォルダのパスは照合に含めない。フォルダ名は、
  「.」を含む場合も名前全体を照合に使い、拡張子として扱わない。ワイルドカードは `*`（0文字以上の任意の文字）と `?`（任意の1文字）と
  する。ワイルドカードを含まないキーワードは名前への部分一致、含むキーワードは名前全体との一致とする。英字の大文字小文字と
  Unicode の正規化の違い（濁点の合成・分解など）は区別しない。前後の空白を除いたキーワードが空のときは「検索」ボタンを無効にする

- **FR-083**: 検索は、検索起点ディレクトリ以下のすべての階層のサブフォルダを辿って行わなければならない。一致の対象は、
  対応メディアファイル（FR-039。判定は FR-009 と同じく拡張子による）と、フォルダ（通常のフォルダの一覧にフォルダの行として
  表示するもの。FR-076）とする。検索起点ディレクトリそのものは一致の対象にしない。隠しファイルと隠しフォルダ（とその中）は
  対象外とし、シンボリックリンクのフォルダとパッケージ（.app など）の中は辿らない。フォルダへのシンボリックリンクとパッケージ
  そのものは、フォルダとしても一致の対象にしない。ファイルへのシンボリックリンクは、通常のフォルダの一覧と同じく名前（拡張子）で
  対応メディアファイルかを判定し、一致の対象にする。名前が一致したフォルダの中も辿り続け、中のファイルとフォルダはそれぞれの
  名前で照合する（親のフォルダが一致したことを理由に、中の項目を一致とはしない）。読み取り権限のないフォルダは、名前が一致すれば
  一致の対象にするが、中は飛ばして検索を続ける。zip ファイル（FR-068）は対応メディアファイルでもフォルダでもないため一致の対象に
  せず、zip の中も検索しない。明示的に指定した検索起点が隠しフォルダの配下にある場合は、起点より上の隠しフォルダを理由に対象外にはしない。
  その起点以下で現れる隠しフォルダは従来どおり中ごと飛ばし、結果から開いたフォルダのツリー同期は EC-102 に従う

- **FR-084**: システムは、検索結果（一致したファイルとフォルダ）を、階層の区別なく1つの一覧としてファイルリストに表示しなければ
  ならない。リスト形式には「場所」列（その項目を含むフォルダの、検索起点のフォルダ名から始まるパス）を加え、FR-012 の並べ替えの
  対象にする。ファイルとフォルダは区別せず、選択した列の順に混ぜて並べる（A-25（file-list.md））。サムネイル形式は名前だけを
  表示し、場所はポインタを重ねたときの説明で示す。先頭行の `..` は表示せず、⌘↑ は何もしない。ファイルリストの上部に、検索結果を
  表示中であることと、キーワード・検索起点・件数（一致したファイルとフォルダの合計）を示す（同じ名前のフォルダを見分けられるよう、
  検索起点の絶対パスをツールチップで示す）。表示形式（FR-010）・並べ替え（FR-012）・複数選択と矢印キーでの移動（FR-016・FR-017）・
  種類フィルタ（FR-056）・プレビュー（FR-028〜FR-038）・フルスクリーン（FR-035〜FR-037・FR-046）は通常のフォルダと同じに使える。
  一致が0件（ファイルもフォルダも一致しない）の場合は、該当する項目がない旨のメッセージを、FR-060 の空のメッセージ・
  絞り込み中のメッセージと区別して表示する

- **FR-085**: 検索は UI を止めずに行い、見つかったファイルとフォルダから順に一覧へ追加しなければならない（並び順は現在の並べ替えに
  従う）。検索中は検索中であることと途中の件数（見つかったファイルとフォルダの合計）を表示し、完了したら件数を確定する。検索中も
  スクロール・選択・プレビュー・ツリーの操作を続けられなければならない。検索結果の表示を解除したとき（FR-086）、フォルダの行を
  開いたとき（FR-140）、または新しい検索を始めたときは、実行中の検索を止める。新しい検索の結果は前の結果を置き換える。結果の件数に
  上限は設けない

- **FR-086**: 検索結果を表示中に、ユーザーがツリーでフォルダ（お気に入りの項目を含む）を選択したとき、システムは検索結果の表示を
  解除し、ファイルリストをそのフォルダの一覧に切り替えなければならない（FR-007）。検索前から選択されていたフォルダの行を
  クリックした場合も同じく解除する。「お気に入り」の見出しの選択は、FR-065 のとおりフォルダの選択として扱わないため解除しない。
  フルスクリーン中とファイル名の変更中を除き、ファイルリストで Esc を押した場合も同じく検索結果の表示を解除し、検索前のフォルダの一覧に戻す
  （検索中なら検索を止める）。検索結果を表示中もツリーの選択は検索前のまま変えず、検索結果と検索条件は保存しない（FR-003 の最後に
  選択していたフォルダも更新しない）
- **FR-087**: 検索結果の一覧で選択したファイルとフォルダには、コピー・名前の変更・ゴミ箱に入れる・移動・複製・ドラッグ&ドロップ
  （FR-018〜FR-027）を通常のフォルダの一覧と同じに行えなければならない（フォルダの行は FR-076 と同じく操作の対象にする）。
  貼り付け先のフォルダがないため、検索結果へのペースト（⌘V・⌥⌘V）は、フォルダの行を選択中も含めて右クリックメニューで淡色にして
  選べないようにし、ショートカットも何もしない。ゴミ箱に入れた・移動したファイルとフォルダ、およびアプリの外で削除・移動された
  （元の場所から消えた）ファイルとフォルダは一覧から外す。フォルダが消えた場合は、その中にあった検索結果（ファイルとフォルダ）も
  すべて外す。外したファイルがプレビュー中だった場合はプレビューを空にする。検索前のフォルダやその祖先のフォルダの行を
  ゴミ箱に入れた・移動した場合も、検索結果の表示を続ける（EC-101）。名前を変更したファイルとフォルダは、キーワードに
  一致しなくなっても新しい名前で一覧に残し、名前を変えたフォルダの中にある検索結果は FR-105 のとおり新しい場所で表示する。
  ただし、ファイルを対応メディアファイルの拡張子でない名前に変えた場合は、FR-083 の対象外になるため一覧から外す（プレビュー中
  だった場合はプレビューを空にする）。複製で作ったファイルとフォルダや、検索の後に新しく現れたファイルとフォルダは一覧に加えない

- **FR-105**: 検索結果を表示中（検索中を含む）に、ツリーまたは検索結果の一覧で、検索結果の項目を含むフォルダ（検索起点そのもの、
  その祖先、または配下のフォルダ）か、検索結果のフォルダの行のフォルダの名前を変えた場合、システムは次のとおり一覧を同期しなければ
  ならない。
  該当するファイルとフォルダは一覧に残し、リスト形式の「場所」列とサムネイル形式のツールチップ（FR-084）を新しい名前で表示する。
  名前を変えたフォルダが検索結果の行であれば、その行もキーワードに一致しなくなったかどうかに関わらず新しい名前で表示する（FR-087）。
  検索起点そのものの名前を変えた場合は、検索バーの起点のフォルダ名とツールチップの絶対パスも新しい名前にする（アプリの外での
  削除・移動を扱う EC-36とは区別し、結果を外さない）。検索起点の祖先の名前を変えた場合は、検索バーのツールチップの
  絶対パスを新しい名前にする。並べ替えている列の値が変わった場合（「場所」列、またはフォルダの行の名前）は並べ直す。
  選択・プレビューは保つ。
  新しい場所が検索の対象（FR-083）でなくなったファイルとフォルダは一覧から外し（FR-103 の検証により、ツリーやファイルリストでの
  名前の変更ではこの場合は起きない。名前の変更を検索結果へ反映する処理の規則として定める）、それがプレビュー中だった場合は
  プレビューを空にして再生中の動画を止める（FR-087と同じ）。検索中であれば検索を止めずに続け、以後に見つかったファイルと
  フォルダも新しい場所で加える。名前の変更を、照合済みの項目の一致を判定し直す契機にはしない。新しい名前がキーワードに一致する
  ようになったフォルダも、検索結果の行でなければ一覧に加えない。検索中は、名前を変えた時点でまだ照合していないフォルダを、
  照合する時点の名前で照合する

- **FR-139**: システムは、検索結果のフォルダの行を、通常のフォルダの一覧のフォルダの行（FR-076（file-list.md））と同じく表示し、
  扱わなければならない。行頭アイコンと縮小画像はフォルダを示す汎用アイコン、「種類」は「フォルダ」、「作成日」はファイルシステムの
  作成日時とする（A-25（file-list.md））。フォルダの行を選択（フォーカス）したときはプレビューを空にし、再生中の動画を止める
  （FR-075（zip.md））。種類フィルタ（FR-056（file-list.md））はフォルダの行に適用せず常に表示し、FR-060（file-list.md）の判定では
  ファイルとして数えない。一致したメディアファイルが種類フィルタで1件も表示されない場合は、残ったフォルダの行に加えて絞り込み中の
  メッセージを表示する。一致したメディアファイルが元々1件もない場合は、フォルダの行が1つでもあれば該当する項目がない旨の
  メッセージも絞り込み中のメッセージも出さない。フルスクリーン中の矢印キーによる移動（FR-046（preview.md））では、FR-076 と同じく
  フォルダの行に止まらずに飛ばす。スライドショー（FR-115（preview.md））の対象にしない
- **FR-140**: ユーザーは、検索結果のフォルダの行をダブルクリックするか、フォーカス行にして ⌘↓（「ファイル」メニューと右クリック
  メニューの「中を表示」を含む）を押すことで、そのフォルダを開けなければならない。開くと、システムは検索結果の表示を終え
  （検索中なら止め）、ファイルリストをそのフォルダの一覧に切り替え、ツリーの選択をそのフォルダへ同期する（FR-078（file-list.md）。
  最後に選択していたフォルダ（FR-003（overview.md））としても保存する）。キーボードフォーカスはファイルリストに残す。
  ただし、開いたフォルダがツリーに表示されない場合は、EC-102 のとおり表示可能な最も近い祖先を選択・保存し、一覧と履歴の場所は
  開いたフォルダのままにする。
  開いたフォルダの一覧は、通常のフォルダの一覧と同じく先頭行の `..` と ⌘↑ を使える（FR-077（file-list.md））。履歴は FR-113
  （navigation-history.md）に従い、検索結果は記録せず、開いたフォルダを新しい履歴として記録する（開いたフォルダが検索前の場所と
  同じ場合は EC-99、zip の中で始めた検索の場合は EC-100）。フォーカス行がファイルの行の
  ときの ⌘↓ は、従来どおり何もしない。検索結果の右クリックメニューでは、フォルダの行に「中を表示（⌘↓）」と区切り線をファイル操作の
  前に加え、「上の階層へ」は出さない
- **FR-232**: 検索結果の一覧を表示中に変更が通知された場合、システムは、通知のあったフォルダの下にある検索結果について内容の置き換えを
  確かめ、FR-228・FR-229（file-list.md）と FR-230（preview.md）をフォルダの一覧と同じく適用しなければならない。消えた結果を外す規則
  （FR-087）と、結果の並びと選択は変えない

### 検索起点フォルダの選択

- **FR-141**: 「選択…」を押すと、macOS 標準のフォルダ選択パネル（`NSOpenPanel`）を検索シートの子シートとして開かなければならない。
  パネルは既存の1つのフォルダを選ぶ用途に構成し、通常ファイル・zip ファイルを選択対象にせず、複数選択と新規フォルダ作成を提供しない。
  パッケージはフォルダとして辿れず、選択できない。隠し項目は標準パネルの動作に従い、既定では非表示、⌘⇧. で表示でき、
  隠しフォルダも選択できる。パネルで「選択」を押すとパネルを閉じ、選択 URL の存在・フォルダであること・読み取り可否を
  UI スレッドの外で再検証する。成功した場合だけ検索起点欄の全体を選択した絶対パスで置き換え、以前の起点に対する検証エラーを消す。
  キーワードを保ち、検索は開始しない。失敗した場合は選択 URL を反映せず、検索シートを開いたまま理由を表示・読み上げ、
  起点欄とキーワードを保持して選び直し・取消を可能にする。確定後も検索時の再検証は省略しない。GUI 選択の表示制限を
  直接入力の検索起点の検証へ追加してはならない
- **FR-142**: 標準パネルで「選択」を押したときは、検索起点欄の全体を選択したフォルダの絶対パスで置き換え、
  以前の起点に対する検証エラーを消さなければならない。キーワードを保ち、パネルだけを閉じる。取消（Esc を含む）と検証失敗では、
  検索シートを開く直前の起点欄・キーワードを保つ。開く・確定・取消のいずれでも検索を開始せず、選択操作を理由にツリーの選択・
  ファイルリスト・プレビューを変更しない。既存の検索が進行中でも、この操作だけでは停止・再開始・置換しない。「変えない」は
  選択操作による変更を指し、既存検索の進行と結果の更新（FR-085）、外部変更の反映（FR-042、overview.md）は継続する。
  新しい検索を有効な条件で開始した時点で FR-085 に従い置き換える。選択後も起点欄を直接編集でき、検索には最新の欄の値を
  FR-081 の規則で解釈して使う。GUI 選択後に起点欄を編集したかどうかは検索シート内だけで扱い、シートを閉じたら破棄する
  （検索条件の非保存は FR-086・contracts/settings.md に従う）
- **FR-143**: 標準パネルの初期表示フォルダは、次の優先順で決めなければならない。（1）現在の起点欄を FR-081 と同じ規則
  （未編集の GUI 選択パスは文字どおり、それ以外は空白・`~`・末尾 `/` の解釈）で解釈した、存在し読み取り可能なフォルダ、
  （2）検索シートを開いた時点の既定フォルダ（存在し読み取り可能な場合）、（3）ユーザーのホームフォルダ。各候補は存在・フォルダ・
  読取りを確かめ、パッケージと読み取り不能なフォルダは飛ばして次へ進む。隠しフォルダは許可する。初期表示のために起点欄を書き換えず、
  パネルを再度開くときも現在の起点欄を優先する。（2）は FR-081 の既定値を開いた時点で捕捉し、後からツリーの選択や一覧の変化で
  置き換えない。EC-102 の F が無効なら、（1）と（2）の F を飛ばしてホームへ進み、ツリーの V を追加候補にはしない。
  取消では起点欄の F を保持する。いずれの候補も利用できない場合は検索シートを保ち、起点欄の近くに理由を表示して直接入力・
  再試行を可能にする。初期位置の解決中も親の「検索」は利用できる。空キーワードの無操作を除き検索操作を受理した時点で
  保留中のパネル提示を失効させ、その後で検索条件を検証する。失効した解決の成功・失敗は、検索検証との完了順によらず
  パネルの提示や親のエラー変更に使わない。検索検証に失敗しても旧依頼を復活させず、親で理由を示して選択操作の再試行を可能にする。
  標準パネルを表示済みなら FR-144 に従い親の検索を受理しない
- **FR-144**: 新しいフォルダ選択操作はキーボードだけで利用でき、「選択…」にフォーカスがあるとき Space で標準パネルを開けなければならない。
  標準パネルでは OS 標準のキーボード操作で階層移動・単一フォルダの選択・確定・取消ができる。パネル表示中は検索シートを操作できず、
  Return・Esc はパネルだけで処理する。確定・取消・検証失敗の後は「選択…」へフォーカスを戻す。ボタンは検索起点フォルダを選ぶ操作で
  あると分かるラベルでスクリーンリーダーから識別でき、パネル自体の標準のアクセシビリティを使う

## 主なエンティティ

- **検索条件**: 検索キーワード（ワイルドカード `*`・`?` を含められる）と検索起点ディレクトリ。保存しない
- **検索結果**: 検索条件に一致したメディアファイルとフォルダの一覧と、各項目の場所（検索起点の
  フォルダ名から始まるパス）、状態（検索中／完了）、件数（ファイルとフォルダの合計）。ツリーでフォルダを選択するか、フォルダの行を
  開くと解除される。元の場所から消えた項目（消えたフォルダの中の項目を含む）は外れ、新しく現れた項目は加わらない（FR-087）

### US15 フォルダを名前で探して開く（P1）

- **US15-AS7**: **Given** 検索結果にフォルダの行 F と、F の中で一致したファイル g がある, **When** 一覧で F の名前を `zzz` に変える, **Then** F の行はキーワードに一致しなくなっても `zzz` として一覧に残り、g の「場所」列も新しい名前で表示される
- **US15-AS8**: **Given** 検索結果にフォルダの行 F と、F の中で一致したファイル g がある, **When** 一覧で F をゴミ箱に入れる, **Then** F の行と g が一覧から外れる。g をプレビュー中だった場合はプレビューが空になる

- **US15-AS10**: **Given** フォルダ2件とファイル3件が一致する, **When** 検索が終わる, **Then** 検索バーの件数は「5 件」になる。一致がフォルダ1件だけの場合も、該当する項目がない旨のメッセージは出ない

### US43 検索結果でも置き換え後の内容を見る（P3）

- **US43-AS1**: **Given** 検索結果の一覧で画像 D をプレビュー中, **When** アプリの外で D を同じパスの別の内容の画像で上書きする,
  **Then** 選択し直さなくても、D のプレビューとサムネイルが上書き後の内容に変わる。検索結果の並びと選択は変わらない

## エッジケース

- **EC-32**: 検索で一致するファイルもフォルダも1件もない場合は、該当する項目がない旨を表示し、フォルダが空のときのメッセージ・
  絞り込み中のメッセージとは区別する（FR-084）

- **EC-33**: 検索中に読み取り権限のないフォルダに当たった場合は、そのフォルダの中を飛ばして検索を続ける。そのフォルダの名前が
  一致すれば、行として表示する（FR-083・EC-91）

- **EC-34**: 検索起点ディレクトリに存在しないパス・フォルダでないパス（zip ファイルを含む）・読み取り権限のないフォルダ・`/` と `~` のどちらでも
  始まらないパスを入力して「検索」を押した場合は、モーダルを閉じずに理由を表示し、検索を始めない（FR-081）
- **EC-35**: 検索結果を表示中に、一覧のファイルまたはフォルダがゴミ箱に入れられた・移動された（アプリの外での削除・移動を含む）
  場合は一覧から外す。フォルダの場合は、その中にあった検索結果もすべて外す。検索結果へのペーストはできない（FR-087）

- **EC-36**: 検索結果を表示中に、検索起点ディレクトリそのものが削除・移動された、または起点を含むボリュームが外された場合は、
  起点以下の結果（ファイルとフォルダ）をすべて一覧から外す。検索結果の表示は続け、検索前のフォルダ・ツリーの選択・最後に表示していた
  フォルダは変えない。フォーカス中の結果を外した場合はプレビューを空にし、再生中の動画を止める。検索が終わっていて結果が0件になった
  場合は、該当する項目がない旨を表示する（FR-087）

- **EC-103**: 起点欄が空・相対パス・存在しないパス・ファイルのパス・読み取り不能なフォルダでも、フォルダ選択は開ける。
  初期表示は FR-143 に従い、取消では元の入力を変更しない。パネルの初期位置への切り替えだけでパス欄を補正しない
- **EC-104**: 選択後から検索開始までにフォルダが削除・移動された、ボリュームが外された、読み取り権限を失った場合は、
  直接入力と同じく FR-081・EC-34 で扱う。GUI で選択したことを理由に検証を省略しない
- **EC-105**: 標準パネルでの Esc はパネルの取消だけを行い、Return はパネルの操作だけを行う。検索シートへ入力を伝播させない。
  復帰後に検索シートで Esc を押した場合は従来どおり検索シートを閉じる。既存の検索は停止しない
- **EC-106**: 日本語・空白を含むフォルダ、ルート `/`、読み取り可能な外部ボリュームのフォルダを選んだ場合も、選択した場所を表す
  絶対パスを欄へ反映する。名前の末尾の空白も保持し、引用符やエスケープ記号を付け加えず、起点欄を編集しなければ再入力せずに検索できる

- **EC-52**: 検索中に検索起点の配下のフォルダの名前を変えた場合も、検索を止めずに続け、名前を変える前に見つかったファイルと
  フォルダは新しい場所で一覧に残り、以後に見つかったファイルとフォルダも新しい場所で加わる（FR-105）

- **EC-91**: 読み取り権限のないフォルダも、名前が一致すれば行として表示する（中は辿らない。FR-083）。その行を開いたときの扱いは、
  通常のフォルダの一覧で読み取り権限のないフォルダを開いたときと同じとする
- **EC-92**: 名前が一致したフォルダの中も辿り続け、中のファイルとフォルダはそれぞれの名前で照合する。親のフォルダが一致したことを
  理由に、中の項目を一致とはしない（FR-083）
- **EC-93**: 検索中にフォルダの行を開いた場合は、検索を止めてからそのフォルダの一覧に切り替える（FR-140）
- **EC-94**: 検索結果を表示中に、ツリーまたは一覧でフォルダの名前を変え、新しい名前がキーワードに一致するようになっても、
  そのフォルダが検索結果の行でなければ一覧に加えない。検索中は、名前を変えた時点でまだ照合していないフォルダを、照合する時点の
  名前で照合する（FR-105）
- **EC-95**: 検索結果を表示中に、フォルダの行のフォルダがアプリの外で削除・移動された場合は、その行と中にあった検索結果をすべて外す。
  プレビュー中のファイルが外れた場合はプレビューを空にし、再生中の動画を止める。新しく作られたフォルダは一覧に加えない（FR-087）
- **EC-96**: 一致したのがフォルダだけでメディアファイルが0件の場合は、該当する項目がない旨のメッセージを出さない。このとき種類フィルタが
  オンでも、一致したメディアファイルが元々ないため絞り込み中のメッセージは出さない（FR-139）
- **EC-97**: フォルダの名前に「.」が含まれていても、名前全体をキーワードと照合し、拡張子として扱わない。たとえば `2024.10_trip` は
  `2024.10` で部分一致し、`photos.jpg` という名前のフォルダは `*.jpg` に一致する（FR-082）
- **EC-98**: 別の場所にある同じ名前のフォルダは、それぞれ別の行として表示し、「場所」列（サムネイル形式ではツールチップ）で見分けられる（FR-084）
- **EC-99**: 検索起点を検索前の場所 A の祖先にして、検索結果の A のフォルダの行を開いた場合は、A の一覧になるが、新しい履歴は
  記録しない。検索結果の表示を終えたときの表示の状態を現在の履歴（A）に反映してから比べるため、操作の後の状態が現在の履歴と
  同じ場所・同じ表示の状態になる（FR-107（navigation-history.md））。続けて「戻る」を実行すると A より前の履歴へ移り、戻る側に
  履歴がなければ「戻る」は無効になる（FR-113・FR-140）
- **EC-100**: zip の中の階層 D を表示中に始めた検索でフォルダの行 F を開いた場合は、F を D の履歴の次に記録する。続けて「戻る」を
  実行すると D へ戻る。Esc・「戻る」で検索結果の表示を終えたとき（FR-113）とは異なり、zip ファイルを含むフォルダの一覧を履歴に
  記録しない（FR-113・FR-140）
- **EC-101**: 検索結果を表示中に、検索結果の一覧から、検索前のフォルダ（zip の中で始めた検索では zip ファイルを含むフォルダ）
  そのもの、またはその祖先のフォルダの行をゴミ箱に入れた、または移動した（ツリーのフォルダへのドラッグ&ドロップを含む）場合は、
  検索結果の表示を続け、その行と中にあった検索結果を一覧から外すだけにする。検索前のフォルダ・ツリーの選択・最後に表示していた
  フォルダ（FR-003（overview.md））は変えない（EC-36 と同じ）。続けて Esc・「戻る」で検索結果の表示を終えた場合は、検索前のフォルダが
  元の場所に存在しないため、存在しないフォルダを開こうとした場合と同じに扱い、その場所を履歴に記録しない（EC-62
  （navigation-history.md））。ゴミ箱に入れた・移動した時点で、そのフォルダと配下の場所は FR-109（navigation-history.md）のとおり
  履歴から取り除かれている。ツリーから同じフォルダをゴミ箱に入れた場合は、従来どおり FR-079（file-operations.md）に従い親フォルダへ
  移る（FR-087）
- **EC-102**: 検索結果から開いたフォルダ F が、隠しフォルダの配下などの理由でツリーの実際の階層に表示されない場合は、
  ファイルリストには F の一覧を表示し、ツリーでは表示可能な最も近い祖先 V を選択する。最後に選択していたフォルダ（FR-003
  （overview.md））としても V を保存する。同期は一覧の読み込みを待たせず、キーボードフォーカスはファイルリストに残す。
  履歴には F を記録し、V への移動や履歴の追加は行わない。検索結果から開く場合に限る FR-078（file-list.md）の例外とし、
  お気に入りから開く場合など既存の経路は変更しない（FR-140）

## 成功基準

- **SC-016**: ローカルディスク上の 10,000 ファイルを含む階層を起点に検索しても、3 秒以内に検索が終わる。検索中も
  スクロール・選択・プレビュー・ツリーの操作が 100ms 以上止まらない（SC-004 と同じ基準）
- **SC-025**: 検索結果を表示中にフォルダの名前を変えたとき、一覧に古い名前の場所が残る結果が 0 件

- **SC-058**: 読み取り可能な通常のフォルダ・日本語名・空白を含む名前・ルート・外部ボリュームの5ケースで、
  起点パスを手入力せずに選択し、有効な検索開始が成立する。選択したフォルダと検索起点が一致するケースは5件中5件、選択の確定だけで検索が始まるケースは0件。
  合格には検索バーの起点パスと、その配下の既知の一致結果で起点を照合する。全階層の走査完了は要求せず、`/` を含め照合後は既存の解除操作で
  終了してよい。起点一致を確認する前に終了したケースは未確認とし、合格に含めない。US16-AS10 の末尾空白があるフォルダと、
  空白がない同名フォルダを併存させたケースでも、未編集の選択パスで検索でき、別フォルダを起点にした件数は0件
- **SC-059**: 標準パネルの取消（キャンセルボタンと Esc）を各5回、合計10回行い、検索シートが閉じる回数、入力値が変わる回数、
  ツリーの選択・一覧・プレビューが選択操作により変わる回数はいずれも0回となる
- **SC-060**: キーボードだけで検索シートを開き、「選択…」から標準パネルを開いて確定し、検索する一連の操作を5回行い、5回すべて完了できる。
  無効な起点からの選び直し、選択後の直接編集、選択後に消えたフォルダの拒否、古いエラーの解消、隠しフォルダ・パッケージの標準動作、
  確定時の削除済み・読み取り不能なフォルダの拒否、既存検索の継続の7ケースもすべて受け入れシナリオどおりとなる（US16-AS3・AS5・AS7・AS9・
  AS11〜AS13）

- **SC-053**: 名前に同じ語を含むフォルダ50個とメディアファイル50個、含まないフォルダ50個、名前に同じ語を含む隠しフォルダ・パッケージ・
  フォルダへのシンボリックリンク・zip ファイルを各5個持つ階層を、名前に同じ語を含むフォルダを起点に検索する。一致するフォルダと
  ファイルが漏れなく100件表示され、それ以外の項目と起点そのものが表示された件数が0件となる
- **SC-054**: SC-016（search.md）の 10,000 ファイルを含む階層（サブフォルダを含む）を起点に、フォルダも照合する検索をしても 3 秒以内に
  検索が終わり、検索中もスクロール・選択・プレビュー・ツリーの操作が 100ms 以上止まらない
- **SC-055**: 検索結果の、検索前の場所と異なるフォルダの行を、ダブルクリック・⌘↓・右クリックメニューの「中を表示」で合わせて20回開く。毎回、ファイルリストと
  ツリーの選択がそのフォルダ（ツリーに表示されない場合は EC-102 の祖先）になり、続けて ⌘[ を押して検索前の場所に戻った回数が20回、検索結果に戻った回数が0回となる
- **SC-056**: 検索結果のフォルダの行の名前の変更とゴミ箱に入れる操作を各10回行う。名前を変えたフォルダの行とその中の結果について、
  古い名前のまま残った件数が0件、ゴミ箱に入れたフォルダの行とその中の結果が一覧に残った件数が0件となる
- **SC-057**: 検索結果でフォルダの行を20回選択し、プレビューが空になった回数が20回となる。フルスクリーン中の矢印キーの移動と
  スライドショーで、フォルダの行に止まった回数が0回となる

## 前提

- **A-83**: 要望の GUI は macOS 標準のフォルダ選択パネル（`NSOpenPanel`）を検索シートの子シートとして使うものと解釈する。
  独自のフォルダ一覧・場所一覧・親移動・表示切替は作らない。選択した時点では入力だけを更新し、検索開始は従来の「検索」操作にまとめる
- **A-84**: 検索起点は従来どおり1つとし、複数起点・新規フォルダ作成・最近使った起点の履歴は範囲外とする。検索条件の保存・
  モーダルを開き直したときの起点の既定値も既存の FR-081・FR-086 と contracts/settings.md に従う
- **A-85**: 標準パネルの初期表示には、現在の有効な入力、モーダルを開いた時点の既定フォルダ、ホームの順に使う。隠しフォルダは許可し、
  パッケージ・読み取り不能なフォルダは飛ばす。入力を修正せずに選び直せ、繰り返し選ぶときも現在の条件から辿れるようにする
- **A-86**: 専用のグローバルショートカットは増やさず、Tab・⇧Tab と「選択…」の Space 操作を入口とする。標準パネル内のキー操作は
  OS 標準に従う。パネルから戻ったときは「選択…」へフォーカスを戻す

- **A-06**: 検索結果のリスト形式に表示する「場所」列の並び順は、検索結果の表示中だけの一時的なものであり、保存しない。
  検索を解除したときは検索前の並び順に戻す（FR-003・084）

- **A-76**: 「フォルダも検索対象にする」は、フォルダ名をキーワードと照合し、一致したフォルダを検索結果の行として表示する意味と
  解釈した。フォルダのパス（祖先のフォルダ名）との照合は引き続き行わず、親のフォルダが一致しても中のファイルを一致とはしない。
  パスで照合すると、一致したフォルダの配下がすべて結果に入り、目的のフォルダを見つけにくくなるためである
- **A-77**: フォルダの照合は常に行い、ファイルだけ・フォルダだけに絞る切り替え（検索のモーダルのチェックボックスなど）は設けない。
  要望が「フォルダも対象にする」であり、検索のモーダルの入力を増やさないためである。種類フィルタはフォルダの行を隠さない
  （FR-076 と同じ）ため、フォルダだけ・ファイルだけを表示する手段は本機能の範囲外とする
- **A-78**: 一致の対象にするフォルダは、通常のフォルダの一覧にフォルダの行として出るもの（FR-076）に合わせる。隠しフォルダ・
  パッケージ・フォルダへのシンボリックリンクは対象外とする。検索起点そのものは検索バーで示すため、行にしない
- **A-79**: zip ファイルの名前と zip の中のディレクトリは照合しない。要望の対象はフォルダであり、zip ファイルの表示設定（FR-095）と
  検索結果の関係を新たに定める必要が生じるためである。zip ファイルの名前による検索は範囲外とする
- **A-80**: フォルダの行を開くと検索結果の表示を終え、検索結果は従来どおり履歴に記録しない（FR-113）。開いたフォルダから検索結果へ
  戻る操作（検索結果を保ったまま中を見る操作）は範囲外とし、必要なら同じ条件で検索し直す
- **A-81**: 検索バーの件数は、一致したファイルとフォルダの合計とし、内訳は表示しない。種類フィルタと件数の関係は従来の検索結果と同じとする
- **A-82**: フォルダの行のファイル操作・右クリックメニュー・キー操作は、通常のフォルダの一覧のフォルダの行（FR-076・contracts/keyboard-and-menus.md）
  と同じとし、検索結果に固有の制限（ペーストできない、「上の階層へ」がない。FR-087）だけを加える
