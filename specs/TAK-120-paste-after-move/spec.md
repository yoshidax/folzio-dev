# Feature Specification: コピー元を移動した後もペーストできるようにする

**Feature Branch**: `claude/tender-carson-4e5op3`

**Created**: 2026-11-20

**Status**: Draft

**Input**: [TAK-120](https://linear.app/takyoshida/issue/TAK-120/)「コピー元を移動した後も、コピーしたファイルをペーストできるようにする」。
⌘C → ⌥⌘V（移動ペースト）→ ⌘V で、移動によってコピー元のパスにファイルがなくなり、2回目のペーストが失敗する。

## Clarifications

### Session 2026-11-20

- 当初は、Folzio の移動・名前の変更の後にクリップボードのパスを移動後のパスへ書き換える方式で設計した（コミット 7474d21）。
  保守者が「クリップボードの中身を後から書き換えるのは、コピーした内容の改変になる」として見直し、
  Finder の仕組みを確かめたうえで、次の方式に改めた
- Q: Finder はコピー後に移動した項目を、クリップボードを書き換えずにペーストできる。その仕組みは
  → A: Finder はコピーのときに、各項目のファイルの参照（`file:///.file/id=…`）とファイル名の文字列とアイコンを置く
  （保守者が macOS で確かめた。A-248）。Folzio のコピーも参照を置き、クリップボードは書き換えない（FR-413）
- Q: どの移動の後もペーストできるようにするか → A: 参照が保たれる移動・名前の変更のすべて
  （Folzio の操作に限らず、Finder・ターミナルなどでの操作も含む）。当初の回答「Folzio の操作だけ」は、方式の変更で広げた
- Q: コピーした項目をゴミ箱に入れた後のペーストは → A: Finder に合わせ、ゴミ箱の中からペーストする（Finder は
  ペーストできることを保守者が確かめた。A-249）。当初の回答「失敗を示す」は改めた
- Q: Folzio のコピーで、ファイル名の文字列も置くか → A: Finder と同じく置く。アイコンは置かない（FR-413）
- Q: 別のアプリ（Finder など）が置いた参照のペーストは → A: 今の Folzio でも、Finder のコピー → ⌥⌘V → ⌘V は成功した
  （A-251）。同じ扱いを要件として定める（FR-414）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。コピー・ペースト・移動ペーストのショートカットとメニュー（FR-019（file-operations.md））、
ペーストできる場所と条件・メニューの有効と無効（FR-354（file-operations.md））、確認・衝突・エラーの表示
（FR-022〜FR-026（file-operations.md））は変えない。

ID は、`specs/product/` の最大値（FR-412・SC-234・EC-280・A-247・US93）の次から振る。

### User Story 1 - 移動した後もコピーしたファイルをペーストする (Priority: P1)

利用者は、Folzio でファイルをコピーした後に、そのファイルを移動・名前の変更・ゴミ箱に入れても、Finder と同じく
⌘V でそのファイルをペーストできる。クリップボードの中身は、コピーした時点から変わらない。

**Why this priority**: TAK-120 の中心の要件である。今は移動ペーストの後の ⌘V が必ず失敗し、もう一度コピーし直す必要がある。

**Independent Test**: Folzio で項目 A を ⌘C し、フォルダ B で ⌥⌘V、フォルダ C で ⌘V して、C に A のコピーができ、
失敗の表示が出ないことを確かめる。

**Acceptance Scenarios**:

- **US94-AS1**: **Given** Folzio で項目 A をコピー（⌘C）した,
  - **When** フォルダ B で移動ペースト（⌥⌘V）し、続けてフォルダ C でペースト（⌘V）する,
  - **Then** B へ移動した A が C へコピーされ、失敗の表示は出ない
- **US94-AS2**: **Given** Folzio で項目 A をコピーした,
  - **When** Folzio または Finder で A の名前を A2 に変え、フォルダ C でペーストする,
  - **Then** A2 が C へコピーされる
- **US94-AS3**: **Given** Folzio でフォルダ F をコピーした,
  - **When** Finder で F を同じボリュームの別のフォルダへ移動し、Folzio のフォルダ C でペーストする,
  - **Then** 移動した F が中身ごと C へコピーされる
- **US94-AS4**: **Given** Folzio で項目 A をコピーした,
  - **When** A をゴミ箱に入れ、フォルダ C でペーストする,
  - **Then** ゴミ箱の中の A が C へコピーされる（Finder と同じ）
- **US94-AS5**: **Given** Folzio で項目 A をコピーし、A をゴミ箱に入れた,
  - **When** フォルダ C で移動ペーストする,
  - **Then** A がゴミ箱から C へ移動する（確認は「移動する前に確認する」に従う）
- **US94-AS6**: **Given** Folzio で項目 A をコピーした,
  - **When** Finder のフォルダで ⌘V する,
  - **Then** A がそのフォルダへコピーされる
- **US94-AS7**: **Given** Folzio で項目 A をコピーした,
  - **When** テキストエディタで ⌘V する,
  - **Then** A のファイル名が貼られる（Finder のコピーと同じ）
- **US94-AS8**: **Given** Finder で項目 A をコピーした,
  - **When** Folzio のフォルダ B で移動ペーストし、続けてフォルダ C でペーストする,
  - **Then** B へ移動した A が C へコピーされる（従来どおり）
- **US94-AS9**: **Given** Folzio で項目 A をコピーした,
  - **When** A を別のボリュームへ移動し（または A を削除してゴミ箱を空にし）、フォルダ C でペーストする,
  - **Then** A の名前と「見つからない」理由を示して失敗する

### Edge Cases

- **EC-281**: Folzio がコピーの参照を用意している間に、Folzio または別のアプリがクリップボードを変えた場合は、
  Folzio はコピーの内容を書かず、後から変えられた内容を残す。
- **EC-282**: コピーの時点で見つからない項目（ほかのアプリが直前に消したなど）は、参照を作れないため、従来どおりパスで置く。
  ペーストのときにそのパスに項目がなければ、従来どおり失敗を示す。
- **EC-283**: 複数の項目をペーストするとき、参照を解決できない項目があれば、その項目だけを失敗として示し、
  ほかの項目のコピー・移動は続ける。失敗は、コピー・移動の失敗とまとめて1回で示す。
- **EC-284**: 参照を解決した場所がペースト先のフォルダと同じ項目の場合（移動ペーストの後、同じフォルダで ⌘V したなど）は、
  コピー元と衝突先が同一の項目の衝突（FR-025（file-operations.md））として扱う。
- **EC-285**: パスで置かれた file URL（Folzio の以前の版のコピー、参照を置かないアプリのコピー）は、従来どおりそのパスを使う。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-413**: Folzio のコピー（ファイルリストとツリーの「コピー」）は、各項目をファイルの参照としてクリップボードに置かなければならない。
  - 参照は、同じボリュームの中で移動・名前の変更・ゴミ箱に入れても、同じ項目を指す（A-250）。
  - 各項目に、ファイル名の文字列も置く（Finder と同じ。A-248）。アイコンは置かない。
  - コピーの後に、Folzio がクリップボードの中身を書き換えることはしない。
  - 参照を作れない項目は、従来どおりパスで置く（EC-282）。
  - 参照とファイル名は UI スレッドの外で用意し、用意できた後にクリップボードへ書く。
  - 用意している間にクリップボードが変わったら、書かない（EC-281）。
- **FR-414**: ペースト・移動ペーストは、実行したときにクリップボードの参照を今の場所に解決し、その場所の項目をコピー・移動しなければならない。
  - 別のアプリ（Finder など）が置いた参照も同じく扱う（A-251）。
  - ゴミ箱の中に解決された項目もペーストする。移動ペーストでは、ゴミ箱から取り出す（US94-AS4・US94-AS5）。
  - 解決できない参照の項目は、クリップボードのファイル名の文字列を名前として、「見つからない」理由の失敗として示す（EC-283）。
  - 解決は UI スレッドの外で行う。
  - クリップボードの中身を読むのは、従来どおりペーストを実行したときだけとする（FR-354（file-operations.md））。

### Key Entities

- **クリップボードの項目**: 1つのファイル・フォルダについて、ファイルの参照（作れなければパス）とファイル名の文字列を持つ。
  コピーのときに作り、ペーストのときに今の場所へ解決する。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-235**: Folzio でコピーした後、同じボリュームの中で項目を移動・名前の変更・ゴミ箱に入れてからペーストしたとき
  （US94-AS1〜AS5）、その項目のペーストが失敗する件数が 0 件。
- **SC-236**: Folzio でコピーした後、移動・名前の変更・ペーストをしても、Folzio がクリップボードの中身を変える件数が 0 件。
- **SC-237**: Folzio のコピーを Finder でペーストすると項目がコピーされ、テキストエディタでペーストするとファイル名が貼られる
  （US94-AS6・US94-AS7）。

## Assumptions

- **A-248**: Finder はコピーのとき、各項目にファイルの参照（`public.file-url` の `file:///.file/id=…`）、ファイル名の文字列
  （`public.utf8-plain-text`）、アイコン（`com.apple.icns`）を置く（2026-11-20 に保守者が macOS で確かめた）。
- **A-249**: Finder は、コピーした項目をゴミ箱に入れた後も、その項目をペーストできる（2026-11-20 に保守者が確かめた）。
- **A-250**: ファイルの参照は、同じボリュームの中の移動・名前の変更では保たれ、別のボリュームへの移動や削除では解決できなくなる。
- **A-251**: 変更前の Folzio でも、Finder のコピー → Folzio の ⌥⌘V → ⌘V は成功した（2026-11-20 に保守者が確かめた）。
  ペースト側は参照を解決できている。
