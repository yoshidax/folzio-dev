# Feature Specification: コピー元を移動した後もペーストできるようにする

**Feature Branch**: `claude/tender-carson-4e5op3`

**Created**: 2026-11-20

**Status**: Draft

**Input**: [TAK-120](https://linear.app/takyoshida/issue/TAK-120/)「コピー元を移動した後も、コピーしたファイルをペーストできるようにする」。
⌘C → ⌥⌘V（移動ペースト）→ ⌘V で、移動によってコピー元のパスにファイルがなくなり、2回目のペーストが失敗する。

## Clarifications

### Session 2026-11-20

- Q: どの移動の後でもペーストできるようにするか → A: Folzio が行った移動・名前の変更だけを対象にする。
  Folzio の外（Finder・ターミナルなど）での移動・名前の変更の後は、従来どおり失敗する（FR-413・EC-282）
- Q: クリップボードの項目が削除された、またはゴミ箱に入れられたときは → A: 従来どおり失敗を示す。
  ゴミ箱に入れる操作では書き換えない（FR-413・US94-AS7）
- Q: 別のアプリ（Finder など）がクリップボードに置いたファイルを Folzio で移動ペーストしたとき、クリップボードを
  書き換えるか → A: 書き換える。どのアプリがコピーしたかは問わない（FR-414）
  - 「クリップボードの中身はユーザーがペーストを実行したときだけ読む」（FR-354（file-operations.md））を保つため、
    対象は Folzio が書いた・ペーストで読んだクリップボードに限る。別のアプリのコピーを、Folzio でペーストせずに
    ドラッグで移動した場合は対象外（US94-AS8）
- Q: Folzio が書き換えたクリップボードのファイルを、別のアプリ（Finder など）で使えるか → A: 使えるようにする。
  Folzio のコピーと同じ形（file URL）で書き、Finder でペーストできることを確かめる（FR-414・SC-237）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。コピー・ペースト・移動ペーストのショートカットとメニュー（FR-019（file-operations.md））、
ペーストできる場所と条件（FR-354（file-operations.md））、確認・衝突・エラーの表示（FR-022〜FR-026（file-operations.md））は変えない。

ID は、`specs/product/` の最大値（FR-412・SC-234・EC-280・A-247・US93）の次から振る。

### User Story 1 - 移動した後もコピーしたファイルをペーストする (Priority: P1)

利用者は、ファイルをコピーした後に Folzio で移動・名前の変更をしても、続けて ⌘V でそのファイルをペーストできる。
Finder と同じく、1回の ⌘C で移動ペーストとペーストを続けられる。

**Why this priority**: TAK-120 の中心の要件である。今は移動ペーストの後の ⌘V が必ず失敗し、もう一度コピーし直す必要がある。

**Independent Test**: Folzio で項目 A を ⌘C し、フォルダ B で ⌥⌘V、フォルダ C で ⌘V して、C に A のコピーができ、
失敗の表示が出ないことを確かめる。

**Acceptance Scenarios**:

- **US94-AS1**: **Given** Folzio で項目 A をコピー（⌘C）した,
  - **When** フォルダ B で移動ペースト（⌥⌘V）し、続けてフォルダ C でペースト（⌘V）する,
  - **Then** B へ移動した A が C へコピーされ、失敗の表示は出ない
- **US94-AS2**: **Given** Finder で項目 A をコピーした,
  - **When** Folzio のフォルダ B で移動ペーストし、続けてフォルダ C でペーストする,
  - **Then** B へ移動した A が C へコピーされる
- **US94-AS3**: **Given** Folzio で項目 A をコピーした,
  - **When** ファイルリストまたはツリーで A の名前を A2 に変え、フォルダ C でペーストする,
  - **Then** A2 が C へコピーされる
- **US94-AS4**: **Given** Folzio でフォルダ F の中の項目 X をコピーした,
  - **When** F をドラッグ&ドロップでフォルダ D へ移動し、フォルダ C でペーストする,
  - **Then** D の中の F の中の X が C へコピーされる
- **US94-AS5**: **Given** Folzio で項目 A と B をコピーした,
  - **When** A だけをドラッグ&ドロップでフォルダ D へ移動し、フォルダ C でペーストする,
  - **Then** D へ移動した A と、元の場所の B の両方が C へコピーされる
- **US94-AS6**: **Given** Folzio で項目 A をコピーした後、別のアプリで文字列をコピーした,
  - **When** Folzio で A を移動する,
  - **Then** クリップボードはその文字列のまま変わらない
- **US94-AS7**: **Given** Folzio で項目 A をコピーした,
  - **When** A をゴミ箱に入れ、フォルダ C でペーストする,
  - **Then** 従来どおり、A の名前と理由を示して失敗する
- **US94-AS8**: **Given** Finder で項目 A をコピーし、Folzio ではペーストしていない,
  - **When** Folzio で A をドラッグ&ドロップで移動し、フォルダ C でペーストする,
  - **Then** 従来どおり、A の名前と理由を示して失敗する（FR-414 の対象外）
- **US94-AS9**: **Given** US94-AS1 の移動ペーストの後,
  - **When** Finder のフォルダで ⌘V する,
  - **Then** B へ移動した A が、そのフォルダへコピーされる

### Edge Cases

- **EC-281**: 複数の項目の移動の途中で、衝突の「中止」で止めた場合と、一部の項目の移動が失敗した場合は、
  移動した項目だけを書き換え、移動しなかった項目は元の場所のまま残す。
- **EC-282**: Folzio の外（Finder・ターミナルなど）で移動・名前の変更をした項目は書き換えず、ペーストは従来どおり失敗する。
- **EC-283**: 衝突で「両方残す」を選び、移動先で別の名前（「名前 2」など）になった項目は、その名前の場所へ書き換える。
- **EC-284**: 移動先が別のボリュームで、コピーしてから元の項目を消す移動も、同じく書き換える。
- **EC-285**: 移動ペーストを続けて行った場合（⌘C → フォルダ B で ⌥⌘V → フォルダ C で ⌥⌘V）は、
  2回目の移動ペーストが B の項目を C へ移動し、クリップボードを C の場所へ書き換える。
- **EC-286**: 移動・名前の変更をしたフォルダの中の項目（子孫）がクリップボードにある場合は、移動後のフォルダの中の場所へ書き換える。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-413**: Folzio が項目の移動または名前の変更を終えたとき、システムは、クリップボードのファイルのうち
  移動・名前の変更をした項目を、移動後の場所に書き換えなければならない。
  - 対象の操作は、移動ペースト、アプリ内のドラッグ&ドロップによる移動（FR-020（file-operations.md））、
    アプリ外からドラッグで受け取る移動（FR-346（file-operations.md））、ファイルリストとツリーの名前の変更とする。
  - 移動・名前の変更をしたフォルダの中の項目も、移動後のフォルダの中の場所に書き換える（EC-286）。
  - 移動先での実際の名前（「両方残す」で付いた名前を含む）を使う（EC-283）。
  - 失敗・中止・キャンセルで移動しなかった項目は書き換えない（EC-281）。
  - 移動と関係のない項目は書き換えず、項目の順序を保つ。
  - 書き換える項目が1つもなければ、クリップボードを変えない。
  - ゴミ箱に入れる操作、複製、コピー、フォルダの新規作成では書き換えない。
  - 移動後の場所は操作の結果から決め、書き換えのためにファイルシステムを調べない。
- **FR-414**: システムは、Folzio が中身を把握しているクリップボードが、その後に変わっていないときだけ、
  FR-413 の書き換えをしなければならない。
  - 把握している中身は、Folzio のコピー（ファイルリストとツリーの「コピー」）で書いたファイルと、
    ペースト・移動ペーストの実行時に読んだファイルとする。
  - 別のアプリがコピーしたファイルも、Folzio でペースト・移動ペーストを実行した後は対象にする。
  - Folzio または別のアプリがその後にクリップボードを変えていれば、書き換えない（US94-AS6）。
  - 書き換えるかを決めるために、クリップボードの中身を読まない（FR-354（file-operations.md）の
    「クリップボードの中身は、ユーザーがペーストを実行したときだけ読む」を保つ）。
  - 書き換えた後のクリップボードは、Folzio のコピーと同じ形で書き、別のアプリ（Finder など）でもペーストできるようにする。
  - 書き換えた後のクリップボードの中身も、把握している中身として扱う（EC-285）。

### Key Entities

- **把握しているクリップボードの中身**: Folzio が最後に書いた、またはペーストで読んだファイルの並びと、
  そのときのクリップボードの版。Folzio の実行中だけメモリに持つ（A-249）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-235**: Folzio でコピーし、Folzio で移動・名前の変更をしてからペーストしたとき（US94-AS1〜AS5）、
  移動・名前の変更をした項目のペーストが失敗する件数が 0 件。
- **SC-236**: クリップボードを別のアプリが変えた後に Folzio で移動・名前の変更をしたとき、
  Folzio がクリップボードを書き換える件数が 0 件。
- **SC-237**: Folzio が書き換えたクリップボードを Finder でペーストしたとき、移動後の項目がコピーされる。

## Assumptions

- **A-248**: Finder が移動の後もペーストできる仕組みは確かめていない。この feature は Finder の仕組みを再現せず、
  Folzio の操作の結果からクリップボードを書き換える。
- **A-249**: 把握しているクリップボードの中身は保存せず、Folzio を終了すると失われる。再起動の後の移動では書き換えない。
- **A-250**: 書き換えた後のクリップボードには、ファイルだけを置く。別のアプリがファイルと一緒に置いていた表現
  （ファイル名の文字列・アイコンなど）は残らない。
- **A-251**: クリップボードの項目と移動した項目は、標準化したパスで比べる。
