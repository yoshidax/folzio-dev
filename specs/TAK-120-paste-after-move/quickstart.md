# Quickstart: コピー元を移動した後もペーストできるようにする

## 自動の検証

Cloud では `scripts/dev/check-all.sh` だけを実行し、`swift build`・`swift test` は macOS の CI で確かめる。

```bash
swift build
swift test
scripts/dev/check-all.sh
scripts/make-app.sh
```

## GUI の確認

古い Folzio を終了してから `open .build/Folzio.app` で起動し、3ペインが表示されることを確かめてから行う。
消えても困らないファイル A・B と、空のフォルダ B・C・D を用意する（フォルダ名は項目名と別の名前でよい）。

1. Folzio で A を選択して ⌘C、フォルダ B で ⌥⌘V、フォルダ C で ⌘V する。
   - A が B へ移動し、C に A のコピーができる。失敗の表示は出ない（US94-AS1）
2. Finder で A をコピーし、Folzio のフォルダ B で ⌥⌘V、フォルダ C で ⌘V する。
   - B へ移動した A が C へコピーされる（US94-AS2）
3. Folzio で A をコピーし、ファイルリストで A の名前を A2 に変えてから、フォルダ C で ⌘V する。
   - A2 が C へコピーされる。ツリーのフォルダの名前の変更でも同じ（US94-AS3）
4. Folzio でフォルダ F の中の X をコピーし、F をツリーかファイルリストでフォルダ D へドラッグして移動し、フォルダ C で ⌘V する。
   - D の中の F の中の X が C へコピーされる（US94-AS4・EC-286）
5. Folzio で A と B をコピーし、A だけをフォルダ D へドラッグして移動し、フォルダ C で ⌘V する。
   - A と B の両方が C へコピーされる（US94-AS5）
6. Folzio で A をコピーし、テキストエディタで文字列をコピーしてから、Folzio で A を移動する。
   - テキストエディタで ⌘V すると、その文字列のまま（US94-AS6）
7. Folzio で A をコピーし、A をゴミ箱に入れてから、フォルダ C で ⌘V する。
   - 従来どおり、A の名前と理由を示して失敗する（US94-AS7）
8. Finder で A をコピーし、Folzio ではペーストせずに A をドラッグで移動してから、Folzio のフォルダ C で ⌘V する。
   - 従来どおり、A の名前と理由を示して失敗する（US94-AS8）
9. 手順 1 の ⌥⌘V の後、Finder のフォルダで ⌘V する。
   - B へ移動した A が、そのフォルダへコピーされる（US94-AS9・SC-237）
10. 移動先に同じ名前の項目がある状態で ⌘C → ⌥⌘V し、衝突で「両方残す」を選んでから、フォルダ C で ⌘V する。
    - 「名前 2」になった項目が C へコピーされる（EC-283）
