# UI Contract: ショートカット割り当ての設定

`specs/product/contracts/keyboard-and-menus.md`（キー操作）・`settings.md`（設定ウインドウと保存キー）へ反映する差分。表示名は日本語。英語は `localization.md` に追加する。

## 2 固定キー（割り当ての候補にならない）

文脈で意味が変わる、または他の操作の一部であるキー。

| 種別 | キー |
|---|---|
| 矢印（修飾なし・⇧・⌥のみ） | ↑ ↓ ← →、⇧↑ ⇧↓ ⇧← ⇧→、⌥↑ ⌥↓ ⌥← ⌥→ |
| 編集・移動 | Return、Esc、Tab、⇧Tab、Space、Delete（修飾なし）、`<`、`>` |
| 選択 | ⌘A（編集メニューの標準キーとして予約も兼ねる） |

⌘↑・⌘↓ は「上の階層へ」「中を表示」の既定値なので固定キーではない（コマンドとして扱う）。
⇧矢印は修飾要件（⌘・⌃・⌥ のいずれか）の検証で先に拒否されるため、固定キーの表には載せるが検証の順序の上では (1) で止まる。⌥矢印は修飾要件を通るため、固定キーの検査（2）が実際に働く。

## 3 予約キー（アプリ・OS の基本操作）

| キー | 理由 |
|---|---|
| ⌘Q ⌘W ⌘, | アプリの終了・ウインドウを閉じる・設定 |
| ⌘Z ⇧⌘Z ⌘X ⌘C ⌘V | 編集メニューの標準キー |
| ⌘H ⌥⌘H ⌘M | アプリを隠す・ほかを隠す・しまう |
| ⌘Tab ⇧⌘Tab ⌘` ⌘Space | アプリ・ウインドウの切り替え、Spotlight |

## 4 設定ウインドウ

- ウインドウの幅は 620pt（現行どおり）。タブは上部に「一般」「ショートカット」。開いたとき常に「一般」を選ぶ
- 「一般」の内容・間隔・Tab 順・補足説明・即時保存は現行（settings.md の「設定ウインドウ（⌘,）」）から変えない。高さは内容に合わせる（FR-222）
- 「ショートカット」: 上から区分の見出し（ショートカット一覧と同じ区分名）と行を並べ、`NSScrollView` に入れる。ウインドウの高さは約 480pt。末尾（スクロール外の下部）に「すべて既定値に戻す」を固定で置く
- 行: コマンド名（左）、現在のキー（中央、等幅風の表記）、状態（「変更済み」・記録中の案内・エラー文）、「記録」ボタン、「既定値に戻す」ボタン（既定値のままなら無効）
- 記録中: 当該の行の現在のキー欄が「キーを入力…」になる。ほかの行の「記録」は無効。エラーは行の下に赤色のテキストと記号付きで表示し、VoiceOver で読み上げる
- 文言（日本語 / 英語）:

| 用途 | 日本語 | 英語 |
|---|---|---|
| タブ | 一般 / ショートカット | General / Shortcuts |
| 記録 | 記録 | Record |
| 記録中の案内 | キーを入力… | Type shortcut… |
| 既定値に戻す | 既定値に戻す | Reset |
| すべて戻す | すべて既定値に戻す | Reset All |
| 変更済み | 変更済み | Changed |
| 修飾なし | ⌘・⌃・⌥ のいずれかと組み合わせてください | Combine with ⌘, ⌃, or ⌥. |
| 固定・予約 | このキーは変更できません | This shortcut can’t be changed. |
| 重複 | 「%@」で使われています | Already used by “%@”. |
| 既定値が重複 | 既定のキーを「%@」が使っています | The default shortcut is used by “%@”. |

## 5 保存キー

`settings.md` の表へ追加:

| キー | 型 | 既定値 | 対応 |
|------|----|--------|------|
| `shortcuts.overrides` | [String: String]（コマンド ID → 組み合わせ） | （未設定 = すべて既定値） | FR-254 |

読み込み時の不正な値の扱いは data-model.md と research.md R9。

## 6 表示の同期

- メインメニュー・コンテキストメニュー・ツールバーのツールチップとアクセシビリティラベル・ショートカット一覧ウインドウ・設定ウインドウは、同じ割り当ての表から生成する
- ショートカット一覧は、コマンドに対応する項目だけキーを割り当てから生成する。複数コマンドを束ねた項目は、区切りを保って連結する
  （例: `paneFocus` = ⌥⌘1 / ⌥⌘2 / ⌥⌘3 を `focusTree`・`focusFileList`・`focusPreview` から）。コマンドに対応しない項目は静的な表記のまま
- 固定キーとコマンドのキーが混ざる項目は、パーツ列（静的な文字列とコマンド）として生成する
  （例: `endSearch` = 静的 `Esc` / コマンド `back` → `Esc / ⌘[`、割り当てを変えると `Esc / <新しいキー>`。
  `imageZoom` = `zoomIn` / 別名 `⌘=`（`zoomIn` が既定値のときだけ）/ `zoomOut`）
- 割り当てを変更したとき、開いている一覧ウインドウは表示を更新する（先頭の可視項目を保つ）
