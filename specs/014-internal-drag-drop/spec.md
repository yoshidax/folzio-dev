## User Scenarios & Testing

### User Story 23 - フォルダへドラッグして整理する (Priority: P1)

- **US23-AS1**: 通常のツリーフォルダを別のツリーフォルダまたはリスト内のフォルダにドラッグすると、確認後に中身ごと移動する。Option を押してドロップするとコピーする。
- **US23-AS2**: リスト形式またはサムネイル形式の選択済みファイル・フォルダをツリーまたはリストのフォルダにドラッグすると、選択全体を一操作として扱う。選択外の項目から開始した場合はその項目だけを対象とする。
- **US23-AS3**: 有効な宛先を指す間は視覚的に示し、無効な宛先では受け付けない。ドラッグの中止または確認のキャンセルでは変更しない。
- **US23-AS4**: 衝突や失敗があれば既存の選択肢と結果表示に従い、成功と失敗を区別する。完了後の表示・選択・プレビューは結果と整合する。
- **US23-AS5**: 検索結果の選択ファイル・フォルダはツリーまたは検索結果のフォルダへドラッグできる。zip 内の項目、親に戻る行、お気に入り見出しや見つからないお気に入りにはドロップできない。

- **US4-AS8（変更）**: **Given** 移動・コピー先に同名の別の項目がある, **When** 操作を実行する, **Then** 設定に関わらず「置き換える / 両方残す / 中止」を選ぶダイアログが表示される。コピー先の同名項目がコピー元そのものの場合は「置き換える」を選べず、「両方残す / 中止」から選ぶ。

### Edge Cases

- **EC-121**: 移動先がいずれかの対象の親と同じ場合、その移動全体を拒否する。同じ場所へのコピーでは同名衝突を示し、「両方残す」または「中止」を選べるが、コピー元を失わないよう「置き換える」は選べない。対象フォルダ自身または配下への移動・コピーは全体を拒否する。選択集合にフォルダとその配下の項目が同時に含まれる場合も、移動・コピーとも全体を拒否する。複数項目の一部だけを黙って除外しない。
- **EC-122**: ドラッグ中または確認中に対象・宛先が消失、変更、アクセス不能になった場合は確定時にも検証し、既存のエラー表示と結果の反映に従う。権限エラーは EC-08（file-operations.md）に従う。
- **EC-123**: 検索結果以外の表示中に、ツリーから表示中のフォルダまたはその祖先を移動した場合、元の親を表示しプレビューを空にする。検索結果を表示中は、検索結果を維持して移動した配下の結果を除き、検索中の重複再出現を防ぐ。コピーでは元の表示を保つ。お気に入りは FR-067 に従う。

## Requirements

### Functional Requirements

- **FR-020（変更）**: ユーザーはアプリ内で、ツリーの通常のフォルダ、またはファイルリストで選択したファイル・フォルダを、ツリー上またはファイルリスト上の別のフォルダへドラッグ&ドロップできなければならない。通常は移動、ドロップ時に Option を押していればコピーとする。ファイルリストはリスト形式・サムネイル形式の両方に対応し、複数選択はまとめて扱う。確認・衝突・エラーは FR-022〜FR-026 に従う。
- **FR-025（変更）**: コピーまたは移動の操作先に同名ファイルが存在する場合、システムは確認モーダル設定に関わらず「置き換える / 両方残す / 中止」を選ばせなければならない。ただしコピー元と衝突先が同一の項目である場合は「置き換える」を選べないようにし、「両方残す / 中止」を選ばせる。この例外はドラッグ以外のコピーにも適用する。名前の変更で既存の名前（大文字小文字の違いのみを含む）を指定した場合は、衝突ダイアログを出さず、名前の検証エラーとして拒否しなければならない。複製は FR-018 の連番の規則に従い、この対象外とする。
- **FR-076（変更）**: システムは、ファイルリストに選択フォルダ直下のサブフォルダ（隠しフォルダとパッケージを除く）を表示しなければならない。ユーザーは、フォルダの行をダブルクリックするか、選択して ⌘↓ を押すことで、ファイルリストをそのフォルダの一覧に切り替えられなければならない。フォルダの行は、プレビュー（FR-075 と同じく空にし、再生中の動画は停止する）・縮小画像と行頭アイコン（フォルダを示す汎用アイコン）・種類フィルタ（FR-056・FR-060。常に表示し、ファイルとして数えない）・フルスクリーン中の矢印キー移動（FR-046。止まらずに飛ばす）について、zip の中のディレクトリと同じく扱う。フォルダの行は FR-018〜FR-027 のファイル操作の対象とする。ツリーの通常フォルダに対しては、ゴミ箱に入れる操作を FR-079、名前の変更を FR-103、ドラッグによる移動・コピーを FR-020 に従って行える（複製はファイルリストからだけ行う）。
- **FR-162**: ドラッグ元はツリーの通常フォルダ（FR-079 と同じ範囲）または通常一覧・検索結果の実項目とする。ホーム・ボリュームのルート、お気に入りの項目・見出し、`..`、zip 内の項目はドラッグ元にしない。zip ファイル自体は通常のファイルとして扱う。検索結果のフォルダも対象とする（009-folder-search の FR-083・FR-087）。
- **FR-163**: 宛先はツリーの実在するフォルダ行（ホーム・ボリュームのルート、利用可能なお気に入りを含む）または通常一覧・検索結果の実フォルダ項目とする。お気に入り見出し、見つからないお気に入り、`..`、ファイル、zip ファイル、zip 内、検索結果の背景、リストの背景、行間にはドロップできない。アプリ外とのドラッグの動作変更は対象外とする。
- **FR-164**: システムは現在の操作と対象全体について宛先を検証し、有効なフォルダ行・項目を視覚的に強調する。Option の変更に追従して操作種別と有効性を更新し、ドロップ時にも再検証する。EC-16・EC-121 の不正な操作は受け付けない。
- **FR-165**: 操作後は FR-027 に従いツリー・リストを更新し、移動された選択項目を元一覧から外す。プレビュー対象が消えたらプレビューを空にして動画を停止する。コピー・キャンセル・失敗した項目の選択とプレビューは保つ。部分成功では成功分だけ反映する。ツリーから表示中のフォルダまたは祖先を移動した場合は EC-123 に従う。検索結果は FR-087 および EC-123 に従う。

## Success Criteria

- **SC-074**: ツリー・リスト形式・サムネイル形式の各ドラッグ元とツリー・リストの両宛先について、移動・Option コピーをそれぞれ確認し、対象・結果が誤る組み合わせは0件。
- **SC-075**: 複数選択、無効な宛先、キャンセル、衝突、権限エラーと検索・zip・お気に入りの各確認で、意図しない変更や不整合が0件。

## Assumptions

- 既存の ⌘C・⌘V・⌥⌘V とメニューをキーボード手段として維持する（FR-019）。ツリーの通常フォルダは親の一覧で選択して同じキーボード手段を使える。
- **A-20（変更）**: お気に入りの見出しはドロップ先・ペースト先にしない。利用可能なお気に入りの項目はアプリ内ドラッグのドロップ先として登録先の実フォルダを使える。見つからない項目はドロップ先にしない。お気に入りの項目をペースト先にはしない。アプリ外とのドラッグの既存動作は今回変更しない。
- コピーと移動の確認、同名衝突、部分失敗は既存のファイル操作と同じ。ファイルシステム上の同一性とシンボリックリンクを含む安全な判定は設計で扱う。

## Clarifications

### Session 2026-10-28（推奨を採用）

- 検索結果のファイルとフォルダはドラッグ元とし、検索結果のフォルダは宛先にもする。検索結果の背景は宛先にしない（009-folder-search の FR-087）。
- お気に入り項目はドラッグ元にせず、利用可能な登録先は宛先として使う。登録は移動に追従しない（FR-067）。
- 一部でも不正な複数選択は全体を拒否し、同じ場所へのコピーは衝突を示し、「両方残す」か「中止」とする。元を失う「置き換える」は選べない。
- リスト背景・`..` は宛先にしない。対象フォルダそのものを指す。
- 検索結果で親フォルダとその配下の項目を同時に選んだ場合は、二重操作を避けるため移動・コピーとも集合全体を拒否する。
- 検索結果表示中にその結果を含むフォルダをツリーから移動した場合は検索結果を維持し、移動分を除く。それ以外で表示中のフォルダまたは祖先を移動した場合は元の親へ移る。

## 既存仕様との照合

`specs/product/search.md` の FR-083・FR-084・FR-087 はファイルのみを記述しているが、実装と README は検索結果のフォルダを扱い、`specs/009-folder-search/spec.md` の対応項目にもその仕様がある。今回は実装済みの検索結果のフォルダを維持してドラッグ対象に含める。製品仕様への反映時には、009 の未反映箇所を別途照合し、014 の反映によって矛盾を拡大しないよう対象と扱いをレビューする。
