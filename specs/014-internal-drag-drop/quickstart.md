# 手動検証: アプリ内ドラッグ

古い MediaViewer を終了し、`scripts/make-app.sh` 後に `open .build/MediaViewer.app` で起動する。専用の使い捨てフォルダを用い、3ペインの表示を確認する。

1. ツリー・リスト形式・サムネイル形式それぞれを元として、ツリーとリスト内のフォルダの両方に通常ドラッグと Option ドロップを行う。移動とコピー、操作種別の切替、対象行の強調を確認する。
2. ファイルとフォルダの複数選択、選択外からのドラッグ、検索結果の複数選択を試し、対象集合と実際の結果を確認する。
3. 同じ親への移動、自身・配下への移動とコピー、無効な背景・ファイル・`..`・zip 内を試し、強調されず何も変更しないことを確認する。同じ親へのコピーで「置き換える」が選べず、「両方残す」と「中止」が安全に働くことを確認する。コピー＆ペーストでも同じ例外と元の保護を確認する。
4. 確認でキャンセル、衝突の置き換え・両方残す・中止、書き込み権限エラーを試す。成功・失敗の区別とファイルシステムの結果を確認する。
5. 利用可能／見つからないお気に入り、ホーム・ボリューム、zip ファイル、検索中のフォルダ移動後も検索結果が維持され移動分が消えることを確認する。ツリーで表示中のフォルダまたはその祖先を移動し、一覧・選択・プレビュー・動画・履歴・お気に入りを確認する。
6. コピー確認省略設定のオン／オフでコピーと移動を試す。既存のキーボード操作と外部ドラッグの挙動を確認する。大きな一覧でドラッグ中の反応を確認する。

実行日、macOS バージョン、使用ビルド、各シナリオの合否と問題を報告する。
