# Data Model

- **内部ドラッグ**: 元の種別、開始時の実 URL 集合、操作（ドロップ時に move/copy）。選択集合は開始時に固定し、空・仮想項目・zip 内を拒否する。
- **宛先**: 実フォルダ URL と表示上の行。お気に入りは登録先 URL を使う。
- **検証結果**: 集合全体の有効／無効。移動で同じ親、フォルダ自身・配下、無効な種類は拒否。コピーの同じ親は衝突を示し「両方残す」または「中止」のみ許す。コピー元と衝突先が同一の「置き換える」は実行しない。シンボリックリンクや別名で同一場所になる場合も安全に扱う。
- **実行結果**: 成功元・成功先・失敗元と理由。確認や衝突の中止では未実行の項目を成功扱いにしない。結果を検索・選択・履歴・ツリーへ反映する。
