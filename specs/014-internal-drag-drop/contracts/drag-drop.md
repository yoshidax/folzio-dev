# 内部ドラッグ契約

1. ドラッグ開始時に有効な実項目の選択集合を固定する。選択外から開始した場合は開始項目だけ。
2. 宛先は明示的なフォルダ項目（検索結果のフォルダを含む）。内部セッションは受け付け可能な宛先だけを強調し、Option 押下状態で move/copy を切り替える。
3. 全対象を検証し、選択にフォルダとその配下の項目がある場合、または1件でも不正なら移動・コピーとも受け付けない。確定時および操作直前に再検証し、変更・消失はエラーとして扱う。
4. coordinator の確認・衝突・結果処理を使う。同じ場所へのコピーでは「置き換える」を選べず、実行層でも元と同一の置き換えを拒否する。中止した項目は未実行として扱い、成功した分だけ画面を同期する。
5. アプリ外の既存ドラッグ経路は変更しない。内部識別情報を信頼境界に使い、外部由来を内部扱いしない。
