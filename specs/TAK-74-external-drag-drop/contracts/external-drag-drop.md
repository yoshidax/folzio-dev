# Contract: アプリ外とのドラッグ&ドロップ

ユーザーから見た入力と結果の契約。ID は spec.md と `specs/product/file-operations.md`。

## Folzio からアプリ外へ（FR-344）

| ドラッグ元 | ドロップ先 | 修飾キー | 結果 |
|---|---|---|---|
| ツリー・リスト・サムネイル・検索結果 | Finder（同じボリューム） | なし | 移動（Finder が実行） |
| 同上 | Finder（同じボリューム） | Option | コピー |
| 同上 | Finder（別のボリューム） | なし | コピー |
| 同上 | Finder（別のボリューム） | ⌘ | 移動 |
| 同上 | ブラウザのアップロード欄 | 任意 | ブラウザがファイルを読む（元は変わらない） |
| 同上 | Dock のゴミ箱 | 任意 | ゴミ箱へ移る |

**表の詳細**

- **ツリー**（ドラッグ元）: ドラッグを始められる範囲は FR-162（ホーム・ボリュームの最上位・お気に入り・`..`・zip の中は不可）
- Folzio は確認モーダルを出さない。結果は FSEvents で反映する（EC-236）
- Finder の挙動は Finder が決める。上の表は Finder の既定の規則で、保守者の macOS で確かめる（research.md R2）

## アプリ外から Folzio へ（FR-345〜FR-351）

宛先: ツリーのフォルダ行（ホーム・ボリュームの最上位を含む）、利用可能なお気に入り、リスト形式のフォルダ行、
サムネイル形式のフォルダのアイコン、検索結果のフォルダ（FR-163 と同じ）。

| 受け取るデータ | 修飾キー | 同じボリューム | 操作 | 確認モーダル |
|---|---|---|---|---|
| file URL | なし | すべて同じ | 移動 | 常に表示 |
| file URL | なし | 混在・別 | コピー | 省略設定に従う |
| file URL | Option | 任意 | コピー | 省略設定に従う |
| file URL | ⌘ | 任意 | 移動 | 常に表示 |
| file promise | 任意 | 任意 | 保存（コピー） | 省略設定に従う |
| 画像データ | 任意 | 任意 | PNG で保存（コピー） | 省略設定に従う |
| URL・文字列だけ | 任意 | 任意 | 受け付けない | なし |

**表の詳細**

- **file URL**（受け取るデータ）: ドラッグ元が許可しない操作は、もう一方に切り替えるか受け付けない（EC-238）。
  自分自身・配下・親と同じ場所への移動・親子の同時の転送は受け付けない（EC-16・EC-121）
- **file promise**（受け取るデータ）: ファイル名と形式はドラッグ元のアプリが決める
- **画像データ**（受け取るデータ）: 名前は FR-350（URL の末尾の名前、なければ「画像 日付 時刻.png」）
- 宛先に同じ名前がある場合は、どの操作でも「置き換える / 両方残す / 中止」（FR-025）
- 失敗は対象の名前と理由を示し、成功した分と区別する（FR-026・EC-239・EC-240）
- キャンセル・中止・失敗では宛先に何も残さない（一時的なファイルを含む。SC-183）

## 変えないこと

- アプリ内のドラッグ（Folzio のビューから始めて Folzio のビューへドロップ）は FR-020・FR-162〜FR-165 のまま（常に移動、Option でコピー）
- ドロップできない場所（お気に入りの見出し、見つからないお気に入り、`..`、ファイル、zip ファイル、zip の中、背景、行間）
