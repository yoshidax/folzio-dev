# Quickstart: TAK-74 他のアプリとのドラッグ&ドロップの検証

## 自動の検査

| 実行する者 | コマンド・場所 | 確かめること |
|---|---|---|
| Cloud（Agent） | `scripts/dev/check-all.sh` | 仕様の形式・公開の境界など |
| CI（macOS） | `swift build`、`swift test` | `ExternalDropPolicy`・`ImportedImageName`・登録した型とマスク・画像データの保存と一時フォルダの削除 |
| 保守者（ローカル） | `swift build`、`swift test`、下の手動の確認 | 同上と GUI |

## 準備（保守者のローカル）

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

- 起動スモーク: 3 ペインが表示される
- 外付けのボリューム（USB メモリやディスクイメージ）を1つマウントし、「別のボリューム」の確認に使う
- 作業用のフォルダ（例: `~/Desktop/tak74`）に、画像ファイル数件とサブフォルダ `dest` を作る

## 手動の確認

### Folzio からアプリ外へ（US75、SC-180）

1. リスト形式・サムネイル形式・ツリー・検索結果の各ドラッグ元から、同じボリュームの Finder のフォルダへドラッグする。修飾キーなしで移動し、Folzio の一覧から消えることを確かめる。Option でコピーになることを確かめる
2. 別のボリュームの Finder のフォルダへドラッグし、コピーになること、⌘ で移動になることを確かめる
3. Safari と Chrome で、ファイルのアップロード欄（`<input type="file">` を持つページ、例: ローカルの HTML ファイル）へ画像をドラッグし、受け付けられることを確かめる
4. Dock のゴミ箱へドラッグし、ゴミ箱へ移ること、Folzio の一覧から消えること、ゴミ箱から戻せることを確かめる
5. zip の中の項目・`..`・お気に入り・ホームからドラッグが始まらないことを確かめる（US75-AS4）

### Finder から Folzio へ（US76、SC-181）

1. ツリーのフォルダ・利用可能なお気に入り・リスト形式のフォルダ行・サムネイル形式のフォルダのアイコン・検索結果のフォルダの各宛先へ、同じボリュームのファイルをドロップし、移動の確認モーダルが出て移動することを確かめる
2. 同じく Option でコピー、別のボリュームのファイルでコピー、別のボリュームで ⌘ を押して移動になることを確かめる
3. 宛先に同名のファイルを置き、「置き換える / 両方残す / 中止」が出ることを確かめる
4. 背景・`..`・ファイル・zip・お気に入りの見出し・見つからないお気に入りの上で、宛先が強調されないことを確かめる
5. Finder で選んだフォルダを、Folzio のツリーのそのフォルダ自身・配下・元の親へドロップできないことを確かめる

### ブラウザの画像を Folzio へ（US77、SC-182・SC-183・SC-184）

1. Safari と Chrome に表示した画像（JPEG・PNG・WebP）を、ツリー・リスト形式・サムネイル形式のフォルダへドロップし、ファイルとして保存されることを確かめる。保存された名前と形式を記録する（research.md R6 の未検証の点）
2. 確認モーダルでキャンセルし、宛先に何も作られないこと、一時的なファイルが残らないことを確かめる
3. 同名のファイルがある宛先へドロップし、衝突の選択肢が出ることを確かめる
4. ブラウザのリンク（画像でない URL）をドラッグし、宛先が強調されないことを確かめる
5. ネットワークを切った状態で（ブラウザのキャッシュにある）画像をドロップし、Folzio が通信しないことを確かめる。ネットワークの監視（「アクティビティモニタ」の「ネットワーク」で Folzio の送受信のバイト数）で、受け取りの前後で増えないことを確かめる

### アプリ内のドラッグの回帰（SC-185）

- `specs/014-internal-drag-drop/quickstart.md` の手順で、ツリー・リスト形式・サムネイル形式の間の移動と Option のコピーが、変更の前と同じであることを確かめる
