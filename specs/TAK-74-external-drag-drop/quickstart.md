## 先に行う確認（tasks.md の Phase 2、マスクだけを変えた版）

実装の残りを始める前に、アプリ外向けのマスクだけを変えた版で、次を確かめて `checklists/validation.md` に記録する（research.md R2 の未検証の点）。

1. リスト形式のファイルを、同じボリュームの Finder のフォルダへ修飾キーなし・Option・⌘ でドラッグし、移動・コピー・移動になるか
2. 同じく別のボリュームの Finder のフォルダへ、修飾キーなし・⌘ でドラッグし、コピー・移動になるか
3. Dock のゴミ箱へドラッグし、ファイルがゴミ箱へ移るか、元の場所に残るか（残る場合、Dock はドラッグ元に削除を任せている）
4. Option と ⌘ を同時に押して Finder のフォルダへドラッグしたとき、何が起きるか（エイリアスが作られる、受け付けない、など）
5. Finder のファイルを Option と ⌘ を同時に押して Folzio のツリーのフォルダへドラッグしたとき、宛先が強調されるか（今の実装のまま）

3 でファイルが残る場合は、Dock のゴミ箱には対応しない（spec の Clarifications）。結果に合わせて spec・research・tasks を直してから、実装の残りを始める。

**結果（2026-11-07、T005）**: 1・2 は設計どおり。3 はファイルが元の場所に残った（Dock のゴミ箱には対応しないことにし、`.delete` を外した）。
4 は受け付けられなかった。5 は宛先が強調された（Finder はコピーを許可している）。詳細は `checklists/validation.md`

## 手動の確認

### Folzio からアプリ外へ（US75、SC-180）

1. リスト形式・サムネイル形式・ツリー・検索結果の各ドラッグ元から、同じボリュームの Finder のフォルダへドラッグする。修飾キーなしで移動し、Folzio の一覧から消えることを確かめる。Option でコピーになることを確かめる
2. 検索結果の表示中に、結果のファイルを Finder のフォルダへ移動し、その行が検索結果から外れることを確かめる。
   大きなフォルダを検索中（列挙が終わる前）に、結果のフォルダを Finder へ移動し、その配下の結果が後から表示されないことを確かめる（EC-236）
3. 別のボリュームの Finder のフォルダへドラッグし、コピーになること、⌘ で移動になることを確かめる。ツリーからは ⌘ を押したままドラッグを始められない（A-132）ので、
   ドラッグを始めてから ⌘ を押す
4. Safari と Chrome で、ファイルのアップロード欄（`<input type="file">` を持つページ、例: ローカルの HTML ファイル）へ画像をドラッグし、受け付けられることを確かめる
5. ファイルとツリーのフォルダを Dock のゴミ箱へドラッグし、受け付けられず、項目が元の場所に残り、Folzio の表示も変わらないことを確かめる（US75-AS5）。
   ゴミ箱へ移った場合は記録して報告する（research.md R2 の残る未検証の点）
6. zip の中の項目・`..`・お気に入り・ホームからドラッグが始まらないことを確かめる（US75-AS4）
7. ツリーのフォルダを Finder へ移動した後、ツリーで別のフォルダをアプリ内でコピーし、ツリーの選択が変わらないことを確かめる（research.md R7）

### Finder から Folzio へ（US76、SC-181・SC-182）

1. ツリーのフォルダ・利用可能なお気に入り・リスト形式のフォルダ行・サムネイル形式のフォルダのアイコン・検索結果のフォルダの各宛先へ、同じボリュームのファイルをドロップし、移動の確認モーダルが出て移動することを確かめる
2. 同じく Option でコピー、別のボリュームのファイルでコピー、別のボリュームで ⌘ を押して移動になることを確かめる。
   Option と ⌘ を同時に押したときは、コピーになることを確かめる（FR-346。Finder はこのときもコピーを許可する）
3. 同じボリュームのファイルと別のボリュームのファイルを Finder で一緒に選び（2つの Finder のウインドウから選べない場合は、検索の結果のウインドウやサイドバーの「最近の項目」を使う）、修飾キーなしでドロップしてコピーになることを確かめる（EC-237）
4. 宛先に同名のファイルを置き、「置き換える / 両方残す / 中止」が出ることを確かめる。確認のキャンセルで何も変わらないこと、
   複数の項目の途中で中止すると、それまでに完了した項目は残り、中止した項目とその後の項目は変わらないことを確かめる（SC-182）
5. 背景・`..`・ファイル・zip・お気に入りの見出し・見つからないお気に入りの上で、宛先が強調されないことを確かめる
6. Finder で選んだフォルダを、Folzio のツリーのそのフォルダ自身・配下・元の親へドロップできないことを確かめる

### file URL 以外のドラッグ（US76-AS6、SC-183）

1. Safari と Chrome に表示した Web の画像、リンク、選択した文字列を、Folzio のフォルダの上へドラッグし、宛先が強調されず、ドロップしても何も起きないことを確かめる。
   宛先が強調された場合は、ブラウザが file URL を渡している（research.md R6 の未検証の点）ので、記録する。file URL を持つ場合は、そのファイルの移動・コピーになる（US76-AS6）

### アプリ内のドラッグの回帰（SC-184）

- `specs/014-internal-drag-drop/quickstart.md` の手順で、ツリー・リスト形式・サムネイル形式の間の移動と Option のコピーが、変更の前と同じであることを確かめる
