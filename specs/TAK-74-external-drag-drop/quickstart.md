# Quickstart: TAK-74 他のアプリとのドラッグ&ドロップの検証

## 自動の検査

| 実行する者 | コマンド・場所 | 確かめること |
|---|---|---|
| Cloud（Agent） | `scripts/dev/check-all.sh` | 仕様の形式・公開の境界・ネットワーク API の不使用など |
| CI（macOS） | `swift build`、`swift test` | `ExternalDropPolicy`、3つのビューのマスク、file URL の判定 |
| 保守者（ローカル） | `swift build`、`swift test`、下の手動の確認 | 同上と GUI |

## 準備（保守者のローカル）

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

- 起動スモーク: 3 ペインが表示される
- 外付けのボリューム（USB メモリやディスクイメージ）を1つマウントし、「別のボリューム」の確認に使う
- 作業用のフォルダ（例: `~/Desktop/tak74`）に、画像ファイル数件とサブフォルダ `dest` を作る。外付けのボリュームにも画像ファイルを数件置く

## 手動の確認

### Folzio からアプリ外へ（US75、SC-180）

1. リスト形式・サムネイル形式・ツリー・検索結果の各ドラッグ元から、同じボリュームの Finder のフォルダへドラッグする。修飾キーなしで移動し、Folzio の一覧から消えることを確かめる。Option でコピーになることを確かめる
2. 検索結果の表示中に、結果のファイルを Finder のフォルダへ移動し、その行が検索結果から外れることを確かめる（EC-236）
3. 別のボリュームの Finder のフォルダへドラッグし、コピーになること、⌘ で移動になることを確かめる
4. Safari と Chrome で、ファイルのアップロード欄（`<input type="file">` を持つページ、例: ローカルの HTML ファイル）へ画像をドラッグし、受け付けられることを確かめる
5. Dock のゴミ箱へドラッグし、ゴミ箱へ移ること、Folzio の一覧から消えること、ゴミ箱から戻せることを確かめる（US75-AS5）
6. zip の中の項目・`..`・お気に入り・ホームからドラッグが始まらないことを確かめる（US75-AS4）
7. ツリーのフォルダを Finder へ移動した後、ツリーで別のフォルダをアプリ内でコピーし、ツリーの選択が変わらないことを確かめる（research.md R7）

### Finder から Folzio へ（US76、SC-181・SC-182）

1. ツリーのフォルダ・利用可能なお気に入り・リスト形式のフォルダ行・サムネイル形式のフォルダのアイコン・検索結果のフォルダの各宛先へ、同じボリュームのファイルをドロップし、移動の確認モーダルが出て移動することを確かめる
2. 同じく Option でコピー、Option と ⌘ を同時に押してコピー、別のボリュームのファイルでコピー、別のボリュームで ⌘ を押して移動になることを確かめる
3. 同じボリュームのファイルと別のボリュームのファイルを Finder で一緒に選び（2つの Finder のウインドウから選べない場合は、検索の結果のウインドウやサイドバーの「最近の項目」を使う）、修飾キーなしでドロップしてコピーになることを確かめる（EC-237）
4. 宛先に同名のファイルを置き、「置き換える / 両方残す / 中止」が出ることを確かめる。中止・確認のキャンセルで何も変わらないことを確かめる
5. 背景・`..`・ファイル・zip・お気に入りの見出し・見つからないお気に入りの上で、宛先が強調されないことを確かめる
6. Finder で選んだフォルダを、Folzio のツリーのそのフォルダ自身・配下・元の親へドロップできないことを確かめる

### file URL 以外のドラッグ（US76-AS6、SC-183）

1. Safari と Chrome に表示した画像、リンク、選択した文字列を、Folzio のフォルダの上へドラッグし、宛先が強調されず、ドロップしても何も起きないことを確かめる。
   宛先が強調された場合は、ブラウザが file URL を渡している（research.md R6 の未検証の点）ので、記録する

### アプリ内のドラッグの回帰（SC-184）

- `specs/014-internal-drag-drop/quickstart.md` の手順で、ツリー・リスト形式・サムネイル形式の間の移動と Option のコピーが、変更の前と同じであることを確かめる
