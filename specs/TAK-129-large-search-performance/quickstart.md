## 保守者の GUI 確認（ローカル）

**準備**: 5万件の階層を作る（500 フォルダ × 100 ファイル、8×8 の JPEG。半数の名前が `cat_`、残りが `dog_`）。

```bash
scripts/make-fixtures.sh ~/FolzioFixtures --large-search
```

古い Folzio を終了してから、次を順に実行する。

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

`~/FolzioFixtures/large-search` を開き、サムネイル形式・名前順にして、次を確認する。時間はストップウォッチで計る。

1. ⌘F でキーワード `cat` を検索する。検索中は結果が一覧の末尾に加わり、先頭の項目は入れ替わらない（US99-AS2）
2. 1 の検索で、3 秒以内に表示範囲のすべての項目に縮小画像が出る（SC-250）
3. 1 の検索が 3 秒以内に終わり、件数が 25,000 件で確定し、一覧が名前順に並ぶ（SC-249・US99-AS1）
4. 3 の後、一覧の先頭が表示され、終了から 3 秒以内に表示範囲の縮小画像がそろう（US99-AS3）
5. もう一度 `cat` を検索し、検索中に一覧をスクロールし、項目を選択し、ツリーのフォルダを開閉する。操作が引っかからない（SC-251・US99-AS5）
6. 5 で選択した項目が、検索の終了後も選択されたまま、見える位置にある（US99-AS4）
7. もう一度 `cat` を検索し、検索中に「名前」の見出しを押して向きを変える（リスト形式に切り替えて行う）。その時点の結果がすぐ並べ替わり、
   終了時に全体が新しい向きで並ぶ（US99-AS7）
8. 検索の終了後に一覧をゆっくりスクロールし、縮小画像が通常のフォルダと同じく表示される（US99-AS8）
9. キーワード `jpg`（5万件すべてが一致）でも検索し、1〜4 の時間を記録する（参考。基準はない）
10. 検索中にアクティビティモニタで Folzio と QuickLook の CPU 使用率を見て、検索の前と比べた印象を報告する（参考。A-266）
11. 通常のフォルダ（`~/FolzioFixtures/huge`）を開き、従来どおり縮小画像が出る。サムネイルの大きさのスライダーとペイン幅をドラッグで変え、
    配置が崩れず、横スクロールが出ず、表示が引っかからない（A-269、SC-004・SC-005（file-list.md））
12. 検索の終了後と通常のフォルダ（`~/FolzioFixtures/huge`）で、縮小画像が出た先頭の画面から数画面下へスクロールして先頭へ戻る。
    サムネイル形式とリスト形式の両方で、先頭の項目に種類のアイコンが一瞬も出ず、前と同じ縮小画像がすぐに出る（FR-438、SC-254、US99-AS9）

報告: 各項目の合否、2・3・4・9 の時間、macOS の版と Mac の機種。12 は、手順 1〜11 の確認と同じ版で行う。

## 計測のためのログ（T034）

原因を数値で確かめるためのログを取る。ログはこのアプリの中だけで記録され、外部へ送られない。ファイル名はハッシュで出る。

1. UI スレッドの止まりの監視を有効にする（10ms ごとに測るので、計測の後に無効にする）

   ```bash
   defaults write local.folzio.Folzio FolzioLogMainThreadStalls -bool YES
   ```

2. アプリを作り直して起動する

   ```bash
   scripts/make-app.sh
   ```

   ```bash
   open .build/Folzio.app
   ```

3. 別のターミナルでログを記録し始める

   ```bash
   log stream --level debug --style compact --predicate 'subsystem == "local.folzio.Folzio" AND category == "Performance"' > ~/folzio-perf.log
   ```

4. 次の操作を、間に数秒ずつ空けて順に行う
   - `~/FolzioFixtures/large-search` を起点に `cat` を検索し、終わるまで待つ
   - 検索結果のサムネイル形式で画像を 3 つ、1 つずつクリックして選ぶ（プレビューの遅れ）
   - スクロールバーを摘んで一覧の中ほどまで動かし、先頭へ戻す（作り直し）
   - 先頭の項目を選び、↓キーを押し続けて数画面分下へ移動し、↑キーを押し続けて先頭へ戻す（作り直し）
5. ログの記録を Control-C で止め、`~/folzio-perf.log` を送る
6. 監視を無効にする

   ```bash
   defaults delete local.folzio.Folzio FolzioLogMainThreadStalls
   ```

## 計測の後の確認（T038）

計測で見つかった原因の対策（research.md R12）の後に、前回と同じ実フォルダで確かめる。

1. 検索の終了後に、サムネイル形式で画像を 3 つ、1 つずつクリックして選ぶ。プレビューがすぐに出る（SC-255）
2. 先頭の項目を選び、↓キーを押し続けて数画面下へ移動する。引っかからずに移動できる（SC-255）
3. スクロールバーを摘んで一覧の中ほどまで動かし、先頭へ戻す。先頭のサムネイルが作り直されずに出る（FR-439・FR-440）
4. ホイールでゆっくりスクロールしたとき、止まった位置のサムネイルが、気にならない程度の遅れで出る（A-270 の 150ms）
5. 通常のフォルダでも、1〜4 で違和感がない（A-269）
