## CI（macOS）

- 検索中は見つかった順に足すこと、反映の間隔、終了時の並べ替え・選択とフォーカスの保持、検索中の名前の変更のテストが通る

  実装の前後の値を PR に記載する（CI は共有ランナーなので参考。A-263）

## 保守者の GUI 確認（ローカル）

**準備**: 5万件の階層を作る（500 フォルダ × 100 ファイル、8×8 の JPEG。半数の名前が `cat_`、残りが `dog_`）。

```bash
scripts/make-fixtures.sh ~/FolzioFixtures --large-search
```

古い Folzio を終了してから、次を順に実行する。

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

`~/FolzioFixtures/large-search` を開き、サムネイル形式・名前順にして、次を確認する。時間はストップウォッチで計る。

1. ⌘F でキーワード `cat` を検索する。検索中は結果が一覧の末尾に加わり、先頭の項目は入れ替わらない（US99-AS2）
2. 1 の検索で、3 秒以内に表示範囲のすべての項目に縮小画像が出る（SC-250）
3. 1 の検索が 3 秒以内に終わり、件数が 25,000 件で確定し、一覧が名前順に並ぶ（SC-249・US99-AS1）
4. 3 の後、一覧の先頭が表示され、終了から 3 秒以内に表示範囲の縮小画像がそろう（US99-AS3）
5. もう一度 `cat` を検索し、検索中に一覧をスクロールし、項目を選択し、ツリーのフォルダを開閉する。操作が引っかからない（SC-251・US99-AS5）
6. 5 で選択した項目が、検索の終了後も選択されたまま、見える位置にある（US99-AS4）
7. もう一度 `cat` を検索し、検索中に「名前」の見出しを押して向きを変える（リスト形式に切り替えて行う）。その時点の結果がすぐ並べ替わり、
   終了時に全体が新しい向きで並ぶ（US99-AS7）
8. 検索の終了後に一覧をゆっくりスクロールし、縮小画像が通常のフォルダと同じく表示される（US99-AS8）
9. キーワード `jpg`（5万件すべてが一致）でも検索し、1〜4 の時間を記録する（参考。基準はない）
10. 検索中にアクティビティモニタで Folzio と QuickLook の CPU 使用率を見て、検索の前と比べた印象を報告する（参考。A-266）
11. 通常のフォルダ（`~/FolzioFixtures/huge`）を開き、従来どおり縮小画像が出る（A-269）

報告: 各項目の合否、2・3・4・9 の時間、macOS の版と Mac の機種。
