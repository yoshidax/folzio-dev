# Quickstart: パス名のコピー

## 自動検証

```bash
swift build
swift test --filter FolzioCoreTests
swift test
scripts/check-no-network.sh
scripts/check-readme-sync.sh master
scripts/dev/check-english-comments.sh
```

## GUI 確認（ユーザーが行う）

```bash
scripts/make-app.sh
open .build/Folzio.app
```

テキストエディタなど貼り付け先を用意する。

1. ファイルリストでメディアの行を右クリック →「パス名をコピー」→ 貼り付けて絶対パスと一致する。選択・プレビューは変わらない。
2. フォルダの行・zip ファイルの行（⌃⌘Z で表示）・検索結果の行で同じ操作をする。
3. 複数行を選んで右クリックすると「パス名をコピー」が淡色。`..` の行も淡色。
4. zip の中を表示し、ディレクトリ・メディア・`..` の行で淡色になる。⌥⌘C は何もしない。
5. ツリーで別のフォルダを選んだまま、ほかのフォルダ・ホーム・お気に入りの項目を右クリック →「パス名をコピー」。ツリーの選択は変わらず、お気に入りは登録先の絶対パスになる。
6. 「お気に入り」の見出しは右クリックでメニューが出ない。見出しを選んだまま「編集 > パス名をコピー」が淡色。
7. ファイルリストに 1 件だけ選んで ⌥⌘C、ツリーにフォーカスして ⌥⌘C → 貼り付けて一致する。
8. ファイルを ⌘C した後に「パス名をコピー」すると、「ペースト」が淡色になる。
9. 設定で英語に切り替えると「Copy as Pathname」になる。
