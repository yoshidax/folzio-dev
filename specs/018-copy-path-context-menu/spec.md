## Clarifications

### Session 2026-10-30

- Q: zip の中の項目（ディレクトリ・メディア・`..`）を対象にするか？ → A: 対象にしない。メニュー項目は出したまま淡色にする。zip 内の項目はファイルシステム上の絶対パスを持たず、FR-073 で zip の中は読み取り専用・操作対象外としているため。zip ファイルそのものは通常のファイルとして対象にする。
- Q: ファイルリストで複数選択しているときは？ → A: 無効（淡色）。Issue が単数選択を対象にしているため。右クリックした行が選択に含まれていなければ、通常どおりその行だけの選択に切り替わってから単数として扱う。
- Q: ツリーで「お気に入り」の見出しを選択中、またはツリーに選択がないときの ⌥⌘C は？ → A: 何もしない（「編集 > パス名をコピー」は淡色）。見出しは実フォルダを持たず、右クリックでもメニューを出さないため（FR-182）。
- Q: 「編集 > パス名をコピー」は既存の「編集 > コピー」（⌘C）の動作を変えるか？ → A: 変えない。別の項目で、ファイルのコピー（ファイルのクリップボード）とは独立している。
- Q: キーボード手段を設けるか？ → A: 設ける。憲章 原則 III とキーボード契約のため、Finder と同じ ⌥⌘C を「編集」メニューに置く。右クリックメニューの対象規則と同じ。
- Q: コピーする文字列の形式は？ → A: 絶対パスをそのまま（エスケープ・引用符・末尾スラッシュなし）。Finder の「パス名をコピー」と同じ。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ファイルリストの項目のパスをコピーする (Priority: P1)

ユーザーは、ファイルリストで選んだファイル・フォルダ・zip ファイルの絶対パスを、右クリックメニューから文字列としてコピーし、他のアプリへ貼り付ける。

**Why this priority**: Issue の中心の要件。

**Independent Test**: 通常のフォルダでメディア・フォルダ・zip ファイルの各行を右クリックして「パス名をコピー」を選び、別のテキスト欄へ貼り付けて絶対パスと一致することを確認する。

**Acceptance Scenarios**:

1. **US26-AS1**: **Given** 通常のフォルダの一覧でメディアファイルを1件選択している、**When** 右クリックメニューの「パス名をコピー」を選ぶ、**Then** そのファイルの絶対パスがクリップボードの文字列になり、ファイルリスト・ツリー・プレビューの状態は変わらない。
2. **US26-AS2**: **Given** フォルダまたは zip ファイルの行（zip ファイルの表示がオン）を1件選択している、**When** 同じ操作をする、**Then** そのフォルダまたは zip ファイルの絶対パスをコピーする。
3. **US26-AS3**: **Given** 複数の行を選択している、**When** 選択に含まれる行を右クリックする、**Then** 「パス名をコピー」は淡色で選べない。
4. **US26-AS4**: **Given** 検索結果を表示している、**When** ファイルまたはフォルダの行で同じ操作をする、**Then** その項目の絶対パスをコピーする。

---

### User Story 2 - ツリーのフォルダのパスをコピーする (Priority: P1)

ユーザーは、ツリーのフォルダ（ホーム・ボリュームのルート、お気に入りの項目を含む）の絶対パスを右クリックメニューからコピーする。

**Why this priority**: Issue の対象にツリーが含まれる。

**Independent Test**: ツリーの通常フォルダ・ホーム・お気に入りの項目を右クリックして「パス名をコピー」を選び、貼り付けた文字列が対応する絶対パスと一致し、ツリーの選択が変わらないことを確認する。

**Acceptance Scenarios**:

1. **US26-AS5**: **Given** ツリーで別のフォルダを選択している、**When** 通常のフォルダの行を右クリックして「パス名をコピー」を選ぶ、**Then** 右クリックした行のフォルダの絶対パスをコピーし、ツリーの選択・ファイルリスト・プレビューは変わらない（A-21）。
2. **US26-AS6**: **Given** お気に入りの項目（利用可能）がある、**When** その行で同じ操作をする、**Then** 登録したフォルダの絶対パスをコピーする（表示名ではない）。
3. **US26-AS7**: **Given** 「お気に入り」の見出しを右クリックする、**When** メニューを開く、**Then** 従来どおりメニューを出さない。

---

### User Story 3 - キーボードでパスをコピーする (Priority: P2)

ユーザーは、キーボードだけでも、フォーカスのあるペインの項目のパスをコピーできる。

**Why this priority**: すべての操作をキーボードで行える原則（FR-040）を保つ。

**Independent Test**: ファイルリスト・ツリーにフォーカスを置き、⌥⌘C で貼り付けた文字列が選択中の項目の絶対パスと一致することを確認する。

**Acceptance Scenarios**:

1. **US26-AS8**: **Given** ファイルリストにフォーカスがあり1件だけ選択している、**When** ⌥⌘C または「編集 > パス名をコピー」を実行する、**Then** その項目の絶対パスをコピーする。
2. **US26-AS9**: **Given** ツリーにフォーカスがあり通常のフォルダ・ホーム・ボリュームのルート・利用可能なお気に入りの項目を選択している、**When** 同じ操作をする、**Then** そのフォルダの絶対パスをコピーする。

---

### Edge Cases

- zip の中の表示中: メディア・ディレクトリ・`..` のどの行でも「パス名をコピー」は淡色で、⌥⌘C は何もしない（FR-073）。
- 通常のフォルダの `..` の行: 淡色で選べない（操作対象にならない。FR-077）。
- 見つからないお気に入りの項目（FR-067）: 淡色で選べない。
- 名前の変更中: ツリー・ファイルリストのメニュー項目と ⌥⌘C を無効にする（FR-102）。編集欄ではシステムのテキスト編集が優先される。
- 右クリックした時点で項目がなくなっていた（外部で削除・移動された）場合: 存在確認はせず、表示していた絶対パスをコピーする（コピーは文字列だけを扱い、ファイルシステムを変更しない）。
- パスに空白・日本語・特殊文字を含む場合: そのままの文字列（Unicode の正規化を変更しない）。
- クリップボードにファイルがある状態でパス名をコピーした場合: クリップボードは文字列に置き換わり、ペースト・移動ペーストは無効になる。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-181**: ユーザーは、ファイルリストの通常のフォルダと検索結果の一覧で、1件だけ選択したファイル・フォルダ・zip ファイル（メディアファイルを含む）の絶対パスを、行の右クリックメニューの「パス名をコピー」で文字列としてクリップボードにコピーできなければならない。コピーする文字列は引用符・エスケープ・末尾スラッシュを加えない絶対パスとし、クリップボードの既存の内容は置き換える。
- **FR-182**: ユーザーは、ツリーの通常のフォルダ、ホーム、マウント中のボリュームの最上位、利用可能なお気に入りの項目の行の右クリックメニューの「パス名をコピー」で、その絶対パスをコピーできなければならない。右クリックした行を対象にし、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003）は変えない（A-21）。お気に入りの項目では登録したフォルダの絶対パスをコピーする。「お気に入り」の見出しはメニューを出さない（従来どおり）。
- **FR-183**: システムは、次の場合に「パス名をコピー」を淡色にして選べなくしなければならない。ファイルリストで複数の行を選択している、`..` の行を対象にしている、zip の中の項目（メディア・ディレクトリ・`..`）を対象にしている（FR-073）、見つからないお気に入りの項目を対象にしている、ツリーの「お気に入り」の見出しを選択中、またはキーボード操作でツリーに選択がない、名前の変更中（FR-102）。
- **FR-184**: ユーザーは、キーボードから「編集 > パス名をコピー」（⌥⌘C、Finder と同じ割り当て）で、フォーカスのあるペインの選択中の項目に FR-181〜183 と同じ規則でパスをコピーできなければならない。ファイルリストにフォーカスがあるときはファイルリストの選択、ツリーにフォーカスがあるときはツリーの選択を対象にし、プレビューにフォーカスがあるとき、ペインの表示切り替えで対象のペインを隠している間（FR-092）、フルスクリーン中、スライドショー実行中は無効にする。
- **FR-185**: 「パス名をコピー」はファイルシステムを変更せず、確認モーダルを出さず、ファイルリスト・ツリー・プレビューの選択・フォーカス・スクロール・再生状態を変えない。成功しても結果の表示を出さない。
- **FR-186**: メニュー項目の位置は、ファイルリストでは「コピー」の直後、ツリーでは「Finder に表示」と同じ区切りの中の直前とする。名前は日本語「パス名をコピー」、英語「Copy as Pathname」とし、表示言語の切り替えに追従する（FR-146）。対象の名前を含めない固定の名前とする（複数選択時に名前を決められないため）。お気に入りの項目では、右クリックメニューの「名前を変更」「お気に入りから削除」の後に区切り線を置いて「パス名をコピー」を置く。

### Key Entities

- **コピー対象のパス**: 対象の行が指す実在のファイルシステム上の絶対パス。zip の中の項目と `..` は持たない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-086**: ツリー（通常のフォルダ・ホーム・ボリューム・お気に入り）とファイルリスト（メディア・フォルダ・zip ファイル・検索結果）の各対象で、貼り付けた文字列が対象の絶対パスと100%一致する。
- **SC-087**: 複数選択・`..`・zip の中・見つからないお気に入り・名前の変更中・「お気に入り」の見出しで、クリップボードが変わる場合が 0 件。
- **SC-088**: 右クリックから貼り付けまでを、説明なしの Finder に慣れたユーザーが初回で完了できる。
- **SC-089**: 「パス名をコピー」の実行でファイルシステム・選択・プレビューが変わる場合が 0 件。

## Assumptions

- **A-100**: zip の中の項目は絶対パスを持たないため対象外とする。zip 内のパスの表現（例: `/a/b.zip!/dir/file`）は定めない。
- **A-101**: 複数選択へのコピーは対象外（Issue の範囲外）。複数の行を選んでいる間はメニュー項目を淡色にする。
- **A-102**: ⌥⌘C は既存のショートカットと衝突しない（確認済み）。⌘C（ファイルのコピー）とは別の操作で、クリップボードを文字列に置き換える。
- **A-103**: 存在しなくなった項目のパスも、表示している絶対パスをそのままコピーする。
- **A-104**: 見つからないお気に入りの項目は、他の操作（Finder に表示など）と同じく利用できないものとして扱う。
