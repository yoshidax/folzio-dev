## User Scenarios & Testing *(mandatory)*

変更点だけを定める。ファイルリストの選択（FR-016・FR-017、file-list.md）、プレビューペインの表示（FR-028〜FR-038、preview.md）、
⌘O（開く）の対象（`ListItemCommands.allowsFileOperations`、keyboard-and-menus.md）は変えない。

### User Story 1 - Space で Finder のようにメディアを一時プレビューする (Priority: P1)

利用者は、ファイルリストでメディアを選んで Space を押し、その行（サムネイル）の位置から拡大する一時プレビューで内容を確かめ、もう一度 Space を押して閉じる。

**Why this priority**: 要望の中心。Finder と同じ操作で、ペインの表示を変えずにメディアを大きく確認できる。

**Independent Test**: フォルダを開き、画像と動画を各1件選んで Space を2回押す。リスト形式とサムネイル形式の両方で行う。

**Acceptance Scenarios**:

- **US3-AS23**: **Given** ファイルリストにフォーカスがあり、メディアファイル1件を選択中, **When** Space を押す,
  **Then** その行（サムネイル形式では選択中のサムネイル）の位置を起点に拡大するアニメーションで、Quick Look のプレビューが表示される。「プレビュー」アプリは起動しない
- **US3-AS24**: **Given** 一時プレビューを表示中, **When** もう一度 Space を押す, **Then** 元の行（サムネイル）の位置へ縮むアニメーションで閉じる。ファイルリストの選択・フォーカス・スクロール位置は開く前と同じ
- **US3-AS25**: **Given** ファイルリストにフォーカスがあり、動画を選択中, **When** Space を押す,
  **Then** 動画の再生／一時停止は切り替わらず、一時プレビューが開く（FR-033 の Space はファイルリストでは使わない）
- **US3-AS35**: **Given** 一時プレビューを表示中でメディア1件を選択している, **When** ↓ または → を押す（リスト形式は ↑↓、サムネイル形式は ←→↑↓）,
  **Then** ファイルリストの選択が次のメディアへ移り、一時プレビューの内容がそのファイルに切り替わる。起点の位置もそのファイルの行（サムネイル）に更新される
- **US3-AS36**: **Given** 一時プレビューを表示中, **When** 矢印キーで移動した先がフォルダ・zip ファイル・`..` の行になる,
  **Then** ファイルリストの選択はその行へ移り、一時プレビューはその行に表示するメディアがないため閉じる（再び Space を押しても対象がなければ開かない。EC-165）
- **US3-AS26**: **Given** プレビューペインの動画にフォーカスがある, **When** Space を押す,
  **Then** 従来どおり動画の再生／一時停止が切り替わり、一時プレビューは開かない（FR-033）

### User Story 2 - 複数選択・検索結果でも Space で一時プレビューする (Priority: P2)

利用者は、複数のメディアを選んで Space を押すと、選んだメディアを順に見られる。検索結果のメディアにも同じ操作を使う。

**Why this priority**: 整理作業の確認に使う。単一選択の動作（US1）が先に成り立てば、独立して価値がある。

**Independent Test**: 3件のメディアを選んで Space を押し、矢印キーで切り替える。検索結果でも同じ操作をする。

**Acceptance Scenarios**:

- **US3-AS27**: **Given** メディアを3件選択中, **When** Space を押す, **Then** 3件を Quick Look の複数ファイル形式の UI で表示し、一覧の並び順で先頭の選択項目から始める。
  ツールバーの `<` `>` ボタンのクリックで3件の間を移動できる。この移動ではファイルリストの選択は変わらない
- **US3-AS37**: **Given** メディアを3件選択して一時プレビューを複数ファイル形式で表示中, **When** 矢印キーを押す,
  **Then** ファイルリストの通常の矢印キーの規則（FR-016・FR-017）で選択が移り、一時プレビューは新しい選択の内容に切り替わる（1件の選択になれば1件の表示になる）
- **US3-AS28**: **Given** メディアとフォルダが混ざった複数選択, **When** Space を押す, **Then** 選択中のメディアだけを対象にする。メディアが1件もなければ何もしない
- **US3-AS29**: **Given** 検索結果を表示中でメディアの行を選択している, **When** Space を押す, **Then** 通常のフォルダと同じく一時プレビューが開き、起点は検索結果の行の位置になる
- **US3-AS30**: **Given** 一時プレビューを表示中で、矢印キーを押していない, **When** プレビューを閉じる（Space・Esc・閉じるボタン）, **Then** 検索結果の表示・複数選択・フォーカスの行は変わらない。
  矢印キーで選択を移していた場合は、閉じた時点の選択が残る

### User Story 3 - メディアのダブルクリックで既定のアプリで開く (Priority: P1)

利用者は、ファイルリストのメディアの行（サムネイル）をダブルクリックして、OS でそのファイルの種類に関連付けられたアプリで開く。

**Why this priority**: 要望の中心。Space による確認の後、そのまま編集・再生のアプリへ渡せる。

**Independent Test**: リスト形式とサムネイル形式のそれぞれで、画像と動画をダブルクリックする。

**Acceptance Scenarios**:

- **US3-AS31**: **Given** ファイルリストにメディアの行がある（リスト形式・サムネイル形式）, **When** その行をダブルクリックする,
  **Then** そのファイルが、OS で関連付けられた既定のアプリで開く。行はダブルクリックした1件だけの選択になり、プレビューペインにもそのメディアが表示される
- **US3-AS32**: **Given** 検索結果のメディアの行, **When** ダブルクリックする, **Then** 通常のフォルダと同じく既定のアプリで開く。検索結果の表示は変わらない
- **US3-AS33**: **Given** フォルダ・zip ファイル・zip の中のディレクトリ・`..` の行, **When** ダブルクリックする,
  **Then** 従来どおり中の表示または階層の移動を行い、既定のアプリは起動しない（FR-069・070・076）
- **US3-AS34**: **Given** 一時プレビューを表示中, **When** ファイルリストのメディアの行をダブルクリックする, **Then** 一時プレビューを閉じてから、そのファイルを既定のアプリで開く

### Edge Cases

- **EC-164**: 一時プレビューは、ファイルリストにフォーカスがあるときだけ開く。ツリー・プレビュー・検索シート・設定ウインドウにフォーカスがあるとき、フルスクリーン中、
  名前の変更中、スライドショー実行中は Space を一時プレビューに使わない（名前の変更中の Space は文字入力、ほかは従来の動作）
- **EC-165**: 選択がない、またはメディアでない行（フォルダ・zip ファイル・`..`）だけの選択で Space を押したときは、何もしない。ビープ音も出さない
- **EC-166**: 一時プレビューの表示中に、選択中のファイルが削除・移動・名前の変更で消えた、またはフォルダの表示が切り替わった（戻る・進む、検索の開始・終了）ときは、
  一時プレビューを閉じる。存在しない項目を表示し続けない
- **EC-167**: 一時プレビューの起点の行がスクロールで見えない位置にあるときは、見える位置にスクロールしてから開く（FR-017 と同じ必要最小限のスクロール）。
  それでも位置が決まらない場合は、ファイルリスト全体の位置を起点にして、アニメーションなしで開いてもよい
- **EC-168**: macOS の「視差効果を減らす」がオンのとき、拡大・縮小のアニメーションは OS の標準の挙動に従う（アプリ側で独自に付け足さない）
- **EC-169**: 一時プレビューを表示している間、プレビューペインで再生中の動画は一時停止する（二重の音声を避ける）。矢印キーで選択が動画に移ったときも、
  表示している間はプレビューペインの動画を自動再生せず、一時停止の状態で表示する（FR-031・032 の自動再生は抑える）。閉じた後に再生を自動で始めない・再開しない
- **EC-170**: 既定のアプリを開けないとき（関連付けがない、ファイルがない、権限がない）は、⌘O と同じく何も表示せず、選択・プレビューも変えない
- **EC-171**: ダブルクリックでアプリを開いても、Folzio の選択・プレビュー・動画の再生状態は、ダブルクリックした行の選択に伴う通常の切り替え（FR-017・034）以外は変えない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-233**: ユーザーは、ファイルリストにフォーカスがありメディアファイルを選択しているとき、Space で macOS の Quick Look の標準パネルによる一時プレビューを開閉できなければならない。
  開くときは対象の行（サムネイル形式ではサムネイル）の画面上の位置を起点に拡大し、閉じるときはその位置へ縮む。表示は Quick Look の標準のものとし、
  「プレビュー」アプリの起動や独自の簡易プレビューで代替してはならない。対象は画像（静止画・アニメーション画像）と動画の両方とする
- **FR-234（変更）**: 動画の再生／一時停止のキーボード操作（Space）は、プレビューの動画にフォーカスがあるときに限る。
  ファイルリストにフォーカスがあるときの Space は FR-233 に従い、動画の行でも再生／一時停止を切り替えない（FR-033 の Space の規定を変更する）
- **FR-235**: 複数のメディアを選択しているときの Space は、選択中のメディアを一覧の並び順で Quick Look の複数ファイル形式の UI に渡す。
  `<` `>` ボタンによる項目の移動は Quick Look の標準の動作とし、ファイルリストの選択は変えない。
  メディアでない選択（フォルダ・zip ファイル・`..`）は対象から除く。対象が0件なら何もしない（EC-165）
- **FR-236**: FR-233〜235 と FR-237 は、リスト形式とサムネイル形式のどちらでも、通常のフォルダと検索結果のどちらでも同じに使える。
  ファイルリストのみ表示（⌃⌘2）でも使える。zip の中は対象外とする（A-145）
- **FR-237**: ユーザーは、ファイルリストのメディアの行（サムネイル）のダブルクリックで、そのファイルを OS が関連付けた既定のアプリで開けなければならない。
  ダブルクリックした行は1件だけの選択にする（従来どおり）。フォルダ・zip ファイル・zip の中のディレクトリ・`..` の行のダブルクリックは変えない（FR-069・070・076）。
  zip の中のメディアは対象外とする（A-145）
- **FR-238**: Space の一時プレビューが標準の Quick Look のパネルでは簡単に実現できないと技術検証で判断した場合は、FR-233〜236 を採用せず、
  Space の一時プレビューを見送る。独自の実装や、「プレビュー」アプリの起動で代替しない。この場合も FR-234 の変更は行わない（Space の動作は従来のまま）。
  FR-237（ダブルクリック）は FR-238 の判断に関係なく採用する
- **FR-240**: 一時プレビューの表示中は、矢印キー（⇧ との組み合わせを含む）を、1件選択でも複数選択でも、ファイルリストのキー入力として扱わなければならない。
  選択の移動と表示の規則は、ファイルリストにフォーカスがあるときの矢印キーと同じとする（FR-016・FR-017。フォルダ・zip・`..` の行にも止まる）。
  選択が変わったら、一時プレビューの項目（FR-235 の対象）と起点の位置を新しい選択に更新する。更新後に対象が0件になったときは閉じる（US3-AS36）
- **FR-239**: 一時プレビューを開いて閉じるだけの操作では、ファイルリストの選択・フォーカス・並べ替え・表示形式・スクロール位置と、プレビューペインの表示内容は変わらない
  （EC-166・169 の場合と、FR-240 の矢印キーによる移動を除く）。一時プレビューの表示中の Esc とパネルの閉じるボタンは、パネルを閉じるだけとし、検索結果の表示は終えない

### Key Entities

- **一時プレビューの対象**: 選択中のメディアファイルの URL の並び（一覧の並び順）と、各項目の画面上の起点の矩形。ファイルシステムのファイルだけを持ち、zip の中の項目は含まない

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-117**: リスト形式とサムネイル形式のそれぞれで、静止画・アニメーション画像・動画を1件ずつ選び、Space で開いて Space で閉じる操作を各5回行う。
  開かなかった回数が0回、「プレビュー」アプリが起動した回数が0回、矢印キーを押していない場合に閉じた後の選択・フォーカス・スクロール位置が開く前と異なった回数が0回となる
- **SC-118**: ファイルリストにフォーカスがあるときの Space で動画の再生状態が変わった回数が0回、プレビューの動画にフォーカスがあるときの Space で再生／一時停止が切り替わらなかった回数が0回となる（各5回）
- **SC-119**: 複数選択（3件）と検索結果で Space を各5回行い、選んだメディアの数だけ項目が表示され、メディアでない行だけの選択で Space を押して何かが開いた回数が0回となる。
  一時プレビュー表示中に、1件選択と3件選択のそれぞれで矢印キーを各10回押し、ファイルリストの選択と表示中のファイルが一致しなかった回数が0回となる
- **SC-120**: リスト形式とサムネイル形式のそれぞれで、画像と動画の行を各5回ダブルクリックし、既定のアプリで開かなかった回数が0回、フォルダ・zip ファイルの行のダブルクリックで既定のアプリが起動した回数が0回となる

## Assumptions

- **A-144**: 一時プレビューの表示と、起点・終点の拡大縮小のアニメーションは、macOS の Quick Look の標準パネルの機能で実現する想定である。
  この想定は、仕様の策定時点では実機で確認していない。Cloud では Swift を実行できないため、保守者が実機で確認する（検証方針）
- **A-149**: Quick Look の標準パネルのツールバーにある「"プレビュー"で開く」・マークアップ・回転・共有・一覧表示のボタンは、標準部品の一部としてそのまま残す（保守者が Finder の表示で確認した）。
  利用者が押したときだけ働き、Space の操作では「プレビュー」アプリは起動しない（FR-233）
- **A-145**: zip の中のメディアは、ファイルシステム上に実ファイルがなく、zip の中は読み取り専用（FR-073）で ⌘O も無効のため、Space もダブルクリックも何もしない。
  展開して開く機能は今回追加しない
- **A-146**: 一時プレビューの表示中のズーム、共有、`<` `>` ボタンなどの操作は Quick Look の標準パネルのものを使い、`<` `>` ボタンによる項目の移動は Folzio の選択と同期しない。
  矢印キーだけは FR-240 のとおりファイルリストのキー入力にする（Finder の挙動に合わせる）。⌘ を含む組み合わせ（⌘↓ など）は転送しない
- **A-147**: 新しい設定項目は追加しない。ショートカット一覧（⌘/）に、ファイルリストの Space を「クイックルック」として載せ、動画の Space の説明に「プレビューにフォーカス」の条件を足す
- **A-148**: メニューバーの項目の追加は行わない。キーボードの入口は Space、ダブルクリックのキーボードの代替は既存の ⌘O（開く）とする

## 検証方針

- Core で判断できる部分（Space の対象に含める行の選び方、ダブルクリックで既定のアプリを開く対象かどうか）は Swift Testing で自動検証する。
- Quick Look のパネルの表示・アニメーションの起点、Space の開閉、既定のアプリの起動は AppKit の実行が必要なため、quickstart.md の手順で保守者が実機確認する。
- Cloud の静的検査、macOS CI の build/test、保守者の起動スモークと実機確認を分けて記録する。
- **技術検証の判定（FR-238）**: 実機で、起点の位置からの拡大・縮小が標準部品の公開 API だけで成り立つかを最初に確認する。成り立たなければ Space の一時プレビューは見送り、ダブルクリックだけを採用する。
