# UI Contract: スライドショーのオプション設定

**Date**: 2026-10-26 | **Branch**: `007-slideshow-options`

本 feature の差分契約。要件の本文は [spec.md](../spec.md) を正とする。既存の [永続化する設定](../../product/contracts/settings.md)・[キーボードとメニュー](../../product/contracts/keyboard-and-menus.md)、および 006 の [contracts/slideshow.md](../../006-add-slideshow/contracts/slideshow.md) に対する追加・変更を記す。実装・検証の後、spec の「反映先」に従って product へ反映するまでは本 feature 内に置く。外部サービス・HTTP API・CLI は追加しない。

## 永続化するキー（contracts/settings.md への追加）

| キー | 型 | 既定値 | 対応 |
|------|----|--------|------|
| `slideshow.intervalSeconds` | Int（1〜3600） | 3 | FR-127・128・132 |
| `slideshow.repeats` | Bool | true | FR-127・129・132 |
| `slideshow.transition` | String（`none` / `crossfade` / `slide` / `zoom`） | `none` | FR-127・130・132 |

- 読み込み時に型や範囲が不正な項目は、その項目だけを既定値として扱う。`slideshow.intervalSeconds` は整数として正確に読めて 1〜3600 のときだけ採用する。小数・真偽値・文字列は既定値になる（EC-75）。
- 3項目は FR-003 の「各種オプション」として保存・復元する。実行状態・次の予定時刻・切り替えの途中の状態は保存しない（FR-126）。
- 既存のキーの名前・意味は変えない。移行処理は持たない。

## 設定ウインドウ（⌘,）

区分は上から「動画」「ファイル操作」「スライドショー」の順に並べる。

| 区分 | 項目 | コントロール | 既定値 | 対応キー |
|------|------|------------|--------|----------|
| スライドショー | 切り替え間隔と単位「秒」 | テキストフィールド | `3` | `slideshow.intervalSeconds` |
| スライドショー | 「最後まで表示したら先頭から繰り返す」 | チェックボックス | オン | `slideshow.repeats` |
| スライドショー | 切り替え効果（「なし」「クロスフェード」「スライド」「ズーム」） | ポップアップメニュー | 「なし」 | `slideshow.transition` |

- チェックボックスとポップアップメニューの変更は、操作した時点で保存して反映する。テキストフィールドは確定した時点で保存して反映する。再起動は要らない（A-60）。
- 「最後まで表示したら先頭から繰り返す」は「動画をループ再生する」とは独立した設定とする（FR-119）。

### キーボード（contracts/keyboard-and-menus.md への追加）

| 入力 | 動作 | 要件 |
|---|---|---|
| Tab／⇧Tab | 動画を自動再生する → 動画をループ再生する → 確認する → 切り替え間隔 → 繰り返す → 切り替え効果 → 先頭へ戻る（⇧Tab は逆順）。システムのキーボードナビゲーションの設定に関わらず、すべての項目に止まる | FR-127、SC-042 |
| Space（チェックボックス） | オン／オフを切り替えて保存する | FR-127 |
| Space（ポップアップメニュー） | メニューを開く。矢印キーで選び、Return で確定して保存する | FR-127 |
| Return（切り替え間隔） | 値を確定する | FR-128 |
| フォーカスの移動・ウインドウを閉じる（切り替え間隔の編集中） | 値を確定する | FR-128、EC-73 |
| Esc（切り替え間隔の編集中） | 編集を取り消し、直前の有効値の表示に戻す。保存しない。設定ウインドウを閉じない。スライドショーを終了しない | FR-128 |

### 切り替え間隔の確定

| 入力（確定時） | 結果 |
|---|---|
| 1〜3600 の整数（前後の空白、全角数字、先頭の `0` を含む） | 正規化した値（例 `１５` → `15`、`007` → `7`）を保存し、その値を表示する |
| 空欄・`0` 以下・小数・符号付き・桁区切り・数字以外を含む・3600 を超える | 保存値を変えず、フィールドを直前の有効値の表示へ戻す。警告のダイアログや音は出さない（FR-128） |

### アクセシビリティ

| 項目 | ラベル |
|---|---|
| 切り替え間隔のテキストフィールド | 切り替え間隔（秒） |
| 繰り返しのチェックボックス | 最後まで表示したら先頭から繰り返す |
| 切り替え効果のポップアップメニュー | 切り替え効果 |

## スライドショーの実行中の振る舞い（006 の contracts/slideshow.md への変更）

006 の契約にある「3秒」は、すべて「設定した切り替え間隔」に読み替える（FR-118・FR-121、A-54）。

### 間隔と繰り返し

| 出来事 | 契約 | 要件 |
|---|---|---|
| 開始 | 開始の操作から切り替え間隔の後に最初の自動送り | FR-118 |
| 自動送り | 各切り替えの開始から切り替え間隔の後に次へ。効果の完了・デコード・動画の終端を待たない | FR-118 |
| 受理した矢印 | 最後の押下から切り替え間隔の後に、その時点の選択の次へ1回進む | FR-121 |
| 繰り返しオン、末尾の次 | 先頭へ戻って続ける | FR-129、US12-AS6 |
| 繰り返しオフ、末尾から間隔が経過 | 次へ進まずに終了する。表示は受理した Esc の終了と同じ（全画面の解除、開始前のペイン表示・フォーカス、末尾のメディアの選択を保つ） | FR-129、A-52、US12-AS5 |
| 繰り返しオフ、対象1件 | 開始から間隔の後に終了する | EC-66 |
| 実行中に間隔を変更 | 予定済みの次の切り替えの時刻は変えない。その次から新しい間隔。矢印による待機の期限も変えない | FR-132、US12-AS9 |
| 実行中に繰り返し・効果を変更 | 次の自動送りの判断から新しい値を使う。実行は続ける | FR-132、EC-77 |

### 切り替え効果

| 効果 | 表示（約0.5秒、間隔の長さによらず一定） |
|---|---|
| なし | 006 と同じく即座に切り替える |
| クロスフェード | 前の表示が薄れると同時に、次のメディアが現れる |
| スライド | 次のメディアが右から入り、前の表示を左へ押し出す。末尾から先頭へ戻る場合も同じ向き |
| ズーム | 前の表示が薄れる間に、次のメディアが中央から拡大しながら現れ、等倍で止まる |

| 条件 | 契約 | 要件 |
|---|---|---|
| 効果を使う場面 | スライドショーの自動送りで、表示するメディアが変わる場合だけ。エラー表示への切り替え・エラー表示からの切り替え、空の表示からの切り替えを含む | FR-130、EC-67・EC-79 |
| 効果を使わない場面 | 開始時の最初の表示、矢印による選び直し、終了時の復帰、スライドショー以外での選択の変更、対象1件で同じ表示を保つ場合 | FR-131、EC-66、US13-AS5・AS8 |
| 前が動画 | 切り替えの開始時点で再生と音声を止め、そのときのフレームで静止した表示を効果に使う | EC-78、Clarifications |
| 次が動画 | 切り替えの開始時点から、既存の自動再生・ループの設定に従う | EC-78 |
| 次の表示の準備が間に合わない | 前の表示を保ったまま待ち、準備ができた時点で効果を始める。次の予定時刻までに準備が終わらなければ効果をやめ、通常どおり次へ進む。表示不能はエラー表示の判定が済んだ時点、動画は最初のフレームを表示できる時点で準備完了とする | FR-130、EC-80 |
| 効果の途中の矢印・Esc | 効果を打ち切り、操作の結果を即座に表示する。矢印は選び直したメディア、Esc は終了と復帰 | FR-131、US13-AS6 |
| 準備待ち・効果の途中の矢印・Esc の基準 | 前の表示の写しが見えていても、選択中のメディア（次の対象）を基準とする。矢印は選択中のメディアから選び直し、Esc は選択中のメディアの選択を保って終了する | EC-80、FR-121・FR-129 |
| 効果の途中の全画面の切り替え・ウインドウのリサイズ | 効果を打ち切り、次のメディアをそのまま表示する。実行と次の予定時刻は変えない | FR-131、EC-80 |
| 視差効果を減らす がオン | 「スライド」「ズーム」を「クロスフェード」で表示する。保存値と設定ウインドウの表示は変えない | FR-131、A-59、US13-AS7 |

効果の表示中も、マウスのクリック（画像のダブルクリックによる全画面の切り替えを含む）は下のプレビューへ届く。効果の表示は VoiceOver の要素にならない（FR-131）。

状態の責務と遷移は [data-model.md](../data-model.md)、検証の手順は [quickstart.md](../quickstart.md) を参照。
