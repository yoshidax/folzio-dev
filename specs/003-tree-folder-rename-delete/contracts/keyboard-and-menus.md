# Contract 差分: キーボード操作とメニュー

`specs/product/contracts/keyboard-and-menus.md` への変更点。実装と検証が終わってから、この内容を反映する
（spec.md の「反映先」）。ここに書かない部分は変えない。

## 1. 「名前の変更中」の定義（FR-102 の変更）

文書の冒頭の定義を次に置き換える。

> 「名前の変更中」は、ファイルリストでのファイル名の変更（FR-019）、ツリーでのお気に入りの表示名の編集（FR-099）、
> ツリーでのフォルダの名前の編集（FR-103）のすべてを指す（FR-102）。

## 2. ディレクトリツリーの表（FR-103・FR-079 の変更）

`⌘Delete` の行を次に置き換える。

| キー | 動作 |
|------|------|
| ⌘Delete | 通常のフォルダ（ホーム・ボリュームの最上位を除く）を選択中のとき、確認モーダルの後にフォルダを中身ごとゴミ箱に入れる。確認モーダルにはフォルダ名と絶対パスを示し、確認モーダルの省略設定に関わらず必ず表示する（「今後この確認を表示しない」も出さない）。表示中のフォルダ（またはその祖先）を入れたときは、親フォルダを選択してその一覧を表示し、フォーカスはツリーに残る（FR-079）。お気に入りの項目を選択中のときは、確認モーダルの後にお気に入りから削除する（実際のフォルダは変えない）。ホーム・ボリュームの最上位・「お気に入り」の見出しでは何もしない（FR-064） |

`Return` の行を次に置き換える。

| キー | 動作 |
|------|------|
| Return | お気に入りの項目を選択中のとき、その項目の表示名の編集を行の中で始める（現在の表示名を全選択）。Return で確定、Esc で取り消す。ほかの場所のクリックでも確定する。確定した名前は前後の空白を除き、空なら登録したフォルダの名前に戻す。実際のフォルダの名前は変えず、確認モーダルも出さない（FR-099〜101）。通常のフォルダ（ホーム・ボリュームの最上位を除く）を選択中のとき、そのフォルダの名前の編集を行の中で始める（最後の「.」より前を選択）。Return で確定、Esc で取り消す。ほかの場所のクリックでも確定する。確定した名前は前後の空白を除き、空・編集前と同じなら何もしない。名前の検証と確認モーダル（フォルダ名と絶対パスを示し、常に表示する）はファイルリストの名前の変更と同じ（FR-103）。「お気に入り」の見出し・ホーム・ボリュームの最上位を選択中は何もしない。ファイルリストに zip の中や検索結果を表示中でも使える |

表の下の段落（「お気に入りの項目は、表示名を…」）の「名前の編集中は、ツリーのメニュー項目（…）を無効にする（FR-102）。」の前に
次の1文を足す。

> 通常のフォルダの名前の編集欄には「フォルダの名前」のアクセシビリティラベルを付ける（FR-103）。

## 3. 右クリックメニュー（ツリー）の通常のフォルダ（FR-103、A-37）

「通常のフォルダ（ホーム・ボリュームのルートを含む）:」の一覧を次に置き換える。

1. ゴミ箱に入れる（⌘Delete）
2. ─
3. 名前を変更（Return）
4. ─
5. ここにペースト / ここに移動ペースト
6. ─
7. お気に入りに追加（⌃⌘T）（登録済みのフォルダでは無効）
8. ─
9. Finder に表示

（ホーム・ボリュームのルートでは、1〜4（「ゴミ箱に入れる」「名前を変更」とその後の区切り線）を出さない。FR-079・FR-103）

一覧の後の段落を次に置き換える。

> 「ゴミ箱に入れる」と「名前を変更」は右クリックした行のフォルダを対象にし、ツリーの選択は変えない（選択中の行ではない。A-21・A-36）。
> 「ゴミ箱に入れる」の確認モーダルはフォルダ名と絶対パスを示し、確認モーダルの省略設定に関わらず必ず表示する（FR-079）。
> ゴミ箱経由・失敗の表示はファイルリストのゴミ箱と同じ（FR-021・026）。「名前を変更」の編集・検証・確認は ⌘Delete の表の Return と同じ（FR-103）。
> 名前の編集中に右クリックメニューを開いたときは、先に編集を確定する（お気に入りの項目と同じ）。

## 4. メニューバーの箇条書き（FR-079・FR-103 の変更）

「ゴミ箱に入れる」（ファイル・編集の両メニュー、⌘Delete）の項目の末尾に次を足す。

> ツリーの通常のフォルダをゴミ箱に入れるときは、確認モーダルの省略設定に関わらず、フォルダ名と絶対パスを示す確認モーダルを必ず表示する（FR-079）。

「編集 > 名前を変更」（Return）の項目を次に置き換える。

> - 「編集 > 名前を変更」（Return）は、ツリーにフォーカスがあるとき、お気に入りの項目を選択中ならその項目の表示名の編集を、
>   通常のフォルダ（ホーム・ボリュームの最上位を除く）を選択中ならそのフォルダの名前の編集を始める。ツリーにフォーカスがあり、
>   それ以外（「お気に入り」の見出し・ホーム・ボリュームの最上位）を選択中のとき（または何も選択していないとき）は無効。名前の変更中は無効。
>   ツリーにフォーカスがあるときは、ファイルリストに zip の中や検索結果を表示中でも上の規則で有効になる（zip の中の読み取り専用と
>   検索結果の制限はファイルリストにフォーカスがあるときだけ効く）。ファイルリストにフォーカスがあるときは従来どおりファイル名の変更（FR-019・073）

## 5. 確認モーダルと衝突ダイアログ（FR-024・FR-079 の変更）

「確認モーダルには「今後この確認を表示しない」チェックボックスを置き…」の項目を次に置き換える。

> - 確認モーダルには「今後この確認を表示しない」チェックボックスを置き、設定の `confirmBeforeFileOperations` と連動させる（FR-023）。
>   ただしファイルリストからのコピー・削除でだけ省略でき、名前の変更と移動、およびツリーのフォルダをゴミ箱に入れる操作の確認モーダルは
>   設定に関わらず常に表示し、チェックボックスも出さない（FR-024・079）。複製（⌘D）は確認モーダルを出さず、設定にも影響されない（FR-018・024）
> - ツリーから行うゴミ箱に入れる操作と名前の変更の確認モーダルは、上の内容に加えて対象のフォルダの絶対パスを示す（FR-079・103）

表示する本文（実装の参考。R58）:

```text
ゴミ箱に入れますか？

対象: 1 件
・<フォルダ名>
フォルダは中身ごとゴミ箱に入ります
場所: <フォルダの絶対パス>
```

```text
名前を変更しますか？

対象: 1 件
・<変更前のフォルダ名>
フォルダは中身ごと操作します
場所: <変更前のフォルダの絶対パス>
```
