## 2. 準備（GUI の確認の前に）

```bash
T=~/MediaViewerTreeRenameTest
mkdir -p "$T/Album/2025/Trip" "$T/Album/2025/Home" "$T/Album/Other" "$T/Photo" "$T/Photos"
# 検索・プレビュー用のメディア。動画は再生が途中で止まらないかを見るため、数十秒以上のものを置く
# 画像は OS に同梱のアイコンから作る（どの Mac にもある）
ICON=/System/Library/CoreServices/CoreTypes.bundle/Contents/Resources/GenericDocumentIcon.icns
for n in 1 2 3; do sips -s format png "$ICON" --out "$T/Album/2025/Trip/photo$n.png" >/dev/null; done
sips -s format png "$ICON" --out "$T/Album/2025/Home/home1.png" >/dev/null
# 動画は手元のファイルを置く（例: cp ~/Movies/sample.mov "$T/Album/2025/Trip/"）
# zip の中の表示（EC-50）用
(cd "$T/Album/2025/Trip" && zip -q ../trip.zip photo*.png)

pgrep -fl MediaViewer   # 残っているプロセスがないこと
scripts/make-app.sh
open .build/MediaViewer.app
```

アプリで `~/MediaViewerTreeRenameTest/Album/2025` と `~/MediaViewerTreeRenameTest/Photos` をお気に入りに登録し（⌃⌘T）、
`Photos` の表示名を「写真（テスト）」に変えておく。設定で「コピー・ゴミ箱に入れる・お気に入りから削除する前に確認する」を**オフ**にする
（10・11 で、それでもツリーのゴミ箱が確認することを見るため）。

元に戻すとき: アプリを終了し、お気に入りから2件を削除してから `rm -rf ~/MediaViewerTreeRenameTest`。設定の確認を元に戻す。
