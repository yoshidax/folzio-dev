## User Scenarios & Testing *(mandatory)*

### User Story 1 - フォルダを辿って画像をプレビューする（既存 US1 への追加）

ツリーでフォルダを辿っている最中に、フォルダの名前の誤りに気づいたり、整理のために名前を付け直したくなったりする。
今はファイルリストで親フォルダを開いてからでないと名前を変えられない（FR-076（file-list.md））。ユーザーは、ツリーの
フォルダをその場で、ファイルリストと同じ操作（Return・右クリックメニュー）で名前を変えたい。名前を変えても、いま
ファイルリストで見ているフォルダの表示や、検索結果・お気に入りの状態が食い違ってはならない。

ツリーのフォルダをゴミ箱に入れる操作（FR-079（file-operations.md））は、選択中でない行を右クリックしても行えるが、
選択中のフォルダと別のフォルダを対象にするため取り違えやすい。そのため、ツリーのフォルダをゴミ箱に入れるときは
確認モーダルの省略設定に関わらず必ず確認する。

**Why this priority**: フォルダを辿る主要な流れ（US1）の途中で、ペインを移らずに整理を続けられるため。名前の変更と
削除はファイルシステムを変えるため、表示の食い違いや取り違えによる誤操作を防ぐことも同じく重要である。

**Independent Test**: ツリーで通常のフォルダを選択して Return で名前を変え、確認モーダルで確定する。Finder で実際の
フォルダの名前が変わっていること、ツリーとファイルリストの表示が新しい名前になっていること、Esc・確認モーダルの
キャンセルでは何も変わらないことを確かめる。続けて、選択中でない別のフォルダを右クリックして「ゴミ箱に入れる」を選び、
確認モーダルの省略設定をオンにしていても確認モーダルが出ることを確かめる。

**Acceptance Scenarios**:

- **US1-AS36**: **Given** ツリーで通常のフォルダを選択し、ツリーにキーボードフォーカスがある, **When** Return を押して
  新しい名前を入力し、Return で確定して確認モーダルで「実行」を選ぶ, **Then** 実際のフォルダの名前が変わり、ツリーでは
  新しい名前で並び順の位置に表示され、選択と展開状態はそのまま保たれる
- **US1-AS37**: **Given** ツリーでフォルダ A を選択している, **When** 別のフォルダ B の行を右クリックして「名前を変更」を選び、
  名前を確定して確認モーダルで「実行」を選ぶ, **Then** フォルダ B の名前が変わり、ツリーの選択はフォルダ A のまま、
  ファイルリストの表示も変わらない
- **US1-AS38**: **Given** ツリーのフォルダの名前を編集している, **When** Esc を押す, **Then** 編集を取り消し、
  確認モーダルは出ず、フォルダの名前は変わらない。確認モーダルで「キャンセル」を選んだ場合も名前は変わらない
- **US1-AS39**: **Given** ツリーのフォルダの名前を編集している, **When** 「/」「:」を含む名前、先頭が「.」の名前、
  同じ場所にある項目と同じ名前（大文字小文字の違いだけのものを含む）、またはパッケージとして扱われる名前（例: `Photos.app`）で
  確定する, **Then** ファイルリストの
  名前の変更と同じ検証エラーが表示され、フォルダの名前は変わらない
- **US1-AS40**: **Given** ファイルリストにツリーで選択したフォルダの内容を表示し、ファイルを選択してプレビュー中,
  **When** ツリーでそのフォルダ（またはその祖先）の名前を変える, **Then** ファイルリストの項目・選択・スクロール位置と
  プレビューは変わらず、再生中の動画も止まらない。続けて ⌘↑ や `..` で戻ると、新しい名前のフォルダの親に戻る
- **US1-AS41**: **Given** ファイルリストにフォルダ P の一覧を表示中で、P のサブフォルダ C がツリーにも表示されている,
  **When** ツリーで C の名前を変える, **Then** ファイルリストの C の行も新しい名前になり、並び順の位置へ移る
- **US1-AS42**: **Given** 検索結果を表示中で、一覧の「場所」列にフォルダ F を含むファイルがある, **When** ツリーで F の
  名前を変える, **Then** それらのファイルは一覧に残り、「場所」列（サムネイル形式ではツールチップ）が新しい名前に
  変わる。選択とプレビューはそのまま保たれる
- **US1-AS43**: **Given** フォルダ F がお気に入りに登録され、表示名を変えている, **When** ツリーで F の名前を変える,
  **Then** お気に入りの項目は見つからない表示（淡色）になる。もう一度 F の名前を元に戻すと、項目は同じ位置・同じ
  表示名のまま通常の表示に戻る
- **US1-AS44**: **Given** ツリーでフォルダ A を選択し、確認モーダルの省略設定（FR-023（file-operations.md））がオン,
  **When** 別のフォルダ B の行を右クリックして「ゴミ箱に入れる」を選ぶ, **Then** B のフォルダ名と絶対パスを示す確認モーダルが
  必ず表示され、確定すると B が中身ごとゴミ箱に入り、ツリーの選択はフォルダ A のまま変わらない。キャンセルすると
  何も変わらない。A を選択中に ⌘⌫ を押した場合と、「ファイル」「編集」メニューの「ゴミ箱に入れる」を選んだ場合も、省略設定に関わらず
  A のフォルダ名と絶対パスを示す確認モーダルが表示される
- **US1-AS45**: **Given** ツリーでホーム・ボリュームの最上位・「お気に入り」の見出しを選択している（または右クリックした）,
  **When** Return を押す（または右クリックメニューを見る）, **Then** 名前の編集は始まらず、右クリックメニューに
  「名前を変更」は出ない
- **US1-AS35**（変更。002 で追加した項目）: **Given** ツリーで「お気に入り」の見出し、またはホーム・ボリュームの最上位を
  選択している, **When** Return を押す, **Then** 何も起きない（名前の編集は始まらず、実際のフォルダの名前も変わらない）。
  ツリーの通常のフォルダの Return は、実際のフォルダの名前の変更（US1-AS36）とする
- **US4-AS7**（変更。US4 の項目）: **Given** 確認を省略する設定が有効, **When** コピーまたは削除を実行する, **Then** モーダルなしで
  即座に実行される（削除はゴミ箱へ移動するため元に戻せる）。名前の変更と移動、およびツリーのフォルダをゴミ箱に入れる操作
  （FR-079）では、設定に関わらず確認モーダルが表示される

### Edge Cases

- **EC-47**: 名前の編集中や確認モーダルの表示中に、対象のフォルダがアプリの外で削除・移動・名前変更された場合は、確定しても
  名前を変えず、対象のフォルダ名と失敗の理由を表示する（FR-026（file-operations.md））。書き込み権限のないフォルダや
  読み取り専用のボリューム上のフォルダも、失敗の理由を表示し、部分的な変更を残さない（EC-08（file-operations.md））
- **EC-48**: 空の名前（前後の空白だけを含む）、または編集前と同じ名前で確定した場合は、エラーも確認モーダルも出さずに
  編集を終え、何も変えない（ファイルリストの名前の変更と同じ）
- **EC-49**: フォルダの名前に「.」が含まれていても、拡張子の変更の確認（EC-15（file-operations.md））は行わない
  （ファイルリストのフォルダの名前の変更と同じ）
- **EC-50**: ファイルリストに、名前を変えたフォルダ（またはその配下）にある zip ファイルの中を表示している場合も、
  zip の中の一覧・選択・プレビューは変わらない。以後の `..`・⌘↑ は新しい場所を辿る
- **EC-51**: お気に入りの項目を選択してそのフォルダをファイルリストに表示中に、ツリーの実際の階層でそのフォルダ（または
  その祖先）の名前を変えた場合、お気に入りの項目は見つからない表示になるが、ファイルリストの表示は変えない
  （FR-104）。その項目を選択し直すと「フォルダが見つかりません」を表示する（FR-067（directory-tree.md））
- **EC-52**: 検索中に検索起点の配下のフォルダの名前を変えた場合も、検索を止めずに続け、名前を変える前に見つかった
  ファイルは新しい場所で一覧に残り、以後に見つかったファイルも新しい場所で加わる（FR-105）
- **EC-53**: フォルダの名前を、システムがパッケージ（`.app` など。FR-006（directory-tree.md））として扱う名前（例: `Photos.app`）に
  変えようとした場合は、検証エラーを表示して拒否し、名前を変えない（名前を変えただけでフォルダがツリーとファイルリストから
  見えなくなる事故を防ぐ）。ツリーのフォルダの名前の変更（FR-103）とファイルリストのフォルダの名前の変更の両方に適用する（EC-14）。
  ファイルの名前の変更には適用しない（ファイルはパッケージにならない）。これにより、フォルダの名前の変更で配下のファイルが
  検索の対象外（FR-083（search.md））になる場合はなくなる（先頭の「.」も FR-103 で拒否する）
- **EC-14**（変更。file-operations.md の項目）: リネームで使用できない文字、同名の既存ファイルを指定した場合、または
  フォルダの名前をシステムがパッケージとして扱う名前（EC-53）に変えようとした場合はエラーを表示し確定しない。空の名前
  （前後の空白だけを含む）と編集前と同じ名前は、エラーを出さずに何もしない（EC-48）
- **EC-17**（変更）: ファイルリストのフォルダをゴミ箱に入れた・移動した・名前を変更した場合、またはツリーでフォルダを
  ゴミ箱に入れた・名前を変更した場合（FR-079・FR-103）、ツリーとファイルリストの該当項目にも即座に反映する（FR-027）。
  そのフォルダ（またはその配下のフォルダ）がお気に入りに登録されていれば、FR-067 に従って見つからない表示になり、
  名前を元に戻せば通常の表示に戻る（FR-106）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-103**: ユーザーは、ツリーの通常のフォルダ（ホーム・マウント中のボリュームの最上位の下にある実際のフォルダ。FR-079 と
  同じ範囲）の名前を、次のどの手段でも変更できなければならない。
  （1）そのフォルダをツリーで選択し、ツリーにキーボードフォーカスがあるときに Return を押す。
  （2）そのフォルダの行の右クリックメニューの「名前を変更」を選ぶ（右クリックした行を対象にし、選択中の行でなくてもよい。
  A-21（directory-tree.md））。
  （3）ツリーにキーボードフォーカスがあり、そのフォルダを選択しているときに「編集」メニューの「名前を変更」を選ぶ。
  名前の編集はその行の中で行い、編集の始め方と終え方、名前の検証、確認はファイルリストのフォルダの名前の変更と同じとする。
  すなわち、編集を始めたときは現在の名前を入れ、ファイルリストと同じ範囲（最後の「.」より前。「.」がなければ全体）を選択した
  状態にする。Return またはほかの場所のクリックなどで確定し、Esc で取り消す（名前を変えず、確認モーダルも出さない）。確定した名前は
  前後の空白（改行を含む）を取り除き、空、または編集前と同じ名前なら何もしない。「/」または「:」を含む名前、先頭が「.」の名前、
  同じ場所にある項目（ツリーやファイルリストに表示していない隠し項目やファイルを含む）と大文字小文字の違いだけを含めて同じ名前、
  システムがパッケージとして扱う名前（EC-53）は、検証エラーを表示して拒否する（EC-14・FR-025（file-operations.md））。検証を通った名前は、確認モーダル（FR-022）を設定に
  関わらず表示してから変更し（FR-024（file-operations.md））、キャンセルした場合は変更しない。この確認モーダルには、ファイルリストの
  名前の変更の確認モーダルの内容に加えて、対象のフォルダの絶対パスを示す（同じ名前の別のフォルダと見分けられるようにする）。
  名前の編集欄には「フォルダの名前」というアクセシビリティラベルを付ける（お気に入りの表示名の編集欄の「お気に入りの名前」
  （FR-101（002））と区別する）。失敗した場合は FR-026 に従って
  表示する。編集を始めても、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003（overview.md））は
  変えない。ホーム・ボリュームの最上位・「お気に入り」の見出しを選択中の Return は何もせず、それらの右クリックメニューに
  「名前を変更」は出さず、それらを選択中は「編集」メニューの「名前を変更」を無効にする。お気に入りの項目の Return・
  「名前を変更」は、従来どおり表示名の変更（FR-099（002））とする。ファイルリストに zip の中または検索結果を表示中でも、
  ツリーにフォーカスがあれば（1）〜（3）は使える（zip の中の読み取り専用と検索結果の制限はファイルリストの操作にだけ適用する）。
  ファイルリストにフォーカスがあるときの Return と「名前を変更」は、従来どおりファイル名の変更（FR-019（file-operations.md））とする
- **FR-104**: ツリーでフォルダの名前を変えたとき、システムは結果を次のとおり即座に反映しなければならない（FR-027）。
  ツリーでは、そのフォルダを新しい名前で、兄弟フォルダの中の並び順の位置に表示する。そのフォルダと配下の展開状態とサブフォルダの
  有無の確認結果（FR-054・FR-055）は保つ。名前を変えたフォルダ（またはその配下）を選択していた場合は選択を保ち、選択中の行全体が
  見える位置まで必要最小限のスクロールを行う。そうでない場合は、ツリーの選択を変えない。
  ファイルリストが、名前を変えたフォルダ自身またはその配下（その中の zip ファイルの中を含む）を表示している場合は、一覧の項目・
  並び順・選択・スクロール位置・表示形式・プレビュー（再生中の動画も止めない）を変えない。以後の操作（`..`・⌘↑・ファイル操作・
  検索のモーダルの検索起点の既定値など）は新しい場所を対象にする。
  ファイルリストが、名前を変えたフォルダの親を表示している場合は、そのフォルダの行を新しい名前にし、並べ替えの位置へ移す
  （選択していれば選択を保つ）。
  最後に選択していたフォルダ（FR-003（overview.md））が、名前を変えたフォルダ自身またはその配下であれば、新しい場所として
  保存する。これらのどれにも当たらない場合は、ファイルリストとプレビューを変えない
- **FR-105**: 検索結果を表示中（検索中を含む）に、ツリーで検索結果のファイルを含むフォルダ（検索起点そのもの、その祖先、
  または配下のフォルダ）の名前を変えた場合、システムは次のとおり一覧を同期しなければならない。
  該当するファイルは一覧に残し、リスト形式の「場所」列とサムネイル形式のツールチップ（FR-084（search.md））を新しい名前で表示する。
  検索起点そのものの名前を変えた場合は、検索バーの起点のフォルダ名とツールチップの絶対パスも新しい名前にする（アプリの外での
  削除・移動を扱う EC-36（search.md）とは区別し、結果を外さない）。検索起点の祖先の名前を変えた場合は、検索バーのツールチップの
  絶対パスを新しい名前にする。「場所」列で並べ替えている場合は並べ直す。選択・プレビューは保つ。
  新しい場所が検索の対象（FR-083（search.md））でなくなったファイルは一覧から外し（FR-103 の検証により、ツリーやファイルリストでの
  名前の変更ではこの場合は起きない。名前の変更を検索結果へ反映する処理の規則として定める）、それがプレビュー中だった場合はプレビューを
  空にして再生中の動画を止める（FR-087（search.md）と同じ）。検索中であれば検索を止めずに続け、以後に見つかったファイルも
  新しい場所で加える。フォルダの名前は検索キーワードと照合しない（FR-082・FR-083（search.md））ため、フォルダの名前の変更で
  一覧にファイルが加わることはない
- **FR-106**: ツリーで名前を変えたフォルダ、またはその配下のフォルダがお気に入りに登録されている場合、システムはファイルリストで
  フォルダの名前を変えた場合（EC-17（file-operations.md））と同じく、その項目を FR-067（directory-tree.md）に従って見つからない
  表示（淡色）にし、新しい名前に追従してはならない。その後、ツリー・ファイルリスト・アプリの外のいずれかでフォルダを元の名前
  （元の場所）に戻したときは、項目を通常の表示に戻す。このとき、項目の並び位置と表示名（FR-101（002））は名前を変える前と
  同じでなければならない
- **FR-079**（変更）: ユーザーは、ツリーの通常のフォルダ（ホーム・マウント中のボリュームの下にある実際のフォルダ）を、その行の
  右クリックメニューの「ゴミ箱に入れる」と、そのフォルダをツリーで選択中の ⌘⌫（FR-019 と同じキー。「ファイル」「編集」メニューの
  「ゴミ箱に入れる」を含む）で、中身ごと OS の
  ゴミ箱に入れられなければならない。右クリックメニューは右クリックした行を対象にし、ツリーでそのフォルダを選択していなくても
  （ほかのフォルダを選択中でも）使える（A-21（directory-tree.md））。どの手段でも、実行前に対象のフォルダ名とその絶対パス
  （同じ名前の別のフォルダと見分けられるようにする）、フォルダを
  中身ごとゴミ箱に入れる旨を示す確認モーダル（FR-022）を、確認モーダルの省略設定（FR-023）に関わらず必ず表示し、
  キャンセルした場合はファイルシステムを変更してはならない。この確認モーダルには「今後この確認を表示しない」を出さない。
  ゴミ箱経由（FR-021）・失敗の表示（FR-026）・結果の反映（FR-027）はファイルリストのゴミ箱に入れる操作と同じとする。
  ホーム・ボリュームの最上位・「お気に入り」の見出し・お気に入りの項目は対象にしない（FR-064）。ファイルリストに表示中の
  フォルダ、またはその祖先をゴミ箱に入れた場合は、削除したフォルダの親をツリーで選択し、ファイルリストを親の一覧に切り替え、
  プレビューを空にする（再生中の動画は FR-034 と同じく停止する）。キーボードフォーカスは移さない（⌘⌫ で削除したときはツリーに
  残り、右クリックメニューから削除したときは削除前にフォーカスがあったペインに残る）。選択した親は最後に選択していたフォルダ
  （FR-003）として保存する。表示中のフォルダと祖先・子孫の関係にないフォルダを削除した場合は、ツリーの選択とファイルリストの
  表示を変えない
- **FR-024**（変更）: 確認モーダルの省略は、コピー（ツリーのフォルダへのペースト・ドロップによるコピーを含む）と、ファイルリストからの
  削除（ゴミ箱へ入れる）と、お気に入りの削除（FR-064）にだけ適用されなければならない。名前の変更（ツリーのフォルダの名前の変更（FR-103）を含む）と移動、およびツリーのフォルダをゴミ箱に
  入れる操作（FR-079）は、設定に関わらず常に確認モーダルを表示しなければならない。設定ウインドウの確認の項目には、
  常に確認する操作として名前の変更・移動・ツリーのフォルダのゴミ箱を示す。
  複製（FR-018）は確認モーダルの対象外とし、設定にも影響されない。省略時の安全性は、削除が必ずゴミ箱経由で
  元に戻せること（FR-021）、コピーが元のファイルを変更しないこと、同名ファイルの上書きが常に確認されること
  （FR-025）で担保する。この方針は憲章 v1.1.0 原則 I の「確認または取り消し可能性」に従う
- **FR-076**（変更）: システムは、ファイルリストに選択フォルダ直下のサブフォルダ（隠しフォルダとパッケージを除く）を表示しなければならない。
  ユーザーは、フォルダの行をダブルクリックするか、選択して ⌘↓ を押すことで、ファイルリストをそのフォルダの一覧に
  切り替えられなければならない。フォルダの行は、プレビュー（FR-075 と同じく空にし、再生中の動画は停止する）・
  縮小画像と行頭アイコン（フォルダを示す汎用アイコン）・種類フィルタ（FR-056・FR-060。常に表示し、ファイルとして数えない）・
  フルスクリーン中の矢印キー移動（FR-046。止まらずに飛ばす）について、zip の中のディレクトリと同じく扱う。
  フォルダの行は FR-018〜FR-027 のファイル操作の対象とする。ツリーのフォルダに対しては、ゴミ箱に入れる操作を FR-079 に、
  名前の変更を FR-103 に従って行える（コピー・移動・複製はファイルリストからだけ行う）
- **FR-099**（変更）: ユーザーは、「お気に入り」の下の項目の表示名を、次のどの手段でも変更できなければならない。
  （1）その項目をツリーで選択し、ツリーにキーボードフォーカスがあるときに Return を押す。
  （2）その項目の右クリックメニューの「名前を変更」を選ぶ（右クリックした行を対象にする。A-21（directory-tree.md））。
  （3）ツリーにキーボードフォーカスがあり、その項目を選択しているときに、「編集」メニューの「名前を変更」を選ぶ。
  名前の編集はその項目の行の中で行い、編集を始めたときは現在の表示名を全選択した状態にする。Return またはほかの場所の
  クリックなどで編集を終えたときは確定し、Esc を押したときは取り消して編集前の表示名に戻す。
  名前の変更はお気に入りの表示名だけを変え、実際のフォルダの名前・場所・中身を変更してはならない。
  ファイルシステムを変えないため、確認モーダル（FR-022・FR-024（file-operations.md））は表示しない。
  「お気に入り」の見出しとホーム・ボリュームの最上位を選択中の Return は何もせず、それらの右クリックメニューに「名前を変更」は
  出さない。ツリーの通常のフォルダの Return・「名前を変更」は、実際のフォルダの名前の変更（FR-103）とする。ツリーにフォーカスが
  あり、お気に入りの項目と通常のフォルダ以外を選択しているときは、「編集」メニューの「名前を変更」は無効にする。ファイルリストに
  zip の中（FR-073（zip.md））または検索結果を表示中でも、ツリーにフォーカスがありお気に入りの項目を選択していれば（1）〜（3）は
  使える（zip の中の読み取り専用と検索結果の制限はファイルリストの操作にだけ適用する）。ファイルリストにフォーカスがあるときの
  Return と「名前を変更」は、従来どおりファイル名の変更（FR-019（file-operations.md））とする
- **FR-102**（変更）: お気に入りの表示名の編集中とツリーのフォルダの名前の編集中（FR-103）は、ファイル名の変更中と同じ扱いと
  しなければならない。既存の項目がいう「ファイル名の変更中」は、ファイル名の変更・お気に入りの表示名の編集・ツリーのフォルダの
  名前の編集のすべて（以下「名前の変更中」）を指すものとし、既存の項目の本文は変えない。
  契約（contracts/keyboard-and-menus.md）でファイル名の変更中に無効とされている操作のすべて（⌃⌘T（FR-062）・⇧⌘F（FR-065）・
  ⌘F（FR-080（search.md））・ペインの表示切り替え（FR-090（window-layout.md））・zip ファイルの表示切り替え（FR-096（zip.md））・
  種類フィルタの「表示」メニュー項目・「中を表示」「上の階層へ」・検索結果の表示を終える Esc）は、編集を終えるまで無効にする。
  編集を始めても、ツリーの選択・ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003（overview.md））は変えない

### Key Entities *(include if feature involves data)*

- **フォルダ（ディレクトリ）**（変更）: ツリーのノード。名前、場所、子フォルダ、アクセス可否、行頭に表示する
  フォルダアイコン、サブフォルダの有無（未確認／あり／なし／確認失敗。「あり」と「確認失敗」のときだけ開閉できる）を持つ。
  親フォルダの一覧ではファイルリストの項目にもなり（名前、場所、作成日、種類「フォルダ」）、ファイル操作の対象になる。
  ツリーのノードとしても、ゴミ箱に入れる操作と名前の変更の対象になる（ホーム・ボリュームの最上位を除く）。名前を変えると、
  そのフォルダと配下の場所が変わり、それを表示・参照しているツリー・ファイルリスト・検索結果・最後に選択していたフォルダは
  新しい場所に追従する。お気に入りの登録は追従しない（FR-106）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-022**: Finder の操作に慣れたユーザーが、説明なしでツリーのフォルダの名前の変更を初回で完了できる
- **SC-023**: ツリーのフォルダの名前の変更を Esc・確認モーダルのキャンセル・検証エラーで終えたとき、ファイルシステムに変更が
  残るものが 0 件（SC-006（file-operations.md）と同じ基準）
- **SC-024**: ファイルリストに表示中のフォルダ（またはその祖先）の名前をツリーで変えたとき、ファイルリストの項目・選択・スクロール
  位置・プレビューが変わる場合が 0 件
- **SC-025**: 検索結果を表示中にフォルダの名前を変えたとき、一覧に古い名前の場所が残る結果が 0 件
- **SC-026**: お気に入りに登録したフォルダの名前を変えて元に戻したとき、項目が通常の表示・同じ並び位置・同じ表示名に戻る割合が 100%
- **SC-027**: ツリーのフォルダをゴミ箱に入れる操作のうち、確認モーダルを経ずに実行されるものが 0 件（確認モーダルの省略設定が
  オンでも）

## Assumptions

- **A-32**: ツリーのフォルダの名前の変更の操作・検証・確認は、ファイルリストのフォルダの名前の変更に合わせた（入力内容の指定）。
  確認モーダルは名前の変更の既存の規則（FR-024（file-operations.md））どおり常に表示する
- **A-33**: 「削除前に確認モーダルを必ず出す」は、ツリーのフォルダをゴミ箱に入れる操作では確認モーダルの省略設定（FR-023）を
  適用しない意味と解釈した。ツリーでは選択中でない行を右クリックして削除できるため、取り違えを防ぐ確認を省略しない。
  ファイルリストからのゴミ箱に入れる操作とお気に入りの削除は、従来どおり省略できる
- **A-34**: 「リネーム対象のフォルダが検索結果に表示されている」は、検索結果の「場所」列（サムネイル形式ではツールチップ）や
  検索バーの起点にそのフォルダが含まれている状態と解釈した。検索の一致の対象は対応メディアファイルだけで、フォルダは検索結果の
  行にならない（FR-083（search.md））ため、フォルダを検索結果に含めるような検索の変更は行わない。「検索条件に該当しなくなったら
  外れる」は、名前の変更で新しい場所が検索の対象外（FR-083）になったファイルを外すことと解釈した。ただし、検索の対象外になる
  名前（先頭の「.」、パッケージになる名前）は FR-103・EC-53 で拒否するため、アプリの中での名前の変更で外れるファイルは実際には出ない
- **A-35**: 「ファイルリストのフォルダーの表示は変わらない」は、ファイルリストが名前を変えたフォルダ自身（またはその配下）を
  表示しているときに、一覧の内容・選択・スクロール・プレビューを保つ意味と解釈した。ファイルリストが親フォルダを表示していて
  名前を変えたフォルダが行として見えている場合は、その行の名前を新しくする（FR-027）
- **A-36**: 右クリックメニューから選択中でない行の名前を変えた・ゴミ箱に入れたときは、ツリーの選択を対象の行へ移さない
  （A-21（directory-tree.md）の「右クリックした行を対象にする」規則と、既存の FR-079 の振る舞いに合わせた）
- **A-37**: ツリーの右クリックメニューの「名前を変更」は、ファイルリストの右クリックメニューと同じく「ゴミ箱に入れる」の次の
  区切り線の後に置く。項目名は Finder とファイルリストに合わせて「名前を変更」とする
- **A-38**: 名前を変えたフォルダの中のファイルをコピー（⌘C）した後に名前を変えた場合、クリップボードは古い場所を指したままになる。
  そのペーストは失敗として FR-026 に従って表示し、クリップボードの内容を新しい場所へ読み替えることはしない
- **A-39**: ホームフォルダとマウント中のボリュームの最上位の名前の変更は、今回の範囲外とする。フォルダ自身の名前の大文字小文字
  だけを変える変更（`Album` → `album`）も範囲外とする（大文字小文字を区別しないボリュームでは、ファイルリストと同じく失敗として
  表示される。既存の振る舞い）
- **A-30**（変更）: 次は今回の範囲外とする。選択中の項目のクリックや一定時間の長押しによる編集の開始（お気に入りの項目と
  ツリーのフォルダの両方）、お気に入りの項目への絶対パスのツールチップの表示、表示名の一括リセット
- **A-21**（変更）: ツリーの右クリックメニューの各項目は、Finder と同じく右クリックした行を対象にする（選択中の行ではない）。
  お気に入りの追加・削除・名前の変更、ツリーのフォルダの「ゴミ箱に入れる」「名前を変更」（FR-079・FR-103）と、既存の
  「ここにペースト」「ここに移動ペースト」「Finder に表示」に同じ規則を使う
- **A-40**: `002-favorite-folder-rename` の変更（FR-099〜FR-102 など）は `specs/product/` へ反映済み（2026-10-25）である。
  この feature は 002 の FR-099・FR-102・US1-AS35・A-30 を変更する
