# UI Contract: キーボード操作とメニュー

ユーザーに公開する操作体系の契約。割り当ては Finder に準じる（FR-019）。すべての操作をキーボードだけで
実行できること（FR-040、憲章 原則 III）を、この表で網羅的に担保する。新しい操作を追加するときは、
必ずこの表に行を追加する。

## ペイン間のフォーカス移動

| キー | 動作 |
|------|------|
| Tab / ⇧Tab | ツリー → リスト → プレビュー の順（逆順）にフォーカスを移す |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | ツリー / リスト / プレビューへ直接フォーカスする |

## ディレクトリツリー

| キー | 動作 |
|------|------|
| ↑ / ↓ | 前 / 次のフォルダを選択する（選択したフォルダの内容がリストに表示される） |
| → | 折りたたまれていれば展開し、展開済みなら最初の子を選択する |
| ← | 展開されていれば折りたたみ、折りたたまれていれば親を選択する |
| ⌥→ / ⌥← | 配下をすべて展開 / 折りたたむ |
| ⌘V / ⌥⌘V | 選択したフォルダへペースト（コピー / 移動） |

ドロップ先: リストからドラッグしたファイルをツリーのフォルダ上にドロップすると移動、⌥ を押しながらだとコピー（FR-020）。

## ファイルリスト

| キー | 動作 | 要件 |
|------|------|------|
| ↑ / ↓（リスト形式）、↑↓←→（サムネイル形式） | 選択を移動し、プレビューを追従させる | FR-017 |
| ⇧ + 矢印 / ⌘A | 選択範囲を広げる / すべて選択する | FR-016 |
| ⌘1 / ⌘2 | サムネイル形式 / リスト形式に切り替える（Finder と同じ番号） | FR-010 |
| ⌘+ / ⌘- | サムネイルを大きく / 小さくする | FR-014 |
| Return | 名前の変更を開始する（Return で確定、Esc で取り消す） | FR-019 |
| ⌘C / ⌘V / ⌥⌘V | コピー / ペースト / 移動ペースト | FR-019 |
| ⌘D | 複製（同じフォルダに「名前 2」として作成） | FR-019 |
| ⌘Delete | ゴミ箱に入れる | FR-019・021 |
| Space | 選択中の動画を再生 / 一時停止する | FR-033 |
| ⌃⌘F | プレビューのフルスクリーンを切り替える | FR-036 |

## プレビュー

| 操作 | 動作 | 要件 |
|------|------|------|
| ダブルクリック | フルスクリーンにする。フルスクリーン中のダブルクリックで解除 | FR-035 |
| ⌃⌘F | フルスクリーンを切り替える | FR-036 |
| Esc | フルスクリーンを解除する | FR-036 |
| Space | 動画の再生 / 一時停止 | FR-033 |
| ← / →（動画にフォーカスがあるとき） | 動画を数秒戻す / 送る（標準の動画コントロールの動作） | FR-033 |
| ↑ / ↓（動画にフォーカスがあるとき） | 音量を上げる / 下げる | FR-033 |

## 右クリックメニュー（ファイルリスト）

選択中のファイルに対して、次の順で表示する。項目の名前は Finder に合わせる。

1. 開く（既定のアプリで開く）
2. ─
3. ゴミ箱に入れる（⌘Delete）
4. ─
5. 名前を変更（Return）
6. 複製（⌘D）
7. ─
8. "<名前>" をコピー（⌘C）（複数選択時は「n 項目をコピー」）
9. ペースト（⌘V）／ 移動ペースト（⌥⌘V）（クリップボードにファイルがある場合のみ有効）
10. ─
11. Finder に表示

## 右クリックメニュー（ツリー）

1. ここにペースト / ここに移動ペースト
2. Finder に表示

## メニューバー

| メニュー | 項目 |
|----------|------|
| アプリ名 | 設定…（⌘,） / 終了（⌘Q） |
| ファイル | 開く / Finder に表示 / ゴミ箱に入れる |
| 編集 | コピー / ペースト / 移動ペースト / 複製 / 名前を変更 / すべてを選択 |
| 表示 | サムネイル / リスト / サムネイルを拡大・縮小 / 並べ替え（名前・作成日・種類）/ フルスクリーン |

## 確認モーダルと衝突ダイアログ

- 確認モーダル（設定で ON のとき）: 操作名、対象の件数、先頭最大5件のファイル名、操作先を表示する。
  既定ボタンは「実行」、Esc で「キャンセル」（FR-022）
- 確認モーダルには「今後この確認を表示しない」チェックボックスを置き、設定の `confirmBeforeFileOperations` と連動させる（FR-023）
- 衝突ダイアログ（常に表示する）: 「置き換える」「両方残す」「中止」と、「残りすべてに適用」のチェックボックス（FR-025）
