# UI Contract: キーボード操作とメニュー

ユーザーに公開する操作体系の契約。割り当ては Finder に準じる（FR-019）。すべての操作をキーボードだけで
実行できること（FR-040、憲章 原則 III）を、この表で網羅的に担保する。新しい操作を追加するときは、
必ずこの表に行を追加する。

## ペイン間のフォーカス移動

| キー | 動作 |
|------|------|
| Tab / ⇧Tab | ツリー → リスト → プレビュー の順（逆順）にフォーカスを移す |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | ツリー / リスト / プレビューへ直接フォーカスする |
| ⇧⌘F | ツリーへフォーカスし、「お気に入り」の見出しを選択する。折りたたまれていれば展開する。ファイルリスト・プレビューは変えない。フルスクリーン中とファイル名の変更中は無効（FR-065） |

## ディレクトリツリー

| キー | 動作 |
|------|------|
| ↑ / ↓ | 前 / 次のフォルダを選択する（選択したフォルダの内容がリストに表示される） |
| → | 折りたたまれていれば展開し、展開済みなら最初の子を選択する |
| ← | 展開されていれば折りたたみ、折りたたまれていれば親を選択する |
| ⌥→ / ⌥← | 配下をすべて展開 / 折りたたむ。展開するのはサブフォルダの有無を確認済みの階層までで、まだ確認していない孫以下は先読みしない（FR-055） |
| ⌘V / ⌥⌘V | 選択したフォルダへペースト（コピー / 移動）。お気に入りの見出し・項目では無効 |
| ⌃⌘T | ツリーで選択中のフォルダ（ホーム・ボリュームのルートを含む）をお気に入りの末尾に登録する。どのペインにフォーカスがあっても効く。登録済みのフォルダ・見出し・お気に入りの項目とファイル名の変更中は無効（FR-062） |
| ⌘Delete | お気に入りの項目を選択中のとき、確認モーダルの後にお気に入りから削除する（実際のフォルダは変えない）。ほかの行では何もしない（FR-064） |

「お気に入り」の見出しは、ホームとボリュームより上に常に表示する。見出しは開閉の三角を持つ通常の行で、→ / ← と
ダブルクリックで開閉できる。起動時は折りたたまれている。見出しを ↑↓ やクリックで選んでも、ファイルリスト・
プレビューは変わらない。見出しの下の各項目には三角がなく、選ぶとそのフォルダの内容がファイルリストに出る。
ツリー下側の実際の階層は展開・選択しない（FR-061・063・065）。見つからない項目は淡色の文字で表示する（FR-067）。

| マウス操作 | 動作 | 要件 |
|------------|------|------|
| 行（アイコンまたはフォルダ名）のダブルクリック | そのフォルダを選択し、折りたたまれていれば展開、展開されていれば折りたたむ。開閉の三角がない（サブフォルダなし・確認中・権限なし）フォルダでは選択だけを行う | FR-053・054 |
| 開閉の三角のクリック | 従来どおり1回のクリックで展開・折りたたみする | FR-005 |

開閉の三角は、サブフォルダ（隠しフォルダ・パッケージを除く）があると確認できたフォルダと、確認に失敗した
フォルダにだけ表示する。三角のないフォルダでは → キーでも展開しない（FR-054・055）。ダブルクリックは
→ / ← キーによる開閉のマウス操作版で、キーボードの割り当ては変えない。

ドロップ先: リストからドラッグしたファイルをツリーのフォルダ上にドロップすると移動、⌥ を押しながらだとコピー（FR-020）。
お気に入りの見出しと項目はドロップ先にならない。

## ファイルリスト

| キー | 動作 | 要件 |
|------|------|------|
| ↑ / ↓（リスト形式）、↑↓←→（サムネイル形式） | 選択を移動し、プレビューを追従させる。サムネイル形式ではフォーカス項目全体が見える最小限のスクロールも行う（既に見えている場合は動かさない） | FR-017 |
| ⇧ + 矢印 / ⌘A | 選択範囲を広げる / すべて選択する。サムネイル形式では移動先のフォーカス項目にスクロールが追従する | FR-016・017 |
| ⌘1 / ⌘2 | サムネイル形式 / リスト形式に切り替える（Finder と同じ番号） | FR-010 |
| ⌘+ / ⌘- | サムネイルを大きく / 小さくする | FR-014 |
| ⇧⌘I | 「画像のみ表示」のオン・オフを切り替える | FR-056・058 |
| ⇧⌘M | 「動画のみ表示」のオン・オフを切り替える | FR-056・058 |
| Return | 名前の変更を開始する（Return で確定、Esc で取り消す） | FR-019 |
| ⌘C / ⌘V / ⌥⌘V | コピー / ペースト / 移動ペースト | FR-019 |
| ⌘D | 複製（同じフォルダに「名前 2」として作成） | FR-019 |
| ⌘Delete | ゴミ箱に入れる | FR-019・021 |
| Space | 選択中の動画を再生 / 一時停止する | FR-033 |
| ⌃⌘F | プレビューのフルスクリーンを切り替える | FR-036 |
| ⌘↓ | フォーカス行が zip ファイル・zip の中のディレクトリなら中を表示し、`...` なら1つ上の階層へ戻る。メディアの行では何もしない | FR-069・070 |
| ⌘↑ | zip の中を表示中なら、どの行を選択中でも1つ上の階層へ戻る（最上位では zip を含むフォルダの一覧へ）。戻った先では出てきた zip ファイル・ディレクトリの行を選択する。zip の外では何もしない | FR-069・070 |

| マウス操作 | 動作 | 要件 |
|------------|------|------|
| zip ファイル・zip の中のディレクトリの行のダブルクリック | 中を表示する（⌘↓ と同じ） | FR-069 |
| `...` の行のダブルクリック | 1つ上の階層へ戻る（⌘↑ と同じ） | FR-070 |
| メディアの行のダブルクリック | 何もしない（従来どおり） | — |

zip の中を表示している間（FR-071・073・075）:

- 一覧の先頭行は常に `...`。続いてディレクトリと対応メディアが、選択した列の順に区別なく並ぶ。`...` は並べ替えの対象にしない
- 矢印キー・⇧ + 矢印・⌘A・⌘1 / ⌘2・⌘+ / ⌘-・⇧⌘I / ⇧⌘M・Space・⌃⌘F は通常のフォルダと同じに使える。種類フィルタは
  メディアの行だけを絞り、zip ファイル・ディレクトリ・`...` は残す
- 読み取り専用。Return（名前の変更）・⌘C・⌘V・⌥⌘V・⌘D・⌘Delete・⌘O は何もしない。ドラッグも始まらない
- ディレクトリ・`...`（と通常のフォルダの zip ファイル）の行を選ぶと、プレビューは空になり、再生中の動画は止まる
- ツリーで別のフォルダを選ぶと、zip の中の表示を終えてそのフォルダの一覧になる

## ツールバー

| 操作 | 動作 | 要件 |
|------|------|------|
| ⇧⌘T / 表示 > ツールバーを表示（隠す） | ツールバーの表示・非表示を切り替える。既定は非表示で、状態は次回起動時に復元する | FR-049・050 |
| 種類フィルタボタン（画像のみ表示 / 動画のみ表示） | ⇧⌘I / ⇧⌘M と同じ。クリックするたびにオン・オフが切り替わり、オンの側を押された見た目で示す。表示形式ボタンの左に置く | FR-056・057 |
| 表示形式ボタン（サムネイル / リスト） | ⌘1 / ⌘2 と同じ。選択中の側を強調表示する | FR-051 |
| サイズのスライダー | ⌘+ / ⌘- と同じ状態を変える。リスト形式では無効（グレー表示） | FR-051 |

- 項目の並びは左から「種類フィルタ」「表示形式」「サイズ」で固定する
- ツールバー上の操作はすべて既存のキー割り当てでも行えるため、ツールバーにキーボードフォーカスを
  移さなくても全操作をキーボードで実行できる（FR-040）
- ツールバーを表示している間は、サムネイル形式の下部サイズバーを表示しない（FR-052）
- フルスクリーン中のツールバーはメニューバーと一緒に自動で隠れる

## プレビュー

| 操作 | 動作 | 要件 |
|------|------|------|
| ダブルクリック（画像のみ） | フルスクリーンにする。フルスクリーン中のダブルクリックで解除。動画の上では対応しない | FR-035 |
| ⌃⌘F | フルスクリーンを切り替える | FR-036 |
| Esc | フルスクリーンを解除する | FR-036 |
| Space | 動画の再生 / 一時停止 | FR-033 |
| ← / →（通常表示で動画にフォーカスがあるとき） | 動画を数秒戻す / 送る（標準の動画コントロールの動作） | FR-033 |
| ↑ / ↓（通常表示で動画にフォーカスがあるとき） | 音量を上げる / 下げる | FR-033 |
| ↑ / ↓（フルスクリーン中） | ファイルリストの選択を前 / 次へ移動し、プレビューを追従させる。リスト形式・サムネイル形式の両方 | FR-046 |
| ← / →（フルスクリーン中、サムネイル形式） | ファイルリストの選択を前 / 次へ移動し、プレビューを追従させる | FR-046 |
| ← / →（フルスクリーン中、リスト形式） | 何もしない（通常表示のリスト形式と同じ） | FR-046 |
| 矢印キー（フルスクリーン中、移動先が zip ファイル・ディレクトリ・`...` の行） | その行を飛ばし、同じ方向の次のメディアファイルへ移る。その方向にメディアがなければ移動しない | FR-046 |
| < / >（フルスクリーン中の動画） | 5 秒戻す / 送る | FR-033・046 |

## 右クリックメニュー（ファイルリスト）

選択中のファイルに対して、次の順で表示する。項目の名前は Finder に合わせる。

1. 開く（既定のアプリで開く）
2. ─
3. ゴミ箱に入れる（⌘Delete）
4. ─
5. 名前を変更（Return）
6. 複製（⌘D）
7. ─
8. "<名前>" をコピー（⌘C）（複数選択時は「n 項目をコピー」）
9. ペースト（⌘V）／ 移動ペースト（⌥⌘V）（クリップボードにファイルがある場合のみ有効）
10. ─
11. Finder に表示

- 通常のフォルダの zip ファイルの行でも、同じ項目を同じ条件で有効にする（zip ファイルそのものはファイル操作の対象: FR-073）。
  ファイル操作の前に、1番目として「中を表示（⌘↓）」と区切り線を加える
- zip の中を表示中は、メディア・ディレクトリ・`...` のどの行でも、「中を表示（⌘↓）」（ディレクトリと `...` のみ有効）と
  「上の階層へ（⌘↑）」のほかは、すべて淡色で選べない（FR-073）

## 右クリックメニュー（ツリー）

右クリックした行の種類で項目を変える（[data-model.md](../data-model.md) の「TreeItemRole と FavoriteCommands」）。

通常のフォルダ（ホーム・ボリュームのルートを含む）:

1. ここにペースト / ここに移動ペースト
2. ─
3. お気に入りに追加（⌃⌘T）（登録済みのフォルダでは無効）
4. ─
5. Finder に表示

お気に入りの項目:

1. お気に入りから削除（⌘Delete）

「お気に入り」の見出し: メニューを出さない。

## メニューバー

| メニュー | 項目 |
|----------|------|
| アプリ名 | 設定…（⌘,） / 終了（⌘Q） |
| ファイル | 開く / 中を表示（⌘↓）/ 上の階層へ（⌘↑）/ Finder に表示 / お気に入りに追加（⌃⌘T）/ ゴミ箱に入れる |
| 編集 | コピー / ペースト / 移動ペースト / 複製 / 名前を変更 / すべてを選択 |
| 表示 | ツールバーを表示（隠す）（⇧⌘T）/ フルスクリーン（⌃⌘F）/ サムネイル（⌘1）/ リスト（⌘2）/ サムネイルを拡大・縮小（⌘+ / ⌘-）/ 画像のみ表示（⇧⌘I）・動画のみ表示（⇧⌘M）/ ディレクトリツリー・ファイルリスト・プレビューへフォーカス（⌥⌘1〜3）/ お気に入りへ移動（⇧⌘F） |

- 項目は実装の並び順で記す。並べ替えはメニューには置かず、リスト形式の列見出しのクリックで行う（FR-012）
- 「画像のみ表示」「動画のみ表示」は、オンの項目にチェックマークを付ける。両方オンのときは両方にチェックが付き、
  一覧は画像と動画をすべて表示する（FR-056・058）。名前の変更中は無効にする
- 「ゴミ箱に入れる」（ファイル・編集の両メニュー、⌘Delete）は、ツリーでお気に入りの項目を選択中のとき項目名を
  「お気に入りから削除」に変え、お気に入りの削除を行う。ツリーでほかの行を選択中のときは無効（FR-064）
- 種類フィルタは、ファイルリストの選択・⌘A・コピーなどの操作・フルスクリーン中の矢印移動の対象を、表示中の一覧に限る
- 「中を表示」「上の階層へ」は、ファイルリストにフォーカスがあるときだけ有効で、名前の変更中は無効。「中を表示」はフォーカス行が
  zip ファイル・ディレクトリ・`...` のとき、「上の階層へ」は zip の中を表示中のときだけ有効（FR-069）
- zip の中を表示中は、「開く」「Finder に表示」「ゴミ箱に入れる」と「編集」メニューのコピー・ペースト・移動ペースト・複製・名前を変更を
  無効にする（FR-073）

## 確認モーダルと衝突ダイアログ

- 確認モーダル（設定で ON のとき）: 操作名、対象の件数、先頭最大5件のファイル名、操作先を表示する。
  既定ボタンは「実行」、Esc で「キャンセル」（FR-022）
- 確認モーダルには「今後この確認を表示しない」チェックボックスを置き、設定の `confirmBeforeFileOperations` と連動させる（FR-023）
- お気に入りの削除の確認モーダル（設定で ON のとき）: 「お気に入りから削除しますか？」、対象のフォルダ名、
  実際のフォルダは変更されないこと。既定ボタンは「削除」、Esc で「キャンセル」。「今後この確認を表示しない」は
  ファイル操作と同じ `confirmBeforeFileOperations` を変える（FR-024・064）
- 衝突ダイアログ（常に表示する）: 「置き換える」「両方残す」「中止」と、「残りすべてに適用」のチェックボックス（FR-025）
