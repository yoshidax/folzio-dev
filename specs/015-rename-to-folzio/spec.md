# Feature Specification: Folzioへの改名

**Feature Branch**: `015-rename-to-folzio`
**Created**: 2026-10-29
**Status**: Draft
**Input**: プロジェクトと製品を Folzio に改名し、プロジェクトディレクトリと公開用ディレクトリも変更する。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Folzioとして閲覧する (Priority: P1)

利用者は Folzio を起動し、フォルダやzip内の画像・動画を従来どおり閲覧・整理する。日英の画面と配布物で Folzio の名前が一貫して見える。

**Why this priority**: 公開される製品の名前と既存の閲覧体験が目的の中心である。

**Independent Test**: 作成したアプリを起動し、3ペイン、両言語、画像・動画・zipの閲覧とファイル整理を確認する。

**Acceptance Scenarios**:

1. **Given** 配布アプリ、**When** FinderやDockから起動する、**Then** Folzio の名前と3ペインが表示される。
2. **Given** 英語または日本語を選択、**When** アプリ名や終了メニューを見る、**Then** 名前は Folzio であり画面の翻訳が使える。
3. **Given** 対応画像・動画とzip、**When** 従来の操作で閲覧・整理する、**Then** 既存仕様に従って動作する。

### User Story 2 - 既存の設定を引き継ぐ (Priority: P2)

開発版の利用者は旧アプリの設定を保護して一度だけ Folzio に移し、お気に入り、表示設定とウインドウ配置を継続して使う。

**Independent Test**: テスト用の旧・新設定を用意し、新規移行・移行先に設定がある場合・旧設定がない場合を検証する。

**Acceptance Scenarios**:

1. **Given** 旧設定と空の新設定、**When** 利用者が移行手順を実行する、**Then** 設定とウインドウ配置が引き継がれ、旧設定は残る。
2. **Given** 移行先に既存設定がある、**When** 移行を試みる、**Then** 上書きをせずに停止し、対処方法を示す。
3. **Given** 対象の旧設定が存在しない、**When** 移行を試みる、**Then** 変更せずにその旨を示す。

### User Story 3 - Folzioとして開発・公開する (Priority: P3)

保守者は改名したプロジェクトと公開先を新しいパスで開き、ビルド・検証・公開準備を実行する。

**Independent Test**: 改名後の手順に従い、開発側でビルド・検証し、保護した公開先に書き出して同じ名前で検証する。

**Acceptance Scenarios**:

1. **Given** Folzioのソース、**When** 文書の手順でビルドする、**Then** アプリとテストが新しい名前で動作する。
2. **Given** 未追跡のIDE設定を含む既存の公開先、**When** 公開準備を行う、**Then** 設定を退避・保護し、内容を失わず確認できる。
3. **Given** 改名後のディレクトリ、**When** IDEを開き直し、ビルドとアプリの起動確認を行う、**Then** 旧パスへの依存なしに作業できる。

### Edge Cases

- 旧設定の不存在、新設定の存在、移行途中の失敗時は、旧設定を削除せず、移行先を上書きしない。
- 開発ディレクトリ内を指すお気に入りや前回のフォルダは移動後に無効となることがあり、明示的に確認して必要に応じて利用者が修正する。
- ディレクトリの移動先が存在するときは移動しない。実行中のアプリとIDEを終了してから移動する。
- 旧仕様・過去の記録は当時の履歴として保存する。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-147（変更）**: システムは、次のものを翻訳・変形してはならない。ファイル名・フォルダ名・パス・お気に入りの表示名・検索キーワード・zip の中の名前などのユーザーデータ、アプリ名「Folzio」、キーボードショートカットの表記。ログ・内部識別子・表示言語の選択を除く保存キーとその値（contracts/settings.md）・履歴の内容は表示言語に依存させず、翻訳の対象外とする。OS が提供する文言（ファイルの種類名、OS が返すエラーの理由、標準のフォルダ選択パネル・動画コントロール・テキスト編集のメニューなど）は OS 標準の翻訳を使い、アプリで訳し直さない。
- **FR-166（追加）**: 製品名は Folzio とし、アプリの表示、配布物、現行の利用・開発ガイドに一貫して用いなければならない。既存の閲覧・整理機能は引き続き既存仕様に従う。
- **FR-167（追加）**: 保守者は旧開発版のアプリと開発実行の設定をそれぞれ対応する新しい保存先へ手動で引き継げなければならない。旧設定は保持し、移行先に設定がある場合は上書きしない。アプリ本体は旧保存先からの自動移行を行わない。
- **FR-168（追加）**: 保守者は Folzio の名称とディレクトリでビルド、テスト、アプリ生成、開発と公開準備を行える。公開先の未追跡IDE設定は退避・保護される。

### Key Entities

- **旧設定・新設定**: 配布アプリと開発実行の独立した保存先。それぞれアプリ設定、ペイン幅、ウインドウ位置を含む。
- **プロジェクト**: 開発用リポジトリ、公開用リポジトリ、Git管理外のIDE設定を含む。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-076（追加）**: 利用者が両言語の画面・配布物で確認するアプリ名はすべて Folzio である。
- **SC-077（追加）**: 旧設定の移行で、保存済みの言語・お気に入り・表示設定・ペイン幅・ウインドウ位置を2つの起動方法ごとに保持でき、移行先の既存設定は上書きされない。
- **SC-078（追加）**: 新しい名前の一時ディレクトリでビルドと全自動テストが成功し、実際の移動後に3ペインの起動、日英表示、画像・動画・zipの閲覧を再確認する手順が揃う。

## Assumptions

- 開発側は `~/projects/folzio`、公開側は `~/projects/folzio-oss` とする。ディレクトリ移動はfeatureの実装・検証と仕様反映後に利用者が実行する。
- 既存のアプリは未公開の開発版で、保存先移行はローカルの手動手順とする。旧データを消さず、ファイルの絶対パスは自動書き換えしない。
- Bundle ID は `local.folzio.Folzio`、アプリ実行名は `Folzio` とする。外部依存やネットワーク通信は追加しない。
- `.app` と `swift run` の設定はそれぞれ独立に移行する。
