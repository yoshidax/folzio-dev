# Contract: 開発版設定の一度きりの移行

- それぞれの起動方法に対応する旧・新ドメインの組は [data-model.md](../data-model.md) に従う。両アプリを終了してから、各ドメインの新しいアプリを初めて起動する前に実施する。
- ユーザーによる明示的な実行のみで開始する。旧ドメインの永続データを非公開なファイルにバックアップし、新ドメインが存在しないことを確認してから復元する。旧ドメインは変更・削除しない。
- 旧ドメインがない場合は何も変更せず説明する。新ドメインがすでに存在する場合は停止し、上書きも自動統合も行わない。バックアップ失敗時は書き込みを開始しない。
- アプリ設定、`NSWindow Frame MainWindow`、`NSSplitView Subview Frames MainSplit` を含む旧ドメインのplist値を保持する。画像・フォルダを移動せず、保存パスを自動変換しない。
- `defaults` や作業ファイルの失敗を検出し、部分的な復元が起きた場合はバックアップを残して結果と復旧手順を提示する。二度目の実行は移行先存在として止まる。
- 自動検証は実ユーザーのドメインを使わず、一時的なテストドメイン・ディレクトリで成功、移行先あり、旧なし、失敗、2回目の実行を確認する。テスト後はテスト用のデータのみを削除する。
- 移行用スクリプトと実際の設定値・バックアップは公開アーカイブに含めない。
