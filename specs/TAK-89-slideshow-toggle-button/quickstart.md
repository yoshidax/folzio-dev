## 保守者の GUI 確認（ローカル）

準備: 次を実行し、⇧⌘T でツールバーを表示する。表示する一覧には、画像を 3 枚以上置く。

```bash
scripts/make-app.sh
```

```bash
open .build/Folzio.app
```

1. **ボタンで開始・停止**（US77-AS1・AS2、SC-187）: 3 ペインの表示で、ボタンを押して開始する。ボタンがオンの表示になり、押せることを確かめる。
   もう一度押して、止まること、ボタンがオフに戻ること、開始前のペイン表示・フォーカス・幅に戻ることを確かめる。同じ手順を Esc で止めて、結果を比べる
2. **全画面**（US77-AS3）: 全画面（⌃⌘F）にしてから開始し、ポインタを画面の上端へ動かしてツールバーを出し、ボタンを押す。1 回で、止まることと全画面が解除されることを確かめる
3. **⇧⌘S・メニューで開始**（US77-AS4、SC-189）: ⇧⌘S で開始し、ボタンがオンであること、メニュー「表示 > スライドショーを開始」が無効であることを確かめる。ボタンで止める
4. **ボタン以外の停止**（US77-AS5、SC-186）: 次の表の開始の方法で始め、停止の方法で止める。それぞれで、開始の後にボタンがオンになること、
   止まった後にボタンがオフに戻り、開始の条件を満たせば再び押して開始できることを確かめる。1〜3 と合わせて、開始の 3 つの方法と停止の 5 つの方法を、どれも 1 回以上試す（SC-186）

   | 開始 | 停止 |
   |---|---|
   | メニュー「表示 > スライドショーを開始」 | Esc |
   | ボタン | 繰り返しをオフにして、末尾まで待つ（切り替え間隔を 1 秒にすると早い） |
   | ⇧⌘S | 実行中に、表示中の画像を Finder ですべてゴミ箱に入れる（対象 0 件の自動終了。FR-125） |
   | メニュー「表示 > スライドショーを開始」 | 実行中に、表示中のフォルダを Finder でゴミ箱に入れる（閲覧先の消失による終了。FR-126） |

   - 閲覧先の変更は、実行中はツリーが隠れていて別のフォルダを選べないため、表示中のフォルダの消失で確かめる
   - ゴミ箱に入れたものは、確認の後に Finder の「戻す」で元に戻す
5. **シートの間は無効**（US77-AS6、SC-188）: 表示中のフォルダ F と**別のボリューム**（外付けのドライブや、ディスクユーティリティで作ったディスクイメージ）に、
   数 GB の動画 `a-big.mov` と、F に同じ名前のファイルがある画像 `z.jpg` を置く。
   - 同じ APFS のボリュームの中のコピーは複製でほぼ一瞬で終わり、開始する間がないため、別のボリュームを使う
   - 衝突は名前の順（表示順）に 1 件ずつ調べるため、衝突する `z.jpg` を `a-big.mov` より後に並ぶ名前にする
   - Folzio で別のボリュームの 2 つを選んで ⌘C し、F を表示して ⌘V する（確認が出たら「コピー」）。`a-big.mov` のコピー中に ⇧⌘S で開始する
   - `z.jpg` の名前の衝突のダイアログが出たら、ボタンがオンのまま無効の表示で、押しても止まらないことを確かめる。ダイアログで「中止」を押した後、ボタンを押して止まることを確かめる
6. **設定ウインドウを開いている間**（US77-AS7）: 実行中に ⌘, で設定ウインドウを開き、メインウインドウのツールバーのボタンを**1 回**押して、止まることを確かめる。
   1 回目のクリックがメインウインドウを前面にするだけで止まらない場合は、その結果を記録する（research.md の R9。US77-AS7 を直すかを決める）
7. **あふれたメニューと文字だけの形式**（EC-240）: ウインドウを狭め、ボタンがあふれたメニュー（`»`）へ入った状態で、メニューから開始と停止ができること、
   実行中に項目にチェックマークが付くことを確かめる。ツールバーの右クリックで「テキストのみ」にし、項目名を押して開始と停止ができることを確かめる
8. **文言と VoiceOver**（US77-AS8）: 停止中と実行中で、ツールチップ（「スライドショーを開始（⇧⌘S）」・「スライドショーを停止（Esc）」）を確かめる。
   VoiceOver（⌘F5）で、ラベルとオン・オフの値が読まれることを確かめる。設定で表示言語を英語にして、`Stop Slideshow (Esc)` になることを確かめる
9. **素早い操作**（EC-239）: 全画面で開始し、ボタンを素早く 2 回押して、全画面の出入りを繰り返さないこと、復帰が終わった後に再び開始できることを確かめる
10. **起動スモーク**: 3 ペインが表示されること
