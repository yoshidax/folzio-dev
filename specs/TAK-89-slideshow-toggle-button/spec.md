  メニューと ⇧⌘S は今のまま、開始だけを行い、実行中は無効（FR-114（変更））
- Q: 実行中（オンの状態）のボタンのツールチップとアクセシビリティラベルは？ → A: 停止の文言に変える。アクセシビリティラベルは「スライドショーを停止」、
  ツールチップは停止とそのキー（Esc）を示す。停止中は今の「スライドショーを開始」に戻す。ツールバー上の項目名「スライドショー」は変えない（FR-353）
  - 設計のレビューで改めた: アクセシビリティラベルは「スライドショー」で固定し、ツールチップとアクセシビリティの説明だけを状態で切り替える（下の Session を参照）
- Q: 実行中に、シート・アプリモーダル・名前の変更の編集欄が開いたとき、ボタンでの停止を受け付けるか？ → A: 受け付けない。Esc の受理の条件（FR-123（preview.md））と同じく、
  その間はボタンを無効にし、オンの表示は保つ（FR-352）
  - 開始後にシートが出る経路の例: 大きなファイルのコピー・移動の実行中（シートがない）に ⇧⌘S で開始すると、後の項目の名前の衝突のダイアログ
    （FR-025（file-operations.md））や、終わった後の失敗の表示（FR-026）が、実行中にシートとして出る
  - この経路を確かめる手順と、その前提（ファイルの置き方）は quickstart.md の 5 にある
  - アプリモーダルと名前の変更の編集欄が実行中に出る経路は、コードを読んだ範囲では見つからなかった。Esc の条件と揃える防御として条件に含める
- 設定ウインドウ（⌘,）はモーダルではない。開いている間はメインウインドウがキー入力先でないので Esc では停止しないが、ボタンはクリックで操作するため押せるようにする（FR-352）

## User Scenarios & Testing *(mandatory)*

### User Story 77 - ツールバーのボタンでスライドショーを止める (Priority: P1)

ユーザーは、ツールバーの「スライドショー」ボタンで開始したスライドショーを、同じボタンをもう一度押して止められる。
ボタンは実行中にオンの状態で表示され、実行中であることが分かる。

**Why this priority**: TAK-89 の主目的。マウスだけで開始と停止ができるようにする。

**Independent Test**: ツールバーを表示し、ボタンで開始してからボタンで停止する。
通常のウインドウと全画面の両方で、終了後の表示が Esc で止めた場合と同じであることを確かめる。
⇧⌘S・メニューで開始した場合、Esc・自動終了で止まった場合も、ボタンのオン・オフが実行状態と一致することを確かめる。

**Acceptance Scenarios**:

- **US77-AS1**: **Given** ツールバーを表示し、表示中の一覧に対応メディアがある, **When** 「スライドショー」ボタンを押す,
  **Then** スライドショーが始まり、ボタンはオンの状態になり、押せるままである
- **US77-AS2**: **Given** ボタンで開始したスライドショーの実行中, **When** ボタンをもう一度押す,
  **Then** スライドショーが終わり、Esc で終えた場合（FR-123（preview.md））と同じく、開始前のペイン表示・フォーカス・幅へ戻る。ボタンはオフに戻る
- **US77-AS3**: **Given** 全画面でスライドショーを実行中で、ツールバーを表示させている, **When** ボタンを押す,
  **Then** 1回の操作で、スライドショーの終了と全画面の解除を行う（Esc と同じ）。
  全画面の解除を待つ間、ボタンはオフの状態で無効になり、解除が終わると開始の条件に従って有効になる
- **US77-AS4**: **Given** ⇧⌘S またはメニュー「表示 > スライドショーを開始」で開始した, **When** 実行中のツールバーを見る,
  **Then** ボタンはオンの状態で押せる。押すと US77-AS2 と同じく終わる。メニューの項目は実行中は無効のまま
- **US77-AS5**: **Given** ボタンがオンの状態, **When** Esc、対象が0件になった自動終了（FR-125）、繰り返しがオフで末尾に達した終了（FR-129）、
  閲覧先の変更による終了（FR-126）のいずれかで止まる, **Then** ボタンはオフに戻り、開始の条件を満たせば再びボタンから開始できる
- **US77-AS6**: **Given** 実行中に、対象ウィンドウにシート（名前の衝突のダイアログなど）が表示された, **When** ボタンを見る・押そうとする,
  **Then** ボタンはオンの状態のまま無効で、押しても止まらない。シートを閉じると押せるようになる
- **US77-AS7**: **Given** 実行中に設定ウインドウ（⌘,）を開き、設定ウインドウがキー入力先になっている, **When** メインウインドウのツールバーのボタンを押す,
  **Then** スライドショーが終わる
- **US77-AS8**: **Given** ボタンがオフ（停止中）とオン（実行中）のそれぞれの状態, **When** ボタンにポインタを置く・VoiceOver で読む,
  **Then** ツールチップは、オフでは「スライドショーを開始」と開始のキーを、オンでは「スライドショーを停止」と Esc を示す。
  VoiceOver は、どちらの状態でもラベル「スライドショー」と、オン・オフの値と、ツールチップと同じ説明を読む

### Edge Cases

- **EC-239**: ボタンを素早く続けて押した場合も、開始と停止を1回の押下につき1回だけ行い、全画面の解除を待つ表示の復帰中の押下では何もしない。
  - 復帰中はボタンを無効にする（FR-352）。表示の復帰の途中で再び開始して、全画面の出入りを繰り返さない（A-48（preview.md）と同じ）
- **EC-240**: ウインドウが狭くツールバーの項目があふれたときのメニューと、ツールバーを文字だけで表示する形式でも、
  ボタンと同じく、停止中は開始、実行中は停止の操作になり、有効・無効は FR-352 に従う。
  - あふれたメニューの項目の名前は、ツールバー上の項目名と同じく「スライドショー」のままとし、実行中はチェックマークを付ける（FR-353）
  - 文字だけで表示する形式では、オン・オフの表示は OS の標準の表示に従う（A-210）
- 実行中にツールバーを隠した（⇧⌘T）場合は、Esc で止める。ツールバーを再び表示したときは、その時点の実行状態でボタンを表示する
- ツールバーのカスタマイズ（FR-233（window-layout.md））でボタンの位置を変えても、トグルの動作は変わらない。
  カスタマイズの画面のパレットの見本は、オン・オフの状態を持たない
- 表示言語の切り替え（FR-145・FR-154（overview.md））を実行中に行っても、ボタンの文言は実行状態に合ったものに切り替わる

## Requirements *(mandatory)*

### Functional Requirements

- **FR-350**: ツールバーの「スライドショー」ボタンは、スライドショーの実行中はオン、それ以外はオフの状態で表示しなければならない。
  - オン・オフは、開始と停止の経路（ボタン・⇧⌘S・メニュー・Esc・自動終了・閲覧先の変更・ウインドウを閉じる）に関わらず、実際の実行状態に同期する
  - 全画面の解除を待つ表示の復帰中は、オフとして表示する
  - アイコンは停止中と同じものを使い、オンの状態は OS の標準のトグルボタンの表示で示す
- **FR-351**: ユーザーは、実行中にツールバーの「スライドショー」ボタンを押して、スライドショーを停止できなければならない。
  - 停止は、FR-123（preview.md）で受理した Esc と同じ終了の処理（自動送り・待機中の再開・切り替え効果の取消、全画面中なら同時に解除、
    開始前のペイン表示・フォーカス・幅への復帰、最後のメディアの選択の保持）を行う
  - 停止の操作は全画面の解除・検索の解除へ重ねて適用しない
- **FR-352**: ツールバーの「スライドショー」ボタンの有効・無効は、次のとおりとしなければならない。
  - 停止中は、FR-114（window-layout.md）の開始の条件を満たすときだけ有効にする
  - 実行中は、対象ウィンドウにシートがなく、アプリモーダルがなく、名前の変更の編集欄が入力を受けていないときに有効にする
    （FR-123（preview.md）の Esc の受理の条件のうち、キー入力先の条件を除いたもの）
  - 実行中に無効にした間も、オンの表示は保つ
  - 全画面の解除を待つ表示の復帰中は無効にする
  - 対象ウィンドウがキー入力先でないこと（設定ウインドウを開いているなど）だけでは無効にしない
- **FR-353**: ツールバーの「スライドショー」ボタンの文言は、状態に合わせなければならない。
  - アクセシビリティラベル、ツールバー上の項目名、カスタマイズの画面の名前は、どちらの状態でも「スライドショー」とする
  - 実行中かどうかは、トグルのオン・オフの値で伝え、ラベルでは伝えない（A-211）
  - 停止中: ツールチップとアクセシビリティの説明は「スライドショーを開始（⇧⌘S）」（今と同じ。キーは現在の割り当てに従う）
  - 実行中: ツールチップとアクセシビリティの説明は「スライドショーを停止（Esc）」
  - 英語の文言は contracts/localization.md に従う（`Stop Slideshow (Esc)` を加える）

### Key Entities *(include if feature involves data)*

- **ボタンの状態**: スライドショーの実行状態（停止中・実行中・表示の復帰中）から決まる、オン・オフ、有効・無効、文言の組。永続化しない

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-186**: 開始の3経路（ボタン・⇧⌘S・メニュー）と停止の5経路（ボタン・Esc・対象0件の自動終了・末尾での終了・閲覧先の変更）をそれぞれ1回以上試し、
  開始後と終了後にボタンのオン・オフが実行状態と食い違う場合が0件。
  - すべての組み合わせ（15通り）は試さない。
    ボタンの表示は実行状態だけから決まり、どの開始・停止の経路も同じ実行状態の変化の通知を通るため（TAK-89 の設計の記録）
- **SC-187**: 通常のウインドウと全画面のそれぞれで、ボタンで停止した後のペイン表示・フォーカス・3ペインの幅・全画面の状態が、
  Esc で停止した場合と食い違う項目が0件。
- **SC-188**: 実行中にシートを表示している間、ボタンを押してスライドショーが止まる場合が0件。
  - 表示の復帰中にボタンを押して、再び開始する、または全画面の出入りを繰り返す場合も0件。
- **SC-189**: メニュー「表示 > スライドショーを開始」と ⇧⌘S の動作（開始の条件、実行中は無効）が、この変更の前と食い違う場合が0件。

## Assumptions

- **A-208**: 停止の操作をトグルにするのはツールバーのボタンだけとし、メニューの項目と ⇧⌘S は開始だけを行う。
  - メニューとキーボードの停止の手段は、今までどおり Esc とする（憲章 原則 III のキーボードの手段は Esc で満たす）
  - メニューと ⇧⌘S を変えないのは、メニューの項目名、ショートカットの一覧、contracts/keyboard-and-menus.md の契約を変えず、
    変更を小さく保つため（2026-11-08 の保守者の決定）
  - そのため、⇧⌘S を実行中に押しても、今までどおり何もしない（EC-71（変更））
- **A-209**: 実行中のボタンの有効の条件を Esc の受理の条件と揃えるのは、シートやモーダルの処理と、終了による表示の復帰を重ねないため。
  - キー入力先の条件を外すのは、ボタンはクリックで操作し、対象ウィンドウを指して押す操作だから。
    キー入力先でないことだけでは、無効の表示にしない
  - 設定ウインドウが前面のときも、最初のクリックで停止できる（US77-AS7。2026-11-10 の保守者の GUI 確認）
- **A-210**: ツールバーを文字だけで表示する形式で、項目名にオン・オフの印を独自に描かない。
  - 文字だけの形式は OS が項目名を描き、ボタンの表示を使わないため。実行中かどうかはプレビューのみ表示の画面で分かり、停止の操作は同じく使える
- **A-211**: トグルのボタンのアクセシビリティラベルは、状態によらず機能の名前（「スライドショー」）で固定する。
  - VoiceOver はラベルに加えてオン・オフの値も読むため、ラベルを「スライドショーを停止」に変えると「スライドショーを停止、オン」のように聞こえ、
    止まっていると取り違える恐れがある（2026-11-08 の設計のレビュー）
  - 今のボタンのアクセシビリティラベル「スライドショーを開始」も、この変更で「スライドショー」になる

## 変更する既存の要件

- **FR-114（変更）**: ツールバーに「スライドショー」ボタンをペイン表示ボタングループ（FR-089）の右隣に追加し、
  「表示」メニューの「スライドショーを開始」と ⇧⌘S でも開始できなければならない。
  - メニューと ⇧⌘S は、表示中の一覧に対応メディアが1件以上あるとき有効とし、名前の変更中、モーダル表示中、実行中は無効にする。
  - ボタンは開始と停止のトグルとし、オン・オフ、有効・無効、文言は FR-350〜FR-353 に従う。
  - ツールバー非表示中や全画面中もショートカットを使えなければならない。
- **A-47（変更）**: 開始キーは既存の contracts/keyboard-and-menus.md と衝突しない ⇧⌘S とする。
  - ツールバーのボタンは実行中にオンの状態で押せるようにし、押すと停止する（FR-351）。
  - メニューの項目と ⇧⌘S は実行中は無効にし、キーボードでの終了は Esc とする（A-208）。
  - メニューからも同じ開始操作に到達できるようにする
- **FR-134（変更）**: ツールバーに、虫眼鏡のレンズの内側に記号を重ねた3つのボタンを1つのボタングループとして、左から「拡大」
  （記号 `+`）、「表示領域に合わせる」（記号は両矢印）、「縮小」（記号 `-`）の順に置かなければならない。
  - グループは「スライドショー」ボタン（FR-114）の右隣、種類フィルタの左に置く。
  - 各ボタンは押した状態を保たない一時的な操作とし、アクセシビリティのラベル「拡大」「表示領域に合わせる」「縮小」と、
    ショートカットを含むツールチップを付けなければならない。
  - FR-136（preview.md）の条件を満たさないときと、上限・下限に達した拡大・縮小は無効にし、
    押しても何も起きないようにする

  FR-134 で変えるのは、ボタンの呼び名（「スライドショーを開始」ボタン → 「スライドショー」ボタン）だけ。

- **EC-71（変更）**: ⇧⌘S とメニュー「表示 > スライドショーを開始」の開始操作を繰り返しても、実行を重複させず、選択や次の予定時刻を変えない。
  - 実行中のツールバーのボタンの押下は、開始操作ではなく停止の操作とする（FR-351）
  - Esc またはボタンの停止と予定時刻が重なる場合は終了を優先し、終了後の切り替えは起こらない

  EC-71 で変えるのは、開始操作の範囲（ボタンを外す）と、予定時刻と重なる停止にボタンを加えることだけ。

- **contracts/keyboard-and-menus.md の「スライドショー」の表（変更）**:
  - 「⇧⌘S / 表示 > スライドショーを開始 / ツールバーの「スライドショーを開始」ボタン」の行を、「⇧⌘S / 表示 > スライドショーを開始」と、ツールバーのボタンの行に分ける
  - ツールバーのボタンの行: 停止中は開始し、実行中は停止する（FR-114・FR-350〜FR-353）

  停止中は ⇧⌘S と同じ、実行中は Esc と同じとする。有効の条件は FR-352 を参照する
