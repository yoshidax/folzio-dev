# Quickstart: 名前順でフォルダを先頭にまとめる（保守者のローカル確認）

前提: macOS のローカルで `scripts/make-app.sh` の後に `open .build/Folzio.app` で起動する。
`scripts/make-fixtures.sh ~/FolzioFixtures` で作る `mixed/`（サブフォルダ・メディア・zip を含む）を使う。

1. **昇順**: リスト形式で `mixed/` を開き、「ファイル名」の列見出しをクリックして昇順にする。フォルダの行が先頭にまとまり、その後にファイルが名前順で並ぶ。zip ファイルの表示をオンにしたときの zip は、ファイルの側に並ぶ。
2. **降順**: もう一度クリックして降順にする。フォルダは先頭のまま、フォルダ同士・ファイル同士が逆順になる。
3. **他の列**: 「作成日」「種類」「サイズ」「変更日」で並べ替える。フォルダが先頭にまとまらず、従来の順序（サイズ順はフォルダが 0 バイトで昇順の先頭）になる。
4. **検索結果と zip の中**: ⌘F でフォルダとファイルの両方に一致するキーワードを検索し、名前順で昇順・降順にする。フォルダの行が先頭にまとまる。検索中に結果が増えても保たれる。
   zip の中を開き、`..` が先頭、その次にディレクトリ、その次にファイルの順になる。
5. **メニュー**: 「表示 > 並べ替え」でファイル名の昇順・降順を選び、列見出しと同じ並びになる。
