# Quickstart: 検証手順

担当を分ける。Cloud は Swift・GUI を実行できない（AGENTS.md）。

## Cloud（Agent）

```bash
scripts/check-no-network.sh
scripts/check-readme-sync.sh master
scripts/dev/check-english-comments.sh
scripts/dev/check-skill-sync.sh
```

期待: すべて成功。

## CI（macOS）

`swift build`、`swift test`（`ToolbarLayoutTests`、ローカライズ整合性）。PR の作成後に結果を読む。

## 保守者の実機（`.app`）

準備: `scripts/make-app.sh` → `open .build/Folzio.app`。復元の確認は `.app` で行う（UserDefaults のドメインは `local.folzio.Folzio`）。

| # | 手順 | 期待 |
|---|---|---|
| Q1 | フォルダ A → B と移動し、カスタマイズ画面を開いて何も変えずに完了。⌘[ で A に戻る | 「<」が淡色、「>」が押せる |
| Q2 | 「履歴」を外して戻す。もう一度 A → B → ⌘[ | 同じく正しい。履歴を操作できる |
| Q3 | 「デフォルトセット」を入れ直し、ペイン（⌃⌘2）・種類（⇧⌘I）・zip（⌃⌘Z）・表示形式（⌘1/⌘2）・サイズ（⌃⌘.）を操作 | 各ボタンの表示が追従する |
| Q4 | セットを並び替え、すべて外し、メニューとショートカットで各機能を実行。全セットを戻す | 機能は使え、すべて戻せる（SC-002a） |
| Q5 | 並び替えてアプリを終了して再起動 | 同じ並び（R-3 の方式を採った後）。不正な保存値では既定の並びで起動 |
| Q6 | 表示モードを「アイコンとテキスト」「テキストのみ」に変える | 破綻しない。再起動後も保たれる |
| Q7 | ラベル・ツールチップを日英で確認（contracts/toolbar-labels.md） | 表のとおり |
| Q8 | ウィンドウを最小幅まで狭める | 他のセットが隠れず、溢れの表示で操作できる |
| Q9 | スライドショー実行中・名前の変更中・全画面中に、カスタマイズ画面を開く | 標準のまま制限しない。開いても動作が破綻せず、閉じた後も状態が正しい（FR-003b） |

R-3 の段0 のログ確認と、macOS のバージョンの共有も、実機で依頼する。
