- `swift run` などで版を取得できないときは、バージョン行を表示しない
- ダイアログはアプリ全体で 1 つとし、再選択すると前面へ出す。独立したウィンドウだが、メインウィンドウを閉じるとき設定ウインドウと同じく一緒に閉じる（確認時に、既存実装が設定ウインドウをそう扱っていると判明したため。保守者への質問では「残る」と案内していた）
- 表示言語の切り替えに再起動なしで追随し、リンクは URL の文字列をそのまま表示する
- 版は `CFBundleShortVersionString` のみを表示する（ビルド番号・日時は出さない）

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。アイコンは FR-043（overview.md）、表示言語は FR-145〜156（overview.md）、メニューは `specs/product/contracts/keyboard-and-menus.md` に従う。US45〜US47 は永続シナリオ ID。

### User Story 1 - アプリの版を確認する (Priority: P1)

利用者はアプリメニューから「Folzio について」を選び、アイコン・アプリ名・バージョンだけの簡素なダイアログで、使っている版を確認する。

**Why this priority**: 現在、版を確認する手段がない。これが本機能の中心の価値。

**Independent Test**: `.app` を起動し、アプリメニューの「Folzio について」を選ぶと、アイコン・Folzio・バージョンを表示するダイアログが開く。

**Acceptance Scenarios**:

- **US45-AS1**: **Given** 通常起動した `.app`、**When** アプリメニューの「Folzio について」を選ぶ、**Then** メインウィンドウとは独立したダイアログが開き、アプリアイコン・「Folzio」・バージョン番号（Info.plist の `CFBundleShortVersionString` と同じ値）を表示する。
- **US45-AS2**: **Given** ダイアログを表示中、**When** タイトルバーを見る、**Then** 閉じるボタンだけがあり、最小化・ズームのボタンとタイトル文字列はない。
- **US45-AS3**: **Given** メニューバーを開く、**When** アプリメニューを見る、**Then** 先頭に「Folzio について」、区切り線、「設定…」、区切り線、「終了」の順で並び、「Folzio について」にショートカットは割り当てない。
- **US45-AS4**: **Given** Info.plist を持たない起動（`swift run`）、**When** 「Folzio について」を選ぶ、**Then** バージョン行を表示せず、アイコン・Folzio・リンクを表示する。クラッシュせず、内部キーや空欄も出さない。

---

### User Story 2 - 公開リポジトリを開く (Priority: P2)

利用者はダイアログのリンクから、Folzio の OSS 公開版 GitHub リポジトリを既定の Web ブラウザで開く。

**Why this priority**: 配布元・最新版・問い合わせ先への入口になるが、版の確認が先にできれば成り立つ。

**Independent Test**: ダイアログのリンクを押す（または Tab で移って Space・Return を押す）と、既定のブラウザで `https://github.com/yoshidax/folzio` が開く。

**Acceptance Scenarios**:

- **US46-AS1**: **Given** ダイアログを表示中、**When** 画面を見る、**Then** `https://github.com/yoshidax/folzio` を URL の文字列そのままで、リンクと分かる見た目（青色・下線）で表示する。
- **US46-AS2**: **Given** ダイアログを表示中、**When** リンクをクリックする、**Then** 既定の Web ブラウザでそのリンク先を開く。ダイアログは開いたままで、アプリのほかの状態は変わらない。
- **US46-AS3**: **Given** ダイアログを表示中、**When** Tab でリンクにフォーカスを移し、Space または Return を押す、**Then** クリックと同じくリンク先を開く（FR-040）。
- **US46-AS4**: **Given** ダイアログを表示中、**When** 操作できる要素を数える、**Then** このリンクだけで、そのほかのボタン・リンクはない。
- **US46-AS5**: **Given** ダイアログを開いた直後、**When** リンクを見る、**Then** フォーカスの枠（青い枠）は表示しない。Tab でリンクへ移したときだけ、フォーカスの枠を表示する（マウスのクリックでは表示しない）。

---

### User Story 3 - 独立したウィンドウとして扱い、言語に追随する (Priority: P2)

利用者は何度選んでも 1 つだけのダイアログを使え、メインウィンドウとは別に閉じられる。表示言語を切り替えても開き直さずに読める。

**Why this priority**: 設定・ショートカット一覧と同じ使い勝手に揃え、国際化の既存仕様（FR-145・146）を保つ。

**Independent Test**: 「Folzio について」を 5 回選んでも 1 枚。⌘W・閉じるボタンで閉じ、表示言語を切り替えるとメニュー項目と読み上げが切り替わる。

**Acceptance Scenarios**:

- **US47-AS1**: **Given** ダイアログがある、**When** 「Folzio について」を再度選ぶ、**Then** 新しいウィンドウは作らず、既存のダイアログを前面へ出す（位置は保つ）。
- **US47-AS2**: **Given** ダイアログがキー入力先、**When** 閉じるボタンまたは ⌘W を実行する、**Then** ダイアログだけが閉じ、メインウィンドウの状態は変わらない。再び「Folzio について」で開ける。
- **US47-AS3**: **Given** ダイアログを表示中、**When** メインウィンドウを閉じる、**Then** ダイアログも閉じ、ダイアログだけが残ってアプリの終了を妨げない（設定ウインドウと同じ。最後のウィンドウを閉じるとアプリが終了する既存の規則は変えない）。
- **US47-AS4**: **Given** ダイアログを表示中、**When** 設定で表示言語を変える、**Then** 再起動と開き直しなしで、バージョン行の語（「バージョン」／「Version」）とアクセシビリティの文言が切り替わり、アプリメニューの項目名も切り替わる。アプリ名・URL・バージョンの数値は変わらない。
- **US47-AS5**: **Given** メインウィンドウがスライドショー中・全画面・名前の変更中・シート表示中、**When** 「Folzio について」を選ぶ、**Then** 設定と同じく選べて、これらの状態を壊さない。

### Edge Cases

- **EC-166**: 既定のブラウザがない、または開けなかったとき、エラーのダイアログは出さず、ダイアログも閉じない。アプリのほかの機能は変わらない。
- **EC-167**: ネットワークに接続していない状態でリンクを押しても、アプリは何も通信しない。表示の可否は既定のブラウザに任せる。
- **EC-168**: `CFBundleShortVersionString` が空・欠落・文字列でないときは、`swift run` と同じくバージョン行を表示しない。
- **EC-169**: 画面が小さい・文字の大きさや表示言語が変わっても、アイコン・アプリ名・バージョン・URL が欠けず、横スクロールや省略を必要としない。ダイアログはサイズ変更できない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-238**: アプリメニューの先頭に「Folzio について」（英語: About Folzio）を追加し、直後に区切り線を置いて、「設定…」の前に並べる。ショートカットは割り当てない。選ぶと FR-239 のダイアログを開く。メインウィンドウの状態（スライドショー・全画面・名前の変更・シート・設定ウインドウの表示中）に関わらず選べる（設定と同じ。US47-AS5）。
- **FR-239**: ダイアログは、メインウィンドウから独立した非モーダルのウィンドウとし、リサイズ・最小化・ズームはできない。タイトルバーは閉じるボタンだけを持ち、タイトル文字列は表示しない（アクセシビリティ上のウィンドウ名は「Folzio について」とする）。親ウィンドウの入力を妨げない。初期位置は画面中央とする。
- **FR-240**: ダイアログは、上から順にアプリアイコン（FR-043（overview.md）のアイコンと同じ図案）、アプリ名「Folzio」、バージョン、リンク（FR-242）を中央揃えで表示する。説明文・著作権表示・ビルド番号・日時・ヘルプ・サポートなどは表示しない。
- **FR-241**: バージョン行は、実行中のアプリの Info.plist の `CFBundleShortVersionString` の値を、表示言語の語とともに「Version 1.0.0」／「バージョン 1.0.0」の形で表示する。値を取得できない場合（`swift run` など Info.plist を持たない起動、または EC-168）は、バージョン行を表示せず、そのぶんの余白も空けない。固定の版の値をコードに持たない。
- **FR-242**: ダイアログは、Folzio の OSS 公開版 GitHub リポジトリ `https://github.com/yoshidax/folzio` を、URL の文字列そのままで、リンクの見た目（青色・下線・ポインターの変化）で表示する。クリック、または Tab でフォーカスして Space・Return を押すと、既定の Web ブラウザでその URL を開く（US46-AS2・AS3）。ダイアログを開いた直後は、リンクにフォーカスがあってもフォーカスの枠を表示しない。Tab などのキー操作でフォーカスが移ったときだけ枠を表示する（US46-AS5）。ダイアログに置く操作要素はこのリンクだけとし、そのほかのボタンやリンクは置かない。失敗時は EC-166 に従う。
- **FR-243**: ダイアログはアプリ全体で最大 1 つとする。再度開く操作は既存のダイアログを前面へ出し、位置を保つ。標準の閉じる操作と ⌘W（FR-205（window-layout.md））で閉じる。閉じた後は再び開ける。メインウィンドウを閉じるとダイアログも直ちに閉じ、ダイアログだけが残ってアプリの終了を妨げない（設定ウインドウと同じ。既存の終了規則は変えない）。起動時には開かず、位置は保存しない。
- **FR-244**: アプリメニューの項目名、バージョン行の語、アクセシビリティの文言（ウィンドウ名・アイコンの説明・リンクの説明・バージョン行）は、アプリ設定の日本語・英語に対応し、表示中も再起動なしで切り替える（FR-145・146（overview.md））。アプリ名・URL・バージョンの数値は翻訳・変形しない（FR-147（overview.md））。
- **FR-245**: ダイアログのアクセシビリティ（FR-154（overview.md））として、アイコン・アプリ名・バージョンを VoiceOver で順に読め、リンクはリンクとして識別できる。OS の明暗設定を尊重する。
- **FR-246**: `scripts/make-app.sh` が `.app` に書く `CFBundleShortVersionString` の既定値（`FOLZIO_VERSION` を指定しない開発時の値）を `1.0.0` にする（次のリリースが 1.0.0 のため）。配布時に指定したバージョンを使う規則（FR-170・171（overview.md））と、`CFBundleVersion` の既定値 `1` は変えない。

### Key Entities

- **About dialog**: アプリ全体で最大 1 つの、独立したウィンドウ。表示内容はアプリアイコン・アプリ名・バージョン（任意）・公開リポジトリのリンクで、永続する状態を持たない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-118**: ビルドした `.app` で、アプリメニューの「Folzio について」から 1 回の操作でダイアログを開き、表示されたバージョンが `plutil -extract CFBundleShortVersionString raw Folzio.app/Contents/Info.plist` の値と 100% 一致する。
- **SC-119**: 「Folzio について」を 10 回選んでもダイアログは 1 枚で、閉じるボタン・⌘W・メインウィンドウを閉じる操作の全ケースで US47-AS1〜AS3 を満たす。ダイアログ内の操作要素はリンク 1 つだけである。
- **SC-120**: リンクのクリックと、キーボード（Tab → Space/Return）の両方で、既定のブラウザに `https://github.com/yoshidax/folzio` が開く。日本語・英語を切り替えた両方向で、未翻訳の文言・アプリ名や URL の変形・文字の欠けは 0 件。`swift run` でバージョン行が出ず、クラッシュも 0 件である。

## Assumptions

- **A-146**: 全機能オフライン・外部送信なし（FR-041（overview.md））は変えない。リンクを押す操作は URL を OS に渡して既定のブラウザに任せるだけで、アプリ自身は通信しない（ネットワークの API を使わない）。ブラウザが開いた後の通信はアプリの外で起きる。
- **A-147**: 参考にした Claude for Mac の About にあるヘルプ・サポートのボタン、括弧付きのビルド番号、日時は対象外。バージョン番号は `CFBundleShortVersionString` のみで、配布時は Release のタグと一致する（FR-171（overview.md））。
- **A-148**: Issue 本文の「「設定…」の手間に」は「手前に」の誤記と解釈し、「設定…」の前に置く。公開リポジトリの URL は固定値とし、設定や環境で変えない。ショートカットは割り当てず、「ショートカット一覧」（entry ID `cheatsheet`）の対象にも加えない。

## 検証方針

Swift Testing で、バージョン文字列の取得と整形（取得不能・空・欠落の扱い、両言語の語）、固定 URL、メニュー項目の位置と識別子、両言語の `Localizable.strings` の揃いを自動検証する。ウィンドウの体裁（閉じるボタンのみ）、アイコン表示、リンクのクリックとキー操作、ブラウザの起動、1 枚だけであること、メインウィンドウを閉じたときの挙動、言語の即時切り替え、VoiceOver は quickstart.md で実機確認する。Cloud の静的検査、macOS CI の build/test、保守者の起動スモークを分けて記録する。
