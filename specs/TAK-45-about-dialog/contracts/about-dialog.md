# Contract: About ダイアログ

反映先は `specs/product/` の `contracts/keyboard-and-menus.md`（メニュー）、`contracts/app-bundle.md`（版の取得元）、`contracts/localization.md`（文言）。

## メニュー

| メニュー | 項目の並び |
|---|---|
| アプリ名 | Folzio について / ─ / 設定…（⌘,）/ ─ / 終了（⌘Q） |

「Folzio について」にキーは割り当てない。有効条件はなく、常に選べる（FR-233）。

## ウィンドウ

| 項目 | 値 |
|---|---|
| 種別 | 非モーダルの独立したウィンドウ。アプリ全体で最大 1 つ |
| スタイル | タイトルあり・閉じるボタンのみ。最小化・ズーム・リサイズなし。タイトル文字列は非表示（名前は「Folzio について」） |
| 内容（上から） | アイコン / 「Folzio」/ バージョン（任意）/ URL リンク。中央揃え |
| 閉じる | 閉じるボタン、⌘W、メインウィンドウを閉じるとき |
| 位置 | 初回は画面中央。再表示では保つ。起動時には開かず、保存もしない |

## 操作

| 操作 | 結果 |
|---|---|
| リンクをクリック / Tab → Space・Return | 既定の Web ブラウザで `https://github.com/yoshidax/folzio` を開く。失敗しても何も表示しない |
| 「Folzio について」を再度選ぶ | 既存のダイアログを前面へ |
| ⌘W | キー入力先がダイアログならダイアログだけ閉じる |
| Esc | 何もしない（閉じる操作に加えない） |

## バージョン

`Bundle.main` の `CFBundleShortVersionString`。取得できない、または空のときは行ごと表示しない。ビルド番号（`CFBundleVersion`）は表示しない。
