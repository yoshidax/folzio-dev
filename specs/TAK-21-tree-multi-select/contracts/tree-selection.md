# Contract: ツリーの複数選択とキーボード・メニュー

`specs/product/contracts/keyboard-and-menus.md` の「ディレクトリツリー」の節への変更点。反映は実装と検証の後に行う。

## キー

| キー | 動作（変更後） |
|------|------|
| ↑ / ↓ | 前 / 次のフォルダを1行だけ選択する（選択したフォルダの内容がリストに表示される）。複数選択中、または ⌘クリックで主の行を選択から外した後は、主の行の前 / 次の1行の選択に戻す。主の行が折りたたみで隠れているときは、隠したフォルダの行を起点にする（EC-143） |
| ⇧↑ / ⇧↓ | 選択を前 / 次の行へ広げる（縮める）。ファイルリストには最後に移動した行のフォルダの内容を表示する（FR-208・FR-209） |
| ⌘A | ツリーにフォーカスがあるときは何もしない（A-119） |
| ⌘V / ⌥⌘V | 選択したフォルダへペースト（コピー / 移動）。お気に入りの見出し・項目、複数の行の選択中は無効（FR-211） |
| ⌥⌘C | 選択したフォルダの絶対パスをコピーする。複数の行の選択中は無効（FR-183） |
| ⌃⌘T | 複数の行の選択中は無効（FR-211） |
| ⌘Delete | 選択中の行がすべて通常のフォルダのとき、確認モーダルの後にまとめて中身ごとゴミ箱に入れる。確認モーダルには件数と各フォルダの名前・絶対パス（先頭5件と残りの件数）を示し、省略設定に関わらず必ず表示する。親子のフォルダを同時に含む場合はエラーを表示して何もしない（EC-141）。通常のフォルダ以外を含む複数の選択では何もしない。お気に入りの項目1つを選択中は従来どおり登録を削除する（FR-064・FR-079・FR-211） |
| Return | 複数の行の選択中は何もしない（FR-211） |

## マウス

| マウス操作 | 動作 | 要件 |
|------------|------|------|
| ⌘クリック | 行を選択に加える（選択中なら外す）。加えた行のフォルダの内容をリストに表示する。外したときは表示を変えない | FR-208・FR-209 |
| Shift クリック | 最後にクリックした行からクリックした行までを選択する。クリックした行のフォルダの内容をリストに表示する | FR-208・FR-209 |
| 右クリック | 選択中の行なら選択全体、選択外の行ならその行だけを対象にメニューを出す。選択は変えない。複数の対象では、通常のフォルダと同じ項目を出し、「ゴミ箱に入れる」以外を淡色にする（「ゴミ箱に入れる」も、通常のフォルダ以外を含めば淡色） | FR-210・FR-211 |
| 通常のクリック（検索結果の表示中、複数選択の中の行） | 選択をその1行にし、検索結果の表示を終えてその行の一覧を表示する | FR-209・FR-086 |
| ドラッグ | 選択中の行からなら選択全体、選択外の行からならその行だけを対象にする。対象に通常のフォルダ以外が含まれるとドラッグは始まらない。⌘・Shift を押しながらでは始まらない（選択の変更になる） | FR-210・FR-211・FR-162・A-125 |

## ファイルリストからの同期

ファイルリストでフォルダを開く・親に戻る、戻る・進む、検索結果のフォルダを開く操作でツリーの選択が同期されたときは、複数選択を解いて同期した1行を選択し、
その行を以後の Shift+↑↓・Shift クリックの起点にする（FR-209）。

## 名前の変更中

名前の変更中に ⌘クリック・Shift クリックで選択を変えた場合は、ほかの場所のクリックと同じく編集を確定する（FR-103）。
