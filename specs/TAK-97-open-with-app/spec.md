# Feature Specification: 関連アプリケーションで開く

**Feature Branch**: `work`（Cloud 指定）

**Created**: 2026-11-11

**Status**: Draft

**Input**: [TAK-97](https://linear.app/takyoshida/issue/TAK-97/)「ファイルの右クリックメニューから関連アプリを選んで開く」。

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。既定アプリで開く動作は FR-251（file-list.md）と既存の「開く」に従う。

### User Story 1 - 1件のファイルを関連アプリで開く (Priority: P1)

利用者はファイルの右クリックメニューで「このアプリケーションで開く」を展開し、インストール済みの関連アプリを選んで開く。

**Why this priority**: TAK-97 の中心の操作である。

**Independent Test**: 画像ファイルを1件選択し、右クリックから既定アプリ以外の候補を選んで、そのアプリで開ける。

**Acceptance Scenarios**:

- **US80-AS1**: **Given** 通常のフォルダまたは検索結果でファイルを1件選択した、**When** 右クリックする、**Then** 「開く」の直後に「このアプリケーションで開く」が表示され、選択ファイルを開けるインストール済みアプリのサブメニューを持つ。
- **US80-AS2**: **Given** サブメニューに複数の候補がある、**When** 1つ選ぶ、**Then** そのアプリで選択ファイルを開き、既定アプリの関連付けを変更しない。
- **US80-AS3**: **Given** 既定の「開く」を選ぶ、**When** 実行する、**Then** 従来どおり OS の既定アプリで開く。

---

### User Story 2 - 利用できない状態を判別する (Priority: P2)

利用者は対象や候補がないときに実行不能なことをメニューで理解できる。

**Why this priority**: ファイル以外の行や複数選択に対して誤ったアプリを起動しないため。

**Independent Test**: 複数選択、フォルダ、zip 内、候補なしの各状態で項目が淡色となり、実行できない。

**Acceptance Scenarios**:

- **US80-AS4**: **Given** 複数選択、フォルダ、`..`、zip 内の項目、または背景、**When** 右クリックする、**Then** 選べるアプリ候補は現れない。
- **US80-AS5**: **Given** 関連アプリの候補がないファイルを1件選択した、**When** 右クリックする、**Then** 「このアプリケーションで開く」は淡色となる。
- **US80-AS6**: **Given** 候補を選んだ後にファイルまたはアプリを開けなかった、**When** 失敗が判明する、**Then** 利用者に失敗を通知する。

### Edge Cases

- zip ファイルそのものは通常のファイルとして対象に含める。zip の中の項目は対象外とする。
- サブメニュー表示後に選択が変わった場合は、別のファイルを誤って開かない。
- ファイル名や拡張子の大文字・小文字、アプリ名の重複、候補アプリの削除に耐える。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-368**: ファイルリストの通常フォルダと検索結果でファイルを1件選択したとき、右クリックメニューの「開く」の直後に「このアプリケーションで開く」を表示しなければならない。
- **FR-369**: 「このアプリケーションで開く」は、選択ファイルを開けるローカルにインストール済みの関連アプリをサブメニューに表示しなければならない。
- **FR-370**: サブメニューのアプリを選ぶと、そのアプリで対象ファイルを開き、OS の既定アプリの設定を変えてはならない。
- **FR-371**: 複数選択、フォルダ、`..`、zip 内の項目、候補なし、または編集操作中は、関連アプリを選ぶ操作を実行できなくしなければならない。
- **FR-372**: 指定アプリで開く処理に失敗した場合は利用者に通知し、ファイルリストの選択と表示を維持しなければならない。
- **FR-373**: 関連アプリを選ぶ操作には、キーボードで到達可能なメニューバーの経路を用意しなければならない。

### Key Entities

- **対象ファイル**: 選択中の1件のローカルファイル。通常のメディアファイルと zip ファイルを含む。
- **関連アプリ候補**: 対象ファイルを開けるローカルアプリ。表示名と一意のアプリ識別子を持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-201**: 関連アプリが2件以上あるファイルで、利用者は右クリックから3回以内のメニュー選択で目的のアプリを起動できる。
- **SC-202**: リスト形式とサムネイル形式、通常のフォルダと検索結果の組み合わせ4通りで、同じ候補と実行結果を得られる。
- **SC-203**: 複数選択、フォルダ、`..`、zip 内、候補なしの各状態で、対象外のアプリ起動が0件である。
- **SC-204**: 関連アプリで開いた後も、同じ拡張子の「開く」は従来の既定アプリを起動する。

## Assumptions

- **A-219**: 初回実装の対象は選択中の1ファイルだけとし、複数ファイルをまとめて同一アプリで開く操作は扱わない。
- **A-220**: 通常のフォルダの行は、拡張子に関連付くアプリの選択対象には含めない。
- **A-221**: ファイル拡張子だけから候補を独自に推定せず、OS がそのファイルを開けると判断する候補を使う。
- **A-222**: 「その他のアプリを選択」は今回の対象外とする。
