# Menu Contract

- 通常のファイルまたは zip ファイルを1件選択: 右クリックの「開く」の直後に「このアプリケーションで開く」サブメニューを表示する。
- 「ファイル」メニューにも同名のサブメニューを「開く」の直後に表示し、キーボードから到達できる。
- 候補は OS の適合順。各項目はアプリ名を表示し、同名の場合は区別できる補足を表示する。ショートカットは設定しない。
- 対象外または候補なし: 親項目を淡色にし、実行できる子項目を置かない。背景の右クリックメニューは変えない。
- アプリを選んだ時点のファイル URL とアプリ URL を使い、失敗時はアラートで通知する。
