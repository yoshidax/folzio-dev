# Quickstart: 削除後の選択の検証

対象: [spec.md](spec.md)、操作契約: [contracts/keyboard-and-menus.md](contracts/keyboard-and-menus.md)。
実装後に実施する手順であり、設計時点では未実行。

## 前提

macOS 15 以降、既存の Swift / Xcode 環境を用いる。依存の導入・更新は行わない。
削除確認には保守者が用意する使い捨ての画像・動画・フォルダ・zip のコピーを使う。
実データを確認のために削除しない。ゴミ箱は空にしない。

ファイル名で A・B・C・D・E と区別できる画像5件と、フォルダ2件（中にも画像）、短い動画、zip を用意する。
検索用には異なるフォルダに同じ検索語を含む名前の画像を複数用意する。
フォルダの最下部と実ファイルの最下部はその時のソートで判断する。

## 自動検証

各実装 Phase の終わりに、リポジトリルートで次をこの順で実行する。

```bash
swift build
swift test
scripts/dev/check-all.sh
scripts/make-app.sh
```

選択判断・model の fake 列挙と検索・coordinator の fake FileOperating・両モードのキー入力を検証する。
ファイルを実際にゴミ箱へ入れる自動テストは必要とせず、fake で成功と失敗を分ける。
性能に関わる結果は既存の基準で記録し、基準値は変更しない。
1万行・5000選択のケースでは候補と残存選択が正しいこと、および極端な増大がないことを記録する。
性能検証の正本は `specs/001-three-pane-media-viewer/quickstart.md` の「性能の検証」。

## Phase 3 の手動確認（T010）

古い Folzio を終了して、保守者が次を実行する。

```bash
open .build/Folzio.app
```

3ペインが表示され、操作が可能なことを確認する。以下をリスト形式・サムネイル形式で行う。

| ケース | 手順 | 期待結果 |
|---|---|---|
| 単一 | A・B・C・D・E の B を削除 | C のみ選択・フォーカス、C のプレビュー |
| 連続複数 | B・C を削除 | D のみ選択 |
| 非連続複数 | B・D を削除 | E のみ選択 |
| 末尾を含む複数 | B・E を削除 | 選択なし、プレビュー空 |
| フォルダ・zip | 削除対象の次がフォルダや zip の状態で削除 | 次の行を選択、中を開かずプレビュー空 |
| 動画 | 再生中の動画を削除 | 削除した動画が停止し、次の選択とプレビューが一致 |
| 画面外の次行 | 小さいウインドウで下端の項目を削除 | 次の選択先全体が最小限のスクロールで見える |
| キャンセル | 確認を表示して削除をキャンセル | 選択・フォーカス・プレビューが維持される |
| 選択外の右クリック | A を選択して B を右クリックから削除 | A の選択・プレビューを維持 |
| 全件失敗 | 権限で削除できないテストコピーを削除 | 理由を表示し、元の選択・プレビューを維持 |
| 一部失敗 | 削除可能・不可能な項目を一緒に削除 | 失敗した残存選択を保ち、別の次行は選ばない |

権限ケースは保守者が用意できる使い捨ての場所でのみ行う。
その環境を用意できない場合は未確認と報告し、自動 fake の結果と区別する。
一覧の名前・作成日・種類・サイズ・変更日の昇順と降順で、次の行が表示順に従うことを確認する。
検索結果では場所の並べ替えも確認する。

種類フィルタと名前の絞り込みをかけ、非表示の行を選ばないことを確認する。
検索結果でファイルとフォルダを削除し、子孫の結果が消え、残存する次の結果を選ぶことを確認する。
検索中の削除でも消えた結果が戻らず、新着行が今回の次行候補に割り込まないことを確認する。

削除中の場所・選択・ソート・フィルタ変更は自動テストで制御して検証する。
実機で操作完了が速く再現できない場合はその旨を報告し、成功と扱わない。
ツリーからの削除、外部での削除、移動で次行を自動選択しないことも確認する。
右クリックから実行してもキーボードフォーカスのペインが移らないことを確認する。

## Phase 4 の手動確認（T015）

再度作成した `.build/Folzio.app` を同じコマンドで起動する。
両表示形式・通常一覧・検索結果で、それぞれ末尾を削除した状態を作り直して確認する。

1. 削除直後は選択・フォーカスなしで、プレビューが空。
2. ↑ で残った最下部を単一選択し、スクロールとプレビューが一致。
3. 同じ選択なしの状態を作り直し、↓ で最上部を単一選択。
4. `..` がある一覧では ↓ が `..` を選び、プレビューは空。
5. `..` だけなら ↑・↓ はどちらも `..` を選ぶ。
6. 検索結果の全件を削除して行がなければ ↑・↓ は何もしない。
7. 選択ありの上下移動、Shift の範囲選択、サムネイルの左右移動、プレビューの矢印移動が従来どおり。

## 最終ビルドの起動確認（T018）

最終の自動検証と app 再作成の後、古いアプリを終了して `open .build/Folzio.app` を実行する。
3ペインの表示と、通常一覧・検索結果の削除後の選択、末尾削除後の ↑・↓ を両形式で再確認する。
