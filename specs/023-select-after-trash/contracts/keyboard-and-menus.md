# UI Contract delta: 削除後の選択と上下キー

反映先: `specs/product/contracts/keyboard-and-menus.md`。
新しい操作・メニュー項目・ショートカット・表示文言は追加しない。

## ゴミ箱に入れる

対象はキーボードの ⌘Delete、メニューバー、選択中の項目の右クリックメニュー。
通常一覧・検索結果、リスト形式・サムネイル形式で共通とする。
確認設定とキャンセルは既存どおり。

| 削除結果 | 選択 |
|---|---|
| 選択項目の削除成功 | 最も下の対象より後の最初の残存項目 |
| 後続候補なし | 選択・フォーカスなし |
| 一部失敗で元の選択が残る | 残存選択を保ち、失ったフォーカスを最後の残存選択へ |
| キャンセル・全件失敗 | 選択・フォーカス・プレビューを操作前のまま保つ |
| 選択外の項目の右クリック | 現在の選択を保つ |
| 操作中に利用者が選択・表示条件を変更 | 新しい状態を優先し、古い自動選択を適用しない |

選択先が見えるまで必要最小限スクロールする。キーボードフォーカスのペインは移さない。
選択先のプレビューは項目の種類に従う。フォルダや zip ファイルは中を開かずプレビューを空にする。
ツリー起点・アプリ外での削除に今回の次行選択は適用しない。

## ファイルリストの選択なしからの再開

| 状態とキー | 選択先 |
|---|---|
| 選択・フォーカスなしで修飾キーなし ↑ | 表示中の最下部の行 |
| 選択・フォーカスなしで修飾キーなし ↓ | 表示中の最上部の行 |
| 表示行なしで ↑ / ↓ | 何もしない |

`..` が表示されれば行として含める。リスト形式とサムネイル形式で同じ入口にする。
左右キー・Shift の範囲選択・既存の選択中の移動・プレビューのキー操作は変えない。
