# Feature Specification: 関連するアプリケーションでファイルを開く

**Feature Branch**: `feature/tak-97-open-with-application`

**Created**: 2026-11-11

**Status**: 実装中

**Input**: [TAK-97](https://linear.app/takyoshida/issue/TAK-97/ファイルの右クリックメニューから関連アプリを選んで開く)

## User Scenarios & Testing

### User Story 78 - ファイルを選んだアプリケーションで開く

ファイルリストでファイルを1件選び、右クリックの「このアプリケーションで開く」から、
そのファイルに関連付けられたアプリケーションを選んで開く。

**Acceptance Scenarios**:

- **US78-AS1**: メディアを1件選んでメニューを開くと、macOS がそのファイルを開けると登録したアプリケーションが表示される。
- **US78-AS2**: 候補を選ぶと、対象ファイルをそのアプリケーションで開く。
- **US78-AS3**: 通常のフォルダにある zip ファイル本体と検索結果中のメディアでも同じ操作ができる。
- **US78-AS4**: 対象がないとき、複数選択、フォルダ、`..`、zip 内の項目では項目を選べない。
- **US78-AS5**: 候補が0件ならサブメニューに案内を表示し、開く操作を実行しない。
- **US78-AS6**: 選んだアプリで開けないときは macOS のエラーを表示する。

## Requirements

### Functional Requirements

- **FR-368**: ファイルリストの右クリックメニューは、単一選択した実ファイルを、macOS が関連付けたアプリケーションから選んで開けなければならない。
  - 「開く」の直後に「このアプリケーションで開く」サブメニューを表示する。
  - メディアと zip ファイル本体を対象とし、通常のフォルダと検索結果の両方で使える。
  - 複数選択、フォルダ、`..`、zip 内の項目、名前の編集中は使えない。
  - 候補がない場合はサブメニューに案内を表示する。
  - アプリケーションによる起動が失敗した場合は、OS のエラーを表示する。
  - 既定の「開く」とメディアのダブルクリック（FR-251（file-list.md））の動作は変えない。
