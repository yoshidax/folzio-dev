# UI Contract: ショートカット一覧

## 起動・終了

「ファイル」の検索項目より後、ゴミ箱グループより前に「ショートカット一覧…」（Keyboard Shortcuts…、⌘/）を置く。
ファイルメニュー末尾に区切りと「閉じる」（Close、⌘W）を置く。

| 操作 | 結果 |
|---|---|
| ⌘/ / ファイル > ショートカット一覧… | 既存の親の一覧を作成または前面化。再実行で閉じない |
| ⌘W / ファイル > 閉じる | キー入力先の閉じられるウィンドウだけを閉じる |
| 親を閉じる | 対応する一覧も閉じる |
| 一覧の ↑↓ / Page Up・Down / Home・End | 一覧だけを縦スクロール |
| 一覧の Esc | 何もしない。親へ流さない |

起動は親終了後・名前の編集・親sheet・app modal・親全画面・slideshow中は無効。
設定や一覧がキーの場合も同じ親を対象とする。親へクリックすれば通常どおり操作できる。
既存の明示ターゲットを持つプレビュー拡大縮小のメニューは既存契約どおり親を操作する。

## 掲載範囲と固定順

以下は実装時のカタログと全行を照合する一覧。1行を1項目とし、合計44項目。
説明は実装時に日本語・英語の完全な文として翻訳する。条件は短い注記にし、現在無効でも項目を隠さない。
条件を省略した既存操作の解釈は `specs/product/contracts/keyboard-and-menus.md` に従う。
OS標準の一般編集キー・設定内の各コントロールのキー・マウス操作の網羅は対象外。

### 1 ペインと表示 / Panes and View

| Entry ID | キー | 説明・条件 |
|---|---|---|
| paneCycle | Tab / ⇧Tab | 表示中ペインを順 / 逆順に巡回 |
| paneFocus | ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | ツリー / リスト / プレビューへ。隠れたペインは対象外 |
| listOnly | ⌃⌘2 | ファイルリストのみ / 元の表示。名前の編集・全画面・slideshow中は無効 |
| previewOnly | ⌃⌘3 | プレビューのみ / 元の表示。名前の編集・全画面・slideshow中は無効 |
| toolbar | ⇧⌘T | ツールバー表示切り替え |
| listStyle | ⌘1 / ⌘2 | サムネイル / リスト形式 |
| thumbnailSize | ⌃⌘. / ⌃⌘, | サムネイル拡大 / 縮小。プレビュー倍率とは別 |
| imageFilter | ⇧⌘I | 画像のみ表示を切り替える。名前の編集中は無効 |
| movieFilter | ⇧⌘M | 動画のみ表示を切り替える。名前の編集中は無効 |
| zipVisibility | ⌃⌘Z | zip 表示を切り替える。zip内と検索結果には効果なし。名前の編集中は無効 |

### 2 フォルダと履歴 / Folders and History

| Entry ID | キー | 説明・条件 |
|---|---|---|
| treeSelect | ↑ / ↓ | ツリーで前 / 次のフォルダ |
| treeExpand | → / ← | ツリーで展開・子へ / 折りたたみ・親へ |
| treeExpandAll | ⌥→ / ⌥← | ツリー配下を展開 / 折りたたむ。未確認の孫以下は先読みしない |
| openContainer | ⌘↓ | リストのフォルダ・zipの中を表示、`..` なら上へ。メディアでは何もしない |
| enclosingFolder | ⌘↑ | 上の階層へ。ツリーのルートと検索結果では無効 |
| history | ⌘[ / ⌘] | 戻る / 進む。編集・全画面・slideshow中は無効。検索結果で戻ると検索を終了し、進むは無効 |
| favorites | ⇧⌘F | お気に入りへフォーカス。ツリー非表示・編集・全画面中は無効 |

### 3 選択とファイル操作 / Selection and Files

| Entry ID | キー | 説明・条件 |
|---|---|---|
| selection | ↑ / ↓ / ← / → | リストは上下、サムネイルは上下左右で選択 |
| extendSelection | ⇧ + 矢印 / ⌘A | 選択範囲を拡張 / すべて選択 |
| openDefault | ⌘O | 既定のアプリで開く。zip内は無効 |
| rename | Return | 名前の編集を開始。Returnで確定、Escで取消。ツリーのお気に入りは表示名、通常フォルダは実名。リストのzip内は無効 |
| copy | ⌘C | リストのファイルをコピー。zip内は無効 |
| paste | ⌘V / ⌥⌘V | コピー / 移動ペースト。ツリーの通常フォルダにも可。zip内・検索結果リストは無効。編集中の⌘Vは文字列の貼り付け |
| copyPath | ⌥⌘C | フォーカス中のツリー / リストの1件のパス。複数・`..`・zip内・編集・全画面・slideshow等は無効 |
| duplicate | ⌘D | 複製。zip内は無効 |
| trash | ⌘Delete | ゴミ箱へ。ツリーのお気に入りでは登録を削除。ルート・見出し・zip内は無効。既存の確認規則に従う |

### 4 検索 / Search

| Entry ID | キー | 説明・条件 |
|---|---|---|
| find | ⌘F | 検索シートを開く。編集・全画面・プレビューのみ表示中は無効 |

| Entry ID | キー | 説明・条件 |

| imageFit | ⌘0 | 表示領域に合わせる（100%）。画像なし・動画・プレビュー非表示は無効 |
| imageScroll | ⌥↑ / ⌥↓ / ⌥← / ⌥→ | プレビューにフォーカス中、はみ出す画像をスクロール |

|---|---|---|

| videoControls | ← / → / ↑ / ↓ | 3ペインで動画にフォーカス中、シーク / 音量（OS標準） |

### 7 アプリとウィンドウ / App and Windows

| Entry ID | キー | 説明・条件 |
|---|---|---|
| settings | ⌘, | 設定を開く |
| cheatsheet | ⌘/ | ショートカット一覧を開く / 前面化。起動の有効条件は本契約の冒頭 |
| close | ⌘W | キー入力先のウィンドウを閉じる。親の場合は対応一覧も閉じる |
| quit | ⌘Q | アプリ終了 |

## 表示とアクセシビリティ

見出し→キー→説明→条件の順。キー列の幅は揃え、説明・条件は残り幅で折り返す。
初期640×680pt、最小480×360ptの内容領域。スクロール内容の先頭が開いた直後の入力対象。
装飾は system colors と標準フォントを使用する。条件は色だけで区別しない。
VoiceOver は各見出しと項目のキー・説明・条件を対応づけて読めること。
言語切り替えで文を更新しても行IDと先頭可視項目を保持する。

## 同期の検証

契約表の44項目をカタログの ID とキー表記に照合し、翻訳の空欄・欠落・内部キー表示を自動検出する。
実際の入力処理との一致は quickstart の全項目照合を実施し、未確認を成功扱いにしない。
メニュー以外のキーはフォーカスと状態に依存するため、一覧自体は有効性のライブ表示を行わない。
