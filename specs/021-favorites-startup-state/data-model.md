# Data Model: 起動時のお気に入りの開閉状態

## 永続データ

| プロパティ | 保存キー | 型 | 既定値 |
|---|---|---|---|
| `restoresFavoritesExpansion` | `favorites.restoreExpansion` | Bool | false |
| `favoritesExpanded` | `favorites.isExpanded` | Bool | false |

- 値は CFBoolean のときだけ採用する。
- 未設定・文字列・整数（0と1も含む）・小数・配列・辞書は false として読む。
- キーはアプリの設定ドメインに保存し、テストでは独立した suite を注入する。
- 各 setter は対応キーだけを書き、登録・表示名・他の設定の値を変更しない。
- 移行元のキーはなく、旧版の登録内容と表示名はそのまま読む。

## 派生値

`SettingsStore.favoritesExpandedOnLaunch` は、2つの永続値が両方 true のときだけ true となる。
この読み取り自体は保存値を変更しない。

| 復元設定 | 保存した展開状態 | 起動時の展開状態 |
|---|---|---|
| false | false | false |
| false | true | false |
| true | false | false |
| true | true | true |

## 状態遷移

| 契機 | 設定 | 現在の開閉 | 保存する開閉 |
|---|---|---|---|
| 初回表示 | 保存値を読む | 派生値を適用 | 適用後の実際の状態 |
| 三角・矢印キー | 変更しない | 操作結果に従う | 操作後の実際の状態 |
| お気に入りへ移動 | 変更しない | 展開する | true |
| 設定オン・オフ | 選択値を保存 | 変更しない | 変更しない |
| ボリュームなどの更新 | 変更しない | 更新前の状態を保持 | 一時状態を保存しない |
| 次回起動 | 保存値を読む | 派生値を適用 | 適用後の実際の状態 |

一時的な再構築中であることを表すフラグは controller のメモリ内だけに置く。
新たなドメインモデルや永続的な更新中の状態は追加しない。

## 独立性

お気に入りの登録パス・表示名・存在確認結果・選択・通常階層の展開とは独立した値とする。
起動時にフォルダの選択や名前を更新せず、お気に入りのフォルダも開かない。
