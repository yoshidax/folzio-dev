# Contract delta: 設定とお気に入りの開閉

反映先: `specs/product/contracts/settings.md`。
これはレビュー用の変更契約であり、製品仕様への反映は実装と検証の後に行う。

## 新しい保存キー

| キー | 型 | 既定値 | 対応 |
|---|---|---|---|
| `favorites.restoreExpansion` | Bool | false | FR-399・402 |
| `favorites.isExpanded` | Bool | false | FR-400・401 |

- 新キーは CFBoolean だけを有効とし、未設定・不正な型は false とする。
- 復元設定は変更した時点で保存する。
- 開閉状態は起動時の適用後と、見出しの実際の開閉が変わった時点で保存する。
- 保存する開閉状態はオン・オフに依存せず、通常フォルダの開閉では変えない。
- 再構築時の一時的な状態は書き込まない。
- 旧キーの名前やお気に入りの登録・表示名の形式は変えず、移行処理も追加しない。

## 既存の非保存規定の置き換え

`FavoriteAvailability` は引き続き保存しない。
見出しの開閉状態は上の新キーへ保存し、既定では折りたたみ、復元オンのときだけ前回の状態で起動する。

## 設定ウインドウ

| 区分 | 項目 | 対応キー |
|---|---|---|
| お気に入り | 起動時に前回の開閉状態を復元する | `favorites.restoreExpansion` |

- 「一般」タブで区分を「言語 → プレビュー → お気に入り → 動画 → ファイル操作 → スライドショー」とする。
- 新しい項目はチェックボックスで、初期状態はオフとする。
- 「画像の操作 → 開閉状態の復元 → 自動再生」の Tab 順にする。
- 逆順も Shift+Tab で移動でき、Space で切り替えられるようにする。
- 新しい項目も区分間20pt、見出しと項目間8pt、幅620ptと内容に合わせる高さに従う。
- 保存は即時だが、現在のツリーは動かさず次回起動時から適用する。
  - 既存の「チェックボックスはすべて即時反映・再起動不要」の記述には、この起動時設定の例外を明記する。
- 英日切り替えでは見出し・チェックボックスと読み上げラベルを即時更新する。
