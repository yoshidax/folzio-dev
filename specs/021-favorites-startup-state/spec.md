# Feature Specification: 起動時のお気に入りの開閉状態

**Feature Branch**: `codex/tak-107-favorites-startup`

「お気に入り」を起動時に必ず閉じるか、前回の開閉状態を復元するかを設定できるようにする。

## Clarifications

### Session 2026-11-17

既定の `clarify_mode=auto` に従い、次の推奨回答を採用した。

- Q: 既存ユーザーにも復元を既定で有効にするか？ → A: オフを既定とし、従来の起動時の動作を維持する。
- Q: 設定を切り替えた時点で見出しを開閉するか？ → A: 現在の表示は変えず、次回起動から適用する。
- Q: 復元がオフの間も開閉状態を保存するか？ → A: 実際の状態を常に保存し、オンにした直後から次回復元できるようにする。
- Q: 保存値がない・不正な場合や登録0件の場合はどうするか？ → A: 保存値が使えなければ閉じ、登録0件にも同じ規則を適用する。
- Q: 「お気に入りへ移動」とボリューム更新の開閉はどう扱うか？ → A: 明示的な移動による展開は保存し、更新中の一時的な状態は保存しない。

## User Scenarios & Testing *(mandatory)*

### User Story 87 - 前回の開閉状態で起動する (Priority: P1)

利用者は前回開いていたお気に入りを次回も開き、閉じていた場合は閉じたまま閲覧を始められる。

**Why this priority**: 起動ごとの開き直しを減らすことが Issue の中心となる価値である。

**Independent Test**: 復元をオンにし、展開・折りたたみのそれぞれで終了して再起動する。

**Acceptance Scenarios**:

- **US87-AS1**: **Given** 復元がオンでお気に入りを展開している,
  - **When** アプリを終了して再起動する,
  - **Then** お気に入りの見出しが展開した状態で表示される。
- **US87-AS2**: **Given** 復元がオンでお気に入りを折りたたんでいる,
  - **When** アプリを終了して再起動する,
  - **Then** お気に入りの見出しが折りたたんだ状態で表示される。
- **US87-AS3**: **Given** 復元がオンでお気に入りが折りたたまれている,
  - **When** 「お気に入りへ移動」で展開し、そのまま終了して再起動する,
  - **Then** 見出しは展開され、フォルダの選択は従来の最後のフォルダの復元規則に従う。

### User Story 88 - 毎回閉じる動作を選ぶ (Priority: P1)

利用者は従来どおり毎回お気に入りを閉じて起動でき、設定はキーボードからも変更できる。

**Why this priority**: 既存ユーザーの起動時の動作を維持し、変更するかを本人が選べるようにする。

**Independent Test**: 設定未変更時とオフを選んだ場合に、展開して終了しても次回は閉じていることを確かめる。

**Acceptance Scenarios**:

- **US88-AS1**: **Given** この設定を変更したことがない,
  - **When** お気に入りを展開して終了し、再起動する,
  - **Then** 復元の設定はオフで、見出しは折りたたまれている。
- **US88-AS2**: **Given** 復元がオンでお気に入りが展開されている,
  - **When** 設定をオフにする,
  - **Then** 現在の開閉・選択・ファイルリスト・プレビューは変わらず、次回起動時は折りたたまれる。
- **US88-AS3**: **Given** 復元がオフでお気に入りが展開されている,
  - **When** 復元をオンにし、開閉操作を追加せず終了して再起動する,
  - **Then** 設定が保存され、お気に入りは展開した状態で表示される。
- **US88-AS4**: **Given** 設定の「一般」タブを開いている,
  - **When** Tab または Shift+Tab で新しいチェックボックスへ移動し、Space で切り替える,
  - **Then** マウスなしで変更が保存され、英語・日本語のどちらでも項目の意味が識別できる。

### Edge Cases

- **EC-268**: 復元する開閉状態が未保存または不正な場合は、復元がオンでも見出しを折りたたんで起動する。
- **EC-269**: お気に入りの登録が0件でも、見出しの開閉状態には同じ保存・復元規則を適用する。
- **EC-270**: 登録先が見つからない場合も、見出しの復元と登録項目の保持・淡色表示を独立して適用する。
- **EC-271**: ボリュームの接続・取り外し、お気に入りの追加・削除、表示言語やペイン表示の変更では、
  見出しの現在の開閉状態と次回復元する状態を変えない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-399**: ユーザーは設定の「一般」タブで、起動時にお気に入りの前回の開閉状態を復元するかを選べなければならない。
  - 「お気に入り」区分を「プレビュー」と「動画」の間に追加する。
  - 項目は「起動時に前回の開閉状態を復元する」チェックボックスとし、既定値はオフとする。
  - オフでは起動時に必ず折りたたみ、オンでは最後に保存した開閉状態で起動する。
  - 設定の未保存・不正な型の値はオフとする。
- **FR-400**: システムは起動時に「お気に入り」の見出しの開閉状態だけを設定に従って復元しなければならない。
  - 起動中に見出しを開く・閉じる操作は、設定がオフでも従来どおり使える。
  - 起動時の開閉状態の適用は、フォルダの選択・ファイルリスト・プレビュー・通常の階層の展開を変えない。
  - 「お気に入りへ移動」（FR-065（directory-tree.md））による展開も次回復元する状態に含める。
- **FR-401**: システムは復元の設定にかかわらず、実際に表示している見出しの開閉状態を変化時に保存しなければならない。
  - 起動時にも、設定を適用した後の開閉状態を保存する。
  - 更新のための一時的な折りたたみは保存せず、更新後の現在の開閉状態を保持する。
  - オフで起動した場合、以前の展開状態の保存値はその起動時の折りたたみ状態で置き換える。
- **FR-402**: 設定の変更は操作時に保存し、次回起動から適用しなければならない。
  - 設定を切り替えただけでは現在の見出しの開閉・選択・ファイルリスト・プレビューを変えない。
  - Tab 順は「言語 → 画像の操作 → 開閉状態の復元 → 自動再生」とし、残りの順序は維持する。
  - 項目は英語・日本語で表示し、表示言語の即時切り替えに追従する。
  - チェックボックスには読み上げで意味を識別できるラベルを付け、キーボードだけで切り替えられるようにする。

### FR-222（変更）

- **FR-222**: 設定ウインドウは、区分（「言語」「プレビュー」「お気に入り」「動画」「ファイル操作」「スライドショー」）
  を一定の間隔で区切って表示しなければならない。
  - （1）各区分の見出しの前（直前の区分の最後の項目との間）の間隔は、どの区分でも同じとし、
    同じ区分の中の項目どうしの間隔より広くする。
  - （2）見出しとその区分の最初の項目の間隔、同じ区分の中の項目どうしの間隔は、どの区分でも同じとする。
  - （3）特定の項目にだけ、文の行数を超える最小の高さを持たせて上下に空白を作ってはならない。
  - （4）設定ウインドウの高さは内容に合わせ、最後の項目の下の余白をウインドウの上端の余白と同じにする。
  - 幅は従来どおり固定とする。
  - （5）区分の並び・項目・保存のタイミングは `contracts/settings.md` の「設定ウインドウ（⌘,）」のとおりとする。

### Key Entities *(include if feature involves data)*

- **起動時の復元設定**: 前回の開閉状態を復元するかを選ぶ真偽値。
- **見出しの開閉状態**: 最後に表示していた「お気に入り」見出しの展開・折りたたみを表す真偽値。
  - お気に入りの登録内容・選択状態・登録先の存在確認結果とは独立して持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-221**: 復元設定のオン・オフと終了前の展開・折りたたみの4通りすべてで、次回起動時に設定どおりの見出しが表示される。
- **SC-222**: 旧版からの初回起動、開閉状態の未保存・不正値、登録0件、登録先不在、起動中の表示更新の各条件で期待結果に一致する。
- **SC-223**: 英語・日本語の両方で、設定の変更・保存・再表示と言語の即時切り替えができ、キーボード操作と読み上げで新しい項目を識別できる。

## Assumptions

### A-27（変更）

- **A-27**: 「お気に入り」の見出しは既定では起動時に折りたたみ、復元をオンにした場合だけ前回の開閉状態で始める。
  - 保存した開閉状態がない場合は折りたたむ。
  - 復元対象はこの見出しだけとし、通常のフォルダ階層の展開・選択・スクロール位置の保存は追加しない。
  - お気に入りの登録内容と表示名、利用可能性の判定、既存のフォルダ選択の復元は従来の規則に従う。
