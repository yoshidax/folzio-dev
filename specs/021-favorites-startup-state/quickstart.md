# Quickstart: 起動時のお気に入りの開閉状態

## 前提

- macOS 15 以降、既存の Swift 6 開発環境を使う。
- 対象ブランチは `codex/tak-107-favorites-startup`、起動対象はこの worktree の `.build/Folzio.app`。
- 設計の承認と実装後に実行する。
- 現在の設定とお気に入りの登録を控え、確認後に希望する復元設定へ戻す。
- 単体・結合テストでは専用 suite を使い、実際のアプリ設定を変更しない。

## 自動検証

対象テストは開発中に実行する。

```bash
swift test --filter 'SettingsStoreTests|FavoritesExpansionTests|SettingsTextTests|CatalogConsistencyTests'
```

実装単位の最後に、以下を順番どおり実行する。

```bash
swift build
swift test
scripts/dev/check-all.sh
scripts/make-app.sh
```

## 手動確認: 基本動作と表示

古い Folzio を終了し、保守者がこの worktree のターミナルで起動する。

```bash
open /Users/igachan/.codex/worktrees/e161/folzio/.build/Folzio.app
```

1. 3ペインが表示され、起動時の選択フォルダとファイルリストが従来どおりであることを確認する。
2. ⌘, で設定を開く。
   「一般」の「プレビュー」と「動画」の間に「お気に入り」と復元のチェックボックスがあることを確認する。
3. 設定オン・オフと終了前の開閉の全組合せを実行する。

| 復元設定 | 終了前 | 再起動時 |
|---|---|---|
| オフ | 折りたたみ | 折りたたみ |
| オフ | 展開 | 折りたたみ |
| オン | 折りたたみ | 折りたたみ |
| オン | 展開 | 展開 |

4. オフのまま展開し、オンに切り替えて追加の開閉操作をせず終了する。
   次回は展開されることを確認する。
5. オンで展開中にオフへ切り替える。
   現在の開閉・選択・プレビューが動かず、次回だけ閉じることを確認する。
6. オフで一度起動して終了し、保存されている展開状態が折りたたみに置き換わることを自動テストでも確認する。
7. オンで見出しを閉じた後に「お気に入りへ移動」（既定 ⇧⌘F）で展開し、再起動でも開いていることを確認する。
8. 見出しの開閉で、ファイルリスト・プレビュー・再生中の動画を意図せず切り替えないことを確認する。
9. 登録の追加・削除、表示言語の切り替え、ツリーのペイン表示切り替えで開閉が保たれることを確認する。
   安全に接続できるボリュームがあれば接続・取り外しでも確認し、未実施ならその旨を報告する。
   登録0件・不在の登録先・ボリューム更新の保存検証は分離した自動テストで必ず補う。
10. 旧版相当の新キー未設定と不正型のフォールバックは、実設定を壊さず専用 suite の自動テストで確認する。

## 手動確認: 言語・キーボード・読み上げ

1. English と日本語の両方で見出しと項目が表示され、文字が切れず、間隔と高さが既存の区分と揃うことを確認する。
2. 設定を開いたまま言語を切り替え、タイトルと読み上げラベルが更新され、チェック状態は変わらないことを確認する。
3. Tab で「画像の操作 → 開閉状態の復元 → 自動再生」、Shift+Tab でその逆順を確認する。
4. チェックボックスを Space で切り替え、設定を閉じて再度開いても値が保持されることを確認する。
5. VoiceOver で新しい項目の名称とオン・オフを両言語で識別できることを確認する。
