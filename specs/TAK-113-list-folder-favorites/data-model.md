# Data Model: フォルダの共通操作

## 操作対象（非永続）

- 入力元: 項目の右クリック、背景の右クリック、メニューバー／キー。
- 項目の右クリック: 選択外ならその項目1件、選択内なら選択全体。
- メニューバー／キー: 現在のフォーカスがあるペインの全選択。
- 元の対象全体の件数を維持し、`..`・不明な URL を除いてから単一と判定してはならない。
- 種類: 通常の実フォルダ、実ファイル、zip 内の仮想項目、`..`、お気に入りの仮想項目、見出し。
- 通常フォルダの URL とルート情報は既存の一覧／ツリーのモデルから得る。
- メニューを閉じた直後の action まで右クリック対象を保持し、キーへは流用しない。

## 共通メニュー方針（非永続）

- 操作順: ペースト群 → ゴミ箱 → 名前変更・複製 → コピー・パス → お気に入り → Finder に表示。
- 実フォルダ1件: 既存の個別条件に従い全操作を使える。
- 実フォルダ複数件: コピー・複製・Finder に表示と条件を満たすゴミ箱を使える。
- 単一先を要する操作: 「対象全体が実フォルダ1件」を満たす場合だけ使える。
- フォルダを含む一覧の混在対象: 外部アプリで開く項目を隠し、フォルダへのペーストは無効。
- ホーム・ボリュームのルート: 名前変更・ゴミ箱の既存の保護を両ビューへ適用する。
- ツリーの仮想項目が混ざる対象: 通常フォルダの一部だけを抽出して実行しない。

## ペースト先（非永続）

- 通常フォルダ1件の項目メニュー: その URL。検索結果でも同じ。
- 一覧の背景・メニューバー／キー: 表示中のフォルダ。検索結果・zip 内では nil。
- ツリーのメニューバー／キー: 選択中の対象フォルダ。従来の条件を使う。
- 一覧の実フォルダを含まない項目メニュー: 従来の表示中のフォルダ。
- 複数・混在・消失したフォルダの項目メニュー: nil。別の先に戻さない。
- 実行直前に対象を再確認し、権限・存在・自己の中への操作・衝突は既存のサービスで検証する。

## コピー・複製（既存のデータ形式）

- コピー: Pasteboard の file URL 群。ツリーでも同じ形式を使う。
- 複製: 対象ごとの親フォルダへ既存の採番規則で複製。元の内容は維持。
- 実操作は FileOperationCoordinator と既存の Core サービスに委譲する。
- テストは一時フォルダと隔離した pasteboard／defaults を使い、利用者の実データを操作しない。

## お気に入り（既存）

- 入力は一覧の MediaFile 群・対象 URL 集合・zip 内の状態。出力は登録対象 URL または nil。
- 制約: 「対象集合は1件」「その URL が一覧に存在する」「種類は `.folder`」「zip 内ではない」。
- 重複判定は既存の標準化したパス。未登録なら末尾へ追加して保存、登録済みなら順序・表示名を保持。
- 一覧のフォーカスで候補なしでもツリーへ戻さない。文字入力中は登録キーを無効にする。
- 新しい保存形式・設定キーはない。
