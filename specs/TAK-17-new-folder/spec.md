## Clarifications

### Session 2026-10-31

- Q: 新しいフォルダの名前の決め方は？ → A: Finder と同じく既定名「名称未設定フォルダ」（同名があれば連番）で即作成し、行の中で名前の編集を始める
- Q: ショートカットは？ → A: ⇧⌘N（Finder の「新規フォルダ」と同じ。現行のメニュー・ショートカット一覧で未使用）
- Q: 「ファイル > 新規フォルダ」と ⇧⌘N の作成先は？ → A: フォーカスのあるペインで決める。ファイルリストなら表示中のフォルダ、ツリーなら選択中のフォルダ（お気に入りの項目なら登録先の実フォルダ）
- Q: ファイルリストの右クリックで出す範囲は？ → A: 項目のない背景だけ。背景では表示中のフォルダ向けの専用メニュー（新規フォルダ / ペースト / 移動ペースト / Finder に表示）を出し、項目（メディア・zip ファイル・フォルダ・`..`）の右クリックメニューは従来どおりで「新規フォルダ」を出さない

## User Scenarios & Testing *(mandatory)*

### User Story 35 - 整理先のフォルダをその場で作る (Priority: P1)

ユーザーは Folzio で画像や動画を閲覧・整理しながら、Finder に切り替えずに整理先のフォルダを作り、名前を付けられる。
ツリーの通常の階層、お気に入り、ファイルリストのどこからでも作れる。

**Why this priority**: TAK-17 の主目的。ドラッグ・移動ペースト（FR-020・FR-019）による整理の前提になる。

**Independent Test**: ツリーの通常のフォルダ・ホーム・お気に入りの項目、ファイルリストの背景（リスト形式・サムネイル形式）、
「ファイル > 新規フォルダ」と ⇧⌘N（ツリー・ファイルリストのそれぞれにフォーカス）から作成し、作成先・既定名・名前の編集・
表示の反映を確かめる。

**Acceptance Scenarios**:

1. **US35-AS1**: **Given** ツリーでフォルダ A を選択中, **When** 別のフォルダ B の行を右クリックして「新規フォルダ」を選ぶ,
   **Then** B の中に「名称未設定フォルダ」が作られ、B がツリーで展開されて新しい行で名前の編集が始まる。ツリーの選択（A）・
   ファイルリスト・プレビューは変わらない。名前を入力して Return で確定すると、確認モーダルなしにその名前になる
2. **US35-AS2**: **Given** ファイルリストに通常のフォルダ F の一覧を表示中（リスト形式またはサムネイル形式）, **When** 項目のない
   背景を右クリックして「新規フォルダ」を選ぶ, **Then** F の中に「名称未設定フォルダ」が作られ、ファイルリストではその行だけが
   選択されて名前の編集が始まる。ツリーで F が展開済みなら新しいフォルダの行も現れる
3. **US35-AS3**: **Given** ファイルリストにフォーカスがあり F を表示中, **When** ⇧⌘N を押す（または「ファイル > 新規フォルダ」を
   選ぶ）, **Then** US35-AS2 と同じ結果になる。ツリーにフォーカスがありフォルダ B を選択中なら、US35-AS1 と同じく B の中に作られる
4. **US35-AS4**: **Given** お気に入りの項目 X（登録先は実フォルダ R）, **When** X を右クリックして「新規フォルダ」を選ぶ（または X を
   選択しツリーにフォーカスがあるときに ⇧⌘N）, **Then** R の中に作られる。ファイルリストが R を表示中なら、ファイルリストで新しい
   行を選択して名前の編集を始める。表示していなければ既定名のまま作成だけを行う
5. **US35-AS5**: **Given** F に「名称未設定フォルダ」が既にある, **When** F に新規フォルダを作る, **Then** 「名称未設定フォルダ 2」
   （それもあれば空いている次の番号）で作られ、既存の項目は変わらない
6. **US35-AS6**: **Given** 作成直後の名前の編集中, **When** Esc を押す、空の名前で確定する、または既定名のまま確定する, **Then**
   フォルダは既定名のまま残る。「/」「:」・先頭の「.」・同じ場所の別項目と同じ名前・パッケージとして扱われる名前で確定すると、
   フォルダの名前の変更と同じ検証エラーを表示し、名前は既定名のまま残る
7. **US35-AS7**: **Given** ファイルリストに zip の中または検索結果を表示中, **When** 背景を右クリックする、またはファイルリストに
   フォーカスがあるときに ⇧⌘N を押す, **Then** 「新規フォルダ」は淡色で、何も作られない。見つからないお気に入りの項目の右クリック
   でも同じく淡色。書き込みできない場所では、作成を試みて失敗の理由を表示し、何も作られない
8. **US35-AS8**: **Given** ファイルリストで項目を選択中, **When** 項目（メディア・zip ファイル・フォルダ・`..`）を右クリックする,
   **Then** 従来どおり選択中の項目向けのメニューが出て、「新規フォルダ」は含まれない

### Edge Cases

- **EC-141**: 作成の直前に作成先が削除・移動・名前変更された、またはアクセスできなくなった場合は、何も作らず、作成先の名前と
  失敗の理由を表示する（FR-026）。書き込み権限のない場所・読み取り専用のボリュームも同じ（EC-08）
- **EC-142**: 既定名を決めてから作成するまでの間に同じ名前の項目がアプリの外で現れた場合は、既存の項目を上書き・変更せず、
  次の空いている番号の名前で作る
- **EC-143**: 作成直後の名前の編集中に、そのフォルダがアプリの外で削除・移動・名前変更された場合は、確定しても名前を変えず、
  失敗の理由を表示する（EC-47 と同じ）
- **EC-144**: ツリーで作成先が折りたたまれている、または開閉の三角がない（サブフォルダがない）場合は、作成後に三角を表示して
  展開し、新しい行を表示する（FR-054）。作成先の祖先が折りたたまれている場合（右クリックした行は常に見えているため、
  ⇧⌘N でスクロール外のフォルダを選択中の場合を含む）は、新しい行が見えるまで必要最小限のスクロールを行う
- **EC-145**: 種類フィルタ（FR-056）がオンでも、新しいフォルダの行はファイルリストに表示する（フォルダの行は種類フィルタで
  隠れない）

## Requirements *(mandatory)*

### Functional Requirements（追加）

- **FR-208**: ユーザーは、次のどの手段でも新しいフォルダを作成できなければならない。
  （1）ツリーのフォルダの行（通常のフォルダ・ホーム・マウント中のボリュームの最上位・利用可能なお気に入りの項目）の右クリックメニューの
  「新規フォルダ」。右クリックした行のフォルダ（お気に入りの項目では登録したフォルダ）の中に作り、ツリーの選択は変えない（A-21）。
  （2）ファイルリストの背景（リスト形式・サムネイル形式で、どの項目にも当たらない位置）の右クリックメニューの「新規フォルダ」。
  表示中のフォルダの中に作る。
  （3）「ファイル > 新規フォルダ」と ⇧⌘N（Finder と同じ割り当て。FR-019）。ファイルリストにフォーカスがあるときは表示中のフォルダの中に、
  ツリーにフォーカスがあるときは選択中のフォルダ（お気に入りの項目では登録したフォルダ）の中に作る
- **FR-209**: 新しいフォルダの名前は既定名「名称未設定フォルダ」（英語: untitled folder）としなければならない。作成先に同じ名前の
  項目（大文字小文字の違いのみ・隠し項目・ファイルを含む）がある場合は、FR-018 の複製と同じく「名称未設定フォルダ 2」から空いている
  番号まで進める。作成は既存の項目を変更しないため、確認モーダル（FR-022）を出さず、確認モーダルの省略設定（FR-023）にも影響されない
- **FR-210**: 作成後、システムは新しいフォルダの行で名前の編集を次のとおり始めなければならない。
  （1）ファイルリストから作成した場合（背景の右クリックメニュー、またはファイルリストにフォーカスがあるときのメニューと ⇧⌘N）:
  ファイルリストで新しい行だけを選択し、並べ替えの位置で行全体が見えるまで必要最小限のスクロールを行い、その行で名前の編集を始める。
  フォルダの行を選んだときと同じくプレビューは空にし、再生中の動画は止める（FR-076）。キーボードフォーカスはファイルリストのまま。
  （2）ツリーで通常のフォルダ・ホーム・ボリュームの最上位を作成先にした場合: 作成先をツリーで展開し、新しい行が見えるまで必要最小限の
  スクロールを行い、その行で名前の編集を始める。ツリーの選択・ファイルリストの表示と選択・プレビュー・最後に選択していたフォルダ
  （FR-003）は変えない（FR-103 と同じ）。キーボードフォーカスはツリーにする。
  （3）お気に入りの項目を作成先にした場合: お気に入りの項目は子の行を持たない（FR-063）ため、ファイルリストが登録したフォルダを
  通常の一覧として表示中なら（1）と同じくファイルリストの新しい行で名前の編集を始め、キーボードフォーカスをファイルリストに移す。
  表示していなければ、名前の編集は始めず既定名で作成するだけとする。ツリー下側の実際の階層の展開・選択は変えない（FR-063）
- **FR-211**: 作成直後の名前の編集は、編集の始め方と終え方、名前の検証をフォルダの名前の変更（FR-103・EC-14・EC-53）と同じとする。
  ただし確認モーダルは、FR-024 に関わらず出さない（作ったばかりの空のフォルダに名前を付けるため）。Esc で取り消した場合、確定した名前が
  空（前後の空白だけを含む）または既定名と同じ場合は、何もせずフォルダを既定名のまま残す。検証エラーのときはエラーを表示し、
  フォルダを既定名のまま残す。名前の変更に失敗した場合は FR-026 に従って表示する。名前の編集を取り消しても作成は取り消さない
- **FR-212**: 次の場合、「新規フォルダ」（右クリックメニュー・「ファイル」メニュー）を淡色にして選べなくし、⇧⌘N は何もしない。
  ファイルリストを作成先にするとき: zip の中を表示中（FR-073）、検索結果を表示中、表示中のフォルダが見つからない・読み込めない。
  ツリーを作成先にするとき: 「お気に入り」の見出しを選択中、選択がない、見つからないお気に入りの項目（FR-067）。
  共通: 名前の変更中（FR-102）、フルスクリーン中、スライドショー実行中、プレビューにフォーカスがあるとき、ペインの表示切り替えで
  作成先のペインを隠している間（FR-092）。書き込みできない場所は事前に無効にせず、実行して EC-141 に従う
- **FR-213**: ファイルリストの背景を右クリックしたとき、システムは選択中の項目向けのメニューの代わりに、表示中のフォルダ向けの
  メニューを次の順で表示しなければならない。1. 新規フォルダ（⇧⌘N）、2. ─、3. ペースト（⌘V）／ 移動ペースト（⌥⌘V）、4. ─、
  5. Finder に表示。ペースト・移動ペーストの対象と有効条件は従来のペースト（表示中のフォルダへ。FR-019・FR-073・FR-087）と同じとし、
  「Finder に表示」は表示中のフォルダを Finder で表示する（zip の中・検索結果の表示中は淡色）。背景の右クリックではファイルリストの
  選択・プレビューを変えない。項目の右クリックメニューは変えず、「新規フォルダ」を出さない
- **FR-214**: 作成の結果は、ツリー・ファイルリストに即座に反映しなければならない（FR-027）。作成先がファイルリストに表示中なら新しい行を
  並べ替えの位置に加え、ツリーで作成先が展開済みなら新しい行を兄弟の並び順の位置に加え、開閉の三角の有無を更新する（FR-054）。
  検索結果は新しく現れた項目を加えない従来の規則（FR-087）に従う。操作の履歴（FR-107）と最後に選択していたフォルダ（FR-003）は変えない

### Functional Requirements（変更）

- **FR-024**（変更）: 確認モーダルの省略は、コピー（ツリーのフォルダへのペースト・ドロップによるコピーを含む）と、ファイルリストからの
  削除（ゴミ箱へ入れる）と、お気に入りの削除（FR-064）にだけ適用されなければならない。名前の変更（ツリーのフォルダの名前の変更（FR-103）を含む）と移動、およびツリーのフォルダをゴミ箱に
  入れる操作（FR-079）は、設定に関わらず常に確認モーダルを表示しなければならない。設定ウインドウの確認の項目には、
  常に確認する操作として名前の変更・移動・ツリーのフォルダのゴミ箱を示す。
  複製（FR-018）とフォルダの新規作成（FR-209）、および作成直後のフォルダの名前の編集（FR-211）は確認モーダルの対象外とし、設定にも影響されない。省略時の安全性は、削除が必ずゴミ箱経由で
  元に戻せること（FR-021）、コピーが元のファイルを変更しないこと、同名ファイルの上書きが常に確認されること
  （FR-025）で担保する。この方針は憲章 v1.1.0 原則 I の「確認または取り消し可能性」に従う

### Assumptions（変更）

- **A-21**（変更）: ツリーの右クリックメニューの各項目は、Finder と同じく右クリックした行を対象にする（選択中の行ではない）。
  お気に入りの追加・削除・名前の変更、ツリーのフォルダの「ゴミ箱に入れる」「名前を変更」（FR-079・FR-103）、「新規フォルダ」（FR-208）と、既存の
  「ここにペースト」「ここに移動ペースト」「Finder に表示」に同じ規則を使う

### Key Entities

- **ファイル操作**（変更）: 種類（コピー/移動/名前の変更/削除/フォルダの作成）、対象ファイル群、操作先、結果（成功/失敗と理由）
- **作成先**: 新しいフォルダを作る実フォルダ。右クリックした行・表示中のフォルダ・ツリーで選択中のフォルダのいずれか。お気に入りの項目では
  登録したフォルダ
- **作成の起点**: ツリー（通常のフォルダ・お気に入りの項目）またはファイルリスト。作成後に名前の編集を始める場所（FR-210）を決める

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-102**: ツリー（通常のフォルダ・ホーム・お気に入りの項目）、ファイルリストの背景（リスト形式・サムネイル形式）、「ファイル > 新規フォルダ」と
  ⇧⌘N（ツリー・ファイルリストのそれぞれにフォーカス）の各手段で、新しいフォルダが意図した作成先に既定名（または連番）で作られる割合が 100%
- **SC-103**: FR-212 の無効条件・書き込みできない場所・名前の編集の取り消しと検証エラーの全ケースで、意図しないフォルダの作成と、既存の
  項目の名前・内容の変更が 0 件
- **SC-104**: Finder に慣れたユーザーが、説明なしで右クリックまたは ⇧⌘N からフォルダを作成して名前を付ける操作を初回で完了できる

## Assumptions

- **A-119**: 既定名は Finder に合わせる（日本語「名称未設定フォルダ」、英語「untitled folder」）。連番の付け方は複製（FR-018）と同じ
- **A-120**: 作成直後の名前付けは、既存の項目の名前を変える操作ではないため確認モーダルを出さない（FR-024 の常時確認は既存の項目の改名が対象）
- **A-121**: ファイルリストの背景の右クリックは、ファイルリストの選択を変えない。背景かどうかは右クリックした位置に項目があるかで決める
  （リスト形式の最終行より下、サムネイル形式の項目の間と外側）
- **A-122**: 取り消し（⌘Z）、選択項目から新規フォルダ（Finder の ⌃⌘N）、フォルダ以外の新規作成、検索起点の選択パネルでの新規作成
  （FR-141（search.md）・A-84（search.md））は範囲外とする
- **A-123**: zip の中は読み取り専用（FR-073）、検索結果は作成先となる単一のフォルダがないため、ファイルリストを作成先にする作成の対象外とする。
  検索結果を表示中でも、ツリーにフォーカスがあればツリーの選択中のフォルダに作れる（FR-103 と同じ考え方）
- **A-124**: ショートカット一覧（FR-202）の「選択とファイル操作」に新規フォルダ（⇧⌘N）を加える（合計 45 項目）
- **A-125**: 新しい文言（「新規フォルダ」「名称未設定フォルダ」とその英語）は既存の翻訳の仕組み（contracts/localization.md）で両言語に追加する
- 新規 ID は master の取り込み時に再確認する。採番時の既存の最大値は FR-207・SC-101・EC-140・A-118・US34
