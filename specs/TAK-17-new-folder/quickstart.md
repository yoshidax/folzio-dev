# Quickstart: TAK-17 フォルダの新規作成

設計段階。以下は実装後の検証手順であり、実行済みではない。

## Prerequisites

macOS 15 以降、Swift 6。書き込める一時テストフォルダ（例: `~/FolzioNewFolderTest`）と、書き込めないフォルダ（例: `chmod a-w` した
テスト用フォルダ）を用意する。既存のデータを使わない。Cloud では `swift`・GUI のコマンドを実行しない。

## Automated validation (macOS / CI)

```bash
swift build
swift test --no-parallel --skip FolzioPerformanceTests
swift test --filter FolzioPerformanceTests
```

新しいテストで、既定名・連番（大文字小文字の違い・隠し項目・ファイルを含む）、作成の成功と実在、作成先なし・書き込み不可・作成時の同名、
ツリーとファイルリストの有効条件、ツリーの右クリックメニューの構成、ショートカット一覧の 45 項目、両言語の文言を確かめる。

## GUI validation (maintainer)

```bash
scripts/make-app.sh
open .build/Folzio.app
```

一時テストフォルダ T に画像を数件と、サブフォルダ A・B を作る。T をお気に入りに登録しておく。

1. ツリーで A を選択したまま B の行を右クリック →「新規フォルダ」。B が展開され、「名称未設定フォルダ」の行で名前の編集が始まる。
   ツリーの選択（A）・ファイルリスト・プレビューが変わらない。名前を入力して Return → 確認モーダルなしで改名される（US35-AS1）
2. ファイルリストに T を表示し、リスト形式で最終行より下の背景を右クリック → 専用メニュー（新規フォルダ / ペースト / 移動ペースト / Finder に表示）。
   「新規フォルダ」で新しい行だけが選択され、編集が始まる。サムネイル形式でも項目の間の背景で同じ（US35-AS2）。背景の右クリックで選択が変わらない（A-121）
3. 画像の行・フォルダの行・`..` の行を右クリック → 従来のメニューで「新規フォルダ」がない（US35-AS8）
4. ファイルリストにフォーカスがあるときに ⇧⌘N と「ファイル > 新規フォルダ」、ツリーにフォーカスがあるときに ⇧⌘N（US35-AS3）
5. お気に入りの T を選択して ⇧⌘N → ファイルリストで編集。別のフォルダを表示中に T を右クリック →「新規フォルダ」→ 既定名で作られるだけ（US35-AS4）
6. 続けて作成 →「名称未設定フォルダ 2」「3」（US35-AS5）。Esc・空・`a/b`・`.x`・既存の名前・`X.app` で確定（US35-AS6）
7. zip の中・検索結果の背景と ⇧⌘N、見つからないお気に入りの右クリック、プレビューにフォーカス・フルスクリーン・スライドショー中の ⇧⌘N が無効（US35-AS7、FR-212）
8. 書き込めないフォルダで作成 → 失敗の理由が出て、何も作られない（EC-141）
9. 表示言語を英語にして作成 → 「untitled folder」、メニューは「New Folder」。ショートカット一覧（⌘/）に ⇧⌘N の行がある（A-124・A-125）

結果は `checklists/validation.md` に記録する（実行日、OS、確認項目、合否）。
