# Feature Specification: お気に入りの名前の変更

**Feature Branch**: `002-favorite-folder-rename`

**Created**: 2026-10-24

**Status**: Draft

**Input**: User description: "お気に入りに登録したフォルダをリネームできるようにする。お気に入りに登録するフォルダの名前はフォルダの名前そのものであるため、複数のパス違いの同名のお気に入りを登録すると区別がつかなくなるため、お気に入りフォルダの名前をユーザーが任意の内容でリネーム可能にする。オペレーションはファイルビューのリネームと同様、お気に入りフォルダを選択してからリターンキー押下、または右クリックメニューからリネームできるようにする。あくまでもお気に入りの登録フォルダーのリネームであって参照先の物理フォルダーの名称は変えてはいけない。"

既存の仕様（`specs/product/`）への変更点だけを書く。既存の項目は `ID（領域のファイル）` で参照する。

## Clarifications

### Session 2026-10-24

- Q: この機能を入れる前に登録したお気に入りは、アップデート後にどう扱うか？ → A: 登録順のまま、表示名を変更していない項目として復元する（保存形式を変える場合は旧形式から読み替える）
- Q: ファイルリストに zip の中または検索結果を表示している間も、ツリーのお気に入りの項目の名前を変更できるか？ → A: できる。zip の中の読み取り専用と検索結果の制限はファイルリストの操作にだけ適用し、ツリーにフォーカスがあるときの Return と「編集 > 名前を変更」は有効にする
- Q: 既存の「ファイル名の変更中は無効」とする項目（FR-062・FR-065・FR-080・FR-090・FR-096）は、お気に入りの表示名の編集中をどう扱うか？ → A: 既存の項目の本文は変えず、FR-102 を「名前の変更中」（ファイル名の変更とお気に入りの表示名の編集の両方）の定義とする。無効にする操作は「など」で済ませず、契約（keyboard-and-menus.md）でファイル名の変更中に無効とされている操作のすべてとし、契約の表記を「名前の変更中」に改める
- Q: 同じ表示名のお気に入りが複数あるとき、削除の確認モーダルでどれを削除するかをどう見分けるか？ → A: 表示名に加えて、登録したフォルダの絶対パスを示す
- Q: スクリーンリーダーが読み上げるお気に入りの項目名は、表示名と登録したフォルダの名前のどちらか？ → A: 表示名。編集欄には「お気に入りの名前」というアクセシビリティラベルを付ける

## User Scenarios & Testing *(mandatory)*

### User Story 1 - フォルダを辿って画像をプレビューする（既存 US1 への追加）

お気に入りには、登録したフォルダの名前がそのまま項目名として表示される（A-19（directory-tree.md））。
場所の違う同じ名前のフォルダ（例: `~/Photos/2025` と `/Volumes/Backup/Photos/2025`）を登録すると、
「お気に入り」の下に「2025」が2つ並び、どちらがどのフォルダか見分けられない。ユーザーは、お気に入りの項目に
自分で分かりやすい名前（例:「2025（バックアップ）」）を付けて区別したい。名前を変えるのはお気に入りの項目の
表示だけで、実際のフォルダの名前は変わってはならない。

**Why this priority**: 同名のお気に入りが見分けられないと、お気に入りから目的のフォルダへすぐ移るという
お気に入り本来の価値（FR-061〜FR-067（directory-tree.md））が失われるため。

**Independent Test**: 場所の違う同じ名前のフォルダを2つお気に入りに登録し、片方の項目を選択して Return で
名前を変えて確定する。ツリー上で2つの項目が見分けられること、Finder で見た実際のフォルダの名前が変わって
いないこと、アプリを再起動しても変更後の名前が残っていることを確かめる。

**Acceptance Scenarios**:

- **US1-AS30**: **Given** 「お気に入り」の下に登録したフォルダの項目があり、ツリーでその項目を選択している,
  **When** Return を押して新しい名前を入力し、Return で確定する, **Then** その項目は新しい名前で表示され、
  実際のフォルダの名前とファイルリストの表示内容は変わらない。確認モーダルは表示されない
- **US1-AS31**: **Given** 「お気に入り」の下に登録したフォルダの項目がある, **When** その項目を右クリックして
  「名前を変更」を選び、新しい名前を入力して確定する, **Then** US1-AS30 と同じく、その項目だけが新しい名前で
  表示され、実際のフォルダの名前は変わらない
- **US1-AS32**: **Given** お気に入りの項目の名前を編集している, **When** Esc を押す, **Then** 編集を取り消し、
  項目は編集前の名前のまま表示される
- **US1-AS33**: **Given** 名前を変えたお気に入りの項目がある, **When** 名前を空にして確定する, **Then** 項目の名前は
  登録したフォルダの名前に戻る
- **US1-AS34**: **Given** 名前を変えたお気に入りの項目がある, **When** アプリを終了して再び起動する, **Then** その項目は
  変更後の名前で表示される
- **US1-AS35**: **Given** ツリーで「お気に入り」の見出し、ホーム・ボリュームの最上位、または通常のフォルダを選択している,
  **When** Return を押す, **Then** 何も起きない（名前の編集は始まらず、実際のフォルダの名前も変わらない）

### Edge Cases

- **EC-40**: 前後の空白だけの名前、または空の名前で確定した場合は、名前の変更を解除し、登録したフォルダの名前で
  表示する（エラーにしない）
- **EC-41**: ほかのお気に入りの項目と同じ名前、または登録したフォルダの名前と同じ名前で確定した場合も、そのまま受け付ける
  （お気に入りの名前は実際のファイル名ではないため、重複を拒否しない）
- **EC-42**: 見つからない項目（FR-067（directory-tree.md））も名前を変えられる。名前を変えても見つからない表示（淡色）は
  そのまま続き、同じ場所にフォルダが戻れば変更後の名前のまま通常の表示に戻る
- **EC-43**: 名前の編集中に、登録したフォルダがアプリの外で削除・移動・名前変更された場合も、編集は続けられる。
  確定した名前はその項目に付き、項目は FR-067（directory-tree.md）に従って見つからない表示になる
- **EC-44**: お気に入りから削除した項目は、付けていた名前も破棄する。同じフォルダを再び登録すると、登録したフォルダの名前で
  表示される
- **EC-45**: この機能を入れる前のバージョンで登録したお気に入りは、アップデート後も登録順のまま、登録したフォルダの名前で
  表示される（登録が失われたり、並びが変わったりしない）
- **EC-46**: ファイルリストに zip の中や検索結果を表示中に、ツリーのお気に入りの項目の名前を変えても、ファイルリストの表示内容・
  選択・プレビューは変わらない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-099**: ユーザーは、「お気に入り」の下の項目の表示名を、次のどの手段でも変更できなければならない。
  （1）その項目をツリーで選択し、ツリーにキーボードフォーカスがあるときに Return を押す。
  （2）その項目の右クリックメニューの「名前を変更」を選ぶ（右クリックした行を対象にする。A-21（directory-tree.md））。
  （3）ツリーにキーボードフォーカスがあり、その項目を選択しているときに、「編集」メニューの「名前を変更」を選ぶ。
  名前の編集はその項目の行の中で行い、編集を始めたときは現在の表示名を全選択した状態にする。Return またはほかの場所の
  クリックなどで編集を終えたときは確定し、Esc を押したときは取り消して編集前の表示名に戻す。
  名前の変更はお気に入りの表示名だけを変え、実際のフォルダの名前・場所・中身を変更してはならない。
  ファイルシステムを変えないため、確認モーダル（FR-022・FR-024（file-operations.md））は表示しない。
  「お気に入り」の見出し、ホーム・ボリュームの最上位、ツリーの通常のフォルダを選択中の Return は何もせず、
  それらの右クリックメニューに「名前を変更」は出さない。ツリーにフォーカスがあり、お気に入りの項目以外を選択しているときは、
  「編集」メニューの「名前を変更」は無効にする。ファイルリストに zip の中（FR-073（zip.md））または検索結果を表示中でも、
  ツリーにフォーカスがありお気に入りの項目を選択していれば（1）〜（3）は使える（zip の中の読み取り専用と検索結果の制限は
  ファイルリストの操作にだけ適用する）。ファイルリストにフォーカスがあるときの Return と「名前を変更」は、
  従来どおりファイル名の変更（FR-019（file-operations.md））とする
- **FR-100**: システムは、確定した名前を次のとおり扱わなければならない。前後の空白（改行を含む）を取り除く。
  取り除いた結果が空なら、表示名の変更を解除して、登録したフォルダの名前で表示する。名前は1行とし、改行は入力できない。
  長さは 255 文字までとし、それを超える入力はできない。ファイル名として使えない文字（`/`・`:` など）も含めてよい。
  ほかのお気に入りの項目と同じ名前も受け付ける。編集前と同じ名前で確定した場合は何も変えない
- **FR-101**: お気に入りの項目には、表示名を変更していればその名前を、変更していなければ登録したフォルダの名前を表示しなければ
  ならない。この表示名は、ツリーの項目の表示、アクセシビリティ API に公開する項目の名前、お気に入りの削除の確認モーダル
  （FR-064）の対象の名前に使う。名前の編集欄には「お気に入りの名前」というアクセシビリティラベルを付ける。表示名は
  お気に入りの登録内容の一部として FR-066（directory-tree.md）に従い保存し、次回起動時に復元する。この機能を入れる前に
  登録したお気に入りは、登録順のまま表示名を変更していない項目として復元しなければならない（保存形式を変える場合は旧形式から
  読み替える）。表示名は登録したフォルダが見つからない間（FR-067（directory-tree.md））も保ち、変更できる。お気に入りから
  削除したときは表示名も破棄する
- **FR-102**: お気に入りの表示名の編集中は、ファイル名の変更中と同じ扱いとしなければならない。既存の項目がいう「ファイル名の
  変更中」は、ファイル名の変更とお気に入りの表示名の編集の両方（以下「名前の変更中」）を指すものとし、既存の項目の本文は変えない。
  契約（contracts/keyboard-and-menus.md）でファイル名の変更中に無効とされている操作のすべて（⌃⌘T（FR-062）・⇧⌘F（FR-065）・
  ⌘F（FR-080（search.md））・ペインの表示切り替え（FR-090（window-layout.md））・zip ファイルの表示切り替え（FR-096（zip.md））・
  種類フィルタの「表示」メニュー項目・「中を表示」「上の階層へ」・検索結果の表示を終える Esc）は、編集を終えるまで無効にする。編集を始めても、ツリーの選択・
  ファイルリスト・プレビュー・最後に選択していたフォルダ（FR-003（overview.md））は変えない
- **FR-064**（変更）: ユーザーは、「お気に入り」の下の項目を、その項目の右クリックメニューの「お気に入りから削除」と、
  その項目をツリーで選択中の ⌘⌫（ファイルリストの「ゴミ箱に入れる」と同じキー）で、お気に入りから削除できなければ
  ならない。どちらの手段でも、実行前に対象のお気に入りの表示名（FR-101）と登録したフォルダの絶対パス、「お気に入りから削除する」旨を
  示す確認モーダルを表示し（同じ表示名の項目が複数あっても対象を見分けられるようにする）、
  キャンセルした場合は登録を変えてはならない。確認モーダルの省略設定（FR-023）がオンのときは、ファイル操作と
  同じく確認を省略して即座に削除する。削除はお気に入りの登録だけを取り除き、実際のフォルダとその中身を変更しては
  ならない（ゴミ箱にも入れない）。お気に入りの項目の右クリックメニューには「ゴミ箱に入れる」を出さない。ホーム・
  ボリュームの最上位・「お気に入り」の見出しの右クリックメニューには削除の項目を出さず、それらを選択中に ⌘⌫ を押しても
  何もしない。ツリーの通常のフォルダは FR-079 に従ってゴミ箱に入れられる。ファイルリストに
  フォーカスがあるときの ⌘⌫ は、従来どおり選択中のファイルをゴミ箱に入れる（FR-019）

### Key Entities *(include if feature involves data)*

- **お気に入り**（変更）: ユーザーが登録したフォルダの一覧。各登録はフォルダの場所、ユーザーが付けた表示名（任意。
  付けていなければ登録したフォルダの名前で表示する）、その場所にフォルダが見つかるかどうか（見つかる／見つからない）を持ち、
  ツリー最上部の仮想項目「お気に入り」の下に表示される。実際のフォルダとは独立し、登録・削除・名前の変更は
  ファイルシステムを変更しない

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-018**: 場所の違う同じ名前のフォルダを2つお気に入りに登録し、片方の名前を変えたあと、ユーザーがツリーの表示だけで
  目的のフォルダの項目を選べる割合が 100%（取り違え 0 件）
- **SC-019**: お気に入りの名前の変更を行ったあと、実際のフォルダの名前・場所・中身に変更が残るものが 0 件
- **SC-020**: Finder の操作に慣れたユーザーが、説明なしでお気に入りの項目の名前の変更を初回で完了できる
- **SC-021**: 変更した表示名が、アプリの再起動後に 100% 復元される

## Assumptions

- **A-19**（変更）: お気に入りの項目名は、既定では登録したフォルダの名前とし、ユーザーが表示名を変更できる（FR-099）。
  並びは登録した順（新しいものを末尾）とする。並べ替え・ドラッグによる登録は範囲外
- **A-29**: お気に入りの名前の変更は、ファイルの名前の変更（FR-024（file-operations.md））と違って確認モーダルを出さない。
  ファイルシステムを変えず、Esc で取り消せ、空にして確定すれば元の名前に戻せるため、憲章の「確認または取り消し可能性」を満たす
- **A-30**: 次は今回の範囲外とする。ツリーの通常のフォルダ（実際のフォルダ）の名前の変更、選択中の項目のクリックや
  一定時間の長押しによる編集の開始、お気に入りの項目への絶対パスのツールチップの表示、表示名の一括リセット
- **A-31**: 編集をほかの場所のクリックなどで終えたときに確定する扱いは、Finder の名前の変更に合わせた
