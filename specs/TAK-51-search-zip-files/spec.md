# Feature Specification: ファイル名検索で zip ファイルも検索対象にする

**Feature Branch**: `claude/great-johnson-41kca1`（Cloud が指定した作業ブランチ。feature ディレクトリとは独立）

**Created**: 2026-11-02

**Status**: Draft

**Input**: [TAK-51](https://linear.app/takyoshida/issue/TAK-51/ファイル名検索で-zip-ファイルも検索対象にする)「ファイル名検索で zip ファイルも検索対象にする」。会話で「ISSUE TAK-51に対応してください」と依頼され、Issue の「検討事項」にあった次の点を保守者が決めた。

- 検索結果の zip ファイルの行をダブルクリック・⌘↓したときは、zip の中（最上位）を開く。検索結果の表示を終える流れはフォルダの行（FR-140）と同じにする
- 検索結果の zip ファイルの行へのファイル操作（コピー・名前の変更・ゴミ箱・移動・複製・ドラッグ&ドロップ）は、通常の一覧の zip ファイルと同じにする
- 種類フィルタ（画像のみ／動画のみ）は、フォルダの行と同じく zip ファイルの行を隠さない
- 検索結果の表示中（検索中を含む）に「zipファイルを表示」を切り替えても、既存の結果と実行中の検索は変えない。切り替えは次の新しい検索から反映する

## User Scenarios & Testing *(mandatory)*

変更点だけを定める。検索全般は FR-080〜FR-087・FR-139・FR-140（search.md）、zip ファイルの表示は FR-068・FR-069・FR-075・FR-095（zip.md）、
zip ファイルのファイル操作は FR-073（zip.md）に従う。US51〜US53 は永続シナリオ ID。

### User Story 1 - zip ファイルを名前から探す (Priority: P1)

利用者は、⌘F の検索で、フォルダやファイルと同じく、zip ファイルを名前（拡張子を含む）から探す。「zipファイルを表示」をオンにしているときだけ、
一致した zip ファイルが検索結果の一覧に出る。

**Why this priority**: 中を閲覧できる zip を名前から探す手段が現在なく、通常のフォルダの一覧を辿るしかない。これが本機能の中心の価値。

**Independent Test**: 「zipファイルを表示」をオンにし、配下に `trip_2024.zip` がある階層で `trip` を検索すると、zip ファイルの行が一覧に出る。

**Acceptance Scenarios**:

- **US51-AS1**: **Given** 「zipファイルを表示」がオンで、検索起点の配下に `trip_2024.zip`・`Trip.ZIP`・`notes.txt` がある, **When** キーワード `trip` で検索する, **Then** `trip_2024.zip` と `Trip.ZIP` が大文字小文字を区別せずに行として表示される。`notes.txt` は表示されない
- **US51-AS2**: **Given** 「zipファイルを表示」がオンで、`photos.zip` の中にディレクトリ `kyoto` とファイル `kyoto_01.jpg` がある, **When** キーワード `kyoto` で検索する, **Then** `photos.zip` は行として表示されない。zip の中のディレクトリ名・ファイル名は照合しない
- **US51-AS3**: **Given** 「zipファイルを表示」がオンで、`a/backup.zip` と `b/backup.zip` がある, **When** キーワード `backup` で検索する, **Then** 2つとも別の行として表示され、リスト形式では「場所」列で、サムネイル形式ではポインタを重ねたときの説明で見分けられる
- **US51-AS4**: **Given** 「zipファイルを表示」がオンで、`archive.zip` と `archive.zip.bak` と `archive.zipx` がある, **When** キーワード `*.zip` で検索する, **Then** 名前全体が `.zip` で終わる `archive.zip` だけが表示される（FR-082 のワイルドカード）
- **US51-AS5**: **Given** 「zipファイルを表示」がオンで、zip ファイルだけが一致する検索をする, **When** 検索が終わる, **Then** 検索バーの件数は一致した zip ファイルの件数になり、該当する項目がない旨のメッセージは出ない
- **US51-AS6**: **Given** 「zipファイルを表示」がオンで、隠しフォルダ・パッケージ・フォルダへのシンボリックリンクの中に名前が一致する zip ファイルがあり、隠しファイル `.kyoto.zip` もある, **When** キーワード `kyoto` で検索する, **Then** これらの zip ファイルは行として表示されない（FR-083）

### User Story 2 - 「zipファイルを表示」の設定に従う (Priority: P1)

利用者は、「zipファイルを表示」（FR-095）がオフのときは zip ファイルを検索結果に出さず、オンのときだけ出す。設定の既定はオフで、これまでの検索結果は変わらない。

**Why this priority**: 設定がオフの利用者の検索結果に、これまでになかった行が増えてはならない。既存の挙動を守る前提になる。

**Independent Test**: 設定をオフにして `trip` を検索すると zip ファイルが出ず、オンにして検索し直すと出る。

**Acceptance Scenarios**:

- **US52-AS1**: **Given** 「zipファイルを表示」がオフ（既定）で、検索起点の配下に `kyoto.zip` とフォルダ `kyoto` がある, **When** キーワード `kyoto` で検索する, **Then** フォルダ `kyoto` だけが表示され、`kyoto.zip` は表示されない。件数にも数えない
- **US52-AS2**: **Given** 設定をオフにして検索し、検索結果を表示中（検索中を含む）, **When** 「zipファイルを表示」をオンにする, **Then** 既存の検索結果と実行中の検索は変わらず、zip ファイルの行は増えない。同じキーワードで新しく検索すると zip ファイルが現れる
- **US52-AS3**: **Given** 設定をオンにして検索し、検索結果に zip ファイルの行がある, **When** 「zipファイルを表示」をオフにする, **Then** 既存の検索結果は変わらず、zip ファイルの行は残る。同じキーワードで新しく検索すると zip ファイルの行は出ない
- **US52-AS4**: **Given** 検索結果を表示中に設定を切り替えた, **When** Esc で検索結果の表示を終える, **Then** 検索前のフォルダの一覧は、切り替え後の設定に従って zip ファイルの行を出す・出さない（FR-095）

### User Story 3 - 検索結果の zip ファイルを開く・操作する (Priority: P2)

利用者は、検索結果に出た zip ファイルの行を、通常の一覧の zip ファイルと同じく開き、ファイル操作の対象にする。

**Why this priority**: 見つけた zip の中をすぐ見られると探した意味が出るが、名前から探せることが先にできれば成り立つ。

**Independent Test**: 検索結果の zip ファイルの行をダブルクリックすると、検索結果の表示が終わり、zip の中の最上位の一覧になる。

**Acceptance Scenarios**:

- **US53-AS1**: **Given** フォルダ A を表示してから検索し、検索結果に zip ファイル z（A の配下のフォルダ B にある）がある, **When** z の行をダブルクリックする（または選択して ⌘↓ を押す）, **Then** 検索結果の表示が終わり（検索中なら止まり）、ファイルリストは z の中の最上位の一覧になり、ツリーの選択は B になる（B がツリーに表示されない場合は EC-102 の祖先）。キーボードフォーカスはファイルリストに残る。続けて ⌘[ を押すと A の一覧に戻り、検索結果には戻らない
- **US53-AS2**: **Given** 検索結果の zip ファイルの行にフォーカスがある, **When** 画面と右クリックメニューを見る, **Then** 行頭アイコン・縮小画像は通常の一覧の zip ファイルと同じ汎用アイコン、「種類」は zip の種類名になる。右クリックメニューには「中を表示（⌘↓）」と区切り線がファイル操作の前に加わり、「上の階層へ」は出ない
- **US53-AS3**: **Given** 検索結果で動画を再生中, **When** 矢印キーで zip ファイルの行へ選択を移す, **Then** プレビューは空になり、再生は止まる。フルスクリーン中の矢印キーの移動では zip ファイルの行に止まらずに飛ばし、スライドショーの対象にもならない
- **US53-AS4**: **Given** 「画像のみ表示」をオンにしている, **When** zip ファイルと動画だけが一致する検索をする, **Then** zip ファイルの行は表示され、動画は表示されない。残った zip ファイルの行に加えて、画像のみ表示中で該当するファイルがない旨のメッセージが表示される
- **US53-AS5**: **Given** 検索結果に zip ファイルの行 z がある, **When** z の名前を `z2.zip` に変える, **Then** z の行はキーワードに一致しなくなっても `z2.zip` として一覧に残る。名前を `z2.txt` のように拡張子が `.zip` でない名前に変えると、行は一覧から外れる
- **US53-AS6**: **Given** 検索結果に zip ファイルの行 z がある, **When** z をゴミ箱に入れる（または別のフォルダへ移動する）, **Then** z の行が一覧から外れる。コピー・複製・ドラッグ&ドロップの操作は、通常の一覧の zip ファイルと同じに行える。検索結果へのペーストは従来どおりできない（FR-087）

### Edge Cases

- 名前が `x.zip` の**フォルダ**は、これまでどおりフォルダの行として一致する（zip ファイルの行にはしない）。zip ファイルの設定にも従わない（FR-083）
- 中身が zip として読めないファイル（壊れた・拡張子だけが `.zip` のファイル）も、名前が一致すれば行として表示する。判定は通常の一覧と同じく拡張子による。開いたときは通常の一覧の zip ファイルと同じ扱いになる（FR-069）
- 読み取り権限のない zip ファイルも、名前が一致すれば行として表示する
- 検索の途中で「zipファイルを表示」を切り替えても、実行中の検索の対象は変わらない（US52-AS2）
- zip の中を表示中に始めた検索の起点・履歴の扱い（EC-100）は変えない。起点は zip ファイルを含むフォルダで、その zip ファイル自身も名前が一致すれば（設定がオンのとき）行になる

## Requirements *(mandatory)*

### Functional Requirements

- **FR-083（変更）**: 検索は、検索起点ディレクトリ以下のすべての階層のサブフォルダを辿って行わなければならない。一致の対象は、
  対応メディアファイル（FR-039。判定は FR-009 と同じく拡張子による）と、フォルダ（通常のフォルダの一覧にフォルダの行として
  表示するもの。FR-076）と、「zipファイルを表示」（FR-095）がオンのときの zip ファイル（FR-068。拡張子 `.zip`、大文字小文字を区別しない）とする。
  検索起点ディレクトリそのものは一致の対象にしない。隠しファイルと隠しフォルダ（とその中）は
  対象外とし、シンボリックリンクのフォルダとパッケージ（.app など）の中は辿らない。フォルダへのシンボリックリンクとパッケージ
  そのものは、フォルダとしても一致の対象にしない。ファイルへのシンボリックリンクは、通常のフォルダの一覧と同じく名前（拡張子）で
  対応メディアファイルか zip ファイルかを判定し、一致の対象にする。名前が一致したフォルダの中も辿り続け、中のファイルとフォルダと zip ファイルはそれぞれの
  名前で照合する（親のフォルダが一致したことを理由に、中の項目を一致とはしない）。読み取り権限のないフォルダは、名前が一致すれば
  一致の対象にするが、中は飛ばして検索を続ける。zip ファイルの中のディレクトリとファイルは照合せず、zip の中も検索しない。
  明示的に指定した検索起点が隠しフォルダの配下にある場合は、起点より上の隠しフォルダを理由に対象外にはしない。
  その起点以下で現れる隠しフォルダは従来どおり中ごと飛ばし、結果から開いたフォルダのツリー同期は EC-102 に従う
- **FR-269**: システムは、zip ファイルを一致の対象にするかどうかを、検索を始めた時点の「zipファイルを表示」（FR-095）の値で決めなければならない。
  オフ（既定）の検索では zip ファイルを照合せず、結果にも件数にも含めない。オンの検索では、zip ファイルの名前（拡張子を含む）を FR-082 の規則
  （部分一致・ワイルドカード・大文字小文字と正規化の違いを区別しない）でキーワードと照合し、一致した zip ファイルを検索結果の行にする。
  その検索の間、決めた対象は変えない。検索結果の表示中や検索中に設定を切り替えても、既存の結果・実行中の検索・件数は変えず、
  切り替えた値は次に始める検索から使う。検索を終えて検索前の一覧に戻ったときは、切り替え後の値に従う（FR-095）
- **FR-270**: システムは、検索結果の zip ファイルの行を、通常の一覧の zip ファイルの行（FR-068・FR-075（zip.md））と同じく表示し、扱わなければならない。
  行頭アイコンと縮小画像は zip ファイルを示す汎用アイコン、「種類」は通常の一覧と同じ zip の種類名、「作成日」と「サイズ」はファイルシステムの値とする。
  「場所」列とサムネイル形式のツールチップ（FR-084）、名前の変更への追随（FR-105）、変更通知への追随（FR-232）は、ファイルの行と同じに扱う。
  zip ファイルの行を選択（フォーカス）したときはプレビューを空にし、再生中の動画を止める。種類フィルタ（FR-056（file-list.md））は zip ファイルの行に適用せず
  常に表示し、FR-060（file-list.md）の判定ではファイルとして数えない。一致したメディアファイルが種類フィルタで1件も表示されない場合は、
  残った zip ファイルの行に加えて絞り込み中のメッセージを表示する。一致したメディアファイルが元々1件もない場合は、zip ファイルの行が
  1つでもあれば該当する項目がない旨のメッセージも絞り込み中のメッセージも出さない。フルスクリーン中の矢印キーによる移動（FR-046（preview.md））では
  zip ファイルの行に止まらずに飛ばし、スライドショー（FR-115（preview.md））の対象にしない。検索バーの件数（FR-084）は、
  一致したファイル・フォルダ・zip ファイルの合計とする
- **FR-271**: ユーザーは、検索結果の zip ファイルの行をダブルクリックするか、フォーカス行にして ⌘↓（「ファイル」メニューと右クリックメニューの「中を表示」を含む）を押すことで、
  その zip の中の最上位の一覧を開けなければならない。開くと、システムは検索結果の表示を終え（検索中なら止め）、ファイルリストをその zip の中の最上位の一覧
  （FR-069・FR-070（zip.md））に切り替える。ツリーの選択は、zip ファイルを含むフォルダへ同期する（FR-078（file-list.md）。最後に選択していたフォルダ
  （FR-003（overview.md））としても保存する）。キーボードフォーカスはファイルリストに残す。zip ファイルを含むフォルダがツリーに表示されない場合は、
  EC-102 のとおり表示可能な最も近い祖先を選択・保存し、一覧と履歴の場所は開いた zip のままにする。履歴は FR-113（navigation-history.md）に従い、
  検索結果は記録せず、開いた zip の最上位を新しい履歴として記録する（開いた場所が検索前の場所と同じにはならない。zip の中で始めた検索の場合は EC-100）。
  検索結果の右クリックメニューでは、zip ファイルの行に「中を表示（⌘↓）」と区切り線をファイル操作の前に加え、「上の階層へ」は出さない。
  検索結果を開いたときの「zipファイルを表示」の値は問わない（切り替え後も、結果に残っている行は開ける）
- **FR-272**: 検索結果の zip ファイルの行は、FR-087 のファイル操作の対象とする。zip ファイルそのものは通常の一覧と同じく FR-018〜FR-027 の対象とし（FR-073（zip.md））、
  コピー・名前の変更・ゴミ箱に入れる・移動・複製・ドラッグ&ドロップを通常の一覧と同じに行える。検索結果へのペーストは従来どおりできない（FR-087）。
  ゴミ箱に入れた・移動した zip ファイル、およびアプリの外で削除・移動された zip ファイルは一覧から外す。名前を変更した zip ファイルは、キーワードに
  一致しなくなっても新しい名前で一覧に残す。ただし、拡張子が `.zip` でない名前に変えた場合は、FR-083 の対象外になるため一覧から外す。
  複製で作った zip ファイルや、検索の後に新しく現れた zip ファイルは一覧に加えない
- **FR-095（変更）**: ユーザーは、ファイルリストに zip ファイル（FR-068）を表示するかどうかを切り替えられなければならない。
  設定は独立したオン・オフで、既定はオフ（非表示）とする。設定は FR-003 に従い保存し、再起動後に復元しなければ
  ならない。保存された値がない初回起動時のみ、既定の非表示を使う。設定は通常のフォルダの一覧にだけ適用し、
  リスト形式・サムネイル形式の両方に同じように適用する。zip の中の一覧（FR-070）は zip ファイルの行を含まないため、表示は変わらない。
  検索結果（FR-084）に zip ファイルの行を含めるかどうかは、検索を始めた時点の設定の値で決まり（FR-269）、検索結果の表示中に切り替えても既存の結果は変わらない。
  オフの間は通常の一覧に zip ファイルの行を表示せず、その行の
  選択・プレビュー・フルスクリーンの移動・開く操作（FR-069）の対象にもならない。種類フィルタ（FR-056）とは
  独立し、両方の条件を満たす行だけを表示する

### Key Entities *(include if feature involves data)*

- **検索結果の zip ファイルの行**: 検索結果の一覧の1行。名前（拡張子を含む）・場所・種類・作成日・サイズを持つ。zip の中身は持たない。通常の一覧の zip ファイルの行（FR-068）と同じ項目・同じ操作を使う

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-133**: 「zipファイルを表示」をオンにして、名前に同じ語を含む zip ファイル50個（大文字の拡張子 `.ZIP` を10個含む）、含まない zip ファイル50個、名前に同じ語を含む隠し zip ファイル・
  パッケージ・フォルダへのシンボリックリンクの中の zip ファイル・名前に同じ語を含むディレクトリを中に持つ zip ファイルを各5個持つ階層を検索する。一致する zip ファイルが漏れなく50件表示され、
  それ以外の zip ファイルと、zip の中の名前による行が表示された件数が0件となる
- **SC-134**: SC-133 と同じ階層を、「zipファイルを表示」をオフにして検索する。zip ファイルの行が表示された件数と件数に数えられた zip ファイルの数が0件となる。検索を終えるまでの時間は、SC-054（search.md）の基準を超えない
- **SC-135**: 検索結果の表示中（検索中を含む）に「zipファイルを表示」を切り替える操作を、オンからオフ・オフからオンで各10回行う。既存の結果の件数が変わった回数が0回、次の新しい検索から切り替え後の設定に従った回数が20回中20回となる

## Assumptions

- **A-164**: 対象にするのは、通常のフォルダの一覧で zip ファイルの行になるもの（FR-068。拡張子 `.zip`、大文字小文字を区別しない）に合わせる。拡張子で判定し、中身が zip として読めるかは確かめない。
  `.zipx` や `.zip.bak` など拡張子が `.zip` でないファイルは対象にしない
- **A-165**: zip の中のディレクトリ名・ファイル名の検索（zip の中を辿る検索）は範囲外とする。検索の速度と、zip の文字コード判定（FR-074）・読み取りを検索に持ち込まないためである
- **A-166**: 検索結果の zip ファイルを対象にするかは、検索を始めた時点の「zipファイルを表示」の値で決め、検索の間は変えない。検索条件を保存しない（FR-086）規則と、
  オンに切り替えても検索し直さずには zip ファイルを増やせない（途中の値で一部だけ含まれる状態を避ける）ことによる
- **A-167**: 種類フィルタ（FR-056）は zip ファイルの行を隠さない。通常の一覧の zip ファイル（FR-056 の末尾）とフォルダの行（FR-139）と同じ扱いに揃える
- **A-168**: 検索結果の zip ファイルの行を開く操作は、フォルダの行を開く操作（FR-140）と同じ流れ（検索結果の表示を終え、履歴は検索結果を記録せずに開いた場所を新しい履歴にする）とする。
  検索結果を保ったまま zip の中を見る操作は範囲外とする（A-80 と同じ）
- **A-169**: zip ファイルを検索結果から開いたあと、zip の最上位から ⌘↑ で戻る一覧では、「zipファイルを表示」がオフであれば zip ファイルの行が表示されない（FR-070）。その場合の扱いは FR-070 に従い、この feature では変えない
- **A-79（削除）**: zip ファイルの名前と zip の中のディレクトリは照合しない（旧）。zip ファイルの名前による検索を範囲外とする旧規則は、本 feature で FR-083（変更）・FR-269 に置き換える。zip の中のディレクトリの検索は範囲外のまま（A-165）
- **A-81（変更）**: 検索バーの件数は、一致したファイルとフォルダと zip ファイルの合計とし、内訳は表示しない。種類フィルタと件数の関係は従来の検索結果と同じとする
