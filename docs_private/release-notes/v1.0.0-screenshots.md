# v1.0.0 README スクリーンショットの撮影依頼

README.md と README.ja.md の「Features」（主な機能）の直後に、次の3枚を参照している。
ファイルがないと GitHub で画像が壊れて表示されるため、**マージと公開の前に3枚を追加する**。
画像は英語版と日本語版で共有する。

## 共通の条件

- 表示言語は英語（設定 → Language → English）。外観は既存の `docs/images/screenshot.jpg` と同じダークモードにそろえる。
  ウインドウは既存より小さくしてよい（下の大きさの目安に従う）
- 保存形式は JPEG（v1.0.0 で PNG から変更）。既存の画像と同じ Retina（2x、144dpi）で撮る
- 大きさは横 2000〜2400px（撮る範囲は 1000〜1200pt）、縦は 1500px 以下を目安にする。
  GitHub の README 欄は横 800〜1000px 程度で、それより大きい画像は縮小されるため、範囲を広げすぎると文字が読めなくなる
  - 目安: `list-view.jpg` 2200×1400、`quick-look.jpg` 2400×1500、`shortcuts.jpg` 2400×1400
  - 大きすぎたら `sips -Z 2400 <ファイル>` で長辺を縮める（縦横比は保たれる）
- ファイルサイズは1枚 1〜2MB 以内を目安にする（v1.0.0 では JPEG に変え、`screenshot.jpg` を含む4枚とも 200〜270KB）
- ⌘⇧4 → Space → ウインドウをクリックで撮ると、既存と同じ影付きの画像になる
- ホームのユーザー名・個人のフォルダ名・個人の写真が写らないようにする。フィクスチャ用のフォルダを使う

## 1. `docs/images/list-view.jpg` — リスト形式と列のメニュー

見せる機能: 列の表示切り替え（TAK-47）、フォルダと zip の固定色アイコン（TAK-46）、フォルダを先頭にまとめる名前順（TAK-54）

- ⌃⌘Z で zip ファイルを表示し、⌘2 でリスト形式にする
- サブフォルダ2〜3個、zip ファイル1〜2個、画像と動画を含むフォルダを開く。名前順（昇順）で並べる
- 列見出しを右クリックして、作成日・種類・サイズ・変更日のメニューを開いた状態で撮る。サイズと変更日は表示しておく
- 確認する点: フォルダの行が先頭にまとまり、フォルダは青、zip は黄のアイコン。右にプレビューが出ている

## 2. `docs/images/quick-look.jpg` — クイックルック

見せる機能: Space によるクイックルック（TAK-18）

- サムネイル形式（⌘1）で画像を1枚選び、Space を押す
- クイックルックのパネルがメインウインドウの上に開いた状態で撮る。パネルとメインウインドウの両方が入るように、
  ウインドウではなく画面の範囲（⌘⇧4 でドラッグ）で撮る
- 確認する点: 選択中のサムネイルとパネルの画像が同じ。パネルがメインウインドウの大半を隠していない

## 3. `docs/images/shortcuts.jpg` — ショートカット一覧

見せる機能: ショートカット一覧（TAK-22）。ショートカットの変更（TAK-24）を見せたい場合は、代わりに設定の「Shortcuts」タブでもよい

- ⌘/ でショートカット一覧を開き、メインウインドウの横に並べる
- 2つのウインドウが入る範囲で撮る
- 確認する点: 一覧の区分の見出しとキーが読める大きさで写っている

設定の「Shortcuts」タブにする場合は、README.md と README.ja.md の3枚目の代替テキストを
「Settings → Shortcuts」（設定の「ショートカット」）に合わせて直す。

## 追加した後

- `git add docs/images/list-view.jpg docs/images/quick-look.jpg docs/images/shortcuts.jpg`
- GitHub で README を表示し、3枚とも表示されること、縦に長すぎないことを確かめる。長すぎる場合は、
  `<img src="…" width="…">` での縮小か、枚数を減らすことを検討する（英語版と日本語版を同じ構造に保つ）
