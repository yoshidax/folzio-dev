Folzio 1.0.0 brings faster everyday controls, more ways to organize folders, and a customizable interface.

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and not notarized;
see the README for how to open it the first time.

## New

### Viewing

- **Quick Look**: press Space in the file list to Quick Look the selected media (several at once if you select several).
  Press Space again to close it.
- **Open in the default app**: double-click an image or video in the file list to open it in its default app.
- **Full screen with a double-click**: double-click the preview to enter full screen, and double-click again to return.
- **Video seeking in the normal layout**: `<` / `>` skip a video back or forward 5 seconds, and Space plays or pauses it
  while the preview's video has the focus.

### Organizing

- **New Folder**: create an "untitled folder" with ⇧⌘N, File → New Folder, or the context menu, and name it in place.
- **Select several folders in the tree**: ⌘-click, Shift-click, or Shift+↑↓, then drag to move (⌥ to copy) or press
  ⌘Delete to move them to the Trash together.
- **Drop onto folders in thumbnail view**: drag files onto a folder shown in the thumbnail grid to move or copy them.
- **Rename by case only**: names that differ only in letter case (for example, `photo.jpg` → `Photo.jpg`) can now be applied.

### Search and list

- **Find zip files by name**: while zip files are shown (⌃⌘Z), name searches also match zip files.
  Archive contents are still not searched.
- **Choose list columns**: right-click the column header to show or hide Date Created, Kind, Size, and Date Modified.
  The Size and Date Modified columns are new (hidden by default) and can be used for sorting.
- **Folders first**: when sorting by name, folders stay above files in both ascending and descending order.
- **Clearer icons**: folders and zip files in the file list use fixed blue and yellow icons.

### Customization

- **Customizable toolbar**: right-click the toolbar and choose Customize Toolbar… to rearrange or remove button groups.
  The layout and display mode are restored on the next launch.
- **Custom keyboard shortcuts**: reassign menu shortcuts in Settings (⌘,) → Shortcuts. Conflicts are detected,
  and each command can be reset to its default.
- **Shortcut reference**: File → Keyboard Shortcuts… (⌘/) opens a reference grouped by purpose in its own window.
- **About Folzio**: the app menu shows the app icon, version, and a link to the GitHub repository.

## Improvements

- Rapidly moving through many images loads fewer images at once and skips unnecessary prefetching.
- Images replaced at the same path are refreshed in thumbnails and the preview.
- Renaming, moving, or deleting the displayed folder or one of its ancestors outside the app is reflected in the list.
- The Settings window has consistent section spacing and closes together with the main window.

## Fixes

- Choosing Stop in a conflict dialog now stops the rest of the transfer.
- Choosing Replace for a folder that contains the item being copied or moved is now refused, instead of moving that folder
  (and the source inside it) to the Trash.
- Reloading a folder no longer lets an older result overwrite a newer one.
- After a rejected or cancelled rename, thumbnails keep the original name, and finished renames return the name to center alignment.

Folzio 1.0.0 では、日常の操作をより速くし、フォルダの整理方法を増やし、画面を自分好みに整えられるようにしました。

macOS 15 以降の Apple silicon Mac が必要です。アドホック署名で公証は受けていないため、初回の開き方は README を参照してください。

## 新機能

### 閲覧

- **クイックルック**: ファイルリストで Space を押すと、選択中のメディアをクイックルックで確認できます（複数選択時はまとめて）。
  もう一度 Space で閉じます。
- **既定のアプリで開く**: ファイルリストで画像や動画をダブルクリックすると、既定のアプリで開きます。
- **ダブルクリックでフルスクリーン**: プレビューをダブルクリックするとフルスクリーンになり、もう一度ダブルクリックで戻ります。
- **通常表示での動画の操作**: `<` / `>` で動画を5秒戻す・送る操作ができ、プレビューの動画にフォーカスがあるときは
  Space で再生・一時停止できます。

### 整理

- **新規フォルダ**: ⇧⌘N、「ファイル > 新規フォルダ」、右クリックで「名称未設定フォルダ」を作り、その場で名前を付けられます。
- **ツリーでのフォルダの複数選択**: ⌘クリック・Shift クリック・Shift+↑↓ で選び、ドラッグで移動（⌥ でコピー）、
  ⌘Delete でまとめてゴミ箱に入れられます。
- **サムネイル形式でフォルダへドロップ**: サムネイルに並ぶフォルダへファイルをドラッグして、移動・コピーできます。
- **大文字小文字だけの名前の変更**: `photo.jpg` → `Photo.jpg` のような変更を確定できるようになりました。

### 検索と一覧

- **zip ファイルの名前の検索**: zip ファイルの表示中（⌃⌘Z）は、名前の検索で zip ファイルも見つかります。zip の中は引き続き対象外です。
- **列の表示の選択**: 列見出しを右クリックして、作成日・種類・サイズ・変更日の列を表示・非表示にできます。
  サイズと変更日の列は新しく追加したもので（既定は非表示）、並べ替えにも使えます。
- **フォルダを先頭に**: ファイル名順では、昇順・降順ともフォルダをファイルより前にまとめます。
- **見分けやすいアイコン**: ファイルリストのフォルダと zip ファイルのアイコンを、青と黄の固定色にしました。

### カスタマイズ

- **ツールバーのカスタマイズ**: ツールバーを右クリックし「ツールバーをカスタマイズ…」で、ボタンのグループを並び替えたり外したりできます。
  並びと表示モードは次回起動時に復元されます。
- **ショートカットの変更**: 設定（⌘,）の「ショートカット」で、メニューのコマンドのキーを変更できます。重複を検出し、
  コマンドごとに既定値へ戻せます。
- **ショートカット一覧**: 「ファイル > ショートカット一覧…」（⌘/）で、目的別の一覧を別ウインドウで開けます。
- **Folzio について**: アプリメニューから、アイコン・バージョン・GitHub リポジトリへのリンクを表示します。

## 改善

- 多くの画像を続けて移動したとき、同時に読み込む画像の数を抑え、不要な先読みをしないようにしました。
- 同じパスで置き換わった画像を、サムネイルとプレビューに反映します。
- 表示中のフォルダやその上の階層が、アプリの外で名前の変更・移動・削除されたとき、一覧に反映します。
- 設定画面のセクションの間隔を揃え、メインウインドウを閉じると設定ウインドウも閉じるようにしました。

## 修正

- 競合ダイアログで「中止」を選んだあと、残りの転送を止めるようにしました。
- コピー・移動する項目を中に含むフォルダを「置き換える」操作を拒否するようにしました。以前はそのフォルダ（と中の転送元）がゴミ箱へ移ることがありました。
- フォルダの再読み込みで、古い結果が新しい結果を上書きしないようにしました。
- 名前の変更を拒否・取り消したあとにサムネイルが元の名前を保ち、変更後はファイル名が中央寄せに戻るようにしました。
